Victim B held zTokens through the entire inactivity window and expected full pro-rata credit. Sequence: blocks N..N+k inactivity, block N+k+1 A deposits then any action triggers accrue. Invariant broken: NON-INTERFERENCE. Impact: theft of unclaimed yield (High). Proof: compare B's zToken redemption value in a run where A deposits immediately before the catch-up accrual vs a run where A deposits only after accrual settles.
