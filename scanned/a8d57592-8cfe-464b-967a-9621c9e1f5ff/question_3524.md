# Q3524: find-superset via collateral-add: make a victim's position resolve to a worse efficiency gro

## Question
Does `collateral-add` (mainnet/contracts/market/v0-4-market.clar:1020) let an unprivileged attacker who controls whether this asset is already collateral (the is-new-collateral branch) reach `find-superset` (mainnet/contracts/registry/v0-egroup.clar:262) in a state where it make a victim's position resolve to a worse efficiency group than it chose? - Expected Immunefi impact: Critical - protocol insolvency through uncollateralised debt
