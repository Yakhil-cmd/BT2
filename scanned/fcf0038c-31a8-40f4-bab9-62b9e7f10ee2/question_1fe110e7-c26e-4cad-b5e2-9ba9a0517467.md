Binding: `Stack#ignore_ci` toggled only by an authenticated operator/config change == toggled by any webhook whose payload names that stack's repository, never by an unrelated one. Scoped impact: Critical - a cross-tenant status webhook alters a victim stack's deploy-gating configuration. Proof idea: minitest test asserting `stack.reload.ignore_ci` (or CI-enabled flag) changes only when the verified payload's repository matches; demonstrate it also changes when it doesn't.
