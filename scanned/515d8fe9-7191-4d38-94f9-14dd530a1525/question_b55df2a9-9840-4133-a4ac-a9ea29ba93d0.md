Binding: the `stack` on which `trigger_continuous_delivery` acts must be a stack whose `repository.full_name` equals the `repository.full_name` in the verified webhook payload -- never checked. Impact: Critical, unauthorized deploy triggered cross-tenant. Proof: minitest test constructing this exact fixture pairing and asserting a deploy/`ContinuousDeliveryJob` fires for Stack A from Repository B's webhook.
