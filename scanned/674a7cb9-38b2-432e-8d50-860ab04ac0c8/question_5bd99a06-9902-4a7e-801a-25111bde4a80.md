Preconditions: victim Stack currently has `ignore_ci: false` requiring green CI before deploy. Attacker sends a forged/collision status for a shared SHA. Impact: Critical, as this can alter the victim Stack's CI enforcement (`Commit#deployable?`) via `stack.ignore_ci?`.
