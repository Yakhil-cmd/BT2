# Q3239: num_rewards arithmetic overflows on reachable values (mod.rs)

## Question

- Entrypoint: a transaction that lands in a block and is replayed by every node on the cluster
- Attacker controls: a denominator that the attacker can drive to zero or one

- Fast validation: Proptest `num_rewards` across full integer ranges; assert checked arithmetic and no wrap in release mode.
