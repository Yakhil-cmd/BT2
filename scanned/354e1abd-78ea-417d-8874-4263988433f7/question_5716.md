# Q5716: vault-system-borrow via repay: write a stranger's ledger through an unsolicited on-behalf

## Question
Does `repay` (mainnet/contracts/market/v0-4-market.clar:1316) let an unprivileged attacker who controls `amount`, including far above the real debt (the capping path) reach `vault-system-borrow` (mainnet/contracts/market/v0-4-market.clar:198) in a state where it write a stranger's ledger through an unsolicited on-behalf-of call?
