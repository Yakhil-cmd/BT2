Target: `Webhooks::Handlers::CheckSuiteHandler#process`. Attacker action: POST a `check_suite` event verified under attacker's own org, with `check_suite.head_branch` set to a branch name shared by a victim's tracked stack (e.g. 'master') and `check_suite.head_sha` matching a victim commit's sha. Binding: org that authenticated the webhook == org owning `repository.full_name` used to resolve `stacks`; false here. Impact: Critical, cross-repository job trigger reaching victim's GitHub API via the app's own credentials (`RefreshCheckRunsJob` uses `Shipit.github` token) for data the attacker chose. Proof: integration test with `repository.full_name` for a victim stack but verified org being attacker's, assert `RefreshCheckRunsJob` enqueued for victim stack's commit.
