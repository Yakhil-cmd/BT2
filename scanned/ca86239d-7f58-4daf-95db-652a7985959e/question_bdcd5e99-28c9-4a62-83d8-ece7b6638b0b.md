Preconditions: archived victim stack with `not_archived` scope false but still has `Commit` rows with matching sha. Call sequence: `StatusHandler#process` -> `create_status_from_github!` on archived stack's commit -> `Status#broadcast_update` (delegated) -> Pubsubstub publish to `stack.<id>` channel. Binding: the requesting organization == the organization whose (possibly archived) stack receives a broadcast update; it does not. Scoped impact: Critical/High boundary but lands on cross-repository stack mutation since it still writes a `Status` row and fires stack-scoped side effects the attacker has no right to trigger. Proof idea: minitest test archiving a victim stack, then asserting `Pubsubstub.expects(:publish)` fires for that stack's channel purely from a foreign-repo webhook.
