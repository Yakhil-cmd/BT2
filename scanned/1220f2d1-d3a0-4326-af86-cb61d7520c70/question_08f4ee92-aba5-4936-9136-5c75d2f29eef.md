Binding: current_api_client.stack_id (a fixed integer) == the id of the Stack object returned by stacks.from_param!(params[:stack_id]) regardless of what slug/param string is supplied. Scoped impact: Critical only if id reuse is possible in this engine's schema (no soft-delete visible) -- primarily a documentation gap; flag as low-confidence without DB migration inspection (out of scope per db/migrate/** exclusion). Proof idea: minitest destroying a Stack, creating a new Stack with a different repository but confirming id is not reused (Rails default auto-increment), asserting an old ApiClient's stack_id never matches the new Stack's id, thereby ruling out this vector for the standard adapter.
