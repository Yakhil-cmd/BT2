`WebhooksController#verify_signature` rescues `Shipit::GithubOrganizationUnknown` (raised by `Shipit.github` when `github_app_config(organization)` returns nil) and calls `head(422)`, logging `unknown_organization=#{e.message}`. Does this log line, or the 422 response body, leak which organizations ARE configured (i.e. is the error message/response distinguishable between 'unknown org' vs 'known org, bad signature'), allowing an attacker to enumerate valid `Shipit.github_organizations` by sending many `repository.owner.login` guesses? Binding: response/log behavior for a valid organization + bad signature must be indistinguishable from an unknown organization to an external prober. Impact: High, information disclosure enabling reconnaissance of configured tenants (feeds into other cross-org attacks above); scope only High since no secret or code execution results directly. Proof: minitest test comparing controller response codes/bodies for (a) unknown org name and (b) known org with a garbage signature, asserting whether they differ in an externally observable way.
