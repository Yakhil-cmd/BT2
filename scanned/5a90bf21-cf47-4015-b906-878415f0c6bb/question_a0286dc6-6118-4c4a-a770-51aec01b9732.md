[Function: borrow] Attacker A calls borrow(ft, amount, receiver=A) sized to push `(+ debt amount)` to exactly CAP-DEBT for the asset B needs. Victim B is a borrower already holding healthy collateral who wants to draw additional debt in the SAME asset to manage an existing loan (e.g., top up before a price move against B). Sequence: Block N: A's borrow saturates CAP-DEBT; Block N: B's borrow(ft, amount, receiver=B) reverts on ERR-DEBT-CAP-EXCEEDED, leaving B's collateral idle and B unable to draw liquidity B was otherwise entitled to under LTV rules. Invariant broken: ORDERING NEUTRALITY. B loses: access to available borrowing capacity for as long as A (or repeats thereof) occupies CAP-DEBT. Impact: temporary freezing of funds (High). Proof idea: two-account test - B borrows alone succeeds under given LTV/collateral; rerun with A's borrow first in the same block and assert B's identical call now reverts.
