# Q3092: interest-rate via liquidate: write a stranger's ledger through an unsolicited on-behalf

## Question
Does `liquidate` (mainnet/contracts/market/v0-4-market.clar:1382) let an unprivileged attacker who controls which collateral and debt asset pair is targeted reach `interest-rate` (mainnet/contracts/vault/v0-vault-stx.clar:371) in a state where it write a stranger's ledger through an unsolicited on-behalf-of call? Given that it interpolates the packed curve at the current utilization, the invariant that no transaction by one principal changes what another can withdraw beyond the pool economics the protocol implements breaks and the result is protocol insolvency through uncollateralised debt.

- Exploit idea: `interest-rate` interpolates the packed curve at the current utilization. Reach it through `liquidate` and write a stranger's ledger through an unsolicited on-behalf-of call.
- Invariant to test: no transaction by one principal changes what another can withdraw beyond the pool economics the protocol implements
- Expected Immunefi impact: Critical - protocol insolvency through uncollateralised debt
