Binding: the `User` row attached to a `PullRequest`/`Team` membership via login lookup == the `User` row that would be found via `github_id` for that same GitHub account. Impact: Critical, identity confusion causing cross-account attribution that can feed into `MergeRequest.request_merge!(stack, number, current_user)` authorization checks. Proof idea: minitest creating two `Shipit::User` fixtures with swapped/stale `login` vs `github_id`, then calling `User.find_or_create_by_login!(login)` and asserting it does not silently attach unrelated GitHub activity to an existing unrelated `User`.
