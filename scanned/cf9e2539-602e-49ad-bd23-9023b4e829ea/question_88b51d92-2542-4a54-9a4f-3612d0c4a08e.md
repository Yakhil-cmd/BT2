Binding: the organization whose webhook_secret verified the signature == the organization owning the repository/stack the handler writes to. Impact: Critical, cross-repository write - an attacker with their own valid webhook_secret (single global secret) can forge push/status webhook bodies that update state for any repository name, not just their own.
