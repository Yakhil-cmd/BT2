# Q5632: insert via transfer: write a stranger's ledger through an unsolicited on-behalf

## Question
Does `transfer` (mainnet/contracts/vault/v0-vault-stx.clar:752) let an unprivileged attacker who controls the timing relative to a pledge or a liquidation reach `insert` (mainnet/contracts/market/v0-market-vault.clar:159) in a state where it write a stranger's ledger through an unsolicited on-behalf-of call?
