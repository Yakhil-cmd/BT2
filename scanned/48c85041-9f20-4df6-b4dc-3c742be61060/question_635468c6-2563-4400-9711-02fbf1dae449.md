[File: mainnet/contracts/market/v0-4-market.clar, Scope: Critical] Function: accrue-and-cache (map index-cache). Attacker A, holding a small STX borrow, calls borrow(aid=STX, amount=1) as the very first transaction of block N purely to prime index-cache {timestamp: stacks-block-time, aid: STX} at a utilization computed before B's larger, already-broadcast borrow lands. Victim B then calls borrow(aid=STX, amount=large) in the same block; B's own debt-index for repayment tracking is unaffected, but every OTHER zSTX holder C (rehypothecated supplier) who redeems later in block N is priced off A's stale-primed cache, not B's post-borrow utilization. Sequence: [Block N: A borrow(1) first -> caches low utilization] -> [Block N: B borrow(large)] -> [Block N: C redeem() reads stale cached lindex]. Invariant: NON-INTERFERENCE. C's redemption value is set by A's ordering choice, not by the real utilization after B's borrow. Impact: theft of unclaimed yield from C. Proof: three-step simnet test (A primes cache, B borrows, C redeems) vs. control (B borrows, C redeems, no A) and diff C's payout.
