Target: Shipit::CCMenuUrlController#fetch and #client. Attacker action: an unprivileged GitHub user who is a Shipit session user (but has no permission on stack X) with only a valid Shipit session (browser cookie) visits GET /ccmenu/*stack_id?stack_id=<stack_X_param> where stack_X belongs to a repository/team the user is not authorized on. Preconditions: CCMenuUrlController inherits ShipitController's session-based auth (not API auth) — need to confirm whether ShipitController#stack/authorization checks (e.g. require_permission via Rack::VerifiedRoutes) are applied to this action, or whether #fetch is reachable purely by having ANY session. Scoped impact: Critical cross-stack read — any session user who can view one stack's settings page obtains a token readable against every stack in the installation.
