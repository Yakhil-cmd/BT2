Equality: `input_size` (allocated) == total bytes actually written by the copy loop (BOUNDS_TRUTH), which fails on overflow. Proof idea: unit test attempting `num_cells` near `SIZE_MAX / BYTES_PER_CELL` (requires a caller/binding that does not clamp `num_cells` first) and observe out-of-bounds write via sanitizer.
