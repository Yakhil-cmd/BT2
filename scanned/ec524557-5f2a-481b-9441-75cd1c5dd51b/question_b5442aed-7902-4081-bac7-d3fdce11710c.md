Binding: repository.owner.login (used to select the verifying webhook_secret) == repository.full_name's owner segment (used to select which Repository row is mutated). Impact: Critical, cross-repository write -- a ReviewStack is provisioned (and later deployed) under victim-org/production-app authenticated only by attacker-org's webhook_secret.
