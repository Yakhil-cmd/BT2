Precondition: any deployment allowing external CI systems to call the API with a shared `ApiClient` token. Attacker action: while this specific header requires a valid `ApiClient` credential to reach (excluded per rules since it needs an ApiClient token), the SAME method is invoked unconditionally on every request including anonymous `Shipit.disable_api_authentication` configurations combined with `UnlimitedApiClient`. Impact: Critical, unauthorized deploy/task-trigger actions can be attributed to (and possibly authorize checklist/permission logic keyed off) an arbitrary chosen `X-Shipit-User` login.
