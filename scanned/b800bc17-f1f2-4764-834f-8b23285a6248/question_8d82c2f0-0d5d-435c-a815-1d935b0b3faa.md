Target: Shipit::Authentication#find_current_user (`session[:user_id].present? && User.find_by(id: session[:user_id])`). Attacker action: none needed beyond normal GitHub login by two different users over time on a shared browser/proxy session id (or an attacker who obtains a stale session cookie). Preconditions: `GithubAuthenticationController#callback` never calls `reset_session` before writing `session[:user_id]`. Binding broken: session[:user_id] resolved by find_current_user == the GitHub identity that completed the OAuth exchange IN THIS SESSION. Impact: Critical - authentication bypass allowing one browser session to be silently rebound to a different, attacker-controlled identity.
