### Title
Missing Strict-Inequality Guard in KIP-71 Base-Fee Bound Votes Allows Permanent Base-Fee Collapse and Fee-Burn Suppression — (`File: kaiax/gov/headergov/impl/header.go`)

---

### Summary

`checkConsistency` in `kaiax/gov/headergov/impl/header.go` validates governance votes for `Kip71LowerBoundBaseFee` and `Kip71UpperBoundBaseFee` using non-strict comparisons (`>` / `<`). This allows a validator to vote `LowerBoundBaseFee == UpperBoundBaseFee`, collapsing the KIP-71 dynamic base-fee range to a single point. In the extreme two-epoch case both bounds can be driven to 0, permanently zeroing the base fee, disabling all fee burning, and corrupting the `BurntFee` field in every subsequent supply checkpoint.

---

### Finding Description

In `checkConsistency` (`kaiax/gov/headergov/impl/header.go`, lines 179–192):

```go
case gov.Kip71LowerBoundBaseFee:
    params := h.GetParamSet(blockNum)
    if vote.Value().(uint64) > params.UpperBoundBaseFee {   // strict >
        return ErrLowerBoundBaseFee
    } else {
        return nil
    }
case gov.Kip71UpperBoundBaseFee:
    params := h.GetParamSet(blockNum)
    if vote.Value().(uint64) < params.LowerBoundBaseFee {   // strict <
        return ErrUpperBoundBaseFee
    } else {
        return nil
    }
```

The guard for `Kip71LowerBoundBaseFee` rejects only when `newLower > currentUpper`; equality (`newLower == currentUpper`) passes. Symmetrically, the guard for `Kip71UpperBoundBaseFee` rejects only when `newUpper < currentLower`; equality passes. Both parameters also use `noopFormatChecker` (`kaiax/gov/param.go`, lines 335–366), so any `uint64` value including 0 clears the format gate.

**Single-epoch attack (pinned maximum fee):**
A validator votes `Kip71LowerBoundBaseFee = currentUpperBound` (e.g., 750 Gkei). The check `750 Gkei > 750 Gkei` is false, so the vote is accepted. After the epoch boundary `Lower = Upper = 750 Gkei`. `NextMagmaBlockBaseFee` clamps `parentBaseFee` to `upperBoundBaseFee` on the very first comparison (`parentBaseFee.Cmp(upperBoundBaseFee) >= 0`), then hits the shortcut `parentBaseFee == upperBoundBaseFee` and returns 750 Gkei unconditionally for every future block regardless of gas usage.

**Two-epoch attack (zero base fee):**
- Epoch N: vote `Kip71LowerBoundBaseFee = 0`. Check: `0 > 750 Gkei` → false → accepted. After epoch N: `Lower = 0`, `Upper = 750 Gkei`.
- Epoch N+1: vote `Kip71UpperBoundBaseFee = 0`. Check: `0 < 0` → false → accepted. After epoch N+1: `Lower = 0`, `Upper = 0`.

With both bounds at 0, `makeEvenByCeil(0) = 0` and `makeEvenByFloor(0) = 0`. Every code path in `NextMagmaBlockBaseFee` returns 0: the first clamp (`parentBaseFee >= 0`) sets `parentBaseFee = 0`, and every shortcut (`parentBaseFee == upperBoundBaseFee` or `parentBaseFee == lowerBoundBaseFee`) fires immediately, returning 0 for all gas-usage levels.

---

### Impact Explanation

**Fee burning disabled / KAIA supply corrupted.**

`blockchain/state_transition.go` line 651–652 computes the burned amount as:
```go
fee := new(big.Int).Mul(new(big.Int).SetUint64(st.gasUsed()), st.gasPrice)
burnt := new(big.Int).Div(fee, big.NewInt(2))
```
`st.gasPrice` is derived from `baseFee`. With `baseFee = 0`, `fee = 0`, `burnt = 0`. No KAIA is burned for any transaction.

`kaiax/reward/impl/getter.go` line 217 computes deferred-mode exec fee as `gasUsed * header.BaseFee`. With `BaseFee = 0` the entire fee component is 0, so `BurntFee` in every `RewardSpec` is 0.

`kaiax/supply` accumulates `BurntFee` into persistent supply checkpoints (`AccReward`). Every checkpoint written after the attack records `BurntFee = 0`, permanently understating total burned KAIA and overstating `TotalSupply` returned by `kaia_getTotalSupply`. This is a persistent, irrecoverable corruption of the canonical supply accounting unless the chain is reorganized past the governance epoch that applied the bad parameters.

Additionally, `VerifyMagmaHeader` (`params/kip71_config.go` line 50–55) calls `NextMagmaBlockBaseFee` to derive the expected base fee and rejects any block whose `header.BaseFee` differs. With both bounds at 0, the expected base fee is 0, so all honest nodes accept blocks with `baseFee = 0` as canonical — the invalid state propagates across the entire network.

---

### Likelihood Explanation

In `governance.governancemode = "none"` (the default), any single validator in the council can cast a governance vote. The vote takes effect at the next epoch boundary (default epoch = 604,800 blocks ≈ 1 week). The single-epoch attack (pinning the fee at the maximum) requires only one vote in one epoch. The two-epoch zero-fee attack requires two votes across two consecutive epochs. No coordination with other validators is needed; no majority is required. The attacker is a semi-trusted validator who is expected to propose blocks but not to manipulate governance parameters to break the fee mechanism.

---

### Recommendation

Replace the non-strict comparisons in `checkConsistency` with strict ones:

```go
case gov.Kip71LowerBoundBaseFee:
    params := h.GetParamSet(blockNum)
    if vote.Value().(uint64) >= params.UpperBoundBaseFee {  // >= instead of >
        return ErrLowerBoundBaseFee
    }
    return nil
case gov.Kip71UpperBoundBaseFee:
    params := h.GetParamSet(blockNum)
    if vote.Value().(uint64) <= params.LowerBoundBaseFee {  // <= instead of <
        return ErrUpperBoundBaseFee
    }
    return nil
```

Additionally, add a `FormatChecker` for both parameters that rejects 0:

```go
Kip71LowerBoundBaseFee: {
    FormatChecker: func(cv any) bool {
        v, ok := cv.(uint64)
        return ok && v > 0
    },
    ...
}
```

### Proof of Concept

**Single-epoch pin at maximum (one vote):**

State: `LowerBoundBaseFee = 25_000_000_000`, `UpperBoundBaseFee = 750_000_000_000`.

1. Validator casts vote: `Kip71LowerBoundBaseFee = 750_000_000_000`.
2. `checkConsistency`: `750_000_000_000 > 750_000_000_000` → `false` → vote accepted.
3. After epoch: `Lower = Upper = 750_000_000_000`.
4. `NextMagmaBlockBaseFee` with any `parentGasUsed`:
   - `parentBaseFee.Cmp(upperBoundBaseFee) >= 0` → `parentBaseFee = 750_000_000_000`
   - `parentGasUsed > gasTarget` → shortcut: `parentBaseFee == upperBoundBaseFee` → return `750_000_000_000`
   - `parentGasUsed < gasTarget` → shortcut: `parentBaseFee == lowerBoundBaseFee` → return `750_000_000_000`
5. All future blocks have `baseFee = 750 Gkei` permanently. Every transaction pays maximum base fee regardless of network load.

**Two-epoch zero-fee (two votes across two epochs):**

1. Epoch N: vote `Kip71LowerBoundBaseFee = 0`. Check: `0 > 750_000_000_000` → false → accepted.
2. After epoch N: `Lower = 0`, `Upper = 750_000_000_000`.
3. Epoch N+1: vote `Kip71UpperBoundBaseFee = 0`. Check: `0 < 0` → false → accepted.
4. After epoch N+1: `Lower = 0`, `Upper = 0`.
5. `NextMagmaBlockBaseFee` returns `0` for all inputs.
6. `VerifyMagmaHeader` accepts `header.BaseFee = 0` as valid.
7. `state_transition.go`: `fee = gasUsed * 0 = 0`, `burnt = 0`. No KAIA burned.

```go
func (kc *KIP71Config) NextMagmaBlockBaseFee(parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) *big.Int {
	// governance parameters
	lowerBoundBaseFee := new(big.Int).SetUint64(kc.LowerBoundBaseFee)
	upperBoundBaseFee := new(big.Int).SetUint64(kc.UpperBoundBaseFee)
	makeEvenByCeil(lowerBoundBaseFee)
	makeEvenByFloor(upperBoundBaseFee)

	// If the parent is the magma disabled block or genesis, then return the lowerBoundBaseFee (default 25ston)
	if parentHeaderNumber.Cmp(new(big.Int).SetUint64(0)) == 0 || parentHeaderBaseFee == nil {
		return makeEvenByFloor(lowerBoundBaseFee)
	}

	var baseFeeDenominator *big.Int
	if kc.BaseFeeDenominator == 0 {
		// To avoid panic, set the fluctuation range small
		baseFeeDenominator = new(big.Int).SetUint64(64)
	} else {
		baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
	}
	gasTarget := kc.GasTarget
	upperGasLimit := kc.MaxBlockGasUsedForBaseFee

	// check the case of upper/lowerBoundBaseFee is updated by governance mechanism
	parentBaseFee := parentHeaderBaseFee
	if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {
		parentBaseFee = upperBoundBaseFee
	} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
		parentBaseFee = lowerBoundBaseFee
	}

	// upper gas limit cut off the impulse of used gas to upper bound
	parentGasUsed := min(parentHeaderGasUsed, upperGasLimit)
	if parentGasUsed == gasTarget {
		return makeEvenByFloor(parentBaseFee)
	} else if parentGasUsed > gasTarget {
		// shortcut. If parentBaseFee is already reached upperbound, do not calculate.
		if parentBaseFee.Cmp(upperBoundBaseFee) == 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		// If the parent block used more gas than its target,
		// the baseFee of the next block should increase.
		// baseFeeDelta = max(1, parentBaseFee * (parentGasUsed - gasTarget) / gasTarget / baseFeeDenominator)
		gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := math.BigMax(x.Div(y, baseFeeDenominator), common.Big1)

		nextBaseFee := x.Add(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(upperBoundBaseFee) > 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	} else {
		// shortcut. If parentBaseFee is already reached lower bound, do not calculate.
		if parentBaseFee.Cmp(lowerBoundBaseFee) == 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		// Otherwise if the parent block used less gas than its target,
		// the baseFee of the next block should decrease.
		// baseFeeDelta = parentBaseFee * (gasTarget - parentGasUsed) / gasTarget / baseFeeDenominator
		gasUsedDelta := new(big.Int).SetUint64(gasTarget - parentGasUsed)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := x.Div(y, baseFeeDenominator)

		nextBaseFee := x.Sub(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(lowerBoundBaseFee) < 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	}
```

```go
func (ar *AccReward) ToTotalSupply(zeroBurn, deadBurn, kip103Burn, kip160Burn *big.Int) *TotalSupply {
	ts := &TotalSupply{
		TotalSupply: nil, // will be filled below

		TotalMinted: new(big.Int).Set(ar.TotalMinted),

		TotalBurnt: nil, // will be filled below
		BurntFee:   new(big.Int).Set(ar.BurntFee),
		ZeroBurn:   zeroBurn,
		DeadBurn:   deadBurn,
		Kip103Burn: kip103Burn,
		Kip160Burn: kip160Burn,
	}

	if ar.TotalMinted != nil && ar.BurntFee != nil && zeroBurn != nil && deadBurn != nil && kip103Burn != nil && kip160Burn != nil {
		totalBurnt := new(big.Int).Set(ar.BurntFee)
		totalBurnt.Add(totalBurnt, zeroBurn)
		totalBurnt.Add(totalBurnt, deadBurn)
		totalBurnt.Add(totalBurnt, kip103Burn)
		totalBurnt.Add(totalBurnt, kip160Burn)
		totalSupply := new(big.Int).Sub(ar.TotalMinted, totalBurnt)

		ts.TotalSupply = totalSupply
		ts.TotalBurnt = totalBurnt
	}
	return ts
```
