### Title
Governance Vote for `kip71.gastarget = 0` Causes Division-by-Zero Panic in `NextMagmaBlockBaseFee`, Halting Block Production and Validation — (`params/kip71_config.go`)

---

### Summary

The `Kip71GasTarget` governance parameter uses `noopFormatChecker`, which accepts any value including zero. However, `NextMagmaBlockBaseFee` uses `gasTarget` as a divisor without a zero-guard, unlike `BaseFeeDenominator` which has both a `FormatChecker` rejecting zero **and** a runtime fallback. A governing node (semi-trusted actor in "single" governance mode) can vote to set `kip71.gastarget = 0`, causing a `big.Int` division-by-zero panic in every subsequent call to `NextMagmaBlockBaseFee` whenever a block has non-zero gas usage. This panics both the block producer and every validating node, halting the chain.

---

### Finding Description

**Root cause — missing zero-guard for `GasTarget` in `NextMagmaBlockBaseFee`:**

`params/kip71_config.go` lines 70–103 show an explicit guard for `BaseFeeDenominator == 0` but none for `GasTarget == 0`:

```go
// Guard exists for BaseFeeDenominator
if kc.BaseFeeDenominator == 0 {
    baseFeeDenominator = new(big.Int).SetUint64(64)  // fallback
} else {
    baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
}
gasTarget := kc.GasTarget  // ← NO guard; zero is accepted
...
// When parentGasUsed > 0 and gasTarget == 0:
gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
y := x.Div(x, new(big.Int).SetUint64(gasTarget))  // ← PANIC: division by zero
``` [1](#0-0) 

**Root cause — `Kip71GasTarget` accepts zero via `noopFormatChecker`:**

`kaiax/gov/param.go` shows the asymmetry: `Kip71BaseFeeDenominator` has a `FormatChecker` that explicitly rejects zero, while `Kip71GasTarget` uses `noopFormatChecker` (always returns `true`):

```go
Kip71BaseFeeDenominator: {
    FormatChecker: func(cv any) bool {
        v, ok := cv.(uint64)
        return ok && v != 0   // ← rejects zero
    },
    ...
},
Kip71GasTarget: {
    FormatChecker: noopFormatChecker,  // ← accepts zero
    ...
},
``` [2](#0-1) 

**Trigger path:**

1. The governing node (in "single" governance mode) casts a vote for `kip71.gastarget = 0`. The vote passes `VerifyVote` because `noopFormatChecker` returns `true` for any `uint64`.
2. After the governance epoch, `GetParamSet` returns a `ParamSet` with `GasTarget = 0`.
3. The next block that includes any transaction (non-zero `GasUsed`) causes `NextMagmaBlockBaseFee` to reach the `parentGasUsed > gasTarget` branch and execute `x.Div(x, new(big.Int).SetUint64(0))`.
4. Go's `math/big.(*Int).Div` panics on a zero divisor.

`NextMagmaBlockBaseFee` is called in two critical paths:

- **Block production** (`work/worker.go` line 382): `pset.ToKip71Config().NextMagmaBlockBaseFee(...)` — the proposer panics and cannot seal any block.
- **Block validation** (`params/kip71_config.go` line 50 via `VerifyMagmaHeader`): every peer validating the block panics. [3](#0-2) [4](#0-3) 

---

### Impact Explanation

Once `GasTarget = 0` takes effect, every block containing at least one transaction causes a panic in both the block producer and all validating nodes. The chain halts: no new blocks can be produced or accepted, all pending transfers and withdrawals are frozen, and the canonical state is permanently stuck. This satisfies the allowed impact gate: **invalid block acceptance / consensus divergence on honest nodes** and **persistent corruption of canonical execution, withdrawals, transfers, and settlement**.

---

### Likelihood Explanation

In "single" governance mode (the current Mainnet configuration), a single governing node can unilaterally cast the decisive vote. No majority-validator collusion is required. The `noopFormatChecker` on `Kip71GasTarget` means the vote is accepted without any on-chain rejection. The asymmetry with `BaseFeeDenominator` (which has both a `FormatChecker` and a runtime guard) demonstrates this case was not considered. The governing node is a semi-trusted actor analogous to the position owner in the Frankencoin H-05 report.

---

### Recommendation

Apply both layers of defense that already protect `BaseFeeDenominator`:

1. **`FormatChecker` in `kaiax/gov/param.go`**: Reject `GasTarget = 0` at vote time:
   ```go
   Kip71GasTarget: {
       FormatChecker: func(cv any) bool {
           v, ok := cv.(uint64)
           return ok && v > 0
       },
   ```

2. **Runtime guard in `params/kip71_config.go`**: Add a fallback analogous to the `BaseFeeDenominator` guard:
   ```go
   gasTarget := kc.GasTarget
   if gasTarget == 0 {
       gasTarget = DefaultGasTarget  // or return lowerBoundBaseFee
   }
   ``` [5](#0-4) [6](#0-5)

// Pseudo-test demonstrating the panic
func TestGasTargetZeroPanic(t *testing.T) {
    cfg := &params.KIP71Config{
        LowerBoundBaseFee:         25_000_000_000,
        UpperBoundBaseFee:         750_000_000_000,
        GasTarget:                 0,          // set via governance vote
        MaxBlockGasUsedForBaseFee: 60_000_000,
        BaseFeeDenominator:        20,
    }

    parentBaseFee := big.NewInt(25_000_000_000)
    parentGasUsed := uint64(1_000_000) // any non-zero gas usage

    // This panics: runtime error: integer divide by zero
    // inside big.Int.Div when divisor = new(big.Int).SetUint64(0)
    _ = cfg.NextMagmaBlockBaseFee(
        big.NewInt(100),   // parentHeaderNumber
        parentBaseFee,
        parentGasUsed,
    )
}
```

```go
func (kc *KIP71Config) NextMagmaBlockBaseFee(parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) *big.Int {
	// governance parameters
	lowerBoundBaseFee := new(big.Int).SetUint64(kc.LowerBoundBaseFee)
	upperBoundBaseFee := new(big.Int).SetUint64(kc.UpperBoundBaseFee)
	makeEvenByCeil(lowerBoundBaseFee)
	makeEvenByFloor(upperBoundBaseFee)

	// If the parent is the magma disabled block or genesis, then return the lowerBoundBaseFee (default 25ston)
	if parentHeaderNumber.Cmp(new(big.Int).SetUint64(0)) == 0 || parentHeaderBaseFee == nil {
		return makeEvenByFloor(lowerBoundBaseFee)
	}

	var baseFeeDenominator *big.Int
	if kc.BaseFeeDenominator == 0 {
		// To avoid panic, set the fluctuation range small
		baseFeeDenominator = new(big.Int).SetUint64(64)
	} else {
		baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
	}
	gasTarget := kc.GasTarget
	upperGasLimit := kc.MaxBlockGasUsedForBaseFee

	// check the case of upper/lowerBoundBaseFee is updated by governance mechanism
	parentBaseFee := parentHeaderBaseFee
	if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {
		parentBaseFee = upperBoundBaseFee
	} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
		parentBaseFee = lowerBoundBaseFee
	}

	// upper gas limit cut off the impulse of used gas to upper bound
	parentGasUsed := min(parentHeaderGasUsed, upperGasLimit)
	if parentGasUsed == gasTarget {
		return makeEvenByFloor(parentBaseFee)
	} else if parentGasUsed > gasTarget {
		// shortcut. If parentBaseFee is already reached upperbound, do not calculate.
		if parentBaseFee.Cmp(upperBoundBaseFee) == 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		// If the parent block used more gas than its target,
		// the baseFee of the next block should increase.
		// baseFeeDelta = max(1, parentBaseFee * (parentGasUsed - gasTarget) / gasTarget / baseFeeDenominator)
		gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := math.BigMax(x.Div(y, baseFeeDenominator), common.Big1)

		nextBaseFee := x.Add(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(upperBoundBaseFee) > 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	} else {
		// shortcut. If parentBaseFee is already reached lower bound, do not calculate.
		if parentBaseFee.Cmp(lowerBoundBaseFee) == 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		// Otherwise if the parent block used less gas than its target,
		// the baseFee of the next block should decrease.
		// baseFeeDelta = parentBaseFee * (gasTarget - parentGasUsed) / gasTarget / baseFeeDenominator
		gasUsedDelta := new(big.Int).SetUint64(gasTarget - parentGasUsed)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := x.Div(y, baseFeeDenominator)

		nextBaseFee := x.Sub(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(lowerBoundBaseFee) < 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	}
}
