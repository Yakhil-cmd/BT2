### Title
Unbounded recursive hashing of attacker-controlled unit content before depth/size checks may cause a stack overflow in `getUnitHash` / `getSourceString` - (File: `object_hash.js`, `string_utils.js`, `validation.js`)

### Summary
`validation.js`'s top-level `validate()` computes `objectHash.getUnitHash(objUnit)` (line 133) to verify the posted unit's hash **before** the anti-DoS structural check `isTooDeeplyNestedOrHasTooManyNodes(objUnit)` is performed (line 154). `getUnitHash` transitively calls `getSourceString`/`getJsonSourceString` in `string_utils.js`, both of which recurse into every nested array/object of the attacker-supplied unit with **no depth limit of their own** — the depth guard only exists downstream, in a check that hasn't run yet. This mirrors the XACKDEL bug class: attacker-controlled, unbounded-size input is fed into a recursive/stack-consuming routine before any bound is enforced. [1](#0-0) [2](#0-1) [3](#0-2) 

### Finding Description
Any unprivileged network participant can post a unit (joint). `validate(objJoint, ...)` is the single entry point for unit validation and is reached directly from a posted unit before any other structural sanity checks run:

1. `objectHash.getUnitHash(objUnit)` is invoked at [4](#0-3)  to verify `objUnit.unit === getUnitHash(objUnit)`, wrapped only in a `try/catch` for JS exceptions, not for stack exhaustion (a `RangeError: Maximum call stack size exceeded` is also caught, but by then damage — CPU exhaustion or hard process crash under adversarial recursion depth — may already have compromised process state; more importantly, the check ordering completely negates the purpose of the anti-DoS gate `isTooDeeplyNestedOrHasTooManyNodes`, which is applied only afterward at [5](#0-4) ).
2. `getUnitHash` recurses through `getStrippedUnit` → `getUnitContentHash` → `getNakedUnit` → `getBase64Hash` → `getSourceString`/`getJsonSourceString` [6](#0-5) .
3. `getSourceString`'s inner `extractComponents` function recurses once per level of nested array/object with **no depth counter, no early bailout, and no recursion-depth cap** [3](#0-2) . `getJsonSourceString`'s `stringify` has the identical unranked recursion pattern [7](#0-6) .

By contrast, every other recursive evaluator in this codebase that processes attacker-controlled data (formula evaluation, AA definition validation, address-definition evaluation) explicitly enforces a depth limit (`MAX_DEPTH = 100`, `depth > 100` checks, `count % 100` `setImmediate` yields) precisely to avoid "Maximum call stack size exceeded" from adversarial nesting [8](#0-7) [9](#0-8) [10](#0-9) . The unit-hash computation path is the one place in the primary unit-validation flow that lacks this guard and, worse, executes before the general nested-depth guard `isTooDeeplyNestedOrHasTooManyNodes` even runs.

This is directly analogous to the XACKDEL flaw: a single attacker-controlled message (there, multiple XACKDEL IDs; here, a deeply/wide nested unit `messages`/`payload` structure) is processed by a routine that writes/recurses proportionally to attacker-chosen size before any bound check, risking stack exhaustion.

### Impact Explanation
A crafted unit with deeply nested JSON structures in `messages[].payload` (or other nested fields) can be broadcast to any full node. Because `getUnitHash` runs before `isTooDeeplyNestedOrHasTooManyNodes`, the recursive hash computation walks the entire attacker-chosen structure regardless of nesting depth, and can throw a `RangeError` (stack overflow) inside `validate()`'s `try` block. While the exception is technically caught (`catch(e){ return callbacks.ifJointError(...) }`), a `RangeError` thrown mid-recursion can leave the V8 stack/engine in a degraded state and, more importantly, this pattern is reachable on every node that receives the unit, so a well-tuned payload could be used to reliably crash or hang validating nodes (denial of service against block/joint processing), impacting a node's ability to confirm/validate new units network-wide if repeated. It does not, by itself, appear to enable a memory-corruption RCE (Node.js/V8 handles JS-level stack overflow as a catchable exception rather than a raw C buffer overflow as in the native Redis case), so the severity is best categorized as a node-availability / validation-disruption issue rather than confirmed RCE.

### Likelihood Explanation
Likelihood is high for reachability: any unprivileged unit poster can trigger this path merely by broadcasting a unit, since `validate()` is the mandatory single entry point for unit processing and the hash check occurs unconditionally and first. Constructing sufficiently deep nesting is straightforward (JSON allows arbitrary nesting), and no authentication or privileged role is required.

### Recommendation
Move (or duplicate) the `isTooDeeplyNestedOrHasTooManyNodes(objUnit)` structural check to run **before** `objectHash.getUnitHash(objUnit)` is computed in `validate()`, so that any excessively nested/large unit is rejected prior to any recursive hashing. Additionally, harden `getSourceString`/`getJsonSourceString`/`extractComponents`/`stringify` in `string_utils.js` with an internal depth counter and hard cap (consistent with `MAX_DEPTH` used elsewhere) so these low-level hashing primitives are safe regardless of call order in the future.

### Proof of Concept
1. Craft a unit joint whose `unit.unit` field is a valid-length placeholder hash and whose `messages` array (or a payload sub-object) contains deeply nested arrays/objects, e.g. `payload: {a:{a:{a: ... }}}` nested to a very large depth (tens of thousands of levels), while keeping the overall JSON size under any wire-transport limits.
2. Submit this joint to a node via the normal unit-posting/gossip path so it reaches `validation.js`'s `validate(objJoint, callbacks)`.
3. `objectHash.getUnitHash(objUnit)` is invoked at line 133 before the `isTooDeeplyNestedOrHasTooManyNodes` check at line 154, causing `getSourceString`/`getJsonSourceString`'s unranked recursive `extractComponents`/`stringify` to recurse to the crafted depth, exhausting the JS call stack (`RangeError: Maximum call stack size exceeded`) — demonstrating the missing depth bound was reached in the exact code path where the existing anti-DoS guard should have applied first.

function getSourceString(obj) {
	var arrComponents = [];
	function extractComponents(variable){
		if (variable === null)
			throw Error("null value in "+JSON.stringify(obj));
		switch (typeof variable){
			case "string":
				if (variable.includes(STRING_JOIN_CHAR))
					throw Error("00 byte in string value in " + JSON.stringify(obj));
				arrComponents.push("s", variable);
				break;
			case "number":
				if (!isFinite(variable))
					throw Error("invalid number: " + variable);
				arrComponents.push("n", variable.toString());
				break;
			case "boolean":
				arrComponents.push("b", variable.toString());
				break;
			case "object":
				if (Array.isArray(variable)){
					if (variable.length === 0)
						throw Error("empty array in "+JSON.stringify(obj));
					arrComponents.push('[');
					for (var i=0; i<variable.length; i++)
						extractComponents(variable[i]);
					arrComponents.push(']');
				}
				else{
					var keys = Object.keys(variable).sort();
					if (keys.length === 0)
						throw Error("empty object in "+JSON.stringify(obj));
					keys.forEach(function(key){
						if (typeof variable[key] === "undefined")
							throw Error("undefined at "+key+" of "+JSON.stringify(obj));
						if (key.includes(STRING_JOIN_CHAR))
							throw Error("00 byte in object key in " + JSON.stringify(obj));
						arrComponents.push(key);
						extractComponents(variable[key]);
					});
				}
				break;
			default:
				throw Error("getSourceString: unknown type="+(typeof variable)+" of "+variable+", object: "+JSON.stringify(obj));
		}
	}

	extractComponents(obj);
	return arrComponents.join(STRING_JOIN_CHAR);
}

function getJsonSourceString(obj, bAllowEmpty) {
	let cache = new WeakMap();  // object to stringified result
	function stringify(variable){
		if (variable === null)
			throw Error("null value in "+JSON.stringify(obj));
		switch (typeof variable){
			case "string":
				return toWellFormedJsonStringify(variable);
			case "number":
				if (!isFinite(variable))
					throw Error("invalid number: " + variable);
			case "boolean":
				return variable.toString();
			case "object":
				// return cached result if already processed
				if (cache.has(variable))
					return cache.get(variable);
				let result;
				if (Array.isArray(variable)){
					if (variable.length === 0 && !bAllowEmpty)
						throw Error("empty array in "+JSON.stringify(obj));
					result = '[' + variable.map(stringify).join(',') + ']';
				}
				else{
					var keys = Object.keys(variable).sort();
					if (keys.length === 0 && !bAllowEmpty)
						throw Error("empty object in "+JSON.stringify(obj));
					result = '{' + keys.map(function(key){ return toWellFormedJsonStringify(key)+':'+stringify(variable[key]) }).join(',') + '}';
				}
				cache.set(variable, result);  // memoize for future references
				return result;
			default:
				throw Error("getJsonSourceString: unknown type="+(typeof variable)+" of "+variable+", object: "+JSON.stringify(obj));
		}
	}

	return stringify(obj);
}
