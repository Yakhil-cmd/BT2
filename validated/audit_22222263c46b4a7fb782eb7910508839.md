### Title
Denial of service in `gh attestation verify` / `gh api-verify-asset` batch attestation fetch: one attacker-published attestation with an unreachable `BundleURL` discards all legitimate attestations for a digest - ([File: pkg/cmd/attestation/api/client.go])

### Summary
`LiveClient.GetByDigest` fetches all attestations attached to an artifact digest from the GitHub API and then resolves each attestation's bundle via `fetchBundleFromAttestations`. That function fetches bundles concurrently with an `errgroup.Group` and returns `nil, err` for the *entire batch* the moment any single bundle fetch fails, discarding every other (legitimate) attestation that was already/would have been fetched successfully.

### Finding Description
`GetByDigest` first calls `getAttestations`, which retrieves the full, unfiltered list of attestations GitHub has recorded for a subject digest via `repos/{owner}/{repo}/attestations/{digest}` or `orgs/{owner}/attestations/{digest}` [1](#0-0) . Any authenticated user/workflow that can publish attestations for a subject in that owner/repo scope can add an attestation entry, and each attestation carries an attacker-influenced `BundleURL` field [2](#0-1) .

`fetchBundleFromAttestations` then iterates the returned attestations and, for each one, fetches its bundle from `BundleURL` inside an `errgroup.Group`:
```go
func (c *LiveClient) fetchBundleFromAttestations(attestations []*Attestation) ([]*Attestation, error) {
	fetched := make([]*Attestation, len(attestations))
	g := errgroup.Group{}
	for i, a := range attestations {
		g.Go(func() error {
			if a.Bundle == nil && a.BundleURL == "" {
				return fmt.Errorf("attestation has no bundle or bundle URL")
			}
			...
			b, err := c.getBundle(safeurl.NewImmutableSafeURL(a.BundleURL))
			if err != nil {
				return fmt.Errorf("failed to fetch bundle with URL: %w", err)
			}
			fetched[i] = &Attestation{Bundle: b}
			return nil
		})
	}
	if err := g.Wait(); err != nil {
		return nil, err
	}
	return fetched, nil
}
``` [3](#0-2) 

If any single attestation in the batch has a `BundleURL` that fails to resolve (e.g., points to a host that 404s, times out, or is otherwise unreachable), `g.Wait()` returns a non-nil error and `fetchBundleFromAttestations` returns `nil, err` — even though other attestations in the same batch may have been fetched successfully. `GetByDigest` propagates this failure directly:
```go
bundles, err := c.fetchBundleFromAttestations(attestations)
if err != nil {
    return nil, fmt.Errorf("failed to fetch bundle with URL: %w", err)
}
``` [4](#0-3) 

This is structurally the same bug class as the LiquidityPool `QueuedWithdrawals` finding: a batch of independent, per-user/per-entry work items is processed together, and a single malicious/broken entry (controlled or influenced by an attacker, analogous to `user=sUSDproxy`) causes the entire batch to fail, denying service to all other legitimate entries in that batch — here, all other legitimate attestations for the digest become unverifiable via `gh attestation verify` and `gh release verify-asset` until the bad entry is removed (which the CLI itself cannot do; it is the API response, so this can persist).

### Impact Explanation
`gh attestation verify` and `gh release verify-asset` are the primary supply-chain verification commands `gh` offers; both ultimately call `GetByDigest` to retrieve attestations for verification [5](#0-4) [6](#0-5) . If a single unreachable/broken `BundleURL` associated with an attestation for a given digest causes the entire fetch to fail, users lose the ability to verify *any* attestation for that artifact — a denial-of-service against the attestation/supply-chain-security verification feature. This does not lead to a false "verified" result (no verification bypass), but it does block legitimate verification workflows, which is the core impact of the referenced H-12 report (loss of ability to process legitimate items due to one bad entry in a shared batch).

### Likelihood Explanation
Likelihood depends on whether an unprivileged party can cause or influence an attestation with a bad `BundleURL` to be associated with a shared digest scope (e.g., an org-wide digest lookup, or a repo where multiple actors/workflows can publish attestations). This is plausible in organizations where many workflows/users can generate attestations for shared digests, but the exact permission model for who can attach attestations with which `BundleURL` values to a given digest is enforced server-side by the GitHub API and is **not verifiable from the CLI's client code alone** — I could not confirm from the available files whether `BundleURL` is attacker-settable or purely populated by GitHub's own attestation storage. Because of this uncertainty around the trust boundary of `BundleURL`, likelihood is assessed as low-to-moderate rather than high.

### Recommendation
In `fetchBundleFromAttestations`, do not fail the whole batch on a single bundle-fetch error. Instead, record per-attestation errors (similar to the pattern already used in `sigstore.go`'s `Verify` function, which tolerates individual verification failures and only fails if *all* attestations fail) [7](#0-6) , so that one broken/malicious attestation entry does not deny verification of all other legitimate attestations for the same digest.

### Proof of Concept
Not independently reproducible from static analysis alone — reproducing this would require an attacker-controlled attestation entry (with a broken/unreachable `BundleURL`) to be associated with a digest that also has legitimate attestations from other principals, then observing that `gh attestation verify`/`gh release verify-asset` fails entirely rather than surfacing/skipping only the broken entry. This requires further verification against the live GitHub Attestations API's authorization model for `BundleURL`, which is outside the scope of this codebase's index.

func (c *LiveClient) fetchBundleFromAttestations(attestations []*Attestation) ([]*Attestation, error) {
	fetched := make([]*Attestation, len(attestations))
	g := errgroup.Group{}
	for i, a := range attestations {
		g.Go(func() error {
			if a.Bundle == nil && a.BundleURL == "" {
				return fmt.Errorf("attestation has no bundle or bundle URL")
			}

			// for now, we fall back to the bundle field if the bundle URL is empty
			if a.BundleURL == "" {
				c.logger.VerbosePrintf("Bundle URL is empty. Falling back to bundle field\n\n")
				fetched[i] = &Attestation{
					Bundle: a.Bundle,
				}
				return nil
			}

			// otherwise fetch the bundle with the provided URL
			b, err := c.getBundle(safeurl.NewImmutableSafeURL(a.BundleURL))
			if err != nil {
				return fmt.Errorf("failed to fetch bundle with URL: %w", err)
			}
			fetched[i] = &Attestation{
				Bundle: b,
			}

			return nil
		})
	}

	if err := g.Wait(); err != nil {
		return nil, err
	}

	return fetched, nil
}

func getAttestations(o *Options, a artifact.DigestedArtifact) ([]*api.Attestation, string, error) {
	// Fetch attestations from GitHub API within this if block since predicate type
	// filter is done when the API is called
	if o.FetchAttestationsFromGitHubAPI() {
		if o.APIClient == nil {
			errMsg := "✗ No APIClient provided"
			return nil, errMsg, errors.New(errMsg)
		}

		params := api.FetchParams{
			Digest:        a.DigestWithAlg(),
			Limit:         o.Limit,
			Owner:         o.Owner,
			PredicateType: o.PredicateType,
			Repo:          o.Repo,
			Initiator:     "user",
		}

		attestations, err := o.APIClient.GetByDigest(params)
		if err != nil {
			msg := "✗ Loading attestations from GitHub API failed"
			return nil, msg, err
		}
		pluralAttestation := text.Pluralize(len(attestations), "attestation")
		msg := fmt.Sprintf("Loaded %s from GitHub API", pluralAttestation)
		return attestations, msg, nil
	}

```go
func (v *LiveSigstoreVerifier) Verify(attestations []*api.Attestation, policy verify.PolicyBuilder) ([]*AttestationProcessingResult, error) {
	if len(attestations) == 0 {
		return nil, ErrNoAttestationsVerified
	}

	results := make([]*AttestationProcessingResult, len(attestations))
	var verifyCount int
	var lastError error
	totalAttestations := len(attestations)
	for i, a := range attestations {
		v.Logger.VerbosePrintf("Verifying attestation %d/%d against the configured Sigstore trust roots\n", i+1, totalAttestations)

		apr, err := v.verify(a, policy)
		if err != nil {
			lastError = err
			// move onto the next attestation in the for loop if verification fails
			continue
		}
		// otherwise, add the result to the results slice and increment verifyCount
		results[verifyCount] = apr
		verifyCount++
	}

	if verifyCount == 0 {
		return nil, lastError
	}

	// truncate the results slice to only include verified attestations
	results = results[:verifyCount]

	return results, nil
}
