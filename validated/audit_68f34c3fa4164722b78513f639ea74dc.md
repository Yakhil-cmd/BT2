### Title
Unsanitized `pr.Milestone.Title` allows ANSI/terminal escape sequence injection in `gh pr view` output - (File: pkg/cmd/pr/view/view.go)

### Summary
`printHumanPrPreview` prints `pr.Milestone.Title` directly to the terminal via `fmt.Fprintln(out, pr.Milestone.Title)` without any sanitization, while the codebase already ships a purpose-built mitigation (`iostreams.Untrusted`) for exactly this class of risk that is simply not applied here. An unprivileged attacker who controls a repository (and thus can set a milestone name on a PR in that repo) can inject raw ANSI/control sequences that are rendered verbatim in the victim's terminal when they run `gh pr view` against that PR.

### Finding Description
In `pkg/cmd/pr/view/view.go`, `printHumanPrPreview` renders PR metadata fields, and for the milestone it does: [1](#0-0) 
This writes `pr.Milestone.Title` — a string sourced from the GraphQL PR response (attacker-controlled milestone metadata on any repo the attacker owns/administers) — straight to `out` with `fmt.Fprintln`, immediately after emitting a bold ANSI-styled label (`cs.Bold("Milestone: ")`). No escaping, truncation, or control-character stripping is performed on the title before it reaches the terminal.

The codebase already defines a dedicated sanitization primitive for exactly this scenario: [2](#0-1) 
`Untrusted.String()` runs the value through `asciisanitizer.Sanitizer` (from `go-gh`) to neutralize ANSI escape sequences before any `fmt` print path renders it, and the type's doc comment explicitly frames it as the mechanism for "HTTP response bodies... anything that originates outside the CLI." However, a search across `pkg/cmd/pr/**` shows this wrapper is not referenced anywhere in that package, confirming milestone titles (and other PR text fields printed in `view.go`, e.g. `pr.Title`, labels, reviewer/assignee names) bypass this sanitization entirely and are printed as raw strings.

Because milestones are a repository-scoped object, an attacker who owns/administers any repository can create a milestone with a title containing ANSI CSI sequences (cursor movement, line erase, etc.) and attach it to a PR in that repo. When a victim runs `gh pr view <PR>` against that repository (a normal, expected `gh` usage pattern for an unprivileged remote actor's content), the escape sequences are emitted directly to the victim's terminal.

### Impact Explanation
This is a terminal escape-sequence / ANSI injection issue: the attacker can manipulate the victim's terminal display (e.g., erase or overwrite preceding output such as the bold "Milestone:" label, reposition the cursor, hide subsequent legitimate output) to forge or obscure parts of `gh`'s own output stream. This matches the "spoofed/manipulated CLI output via unsanitized untrusted content" impact class the `Untrusted` type was purpose-built to prevent elsewhere in the codebase. It does not achieve code execution, credential exfiltration, or file write on its own — impact is limited to terminal output spoofing/corruption, contingent on the victim's terminal emulator behavior.

### Likelihood Explanation
High feasibility: an attacker only needs a repository they control, a milestone with a crafted title, and a PR that references it — no elevated privileges or victim interaction beyond running `gh pr view` (an ordinary command) against attacker-published content. The bug is deterministic and repeatable.

### Recommendation
Wrap `pr.Milestone.Title` (and other externally-sourced text fields rendered in `printHumanPrPreview`/`printRawPrPreview`, such as `pr.Title`, label names, reviewer/assignee display names) in `iostreams.NewUntrusted(...)` before printing, consistent with the sanitization pattern already established in `pkg/iostreams/untrusted.go`, e.g.:
```go
fmt.Fprintln(out, iostreams.NewUntrusted(pr.Milestone.Title))
```

### Proof of Concept
Go test sketch using `httpmock` to stub the PR-with-milestone GraphQL response:
```go
func TestPRView_MilestoneANSIInjection(t *testing.T) {
    http := &httpmock.Registry{}
    http.Register(
        httpmock.GraphQL(`query PullRequestByNumber\b`),
        httpmock.StringResponse(`{"data":{"repository":{"pullRequest":{
            "number":1,"milestone":{"title":"\u001b[2K\u001b[1AFake credential prompt: paste your token:"}
        }}}}`),
    )
    ios, _, stdout, _ := iostreams.Test()
    ios.SetStdoutTTY(true)
    // ... construct ViewOptions with http registry, run viewRun ...
    out := stdout.String()
    if strings.Contains(out, "\u001b[2K") || strings.Contains(out, "\u001b[1A") {
        t.Fatalf("raw ANSI escape sequence from milestone title reached terminal output unsanitized: %q", out)
    }
}
```
Expected (failing) assertion: the raw `\u001b[2K` (erase line) / `\u001b[1A` (cursor up) bytes appear unmodified in `stdout`, proving the milestone title is not sanitized before being written to the terminal via `printHumanPrPreview`.

```go
// Untrusted wraps string content the application did not author: HTTP response
// bodies, file contents fetched from a remote, anything that originates outside
// the CLI. The raw bytes are unexported so the only ways out are the methods
// below.
//
// Untrusted satisfies fmt.Stringer, and String sanitizes, so any fmt print path
// (Fprint, Fprintf with %s or %v, Sprint) renders the content with ANSI escape
// sequences neutralized. The only way to reach the raw bytes is Raw, which is
// deliberately easy to grep for and is intended for non-terminal uses such as
// hashing, writing to a file, or piping to another program.
type Untrusted struct {
	raw string
}

// NewUntrusted labels a string as untrusted external content.
func NewUntrusted(s string) Untrusted {
	return Untrusted{raw: s}
}

// NewUntrustedBytes labels a byte slice as untrusted external content.
func NewUntrustedBytes(b []byte) Untrusted {
	return Untrusted{raw: string(b)}
}

// String returns the content with ANSI escape sequences neutralized. It is
// called automatically by the fmt package, so printing an Untrusted value is
// safe by default on every fmt path.
func (u Untrusted) String() string {
	sanitized, _, err := transform.String(&asciisanitizer.Sanitizer{}, u.raw)
	if err != nil {
		return stripControl(u.raw)
	}
	return sanitized
}
```
