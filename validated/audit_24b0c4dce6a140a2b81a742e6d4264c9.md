### Title
Off-by-one in `RemoveGovAfter`/`RemoveVotesAfter` retains stale governance state after rewind, causing consensus divergence — (`kaiax/gov/headergov/impl/rewind.go`)

---

### Summary

`RewindDelete(hash, N)` is the per-block deletion hook called for every block being unwound. It delegates to `RemoveVotesAfter(N)` and `RemoveGovAfter(N)`. Both helpers use a **strict** `>` comparison, so the entry at exactly `blockNum = N` is never deleted. When block N is an epoch block that carried a governance vote or a ratified governance payload, that data survives the rewind in both the in-memory maps and the on-disk index, corrupting the module's view of governance history for all subsequent blocks.

---

### Finding Description

`RemoveGovAfter` iterates `h.governances` and deletes only entries where `blockNumIter > blockNum`:

```go
// kaiax/gov/headergov/impl/rewind.go  lines 41-57
func (h *headerGovModule) RemoveGovAfter(blockNum uint64) {
    dirty := false
    for blockNumIter := range h.governances {
        if blockNumIter > blockNum {   // ← strict >, entry at N is skipped
            dirty = true
            ...
            delete(h.governances, blockNumIter)
        }
    }
    if dirty {
        WriteGovDataBlockNums(h.ChainKv, h.GovBlockNums())
        h.history = headergov.GovsToHistory(h.governances)
    }
}
``` [1](#0-0) 

`RemoveVotesAfter` has the identical flaw:

```go
for blockNumIter := range votes {
    if blockNumIter > blockNum {   // ← strict >, vote at N is skipped
``` [2](#0-1) 

The `RewindableModule` interface contract is explicit: `RewindDelete` **"should deal with exactly one block"** — the block being deleted. [3](#0-2) 

Because `dirty` is never set when the only stale entry is at exactly N, `WriteGovDataBlockNums` is also **not called**, so the on-disk block-number index (`govDataBlockNumsKey`) still lists N after the rewind. [4](#0-3) 

---

### Impact Explanation

**Path 1 — stale vote corrupts `VerifyGov` for the next epoch block (consensus divergence)**

`getExpectedGovernance(N + epoch)` reads `h.groupedVotes[epochIdx]`, which still contains the stale vote from old block N. It therefore expects the new block `N + epoch` to carry a ratified governance payload. If the new chain's block N carried no vote (or a different vote), the new block `N + epoch` will have no `header.Governance` field. `VerifyGov` then returns `ErrGovVerification` and the rewound node **rejects a block that every non-rewound peer accepts**, producing consensus divergence. [5](#0-4) [6](#0-5) 

**Path 2 — stale governance entry corrupts `GetParamSet` for blocks ≥ 2N**

`h.history` is rebuilt from `h.governances`. With the stale entry at N still present, `GetParamSet` returns wrong parameters (unit price, reward ratio, governing node, etc.) for any block whose `prevEpochStart` resolves to N. This affects `VerifyVote` (wrong governing-node check), fee validation, and reward distribution. [7](#0-6) [8](#0-7) 

**Path 3 — persistent on-disk index corruption across restarts**

Because `dirty` stays `false`, `WriteGovDataBlockNums` is never called. On the next node restart, `Init` calls `readGovDataFromDB` using the stale index, which still lists N. It attempts to load governance data for a block that has been deleted from the canonical chain, re-populating `h.governances[N]` with stale data and perpetuating the corruption across restarts. [9](#0-8) [10](#0-9) 

---

### Likelihood Explanation

Natural reorgs triggered by P2P block propagation call `setHeadBeyondRoot` → `delFn` → `module.RewindDelete` for every deleted block. This is a **permissionless, zero-privilege path**. A reorg that crosses an epoch boundary (e.g., a 1-block reorg at block N where N % epoch == 0) is sufficient to trigger the bug. Such reorgs are routine on live networks. [11](#0-10) 

---

### Recommendation

Change both comparisons from strict `>` to `>=` so that the entry at exactly `blockNum` is also removed:

```go
// RemoveGovAfter
if blockNumIter >= blockNum {   // was: blockNumIter > blockNum

// RemoveVotesAfter
if blockNumIter >= blockNum {   // was: blockNumIter > blockNum
```

Also ensure `dirty` is set and `WriteGovDataBlockNums` / `WriteVoteDataBlockNums` are called even when only the entry at `blockNum` itself is removed, so the on-disk index is kept consistent.

---

### Proof of Concept

```go
// Insert governance entry at epoch block N
h.AddGov(N, someGovData)
// Insert vote at block N
h.AddVote(N, someVoteData)

// Simulate rewind: blockchain calls RewindDelete for block N
h.RewindDelete(common.Hash{}, N)

// BUG: entry at N is still present
assert.Nil(t, h.governances[N])          // FAILS — entry survives
assert.NotContains(t, h.GovBlockNums(), N) // FAILS — index still lists N

// BUG: vote at N is still present
epochIdx := calcEpochIdx(N, epoch)
assert.Empty(t, h.groupedVotes[epochIdx][N]) // FAILS — vote survives

// Consequence: getExpectedGovernance(N+epoch) still sees the stale vote
// and VerifyGov will reject a valid new block at N+epoch that has no Governance field
``` [12](#0-11) [13](#0-12)

func (h *headerGovModule) RemoveVotesAfter(blockNum uint64) {
	dirty := false
	for epochIdxIter, votes := range h.groupedVotes {
		for blockNumIter := range votes {
			if blockNumIter > blockNum {
				dirty = true
				h.mu.Lock()
				delete(h.groupedVotes[epochIdxIter], blockNumIter)

	// (1)
	if header.Number.Uint64()%h.epoch != 0 {
		if len(header.Governance) > 0 {
			logger.Error("governance is not allowed in non-epoch block", "num", header.Number.Uint64())
			return ErrGovInNonEpochBlock
		} else {
			return nil
		}
	}

	// (2), (3)
	expected := h.getExpectedGovernance(header.Number.Uint64())
	if len(header.Governance) == 0 {
		if len(expected.Items()) != 0 {
			return ErrGovVerification
		}

		return nil
	}

	// (4)
	var gb headergov.GovBytes = header.Governance
	actual, err := gb.ToGovData()
	if err != nil {
		logger.Error("DeserializeHeaderGov error", "num", header.Number.Uint64(), "governance", gb, "err", err)
		return err
	}

	// (5)
	if !reflect.DeepEqual(expected, actual) {
		logger.Error("Governance mismatch", "expected", expected, "actual", actual)
		return ErrGovVerification
	}

	return nil

func (h *headerGovModule) getExpectedGovernance(blockNum uint64) headergov.GovData {
	prevEpochIdx := calcEpochIdx(blockNum, h.epoch) - 1
	prevEpochVotes := h.getVotesInEpoch(prevEpochIdx)
	govs := make(gov.PartialParamSet)

	sortedVoteBlocks := slices.Collect(maps.Keys(prevEpochVotes))
	slices.Sort(sortedVoteBlocks)

	for _, voteBlock := range sortedVoteBlocks {
		vote := prevEpochVotes[voteBlock]
		govs.Add(string(vote.Name()), vote.Value())
	}

	// assert(len(headergov.NewGovData(govs).Items()) == len(govs))
	return headergov.NewGovData(govs)
}

func (h *headerGovModule) GetParamSet(blockNum uint64) gov.ParamSet {
	h.mu.RLock()
	defer h.mu.RUnlock()

	prevEpochStart := PrevEpochStart(blockNum, h.epoch, h.isKoreHF(blockNum))
	gh := h.history
	gp, err := gh.Search(prevEpochStart)
	if err != nil {
		logger.Warn("No param set", "blockNum", blockNum, "prevEpochStart", prevEpochStart)
		return *gov.GetDefaultGovernanceParamSet()

	return gp
