### Title
Governance vote of `kip71.gastarget = 0` causes division-by-zero panic in `NextMagmaBlockBaseFee`, halting all nodes — (`params/kip71_config.go`)

---

### Summary

The `kip71.gastarget` governance parameter accepts `0` as a valid value (its `FormatChecker` is `noopFormatChecker`). Once ratified, every subsequent call to `NextMagmaBlockBaseFee` divides by `gasTarget` without a zero-guard, triggering a Go runtime panic that crashes every node processing any block with non-zero gas usage.

---

### Finding Description

`NextMagmaBlockBaseFee` in `params/kip71_config.go` computes the next base fee by dividing by `gasTarget` at two points:

```go
// line 102 (parentGasUsed > gasTarget branch)
y := x.Div(x, new(big.Int).SetUint64(gasTarget))

// line 120 (parentGasUsed < gasTarget branch)
y := x.Div(x, new(big.Int).SetUint64(gasTarget))
``` [1](#0-0) 

Go's `(*big.Int).Div` panics when the divisor is zero. The function already has an explicit zero-guard for `BaseFeeDenominator`:

```go
if kc.BaseFeeDenominator == 0 {
    // To avoid panic, set the fluctuation range small
    baseFeeDenominator = new(big.Int).SetUint64(64)
}
``` [2](#0-1) 

No equivalent guard exists for `GasTarget`.

The `Kip71GasTarget` parameter definition uses `noopFormatChecker`, meaning any `uint64` value — including `0` — passes format validation:

```go
Kip71GasTarget: {
    Canonicalizer: uint64Canonicalizer,
    FormatChecker: noopFormatChecker,
    ...
    DefaultValue: uint64(30000000),
},
``` [3](#0-2) 

In `checkConsistency`, `gov.Kip71GasTarget` falls into the no-op branch — no cross-parameter or range check is applied:

```go
case gov.Kip71BaseFeeDenominator, gov.Kip71GasTarget, gov.Kip71MaxBlockGasUsedForBaseFee,
    ...
    return nil
``` [4](#0-3) 

---

### Impact Explanation

After the governance vote for `kip71.gastarget = 0` is ratified at epoch block `k*epoch` and takes effect at `(k+1)*epoch`:

1. Every call to `NextMagmaBlockBaseFee` on a block with `parentGasUsed > 0` reaches line 102 or 120 and executes `big.Int.Div(x, big.NewInt(0))`.
2. Go's runtime panics with "division by zero", crashing the node process.
3. `NextMagmaBlockBaseFee` is called during both `PrepareHeader` (block production) and `VerifyMagmaHeader` (block import/sync), so **every node** — proposers, validators, and full nodes — crashes on the first non-empty block after the governance change takes effect.
4. The chain halts permanently until all nodes are patched and restarted with a corrected parameter.

This is an invalid state transition / consensus-halting condition affecting all honest nodes. [5](#0-4) 

---

### Likelihood Explanation

- In `none` governance mode, any GC member (validator) can cast this vote. The vote passes all existing validation layers (`NewVoteData` format check, `checkConsistency`, `VerifyVote`) without error.
- In `single` governance mode, only the governing node can vote, raising the privilege bar — but the code-level defect (missing zero-guard) is identical.
- The `BaseFeeDenominator == 0` guard already in the same function proves the developers are aware of this class of risk; the `GasTarget` case was simply missed.

---

### Recommendation

Add a zero-guard for `GasTarget` in `NextMagmaBlockBaseFee`, mirroring the existing `BaseFeeDenominator` guard:

```go
gasTarget := kc.GasTarget
if gasTarget == 0 {
    // Avoid division by zero; treat as if gas usage equals target (no change)
    return makeEvenByFloor(parentBaseFee)
}
```

Additionally, add a non-zero `FormatChecker` for `Kip71GasTarget` in `kaiax/gov/param.go` to reject `0` at vote time:

```go
FormatChecker: func(cv any) bool {
    v, ok := cv.(uint64)
    return ok && v > 0
},
``` [3](#0-2) 

---

### Proof of Concept

1. On a Magma-enabled chain in `none` governance mode, any GC member calls:
   ```
   governance_vote("kip71.gastarget", 0)
   ```
2. The vote is inscribed in `header.Vote` when the caller becomes proposer. `VerifyVote` → `checkConsistency` returns `nil` (no-op branch). Vote is accepted.
3. At the next epoch block, the vote is ratified and written to `header.Governance`.
4. Starting from `(k+1)*epoch`, `GetParamSet()` returns `GasTarget = 0`.
5. The first block with any transactions (non-zero `parentGasUsed`) triggers:
   ```
   x.Div(x, new(big.Int).SetUint64(0))  // panic: division by zero
   ```
   in `NextMagmaBlockBaseFee` at line 102 or 120.
6. All nodes crash. Chain halts. [6](#0-5)
