### Title
Same-Epoch Dual Governance Vote Bypasses Cross-Bound Validation, Permanently Corrupting KIP-71 Base Fee — (`kaiax/gov/headergov/impl/header.go`)

---

### Summary

`checkConsistency` in `kaiax/gov/headergov/impl/header.go` validates each governance vote individually against the **current** effective `ParamSet`. When `Kip71LowerBoundBaseFee` and `Kip71UpperBoundBaseFee` are both voted within the same epoch, each vote passes its individual check against the pre-epoch params, but the combined result — `LowerBoundBaseFee > UpperBoundBaseFee` — is never validated. This inverted state is committed to governance at the epoch boundary and permanently corrupts the KIP-71 base fee calculation in `NextMagmaBlockBaseFee`, causing every subsequent block to charge incorrect transaction fees and burn incorrect amounts of KAIA.

---

### Finding Description

`checkConsistency` is called from `VerifyVote` once per block header that carries a vote. For the two KIP-71 bound parameters the checks are:

```go
// kaiax/gov/headergov/impl/header.go  lines 179-192
case gov.Kip71LowerBoundBaseFee:
    params := h.GetParamSet(blockNum)          // reads CURRENT committed params
    if vote.Value().(uint64) > params.UpperBoundBaseFee {
        return ErrLowerBoundBaseFee
    }
case gov.Kip71UpperBoundBaseFee:
    params := h.GetParamSet(blockNum)          // reads CURRENT committed params
    if vote.Value().(uint64) < params.LowerBoundBaseFee {
        return ErrUpperBoundBaseFee
    }
```

`GetParamSet(blockNum)` returns the parameter set that was **already committed** at the last epoch boundary. It does not include any pending votes cast earlier in the current epoch. Therefore, if two votes are cast in the same epoch:

| Block | Vote | Check against current params | Result |
|-------|------|------------------------------|--------|
| 400 | `LowerBoundBaseFee = 600` | `600 <= 750` (current upper) | ✅ passes |
| 500 | `UpperBoundBaseFee = 100` | `100 >= 25` (current lower) | ✅ passes |

At the epoch boundary `getExpectedGovernance` collects both votes and writes `LowerBoundBaseFee=600, UpperBoundBaseFee=100` into `header.Governance`. `VerifyGov` only checks that the bytes match the locally derived map — it performs no cross-parameter consistency check. The inverted bounds are committed. [1](#0-0) [2](#0-1) 

---

### Impact Explanation

After the inverted bounds are committed, every call to `NextMagmaBlockBaseFee` (used by `VerifyMagmaHeader` and the block builder) enters a permanently oscillating state:

```
// params/kip71_config.go  lines 82-86
if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {   // upper is now the SMALL value (100)
    parentBaseFee = upperBoundBaseFee              // clamp to 100
} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
    parentBaseFee = lowerBoundBaseFee
}
```

With `lower=600, upper=100`:

- Any `parentBaseFee >= 100` → clamped to `100`.
- Gas below target → `nextBaseFee = 100 − delta < 600` → clamped back to `600`.
- Next block: `600 >= 100` → clamped to `100` again.
- **Infinite oscillation between 100 and 600 every block.** [3](#0-2) 

Because all honest nodes apply the same broken governance parameters, they all compute the same wrong base fee and reach consensus — but the fee charged to every transaction sender and the amount of KAIA burnt per block are both permanently wrong. This constitutes:

- **Unauthorized incorrect fee charges** to all transaction senders (protected-asset impact).
- **Incorrect fee burn** (KIP-71 burn mechanism broken), inflating or deflating KAIA supply relative to the intended schedule.
- **Persistent corruption of chain state** that cannot self-heal without a governance correction vote.

---

### Likelihood Explanation

In `"none"` or `"all"` governance mode any validator who is elected proposer in two blocks within the same epoch can cast both conflicting votes unilaterally. In `"single"` mode the governing node alone can do so. The epoch length is configurable (default 604,800 blocks); a validator is routinely a proposer many times per epoch, making the two-vote sequence trivially achievable in a single epoch without any external coordination. [4](#0-3) [5](#0-4) 

---

### Recommendation

In `checkConsistency`, when validating a `Kip71LowerBoundBaseFee` vote, also look up any pending `Kip71UpperBoundBaseFee` vote already recorded in the current epoch (and vice versa), and cross-validate the two proposed values against each other. Alternatively, add a combined consistency check inside `VerifyGov` (or `getExpectedGovernance`) that rejects any epoch-boundary governance whose resulting `ParamSet` has `LowerBoundBaseFee >= UpperBoundBaseFee`.

```go
// Proposed addition in checkConsistency
case gov.Kip71LowerBoundBaseFee:
    params := h.GetParamSet(blockNum)
    newLower := vote.Value().(uint64)
    // Use pending upper if already voted this epoch, else current upper
    effectiveUpper := h.getPendingOrCurrentUpper(blockNum, params.UpperBoundBaseFee)
    if newLower >= effectiveUpper {
        return ErrLowerBoundBaseFee
    }
case gov.Kip71UpperBoundBaseFee:
    params := h.GetParamSet(blockNum)
    newUpper := vote.Value().(uint64)
    effectiveLower := h.getPendingOrCurrentLower(blockNum, params.LowerBoundBaseFee)
    if newUpper <= effectiveLower {
        return ErrUpperBoundBaseFee
    }
```

### Proof of Concept

Assume epoch = 1000, current params: `LowerBoundBaseFee=25_000_000_000`, `UpperBoundBaseFee=750_000_000_000`.

1. **Block 400** (validator V is proposer): V casts vote `Kip71LowerBoundBaseFee = 600_000_000_000`.
   - `checkConsistency`: `600e9 <= 750e9` → passes. Block accepted.

2. **Block 700** (validator V is proposer again): V casts vote `Kip71UpperBoundBaseFee = 100_000_000_000`.
   - `checkConsistency`: `100e9 >= 25e9` → passes. Block accepted.

3. **Block 1000** (epoch boundary): `getExpectedGovernance` collects both votes. `header.Governance = {"kip71.lowerboundbasefee": 600e9, "kip71.upperboundbasefee": 100e9}`. `VerifyGov` confirms the bytes match — no cross-check. Governance committed.

4. **Block 1001 onward**: `NextMagmaBlockBaseFee` is called with `lower=600e9, upper=100e9`. Any `parentBaseFee >= 100e9` is clamped to `100e9`. With gas below target, `nextBaseFee < 600e9` → clamped to `600e9`. Next block: `600e9 >= 100e9` → clamped to `100e9`. The base fee oscillates between `100e9` and `600e9` every block indefinitely, charging users the wrong fee and burning the wrong amount of KAIA on every transaction. [6](#0-5) [7](#0-6)

// VerifyVote checks the following:
// (1) voter must be in valset,
// (2) integrity of the voter (the voter must be the block proposer),
// (3) the vote value must be consistent compared to the latest ParamSet.
func (h *headerGovModule) VerifyVote(header *types.Header) error {
	if len(header.Vote) == 0 {
		return nil
	}

	var (
		vb       headergov.VoteBytes = header.Vote
		blockNum                     = header.Number.Uint64()
	)

	vote, err := vb.ToVoteData()
	if err != nil {
		logger.Error("ToVoteData error", "num", blockNum, "vote", vb, "err", err)
		return err
	}

	if gov.DeprecatedAt(vote.Name(), h.ChainConfig.Rules(header.Number)) {
		logger.Error("Vote is deprecated", "num", blockNum, "name", vote.Name())
		return ErrDeprecatedVote
	}

	council, err := h.ValSet.GetCouncil(blockNum)
	if err != nil {
		return err
	}

	// check if the voter is in council
	if !slices.Contains(council, vote.Voter()) {
		return ErrInvalidKeyValue
	}

	// check if Voter is the block proposer.
	author, err := h.Chain.Sealer().Author(header)
	if err != nil {
		return err
	}
	if author != vote.Voter() {
		return ErrInvalidVoter
	}

	// In single mode, only the governing node can write header.Vote after Permissionless.
	params := h.GetParamSet(blockNum)
	if h.ChainConfig.IsPermissionlessForkEnabled(new(big.Int).SetUint64(blockNum)) &&
		params.GovernanceMode == "single" &&
		vote.Voter() != params.GoverningNode {
		return ErrVotePermissionDenied
	}

	return h.checkConsistency(blockNum, vote)
}

// (2) if there are no votes in the previous epoch, governance must be empty,

func (h *headerGovModule) VerifyGov(header *types.Header) error {
	// (1)
	if header.Number.Uint64()%h.epoch != 0 {
		if len(header.Governance) > 0 {
			logger.Error("governance is not allowed in non-epoch block", "num", header.Number.Uint64())
			return ErrGovInNonEpochBlock
		} else {
			return nil
		}
	}

	// (2), (3)
	expected := h.getExpectedGovernance(header.Number.Uint64())
	if len(header.Governance) == 0 {
		if len(expected.Items()) != 0 {
			return ErrGovVerification
		}

		return nil
	}

	// (4)
	var gb headergov.GovBytes = header.Governance
	actual, err := gb.ToGovData()
	if err != nil {
		logger.Error("DeserializeHeaderGov error", "num", header.Number.Uint64(), "governance", gb, "err", err)
		return err
	}

	// (5)
	if !reflect.DeepEqual(expected, actual) {
		logger.Error("Governance mismatch", "expected", expected, "actual", actual)
		return ErrGovVerification
	}

	return nil
}

func (h *headerGovModule) getExpectedGovernance(blockNum uint64) headergov.GovData {
	prevEpochIdx := calcEpochIdx(blockNum, h.epoch) - 1
	prevEpochVotes := h.getVotesInEpoch(prevEpochIdx)
	govs := make(gov.PartialParamSet)

	sortedVoteBlocks := slices.Collect(maps.Keys(prevEpochVotes))
	slices.Sort(sortedVoteBlocks)

	for _, voteBlock := range sortedVoteBlocks {
		vote := prevEpochVotes[voteBlock]
		govs.Add(string(vote.Name()), vote.Value())
	}

	// assert(len(headergov.NewGovData(govs).Items()) == len(govs))
	return headergov.NewGovData(govs)
}

func (kc *KIP71Config) NextMagmaBlockBaseFee(parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) *big.Int {
	// governance parameters
	lowerBoundBaseFee := new(big.Int).SetUint64(kc.LowerBoundBaseFee)
	upperBoundBaseFee := new(big.Int).SetUint64(kc.UpperBoundBaseFee)
	makeEvenByCeil(lowerBoundBaseFee)
	makeEvenByFloor(upperBoundBaseFee)

	// If the parent is the magma disabled block or genesis, then return the lowerBoundBaseFee (default 25ston)
	if parentHeaderNumber.Cmp(new(big.Int).SetUint64(0)) == 0 || parentHeaderBaseFee == nil {
		return makeEvenByFloor(lowerBoundBaseFee)
	}

	var baseFeeDenominator *big.Int
	if kc.BaseFeeDenominator == 0 {
		// To avoid panic, set the fluctuation range small
		baseFeeDenominator = new(big.Int).SetUint64(64)
	} else {
		baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
	}
	gasTarget := kc.GasTarget
	upperGasLimit := kc.MaxBlockGasUsedForBaseFee

	// check the case of upper/lowerBoundBaseFee is updated by governance mechanism
	parentBaseFee := parentHeaderBaseFee
	if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {
		parentBaseFee = upperBoundBaseFee
	} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
		parentBaseFee = lowerBoundBaseFee
	}

	// upper gas limit cut off the impulse of used gas to upper bound
	parentGasUsed := min(parentHeaderGasUsed, upperGasLimit)
	if parentGasUsed == gasTarget {
		return makeEvenByFloor(parentBaseFee)
	} else if parentGasUsed > gasTarget {
		// shortcut. If parentBaseFee is already reached upperbound, do not calculate.
		if parentBaseFee.Cmp(upperBoundBaseFee) == 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		// If the parent block used more gas than its target,
		// the baseFee of the next block should increase.
		// baseFeeDelta = max(1, parentBaseFee * (parentGasUsed - gasTarget) / gasTarget / baseFeeDenominator)
		gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := math.BigMax(x.Div(y, baseFeeDenominator), common.Big1)

		nextBaseFee := x.Add(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(upperBoundBaseFee) > 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	} else {
		// shortcut. If parentBaseFee is already reached lower bound, do not calculate.
		if parentBaseFee.Cmp(lowerBoundBaseFee) == 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		// Otherwise if the parent block used less gas than its target,
		// the baseFee of the next block should decrease.
		// baseFeeDelta = parentBaseFee * (gasTarget - parentGasUsed) / gasTarget / baseFeeDenominator
		gasUsedDelta := new(big.Int).SetUint64(gasTarget - parentGasUsed)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := x.Div(y, baseFeeDenominator)

		nextBaseFee := x.Sub(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(lowerBoundBaseFee) < 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	}
