CCMenu Read Token Not Scoped to Requesting Stack Grants Cross-Stack Read Access - ([File: app/controllers/shipit/ccmenu_url_controller.rb])

### Summary
`CCMenuUrlController#fetch` is advertised, in the UI, as generating a per-stack read-only URL (`Settings → "Fetch URL"` button embeds `stack_id: @stack.to_param`), but the `ApiClient` it mints is never bound to that stack. Because `ApiClient#stack_id` is left `nil`, the token is treated as globally scoped by `Shipit::Api::BaseController#stacks`, and `Shipit::Api::CCMenuController#stack` additionally bypasses that scope check entirely by resolving `Stack.from_param!(params[:stack_id])` directly. The equality the app is supposed to enforce — *the stack a token authorises == the stack it touches* — is never checked, so the query-string token embedded in one stack's CCMenu URL can be replayed with a different `stack_id` to read any other stack's build/deploy status.

### Finding Description
- `CCMenuUrlController#client` creates/looks up the token with: [1](#0-0) 
  `ApiClient.create_with(permissions: %w[read:stack]).find_or_create_by!(creator: current_user, name: 'CCMenu Client')` — note `stack:` is never passed, so `ApiClient#stack_id` remains `nil` even though `ApiClient` supports a `belongs_to :stack, optional: true` scoping field: [2](#0-1) 
- The generated URL embeds a specific `stack_id` (`api_stack_ccmenu_url(stack_id: stack.to_param)`), giving the visual/UX impression the token is scoped to that one stack: [3](#0-2) 
  and is presented per-stack on the stack settings page: [4](#0-3) 
- On the consuming side, `Shipit::Api::BaseController` would normally restrict a scoped client to its own stack via `stacks`, but only when `stack_id?` is true: [5](#0-4) 
  Since the client is never given a `stack_id`, this scoping is a no-op (`Stack.all`).
- `Shipit::Api::CCMenuController` compounds the issue by not even using the (already ineffective) `stacks` scoping — it resolves the target stack directly from the unauthenticated URL parameter: [6](#0-5) 
- `check_permissions!` only verifies the string `"read:stack"` is present in the client's permission list; it performs no per-stack comparison at all: [7](#0-6) 

Because CCMenu URLs are designed to be embedded in external CI dashboards/badges without any further authentication (the token alone authorizes the request), a single leaked/shared CCMenu URL from Stack A grants the holder read access to the build/deploy status of every stack in the Shipit instance, not just Stack A.

### Impact Explanation
This is an unauthenticated (beyond possessing the URL) cross-stack information-disclosure of stack state — it discloses `lastBuildStatus`, `lastBuildLabel`, `activity`, lock status, etc. for arbitrary stacks the token holder was never intended to see. This matches the High-impact category "unauthenticated read of stack state, task streams or deploy output" defined in scope, since CCMenu URLs are explicitly meant to be embeddable/shareable artifacts, not secrets bound to a login session.

### Likelihood Explanation
High. No special privilege is required beyond obtaining one valid, already-shared CCMenu URL (these are designed to be pasted into third-party CI tools/badges and are not treated as sensitive by users). The `stack_id` path segment is fully attacker-controlled and trivially guessable/enumerable (`owner/repo/environment` triples, often public GitHub repo names). No additional authentication, signature, or per-stack check exists to stop the substitution.

### Recommendation
- Persist the requesting stack on the `ApiClient` created in `CCMenuUrlController#client` (e.g., `ApiClient.create_with(permissions: %w[read:stack], stack:).find_or_create_by!(creator: current_user, stack:, name: 'CCMenu Client')`), and use a per-stack lookup key.
- In `Shipit::Api::CCMenuController#stack`, resolve the target stack via the scoped `stacks` collection (`stacks.from_param!(params[:stack_id])`) instead of the unscoped `Stack.from_param!`, so a client whose `stack_id` doesn't match the requested stack is rejected.
- Add an explicit assertion in `ApiClient#check_permissions!` (or a new check) that when `stack_id` is present it must equal the stack being acted upon.

### Proof of Concept
1. As a logged-in Shipit user with access only to Stack A, click "Fetch URL" on Stack A's settings page (`GET /ccmenu/*A/`) to obtain `https://shipit.example.com/api/stacks/*A/ccmenu?token=<T>`.
2. Share/embed that URL as a CI badge (its normal intended use).
3. An unprivileged holder of that URL replaces the stack path segment with Stack B's identifier while reusing the same `token=<T>`: `GET /api/stacks/*B/ccmenu?token=<T>`.
4. `CCMenuController#authenticate_api_client` successfully authenticates `<T>` via `ApiClient.authenticate`; `require_permission :read, :stack` passes because `<T>` has `read:stack`; `stack` resolves `Stack.from_param!(params[:stack_id])` for Stack B directly, bypassing any per-stack ownership check.
5. Response renders Stack B's CCMenu XML (build status, activity, lock state) even though `<T>` was only ever meant to authorize Stack A. [8](#0-7) [9](#0-8)

require 'uri'

module Shipit
  class CCMenuUrlController < ShipitController
    def fetch
      uri = URI(api_stack_ccmenu_url(stack_id: stack.to_param))
      uri.query = { 'token' => client.authentication_token }.to_query
      render(json: { ccmenu_url: uri.to_s })
    end

    private

    def client
      @client ||= ApiClient.create_with(permissions: %w[read:stack])
                           .find_or_create_by!(creator: current_user, name: 'CCMenu Client')
    end

    def stack
      @stack ||= Stack.from_param!(params[:stack_id])
    end
  end
end

# frozen_string_literal: true

module Shipit
  module Api
    class CCMenuController < BaseController
      require_permission :read, :stack

      class NoDeploy
        def id
          0
        end

        def ended_at
          Time.now.utc
        end

        def running?
          false
        end
      end

      def show
        latest_deploy = stack.deploys_and_rollbacks.last || NoDeploy.new
        render('shipit/ccmenu/project', formats: [:xml], locals: { stack:, deploy: latest_deploy })
      end

      private

      def stack
        @stack ||= Stack.from_param!(params[:stack_id])
      end

      def authenticate_api_client
        @current_api_client = ApiClient.authenticate(params[:token])
        super unless @current_api_client
      end
    end
  end
end
