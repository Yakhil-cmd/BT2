**Analysis:** `camel_to_snake` in [1](#0-0)  is a **compile-time proc-macro helper**. It is invoked inside the `#[proc_macro_derive(CryptoHasher)]` expansion at [2](#0-1)  solely to build the *Rust identifier names* for the static seed/hasher variables (`#static_seed_name`, `#static_hasher_name`). Its input is the hardcoded struct/enum name (`item.ident.to_string()`) chosen by the developer at compile time — it never receives any data derived from a transaction, authenticator, or API input, so unprivileged runtime input has no path into this function at all.

Critically, the actual domain-separation seed bytes used by `CryptoHasher::seed()` are computed from `aptos_crypto::_serde_name::trace_name::<#type_name>()` (the real Serde container name), not from the `camel_to_snake` output: [3](#0-2) . Even in the hypothetical case where two differently-cased type names produced an identical `snake_name` string, the consequence would be a duplicate `static` identifier, which is a **Rust compile-time naming collision** (a build failure), not a runtime seed collision — the hash seed itself is keyed by the distinct, fully-qualified type name via `trace_name`, so two different hasher types can never share a seed at runtime regardless of what `camel_to_snake` produces for identifier naming.

Since there is no unprivileged, runtime-reachable path from a `SignedTransaction`, authenticator, or API input into `camel_to_snake`, and the actual public-key-binding seed is derived independently of its output, this does not meet the admission-boundary exploit criteria.

/// Converts a camel-case string to snake-case
pub fn camel_to_snake(text: &str) -> String {
    let mut out = String::with_capacity(text.len());
    let mut first = true;
    text.chars().for_each(|c| {
        if !first && c.is_uppercase() {
            out.push('_');
            out.extend(c.to_lowercase());
        } else if first {
            first = false;
            out.extend(c.to_lowercase());
        } else {
            out.push(c);
        }
    });
    out
}
