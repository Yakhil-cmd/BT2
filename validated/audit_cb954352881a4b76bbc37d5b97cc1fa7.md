The AWS-LC X.509 name-constraints bypass concerns TLS certificate chain validation (CN/wildcard/SAN hostname matching), which is a network-layer trust mechanism. In Agave, the only X.509/TLS usage is confined to the QUIC transport layer in `tls-utils`, and that code deliberately disables all certificate-chain and hostname verification rather than relying on CN fallback logic: `SkipServerVerification::verify_server_cert` and `SkipClientVerification::verify_client_cert` both unconditionally return `Ok(...Verified::assertion())` without inspecting the certificate's subject or SAN fields at all [1](#0-0) [2](#0-1) . Peer identity is instead derived by extracting the raw Ed25519 public key straight from the self-signed DER certificate via `get_pubkey_from_tls_certificate`/`get_remote_pubkey`, with no CA chain, hostname, or CN validation involved at all [3](#0-2) .

Because Agave never performs name-constraint or CN-based hostname verification in the first place, there is no analogous logic path where a "bypass" of such checks could occur. This TLS/QUIC handshake code is also part of the peer-to-peer network layer, not reachable via a single submitted transaction's sanitization, sigverify, precompile, fee/compute-budget, account-loading, SVM/CPI, syscall, builtin, bank-commit, or stake/reward paths — placing it outside the in-scope categories and squarely in the excluded "network-layer" category per the scan rules.

pub fn get_pubkey_from_tls_certificate(
    der_cert: &rustls::pki_types::CertificateDer,
) -> Option<Pubkey> {
    let (_, cert) = X509Certificate::from_der(der_cert.as_ref()).ok()?;
    match cert.public_key().parsed().ok()? {
        PublicKey::Unknown(key) => Pubkey::try_from(key).ok(),
        _ => None,
    }
}

/// Recover the peer's Solana pubkey from a `quinn::Connection`. Accepts
/// only a self-signed cert chain of length 1 (matches the cert shape
/// produced by [`new_dummy_x509_certificate`]).
///
/// Single source of truth for anything doing QUIC and using
/// Solana validator identities for auth.
pub fn get_remote_pubkey(connection: &quinn::Connection) -> Option<Pubkey> {
    connection
        .peer_identity()?
        .downcast::<Vec<rustls::pki_types::CertificateDer>>()
        .ok()
        .filter(|certs| certs.len() == 1)?
        .first()
        .and_then(get_pubkey_from_tls_certificate)
}
