### Title
CAPI transport re-attaches Bearer token on every request regardless of destination host, defeating cross-host redirect stripping - (File: `pkg/cmd/agent-task/capi/client.go`)

### Summary
`capiTransport.RoundTrip()` in `pkg/cmd/agent-task/capi/client.go` unconditionally sets `Authorization: Bearer <token>` on every outgoing request before delegating to the wrapped transport, with no check of the request's destination host. This is the same class of bug as the reported flash-loan issue: a piece of code hands privileged material (here, the GitHub OAuth/session token used for CAPI, functioning like the "callback recipient") to whatever request comes through the pipe without any way to verify/scope the destination ("initiator"), unlike the sibling implementation in `api/http_client.go`.

### Finding Description
Compare the two "attach-token-to-outgoing-request" transports in this codebase:

- `AddAuthTokenHeader` in [1](#0-0)  explicitly detects whether a request is a redirect to a different host than the initial request (`redirectHostnameChange := getHost(req) != getHost(req.Response.Request)`) and refuses to set the `Authorization` header if the host changed. This is the correct, defensive pattern — analogous to what the audit report recommends: verify the "initiator"/origin before trusting a callback.
- `capiTransport.RoundTrip` in [2](#0-1)  has no equivalent check. It does:
```go
func (ct *capiTransport) RoundTrip(req *http.Request) (*http.Response, error) {
	req.Header.Set("Authorization", "Bearer "+ct.token)
	...
	return ct.rp.RoundTrip(req)
}
```
This transport is installed as the *outermost* `http.Client.Transport` via `NewCAPIClient` [3](#0-2) , and the underlying `httpClient` passed in is the shared `f.HttpClient()` used elsewhere for GitHub API calls (see `CapiClientFunc` in [4](#0-3) ). Because Go's `net/http.Client` runs `RoundTrip` again for every redirect hop, and `capiTransport.RoundTrip` re-sets `Authorization` on *every* call unconditionally (not just the first), it re-injects the Bearer token into a redirected request even when the request's host has changed from `ct.capiHost`/`ct.host` — silently overriding Go's own built-in protection that strips sensitive headers like `Authorization` when a redirect crosses origins.

### Impact Explanation
If a CAPI or GitHub API endpoint reachable through this client returns a 3xx redirect (e.g., `Location` header) to a different, attacker-influenced host — this is plausible for GHES/tenant deployments where `capiBaseURL` is resolved dynamically via a GraphQL query (`resolveCapiURL` in [5](#0-4) ) or where any downstream endpoint on the CAPI/API host is compromised or misconfigured — the user's Bearer token/session credential would be sent to the redirect target. This is a credential-exfiltration primitive: an attacker-controlled or attacker-influenced host reachable from a normal `gh` command flow (e.g., `gh agent-task create`, session listing, etc.) can end up receiving the user's GitHub token.

### Likelihood Explanation
The `capiTransport` unconditionally re-sets the header on *every* RoundTrip call including the one made for a followed redirect (the standard `http.Client` calls `Transport.RoundTrip` again per hop). There is no `CheckRedirect` override configured for this client to prevent cross-host redirects, and no host comparison inside `capiTransport.RoundTrip` (it only conditionally adds `Copilot-Integration-Id`/version headers based on host, but never gates the `Authorization` header). Reaching this requires the CAPI/API server to issue a redirect to a different host, which is plausible for enterprise/tenant hosts or if any endpoint in the chain is compromised, but I was not able to fully trace every server response path (e.g., whether GitHub's real CAPI backend ever legitimately issues cross-host redirects) to prove exploitation is trivially reachable in production traffic today — this should be validated against real server behavior.

### Recommendation
Mirror the pattern already used in `AddAuthTokenHeader`: before setting the `Authorization: Bearer` header in `capiTransport.RoundTrip`, verify that the request's destination host matches an expected/allow-listed host (e.g., `ct.capiHost` or `ct.host`), and skip attaching the token on host-changed redirects. Consider also setting an explicit `CheckRedirect` on the underlying `http.Client` to refuse cross-host redirects for this authenticated client, consistent with defense-in-depth already applied elsewhere in the codebase (e.g., `pkg/cmd/release/download/download.go`, `pkg/cmd/repo/delete/http.go`).

### Proof of Concept
Conceptual reproduction (not executed, since no live CAPI/redirect target was available to test against):
1. Configure `CapiClientFunc` to point `capiBaseURL` at a server the tester controls (simulating a resolved/misconfigured Copilot endpoint or a compromised intermediary).
2. Have that server respond to the first legitimate CAPI request with an HTTP 302 redirect to `https://attacker.example/collect`.
3. Because `capiTransport.RoundTrip` sets `Authorization: Bearer <token>` unconditionally on the redirected request (host now `attacker.example`, not `ct.capiHost`), the token is sent to `attacker.example`.
4. Compare against the same scenario routed only through `AddAuthTokenHeader` (`api/http_client.go`), which correctly withholds the token once `getHost(req) != getHost(req.Response.Request)`, as covered by the existing test `TestHTTPClientRedirectAuthenticationHeaderHandling` in [6](#0-5)  — there is no equivalent test/protection for `capiTransport`.

```go
// AddAuthTokenHeader adds an authentication token header for the host specified by the request.
func AddAuthTokenHeader(rt http.RoundTripper, cfg tokenGetter) http.RoundTripper {
	return &funcTripper{roundTrip: func(req *http.Request) (*http.Response, error) {
		// If the header is already set in the request, don't overwrite it.
		if req.Header.Get(authorization) == "" {
			var redirectHostnameChange bool
			if req.Response != nil && req.Response.Request != nil {
				redirectHostnameChange = getHost(req) != getHost(req.Response.Request)
			}
			// Only set header if an initial request or redirect request to the same host as the initial request.
			// If the host has changed during a redirect do not add the authentication token header.
			if !redirectHostnameChange {
				hostname := ghauth.NormalizeHostname(getHost(req))
				if token, _ := cfg.ActiveToken(hostname); token != "" {
					req.Header.Set(authorization, fmt.Sprintf("token %s", token))
				}
			}
		}
		return rt.RoundTrip(req)
	}}
}
```

```go
func (ct *capiTransport) RoundTrip(req *http.Request) (*http.Response, error) {
	req.Header.Set("Authorization", "Bearer "+ct.token)

	// Since this RoundTrip is reused for both Copilot API and
	// GitHub API requests, we conditionally add the integration
	// ID only when performing requests to the Copilot API.
	if req.URL.Host == ct.capiHost {
		req.Header.Add("Copilot-Integration-Id", "copilot-4-cli")

		// Ensure we are not using GitHub API versions while targeting CAPI.
		req.Header.Set("X-GitHub-Api-Version", "2026-01-09")
	}
	return ct.rp.RoundTrip(req)
```

```go
func CapiClientFunc(f *cmdutil.Factory) func() (capi.CapiClient, error) {
	return func() (capi.CapiClient, error) {
		cfg, err := f.Config()
		if err != nil {
			return nil, err
		}

		httpClient, err := f.HttpClient()
		if err != nil {
			return nil, err
		}

		authCfg := cfg.Authentication()
		host, _ := authCfg.DefaultHost()
		token, _ := authCfg.ActiveToken(host)

		cachedClient := api.NewCachedHTTPClient(httpClient, time.Minute*10)
		capiBaseURL, err := resolveCapiURL(cachedClient, host)
		if err != nil {
			return nil, fmt.Errorf("failed to resolve Copilot API URL: %w", err)
		}

		return capi.NewCAPIClient(httpClient, token, host, capiBaseURL), nil
	}
}
```

```go
// resolveCapiURL queries the GitHub API for the Copilot API endpoint URL.
func resolveCapiURL(httpClient *http.Client, host string) (string, error) {
	apiClient := api.NewClientFromHTTP(httpClient)

	var resp struct {
		Viewer struct {
			CopilotEndpoints struct {
				Api string `graphql:"api"`
			} `graphql:"copilotEndpoints"`
		} `graphql:"viewer"`
	}

	if err := apiClient.Query(host, "CopilotEndpoints", &resp, nil); err != nil {
		return "", err
	}

	if resp.Viewer.CopilotEndpoints.Api == "" {
		return "", errors.New("empty Copilot API URL returned")
	}

	return resp.Viewer.CopilotEndpoints.Api, nil
}
```

```go
func TestHTTPClientRedirectAuthenticationHeaderHandling(t *testing.T) {
	var request *http.Request
	server := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		request = r
		w.WriteHeader(http.StatusNoContent)
	}))
	defer server.Close()

	var redirectRequest *http.Request
	redirectServer := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		redirectRequest = r
		http.Redirect(w, r, server.URL, http.StatusFound)
	}))
	defer redirectServer.Close()

	client, err := NewHTTPClient(HTTPClientOptions{
		Config: tinyConfig{
			fmt.Sprintf("%s:oauth_token", strings.TrimPrefix(redirectServer.URL, "http://")): "REDIRECT-TOKEN",
			fmt.Sprintf("%s:oauth_token", strings.TrimPrefix(server.URL, "http://")):         "TOKEN",
		},
	})
	require.NoError(t, err)

	req, err := http.NewRequest("GET", redirectServer.URL, nil)
	require.NoError(t, err)

	res, err := client.Do(req)
	require.NoError(t, err)

	assert.Equal(t, "token REDIRECT-TOKEN", redirectRequest.Header.Get(authorization))
	assert.Equal(t, "", request.Header.Get(authorization))
	assert.Equal(t, 204, res.StatusCode)
}
```
