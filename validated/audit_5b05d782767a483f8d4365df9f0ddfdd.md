The `PartitionState::trackers` `DashMap` in `execution/block-partitioner/src/v2/state.rs` is part of the sharded block-execution partitioner, which reorders/schedules transactions across execution shards *after* a block has already been ordered by consensus and admitted via mempool/VM validation. It is not part of the transaction admission path (mempool, vm-validator, authenticator, or API input validation) required by the review scope [1](#0-0) .

`DashMap` is a concurrent hashmap that guarantees correctness of lookups regardless of internal shard/bucket collisions between keys — shard co-location of two `StorageKeyIdx` values under the hood does not cause "stale reads" or cross-contamination of the value stored under a different key; each entry's own `RwLock<ConflictingTxnTracker>` still gates concurrent access to that specific tracker [2](#0-1) . `key_owned_by_another_shard` and `update_trackers_on_accepting` both fetch the tracker for the exact `StorageKeyIdx` key via `self.trackers.get(&key)`/`self.trackers.get(&key_idx)`, so an attacker choosing keys that hash into the same internal DashMap shard as a victim's key has no effect on which `ConflictingTxnTracker` entry is read or written [3](#0-2) .

Additionally, this component operates on `StorageKeyIdx`/state-key conflict tracking for parallel execution scheduling, not on fee-payer, sender, or signer authentication — there is no sender/fee-payer binding decision made here, so even a hypothetical scheduling bug would not translate into an admission-boundary authorization bypass as defined by the review's Admission Impact Gate [4](#0-3) .

    pub(crate) fn key_owned_by_another_shard(&self, shard_id: ShardId, key: StorageKeyIdx) -> bool {
        let tracker_ref = self.trackers.get(&key).unwrap();
        let tracker = tracker_ref.read().unwrap();
        let range_start = self.start_txn_idxs_by_shard[tracker.anchor_shard_id];
        let range_end = self.start_txn_idxs_by_shard[shard_id];
        tracker.has_write_in_range(range_start, range_end)
    }

    pub(crate) fn update_trackers_on_accepting(
        &self,
        txn_idx: PrePartitionedTxnIdx,
        round_id: RoundId,
        shard_id: ShardId,
    ) {
        let ori_txn_idx = self.ori_idxs_by_pre_partitioned[txn_idx];
        let write_set = self.write_sets[ori_txn_idx].read().unwrap();
        let read_set = self.read_sets[ori_txn_idx].read().unwrap();
        for &key_idx in write_set.iter().chain(read_set.iter()) {
            self.trackers
                .get(&key_idx)
                .unwrap()
                .write()
                .unwrap()
                .mark_txn_ordered(txn_idx, round_id, shard_id);
        }
    }
