### Title
Gasless Swap Deadline Checked Only at Txpool Admission, Not at Block-Building Time — Proposer Loses Lent KAIA on Expired Bundle Execution (`kaiax/gasless/impl/getter.go`, `kaiax/gasless/impl/tx_pool.go`)

---

### Summary

The `kaiax/gasless` module enforces the swap `Deadline` field only inside `checkBalanceForSwap`, which is invoked at **txpool admission time** via `GetCheckBalance()`. The block-building gate `VerifyExecutable` / `IsExecutable`, called by the worker when it constructs the `[LendTx, ApproveTx?, SwapTx]` bundle, performs **no deadline check**. A user can submit a gasless swap with a deadline that is valid at submission but expires before the proposer seals the block. The proposer's `LendTx` (which transfers KAIA to the user) executes successfully, but the `SwapTx` reverts inside the Uniswap V2 router's `require(deadline >= block.timestamp)` guard, so the repayment never occurs. The proposer permanently loses the lent KAIA.

---

### Finding Description

**Txpool path (admission-time check — present):**

In `kaiax/gasless/impl/tx_pool.go`, `checkBalanceForSwap` enforces:

```go
// tx.deadline >= currentTimestamp
deadline := swapArgs.Deadline
if deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
    return fmt.Errorf("insufficient deadline: deadline=%s, want=%s", ...)
}
```

This rejects swaps whose deadline has already passed at the moment the transaction enters the pool. [1](#0-0) 

**Block-building path (execution-time check — absent):**

`VerifyExecutable` is the function called at block-building time to decide whether to emit a `LendTxGenerator` and include the bundle. It checks sender identity, token match, nonce sequencing, and repay amount — but contains **no deadline check**:

```go
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
    swapArgs, ok := decodeSwapTx(swapTx, g.signer)
    ...
    // SP3 – nonce checks
    // SP4 – repay amount check
    return nil   // ← deadline never tested
}
``` [2](#0-1) 

`IsExecutable` (the `bool` wrapper used by the txpool promotion path and the worker bundle extractor) delegates to `VerifyExecutable`, so it inherits the same omission. [3](#0-2) 

**Lend transaction mechanics:**

`GetLendTxGenerator` is called only after `IsExecutable` returns `true`. It creates a signed transfer of `lendAmount` KAIA from the proposer's node key to the swap sender:

```go
types.TxValueKeyAmount: lendAmount(approveTxOrNil, swapTx),
``` [4](#0-3) 

The lend amount equals the total gas fee of the gasless bundle (`swapTx.Fee()` + optional `approveTx.Fee()`). [5](#0-4) 

**On-chain revert:**

The Uniswap V2 Router (deployed as `GaslessSwapRouter`) enforces `require(deadline >= block.timestamp)` inside the swap call. When the deadline has expired, the `SwapTx` reverts. The `LendTx` that preceded it in the same block is already finalised and cannot be rolled back. The proposer's KAIA is gone; the user retains it.

---

### Impact Explanation

- **Asset affected:** KAIA held by the block proposer (validator node key balance).
- **Corrupted value:** `lendAmount` = `swapTx.GasFeeCap × swapTx.GasLimit` (+ approve fee if present). For a swap with a 1 000 000 gas limit at the base fee, this is on the order of 1 000 000 × baseFee KAIA per bundle.
- **Invariant broken:** The gasless protocol invariant is that the proposer is always repaid by the swap. When the deadline expires between txpool admission and block sealing, the repayment leg reverts while the lend leg is irreversible.
- **Scope:** Matches the allowed impact gate — unauthorized transfer of KAIA from a system participant (proposer) caused by a broken protocol invariant in production consensus/block-building code.

---

### Likelihood Explanation

- Any unprivileged user can submit a gasless swap with a `Deadline` set to `currentBlock.Time + N seconds` for a small `N`.
- Once admitted to the pool, the transaction persists. If the proposer's node is under load, or if the transaction is delayed by txpool eviction and re-submission, the deadline can expire while the transaction remains pending.
- The attacker does not need to predict the exact block; they only need the deadline to expire before the proposer seals. A deadline of a few blocks is sufficient.
- No privileged access, no key compromise, no majority-validator collusion required.

---

### Recommendation

Add a deadline check inside `VerifyExecutable` (and therefore `IsExecutable`) so that the block-building gate rejects bundles whose swap deadline has already passed relative to the **pending block's timestamp**:

```go
// In VerifyExecutable, after decoding swapArgs:
pendingTime := new(big.Int).SetUint64(g.Chain.CurrentBlock().Time().Uint64() + 1)
if swapArgs.Deadline.Cmp(pendingTime) < 0 {
    return ErrExpiredDeadline
}
```

Using `currentBlock.Time + 1` (a conservative lower bound for the next block timestamp) ensures the check is at least as strict as the on-chain router guard. The same check should be applied in the worker's bundle-extraction loop before `GetLendTxGenerator` is called.

---

### Proof of Concept

1. Attacker calls `eth_sendRawTransaction` with a gasless `SwapTx` whose `Deadline` = `currentBlock.Time + 2` (expires in ~2 seconds / ~1 block).
2. The txpool's `checkBalanceForSwap` passes because `deadline >= currentBlock.Time`.
3. One block elapses; `currentBlock.Time` advances past `Deadline`.
4. The proposer's worker calls `IsExecutable(nil, swapTx)` → `VerifyExecutable` → returns `nil` (no deadline check).
5. Worker emits `[LendTx(proposer → attacker, value=swapTx.Fee()), SwapTx]`.
6. `LendTx` executes: proposer's balance decreases by `swapTx.Fee()`, attacker's balance increases.
7. `SwapTx` executes: Uniswap V2 Router reverts with `UniswapV2Router: EXPIRED`.
8. Net result: attacker gained `swapTx.Fee()` KAIA; proposer lost the same amount with no repayment.

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
