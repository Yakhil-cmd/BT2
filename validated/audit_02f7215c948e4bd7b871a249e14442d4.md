The reported bug is a hardcoded incorrect Chainlink price-feed address in an external Solidity contract (`StableOracleWBTC.sol`), which is a static configuration/data-source error specific to that contract's constructor constants. I searched for structurally analogous logic in this Polkadot SDK repository:

- `pallet-oracle` (`substrate/frame/honzon/oracle/src/lib.rs`) is a generic key-value oracle pallet where `OracleKey`/`OracleValue` pairs are submitted by authorized members via `feed_values` [1](#0-0) . There is no hardcoded asset-to-feed mapping inside the pallet itself that could be "swapped" the way the Solidity contract swapped WETH/WBTC feed addresses — the key is caller/config-supplied, not baked into pallet logic.
- `pallet-asset-rate` stores a `FixedU128` conversion rate per `AssetKind`, set explicitly via privileged `create`/`update` calls under `CreateOrigin`/`UpdateOrigin` (root or governance) [2](#0-1) ; any wrong rate would require a privileged origin to set it, which is out of scope per the analog rules (no privileged prerequisites).
- `pallet-psm` (Peg Stability Module), the closest candidate for an oracle-consuming swap pallet, does **not** use any price oracle at all — its `mint`/`redeem` logic performs fixed-decimal 1:1 conversion between internal and external assets via `internal_to_external`/`external_to_internal`, with no `DataProvider`/oracle price lookup involved [3](#0-2) .

There is no reachable code path in this codebase where a user-triggered extrinsic causes a mismatched/wrong asset price feed to be consulted due to a code-level (not configuration-level) defect. The underlying bug class here is a static config/constant mistake, not a missing check or logic flaw exploitable by an unprivileged actor, so per the analog-scan rules (reject config-only/dependency-only findings) no valid FRAME/XCM analog exists.

	#[pallet::call]
	impl<T: Config> Pallet<T> {
		/// Initialize a conversion rate to native balance for the given asset.
		///
		/// ## Complexity
		/// - O(1)
		#[pallet::call_index(0)]
		#[pallet::weight(T::WeightInfo::create())]
		pub fn create(
			origin: OriginFor<T>,
			asset_kind: Box<T::AssetKind>,
			rate: FixedU128,
		) -> DispatchResult {
			T::CreateOrigin::ensure_origin(origin)?;

			ensure!(
				!ConversionRateToNative::<T>::contains_key(asset_kind.as_ref()),
				Error::<T>::AlreadyExists
			);
			ConversionRateToNative::<T>::set(asset_kind.as_ref(), Some(rate));

			Self::deposit_event(Event::AssetRateCreated { asset_kind: *asset_kind, rate });
			Ok(())
		}

		/// Update the conversion rate to native balance for the given asset.
		///
		/// ## Complexity
		/// - O(1)
		#[pallet::call_index(1)]
		#[pallet::weight(T::WeightInfo::update())]
		pub fn update(
			origin: OriginFor<T>,
			asset_kind: Box<T::AssetKind>,
			rate: FixedU128,
		) -> DispatchResult {
			T::UpdateOrigin::ensure_origin(origin)?;

			let mut old = FixedU128::zero();
			ConversionRateToNative::<T>::mutate(asset_kind.as_ref(), |maybe_rate| {
				if let Some(r) = maybe_rate {
					old = *r;
					*r = rate;

					Ok(())
				} else {
					Err(Error::<T>::UnknownAssetKind)
				}
			})?;

			Self::deposit_event(Event::AssetRateUpdated {
				asset_kind: *asset_kind,
				old,
				new: rate,
			});
			Ok(())
		}
