### Title
CPMatrix Initialized with Mid-Epoch `GetCandTesting` Instead of Epoch-Start Snapshot Causes Divergent CFS and Consensus Split at Epoch Boundary — (`kaiax/vrank/impl/scoring.go`)

### Summary

`newCPMatrix(blockNum)` seeds the candidate-proposer matrix with `GetCandTesting(blockNum)` where `blockNum` is the **current query block**, not `epochStart`. Nodes that cold-start or restart mid-epoch initialize the CPMatrix with a later, larger candidate set than nodes that have been running since epoch start. A byzantine block proposer can include a mid-epoch candidate `C` in `header.VRank` — which passes `VerifyHeader` because `C ∈ GetCandTesting(N-1)` — but `C` is absent from the CPMatrix of nodes that initialized before `C` joined. Those nodes silently skip `C`'s score. At the epoch boundary, `GetCFS` returns divergent maps across the two node populations, `isPassVrankTest` produces different demotion decisions, `writeTransitionToABv2` writes different diffs to ABv2, and the resulting state roots diverge — a consensus split.

### Finding Description

**Root cause — wrong snapshot block in `newCPMatrix`:**

```go
// scoring.go:134
func (v *VRankModule) newCPMatrix(blockNum uint64) (vrank.CPMatrix, error) {
    candidates, err := v.Valset.GetCandTesting(blockNum)  // ← should be epochStart
    ...
    return vrank.NewCPMatrix(candidates), nil
}
```

`lookupCFSSeed` calls `newCPMatrix(blockNum)` with the **current** block when no cache or checkpoint exists, then replays from `epochStart`. This means:

- **Node A** (running since epoch start): `PostInsertBlock(epochStart)` → `getCPMatrix(epochStart)` → `newCPMatrix(epochStart)` → `GetCandTesting(epochStart)` → CPMatrix **without C**. Cached at `epochStart`.
- **Node B** (restarted or syncing at `epochStart+5`): `catchUpScoreCaches` → `getCPMatrix(epochStart+5)` → no cache/checkpoint → `newCPMatrix(epochStart+5)` → `GetCandTesting(epochStart+5)` → CPMatrix **with C**. Replays from `epochStart`.

**Attack path:**

1. Candidate `C` joins `CandTesting` at block `epochStart+3` (permissionless, no attacker action needed).
2. Byzantine block proposer at block `epochStart+5` sets `header.VRank` to include `C`.
3. `VerifyHeader` passes: `C ∈ GetCandTesting(epochStart+4)` (N-1 = epochStart+4). [4](#0-3) 
4. `applyBlocksForCPMatrix` on Node A: `cpMatrix[C]` does not exist → `logger.Warn` + `continue`. Score not incremented. [3](#0-2) 
5. `applyBlocksForCPMatrix` on Node B: `cpMatrix[C]` exists → `cpMatrix.Increment(C, reporter)`. Score incremented.
6. At epoch boundary, `fetchVRankCtx` calls `GetCFS(epochEnd-1)`. Node A returns `cfs[C]=0`; Node B returns `cfs[C]≥1`. [6](#0-5) 
7. `isPassVrankTest(C)`: Node A → `true` (C stays in CandTesting or competes); Node B → `false` if score ≥ threshold (C demoted to Registered). [5](#0-4) 
8. `writeTransitionToABv2` is called during block finalization by all nodes independently. Different diffs → different ABv2 state → **different state roots** → consensus split. [7](#0-6) 

**Checkpoint propagation amplifies the bug:** Checkpoints are written every `VRankEpoch/8` blocks. A node that writes a checkpoint before `C` joined will seed all future lookups with a CPMatrix without `C`, persisting the divergence across restarts. [8](#0-7) 

### Impact Explanation

Divergent state roots at the epoch boundary cause honest nodes to reject each other's blocks. The validator set written to ABv2 differs between node populations, so the active validator set for the next epoch is inconsistent. This is a **consensus split / chain halt** on honest nodes — a required impact under the contest scope ("consensus divergence on honest nodes").

### Likelihood Explanation

- Any candidate joining `CandTesting` mid-epoch (a normal permissionless operation) creates the precondition.
- A single byzantine validator (one block proposer slot) is sufficient to trigger the divergence — no majority collusion required.
- Node restarts, syncing nodes, and nodes catching up after downtime all produce the vulnerable cold-start path through `newCPMatrix(headNum)` via `catchUpScoreCaches`. This is a routine operational state.
- The warning log in `applyBlocksForCPMatrix` provides no alerting that would surface the divergence before the epoch boundary.

### Recommendation

`newCPMatrix` must always be seeded with `GetCandTesting(epochStart)`, not the current query block:

```go
func (v *VRankModule) newCPMatrix(blockNum uint64) (vrank.CPMatrix, error) {
    epochStart := calcEpochStart(blockNum, v.vrankEpoch())
    candidates, err := v.Valset.GetCandTesting(epochStart)  // ← fixed
    ...
}
```

Additionally, `applyBlocksForCPMatrix` should return an error (not silently skip) when a `cfReport` address is absent from the CPMatrix, so any future initialization mismatch surfaces immediately rather than producing silent divergence.

### Proof of Concept

1. Set `VRankEpoch = 100`. Start two nodes: Node A from genesis, Node B restarted at block `epochStart+3`.
2. At block `epochStart+3`, register candidate `C` into `CandTesting`.
3. At block `epochStart+5`, byzantine proposer sets `header.VRank = encode([C])`. Confirm `VerifyHeader` passes on both nodes.
4. Assert: Node A's `getCPMatrix(epochStart+5)` has no entry for `C` (initialized from `GetCandTesting(epochStart)`). Node B's `getCPMatrix(epochStart+5)` has `C` with score ≥ 1.
5. At block `epochStart+100` (epoch boundary), call `GetCFS(epochStart+99)` on both nodes. Assert Node A returns `cfs[C]=0`, Node B returns `cfs[C]≥1`.
6. If `CfsThreshold=1`, assert Node A keeps `C` in `CandTesting` while Node B demotes `C` to `Registered`.
7. Assert the state roots of the epoch-boundary block differ between the two nodes.

func (v *ValsetModule) writeTransitionToABv2(
	vmenv *vm.EVM,
	header *types.Header,
	statedb *state.StateDB,
) error {
	num := header.Number.Uint64()
	tr, err := v.getTransitionResult(num, statedb)
	if err != nil {
		return err
	}

	// Compute diff against committed ABv2(N-1) to get only applyTr(N-1) changes.
	parentHeader := v.Chain.GetHeaderByNumber(num - 1)
	if parentHeader == nil {
		return errParentHeaderNotFound(num)
	}
	parentRes, err := system.ReadABv2Snapshot(statedb, v.Chain, parentHeader)
	if err != nil {
		return fmt.Errorf("failed to read ABv2(N-1): %w", err)
	}
	diff := diffNodeStates(parentRes.Nodes, tr.Nodes)

	// Skip the call if no changes and not an epoch block (epoch blocks need
	// the epochVACount snapshot update regardless)
	if len(diff) == 0 && !v.isVrankEpoch(num) {
		return nil
	}

	config := v.Chain.Config()
	from, msg, err := system.EncodeProcessSystemTransition(config.Rules(header.Number), diff, tr.epochVACountForWrite)
	if err != nil {
		logger.Error("Failed to encode processSystemTransition", "number", header.Number.Uint64(), "err", err.Error(), "nodes", diff.String())
		return err
	}
	if ret, err := blockchain.SystemTxCall(msg, from, header, vmenv, statedb, config.Rules(header.Number)); err != nil {
		return fmt.Errorf("processSystemTransition failed: %w (ret=%s)", err, common.Bytes2Hex(ret))
	}
	return nil
