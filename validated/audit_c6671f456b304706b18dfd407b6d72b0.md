### Title
Permissionless execution of a ready `Unpause` operation defeats an emergency controller pause - (File: `contracts/governance/src/timelock/lifecycle.rs`)

### Summary
`Governance::execute` can run any ready, unexpired timelocked operation without checking whether the controller is currently paused, and `executor=None` requires no caller authentication or role. [1](#0-0) [2](#0-1)  Because `AdminOperation::Unpause` resolves to a controller `unpause` call, any address can execute a queued unpause during an emergency and re-enable guarded lending actions. [3](#0-2) [4](#0-3) 

### Finding Description
A guardian can immediately pause the controller through `Governance::pause`, which forwards directly to `Controller::pause`. [5](#0-4)  However, `lifecycle::execute` only rejects governance-self targets, prepares the scheduled operation, invokes it, and clears it; it contains no pause-state check. [6](#0-5)  `prepare_execute` calls `authorize_executor`, and `authorize_executor` explicitly performs no authentication or role check when `executor` is `None`. [2](#0-1) [7](#0-6)  The protocol test confirms that a caller with no signatures can execute a ready operation. [8](#0-7)  Consequently, a previously scheduled `Unpause` that becomes ready before or during the emergency remains permissionlessly executable after the guardian pauses the controller. [9](#0-8) 

### Impact Explanation
An attacker can reverse the guardian’s emergency halt at the exact moment risk controls are needed, re-opening `supply`, `borrow`, flash loans, leveraged strategies, collateral swaps, migrations, index updates, revenue claims, and threshold refresh operations protected by `#[when_not_paused]`. [10](#0-9) [11](#0-10) [12](#0-11)  If the pause was initiated because of an oracle failure, pricing discrepancy, market malfunction, or active exploitation path, reopening those entrypoints can enable theft of user funds or protocol insolvency before a canceller can veto the queued operation. [13](#0-12) 

### Likelihood Explanation
The attacker cannot schedule `AdminOperation::Unpause` without the proposer role, so exploitation requires a valid `Unpause` operation to already be waiting or ready when the guardian pauses the controller. [14](#0-13)  Once such an operation is ready, however, no signature, executor role, or emergency-state condition prevents any observer from calling `execute(None, controller, "unpause", [], predecessor, salt)`. [15](#0-14) [16](#0-15)  Pending operations and readiness are public through `get_operation_state` and `get_operation_ledger`, allowing precise monitoring and immediate execution. [17](#0-16) 

### Recommendation
Treat controller pause as an emergency execution barrier for externally targeted administrative operations: either reject `Governance::execute` while the controller is paused, or specifically prevent ready `Unpause` operations from executing after a later guardian pause. Requiring a new post-emergency scheduling epoch or guardian/canceller confirmation for `Unpause` would prevent stale pre-incident approvals from becoming permissionlessly executable during the incident.

### Proof of Concept
```rust
#[test]
fn ready_unpause_executes_while_controller_paused() {
    let env = Env::default();
    env.mock_all_auths();

    let delay = 10;
    let (admin, controller, gov) = register_with_controller(&env, delay);
    let salt = zero_salt(&env);

    // Initial deployment starts paused.
    let op_id = gov.propose(&admin, &AdminOperation::Unpause, &salt);
    env.ledger().with_mut(|l| l.sequence_number += delay);
    gov.execute(
        &None,
        &controller,
        &Symbol::new(&env, "unpause"),
        &vec![&env],
        &zero_salt(&env),
        &salt,
    );
    assert!(!env.as_contract(&controller, || {
        stellar_contract_utils::pausable::paused(&env)
    }));

    // Schedule a second unpause before an incident.
    let emergency_salt = BytesN::<32>::from_array(&env, &[9; 32]);
    let op_id = gov.propose(&admin, &AdminOperation::Unpause, &emergency_salt);
    env.ledger().with_mut(|l| l.sequence_number += delay);
    assert_eq!(gov.get_operation_state(&op_id), OperationState::Ready);

    // Guardian emergency-pauses the controller.
    gov.pause(&admin);
    assert!(env.as_contract(&controller, || {
        stellar_contract_utils::pausable::paused(&env)
    }));

    // Any unauthenticated caller can defeat the pause.
    env.set_auths(&[]);
    gov.execute(
        &None,
        &controller,
        &Symbol::new(&env, "unpause"),
        &vec![&env],
        &zero_salt(&env),
        &emergency_salt,
    );

    assert!(!env.as_contract(&controller, || {
        stellar_contract_utils::pausable::paused(&env)
    }));
}
```
