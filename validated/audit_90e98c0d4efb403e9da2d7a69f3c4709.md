### Title
Argument/Flag Injection via Attacker-Controlled Skill Name Redirects `gh skill install` to Write Attacker Content to Arbitrary Local Paths - ([File: pkg/cmd/skills/search/search.go])

### Summary
`gh skill search` lets a user browse GitHub-hosted "Agent Skills" and select one to install. The interactive installer (`promptInstall`) re-invokes `gh` itself via `exec.Command`, passing the attacker-controlled repository name and skill identifier as raw, unescaped positional arguments to `gh skills install`. Because that sub-invocation uses normal Cobra flag parsing (not `DisableFlagParsing`), an attacker who controls the skill's directory name (fully attacker-controlled, since it's just a folder they create in their own public repository) can craft a skill "name" that Cobra parses as a flag (e.g. `--dir=<path>`) instead of a positional argument, redirecting the install target directory to an arbitrary filesystem location writable by the victim.

### Finding Description
`promptInstall` builds the install argument directly from search-result fields that originate from the attacker's own repository content: [1](#0-0) 

`s.SkillName` / `s.Path` are derived from the skill's directory name inside the (attacker-owned) source repository, and `s.Repo` is the attacker's own `owner/repo` string — both fully attacker-controlled at publish time: [2](#0-1) 

These values are passed as bare argv elements to a real `exec.Command` invocation of `gh skills install`:
```go
cmd := exec.Command(opts.ExecutablePath, "skills", "install", s.Repo, installArg,
    "--agent", host.ID, "--scope", scope)
```
Because `gh skills install` is a normal Cobra command (only `Args: cobra.MaximumNArgs(2)` is set, flag parsing is not disabled), Cobra parses `installArg` as a flag if it begins with `-`/`--`, rather than as the intended skill argument: [3](#0-2) 

If the attacker names their skill directory `--dir=/some/path`, the child `gh` process receives that as a real `--dir` flag. `resolveInstallDir` unconditionally honors `opts.Dir` when set, overriding the normal agent/scope-derived install location: [4](#0-3) 

The installer then writes attacker-supplied file contents (fetched verbatim from the attacker's repo blobs) to `filepath.Join(targetDir, skill.Name)` under that redirected directory: [5](#0-4) 

### Impact Explanation
This allows an unprivileged remote attacker (anyone who can publish a public GitHub repository containing a skill) to cause the victim's `gh` process to write attacker-controlled file content to a directory of the attacker's choosing on the victim's machine, outside the intended skills-install directory, when the victim uses the normal `gh skill search` → interactive install workflow. This is a file-write-outside-intended-path primitive, consistent with the reported bug class (attacker-controlled name/identifier strings being interpreted as executable directives rather than inert data).

### Likelihood Explanation
Requires the victim to run `gh skill search`, see the attacker's repo among results, and choose to install it via the interactive multi-select flow — a normal, expected usage pattern for this preview feature, not a privileged or local-attacker scenario. No dependency on MITM, leaked tokens, or admin access; only that the attacker's repository is discoverable and selected.

### Recommendation
- In `promptInstall`, invoke installation logic directly (in-process, e.g. via the `installer` package) instead of re-executing `gh` as a subprocess with untrusted strings as argv.
- If subprocess re-invocation must be kept, prefix positional arguments with `--` (`cmd := exec.Command(opts.ExecutablePath, "skills", "install", "--", s.Repo, installArg, ...)`) or otherwise disable flag reinterpretation, and additionally reject/escape skill names or repo strings that begin with `-`.
- Validate and sanitize `Skill.Name`/`Skill.Path` at discovery time to reject directory names beginning with `-`.

### Proof of Concept
1. Attacker publishes a public repository `attacker/skills-repo` containing `skills/--dir=/tmp/pwned/SKILL.md` (a directory literally named `--dir=/tmp/pwned`).
2. Victim runs `gh skill search <query>` and the malicious skill appears in results; victim selects it in the interactive multi-select installer.
3. `promptInstall` computes `installArg = "--dir=/tmp/pwned"` and executes:
   `gh skills install attacker/skills-repo --dir=/tmp/pwned --agent <host> --scope <scope>`
4. The child `gh skills install` process parses `--dir=/tmp/pwned` as the `--dir` flag (overriding the normal scope/agent-derived location) rather than as the missing skill positional argument, causing attacker-supplied file content to be written under `/tmp/pwned` instead of the intended skills directory.

func (s Skill) DisplayName() string {
	name := s.Name

		name = s.Namespace + "/" + name

		return "[plugins] " + name
	case "root":
		return "[root] " + name

	}

func installSkill(opts *Options, skill discovery.Skill, baseDir string) error {
	// Use skill.Name (not InstallName) for a flat directory layout.
	skillDir := filepath.Join(baseDir, skill.Name)
	if err := os.MkdirAll(skillDir, 0o755); err != nil {
		return fmt.Errorf("could not create directory %s: %w", skillDir, err)
	}

	files, err := discovery.DiscoverSkillFiles(opts.Client, opts.Host, opts.Owner, opts.Repo, skill.TreeSHA, skill.Path)
	if err != nil {
		return fmt.Errorf("could not list skill files: %w", err)
	}

	safeSkillDir, err := safepaths.ParseAbsolute(skillDir)
	if err != nil {
		return fmt.Errorf("could not resolve skill directory path: %w", err)
	}

	for _, file := range files {
		fetchedContent, err := discovery.FetchBlob(opts.Client, opts.Host, opts.Owner, opts.Repo, file.SHA)
		if err != nil {
			return fmt.Errorf("could not fetch %s: %w", file.Path, err)
		}

		// Install path: the blob is written to disk verbatim, so the raw bytes
		// must be preserved.
		content := fetchedContent.Raw()

		relPath := strings.TrimPrefix(file.Path, skill.Path+"/")

		safeDest, err := safeSkillDir.Join(relPath)
		if err != nil {
			var traversalErr safepaths.PathTraversalError
			if errors.As(err, &traversalErr) {
				return fmt.Errorf("blocked path traversal in %q", relPath)
			}
			return fmt.Errorf("could not resolve destination path: %w", err)
		}
		destPath := safeDest.String()

		if dir := filepath.Dir(destPath); dir != skillDir {
			if err := os.MkdirAll(dir, 0o755); err != nil {
				return fmt.Errorf("could not create directory: %w", err)
			}
		}

		if filepath.Base(relPath) == "SKILL.md" {
			content, err = frontmatter.InjectGitHubMetadata(content, opts.Host, opts.Owner, opts.Repo, opts.Ref, skill.TreeSHA, opts.PinnedRef, skill.Path)
			if err != nil {
				return fmt.Errorf("could not inject metadata: %w", err)
			}
		}

		if err := os.WriteFile(destPath, []byte(content), 0o644); err != nil {
			return fmt.Errorf("could not write %s: %w", destPath, err)
		}
	}

	return nil
}
