### Title
Symlink-following arbitrary file overwrite via `os.Create` in `createMetadataFile` - ([File: pkg/cmd/attestation/download/metadata.go])

### Summary
`createMetadataFile` writes attestation bundle data to a path built purely by `fmt.Sprintf` (`createJSONLinesFilePath`), then calls `os.Create` on it with no `Lstat`/symlink check. Because the resulting filename is fully deterministic from the artifact's digest, and `gh attestation download` always writes to the current working directory (`NewLiveStore("")` is hard-coded in `download.go`, there is no `--output` flag), an attacker who controls both the artifact file and the checkout directory contents (e.g. a malicious git repo) can pre-plant a symlink at the exact predictable filename, causing the victim's write to be redirected outside the intended location.

### Finding Description
`createJSONLinesFilePath` builds the target path with `fmt.Sprintf("%s.jsonl", artifact)` / `fmt.Sprintf("%s/%s", s.outputPath, path)` [1](#0-0) , and `createMetadataFile` then calls `os.Create(metadataFilePath)` directly with no symlink check [2](#0-1) . `os.Create` uses `O_RDWR|O_CREATE|O_TRUNC` without `O_NOFOLLOW`/`O_EXCL`, so if the target name already exists as a symlink, the write follows it and truncates/overwrites the symlink's target rather than creating a new file at that name.

The filename is derived from `artifact.DigestWithAlg()`, i.e. `"<alg>:<hex-digest>"` (or `"<alg>-<hex-digest>"` on Windows), computed by hashing the artifact file's actual bytes in `digestLocalFileArtifact` [3](#0-2) . Although the digest itself contains only hex characters (no `../` traversal is possible through the digest value), an attacker who supplies both the artifact file and the directory contents (a git repository/checkout) can precompute the digest of the artifact file they include and then commit a symlink at exactly that predictable filename (`sha256:<digest>.jsonl`), pointing outside the checkout (e.g., to `~/.bashrc`, `~/.ssh/authorized_keys`, or a hook file). Because `gh attestation download` always resolves its output path relative to the current directory (`opts.Store = NewLiveStore("")` in `RunE`, with no output-path flag) [4](#0-3) , running `gh attestation download <artifact> --owner <attacker>` from inside such a cloned repository will hit `createMetadataFile` -> `os.Create` on the attacker-planted symlink name, following it.

No `internal/safepaths` confinement or `Lstat`-based symlink detection is used anywhere in this package, unlike other file-writing paths in the codebase (`internal/zip/zip.go`, `pkg/cmd/run/download/*`) which do use `safepaths.Absolute.Join` for confinement .

### Impact Explanation
This is a file write outside the intended output path (arbitrary file overwrite), matching the "file write outside intended path" bounty impact class. The overwritten content is the attacker's chosen JSON-lines attestation bundle content (not arbitrary attacker bytes of their choosing beyond that structure), but the ability to redirect the write target to any path the victim's OS user can write to (dotfiles, shell rc files, git hooks, etc.) can be leveraged toward local persistence/code execution on subsequent shell or git actions.

### Likelihood Explanation
Exploitation requires: (1) the victim to clone/checkout an attacker-published git repository containing both a malicious artifact file and a git-tracked symlink whose name matches the digest of that artifact, (2) the victim to `cd` into that directory and run `gh attestation download <artifact> --owner/--repo <attacker>` from there. Git preserves symlinks on checkout by default on Linux/macOS (`core.symlinks=true`), making the precondition realistic for those platforms; Windows checkouts commonly require Developer Mode/privilege for symlinks and are less likely to be affected. The digest filename is fully attacker-computable since the attacker controls the artifact content. This is a plausible but non-trivial social-engineering-adjacent scenario (victim must run the command from a specific attacker-influenced directory), so likelihood is moderate rather than high.

### Recommendation
Before calling `os.Create`, perform an `os.Lstat` on the target path and reject/abort if it is a symlink (or open with a platform-appropriate `O_NOFOLLOW` flag). Additionally, route the output path through `internal/safepaths.Absolute.Join` (as already used elsewhere in the codebase) to enforce confinement, and consider defaulting to `O_EXCL` semantics with an explicit "overwrite" confirmation rather than silently following/truncating whatever exists at that name.

### Proof of Concept
```go
func TestCreateMetadataFileDoesNotFollowSymlink(t *testing.T) {
    tempDir := t.TempDir()
    outsideDir := t.TempDir()
    targetFile := filepath.Join(outsideDir, "victim.txt")
    require.NoError(t, os.WriteFile(targetFile, []byte("original"), 0o644))

    digest := "sha256:deadbeef" // pretend attacker precomputed this to match an artifact they control
    linkName := filepath.Join(tempDir, digest+".jsonl")
    require.NoError(t, os.Symlink(targetFile, linkName))

    store := &LiveStore{outputPath: tempDir}
    _, err := store.createMetadataFile(digest, []*api.Attestation{ /* ... */ })
    require.NoError(t, err)

    content, _ := os.ReadFile(targetFile)
    require.Equal(t, "original", string(content), "symlink target outside outputPath must not be overwritten")
}
```
Expected current (vulnerable) behavior: the assertion fails because `targetFile` gets truncated/overwritten with attestation JSON lines, proving the symlink was followed.

func (s *LiveStore) createJSONLinesFilePath(artifact string) string {
	if runtime.GOOS == "windows" {
		// Colons are special characters in Windows and cannot be used in file names.
		// Replace them with dashes to avoid issues.
		artifact = strings.ReplaceAll(artifact, ":", "-")
	}

	path := fmt.Sprintf("%s.jsonl", artifact)
	if s.outputPath != "" {
		return fmt.Sprintf("%s/%s", s.outputPath, path)
	}
	return path
}

func digestLocalFileArtifact(filename, digestAlg string) (*DigestedArtifact, error) {
	data, err := os.Open(filename)
	if err != nil {
		return nil, fmt.Errorf("failed to open local artifact: %v", err)
	}
	defer data.Close()
	digest, err := digest.CalculateDigestWithAlgorithm(data, digestAlg)
	if err != nil {
		return nil, fmt.Errorf("failed to calculate local artifact digest: %v", err)
	}
	return &DigestedArtifact{
		URL:       fmt.Sprintf("file://%s", filename),
		digest:    digest,
		digestAlg: digestAlg,
	}, nil
