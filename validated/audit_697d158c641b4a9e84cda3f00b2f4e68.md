### Title
Missing Zero-Check for `GasTarget` in `NextMagmaBlockBaseFee` Causes Division-by-Zero Panic Halting Block Production — (File: `params/kip71_config.go`)

---

### Summary

`NextMagmaBlockBaseFee` in `params/kip71_config.go` explicitly guards against `BaseFeeDenominator == 0` but contains no equivalent guard for `GasTarget == 0`. The governance parameter `kip71.gastarget` is registered with `noopFormatChecker`, which accepts any `uint64` value including zero. A governance vote that sets `kip71.gastarget = 0` passes all validation, takes effect at the next epoch boundary, and then causes a Go runtime division-by-zero panic on every block where the parent block consumed any gas. This halts block production on all honest nodes that process the affected block.

---

### Finding Description

**Root cause — missing zero-check for `GasTarget`:**

In `params/kip71_config.go`, `NextMagmaBlockBaseFee` explicitly handles `BaseFeeDenominator == 0`:

```go
// params/kip71_config.go lines 70-76
var baseFeeDenominator *big.Int
if kc.BaseFeeDenominator == 0 {
    // To avoid panic, set the fluctuation range small
    baseFeeDenominator = new(big.Int).SetUint64(64)
} else {
    baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
}
``` [1](#0-0) 

No equivalent guard exists for `GasTarget`. The function then unconditionally divides by `gasTarget` at two points:

```go
// lines 102 and 120
y := x.Div(x, new(big.Int).SetUint64(gasTarget))  // panics if gasTarget == 0
``` [2](#0-1) [3](#0-2) 

The only escape before reaching these divisions is the equality check `parentGasUsed == gasTarget` (line 90). When `gasTarget == 0`, this only saves execution if `parentGasUsed` is also exactly 0. Any block with non-zero gas usage takes the `parentGasUsed > gasTarget` branch and panics.

**Root cause — governance accepts `GasTarget = 0`:**

The `kip71.gastarget` parameter is registered with `noopFormatChecker`, which unconditionally returns `true`:

```go
// kaiax/gov/param.go
Kip71GasTarget: {
    Canonicalizer: uint64Canonicalizer,
    FormatChecker: noopFormatChecker,   // accepts any value, including 0
    DefaultValue:  uint64(30000000),
},
``` [4](#0-3) 

Compare with `Kip71BaseFeeDenominator`, which correctly rejects zero:

```go
Kip71BaseFeeDenominator: {
    FormatChecker: func(cv any) bool {
        v, ok := cv.(uint64)
        return ok && v != 0   // zero explicitly rejected
    },
``` [5](#0-4) 

The inconsistency is the direct analog to the external bug: one parameter (`BaseFeeDenominator`) is protected both at the governance layer and at the computation layer; the other (`GasTarget`) is protected at neither.

**Call sites that trigger the panic:**

`NextMagmaBlockBaseFee` is called on every block in three production paths:

1. Block worker (`work/worker.go` line 382) — halts block proposal.
2. Transaction pool reset (`blockchain/tx_pool.go` line 576) — halts tx pool updates.
3. Block header verification (`params/kip71_config.go` `VerifyMagmaHeader` → `NextMagmaBlockBaseFee`) — causes all honest nodes to reject or panic on the affected block. [6](#0-5) [7](#0-6) 

---

### Impact Explanation

Once `kip71.gastarget = 0` takes effect (at the next epoch boundary after ratification), every block where `parentGasUsed > 0` triggers a Go runtime panic inside `NextMagmaBlockBaseFee`. This crashes the block worker on the proposer node and causes all validating nodes to panic during header verification. The result is a complete halt of block production and consensus on the Kaia network for as long as the parameter remains at zero. This is an invalid state transition / consensus divergence on all honest nodes.

---

### Likelihood Explanation

In `none` governance mode, any single GC member can cast a vote that becomes ratified (last vote in epoch wins). In `single` mode, the governing node must be involved. The `kip71.gastarget` parameter is not in `AlwaysDeprecated` or `PermissionlessDeprecated`, so it remains votable. The vote passes `VerifyVote` because `noopFormatChecker` accepts zero. No other on-chain guard prevents the parameter from reaching the computation layer. [8](#0-7) 

---

### Recommendation

1. Add a non-zero check for `GasTarget` in `NextMagmaBlockBaseFee`, mirroring the existing `BaseFeeDenominator` guard:

```go
gasTarget := kc.GasTarget
if gasTarget == 0 {
    gasTarget = DefaultGasTarget // or return lowerBoundBaseFee as a safe fallback
}
```

2. Change `Kip71GasTarget`'s `FormatChecker` to reject zero, consistent with `Kip71BaseFeeDenominator`:

```go
FormatChecker: func(cv any) bool {
    v, ok := cv.(uint64)
    return ok && v != 0
},
``` [9](#0-8)

parentBaseFee := big.NewInt(25_000_000_000)
parentGasUsed := uint64(21_000) // any non-zero gas usage

// Panics: runtime error: integer divide by zero
// inside x.Div(x, new(big.Int).SetUint64(gasTarget)) at kip71_config.go:102

```

This panic propagates through `work/worker.go` `commitNewWork` and `blockchain/tx_pool.go` `reset`, halting block production on every node that processes a block with non-zero gas after the governance change takes effect. [10](#0-9)

func (kc *KIP71Config) NextMagmaBlockBaseFee(parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) *big.Int {
	// governance parameters
	lowerBoundBaseFee := new(big.Int).SetUint64(kc.LowerBoundBaseFee)
	upperBoundBaseFee := new(big.Int).SetUint64(kc.UpperBoundBaseFee)
	makeEvenByCeil(lowerBoundBaseFee)
	makeEvenByFloor(upperBoundBaseFee)

	// If the parent is the magma disabled block or genesis, then return the lowerBoundBaseFee (default 25ston)
	if parentHeaderNumber.Cmp(new(big.Int).SetUint64(0)) == 0 || parentHeaderBaseFee == nil {
		return makeEvenByFloor(lowerBoundBaseFee)
	}

	var baseFeeDenominator *big.Int
	if kc.BaseFeeDenominator == 0 {
		// To avoid panic, set the fluctuation range small
		baseFeeDenominator = new(big.Int).SetUint64(64)
	} else {
		baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
	}
	gasTarget := kc.GasTarget
	upperGasLimit := kc.MaxBlockGasUsedForBaseFee

	// check the case of upper/lowerBoundBaseFee is updated by governance mechanism
	parentBaseFee := parentHeaderBaseFee
	if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {
		parentBaseFee = upperBoundBaseFee
	} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
		parentBaseFee = lowerBoundBaseFee
	}

	// upper gas limit cut off the impulse of used gas to upper bound
	parentGasUsed := min(parentHeaderGasUsed, upperGasLimit)
	if parentGasUsed == gasTarget {
		return makeEvenByFloor(parentBaseFee)
	} else if parentGasUsed > gasTarget {
		// shortcut. If parentBaseFee is already reached upperbound, do not calculate.
		if parentBaseFee.Cmp(upperBoundBaseFee) == 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		// If the parent block used more gas than its target,
		// the baseFee of the next block should increase.
		// baseFeeDelta = max(1, parentBaseFee * (parentGasUsed - gasTarget) / gasTarget / baseFeeDenominator)
		gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := math.BigMax(x.Div(y, baseFeeDenominator), common.Big1)

		nextBaseFee := x.Add(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(upperBoundBaseFee) > 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	} else {
		// shortcut. If parentBaseFee is already reached lower bound, do not calculate.
		if parentBaseFee.Cmp(lowerBoundBaseFee) == 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		// Otherwise if the parent block used less gas than its target,
		// the baseFee of the next block should decrease.
		// baseFeeDelta = parentBaseFee * (gasTarget - parentGasUsed) / gasTarget / baseFeeDenominator
		gasUsedDelta := new(big.Int).SetUint64(gasTarget - parentGasUsed)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := x.Div(y, baseFeeDenominator)

		nextBaseFee := x.Sub(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(lowerBoundBaseFee) < 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	}
}
