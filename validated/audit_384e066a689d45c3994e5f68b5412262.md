### Title
`gh skill update` trusts attacker-controlled SKILL.md frontmatter metadata instead of the lockfile, allowing wrong-repo authenticated fetch and directory overwrite - (File: `pkg/cmd/skills/update/update.go`)

### Summary
`parseInstalledSkill` in `pkg/cmd/skills/update/update.go` derives the repo host/owner/repo used for updating a skill entirely from the on-disk `SKILL.md` frontmatter (`github-repo` metadata), gated only by `source.ValidateSupportedHost`. The lockfile written by `lockfile.RecordInstall` (`internal/skills/lockfile/lockfile.go`) records the true install source, but it is never read back or cross-checked anywhere in the update flow, so tampering with the frontmatter alone is sufficient to redirect `gh skill update` to a different, attacker-chosen repository on the same host.

### Finding Description
`scanInstalledSkills` → `parseInstalledSkill` (`pkg/cmd/skills/update/update.go:600-639`) parses `SKILL.md` and extracts `s.repoHost`, `s.owner`, `s.repo` solely via `source.ParseMetadataRepo(result.Metadata.Meta)`, validating only that the host is an allowed GitHub host with `source.ValidateSupportedHost`:
```go
repoInfo, ok, repoErr := source.ParseMetadataRepo(result.Metadata.Meta)
...
} else if ok {
    if err := source.ValidateSupportedHost(repoInfo.RepoHost()); err != nil {
        s.metadataErr = err
    } else {
        s.repoHost = repoInfo.RepoHost()
        s.owner = repoInfo.RepoOwner()
        s.repo = repoInfo.RepoName()
    }
}
```
`updateRun` then uses these frontmatter-derived fields directly to resolve the ref and discover skills from that repo (`update.go:266-292`), and `updateSkillInPlace` uses `u.local.repoHost/owner/repo` to build `installer.Options` and call `installer.Install`, which performs an authenticated GitHub API fetch and then atomically swaps the fetched content into the existing skill directory via `swapDirectoryContents` (`update.go:418-508`).

Separately, `lockfile.RecordInstall` (`internal/skills/lockfile/lockfile.go:97-137`) records the true install source (`Source`, `SourceURL`) at install time. However, the lockfile package exposes no read/verification API used by the update path — `RecordInstall` is write-only from the perspective of `install`/`update`, and nothing in `update.go` reads `.skill-lock.json` or compares its `SourceURL` against the frontmatter-derived `owner`/`repo` before fetching. This means the lockfile is not actually used as a trust anchor despite existing specifically to record install provenance.

If an attacker can get the `github-repo` metadata line in an installed `SKILL.md` changed (e.g., via a merged PR into a git-tracked skills directory, or a synced dotfiles repo containing skills), the next `gh skill update` run will silently fetch from and overwrite the skill directory using the attacker's chosen `owner/repo` — with no mismatch detection against the previously recorded lockfile source.

### Impact Explanation
This results in a wrong-repo authenticated fetch: the victim's `gh` (using their authenticated GitHub credentials) is redirected to pull and install content from an attacker-controlled repository under the same host, and that content is written in place over the existing skill directory (`swapDirectoryContents`, `update.go:470-508`). Since skill content is meant to be consumed/interpreted by AI coding agents (Copilot, Claude, etc.), this allows attacker-controlled instructions to replace a previously trusted skill without the user's awareness, matching a "wrong-host/wrong-account request routing" and "verification bypass" impact class.

### Likelihood Explanation
Requires: (1) victim previously installed a skill (lockfile has the true source), and (2) the on-disk `SKILL.md`'s `metadata.github-repo` field is later modified to an attacker-chosen repo (e.g., through a merged pull request touching a git-tracked skills directory, or a compromised/malicious dotfiles sync). This is a plausible supply-chain path reachable without local shell access to the victim's machine, but it does depend on the victim incorporating attacker-modified content into their skill directory before running `gh skill update`, which is a meaningful precondition rather than a fully remote, zero-interaction compromise.

### Recommendation
Before fetching from `s.repoHost/s.owner/s.repo` in `updateRun`, cross-check against the corresponding lockfile entry's `SourceURL` (via a new exported lockfile read/verify function). If the frontmatter-derived repo doesn't match the lockfile's recorded source, either reject the update, or warn and require explicit user confirmation (similar to the existing "no GitHub metadata" prompt flow) before proceeding with a fetch from the new source.

func updateSkillInPlace(opts *UpdateOptions, u pendingUpdate, apiClient *api.Client, gitRoot, homeDir string) error {
	if u.local.dir == "" {
		return fmt.Errorf("cannot update %s: no install location recorded", u.local.name)
	}

	parent := filepath.Dir(u.local.dir)
	if err := os.MkdirAll(parent, 0o755); err != nil {
		return fmt.Errorf("could not ensure parent directory %s: %w", parent, err)
	}

	// Stage as a sibling of the existing skill directory so the swap stays
	// on the same filesystem and every rename is atomic.
	staging, err := os.MkdirTemp(parent, "."+u.skill.Name+".gh-skill-update-")
	if err != nil {
		return fmt.Errorf("could not create staging directory: %w", err)
	}
	defer os.RemoveAll(staging)

	installOpts := &installer.Options{
		Host:    u.local.repoHost,
		Owner:   u.local.owner,
		Repo:    u.local.repo,
		Ref:     u.resolved.Ref,
		SHA:     u.resolved.SHA,
		Skills:  []discovery.Skill{u.skill},
		Dir:     staging,
		GitRoot: gitRoot,
		HomeDir: homeDir,
		Client:  apiClient,
	}
	if _, err := installer.Install(installOpts); err != nil {
		return err
	}

	stagedSkillDir := filepath.Join(staging, u.skill.Name)
	if _, err := os.Stat(stagedSkillDir); err != nil {
		return fmt.Errorf("installer did not produce %s: %w", stagedSkillDir, err)
	}

	if err := os.MkdirAll(u.local.dir, 0o755); err != nil {
		return fmt.Errorf("could not ensure skill directory %s: %w", u.local.dir, err)
	}

	return swapDirectoryContents(u.local.dir, stagedSkillDir)

func swapDirectoryContents(dest, src string) error {
	backup, err := os.MkdirTemp(filepath.Dir(dest), "."+filepath.Base(dest)+".gh-skill-backup-")
	if err != nil {
		return fmt.Errorf("could not create backup directory: %w", err)
	}

	existing, err := os.ReadDir(dest)
	if err != nil {
		_ = os.RemoveAll(backup)
		return fmt.Errorf("could not read skill directory %s: %w", dest, err)
	}
	var movedOut []string
	for _, entry := range existing {
		if err := os.Rename(filepath.Join(dest, entry.Name()), filepath.Join(backup, entry.Name())); err != nil {
			restoreBackup(dest, backup, movedOut, nil)
			return fmt.Errorf("could not move %s aside: %w", entry.Name(), err)
		}
		movedOut = append(movedOut, entry.Name())
	}

	staged, err := os.ReadDir(src)
	if err != nil {
		restoreBackup(dest, backup, movedOut, nil)
		return fmt.Errorf("could not read staged skill directory %s: %w", src, err)
	}
	var movedIn []string
	for _, entry := range staged {
		from := filepath.Join(src, entry.Name())
		to := filepath.Join(dest, entry.Name())
		if err := os.Rename(from, to); err != nil {
			restoreBackup(dest, backup, movedOut, movedIn)
			return fmt.Errorf("could not move %s into place: %w", entry.Name(), err)
		}
		movedIn = append(movedIn, entry.Name())
	}

	_ = os.RemoveAll(backup)
	return nil
}

// parseInstalledSkill parses a SKILL.md file and returns an installedSkill.
func parseInstalledSkill(data []byte, name, dir string, host *registry.AgentHost, scope registry.Scope) (installedSkill, bool) {
	result, err := frontmatter.Parse(string(data))
	if err != nil {
		return installedSkill{
			name:        name,
			dir:         dir,
			host:        host,
			scope:       scope,
			metadataErr: fmt.Errorf("invalid SKILL.md: %w", err),
		}, true
	}

	s := installedSkill{
		name:  name,
		dir:   dir,
		host:  host,
		scope: scope,
	}

	if result.Metadata.Meta != nil {
		repoInfo, ok, repoErr := source.ParseMetadataRepo(result.Metadata.Meta)
		if repoErr != nil {
			s.metadataErr = repoErr
		} else if ok {
			if err := source.ValidateSupportedHost(repoInfo.RepoHost()); err != nil {
				s.metadataErr = err
			} else {
				s.repoHost = repoInfo.RepoHost()
				s.owner = repoInfo.RepoOwner()
				s.repo = repoInfo.RepoName()
			}
		}
		s.treeSHA, _ = result.Metadata.Meta["github-tree-sha"].(string)
		s.pinned, _ = result.Metadata.Meta["github-pinned"].(string)
		s.sourcePath, _ = result.Metadata.Meta["github-path"].(string)
	}

	return s, true
}

// RecordInstall adds or updates a skill entry in the lock file.
// It uses a file-based lock to prevent concurrent read-modify-write races
// when multiple install processes run simultaneously.
func RecordInstall(host, skillName, owner, repo, skillPath, treeSHA, pinnedRef string) error {
	lockPath, err := lockfilePath()
	if err != nil {
		return err
	}
	if err := os.MkdirAll(filepath.Dir(lockPath), 0o755); err != nil {
		return fmt.Errorf("could not create lock directory: %w", err)
	}

	lockedFile, unlock, err := acquireFLock()
	if err != nil {
		return err
	}
	defer unlock()

	f, err := readFrom(lockedFile)
	if err != nil {
		return err
	}

	now := time.Now().UTC().Format(time.RFC3339)

	existing, exists := f.Skills[skillName]
	installedAt := now
	if exists {
		installedAt = existing.InstalledAt
	}

	f.Skills[skillName] = entry{
		Source:          owner + "/" + repo,
		SourceType:      "github",
		SourceURL:       ghinstance.HostPrefix(host) + owner + "/" + repo + ".git",
		SkillPath:       skillPath,
		SkillFolderHash: treeSHA,
		InstalledAt:     installedAt,
		UpdatedAt:       now,
		PinnedRef:       pinnedRef,
	}

	return writeTo(lockedFile, f)
}
