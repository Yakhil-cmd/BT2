The reported issue concerns Solidity's `Token.tokenURI()` returning metadata-like strings for non-minted NFT IDs, deceiving callers into believing a token exists. Investigating the FRAME analog (`pallet-nfts`), the corresponding inspection methods explicitly return `Option<Vec<u8>>` and correctly resolve to `None` when the queried item does not exist, rather than fabricating plausible-looking data:

- `Pallet::attribute()`, `custom_attribute()`, `system_attribute()`, `collection_attribute()` all read from `ItemMetadataOf`/`Attribute` storage maps via `.get(...).map(...)`, which naturally yields `None` for unset/non-existent items [1](#0-0) .
- `owner()` likewise returns `None` if the item was never minted [2](#0-1) .
- The trait documentation for `nonfungibles_v2::Inspect` explicitly states these return `None` when the item doesn't exist — this is the designed and documented contract, not an oversight [3](#0-2) .
- The `uniques` pallet's asset-ops `Inspect` implementations go further, returning explicit `Error::UnknownItem`/`Error::NoMetadata` dispatch errors rather than any fabricated data [4](#0-3) .
- The runtime-exposed `NftsApi` RPC methods (`owner`, `attribute`, `system_attribute`, `collection_attribute`) simply forward to these `Inspect` implementations, so callers receive `None`/absence signals for non-existent items across all runtimes wiring this API [5](#0-4) .

Unlike Solidity's `tokenURI()`, which returns a string that can be indistinguishable from a valid token's metadata URI (creating a spoofing/deception risk for off-chain consumers), the Rust/FRAME equivalents use `Option`/`Result` types that unambiguously signal non-existence to any caller. There is no forgeable "looks legitimate" data path analogous to the Solidity issue — the root cause (absence of an existence check leading to fabricated-looking output) does not reproduce in this codebase's design.

	fn attribute(
		collection: &Self::CollectionId,
		item: &Self::ItemId,
		key: &[u8],
	) -> Option<Vec<u8>> {
		if key.is_empty() {
			// We make the empty key map to the item metadata value.
			ItemMetadataOf::<T, I>::get(collection, item).map(|m| m.data.into())
		} else {
			let namespace = AttributeNamespace::CollectionOwner;
			let key = BoundedSlice::<_, _>::try_from(key).ok()?;
			Attribute::<T, I>::get((collection, Some(item), namespace, key)).map(|a| a.0.into())
		}
	}
