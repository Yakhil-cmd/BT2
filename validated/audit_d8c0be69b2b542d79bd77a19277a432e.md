### Title
Deregistered Bridge Operator's Vote Persists and Can Execute Value Transfers - (File: `contracts/service_chain/bridge/BridgeOperator.sol`)

---

### Summary

`BridgeOperator.deregisterOperator` removes an operator from the `operators` mapping but does **not** clear that operator's outstanding votes from the `votes` storage. A deregistered operator's prior vote remains counted toward the threshold, so a single subsequent vote from any still-registered operator can reach the threshold and execute a bridge value transfer — transferring KAIA or ERC20/ERC721 tokens — using authority that was explicitly revoked.

---

### Finding Description

`_voteCommon` records votes keyed by `(voteType, nonce)` in persistent storage:

```solidity
VotesData storage vote = votes[uint8(_voteType)][_nonce];
vote.voted[msg.sender] = _voteKey;
vote.voteCounts[_voteKey]++;
if (vote.voteCounts[_voteKey] >= operatorThresholds[uint8(_voteType)]) {
    return true;
}
``` [1](#0-0) 

`deregisterOperator` only deletes the operator from the `operators` mapping and `operatorList` array. It does **not** touch `votes[*][*].voted[operator]` or `votes[*][*].voteCounts[*]`:

```solidity
function deregisterOperator(address _operator) external onlyOwner {
    require(operators[_operator]);
    delete operators[_operator];
    // operatorList removal only — votes storage untouched
    ...
}
``` [2](#0-1) 

The code itself documents the resulting invariant violation:

> "Note that outstanding votes by the deregistered operator are not revoked. This enables a subtle counterintuitive scenario… the request was executed with A's vote after A is deregistered." [3](#0-2) 

This is the direct Kaia analog of `LlamaPolicy.hasRole` not checking `balanceOf`: the "role" (operator status) is revoked, but the vote — the operative effect of that role — persists in storage and continues to count toward threshold.

---

### Impact Explanation

When the threshold is met using a deregistered operator's stale vote, `_voteValueTransfer` sets `closedValueTransferVotes[_requestNonce] = true` and returns `true`, causing the caller (`handleKLAYTransfer`, `handleERC20Transfer`, `handleERC721Transfer`) to execute the asset transfer: [4](#0-3) 

The result is a bridge value transfer of KAIA or bridged ERC20/ERC721 tokens executed with the effective participation of an operator whose authority was explicitly revoked. This satisfies the allowed impact gate: **unauthorized transfer of KAIA or bridged assets**.

---

### Likelihood Explanation

The scenario is realistic in any operator rotation or incident-response event:

1. Operator A (legitimate at the time) calls `handleKLAYTransfer` for nonce N → vote stored.
2. Owner calls `deregisterOperator(A)` to revoke A's authority (e.g., key compromise).
3. Operator B calls `handleKLAYTransfer` for nonce N → threshold reached → KAIA transferred.

The owner's intent — that A's authority is fully revoked — is not achieved. The window is bounded only by how quickly another operator votes on the same nonce, which in an active bridge is immediate.

---

### Recommendation

In `deregisterOperator`, iterate over all open nonces and decrement (or zero) the deregistered operator's vote counts, or add a check inside `_voteCommon` that verifies `operators[msg.sender]` is still `true` at the time the threshold comparison is made. The simplest targeted fix mirrors the LlamaPolicy resolution — add an active-operator guard at the point where the vote count is compared to the threshold:

```solidity
// In _voteCommon, before the threshold check:
if (!operators[msg.sender]) {
    return false;
}
```

Alternatively, clear `vote.voted[operator]` and decrement `vote.voteCounts` for all open nonces during `deregisterOperator`.

---

### Proof of Concept

Setup: threshold = 2, operators = {Owner, A, B}.

1. `A.handleKLAYTransfer(txHash, from, to, 1 ether, nonce=5, blk, "")` → `_voteCommon` stores `votes[VT][5].voted[A] = key`, `votes[VT][5].voteCounts[key] = 1`. Returns `false` (count 1 < threshold 2).
2. `Owner.deregisterOperator(A)` → `operators[A] = false`. `votes[VT][5]` is **unchanged**.
3. `B.handleKLAYTransfer(txHash, from, to, 1 ether, nonce=5, blk, "")` → `_voteCommon` increments `votes[VT][5].voteCounts[key]` to 2 ≥ threshold → returns `true` → `closedValueTransferVotes[5] = true` → `_to.call.value(1 ether)("")` executes.

The transfer is executed using A's vote despite A being deregistered, violating the owner's intent to revoke A's authority over bridge transfers. [5](#0-4)

    function _voteCommon(VoteType _voteType, uint64 _nonce, bytes32 _voteKey)
        private
        returns(bool)
    {
        VotesData storage vote = votes[uint8(_voteType)][_nonce];

        // If the same voter voted again, revoke previous vote.
        bytes32 oldVoteKeyOfVoter = vote.voted[msg.sender];
        if (oldVoteKeyOfVoter == bytes32(0)) {
            vote.voters.push(msg.sender);
        } else {
            vote.voteCounts[oldVoteKeyOfVoter]--;
        }

        // Either the current voter has voted before or not, update the vote data.
        vote.voted[msg.sender] = _voteKey;

        if (vote.voteCounts[_voteKey] == 0) {
            vote.voteKeys.push(_voteKey);
        }
        vote.voteCounts[_voteKey]++;

        if (vote.voteCounts[_voteKey] >= operatorThresholds[uint8(_voteType)]) {
            return true;
        }
        return false;
    }

    // _voteValueTransfer votes value transfer transaction with the operator.
    function _voteValueTransfer(uint64 _requestNonce)
        internal
        returns(bool)
    {
        require(!closedValueTransferVotes[_requestNonce], "closed vote");

        bytes32 voteKey = keccak256(msg.data);
        if (_voteCommon(VoteType.ValueTransfer, _requestNonce, voteKey)) {
            closedValueTransferVotes[_requestNonce] = true;
            return true;
        }

        return false;
    }

    function deregisterOperator(address _operator)
    external
    onlyOwner
    {
        require(operators[_operator]);
        delete operators[_operator];

        for (uint i = 0; i < operatorList.length; i++) {
           if (operatorList[i] == _operator) {
               operatorList[i] = operatorList[operatorList.length-1];
               operatorList.length--;
               break;
           }
        }
        emit OperatorDeregistered(_operator);
    }
