### Title
Unbounded response read and decompression when fetching attacker-supplied attestation bundle URLs enables memory-exhaustion DoS of the `gh` process - ([File: pkg/cmd/attestation/api/client.go])

### Summary
`gh attestation verify` fetches attestation metadata from the GitHub API and then, for each attestation, dereferences a `bundle_url` field taken directly from that API response to retrieve the actual Sigstore bundle from an arbitrary external host via `c.externalHttpClient.Get(url.String())`. The response body is read in full with `io.ReadAll` and then decompressed with `snappy.Decode` with no size limits anywhere in the chain, so a malicious/attacker-controlled endpoint referenced by `bundle_url` can force the `gh` client to allocate unbounded memory and crash — the same “evil endpoint forces OOM crash” bug class as the Nethermind P2P report, just at the HTTP/attestation layer instead of the P2P layer.

### Finding Description
`getAttestations` retrieves `AttestationsResponse` objects (including a `BundleURL` field) from the GitHub REST attestations endpoint [1](#0-0) . `fetchBundleFromAttestations` then calls `c.getBundle(safeurl.NewImmutableSafeURL(a.BundleURL))` for each attestation whenever `BundleURL` is non-empty [2](#0-1) .

`getBundle` performs a plain `GET` to that URL using `c.externalHttpClient`, an interface that is only `Get(url string) (*http.Response, error)` with no transport-level body size cap configured anywhere in this file [3](#0-2) [4](#0-3) . The full response body is buffered into memory with `io.ReadAll(resp.Body)` (no `io.LimitReader`/`http.MaxBytesReader`), and the result is passed to `snappy.Decode(out, body)` with `out` pre-allocated as `nil`, meaning the decompressed buffer size is dictated entirely by the length prefix embedded in the attacker-supplied Snappy stream [5](#0-4) . Neither the compressed read nor the decompression step enforces any upper bound, so a small attacker response can request allocation of an arbitrarily large decompressed buffer, or the attacker can simply stream a very large HTTP response body directly.

Because `BundleURL` is a value taken verbatim from the API response object, it is effectively attacker-influenced content: any entity able to attach an attestation for a digest that the victim later verifies (e.g., anyone with write access to a repository/artifact the victim runs `gh attestation verify` against, or a compromised/malicious attestation registered in the flow) can set `bundle_url` to point at a server they control. When the victim runs `gh attestation verify`, `gh` will fetch and fully buffer/decompress whatever that attacker-controlled host serves.

### Impact Explanation
This is a client-side denial-of-service: an attacker who can supply/influence an attestation record (or otherwise redirect `bundle_url`) can crash any user’s `gh` process performing `gh attestation verify` by exhausting available memory via an oversized or maliciously-crafted (decompression-bomb-style) HTTP response, mirroring the Nethermind analog of a remote peer causing the victim client to OOM/crash through unbounded resource consumption from untrusted network data. Impact is limited to the invoking process (no code execution or credential exposure demonstrated), consistent with a Medium-severity availability bug rather than a critical one.

### Likelihood Explanation
Reachable through the normal, unprivileged `gh attestation verify` workflow — no special permissions on the victim’s machine are required, only that the victim verifies an artifact/digest associated with an attacker-influenced attestation whose `bundle_url` points at an attacker-controlled host, or an attacker positioned to serve/return arbitrary content at that URL (blob storage response tampering is explicitly anticipated by the surrounding error-handling code, e.g. the 5xx-status retry check at lines 248-250). No MITM, no local access, and no leaked credentials are needed.

### Recommendation
- Wrap `resp.Body` with `io.LimitReader` (or use `http.MaxBytesReader`) before calling `io.ReadAll` in `getBundle`, bounding the compressed payload to a sane maximum (e.g., a few MB, consistent with expected Sigstore bundle sizes).
- Bound the Snappy decompression output as well — pre-size or cap `out` and reject streams whose declared decompressed length exceeds a fixed ceiling, rather than passing `nil` to `snappy.Decode`.
- Consider validating/pinning the host of `bundle_url` (e.g., restrict to expected GitHub-controlled blob-storage domains) rather than trusting an arbitrary attacker-influenced URL from the API payload.

### Proof of Concept
1. Attacker publishes/attaches an attestation for an artifact digest such that the GitHub attestations API response for that digest includes `"bundle_url": "https://attacker.example/bundle"` (per the JSON parsing in `AttestationsResponse`/`Attestation.BundleURL`, as also exercised in `TestGetAttestationsRetriesRESTWithNextError` where a `bundle_url` field is set directly from a mocked API response [6](#0-5) ).
2. Victim runs `gh attestation verify <artifact> --owner <owner>` (or `--repo`), which reaches `getByDigest` → `getAttestations` → `fetchBundleFromAttestations` → `getBundle` [7](#0-6) .
3. `attacker.example/bundle` serves either (a) a very large raw byte stream, or (b) a small Snappy-compressed stream whose block/length header claims an enormous decompressed size.
4. `getBundle`’s unbounded `io.ReadAll(resp.Body)` and/or `snappy.Decode(out, body)` call attempts to allocate memory proportional to the attacker-chosen size, exhausting available memory and crashing the `gh` process [8](#0-7) .

func (c *LiveClient) getAttestations(params FetchParams) ([]*Attestation, error) {
	u, err := c.buildRequestURL(params)
	if err != nil {
		return nil, err
	}

	var attestations []*Attestation
	var resp AttestationsResponse
	bo := backoff.NewConstantBackOff(getAttestationRetryInterval)

	var pageURL safeurl.SafeURL = u

	// if no attestation or less than limit, then keep fetching
	for pageURL.String() != "" && len(attestations) < params.Limit {
		err := backoff.Retry(func() error {
			newURL, restErr := c.githubAPI.RESTWithNext(c.host, http.MethodGet, pageURL.String(), nil, &resp)
			if restErr != nil {
				if shouldRetry(restErr) {
					return restErr
				}
				return backoff.Permanent(restErr)
			}

			pageURL = safeurl.NewImmutableSafeURL(newURL)

			// filter by the initiator type
			if params.Initiator != "" {
				filtered := make([]*Attestation, 0, len(resp.Attestations))
				for _, att := range resp.Attestations {
					if att.Initiator == params.Initiator {
						filtered = append(filtered, att)
					}
				}
				resp.Attestations = filtered
			}
			attestations = append(attestations, resp.Attestations...)

			return nil
		}, backoff.WithMaxRetries(bo, 3))

		// bail if RESTWithNext errored out
		if err != nil {
			return nil, err
		}
	}

	if len(attestations) == 0 {
		return nil, ErrNoAttestationsFound
	}

	if len(attestations) > params.Limit {
		return attestations[:params.Limit], nil
	}

	return attestations, nil
}

func (c *LiveClient) fetchBundleFromAttestations(attestations []*Attestation) ([]*Attestation, error) {
	fetched := make([]*Attestation, len(attestations))
	g := errgroup.Group{}
	for i, a := range attestations {
		g.Go(func() error {
			if a.Bundle == nil && a.BundleURL == "" {
				return fmt.Errorf("attestation has no bundle or bundle URL")
			}

			// for now, we fall back to the bundle field if the bundle URL is empty
			if a.BundleURL == "" {
				c.logger.VerbosePrintf("Bundle URL is empty. Falling back to bundle field\n\n")
				fetched[i] = &Attestation{
					Bundle: a.Bundle,
				}
				return nil
			}

			// otherwise fetch the bundle with the provided URL
			b, err := c.getBundle(safeurl.NewImmutableSafeURL(a.BundleURL))
			if err != nil {
				return fmt.Errorf("failed to fetch bundle with URL: %w", err)
			}
			fetched[i] = &Attestation{
				Bundle: b,
			}

			return nil
		})
	}

	if err := g.Wait(); err != nil {
		return nil, err
	}

	return fetched, nil
}

	c.logger.VerbosePrintf("Fetching attestation bundle with bundle URL\n\n")

	var sgBundle *bundle.Bundle
	bo := backoff.NewConstantBackOff(getAttestationRetryInterval)
	err := backoff.Retry(func() error {
		resp, err := c.externalHttpClient.Get(url.String())
		if err != nil {
			return fmt.Errorf("request to fetch bundle from URL failed: %w", err)
		}

		if resp.StatusCode >= 500 && resp.StatusCode <= 599 {
			return fmt.Errorf("attestation bundle with URL %s returned status code %d", url.String(), resp.StatusCode)
