The reported issue is specific to a yield vault (VotiumStrategy) that locks deposits into vote-locked CVX for a mandatory 16-week period and later allows withdrawal via a token-expiration queue — a depositor can sandwich a reward-claiming event and exit early by exploiting slack in that queue.

`raydium-cp-swap` is a constant-product AMM with no analogous lock-up or reward-compounding mechanism. Deposits and withdrawals of LP tokens are settled atomically within a single instruction via `deposit` and `withdraw`, using `CurveCalculator::lp_tokens_to_trading_tokens` against the current vault balances net of accumulated fees [1](#0-0) [2](#0-1) . There is no time-locked position, no vote-escrow analog, and no withdrawal queue — LP shares can be minted and redeemed in the same transaction.

Protocol, fund, and creator fees accrued from swaps are tracked separately in `PoolState` (`protocol_fees_token_0/1`, `fund_fees_token_0/1`, `creator_fees_token_0/1`) and excluded from the LP-token pricing calculation via `vault_amount_without_fee`, so they don't get "deposited back" into LP value in a way a user could specifically time [3](#0-2) . Those fees are collected separately through dedicated permissioned/permissionless instructions and don't affect `lp_supply` or trigger any exit eligibility window [4](#0-3) .

The only fee component that does flow into the pool's tradable balance (and thus LP value) is the LP portion of the swap trade fee, which is a standard, continuous part of constant-product AMM design — not a lockup-bypass or reward-sandwiching vulnerability, and it doesn't cause insolvency, unbacked LP minting, or fund freezing. There is no reachable path here matching the reported bug class (bypassing a mandatory commitment/lock period via a withdrawal queue) that produces a concrete theft or freezing impact.

    pub fn vault_amount_without_fee(&self, vault_0: u64, vault_1: u64) -> Result<(u64, u64)> {
        let fees_token_0 = self
            .protocol_fees_token_0
            .checked_add(self.fund_fees_token_0)
            .ok_or(ErrorCode::MathOverflow)?
            .checked_add(self.creator_fees_token_0)
            .ok_or(ErrorCode::MathOverflow)?;
        let fees_token_1 = self
            .protocol_fees_token_1
            .checked_add(self.fund_fees_token_1)
            .ok_or(ErrorCode::MathOverflow)?
            .checked_add(self.creator_fees_token_1)
            .ok_or(ErrorCode::MathOverflow)?;
        Ok((
            vault_0
                .checked_sub(fees_token_0)
                .ok_or(ErrorCode::InsufficientVault)?,
            vault_1
                .checked_sub(fees_token_1)
                .ok_or(ErrorCode::InsufficientVault)?,
        ))
    }

pub fn collect_creator_fee(ctx: Context<CollectCreatorFee>) -> Result<()> {
    let mut pool_state = ctx.accounts.pool_state.load_mut()?;
    let creator_fees_token_0 = pool_state.creator_fees_token_0;
    let creator_fees_token_1 = pool_state.creator_fees_token_1;
    if creator_fees_token_0 == 0 && creator_fees_token_1 == 0 {
        return err!(ErrorCode::NoFeeCollect);
    }

    let signer_seeds: &[&[u8]] = &[crate::AUTH_SEED.as_bytes(), &[ctx.bumps.authority]];

    transfer_from_pool_vault_to_user(
        ctx.accounts.authority.to_account_info(),
        ctx.accounts.token_0_vault.to_account_info(),
        ctx.accounts.creator_token_0.to_account_info(),
        ctx.accounts.vault_0_mint.to_account_info(),
        ctx.accounts.token_0_program.to_account_info(),
        creator_fees_token_0,
        ctx.accounts.vault_0_mint.decimals,
        &[signer_seeds],
    )?;

    transfer_from_pool_vault_to_user(
        ctx.accounts.authority.to_account_info(),
        ctx.accounts.token_1_vault.to_account_info(),
        ctx.accounts.creator_token_1.to_account_info(),
        ctx.accounts.vault_1_mint.to_account_info(),
        ctx.accounts.token_1_program.to_account_info(),
        creator_fees_token_1,
        ctx.accounts.vault_1_mint.decimals,
        &[signer_seeds],
    )?;

    pool_state.creator_fees_token_0 = 0;
    pool_state.creator_fees_token_1 = 0;
    pool_state.recent_epoch = Clock::get()?.epoch;

    Ok(())
