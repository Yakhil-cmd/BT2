### Title
Unauthenticated Bridge P2P Peer Can Inject Arbitrary JSON-RPC Calls via `ServiceChainCall` Message — (`node/sc/main_bridge_handler.go`)

---

### Summary

Any peer that can reach the `MainBridge` P2P port (default 50505) can complete the bridge handshake (which only checks `NetworkId` and `ProtocolVersion`), send a `ServiceChainCall` message containing an arbitrary JSON-RPC payload, and have it executed by the bridge's internal RPC server with no further authentication. Because the bridge registers the full public `kaia`/`klay` API surface — including `kaia_sendTransaction` — and the bridge operator account must be unlocked for normal bridge operation, an attacker can drain the bridge operator's KAIA balance or invoke bridge contracts without any authority.

---

### Finding Description

**Step 1 — Handshake is trivially satisfiable.**

`baseBridgePeer.readStatus` only validates `NetworkId` and `ProtocolVersion`: [1](#0-0) 

There is no genesis-block check, no chain-ID check, and no cryptographic proof of identity. Any peer that knows the public network ID and protocol version can pass the handshake.

**Step 2 — Bridge port is publicly reachable.**

`MainBridge.Start` creates a `bridgeServer` that listens on `MainBridgePort` (default `:50505`). `NoDiscovery = true` and `NoDial = true` are set, but the server still accepts inbound TCP connections: [2](#0-1) 

**Step 3 — `ServiceChainCall` message is forwarded verbatim to the RPC server.**

`handleCallMsg` decodes the raw bytes from the P2P message and writes them directly to `rpcConn` with zero validation: [3](#0-2) 

**Step 4 — `rpcConn` is one end of a `net.Pipe()` whose other end is served by a real `rpc.Server`.** [4](#0-3) 

**Step 5 — The RPC server has the full public `kaia`/`klay` API surface registered.**

`SetComponents` registers every `Public` API with namespace `klay` or `kaia` — including `KaiaTransactionAPI` which exposes `kaia_sendTransaction`, `kaia_sendRawTransaction`, etc.: [5](#0-4) 

**Step 6 — `kaia_sendTransaction` signs and submits a transaction using an unlocked account.**

The bridge operator account must be unlocked for the bridge to function. An attacker can therefore call `kaia_sendTransaction` with `from` set to the bridge operator address: [6](#0-5) 

---

### Impact Explanation

An attacker who can reach port 50505 can:

1. Transfer KAIA from the bridge operator account to an arbitrary address via `kaia_sendTransaction`.
2. Call bridge contracts (e.g., `requestValueTransfer`, `setOperator`) from the bridge operator account, redirecting bridged ERC-20/ERC-721 assets or changing bridge governance.
3. Submit pre-signed transactions via `kaia_sendRawTransaction` to interact with any on-chain contract.

This constitutes **unauthorized transfer of KAIA and bridged assets** from system-managed bridge operator accounts.

---

### Likelihood Explanation

- The bridge port is a standard TCP listener with no IP allowlist enforced by the code.
- The handshake requires only public, observable values (`NetworkId`, `ProtocolVersion`).
- Bridge operator accounts are routinely unlocked in production deployments for automated value-transfer signing.
- No exploit primitives beyond a TCP connection and knowledge of the network ID are required.

---

### Recommendation

1. **Authenticate `ServiceChainCall` senders.** Verify that the sending peer's derived address (`crypto.PubkeyToAddress`) matches a configured allowlist of known sub-bridge node keys before forwarding any RPC payload.
2. **Restrict the internal RPC server's API surface.** Only register the minimal read-only methods actually needed by the sub-bridge (e.g., `kaia_getTransactionReceipt`, `kaia_getBlockByNumber`). Remove `kaia_sendTransaction`, `kaia_sendRawTransaction`, and all write-capable methods from `mb.rpcServer`.
3. **Validate the JSON-RPC method name** before writing to `rpcConn`, rejecting any method not on an explicit allowlist.
4. **Firewall the bridge port** at the network level to accept connections only from known sub-bridge IP addresses.

---

### Proof of Concept

```go
// 1. Dial the MainBridge port (default :50505) using the SC protocol.
// 2. Complete the handshake: send StatusMsg with the correct NetworkId and ProtocolVersion.
// 3. Send a ServiceChainCall message whose payload is:
payload := []byte(`{"jsonrpc":"2.0","method":"kaia_sendTransaction","params":[{` +
    `"from":"<bridge_operator_address>",` +
    `"to":"<attacker_address>",` +
    `"value":"0xDE0B6B3A7640000"` + // 1 KAIA
    `}],"id":1}`)
// RLP-encode payload as []byte and send with msg.Code = ServiceChainCall.
// The MainBridge writes it verbatim to rpcConn; the RPC server signs and
// submits the transaction using the unlocked bridge operator key.
```

The `handleCallMsg` path (`HandleSubMsg` → `handleCallMsg` → `rpcConn.Write`) executes the injected call with no authentication check, and the response is forwarded back to the attacker peer via `SendRPCResponseData`. [7](#0-6) [8](#0-7)

func (p *baseBridgePeer) readStatus(network uint64, status *statusData) error {
	msg, err := p.rw.ReadMsg()
	if err != nil {
		return err
	}
	if msg.Code != StatusMsg {
		return errResp(ErrNoStatusMsg, "first msg has code %x (!= %x)", msg.Code, StatusMsg)
	}
	if msg.Size > ProtocolMaxMsgSize {
		return errResp(ErrMsgTooLarge, "%v > %v", msg.Size, ProtocolMaxMsgSize)
	}
	// Decode the handshake and make sure everything matches
	if err := msg.Decode(&status); err != nil {
		return errResp(ErrDecode, "msg %v: %v", msg, err)
	}
	if status.NetworkId != network {
		return errResp(ErrNetworkIdMismatch, "%d (!= %d)", status.NetworkId, network)
	}
	if int(status.ProtocolVersion) != p.version {
		return errResp(ErrProtocolVersionMismatch, "%d (!= %d)", status.ProtocolVersion, p.version)
	}
	return nil
}

func (mb *MainBridge) Start(srvr p2p.Server) error {
	serverConfig := p2p.Config{}
	serverConfig.PrivateKey = mb.ctx.NodeKey()
	serverConfig.Name = mb.ctx.NodeType().String()
	serverConfig.Logger = logger
	serverConfig.ListenAddr = mb.config.MainBridgePort
	serverConfig.MaxPhysicalConnections = mb.maxPeers
	serverConfig.NoDiscovery = true
	serverConfig.EnableMultiChannelServer = false
	serverConfig.NoDial = true

	scprotocols := make([]p2p.Protocol, 0, len(mb.SCProtocol().Versions))
	for i, version := range mb.SCProtocol().Versions {
		// Compatible; initialise the sub-protocol
		scprotocols = append(scprotocols, p2p.Protocol{
			Name:    mb.SCProtocol().Name,
			Version: version,
			Length:  mb.SCProtocol().Lengths[i],
			Run: func(p *p2p.Peer, rw p2p.MsgReadWriter) error {
				peer := mb.newPeer(int(version), p, rw)
				pubKey, _ := p.ID().Pubkey()
				addr := crypto.PubkeyToAddress(*pubKey)
				peer.SetAddr(addr)
				select {
				case mb.newPeerCh <- peer:
					mb.wg.Add(1)
					defer mb.wg.Done()
					return mb.handle(peer)
				case <-mb.quitSync:
					return p2p.DiscQuitting
				}
			},
			NodeInfo: func() interface{} {
				return mb.NodeInfo()
			},
			PeerInfo: func(id discover.NodeID) interface{} {
				if p := mb.peers.Peer(fmt.Sprintf("%x", id[:8])); p != nil {
					return p.Info()
				}
				return nil
			},
		})
	}
	mb.bridgeServer = p2p.NewServer(serverConfig)
	mb.bridgeServer.AddProtocols(scprotocols)

	if err := mb.bridgeServer.Start(); err != nil {
		return errors.New("fail to bridgeserver start")
	}

func (mbh *MainBridgeHandler) HandleSubMsg(p BridgePeer, msg p2p.Msg) error {
	logger.Trace("mainbridge handle sub message", "msg.Code", msg.Code)

	// Handle the message depending on its contents
	switch msg.Code {
	case ServiceChainCall:
		if err := mbh.handleCallMsg(p, msg); err != nil {
			return err
		}
		return nil
	case StatusMsg:
		return nil
	case ServiceChainTxsMsg:
		logger.Trace("received ServiceChainTxsMsg")
		// TODO-Kaia how to check acceptTxs
		// Transactions arrived, make sure we have a valid and fresh chain to handle them
		//if atomic.LoadUint32(&pm.acceptTxs) == 0 {
		//	break
		//}
		if err := mbh.handleServiceChainTxDataMsg(p, msg); err != nil {
			return err
		}
	case ServiceChainParentChainInfoRequestMsg:
		logger.Debug("received ServiceChainParentChainInfoRequestMsg")
		if err := mbh.handleServiceChainParentChainInfoRequestMsg(p, msg); err != nil {
			return err
		}
	case ServiceChainReceiptRequestMsg:
		logger.Debug("received ServiceChainReceiptRequestMsg")
		if err := mbh.handleServiceChainReceiptRequestMsg(p, msg); err != nil {
			return err
		}
	default:
		return errResp(ErrInvalidMsgCode, "%v", msg.Code)
	}
	return nil
}

func (mbh *MainBridgeHandler) handleCallMsg(p BridgePeer, msg p2p.Msg) error {
	logger.Trace("mainbridge writes the rpc call message to rpc server", "msg.Size", msg.Size, "msg", msg)
	data := make([]byte, msg.Size)
	err := msg.Decode(&data)
	if err != nil {
		logger.Error("error in mainbridge message handler", "err", err)
		return err
	}

	// Write to RPC server pipe
	_, err = mbh.mainbridge.rpcConn.Write(data)
	if err != nil {
		logger.Error("failed to write to the rpc server pipe", "err", err)
		return err
	}
	return nil
}
