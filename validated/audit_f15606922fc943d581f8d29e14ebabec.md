The reported issue is specific to Angle's `SavingsVest.sol` time-based yield vesting mechanism, where `accrue()` conditionally skips updating `vestingProfit`/`lastUpdate` state based on a collateral-ratio threshold, causing stale vesting math when `vestingPeriod` or `protocolSafetyFee` are changed mid-vest.

The raydium-cp-swap program has no equivalent vesting/accrual state. Its `update_amm_config` instruction directly mutates `AmmConfig` fields (`trade_fee_rate`, `protocol_fee_rate`, `fund_fee_rate`, `creator_fee_rate`) with no time-weighted or conditionally-updated intermediate state analogous to `vestingProfit`/`lastUpdate`. [1](#0-0) 

Fee rates in `AmmConfig` are applied deterministically at the moment of each swap via the constant-product curve/fee split logic, not accrued over time or vested across a period; already-collected protocol/fund fees are fixed the instant they're computed during a swap, so changing config params afterward cannot retroactively misattribute past yield the way a stale vesting checkpoint would. [2](#0-1) 

Since there is no reachable analog of a conditionally-skipped state update prior to a parameter change affecting a time-vested yield calculation within the in-scope surface (initialize, deposit, withdraw, swap_base_input/output, collect_creator_fee, AmmConfig/PoolState handling, curve/fee split, token CPIs), this bug class does not map to a valid Medium/High/Critical finding here.

pub fn update_amm_config(ctx: Context<UpdateAmmConfig>, param: u8, value: u64) -> Result<()> {
    let amm_config = &mut ctx.accounts.amm_config;
    let match_param = Some(param);
    match match_param {
        Some(0) => update_trade_fee_rate(amm_config, value),
        Some(1) => update_protocol_fee_rate(amm_config, value),
        Some(2) => update_fund_fee_rate(amm_config, value),
        Some(3) => {
            let new_procotol_owner = *ctx.remaining_accounts.iter().next().unwrap().key;
            set_new_protocol_owner(amm_config, new_procotol_owner)?;
        }
        Some(4) => {
            let new_fund_owner = *ctx.remaining_accounts.iter().next().unwrap().key;
            set_new_fund_owner(amm_config, new_fund_owner)?;
        }
        Some(5) => amm_config.create_pool_fee = value,
        Some(6) => amm_config.disable_create_pool = if value == 0 { false } else { true },
        Some(7) => update_creator_fee_rate(amm_config, value),
        _ => return err!(ErrorCode::InvalidInput),
    }

    Ok(())
}
