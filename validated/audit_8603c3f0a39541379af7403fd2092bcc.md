### Title
Unbounded `kip71.gastarget` Governance Parameter Allows Division-by-Zero Panic Halting All Nodes — (File: `kaiax/gov/param.go`, `params/kip71_config.go`)

---

### Summary

The `kip71.gastarget` governance parameter uses `noopFormatChecker` (always returns `true`), accepting any `uint64` value including `0`. When a governing node votes to set `kip71.gastarget = 0` and any subsequent block has non-zero gas usage, `NextMagmaBlockBaseFee` performs an integer division by zero via `big.Int.Div`, causing a panic that halts every node on the network.

---

### Finding Description

**Root cause — missing lower-bound in `FormatChecker`:**

`Kip71GasTarget` is registered with `noopFormatChecker`, which unconditionally returns `true`: [1](#0-0) 

In contrast, the structurally identical `Kip71BaseFeeDenominator` parameter explicitly rejects zero: [2](#0-1) 

The `checkConsistency` function in header governance also performs no additional check for `Kip71GasTarget`, placing it in the "return nil" catch-all: [3](#0-2) 

So a vote of `kip71.gastarget = 0` passes every validation layer (`uint64Canonicalizer`, `noopFormatChecker`, `checkConsistency`) and is committed to chain state.

**Execution path — division by zero in `NextMagmaBlockBaseFee`:**

After the vote takes effect, every block's base-fee computation calls `NextMagmaBlockBaseFee`. The function has a runtime guard for `BaseFeeDenominator == 0` but **no guard for `GasTarget == 0`**: [4](#0-3) 

When `gasTarget = 0` and `parentGasUsed > 0`:

1. Line 90: `parentGasUsed == gasTarget` → `false` (no early return).
2. Line 92: `parentGasUsed > gasTarget` → `true` (enters the increase branch).
3. Line 100: `gasUsedDelta = parentGasUsed - 0 = parentGasUsed`.
4. Line 101: `x = parentBaseFee * gasUsedDelta`.
5. **Line 102: `y = x.Div(x, new(big.Int).SetUint64(0))` → `big.Int.Div` panics on zero divisor.**

This panic occurs inside `VerifyMagmaHeader` (called during block import) and inside the block-production path, halting every honest node simultaneously.

---

### Impact Explanation

Every node that attempts to import or produce a block after the `gasTarget = 0` governance change takes effect will panic. Because the panic is deterministic and triggered by the canonical chain state, **all nodes halt in unison**, constituting a complete consensus divergence / chain halt. No KAIA transfers, staking rewards, or bridge settlements can proceed. The corrupted governance parameter persists in chain state and cannot be overridden without a coordinated hard-fork or node patch.

---

### Likelihood Explanation

In `single` governance mode the governing node is a single address. A misconfiguration (e.g., intending to set `gastarget` to `0` as a "disable" sentinel, or a fat-finger error) or a compromised governing key is sufficient to trigger the halt. The governance vote requires no collusion and passes all existing on-chain validation.

---

### Recommendation

Add a non-zero lower-bound check to `Kip71GasTarget`'s `FormatChecker`, mirroring the existing check for `Kip71BaseFeeDenominator`:

```go
Kip71GasTarget: {
    Canonicalizer: uint64Canonicalizer,
    FormatChecker: func(cv any) bool {
        v, ok := cv.(uint64)
        return ok && v > 0   // gasTarget must be non-zero (used as divisor)
    },
    ...
},
```

Additionally, add a defensive runtime guard in `NextMagmaBlockBaseFee` analogous to the existing `BaseFeeDenominator` guard:

```go
gasTarget := kc.GasTarget
if gasTarget == 0 {
    gasTarget = kc.MaxBlockGasUsedForBaseFee // or any safe fallback
}
```

---

### Proof of Concept

1. Deploy a Kaia network in `single` governance mode.
2. The governing node submits a header vote: `kip71.gastarget = 0`.
3. The vote is accepted by `NewVoteData` (passes `uint64Canonicalizer` + `noopFormatChecker`) and by `VerifyVote` / `checkConsistency` (falls into the `return nil` branch).
4. At the next epoch boundary the governance change is committed to `header.Governance`.
5. On the first block where `parentGasUsed > 0`, every node calls `NextMagmaBlockBaseFee` and executes `x.Div(x, new(big.Int).SetUint64(0))`.
6. `big.Int.Div` panics; all nodes crash; the chain halts.
