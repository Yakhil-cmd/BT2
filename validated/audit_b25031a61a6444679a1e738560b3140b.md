The XWiki advisory describes a path-traversal in a server-side extension-installation flow where an admin-controlled WebJar path is used unsanitized to write files to the filesystem. Polkadot SDK's runtime dispatch (extrinsics, contracts/revive calls, XCM execute/send) is a deterministic state machine over the storage trie — it has no equivalent operation that takes attacker/admin-controlled input and writes to the node's local filesystem. The only filesystem-write code paths found are CLI/tooling utilities that require local process invocation by the node operator, not reachable through any signed extrinsic, contract call, or XCM message:

- `substrate/utils/frame/benchmarking-cli/src/pallet/writer.rs` writes weight files from CLI-provided `--output` paths, invoked only by whoever runs the benchmarking CLI locally. [1](#0-0) 
- `cumulus/client/cli/src/lib.rs` `ExportGenesisHeadCommand`/`ExportGenesisWasmCommand` write to a CLI-supplied `Option<PathBuf>` output. [2](#0-1) 
- `substrate/client/cli/src/commands/generate_node_key.rs` writes generated keys to a CLI-supplied file path. [3](#0-2) 

None of these are reachable by an unprivileged (or even privileged-but-remote) actor through a signed extrinsic, enabled contract call, or permitted XCM message — the required "real user entry" per the analysis method. There is no analogous "extension/plugin install" mechanism in FRAME pallets, `pallet-contracts`/`pallet-revive`, or `pallet-xcm` that results in filesystem writes driven by untrusted path/name input, so this bug class does not have a demonstrable Polkadot SDK analog.

impl ExportGenesisHeadCommand {
	/// Run the export-genesis-head command
	pub fn run<B, C>(&self, client: Arc<C>) -> sc_cli::Result<()>
	where
		B: BlockT,
		C: HeaderBackend<B> + 'static,
	{
		let raw_header = get_raw_genesis_header(client)?;
		let output_buf = if self.raw {
			raw_header
		} else {
			format!("0x{:?}", HexDisplay::from(&raw_header)).into_bytes()
		};

		if let Some(output) = &self.output {
			fs::write(output, output_buf)?;
		} else {
			io::stdout().write_all(&output_buf)?;
		}

		Ok(())
	}

	bin: bool,

	base_path: &Option<PathBuf>,

	let keypair = ed25519::Keypair::generate();

	let secret = keypair.secret();

	let file_data = if bin {
		secret.as_ref().to_owned()
	} else {
		array_bytes::bytes2hex("", secret).into_bytes()
	};

	match (file, base_path, default_base_path) {
		(Some(file), None, false) => fs::write(file, file_data)?,
		(None, Some(_), false) | (None, None, true) => {
			let network_path = build_network_key_dir_or_default(

				chain_spec_id.unwrap_or_default(),

			);

				return Err(Error::KeyAlreadyExistsInPath(key_path));
			} else {

				fs::write(key_path, file_data)?
			}
		},
