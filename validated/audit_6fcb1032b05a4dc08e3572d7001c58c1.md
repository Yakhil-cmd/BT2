Based on my analysis of `runtime/src/bank/partitioned_epoch_rewards/mod.rs::get_rewards_and_num_partitions` and the surrounding reward-distribution machinery, this claim does not hold up.

**Key facts:**

1. `get_rewards_and_num_partitions` deliberately serves two *decoupled* pieces of data: `keyed_rewards` reflects only what was actually credited in the *current* block (voting/commission rewards at the boundary block, staking rewards in later distribution blocks), while `num_partitions` is metadata describing how many total distribution blocks will follow. This is not accidental — it's explicitly tested in `test_get_rewards_and_partitions`, which asserts that at the epoch-boundary bank `keyed_rewards` contains only `RewardType::Voting` entries while `num_partitions` is `Some(...)`, and in every subsequent partition block `keyed_rewards` contains `RewardType::Staking` entries with `num_partitions == None`. [1](#0-0) [2](#0-1) 

2. `is_first_block_in_epoch` (the check the attacker is alleged to manipulate) is computed purely from `epoch_schedule.get_epoch(self.parent_slot())` vs `self.epoch()` — both are deterministic, slot-number-derived values with no dependency on any transaction content, including stake split/merge instructions. [3](#0-2) 

3. Reward calculation snapshots stake delegations from the `stakes_cache` *before* any transactions of the boundary block are processed (in `compute_new_epoch_caches_and_rewards`, called from `process_new_epoch`, which runs prior to transaction execution for the new bank). [4](#0-3) 

4. When rewards are later distributed via `store_stake_accounts_in_partition`, the code looks up the *current* stake account state by `stake_pubkey` at distribution time. If a stake account was split/merged (i.e., the pubkey account no longer exists), `build_updated_stake_reward` returns `DistributionError::AccountNotFound`, which is explicitly handled by burning that specific reward's lamports and adjusting capitalization/sysvar bookkeeping accordingly — not a panic, not a double-credit, not a silent loss outside tracked accounting.
