`FixedSupplyResource` in `types/src/account_config/resources/fixed_supply.rs` is a plain Move resource representation (`current_supply`, `max_supply`, `total_minted`, `burn_events`, `mint_events`) used purely for reading on-chain fungible-asset/collection supply data [1](#0-0) . Its `derive(Eq, PartialEq)` has no relationship whatsoever to transaction admission, authenticator handling, or public key binding — it is not referenced anywhere in mempool, vm-validator, or authenticator dedup code.

The actual transaction/authenticator dedup logic in this codebase is `TxnHashAndAuthenticatorDeduper`, which keys strictly on the tuple `(txn.committed_hash(), txn.authenticator())` — i.e., the full committed transaction hash and the actual `TransactionAuthenticator` (which contains the real public key/signature bytes), not on any unrelated resource type's `Eq` implementation [2](#0-1) . The initial possible-duplicate detection is keyed on `(txn.sender(), txn.replay_protector())`, again unrelated to `FixedSupplyResource` [3](#0-2) . The existing `test_bad_signer` test explicitly confirms that transactions with differing signers/authenticators (even with identical raw txn content) are never collapsed into one, since the authenticator bytes differ [4](#0-3) .

Since `FixedSupplyResource` equality is never consulted by any authenticator/public-key dedup or caching path, there is no admission-path mechanism by which crafting colliding `FixedSupplyResource` instances could cause two distinct authenticators/public keys to be treated as the same signer. The premise connecting this resource's `Eq`/`PartialEq` derive to signer/public-key binding does not correspond to any real code path in this repository.

    fn test_bad_signer() {

            .unwrap()
            .into_inner();
        // Same txn, but signed by the correct signer (sender). Should not be filtered.
        let txn_0b = empty_txn(sender.addr, 0, 100)
            .sign(&sender.privkey, sender.pubkey.clone())
            .unwrap()
            .into_inner();
        let txns = block(vec![&txn_0a, &txn_0b]);
        let deduped_txns = deduper.dedup(txns.clone());
        assert_eq!(txns.len(), deduped_txns.len());
