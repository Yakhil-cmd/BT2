### Title
Attacker-Controlled `rpcNode.NType` in NEIGHBORS Response Injects Arbitrary Nodes into CN `flatStorage` — (`networks/p2p/discover/table_lookup.go`, `udp.go`, `table_data.go`)

### Summary
Any legitimately-bonded peer can return NEIGHBORS packets whose per-node `NType` field is set to `NodeTypeCN` regardless of the `targetType` of the FINDNODE request. Because `nodeFromRPC` blindly trusts `rn.NType` and `addNode` routes on `n.NType`, attacker-controlled keys are inserted into the CN `flatStorage` and served via `RandomNodes(NodeTypeCN)`, corrupting the CN peer-discovery set.

### Finding Description
During `kademliaRefresh(NodeTypeEN)`, the local node sends FINDNODE packets with `TargetType = NodeTypeEN` to bonded peers. The `loop()` goroutine validates that the incoming NEIGHBORS packet's outer `TargetType` field matches the pending request, but does **not** validate the `NType` of individual `rpcNode` entries within the packet. `nodeFromRPC` constructs a `Node` with `NType` taken verbatim from the attacker-supplied `rpcNode.NType`. After `bondall` completes a successful ping/pong with the attacker's node (which the attacker controls and makes responsive), `Bond` calls `addNode(n)`, which routes the node into `tab.storages[NodeTypeCN]` — the CN `flatStorage`. These entries survive `revalidateOnce` because the attacker's nodes respond to UDP pings.

### Impact Explanation
`RandomNodes(NodeTypeCN)` and `ClosestNodes(NodeTypeCN)` are the discovery API used by the P2P dial scheduler to select CN peers for block relay and transaction propagation. Filling CN `flatStorage` with attacker-controlled entries crowds out legitimate CNs, causing the victim node to waste dial attempts on attacker nodes (which fail at the RLPx layer) while starving real CN connections. Sustained, this constitutes an eclipse attack on the CN peer set: block relay and txpool propagation to/from CNs are disrupted, enabling block withholding and transaction censorship against the victim node.

### Likelihood Explanation
The prerequisite is a single legitimately-bonded peer — achievable by any node that completes a UDP ping/pong exchange, which is permissionless. The attacker needs to control the IP:port of the nodes advertised in the NEIGHBORS response (to pass `bondall`'s ping), which requires running additional UDP-responsive nodes. No privileged keys, governance access, or cryptographic breaks are needed.

### Recommendation
In `findNodesOnce` (or in `nodeFromRPC`), reject or retype any node whose `NType` does not match the `targetType` of the FINDNODE request. For example:

```go
// In findNodesOnce, after nodeFromRPC returns n:
if n.NType != targetType && n.NType != NodeTypeBN {
    continue // discard mismatched-type nodes
}
```

Alternatively, enforce this inside `nodeFromRPC` by passing `targetType` as a parameter and returning an error on mismatch.

### Proof of Concept
1. Start a local EN node performing `kademliaRefresh(NodeTypeEN)`.
2. Run an attacker node that completes the ping/pong bond with the local node.
3. When the local node sends FINDNODE with `TargetType = NodeTypeEN`, the attacker responds with a NEIGHBORS packet where `TargetType = NodeTypeEN` (passes the `loop()` check) but each `rpcNode.NType = NodeTypeCN` and `rpcNode.ID/IP/UDP` point to attacker-controlled endpoints that respond to UDP pings.
4. After `bondall` completes, assert that `tab.storages[NodeTypeCN].all()` contains the attacker's nodes.
5. Call `RandomNodes(NodeTypeCN)` and observe the attacker's nodes are returned, confirming CN `flatStorage` corruption.

func (tab *Table2) revalidateOnce(s tableStorage) {
	n := s.oldest() // pick a node to revalidate.
	if n == nil {
		return
	}

	if tab.bondAge(n.ID, n.IP) < revalidateBackoff {
		logger.Trace("skip revalidate", "node", n.addr())
		return
	}

	err := tab.udp.ping(n.ID, n.addr())
	if err == nil {
		s.add(n) // bump the node
		tab.db.updateBondTime(n.ID, n.IP, time.Now())
		logger.Debug("Discovery revalidation passed", "node", n.addr())
	} else {
		s.delete(n)
		tab.db.deleteNode(n.ID)
		logger.Debug("Discovery revalidation failed", "node", n.addr())
	}
}
