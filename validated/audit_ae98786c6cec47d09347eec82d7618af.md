### No vulnerability found for this question.

**Reasoning summary:** The exploit hypothesis requires the pre-publish hook to gate the publish decision while observing a partial worktree. Neither premise holds in this codebase:

1. `--webhook-url` is only ever wired to `afterPublish`, never `beforePublish` [1](#0-0) , so a webhook can never act as the "pre-publish" gating hook described in the question.
2. Even the actual pre-publish hook (`prePubExechookRunner`) does not gate the publish: `beforePublish` merely calls the non-blocking `Send(hash)` and unconditionally returns `nil`, and `SyncRepo` proceeds straight to `publishSymlink` regardless of whether the hook eventually succeeds or fails [2](#0-1) [3](#0-2) . `HookRunner.Run`'s retry loop only affects metrics/logging and, in `--one-time` mode, the process exit code — it never blocks or reverses an already-completed `publishSymlink` call [4](#0-3) .
3. The worktree for a given hash is fully created and configured via `createWorktree`/`configureWorktree` *before* `beforePublish` (and thus `Send`) is ever invoked [5](#0-4) , so the hook (when it runs) is never handed a partially-configured worktree path for that hash.
4. The single-slot `hookData` channel's "may skip intermediate hashes" behavior is explicit, documented, intentional design [6](#0-5) , not a race that lets a hook validate content different from what gets published, since the hook is not a publish gate.

Since neither webhook-as-pre-publish nor an actual publish-blocking gate exists in the code, the described invariant violation cannot be reached through attacker-controlled repo content or timing.

// Run waits for trigger events from the channel, and run hook when triggered.
func (r *HookRunner) Run(ctx context.Context) {
	var lastHash string

	// Wait for trigger from hookData.Send
	for range r.data.events() {
		// Retry in case of error
		for {
			// Always get the latest value, in case we fail-and-retry and the
			// value changed in the meantime.  This means that we might not send
			// every single hash.
			hash := r.data.get()
			if hash == lastHash {
				break
			}

			if err := r.hook.Do(ctx, hash); err != nil {
				r.log.Error(err, "hook failed", "hash", hash, "retry", r.backoff)
				updateHookRunCountMetric(r.hook.Name(), "error")
				// don't want to sleep unnecessarily terminating anyways
				r.sendOneTimeResultAndTerminate(false)
				time.Sleep(r.backoff)
			} else {
				updateHookRunCountMetric(r.hook.Name(), "success")
				lastHash = hash
				r.sendOneTimeResultAndTerminate(true)
				break
			}
		}
	}
}
