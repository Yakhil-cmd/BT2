### Title
Wrong Address Checked in `checkConsistency` Allows Governing Node to Set Off-Council `GoverningNode`, Permanently Locking Single-Mode Governance — (`kaiax/gov/headergov/impl/header.go`)

### Summary

`checkConsistency` for `GovernanceGoverningNode` validates that `params.GoverningNode` (the **current** governing node) is in the council, but never checks that `vote.Value()` (the **proposed** new governing node) is in the council. A malicious governing node can vote to transfer governance authority to any arbitrary address, including one not in the council. The vote passes all validation, is ratified at the next epoch boundary, and permanently locks single-mode governance.

### Finding Description

In `checkConsistency`, the `GovernanceGoverningNode` case reads:

```go
council, err := h.ValSet.GetCouncil(blockNum - 1)
// ...
if slices.Contains(council, params.GoverningNode) {   // ← checks CURRENT node
    return nil
}
return ErrGovNodeNotInValSetList
``` [1](#0-0) 

The check asks "is the current governing node in the council?" — a condition that is trivially true in any healthy chain state — rather than "is the proposed new governing node in the council?" (`vote.Value()`). The proposed value is never inspected.

Compare with the `AddValidator`/`RemoveValidator` case in the same function, which correctly reads `vote.Value()`:

```go
if slices.Contains(vote.Value().([]common.Address), params.GoverningNode) {
``` [2](#0-1) 

The full call path from P2P block propagation is:

`VerifyHeader` → `VerifyVote` → `checkConsistency(GovernanceGoverningNode)` [3](#0-2) [4](#0-3) 

### Impact Explanation

**Phase 1 — Vote accepted:** The governing node (a council member, e.g. `address[0]`) crafts a `header.Vote` for `governance.governingnode` with value `address[10]` (not in council). `checkConsistency` checks `slices.Contains(council, params.GoverningNode)` = `slices.Contains(council, address[0])` = **true** → returns `nil`. The vote is accepted and stored by all honest nodes.

**Phase 2 — Ratification:** At the next epoch boundary, `getExpectedGovernance` collects the vote and includes it in `header.Governance`. `VerifyGov` accepts it (it matches the locally-derived expected governance). `GetParamSet` now returns `GoverningNode = address[10]`. [5](#0-4) [6](#0-5) 

**Phase 3 — Permanent governance lock:**

- *After Permissionless fork:* `VerifyVote` at lines 103–107 rejects any vote whose `Voter() != params.GoverningNode`. Since `address[10]` is not in the council, it can never be a block proposer, so no vote can ever pass this check again.
- *Before Permissionless fork:* Any council member can still vote for other parameters, but any attempt to vote for `GovernanceGoverningNode` again will hit `checkConsistency`, which now checks `slices.Contains(council, address[10])` = **false** → `ErrGovNodeNotInValSetList`. The governing node cannot be corrected. [7](#0-6) 

The invariant documented in the `valset` module — "the governing node is unconditionally qualified to allow governance parameter change under any circumstances" — is violated because the governing node is no longer a council member at all.

### Likelihood Explanation

Requires the current governing node to act maliciously. On Mainnet and Kairos, which both operate in `single` mode, this is a single key holder. The attack is a one-shot, irreversible action requiring no collusion and no external dependencies. The malicious block propagates normally over P2P and is accepted by all honest nodes.

### Recommendation

Replace `params.GoverningNode` with `vote.Value().(common.Address)` in the council membership check:

```go
case gov.GovernanceGoverningNode:
    params := h.GetParamSet(blockNum)
    if params.GovernanceMode != "single" {
        return nil
    }
    council, err := h.ValSet.GetCouncil(blockNum - 1)
    if err != nil {
        return err
    }
    // Check the PROPOSED new governing node, not the current one
    if slices.Contains(council, vote.Value().(common.Address)) {
        return nil
    }
    return ErrGovNodeNotInValSetList
```

### Proof of Concept

1. Start a chain with `epoch=10`, `GovernanceMode=single`, council = `[addr0..addr4]`, `GoverningNode=addr0`.
2. At block 5, `addr0` (as proposer) embeds a `header.Vote` for `governance.governingnode` = `addr10` (not in council).
3. `VerifyVote` → `checkConsistency`: checks `slices.Contains(council, addr0)` = true → vote accepted.
4. At block 10 (epoch boundary), `header.Governance` = `{"governance.governingnode": addr10}` is ratified and accepted by `VerifyGov`.
5. At block 11+, `GetParamSet` returns `GoverningNode=addr10`.
6. Any subsequent `header.Vote` from any council member is rejected: post-Permissionless by `ErrVotePermissionDenied` (line 106); pre-Permissionless, any `GovernanceGoverningNode` vote is rejected by `ErrGovNodeNotInValSetList` (line 178, now checking `addr10` ∉ council).
7. Governance is permanently locked. [8](#0-7)

func (h *headerGovModule) VerifyVote(header *types.Header) error {
	if len(header.Vote) == 0 {
		return nil
	}

	var (
		vb       headergov.VoteBytes = header.Vote
		blockNum                     = header.Number.Uint64()
	)

	vote, err := vb.ToVoteData()
	if err != nil {
		logger.Error("ToVoteData error", "num", blockNum, "vote", vb, "err", err)
		return err
	}

	if gov.DeprecatedAt(vote.Name(), h.ChainConfig.Rules(header.Number)) {
		logger.Error("Vote is deprecated", "num", blockNum, "name", vote.Name())
		return ErrDeprecatedVote
	}

	council, err := h.ValSet.GetCouncil(blockNum)
	if err != nil {
		return err
	}

	// check if the voter is in council
	if !slices.Contains(council, vote.Voter()) {
		return ErrInvalidKeyValue
	}

	// check if Voter is the block proposer.
	author, err := h.Chain.Sealer().Author(header)
	if err != nil {
		return err
	}
	if author != vote.Voter() {
		return ErrInvalidVoter
	}

	// In single mode, only the governing node can write header.Vote after Permissionless.
	params := h.GetParamSet(blockNum)
	if h.ChainConfig.IsPermissionlessForkEnabled(new(big.Int).SetUint64(blockNum)) &&
		params.GovernanceMode == "single" &&
		vote.Voter() != params.GoverningNode {
		return ErrVotePermissionDenied
	}

	return h.checkConsistency(blockNum, vote)
}

func (h *headerGovModule) checkConsistency(blockNum uint64, vote headergov.VoteData) error {
	switch vote.Name() {
	case gov.GovernanceGoverningNode:
		params := h.GetParamSet(blockNum)

		// compare with governing node only in single mode.
		if params.GovernanceMode != "single" {
			return nil
		}

		// we'll use blockNum-1 for the blocknumber of GetCouncil since blockNum cannot be available(eg. vote)
		// it's definite that the valSet vote is not included in this block
		// so the council(blockNum - 1) and council(blockNum) should be same
		council, err := h.ValSet.GetCouncil(blockNum - 1)
		if err != nil {
			return err
		}

		if slices.Contains(council, params.GoverningNode) {
			return nil
		}
		return ErrGovNodeNotInValSetList

func (h *headerGovModule) getExpectedGovernance(blockNum uint64) headergov.GovData {
	prevEpochIdx := calcEpochIdx(blockNum, h.epoch) - 1
	prevEpochVotes := h.getVotesInEpoch(prevEpochIdx)
	govs := make(gov.PartialParamSet)

	sortedVoteBlocks := slices.Collect(maps.Keys(prevEpochVotes))
	slices.Sort(sortedVoteBlocks)

	for _, voteBlock := range sortedVoteBlocks {
		vote := prevEpochVotes[voteBlock]
		govs.Add(string(vote.Name()), vote.Value())
	}

	// assert(len(headergov.NewGovData(govs).Items()) == len(govs))
	return headergov.NewGovData(govs)
}

func (h *headerGovModule) GetParamSet(blockNum uint64) gov.ParamSet {
	h.mu.RLock()
	defer h.mu.RUnlock()

	prevEpochStart := PrevEpochStart(blockNum, h.epoch, h.isKoreHF(blockNum))
	gh := h.history
	gp, err := gh.Search(prevEpochStart)
	if err != nil {
		logger.Warn("No param set", "blockNum", blockNum, "prevEpochStart", prevEpochStart)
		return *gov.GetDefaultGovernanceParamSet()
	}
	return gp
}
