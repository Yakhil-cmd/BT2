Based on the searches conducted, this report describes an Aave-style lending protocol liquidation bug specific to `liquidateLogic`, where `amountToLiquidate` is computed from oracle prices for a borrowed/collateral token pair and a `liquidationBonus`, but isn't re-adjusted after `amountToSeize` is capped to the borrower's actual collateral balance. This requires a lending-market pallet with price-oracle-based collateral/debt accounting and a liquidation bonus mechanism.

The Polkadot SDK repository (`Camomtat/polkadot-sdk--016`) does not contain an analogous lending/liquidation pallet. The only related slashing/liquidation-adjacent logic found is in `substrate/frame/staking/src/lib.rs` (slash-out-of logic) and `substrate/frame/balances/src/impl_currency.rs` (`slash`), which are share/ratio-based staking slashes rather than a two-sided (price-converted, price-oracle-derived) collateral seizure with a bonus multiplier [1](#0-0) [2](#0-1) . These functions already cap the amount slashed by the actual available balance in the same operation, with no separate "amount to seize" vs "amount to liquidate" cross-asset conversion step, so the Aave bug class (computing a repay amount from one asset's price before capping the seize amount of a different collateral asset, then failing to re-derive the repay amount from the capped seize) has no structural analog here.

No other lending, borrowing, or price-oracle-based collateral liquidation logic exists in the indexed code of this repository, so this specific bug class does not map onto the codebase.

		if value.is_zero() {
			return (NegativeImbalance::zero(), Zero::zero());
		}
		if Self::total_balance(who).is_zero() {
			return (NegativeImbalance::zero(), value);
		}

		let result = match Self::try_mutate_account_handling_dust(
			who,
			false,
			|account, _is_new| -> Result<(Self::NegativeImbalance, Self::Balance), DispatchError> {
				// Best value is the most amount we can slash following liveness rules.
				let ed = T::ExistentialDeposit::get();
				let actual = match system::Pallet::<T>::can_dec_provider(who) {
					true => value.min(account.free),
					false => value.min(account.free.saturating_sub(ed)),
				};
				account.free.saturating_reduce(actual);
				let remaining = value.saturating_sub(actual);
				Ok((NegativeImbalance::new(actual), remaining))
			},
		) {
			Ok((imbalance, remaining)) => {
				Self::deposit_event(Event::Slashed {
					who: who.clone(),
					amount: value.saturating_sub(remaining),
				});
				(imbalance, remaining)
			},
			Err(_) => (Self::NegativeImbalance::zero(), value),
