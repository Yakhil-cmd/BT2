### Title
Attacker-controlled PR branch name is substituted with live `GITHUB_TOKEN` via `EnvironmentVariables#interpolate` before being passed to `git clone` — ([File: lib/shipit/command.rb], [File: lib/shipit/environment_variables.rb], [File: lib/shipit/stack_commands.rb])

### Summary
`ReviewStackAdapter#stack_attributes` stores `params.pull_request.head.ref` verbatim as `Stack#branch` with no format validation, and `StackCommands#fetch`/`#fetch_commit`/`#git_clone` pass that value unmodified as the `--branch` argument to `git`. `Command#interpolated_arguments` unconditionally runs every argument through `EnvironmentVariables#interpolate`, which replaces any `$VARNAME` substring with the value from `Command#env` (which includes the live `GITHUB_TOKEN` via `Commands#base_env`) — with no whitelist/`#permit` check applied to this path.

### Finding Description
Broken binding: `Stack#branch` (attacker-supplied PR `head.ref`) `==` the literal string substituted into the `git --branch <value>` argv element by `EnvironmentVariables#interpolate`, using secrets from `Commands#base_env` (`GITHUB_TOKEN`, `GITHUB_DOMAIN`) — with zero sanitization or whitelist enforcement between the two.

Path:
1. `OpenedHandler#process` → `ReviewStackAdapter#find_or_create!` → `#create!` builds `stack_attributes` with `branch: params.pull_request.head.ref` [1](#0-0) , with no format validation found on `Stack#branch` anywhere in the model.
2. `Shipit::ReviewStackProvisioningQueue.add(stack)` eventually triggers `StackCommands#fetch`/`#fetch_commit`, which call `git_clone(@stack.repo_git_url, @stack.git_path, branch: @stack.branch, env:, ...)` [2](#0-1) , and `#git_clone` places the raw branch string as a `--branch` argv element: `git('clone', ..., '--branch', branch, url, path, **kwargs)` [3](#0-2) .
3. `env` used for this command is `Commands#base_env` merged with `@stack.env`, and `base_env` includes the real `GITHUB_TOKEN` and `GITHUB_DOMAIN` [4](#0-3) .
4. When the command starts, `Command#start` calls `PTY.spawn(unbundled_env, *interpolated_arguments, chdir: @chdir)`, where `interpolated_arguments` maps every argv element through `EnvironmentVariables.with(env).interpolate(argument)` [5](#0-4) .
5. `EnvironmentVariables#interpolate` unconditionally substitutes any `$WORD` substring in an argument with `@env.fetch(variable) { ENV[variable] }`, with no whitelist check (`#permit` is a separate, unused method on this path) [6](#0-5) .

Consequently, a PR opened from a fork with `head.ref = '$GITHUB_TOKEN'` produces a `Stack#branch` of `'$GITHUB_TOKEN'`, and the `git clone`/`git fetch` argv actually executed on the deploy host contains the live token value as the `--branch` argument, instead of the literal string `$GITHUB_TOKEN`.

Because `PTY.spawn` is invoked with the array form (`*interpolated_arguments`), there is **no shell** interpreting the argv, so the "RCE via shell metacharacters" (`; rm -rf / #`) portion of the original claim does not hold — git receives such a ref name as a literal, non-shell-interpreted string and will simply reject it as an invalid/unknown ref. The credential-substitution portion of the claim, however, is real and verified in code: no validation, no `#permit` whitelist, and no escaping prevents the branch name from pulling `GITHUB_TOKEN` out of the process environment and placing it into the subprocess argv. Git commands typically echo the requested (now token-valued) ref name back in their error output (e.g. "Remote branch <value> not found in upstream origin"), which is captured by `Command#stream`/`#run` and surfaces in the stack's build/task output.

### Impact Explanation
An attacker who can open a PR against any repository with `review_stacks_enabled` and `provisioning_behavior_allow_all` can force the live `GITHUB_TOKEN` (and `GITHUB_DOMAIN`) into a `git` subprocess's argument list and, via git's own error reporting, into that repository's review-stack task/build output. This is a genuine secret-exposure primitive scoped to whichever repository/organization is targeted — repeatable per-PR and per-repository that has review stacks auto-provisioning enabled. It does not achieve arbitrary shell RCE (PTY.spawn bypasses the shell), so the "flags-as-argv"/RCE portion of the original claim is not substantiated. The credential-exposure portion matches the Critical category "exfiltration of GITHUB_TOKEN," though actual attacker visibility depends on who can view that review stack's task output (typically requires an authenticated Shipit session/team membership), which was not verified to be unauthenticated in this codebase.

### Likelihood Explanation
Requires no special attacker privilege beyond forking and opening a PR; the only preconditions are repository-level configuration (`review_stacks_enabled`, `provisioning_behavior_allow_all`), which are operator choices, not attacker-controlled. Given those preconditions, the attack is trivial and fully repeatable (one PR per exploit attempt, any branch name).

### Recommendation
- Validate/sanitize `Stack#branch` (and any other user-derived value reaching `Command`) to a strict allow-list pattern (e.g., valid git ref characters only, reject `$`).
- Do not run `EnvironmentVariables#interpolate` over arguments derived from untrusted external input (PR refs); reserve interpolation for operator-authored deploy-spec commands only, and route it through `EnvironmentVariables#permit` with an explicit whitelist.
- Alternatively, pass `--branch` values using a mechanism that never subjects them to `$VAR` interpolation (e.g., don't include externally-controlled strings in `Command`'s args array passed to `interpolate_environment_variables`).

### Proof of Concept
In a minitest test (e.g. `test/unit/command_test.rb` style):
```ruby
env = { 'GITHUB_TOKEN' => 'super-secret-token' }
command = Shipit::Command.new('git', 'clone', '--branch', '$GITHUB_TOKEN', 'url', 'path', env: env, chdir: '/tmp')
assert_includes command.interpolated_arguments, 'super-secret-token'
refute_includes command.interpolated_arguments, '$GITHUB_TOKEN'
```
This demonstrates the equality-break: `Stack#branch` (`'$GITHUB_TOKEN'`, attacker-controlled) resolves to `Command#env['GITHUB_TOKEN']`'s literal value in `interpolated_arguments`, the exact argv passed to `PTY.spawn`.

    def interpolate(argument)
      return argument unless @env

      argument.gsub(/(\$\w+)/) do |variable|
        variable.sub!('$', '')
        Shellwords.escape(@env.fetch(variable) { ENV[variable] })
      end
    end
