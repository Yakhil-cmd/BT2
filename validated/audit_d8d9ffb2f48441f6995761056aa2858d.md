### Title
Allowance Check Bypassed for Swap Tx with `nonce == senderNonce+1`, Enabling Proposer KAIA Loss — (`kaiax/gasless/impl/tx_pool.go`)

### Summary

A swap tx submitted with `nonce = senderNonce+1` skips the `tokenContract.Allowance` check at admission. If the sender later mines a non-approve tx at `senderNonce`, the swap tx is re-evaluated as a solo swap (no approve tx), passes all promotion checks, and is included in a bundle. The proposer lends KAIA via `LendTx`, but the swap reverts due to zero allowance, and the lend amount is permanently lost.

### Finding Description

In `checkBalanceForSwap`, the allowance check is conditional on `noApproveTxPreceeds`:

```go
senderNonce := g.getCurrentStateNonce(swapArgs.Sender)
noApproveTxPreceeds := swapNonce == senderNonce
if noApproveTxPreceeds {
    // tx.token.allowance(sender, router) >= tx.amountIn
    approval, err := tokenContract.Allowance(...)
    if approval.Cmp(swapArgs.AmountIn) < 0 { return err }
}
``` [1](#0-0) 

When `swapNonce == senderNonce+1`, the intent is that an approve tx will precede the swap. But there is no enforcement that the tx at `senderNonce` must actually be an approve tx. If the sender mines any other tx at `senderNonce`, the swap tx's nonce becomes the new head nonce, and `isSwapTxReady` promotes it as a solo swap:

```go
if swapTx.Nonce() == nonce {   // now true after non-approve tx mined
    approveTx = nil
}
return g.IsExecutable(nil, swapTx)
``` [5](#0-4) 

`VerifyExecutable(nil, swapTx)` checks only nonce equality and `amountRepay` — no allowance check. [2](#0-1) 

The proposer then generates a `LendTx` transferring `SwapTx.Fee()` KAIA to the sender, and includes `[LendTx, SwapTx]` in the block. The swap tx reverts (zero allowance on `transferFrom`), but the lend tx is already committed. The proposer's KAIA balance is reduced by the lend amount with no repayment. [6](#0-5) 

### Impact Explanation

The proposer (block builder) permanently loses `SwapTx.Fee()` KAIA per exploited bundle. An attacker can repeat this across multiple blocks and multiple proposers. This is an unauthorized drain of the proposer's KAIA balance — a direct financial loss to a chain participant caused by a logic flaw in the gasless module's admission/promotion pipeline.

### Likelihood Explanation

The attack requires only:
1. Holding any nonzero token balance (to pass the `balanceOf` check at admission).
2. Submitting a swap tx with `nonce = senderNonce+1`, zero allowance, and `amountRepay` matching the solo-swap formula.
3. Mining any regular tx at `senderNonce` (the attacker's own nonce — fully self-controlled).

No privileged access, governance keys, or validator collusion is needed. The entire path is reachable via public RPC.

### Recommendation

Re-validate allowance at promotion time, or enforce it unconditionally at admission regardless of the nonce relationship. Specifically, in `checkBalanceForSwap`, the allowance check should not be gated on `noApproveTxPreceeds`. Alternatively, `isSwapTxReady` (or `VerifyExecutable`) should perform an on-chain allowance check when promoting a swap tx as a solo swap (i.e., when `approveTxOrNil == nil`).

### Proof of Concept

1. `senderNonce = 5`, attacker holds sufficient token balance, allowance = 0.
2. Submit `swapTx` with `nonce=6`, `amountRepay = R1+R3` (solo-swap formula), `minAmountOut >= amountRepay`.
3. `checkBalanceForSwap`: `noApproveTxPreceeds = (6==5) = false` → allowance check skipped → tx admitted to queue.
4. Submit any regular tx with `nonce=5` → mined → `senderNonce` becomes 6.
5. `isSwapTxReady`: `swapTx.Nonce()==6 == senderNonce==6` → `approveTx=nil` → `IsExecutable(nil, swapTx)` passes (nonce ✓, amountRepay ✓).
6. Swap tx promoted to pending. Proposer generates `LendTx` (value = `SwapTx.Fee()`), includes `[LendTx, SwapTx]`.
7. `LendTx` executes: proposer sends `SwapTx.Fee()` KAIA to attacker.
8. `SwapTx` executes: `transferFrom(sender, router, amountIn)` reverts (allowance=0). Repayment never occurs.
9. Proposer's KAIA balance is permanently reduced by `SwapTx.Fee()`.

func (g *GaslessModule) isSwapTxReady(swapTx, prevTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, swapTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	var approveTx *types.Transaction
	if swapTx.Nonce() == nonce {
		approveTx = nil
	} else if swapTx.Nonce() == nonce+1 {
		if prevTx == nil || !g.IsApproveTx(prevTx) {
			return false
		}
		approveTx = prevTx
	} else {
		return false
	}

	return g.IsExecutable(approveTx, swapTx)
}
