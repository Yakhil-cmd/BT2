### Title
Suspended `ValActive` Validators Receive Staking Rewards — (`File: kaiax/staking/impl/getter.go`)

---

### Summary

After the permissionless hardfork, `parsePermissionlessCallResult` filters staking-eligible nodes by `IsRewardEligible()` (i.e., `ValActive` state) but never checks the `Suspended` flag. Because the `MultiCallStakingInfoPermissionless` multicall does not return suspension information in its `Profile` struct, and the staking module never queries the suspended-validators list, a suspended `ValActive` validator is included in `StakingInfo` and receives proportional KAIA staking rewards every block — exactly the outcome the suspension mechanism is designed to prevent.

---

### Finding Description

**Suspension is checked in the consensus path but not in the reward path.**

In the valset module, `getQualifiedValidators` calls `committeeWithFallback` → `nodes.Committee()` → `FilterByState(ValActive).ExcludeSuspended()`. Suspended validators are correctly excluded from block signing and proposing. [1](#0-0) [2](#0-1) 

In the staking module, `getFromState` (post-permissionless fork) calls `MultiCallStakingInfoPermissionless`, which returns `Profile` structs containing only `(nodeId, stakingContract, rewardAddress, timeoutAt, state)` — no suspended flag. [3](#0-2) 

`parsePermissionlessCallResult` then filters profiles solely by `IsRewardEligible()`:

```go
for i, p := range profiles {
    if !valset.NodeState(p.State).IsRewardEligible() {
        continue
    }
    // suspended ValActive validators pass this check
    nodeIds = append(nodeIds, p.NodeId)
    ...
}
``` [4](#0-3) 

`IsRewardEligible()` returns `true` only for `ValActive` — it has no knowledge of the `Suspended` flag: [5](#0-4) 

The suspended-validators list is fetched separately only in `ReadABv2Snapshot` (used by the valset module), never in the staking module's `getFromState`: [6](#0-5) 

The resulting `StakingInfo` (containing suspended validators) is then consumed by `getDeferredReward` → `assignStakingRewards` / `assignStakingRewardsFlex`, which distribute KAIA staking rewards proportionally to all nodes in `StakingInfo.ConsolidatedNodes()`: [7](#0-6) [8](#0-7) 

Finally, `FinalizeState` calls `state.AddBalance` for every address in `spec.Rewards`, crediting the suspended validator's reward address with KAIA: [9](#0-8) 

---

### Impact Explanation

A suspended `ValActive` validator — one that the suspender role has explicitly removed from consensus participation — continues to receive proportional KAIA staking rewards every block. This is unauthorized reward distribution affecting KAIA tokens. The suspension mechanism's purpose (removing a misbehaving or compromised validator from all chain privileges) is only half-enforced: consensus participation is blocked, but reward accrual is not.

---

### Likelihood Explanation

The trigger requires a validator to be in `ValActive` state and suspended by the suspender role. Suspension is a privileged operation, but the bug manifests automatically and continuously after suspension occurs — no further attacker action is needed. Every block produced while the validator remains suspended and `ValActive` results in incorrect KAIA distribution. The permissionless hardfork must be active.

---

### Recommendation

In `parsePermissionlessCallResult`, additionally query the suspended-validators list (e.g., via `MultiCallNodeStatesPermissionless` which already returns `SuspendedValidators`) and skip any profile whose `NodeId` appears in that list, mirroring the `ExcludeSuspended()` logic already applied in the valset committee path.

Alternatively, extend the `MultiCallStakingInfoPermissionless` contract function to include a `suspended` boolean in each `Profile`, so the staking module can filter in a single call.

---

### Proof of Concept

1. Deploy post-permissionless chain. Validator `V` is `ValActive` with 10M KAIA staked.
2. Suspender calls `AddressBookV2.suspendValidator(V)`. `V` is now excluded from `Committee()` and cannot sign blocks.
3. At the next block, `FinalizeState` calls `GetDeferredReward` → `getDeferredRewardFull` → `assignStakingRewards(config, stakers, si)`.
4. `si` was built by `parsePermissionlessCallResult`: `V`'s profile has `State = ValActive (6)`, passes `IsRewardEligible()`, and is included in `si.NodeIds` / `si.StakingAmounts`.
5. `assignStakingRewards` computes `V`'s proportional share of staking rewards and adds it to `alloc[V.RewardAddr]`.
6. `state.AddBalance(V.RewardAddr, amount)` credits KAIA to the suspended validator's reward address.
7. This repeats every block until `V` transitions out of `ValActive` state (which requires a separate epoch transition or violation transition — not triggered by suspension alone). [10](#0-9) [11](#0-10) [12](#0-11)

// committeeWithFallback returns the committee at the given block.
// Committee = {VA} - {Suspended}.
//
// Safety fallback: when len(committee)=0 due to {ValActive} ⊆ SuspendedSet, fallback to all VA.
func committeeWithFallback(nodes valset.NodeMap) (committee valset.NodeMap, fellBack bool) {
	committee = nodes.Committee()
	if len(committee) > 0 {
		return committee, false
	}

	// ignore SuspendedSet
	return nodes.FilterByState(valset.ValActive), true
}

// getQualifiedValidators: qualified = committee = {VA} − {Suspended} (with safety fallback).
func (v *ValsetModule) getQualifiedValidators(num uint64) (*valset.AddressSet, error) {
	nodes, err := v.getNodes(num)
	if err != nil {
		return nil, err
	}
	committee, fellBack := committeeWithFallback(nodes)
	if fellBack && v.lastSuspendFallbackLog != num {
		logger.Warn("all ValActive are suspended, ignoring suspended set for committee", "num", num)
		v.lastSuspendFallbackLog = num
	}
	return valset.NewAddressSet(committee.Addresses()), nil

// ReadABv2Snapshot reads all node states, timeouts, max counts, and thresholds from ABv2 in a single MultiCall.
func ReadABv2Snapshot(
	statedb *state.StateDB,
	chain backends.BlockChainForCaller,
	header *types.Header,
) (*ABv2Snapshot, error) {
	caller, err := NewMultiCallContractCaller(statedb, chain, header)
	if err != nil {
		return nil, err
	}
	opts := &bind.CallOpts{BlockNumber: header.Number}

	res, err := caller.MultiCallNodeStatesPermissionless(opts)
	if err != nil {
		return nil, err
	}

	nodes, err := NewNodeMapFromABv2(res.Profiles, res.StakingAmounts)
	if err != nil {
		return nil, err
	}

	return &ABv2Snapshot{
		Nodes: nodes,
		ABv2TransitionParam: ABv2TransitionParam{
			PauseTimeout:            time.Duration(res.PauseTimeout.Int64()) * time.Second,
			IdleTimeout:             time.Duration(res.IdleTimeout.Int64()) * time.Second,
			PfsThreshold:            res.PfsThreshold.Uint64(),
			CfsThreshold:            res.CfsThreshold.Uint64(),
			EpochVACount:            res.EpochVACount.Uint64(),
			MaxValActivePausedCount: res.MaxValActivePausedCount.Uint64(),
		},
		SuspendedValidators: res.SuspendedValidators,
	}, nil
}

// assignStakingRewards assigns staking rewards to stakers according to their staking amounts.
// Returns the allocation and the remainder.
func assignStakingRewards(config *reward.RewardConfig, stakersReward *big.Int, si *staking.StakingInfo) (map[common.Address]*big.Int, *big.Int) {
	var (
		cns               = si.ConsolidatedNodes()
		minStake          = config.MinimumStake.Uint64()
		totalExcessInt    = uint64(0) // sum of excess stakes (the amount over minStake) over all stakers
		cnTotalStakingMap = make(map[common.Address]uint64)
		isPrague          = config.Rules.IsPrague
	)
	for _, cn := range cns {
		// If the CNStaking is less than minStake, skip it.
		if cn.StakingAmount >= minStake {
			// Calculate total staking amount once
			cnTotalStakingAmount := cn.StakingAmount
			if isPrague && cn.CLStakingInfo != nil {
				cnTotalStakingAmount += cn.CLStakingInfo.CLStakingAmount
			}
			totalExcessInt += cnTotalStakingAmount - minStake
			cnTotalStakingMap[cn.RewardAddr] = cnTotalStakingAmount
		}
	}
