### Title
Unauthenticated gRPC Endpoint Exposes `governance_vote` Write API, Allowing Remote Governance Parameter Manipulation — (`node/node.go`, `kaiax/gov/headergov/impl/api.go`)

### Summary
`startgRPC()` registers all `Public: true` APIs without any namespace allowlist. The `headerGovModule.APIs()` returns a `governance`-namespace entry with `Public: true` that includes the `Vote(name, value)` method. The gRPC server has no authentication. A remote unauthenticated caller can invoke `governance_vote` and cause the node to queue a governance vote — signed with the node's own validator identity — for any governance parameter, including reward minting amounts and distribution ratios.

### Finding Description
`node/node.go:startgRPC()` iterates all APIs and registers every one where `api.Public == true`:

```go
for _, api := range apis {
    if api.Public {
        handler.RegisterName(api.Namespace, api.Service)
    }
}
```

`kaiax/gov/headergov/impl/api.go` registers `headerGovAPI` under the `governance` namespace with `Public: true`. This service exposes `Vote(name string, value any)`, which:
1. Sets `voter = api.h.nodeAddress` (the node's own validator address — not caller-controlled)
2. Checks governance mode: in `"single"` mode, rejects if the node is not the governing node; in `"ballot"` mode, any validator can vote
3. Calls `api.h.PushMyVotes(vote)` to queue the vote for inclusion in the next block the node proposes

The gRPC server is created with `grpc.NewServer()` — no TLS, no auth interceptor, no token check.

### Impact Explanation
- **"single" governance mode, node is the governing node**: A single unauthenticated gRPC call can change any governance parameter (e.g., `reward.mintingamount`, `reward.ratio`, `reward.kip82ratio`, `governance.governingnode`). The vote takes effect at the next epoch boundary. This is a direct, complete governance takeover affecting validator reward amounts and treasury distribution.
- **"ballot" governance mode**: An attacker can cause any validator node with gRPC exposed to cast votes for attacker-chosen governance changes. If enough nodes are reachable (or the attacker targets nodes holding a quorum), governance parameters can be changed.

This satisfies the impact gate: governance privilege escalation that changes protected chain state (governance parameter set, reward distribution, minting amount).

### Likelihood Explanation
Requires the gRPC endpoint to be enabled (`--grpc` flag) and publicly reachable. This is not the default configuration, but the gRPC feature exists specifically for external clients. Operators enabling it for legitimate use (e.g., light clients, tooling) unknowingly expose `governance_vote`. No credentials, keys, or special knowledge beyond the gRPC endpoint address are needed.

### Recommendation
1. **Immediate**: Add a namespace allowlist to `startgRPC()` analogous to the `modules []string` parameter used by `startHTTP`/`startWS`. Default the gRPC allowlist to exclude `governance`, `admin`, and `debug`.
2. **Defense-in-depth**: Add gRPC server-side authentication (mTLS or token interceptor) in `networks/grpc/gServer.go`.
3. **API design**: Mark `headerGovAPI.Vote()` as `Public: false` (IPC-only), consistent with how `admin` write APIs are handled.

func (n *Node) startgRPC(apis []rpc.API) error {
	if n.grpcEndpoint == "" {
		return nil
	}

	handler := rpc.NewServer()
	for _, api := range apis {
		if api.Public {
			if err := handler.RegisterName(api.Namespace, api.Service); err != nil {
				return err
			}
			n.logger.Debug("gRPC registered", "namespace", api.Namespace)
		}
	}

	listener := &grpc.Listener{Addr: n.grpcEndpoint}
	n.grpcHandler = handler
	n.grpcListener = listener
	listener.SetRPCServer(handler)

	go listener.Start()
	n.logger.Info("gRPC endpoint opened", "url", n.grpcEndpoint)
	return nil
}

func (api *headerGovAPI) Vote(name string, value any) (string, error) {
	var (
		voter     = api.h.nodeAddress
		nextBlock = api.h.Chain.CurrentBlock().NumberU64() + 1
		gp        = api.h.GetParamSet(nextBlock)
		gMode     = gp.GovernanceMode
	)

	if gMode == "single" && voter != gp.GoverningNode {
		return "", ErrVotePermissionDenied
	}

	vote := headergov.NewVoteData(voter, name, value)
	if vote == nil {
		return "", ErrInvalidKeyValue
	}

	if gov.DeprecatedAt(vote.Name(), api.h.ChainConfig.Rules(new(big.Int).SetUint64(nextBlock))) {
		return "", ErrDeprecatedVote
	}

	err := api.h.checkConsistency(nextBlock, vote)
	if err != nil {
		return "", err
	}

	// TODO-kaiax: add removevalidator vote check

	api.h.PushMyVotes(vote)
	return "(kaiax) Your vote is prepared. It will be put into the block header or applied when your node generates a block as a proposer. Note that your vote may be duplicate.", nil
}
