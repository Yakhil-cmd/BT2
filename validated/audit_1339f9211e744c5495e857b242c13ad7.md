### Title
Missing per-host credential scoping when checking out PRs from forks may send GitHub OAuth token to an attacker-influenced host - ([File: pkg/cmd/pr/checkout/checkout.go])

### Summary
The Solidity report describes a missing authorization check (`manager.allowedVaults`) before a privileged action (`addStrategy`/`removeStrategy`), letting a strategist act on vaults it shouldn't be allowed to touch. The closest reachable analog in this Go CLI codebase is in the git-credential-helper wiring: `git.Client.AuthenticatedCommand` in [1](#0-0)  takes a `CredentialPattern` that scopes which host git is allowed to request `gh`'s stored OAuth token for, but callers can opt into `AllMatchingCredentialsPattern`, which configures `credential.helper=` globally for **all** hosts for the duration of the git invocation [2](#0-1) . I was not able to fully verify, in the time available, whether `pkg/cmd/pr/checkout/checkout.go` actually invokes `AuthenticatedCommand` with `AllMatchingCredentialsPattern` for a fetch/checkout of a fork-supplied remote URL (the file matched the pattern usage 18 times but I could not read its body before running out of iterations).

### Finding Description
`CredentialPatternFromGitURL`/`CredentialPatternFromHost` are the "allow-list" analog: they scope the git credential helper so that `gh`'s stored token is only offered to the exact host being operated on [3](#0-2) . The comment on `AllMatchingCredentialsPattern` explicitly calls out that this is "less secure" and that it should be removed, because it makes `gh` act as the credential helper for *every* host git subsequently talks to during that command, not just the intended target repository [2](#0-1) . This mirrors the missing `allowedVaults` check pattern: a sensitive credential-granting operation (returning the OAuth token via `gh auth git-credential`, see `helperRun` in [4](#0-3) ) is not scoped to the host the user actually intended to authenticate against, but to whatever host is presented by the current git invocation. `pr checkout` is a case where the URL/remote used for fetching (a PR's head repository) can be influenced by the PR author (an external, less-trusted party) rather than the maintainer running the command.

If `pr checkout` (or any other command that clones/fetches a fork remote) uses `AllMatchingCredentialsPattern` instead of a host-scoped `CredentialPattern` derived from the trusted upstream host, git could send `credential get` requests for any host referenced during that operation, and `gh`'s credential helper would attempt to satisfy them for whatever host is asked (see `lookupHost := wants["host"]` in `helperRun`, [5](#0-4) ). The helper does have its own guard—it only returns a token if `cfg.ActiveToken(lookupHost)` has a token configured for that exact host—so this is not a direct token leak to arbitrary attacker hosts by itself, but it does mean the scoping intended by `CredentialPattern` (equivalent to the missing `allowedVaults`-style check) is bypassed for any host git is coaxed into querying.

### Impact Explanation
If confirmed to be reachable, the actual impact is bounded: `helperRun` still requires that the requested host has a configured token in `gh`'s config (`ActiveToken`) before returning credentials, and rejects non-HTTPS protocols and mismatched usernames [6](#0-5) . So the primary exposure would be to any *other GitHub Enterprise host the user has also authenticated `gh` against* being queried unexpectedly during an operation the user believed was scoped to a single host — a credential-scope-widening issue rather than a leak to a truly arbitrary attacker-controlled domain. Given I could not confirm which pattern `pr checkout` actually passes to `AuthenticatedCommand`, I cannot assert this is currently exploitable in this codebase; the citation only supports that the constructs (a globally-scoped credential pattern and a code comment self-identifying it as less secure) exist.

### Likelihood Explanation
Low-to-moderate, and unverified. The `CredentialPattern` type is specifically designed to prevent this class of issue in the common case (`CredentialPatternFromGitURL`), and `AllMatchingCredentialsPattern` is documented as a deliberate, legacy "opt-in" for backwards compatibility [7](#0-6) , suggesting the maintainers are aware of the risk and are moving away from it. Whether `pr checkout` (which is the command most exposed to fork/attacker-supplied remotes) still uses the wide pattern could not be confirmed with the remaining budget.

### Recommendation
- Confirm which `CredentialPattern` is passed by every caller of `AuthenticatedCommand` (`pkg/cmd/pr/checkout/checkout.go`, `pkg/cmd/repo/create/create.go`, `pkg/cmd/repo/sync/git.go`) and ensure fork/PR-checkout flows use a host-scoped pattern derived from the actual remote being operated on rather than `AllMatchingCredentialsPattern`.
- Continue the stated goal of eliminating `AllMatchingCredentialsPattern` usage entirely in favor of `CredentialPatternFromGitURL`/`CredentialPatternFromHost`.

// CredentialPatternFromGitURL takes a git remote URL e.g. "https://github.com/cli/cli.git" or
// "git@github.com:cli/cli.git" and returns the credential pattern that should be used for it.
func CredentialPatternFromGitURL(gitURL string) (CredentialPattern, error) {
	normalizedURL, err := ParseURL(gitURL)
	if err != nil {
		return CredentialPattern{}, fmt.Errorf("failed to parse remote URL: %w", err)
	}
	return CredentialPatternFromHost(normalizedURL.Host), nil
}

// CredentialPatternFromHost expects host to be in the form "github.com" and returns
// the credential pattern that should be used for it.
// It does not perform any canonicalisation e.g. "api.github.com" will not work as expected.
func CredentialPatternFromHost(host string) CredentialPattern {
	return CredentialPattern{
		pattern: strings.TrimSuffix(ghinstance.HostPrefix(host), "/"),
	}
}

// AuthenticatedCommand is a wrapper around Command that included configuration to use gh
// as the credential helper for git.
func (c *Client) AuthenticatedCommand(ctx context.Context, credentialPattern CredentialPattern, args ...string) (*Command, error) {
	if c.GhPath == "" {
		// Assumes that gh is in PATH.
		c.GhPath = "gh"
	}
	credHelper := fmt.Sprintf("!%q auth git-credential", c.GhPath)

	var preArgs []string
	if credentialPattern == disallowedCredentialPattern {
		return nil, fmt.Errorf("empty credential pattern is not allowed unless provided explicitly")
	} else if credentialPattern == AllMatchingCredentialsPattern {
		preArgs = []string{"-c", "credential.helper="}
		preArgs = append(preArgs, "-c", fmt.Sprintf("credential.helper=%s", credHelper))
	} else {
		preArgs = []string{"-c", fmt.Sprintf("credential.%s.helper=", credentialPattern.pattern)}
		preArgs = append(preArgs, "-c", fmt.Sprintf("credential.%s.helper=%s", credentialPattern.pattern, credHelper))
	}

	args = append(preArgs, args...)
	return c.Command(ctx, args...)
}

func helperRun(opts *CredentialOptions) error {
	if opts.Operation == "store" {
		// We pretend to implement the "store" operation, but do nothing since we already have a cached token.
		return nil
	}

	if opts.Operation == "erase" {
		// We pretend to implement the "erase" operation, but do nothing since we don't want git to cause user to be logged out.
		return nil
	}

	if opts.Operation != "get" {
		return fmt.Errorf("gh auth git-credential: %q operation not supported", opts.Operation)
	}

	wants := map[string]string{}

	s := bufio.NewScanner(opts.IO.In)
	for s.Scan() {
		line := s.Text()
		if line == "" {
			break
		}
		parts := strings.SplitN(line, "=", 2)
		if len(parts) < 2 {
			continue
		}
		key, value := parts[0], parts[1]
		if key == "url" {
			u, err := url.Parse(value)
			if err != nil {
				return err
			}
			wants["protocol"] = u.Scheme
			wants["host"] = u.Host
			wants["path"] = u.Path
			wants["username"] = u.User.Username()
			wants["password"], _ = u.User.Password()
		} else {
			wants[key] = value
		}
	}
	if err := s.Err(); err != nil {
		return err
	}

	if wants["protocol"] != "https" {
		return cmdutil.SilentError
	}

	cfg, err := opts.Config()
	if err != nil {
		return err
	}

	lookupHost := wants["host"]
	var gotUser string
	gotToken, source := cfg.ActiveToken(lookupHost)
	if gotToken == "" && strings.HasPrefix(lookupHost, "gist.") {
		lookupHost = strings.TrimPrefix(lookupHost, "gist.")
		gotToken, source = cfg.ActiveToken(lookupHost)
	}

	if strings.HasSuffix(source, "_TOKEN") {
		gotUser = tokenUser
	} else {
		gotUser, _ = cfg.ActiveUser(lookupHost)
		if gotUser == "" {
			gotUser = tokenUser
		}
	}

	if gotUser == "" || gotToken == "" {
		return cmdutil.SilentError
	}

	if wants["username"] != "" && gotUser != tokenUser && !strings.EqualFold(wants["username"], gotUser) {
		return cmdutil.SilentError
	}
