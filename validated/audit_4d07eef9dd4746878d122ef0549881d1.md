## Title
Unauthenticated SSRF via attacker-controlled ArbStore URL in `arbiters.getArbstoreInfo`/`getInfo` and `arbiter_contract.appeal`/`getAppealFee` - (File: arbiters.js, arbiter_contract.js)

### Summary
The external report describes an SSRF where a caller-supplied URL is fetched server-side without validating that it doesn't point to internal/loopback/link-local/cloud-metadata addresses, and the guard that would prevent this exists but is off by default. In ocore, `arbiters.js` and `arbiter_contract.js` contain a stronger analog: URLs used to contact an "ArbStore" (arbiter's HTTP service) are fetched via plain `http.get`/`http.request` with **no address-validation guard at all** (not even a disabled-by-default one), and the URL is ultimately controlled by whichever address a user's counterparty proposes as arbiter in a contract.

### Finding Description
`requestInfoFromArbStore` performs an unauthenticated `http.get(url, ...)` call and returns the parsed JSON response with no restriction on the destination host/IP: [1](#0-0) 

This function is invoked from `getInfo` and `getArbstoreInfo`, both of which resolve the fetch target via `device.requestFromHub("hub/get_arbstore_url", address, ...)` — i.e., the URL string associated with an `arbiter_address` is obtained from the hub and only checked for being a "nonempty string", never validated as pointing to a safe external host: [2](#0-1) [3](#0-2) 

Similarly, `arbiter_contract.js`'s `appeal()` and `getAppealFee()` retrieve an `arbstore` URL through the same `hub/get_arbstore_url`/`hub/get_arbstore_url_by_address` calls and then POST attacker-influenceable contract data to it via a hand-rolled `httpRequest` helper built on Node's raw `http` module, again with zero host/IP filtering: [4](#0-3) [5](#0-4) 

Because an "arbiter address" is just any Byteball/Obyte address that registers itself with a hub together with an arbitrary ArbStore URL, a malicious counterparty who proposes themselves (or a colluding address) as the arbiter in an arbiter contract can cause the victim's own node/wallet to silently perform outbound HTTP requests (and in `appeal()`, POST JSON containing contract details) to any URL the attacker registers — including `http://127.0.0.1/...`, internal service ports, or `http://169.254.169.254/...` cloud metadata endpoints.

### Impact Explanation
This is reachable by an unprivileged private-payment counterparty: any user who negotiates/offers or accepts an arbiter contract naming a malicious arbiter address will have their wallet node issue outbound HTTP requests to attacker-chosen destinations whenever it looks up arbiter info (`getInfo`/`getArbstoreInfo`, used during contract setup/eligibility display) or later interacts with the arbitration flow (`appeal`, `getAppealFee`). Unlike the reported `mcp-searxng` bug, here there is no SSRF guard at all — not even one disabled by default — so internal services and cloud metadata can be reached and their responses returned into the wallet UI/state, and in the `appeal` case sensitive contract details (title, text, addresses, amount, asset) are POSTed to the attacker-controlled endpoint, which is itself an information-disclosure/exfiltration channel.

### Likelihood Explanation
Likelihood is high for any user who engages in arbiter-mediated contracts with an untrusted counterparty: registering a hub-facing "arbstore URL" is fully under the control of whoever controls the arbiter address, requiring no special privileges, and lookup happens automatically as part of the normal arbiter-contract workflow (choosing/displaying an arbiter, requesting a fee, or appealing).

### Recommendation
Before dereferencing any `arbstore_url` returned by the hub, resolve and validate the destination host: reject loopback (127.0.0.0/8, ::1), link-local/metadata (169.254.0.0/16, fd00::/8, fe80::/10), 0.0.0.0/8, and RFC1918/ULA private ranges; re-validate on every redirect hop rather than trusting Node's default `follow-redirects` behavior; and require `https://` with a public, non-IP-literal-only host. Apply this validation uniformly in `arbiters.js` (`requestInfoFromArbStore`) and `arbiter_contract.js` (`httpRequest`), fail closed by default rather than making it opt-in.

### Proof of Concept
1. Attacker registers with a hub as an arbiter, setting the hub-served ArbStore URL for their `arbiter_address` to `http://169.254.169.254/latest/meta-data/` (or `http://127.0.0.1:<internal-port>/`).
2. Victim opens/negotiates an arbiter contract naming the attacker's address as arbiter, or simply looks up the attacker's arbiter profile (`arbiters.getInfo`/`getArbstoreInfo`).
3. Victim's node calls `device.requestFromHub("hub/get_arbstore_url", attacker_address, ...)`, receives the attacker's URL, and `requestInfoFromArbStore` performs `http.get(url + '/api/arbiter/' + address, ...)` — reaching the internal/metadata endpoint and returning its content to the caller.
4. If the contract proceeds to `appeal()`, the victim's node additionally POSTs the full contract JSON (title, text, addresses, amount, asset) to the same attacker-controlled endpoint via `httpRequest`. [6](#0-5) [7](#0-6)

function getInfo(address, cb) {
	cb = cb || function() {};
	db.query("SELECT device_pub_key, real_name FROM wallet_arbiters WHERE arbiter_address=?", [address], function(rows){
		if (rows.length && rows[0].real_name) { // request again if no real name
			cb(null, rows[0]);
		} else {
			device.requestFromHub("hub/get_arbstore_url", address, function(err, url){
				if (err) {
					return cb(err);
				}
				if (!validationUtils.isNonemptyString(url))
					return cb("invalid url received from hub");
				requestInfoFromArbStore(url+'/api/arbiter/'+address, function(err, info){
					if (err) {
						return cb(err);
					}
					if (!validationUtils.isNonemptyObject(info))
						return cb("invalid arbiter info received from arbstore");
					db.query("REPLACE INTO wallet_arbiters (arbiter_address, device_pub_key, real_name) VALUES (?, ?, ?)", [address, info.device_pub_key, info.real_name], function() {cb(null, info);});
				});
			});
		}
	});
}

function requestInfoFromArbStore(url, cb){
	http.get(url, function(resp){
		var data = '';
		resp.on('data', function(chunk){
			data += chunk;
		});
		resp.on('end', function(){
			try {
				cb(null, JSON.parse(data));
			} catch(ex) {
				cb(ex);
			}
		});
	}).on("error", cb);
}

function getArbstoreInfo(arbiter_address, cb) {
	if (!cb)
		return new Promise(function(resolve, reject){
			getArbstoreInfo(arbiter_address, function(err, info){
				if (err) return reject(err);
				resolve(info);
			});
		});
	if (arbStoreInfos[arbiter_address]) return cb(null, arbStoreInfos[arbiter_address]);
	device.requestFromHub("hub/get_arbstore_url", arbiter_address, function(err, url){
		if (err) {
			return cb(err);
		}
		if (!validationUtils.isNonemptyString(url))
			return cb("invalid url received from hub");
		requestInfoFromArbStore(url+'/api/get_info', function(err, info){
			if (err)
				return cb(err);
			if (!validationUtils.isNonemptyObject(info))
				return cb("invalid info received from arbstore");
			const cut = parseFloat(info.cut);
			if (!info.address || !validationUtils.isValidAddress(info.address) || isNaN(cut) || cut < 0 || cut >= 1) {
				return cb("malformed info received from ArbStore");
			}
			info.url = url;
			arbStoreInfos[arbiter_address] = info;
			cb(null, info);
		});
	});
}

function appeal(hash, cb) {
	getByHash(hash, function(objContract){
		if (objContract.status !== "dispute_resolved")
			return cb("contract can't be appealed");
		var command = "hub/get_arbstore_url";
		var address = objContract.arbiter_address;
		if (objContract.arbstore_address) {
			command = "hub/get_arbstore_url_by_address";
			address = objContract.arbstore_address;
		}
		device.requestFromHub(command, address, async function(err, url){
			if (err)
				return cb("can't get arbstore url:", err);
			err = await fillArbstoreAddresses(objContract);
			if (err)
				return cb(err);
			device.getOrGeneratePermanentPairingInfo(function(pairingInfo){
				var my_pairing_code = pairingInfo.device_pubkey + "@" + pairingInfo.hub + "#" + pairingInfo.pairing_secret;
				var data = JSON.stringify({
					contract_hash: hash,
					my_pairing_code: objContract.my_pairing_code,
					my_address: objContract.my_address,
					contract: {title: objContract.title, text: objContract.text, creation_date: objContract.creation_date, me_is_payer: objContract.me_is_payer, my_address: objContract.my_address, peer_address: objContract.peer_address, my_party_name: objContract.my_party_name, peer_party_name: objContract.peer_party_name, arbiter_address: objContract.arbiter_address, amount: objContract.amount, asset: objContract.asset},
				});
				httpRequest(url, "/api/appeal/new", data, function(err, resp) {
					if (err)
						return cb(err);
					setField(hash, "status", "in_appeal", function(objContract) {
						cb(null, resp, objContract);
					});
				});
			});
		});
	});
}

function getAppealFee(hash, cb) {
	getByHash(hash, function(objContract){
		var command = "hub/get_arbstore_url";
		var address = objContract.arbiter_address;
		if (objContract.arbstore_address) {
			command = "hub/get_arbstore_url_by_address";
			address = objContract.arbstore_address;
		}
		device.requestFromHub(command, address, function(err, url){
			if (err)
				return cb("can't get arbstore url:", err);
			httpRequest(url, "/api/get_appeal_fee", "", function(err, resp) {
				if (err)
					return cb(err);
				cb(null, resp);
			});
		});
	});
}

function httpRequest(host, path, data, cb) {
	var reqParams = Object.assign(url.parse(host),
		{
			path: path,
			method: "POST",
			headers: {
				"Content-Type": "application/json",
				"Content-Length": (new TextEncoder().encode(data)).length
			}
		}
	);
	var req = http.request(
		reqParams,
		function(resp){
			var data = "";
			resp.on("data", function(chunk){
				data += chunk;
			});
			resp.on("end", function(){
				try {
					data = JSON.parse(data);
					if (data.error) {
						return cb(data.error);
					}
					cb(null, data);
				} catch (e) {
					cb(e);
				}
			});
		}).on("error", cb);
	req.write(data);
	req.end();
}
