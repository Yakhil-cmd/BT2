### Title
Unlocked Map Iteration in `RemoveVotesAfter`/`RemoveGovAfter` Races with Concurrent `AddVote`/`AddGov`, Enabling Governance Map Corruption and Consensus Divergence — (`kaiax/gov/headergov/impl/rewind.go`)

### Summary

`RemoveVotesAfter` and `RemoveGovAfter` iterate over `h.groupedVotes` and `h.governances` respectively **without holding `h.mu`**, then acquire `h.mu` only inside the loop body to perform deletes. Concurrent calls to `AddVote` and `AddGov` (via `PostInsertBlock`) hold `h.mu` during their writes. Because the range loop itself is an unsynchronized read, the mutex provides no protection against the concurrent read in the rewind goroutine. This is a textbook Go data race: concurrent map read (unlocked range) + map write (locked `AddVote`/`AddGov`).

### Finding Description

**`RemoveVotesAfter`** — the outer range loop reads `h.groupedVotes` with no lock held: [1](#0-0) 

**`AddVote`** — concurrent writer holds `h.mu.Lock()` for the entire write: [2](#0-1) 

**`RemoveGovAfter`** — same pattern for `h.governances`: [3](#0-2) 

**`AddGov`** — concurrent writer holds `h.mu.Lock()`: [4](#0-3) 

The struct definition confirms both maps share a single `*sync.RWMutex`: [5](#0-4) 

### Impact Explanation

The corrupted `h.groupedVotes` map is consumed by `getExpectedGovernance` → `getVotesInEpoch`, which reads `h.groupedVotes` under `h.mu.RLock()`: [6](#0-5) [7](#0-6) 

`PrepareHeader` calls `getExpectedGovernance` to write the `Governance` field into the proposed block header: [8](#0-7) 

`VerifyGov` on every other node independently recomputes `getExpectedGovernance` and does a `reflect.DeepEqual` comparison: [9](#0-8) 

If the proposer's in-memory `h.groupedVotes` is silently corrupted by the race (stale entries retained or entries missing), its `getExpectedGovernance` diverges from every other node's, causing the proposed block to fail `VerifyGov` on all peers — **consensus divergence**. The corrupted `h.governances` map similarly corrupts `h.history`, which feeds `GetParamSet` used for reward and validator-set parameter lookups.

### Likelihood Explanation

`RewindDelete` is triggered by any chain-reorg event (receiving a competing chain from any peer — a fully permissionless P2P flow). `PostInsertBlock` runs concurrently as new blocks arrive. The blockchain engine does not serialize these two paths through a single lock before calling into the kaiax module. The race window is every reorg that overlaps with block insertion, which is a normal operational condition on a live network. Go's runtime map-write flag (`hashWriting`) catches the race only when the flag check and the concurrent access overlap exactly; when they don't, the map is silently corrupted rather than panicking.

### Recommendation

Acquire `h.mu.Lock()` **before** the range loop and hold it for the entire iteration, not just the delete:

```go
func (h *headerGovModule) RemoveVotesAfter(blockNum uint64) {
    h.mu.Lock()
    defer h.mu.Unlock()
    dirty := false
    for epochIdxIter, votes := range h.groupedVotes {
        for blockNumIter := range votes {
            if blockNumIter > blockNum {
                dirty = true
                delete(h.groupedVotes[epochIdxIter], blockNumIter)
                if len(h.groupedVotes[epochIdxIter]) == 0 {
                    delete(h.groupedVotes, epochIdxIter)
                }
            }
        }
    }
    // WriteVoteDataBlockNums must be called outside the lock
    if dirty {
        WriteVoteDataBlockNums(h.ChainKv, h.VoteBlockNums())
    }
}
```

Apply the same fix to `RemoveGovAfter`.

func (h *headerGovModule) getVotesInEpoch(epochIdx uint64) map[uint64]headergov.VoteData {
	pBorder := ReadLowestVoteScannedEpochIdx(h.ChainKv)
	if pBorder == nil {
		panic("lowest vote scanned epoch index must exist")
	}
	border := *pBorder

	if border <= epochIdx {
		logger.Debug("Scanning votes fastpath")
		votes := make(map[uint64]headergov.VoteData)

		h.mu.RLock()
		defer h.mu.RUnlock()
		maps.Copy(votes, h.groupedVotes[epochIdx])
		return votes
	} else {
		logger.Debug("Scanning votes slowpath")
		// Deduplicate concurrent slow-path scans of the same epoch.
		// The returned map is read-only for all callers, so sharing one instance is safe.
		votes, _, _ := h.scanGroup.Do(strconv.FormatUint(epochIdx, 10), func() (interface{}, error) {
			return h.scanAllVotesInEpoch(epochIdx), nil
		})
		return votes.(map[uint64]headergov.VoteData)
	}
}
