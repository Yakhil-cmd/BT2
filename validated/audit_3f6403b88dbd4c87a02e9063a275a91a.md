### Title
Spot AMM Price Checked Only at Tx-Pool Admission, Not at Block-Build Time, Allows Sandwich-Induced Proposer KAIA Loss — (`kaiax/gasless/impl/tx_pool.go`)

---

### Summary

The KIP-247 gasless module validates a swap transaction's `amountIn` against the current AMM spot price (`GetAmountIn`) only once, at tx-pool admission. At block-building time the bundle is re-validated through `IsExecutable` / `VerifyExecutable`, which performs only static checks and never re-queries the AMM. An attacker who manipulates the Uniswap V2 pool price between admission and execution causes the `SwapTx` to revert on-chain while the proposer's `LendTx` (which transfers KAIA to the user unconditionally) has already been committed, resulting in an unrecovered KAIA loss for the proposer.

---

### Finding Description

**Gasless flow recap**

The block proposer's node automatically prepends a `LendTx` that transfers `lendAmount = ApproveTx.Fee() + SwapTx.Fee()` KAIA to the user. The bundle `[LendTx, ApproveTx, SwapTx]` is then executed atomically. `SwapTx` calls `GaslessSwapRouter.swapForGas(token, amountIn, minAmountOut, amountRepay, deadline)`, which swaps the user's tokens for KAIA via Uniswap V2 and repays the proposer. The contract enforces `minAmountOut` as a hard slippage guard; if the actual output is below `minAmountOut`, the swap reverts.

**Admission-time price check (the only AMM check)** [1](#0-0) 

`checkBalanceForSwap` calls `routerContract.GetAmountIn(nil, token, minAmountOut)` against the current chain state and rejects the tx if `amountIn < requiredAmountIn`. This snapshot is taken once, at the moment the tx enters the pool.

**Block-build time validation — no AMM re-check** [2](#0-1) 

`isSwapTxReady` calls `g.IsExecutable(approveTx, swapTx)`, which delegates to `VerifyExecutable`. [3](#0-2) 

`VerifyExecutable` checks sender identity, nonce ordering (SP3), and the fixed `repayAmount` formula (SP4). It never calls `GetAmountIn` or any AMM view. The AMM price is therefore **not re-validated** before the proposer commits the `LendTx`.

**LendTx is unconditional** [4](#0-3) 

The `LendTx` is a plain KAIA transfer (`TxTypeEthereumDynamicFee`, `value = lendAmount`). It executes before `SwapTx` and has no rollback mechanism if `SwapTx` later reverts.

**`repayAmount` formula** [5](#0-4) 

`repayAmount = R1 + R2 + R3` where R1 = LendTx fee, R2 = ApproveTx fee, R3 = SwapTx fee. All three are fixed at tx-signing time and are independent of the AMM price. The proposer's recovery depends entirely on the `SwapTx` succeeding.

---

### Impact Explanation

When `SwapTx` reverts:

1. `LendTx` has already transferred `lendAmount` KAIA from the proposer to the user — this is irreversible.
2. `ApproveTx` has already executed — the user retains their tokens.
3. The user keeps both the lent KAIA and their tokens; the proposer is unrepaid.

The proposer loses `lendAmount = ApproveTx.Fee() + SwapTx.Fee()` KAIA per failed bundle. With typical gas limits (100 k + 500 k gas) at 50 Gkei, this is ~0.03 KAIA per bundle. Repeated across many bundles or with higher gas prices the loss scales linearly. The corrupted value is the proposer's KAIA balance — a direct, unauthorized transfer of system-managed funds.

---

### Likelihood Explanation

The attack requires only standard on-chain transactions:

1. Observe a gasless bundle in the mempool with `minAmountOut = amountRepay + small_margin`.
2. In the block immediately before the proposer's block, submit a large token→KAIA swap on the same Uniswap V2 pair, moving the price so that `amountIn` tokens yield < `minAmountOut` KAIA.
3. The proposer's node re-evaluates the bundle via `isSwapTxReady` → `IsExecutable` → `VerifyExecutable` (no AMM check) and includes it.
4. `LendTx` executes; `SwapTx` reverts on the `minAmountOut` guard.
5. Back-run: restore the price, collect arbitrage profit.

The attacker's profit from the AMM manipulation (arbitrage) can exceed the cost of the manipulation, making the attack economically rational. No privileged access, no key compromise, and no validator collusion is required.

---

### Recommendation

Re-validate the AMM price at block-building time, not only at tx-pool admission. Concretely, inside `isSwapTxReady` (or a new pre-bundle-inclusion hook), repeat the `GetAmountIn` check against the current head state before the proposer commits the `LendTx`. If `swapArgs.AmountIn < requiredAmountIn` at build time, drop the bundle from the candidate set rather than including it. This mirrors the admission-time guard and closes the window between price snapshot and execution.

Alternatively, the `LendTx` value could be made conditional on the swap succeeding (e.g., via a smart-contract escrow that releases funds only after a successful `SwapTx`), but that requires a more significant protocol redesign.

---

### Proof of Concept

```
Block N-1 (attacker):
  - AttackerSwapTx: swap large amount of Token → KAIA on the Uniswap V2 pair
    used by GaslessSwapRouter, moving the price so that
    amountIn tokens now yield < minAmountOut KAIA.

Block N (proposer, automatic bundle inclusion):
  1. LendTx:    proposer → user,  value = lendAmount KAIA  ✓ executes
  2. ApproveTx: user approves GaslessSwapRouter             ✓ executes
  3. SwapTx:    GaslessSwapRouter.swapForGas(...)
                  → Uniswap swap output < minAmountOut
                  → REVERT                                  ✗ reverts

Block N (attacker, after bundle):
  - AttackerRestoreTx: swap KAIA → Token, restoring price,
    collecting arbitrage profit.

Result:
  - Proposer balance: -lendAmount KAIA (unrecovered)
  - User balance:     +lendAmount KAIA (kept), tokens unchanged
  - Attacker balance: +arbitrage profit
```

The root cause is the missing AMM re-validation in `isSwapTxReady` / `VerifyExecutable` at block-build time, located in `kaiax/gasless/impl/tx_pool.go` and `kaiax/gasless/impl/getter.go`. [6](#0-5) [7](#0-6)

func (g *GaslessModule) checkBalanceForSwap(swapArgs *SwapArgs, swapNonce uint64) error {
	token := swapArgs.Token
	bc := backends.NewBlockchainContractBackend(g.Chain, nil, nil)

	g.gaslessInfoMu.RLock()
	swapRouter := g.swapRouter
	g.gaslessInfoMu.RUnlock()

	// tx.minAmountOut >= tx.amountRepay
	minAmountOut := swapArgs.MinAmountOut
	amountRepay := swapArgs.AmountRepay

	}

		if g.getCurrentHasCode(swapArgs.Sender) {

		}

		// tx.amountIn >= gsr.getAmountIn(minAmountOut)

		if err != nil {
			return err
		}

			return err

			return fmt.Errorf("insufficient amountIn: have=%s, want=%s", swapArgs.AmountIn.String(), requiredAmountIn.String())
		}
	}

// isSwapTxReady assumes that the caller checked `g.IsSwapTx(swapTx)`
func (g *GaslessModule) isSwapTxReady(swapTx, prevTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, swapTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	var approveTx *types.Transaction
	if swapTx.Nonce() == nonce {
		approveTx = nil
	} else if swapTx.Nonce() == nonce+1 {
		if prevTx == nil || !g.IsApproveTx(prevTx) {
			return false
		}
		approveTx = prevTx
	} else {
		return false
	}

	return g.IsExecutable(approveTx, swapTx)
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

func repayAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	// R1 = LendTx.Fee() = SwapTx.GasPrice() * TxGas
	r1 := new(big.Int).Mul(swapTx.GasPrice(), new(big.Int).SetUint64(params.TxGas))

	// RepayAmount = R1 + R2 + R3
	return new(big.Int).Add(r1, lendAmount(approveTxOrNil, swapTx))
}
