### Title
Path traversal via unsanitized release asset name in `gh release download` writes files outside destination directory - ([File: pkg/cmd/release/download/download.go])

### Summary
`gh release download` fetches the list of assets for a GitHub release from the API and, for each asset whose name matches the requested pattern, streams the asset content into a local file built by naively joining the user's destination directory with the asset's `name` field. Unlike the artifact-download code path (`pkg/cmd/run/download`), which validates joined paths with `safepaths.Absolute.Join` and rejects any traversal attempt [1](#0-0) , the release-asset download path performs no such validation on the asset `Name` before it is used to construct a filesystem path.

### Finding Description
In `downloadRun`, each release asset's `Name` is taken directly from the GitHub API response and, aside from a check for Windows-reserved filenames, is passed unmodified into `downloadAsset` as the `fileName` used for writing to disk: [2](#0-1) 

`downloadAsset` eventually calls `dest.Copy(fileName, resp.Body)`: [3](#0-2) 

`Copy` computes the destination path via `makePath`, which is a plain `filepath.Join(w.dir, name)` with **no path-traversal check, no `filepath.Clean`/`filepath.Base` sanitization, and no confinement to `w.dir`**: [4](#0-3) 

This mirrors the root cause of the GitLab report: an attacker-controlled identifier (there, the cache `key`; here, the release asset `Name`, which is fully controlled by whoever publishes the release/asset) is concatenated into a filesystem/URL path with no traversal guard, allowing the write location to be moved outside the intended base directory. The codebase has clearly already recognized this exact class of bug and fixed it in the adjacent `gh run download` and `internal/zip`/`internal/safepaths` code (`safepaths.Absolute.Join` returns a `PathTraversalError` when a joined path escapes the base) [5](#0-4) , but the release-download destination writer was never migrated to use `safepaths`.

### Impact Explanation
If a user runs `gh release download` against a repository whose releases are controlled by an attacker (e.g., a malicious or compromised public repo, or a repo the victim collaborates on), the attacker can publish a release asset with a `name` such as `../../.ssh/authorized_keys` or `../../.bashrc`. When the victim downloads all assets (or a pattern that matches the malicious asset), `gh` will write attacker-supplied content to a path outside the chosen `--dir`/current working directory, potentially overwriting sensitive files reachable by the invoking user — a file-write-outside-intended-path primitive that can lead to code execution (e.g., overwriting shell startup files, SSH authorized_keys, or files later executed by CI).

### Likelihood Explanation
Exploitation only requires the victim to run `gh release download` (a routine command) against a release published by the attacker; no elevated privileges, MITM, or leaked tokens are needed. The only uncertainty is whether the GitHub release/asset upload APIs currently reject `name` values containing path-traversal sequences (`../`) server-side — the `gh` client code itself performs no such validation, so the client is unconditionally exposed to any server or asset name the API returns.

### Recommendation
Sanitize/confine the asset `name` before constructing a local path in `destinationWriter.makePath`/`Copy` — e.g., reuse `internal/safepaths.Absolute.Join` (as already done in `pkg/cmd/run/download`) or at minimum apply `filepath.Base` and reject any resulting path that is not a subpath of the destination directory, returning an error identical in spirit to `PathTraversalError`.

### Proof of Concept
1. Attacker creates/controls a repository and publishes a release with an asset whose `name` field (as returned by the Releases API) is `../../evil.sh` (or any traversal sequence not blocked by the Assets API).
2. Victim runs: `gh release download -R attacker/repo --dir ./safe-output`
3. `downloadRun` iterates `release.Assets`, includes the malicious asset (no traversal check, only a Windows-reserved-name check) [2](#0-1) , and `downloadAsset` → `dest.Copy` writes the attacker's content to `filepath.Join("./safe-output", "../../evil.sh")`, landing the file two directories above the intended destination [6](#0-5) .

func downloadAsset(dest *destinationWriter, httpClient *http.Client, assetURL safeurl.SafeURL, fileName string, isArchive bool) error {
	if err := dest.Check(fileName); err != nil {
		return err
	}

	req, err := http.NewRequest("GET", assetURL.String(), nil)
	if err != nil {
		return err
	}

	req.Header.Set("Accept", "application/octet-stream")
	if isArchive {
		// adding application/json to Accept header due to a bug in the zipball/tarball API endpoint that makes it mandatory
		req.Header.Set("Accept", "application/octet-stream, application/json")

		// override HTTP redirect logic to avoid "legacy" Codeload resources
		oldClient := *httpClient
		httpClient = &oldClient
		httpClient.CheckRedirect = func(req *http.Request, via []*http.Request) error {
			if len(via) == 1 {
				req.URL.Path = removeLegacyFromCodeloadPath(req.URL.Path)
			}
			return nil
		}
	}

	resp, err := httpClient.Do(req)
	if err != nil {
		return err
	}
	defer resp.Body.Close()

	if resp.StatusCode > 299 {
		return api.HandleHTTPError(resp)
	}

	if len(fileName) == 0 {
		contentDisposition := resp.Header.Get("Content-Disposition")

		_, params, err := mime.ParseMediaType(contentDisposition)
		if err != nil {
			return fmt.Errorf("unable to parse file name of archive: %w", err)
		}
		if serverFileName, ok := params["filename"]; ok {
			fileName = filepath.Base(serverFileName)
		} else {
			return errors.New("unable to determine file name of archive")
		}
	}

	return dest.Copy(fileName, resp.Body)
}

func (w destinationWriter) makePath(name string) string {
	if w.file == "" {
		return filepath.Join(w.dir, name)
	}
	return w.file
}

// Check returns an error if a file already exists at destination
func (w destinationWriter) Check(name string) error {
	if name == "" {
		// skip check as file name will only be known after the API request
		return nil
	}
	fp := w.makePath(name)
	if fp == "-" {
		// writing to stdout should always proceed
		return nil
	}
	return w.check(fp)
}

func (w destinationWriter) check(fp string) error {
	if _, err := os.Stat(fp); err == nil {
		if w.skipExisting {
			return errSkipped
		}
		if !w.overwrite {
			return fmt.Errorf(
				"%s already exists (use `--clobber` to overwrite file or `--skip-existing` to skip file)",
				fp,
			)
		}
	}
	return nil
}

// Copy writes the data from r into a file specified by name.
func (w destinationWriter) Copy(name string, r io.Reader) (copyErr error) {
	fp := w.makePath(name)
	if fp == "-" {
		if w.allowEscapes {
			_, copyErr = io.Copy(w.stdout, r)
			return
		}
		copyErr = iostreams.CopyGuardedContent(w.stdout, r, w.isTTY)
		if binErr, ok := errors.AsType[iostreams.BinaryTerminalError](copyErr); ok {
			copyErr = fmt.Errorf("%w; use `--output` to save it to a file, or pass --allow-escape-sequences to output it anyway", binErr)
		} else if errors.Is(copyErr, iostreams.ErrEscapeSequence) {
			copyErr = errors.New("the asset contains terminal escape sequences; use `--output` to save it to a file, or pass --allow-escape-sequences to output it anyway")
		}
		return
	}
	if copyErr = w.check(fp); copyErr != nil {
		return
	}

	if dir := filepath.Dir(fp); dir != "." {
		if copyErr = os.MkdirAll(dir, 0755); copyErr != nil {
			return
		}
	}

	var f *os.File
	if f, copyErr = os.OpenFile(fp, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, 0644); copyErr != nil {
		return
	}

	defer func() {
		if err := f.Close(); copyErr == nil && err != nil {
			copyErr = err
		}
	}()

	_, copyErr = io.Copy(f, r)
	return
}

func (a Absolute) Join(elem ...string) (Absolute, error) {
	joinedAbsolutePath, err := ParseAbsolute(filepath.Join(append([]string{a.path}, elem...)...))
	if err != nil {
		return Absolute{}, fmt.Errorf("failed to parse joined path: %w", err)
	}

	isSubpath, err := joinedAbsolutePath.isSubpathOf(a)
	if err != nil {
		return Absolute{}, err
	}

	if !isSubpath {
		return Absolute{}, PathTraversalError{
			Base:  a,
			Elems: elem,
		}
	}

	return joinedAbsolutePath, nil
}
