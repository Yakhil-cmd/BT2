This confirms the vulnerability. The pattern is clear: other download code paths in this same codebase (`pkg/cmd/run/download/download.go`, `internal/zip/zip.go`, `pkg/cmd/copilot/copilot.go`, `internal/skills/installer/installer.go`) consistently use `safepaths.Absolute.Join` to reject path traversal in attacker-controlled names, but `pkg/cmd/release/download/download.go`'s `destinationWriter.makePath` uses plain `filepath.Join(w.dir, name)` with no such check, and release asset `Name` is fully attacker-controlled via the public Releases API.

### Title
Release asset `Name` allows path traversal write outside download directory - (File: pkg/cmd/release/download/download.go)

### Summary
`gh release download` writes each asset to a path built via `destinationWriter.makePath`, which does `filepath.Join(w.dir, name)` using the release asset's `Name` field verbatim, without any traversal check. An unprivileged attacker who publishes a public release with an asset named e.g. `../../.bashrc` can cause the victim's `gh release download` to write/overwrite files outside the intended destination directory.

### Finding Description
In `downloadRun` (`pkg/cmd/release/download/download.go:196-208`), for the non-archive case, assets are taken directly from `release.Assets`, and each `shared.ReleaseAsset.Name` (sourced from the GitHub Releases API `name` field, fully controlled by whoever publishes the release) is passed as `downloadTarget.name` (`pkg/cmd/release/download/download.go:238-243`) with no sanitization beyond a pattern match (`--pattern`) and a Windows-reserved-filename check (`isWindowsReservedFilename`, lines 203-205), neither of which blocks path separators or `..`.

`downloadAsset` calls `dest.Copy(fileName, resp.Body)` (line 350), which calls `destinationWriter.makePath(name)`:
```go
func (w destinationWriter) makePath(name string) string {
	if w.file == "" {
		return filepath.Join(w.dir, name)
	}
	return w.file
}
``` [1](#0-0) 

`filepath.Join` normalizes `..` segments syntactically but does not confine the result to `w.dir` — if `name` contains enough `../` segments (or an absolute path-like component after join semantics), the resulting `fp` can point anywhere on the filesystem the process user can write to. `Copy` then does `os.MkdirAll(dir, 0755)` and `os.OpenFile(fp, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, 0644)` (`pkg/cmd/release/download/download.go:435-442`), writing/truncating whatever file `fp` resolves to.

This is exactly the class of bug the codebase's `internal/safepaths` package (`internal/safepaths/absolute.go`) was built to prevent — `Absolute.Join` explicitly rejects any join that would escape the base directory, returning a `PathTraversalError`. This pattern is used consistently elsewhere for attacker-controlled names: `pkg/cmd/run/download/download.go:179-188` uses `absoluteDestinationDir.Join(a.Name)` and rejects traversal (there is even a dedicated test `Test_runDownload/"handling artifact name with path traversal exploit"` at `pkg/cmd/run/download/download_test.go:687-714` for artifact names), `internal/zip/zip.go:24-33` uses `destDir.Join(zf.Name)` when extracting zip archives, and `internal/skills/installer/installer.go:195-226` / `pkg/cmd/copilot/copilot.go:385-401,420-438` do the same for skill/archive extraction. The release-download code path is the outlier that still uses raw `filepath.Join` on an attacker-supplied name.

### Impact Explanation
This is an arbitrary file write/overwrite outside the intended directory (`w.dir`), triggered purely by the victim running `gh release download` (or `gh release download <tag>` without `--pattern`, since only pattern-matched assets are otherwise filtered, and pattern matching does not prevent traversal within a matched name) against a release published by the attacker. Depending on traversal depth and OS, this can overwrite files such as shell startup files (`.bashrc`, `.profile`), SSH config, cron files, or other files reachable by the invoking user — a real file-write-outside-intended-path impact.

### Likelihood Explanation
Feasible and repeatable: an attacker only needs write/publish access to a public repository they control (fork, personal repo, or any repo where they can create releases) and to set an asset's display `name` field via the GitHub Releases API/UI to a traversal string such as `../../.bashrc`. The victim need only run a plain `gh release download` (no `--pattern`/`--output`) against that release for the write to occur — no special privileges, MITM, or social engineering beyond getting the victim to run the standard download command against the attacker's release.

### Recommendation
In `destinationWriter.makePath` (or before calling `Copy`/`Check`), validate `name` against `w.dir` using the existing `internal/safepaths` package, mirroring `pkg/cmd/run/download/download.go`'s use of `safepaths.Absolute.Join`: parse `w.dir` via `safepaths.ParseAbsolute`, then `Join(name)`, and reject (or error) on `safepaths.PathTraversalError` instead of writing the file.

	fp := w.makePath(name)
	if fp == "-" {
		if w.allowEscapes {
			_, copyErr = io.Copy(w.stdout, r)
			return
		}
		copyErr = iostreams.CopyGuardedContent(w.stdout, r, w.isTTY)
		if binErr, ok := errors.AsType[iostreams.BinaryTerminalError](copyErr); ok {
			copyErr = fmt.Errorf("%w; use `--output` to save it to a file, or pass --allow-escape-sequences to output it anyway", binErr)
		} else if errors.Is(copyErr, iostreams.ErrEscapeSequence) {
			copyErr = errors.New("the asset contains terminal escape sequences; use `--output` to save it to a file, or pass --allow-escape-sequences to output it anyway")
		}
		return
	}
	if copyErr = w.check(fp); copyErr != nil {
		return
	}

	if dir := filepath.Dir(fp); dir != "." {
		if copyErr = os.MkdirAll(dir, 0755); copyErr != nil {
			return
		}
	}

	var f *os.File
	if f, copyErr = os.OpenFile(fp, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, 0644); copyErr != nil {
		return
	}

	defer func() {
		if err := f.Close(); copyErr == nil && err != nil {
			copyErr = err
		}
	}()

	_, copyErr = io.Copy(f, r)
	return
}

// Join an absolute path with elements to create a new Absolute path, or error.
// A PathTraversalError will be returned if the joined path would traverse outside of
// the base Absolute path. Note that this does not handle symlinks.
func (a Absolute) Join(elem ...string) (Absolute, error) {
	joinedAbsolutePath, err := ParseAbsolute(filepath.Join(append([]string{a.path}, elem...)...))
	if err != nil {
		return Absolute{}, fmt.Errorf("failed to parse joined path: %w", err)
	}

	isSubpath, err := joinedAbsolutePath.isSubpathOf(a)
	if err != nil {
		return Absolute{}, err
	}

	if !isSubpath {
		return Absolute{}, PathTraversalError{
			Base:  a,
			Elems: elem,
		}
	}

	return joinedAbsolutePath, nil
}
