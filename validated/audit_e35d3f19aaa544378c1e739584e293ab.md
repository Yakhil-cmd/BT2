### Title
Unauthenticated NType Spoofing in PING Handler Inserts Attacker Node into All Four Per-Type Discovery Storages — (`networks/p2p/discover/udp.go`, `table_data.go`)

### Summary

A remote peer can send a UDP PING packet with `req.From.NType = NodeTypeBN`. The victim node accepts this field without any validation, constructs a `Node` with `NType=NodeTypeBN`, and — after a trivial PONG exchange — inserts it into all four per-type discovery storages (CN, PN, EN, BN). An attacker operating multiple such nodes can poison `RandomNodes` for every node type, eclipsing the victim's peer set and enabling delivery of attacker-crafted blocks or sync data.

### Finding Description

`ping.handle` extracts `req.From.NType` from the incoming PING packet and passes it verbatim to `t.bond`:

```go
// udp.go:778
go t.bond(true, fromID, from, req.From.TCP, req.From.NType)
```

`t.bond` constructs a `Node` with the attacker-supplied type and calls `tab.Bond`:

```go
// udp.go:365-368
func (t *udp) bond(pinged bool, id NodeID, addr *net.UDPAddr, tcpPort uint16, nType NodeType) {
    n := NewNode(id, addr.IP, uint16(addr.Port), tcpPort, nil, nType)
    t.tab.Bond(pinged, n)
}
```

`tab.Bond` has one inbound guard — `if pinged && !tab.initialized()` — which only blocks before the table's initial seeding completes. Once initialized (normal operating state), any inbound PING proceeds to `pingpong` and then `addNode`.

`addNode` contains the vulnerable branch:

```go
// table_data.go:75-86
func (tab *Table2) addNode(n *Node) {
    if n.NType == NodeTypeBN {
        for _, s := range tab.storages {
            s.add(n)   // adds to CN, PN, EN, BN storages
        }
        return
    }
    ...
}
```

The CN, PN, and BN storages are `flatStorage` instances with capacity `math.MaxInt64`, so they accept an unlimited number of attacker nodes. The EN storage is `kademliaStorage` with bucket limits, but the attacker still occupies at least one bucket entry per distinct NodeID.

`ping.preverify` performs no NType validation — it only checks expiration, networkID, and a rate limit that applies only when the **victim** is itself a BN node.

### Impact Explanation

An attacker operating `k` nodes (each with a distinct ECDSA key and real UDP endpoint) can:

1. Send PING with `NType=NodeTypeBN` from each node.
2. Respond to the victim's return PING with a valid PONG.
3. Have all `k` nodes inserted into all four storages.

`RandomNodes(NodeTypeCN)`, `RandomNodes(NodeTypePN)`, `RandomNodes(NodeTypeEN)`, and `RandomNodes(NodeTypeBN)` all return attacker nodes. The victim's `p2p.DialSched` dials only attacker-controlled peers for every node type. Once eclipsed, the victim CN accepts attacker-crafted blocks or sync data, producing a chain split on honest nodes. This satisfies the "consensus divergence on honest nodes" impact criterion.

### Likelihood Explanation

The attack requires only a real UDP endpoint and the ability to craft a valid (ECDSA-signed) PING packet with `NType=NodeTypeBN`. No privileged access, governance keys, or cryptographic breaks are needed. The `NType` field is a single byte in the RLP-encoded `rpcEndpoint` struct and is trivially set by any standard discovery client. The attack is executable by any internet-reachable adversary against any initialized Kaia node.

### Recommendation

Validate the claimed `NType` in `ping.handle` (or in `tab.Bond`) against an allowlist of authenticated bootstrap node IDs before accepting `NodeTypeBN`. Specifically:

- In `addNode`, only treat a node as `NodeTypeBN` if its `NodeID` appears in `tab.nursery` (the configured bootstrap list).
- Alternatively, clamp any inbound-PING-derived NType to the sender's actual authenticated identity, rejecting `NodeTypeBN` claims from non-nursery nodes.

func (req *ping) preverify(t *udp, from *net.UDPAddr, fromID NodeID) error {
	if expired(req.Expiration) {
		return errExpired
	}
	if req.NetworkID != t.networkID {
		logger.Debug("udp: ping: mismatch networkid", "local", t.networkID, "remote", req.NetworkID)
		mismatchNetworkCounter.Mark(1)
		return errMismatchNetwork
	}
	// Bootstrap nodes rate-limit discovery pings per source IP to bound
	// amplification/DoS against the UDP endpoint. Rejecting here prevents both
	// the pong reply and the bonding goroutine in handle().
	//
	// LAN/loopback sources are exempt: the limit protects an internet-reachable
	// BN from public ping floods, while co-located/local nodes legitimately share
	// a single private IP (e.g. many nodes behind one NAT, or localhost in tests)
	// and must not throttle one another. This mirrors the LAN exemption on the
	// inbound TCP connection throttle.
	//
	// The limit is otherwise applied to every (non-LAN) source IP, not just
	// unbonded ones: a UDP source IP is unauthenticated/spoofable and kaia's bond
	// is keyed by NodeID only, so a "bonded NodeID + spoofed source IP" packet
	// could otherwise bypass the limit and reflect a pong to the spoofed victim.
	if t.ourEndpoint.NType == NodeTypeBN && t.pingLimiter != nil && !netutil.IsLAN(from.IP) {
		if !t.pingLimiter.allow(from.IP, time.Now()) {
			logger.Trace("udp: ping: rate limited", "addr", from)
			pingRateLimitedCounter.Mark(1)
			return errPingRateLimited
		}
	}
	return nil

func (req *ping) handle(t *udp, from *net.UDPAddr, fromID NodeID, mac []byte) error {

		To:         makeEndpoint(from, req.From.TCP, req.From.NType),
		ReplyTok:   mac,
		Expiration: uint64(time.Now().Add(expiration).Unix()),
	})

		// Note: we're ignoring the provided IP address right now
		go t.bond(true, fromID, from, req.From.TCP, req.From.NType)
	}
