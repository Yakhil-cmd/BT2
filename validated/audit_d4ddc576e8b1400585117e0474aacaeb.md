### Title
Attacker-controlled YAML frontmatter metadata keys are echoed unsanitized into terminal diagnostics, allowing ANSI/OSC escape injection - ([File: pkg/cmd/skills/publish/publish.go])

### Summary
`publishRun` derives diagnostic messages from `findGitHubMetadataKeys`, which returns raw map keys parsed directly from an attacker-supplied `SKILL.md`'s YAML `metadata` block. These keys are interpolated with `%s` (not `%q`) into `publishDiagnostic.message` and then written verbatim to `opts.IO.Out`/`opts.IO.ErrOut` by `renderDiagnosticsTTY`/`renderDiagnosticsPlain` via `fmt.Fprintf`, with no control-character stripping or escaping.

### Finding Description
In `publishRun`, when a skill's frontmatter contains a `metadata` map, `findGitHubMetadataKeys` collects keys with a `github-` prefix directly from `result.RawYAML["metadata"]`: [1](#0-0) 

These attacker-controlled key strings (YAML allows quoted keys containing arbitrary escape sequences, e.g. `"github-\x1b]0;pwned\x07"`) are joined and placed into diagnostic messages using plain `%s` formatting (not `%q`, which would escape control bytes): [2](#0-1) 

Contrast this with other diagnostics in the same function that use `%q` for `result.Metadata.Name` (Go's `%q` verb escapes control/non-printable characters into a safe literal representation, e.g. `\x1b` becomes the text `\x1b`), which would not leak raw escape bytes: [3](#0-2) 

The resulting `publishDiagnostic.message` is later written to the terminal without any sanitization: [4](#0-3) [5](#0-4) 

There is no ANSI/OSC stripping utility applied anywhere in this code path (no `SanitizeControlSequences`/`StripANSI` calls found in the repo), and `iostreams` output is written raw via `fmt.Fprintf`.

### Impact Explanation
A victim who runs `gh skill publish` (or `--dry-run`) against a directory containing an attacker-crafted `SKILL.md` (e.g., a cloned fork or a repo they collaborate on) with a `metadata` YAML key such as `"github-\x1b]0;forged-title\x07"` or `"github-\x1b[2J\x1b[Hfake output"` will have those raw control bytes written to their terminal. This enables terminal escape sequence injection: title-bar spoofing, screen clearing/overwrite to forge CLI output, and depending on terminal emulator, potentially OSC-based side effects (e.g., clipboard write via OSC 52 in vulnerable terminals) or clickable hyperlink escape sequences (OSC 8) that could be used for phishing. This matches an output-sanitization / terminal-injection class finding — not remote code execution, but a real client-side terminal-spoofing/social-engineering-adjacent primitive triggered purely by running a scoped, expected CLI command on untrusted content.

### Likelihood Explanation
Preconditions are realistic and match the intended threat model: an unprivileged attacker publishes a repo/fork with a crafted `SKILL.md`, and the victim runs `gh skill publish` against it (a normal workflow when validating/adjusting a fork or contribution before publishing). The `metadata.github-*` mechanism is a real, explicitly-checked code path (used for stripping "install metadata"), and YAML trivially supports quoted string keys containing escape sequences, so crafting the payload requires no special tooling. The vulnerable message is reached whenever a `metadata` map has any key with the `github-` prefix, regardless of `--fix`/`--dry-run` mode. This is a repeatable, deterministic effect (no timing/race Assumptions).

### Recommendation
Sanitize all diagnostic message content before formatting/output — either strip C0/C1 control characters and OSC/CSI sequences from any attacker-influenced strings (skill names, descriptions, YAML keys such as `githubKeys`, remote URLs joined in `detectMissingRepoDiagnostic`, etc.) before building `publishDiagnostic.message`, or apply a text-sanitization pass in `renderDiagnosticsTTY`/`renderDiagnosticsPlain` immediately before `fmt.Fprintf`. Alternatively, consistently use `%q` (as already done for `result.Metadata.Name`) for any value that could originate from untrusted YAML content, including `githubKeys`.

func renderDiagnosticsPlain(opts *PublishOptions, diagnostics []publishDiagnostic, errors, warnings int) {
	for _, d := range diagnostics {
		if d.severity == "info" {
			continue
		}
		fmt.Fprintf(opts.IO.Out, "%s\t%s\t%s\n", d.severity, d.skill, d.message)
	}
	if errors == 0 && warnings == 0 {
		fmt.Fprintf(opts.IO.Out, "ok\n")
	}
}

// findGitHubMetadataKeys returns metadata keys with the "github-" prefix.
func findGitHubMetadataKeys(meta map[string]interface{}) []string {
	var keys []string
	for k := range meta {
		if strings.HasPrefix(k, "github-") {
			keys = append(keys, k)
		}
	}
	sort.Strings(keys)
	return keys
}
