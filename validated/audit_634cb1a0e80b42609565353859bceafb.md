CVE-2010-2064 describes a local symlink race attack on predictable filenames in `/tmp` (rpcbind's `/tmp/portmap.xdr`, `/tmp/rpcbind.xdr`), which requires the attacker to already have local, unprivileged shell access to the same host as the vulnerable daemon before it starts. This bug class does not map onto any Polkadot SDK runtime attack surface reachable via a signed extrinsic, contract call, XCM message, or public proof submission — the report's required entry points.

I checked the codebase's temp-file handling in security-relevant client code:
- The PVF worker uses randomized, non-predictable temp paths via `tempfile::NamedTempFile`/`tempfile::TempDir` and unique worker directories, not fixed guessable filenames [1](#0-0) .
- Secret key files are opened with `create_new(true)` and mode `0o600` on Unix, which fails if a symlink or file already exists at the path, avoiding the classic symlink-follow write vulnerability [2](#0-1) .
- The keystore write path uses `File::create` with restrictive permissions, which is local node-operator/filesystem-level code, not reachable by any external/unprivileged network actor [3](#0-2) .

Even in the closest analogs, exploitation would require the attacker to already have local shell/filesystem access to the validator/collator/node host — a privileged local prerequisite explicitly excluded by the report's rules ("no privileged role... local access" and rejection of "privileged prerequisites"). There is no signed extrinsic, XCM message, or contract call that causes the runtime or client to write to an attacker-predictable, attacker-writable temp path on behalf of a remote, unprivileged actor. No demonstrable analog exists.

	/// Returns a path under [`std::env::temp_dir`]. The path name will start with the given prefix.
	///
	/// There is only a certain number of retries. If exceeded this function will give up and return
	/// an error.
	pub async fn tmppath(prefix: &str) -> io::Result<PathBuf> {
		fn make_tmppath(prefix: &str, dir: &Path) -> PathBuf {
			use rand::distributions::Alphanumeric;

			const DISCRIMINATOR_LEN: usize = 10;

			let mut buf = Vec::with_capacity(prefix.len() + DISCRIMINATOR_LEN);
			buf.extend(prefix.as_bytes());
			buf.extend(rand::thread_rng().sample_iter(&Alphanumeric).take(DISCRIMINATOR_LEN));

			let s = std::str::from_utf8(&buf)
				.expect("the string is collected from a valid utf-8 sequence; qed");

			let mut path = dir.to_owned();
			path.push(s);
			path
		}

		const NUM_RETRIES: usize = 50;

		let dir = std::env::temp_dir();
		for _ in 0..NUM_RETRIES {
			let tmp_path = make_tmppath(prefix, &dir);
			if !tmp_path.exists() {
				return Ok(tmp_path);
			}
		}

		Err(io::Error::new(io::ErrorKind::Other, "failed to create a temporary path"))
	}
