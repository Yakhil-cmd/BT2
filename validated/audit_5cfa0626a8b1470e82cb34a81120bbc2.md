The reported CVE-2016-10190 is a C-language heap buffer overflow in FFmpeg's custom HTTP chunked-transfer-encoding parser (`libavformat/http.c`), caused by an unchecked negative chunk size leading to an out-of-bounds heap write. This is a memory-safety class of bug tied to manual buffer arithmetic in unsafe C code.

The Polkadot SDK's only comparable HTTP-client code path is the offchain worker HTTP API [1](#0-0) , which delegates all request/response transport — including any chunked-transfer-encoding decoding — to the `hyper` crate rather than implementing custom chunk-size parsing itself [2](#0-1) . Body bytes are read into a fixed-size `[u8; 4096]` buffer with all indexing bounded by `position`/`filled_up_to` checked against the actual returned size [3](#0-2) , and the mock testing implementation similarly bounds reads with `std::cmp::min` against buffer/response lengths [4](#0-3) . There is no analogous unsafe/manual heap-overflow-prone chunk-size arithmetic in this codebase.

Additionally, offchain-worker HTTP requests are not a "real user entry" of the kind required by the scan methodology: they are outbound calls initiated by node-local offchain worker code to URLs the node operator/runtime chooses, not remote-attacker-controlled input reachable via a signed extrinsic, XCM message, or proof submission that affects consensus state. Rust's memory safety combined with `hyper`'s well-tested chunked-decoding implementation also removes the underlying unsafe-buffer-overflow primitive that the original CVE depends on. No demonstrable analog with attacker-controlled entry, violated invariant, and measurable on-chain impact exists in this codebase.

impl Iterator for ResponseBody {
	type Item = u8;

	fn next(&mut self) -> Option<Self::Item> {
		if self.error.is_some() {
			return None;
		}

		if self.filled_up_to.is_none() {
			let result =
				sp_io::offchain::http_response_read_body(self.id, &mut self.buffer, self.deadline);
			match result {
				Err(e) => {
					self.error = Some(e);
					return None;
				},
				Ok(0) => return None,
				Ok(size) => {
					self.position = 0;
					self.filled_up_to = Some(size as usize);
				},
			}
		}

		if Some(self.position) == self.filled_up_to {
			self.filled_up_to = None;
			return self.next();
		}

		let result = self.buffer[self.position];
		self.position += 1;
		Some(result)
	}
