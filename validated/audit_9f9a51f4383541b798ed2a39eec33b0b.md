### Title
Missing Zero-Value Validation for `kip71.gastarget` Governance Parameter Enables Division-by-Zero Panic in Base Fee Calculation — (`kaiax/gov/param.go`, `params/kip71_config.go`)

---

### Summary

The `Kip71GasTarget` governance parameter uses `noopFormatChecker`, accepting `0` as a valid value. `NextMagmaBlockBaseFee` uses `GasTarget` as a divisor without a zero guard. A ratified governance vote setting `kip71.gastarget = 0` causes every subsequent block that uses any gas to trigger a `big.Int.Div` panic, crashing all nodes and halting consensus.

---

### Finding Description

**Root cause — missing zero check in `FormatChecker`:**

`Kip71BaseFeeDenominator` correctly rejects zero:

```go
Kip71BaseFeeDenominator: {
    FormatChecker: func(cv any) bool {
        v, ok := cv.(uint64)
        return ok && v != 0   // ← zero rejected
    },
``` [1](#0-0) 

`Kip71GasTarget` uses `noopFormatChecker`, which always returns `true`:

```go
Kip71GasTarget: {
    Canonicalizer: uint64Canonicalizer,
    FormatChecker: noopFormatChecker,   // ← zero accepted
``` [2](#0-1) 

`noopFormatChecker` is defined as:

```go
func noopFormatChecker(cv any) bool {
    return true
}
``` [3](#0-2) 

**Vote acceptance path — no consistency check for `Kip71GasTarget`:**

`checkConsistency` in `VerifyVote` explicitly lists `gov.Kip71GasTarget` in the "no further checks" branch, returning `nil` unconditionally:

```go
case gov.GovernanceDeriveShaImpl, ...,
    gov.Kip71BaseFeeDenominator, gov.Kip71GasTarget, gov.Kip71MaxBlockGasUsedForBaseFee,
    ...:
    return nil
``` [4](#0-3) 

A vote `kip71.gastarget = 0` therefore passes `NewVoteData` (format check), `VerifyVote` (consistency check), and is ratified at the next epoch boundary.

**Crash site — `GasTarget` used as divisor without zero guard:**

`NextMagmaBlockBaseFee` uses `gasTarget` as a divisor in two places:

```go
// line 102 (parentGasUsed > gasTarget branch)
y := x.Div(x, new(big.Int).SetUint64(gasTarget))

// line 120 (parentGasUsed < gasTarget branch)
y := x.Div(x, new(big.Int).SetUint64(gasTarget))
``` [5](#0-4) [6](#0-5) 

`BaseFeeDenominator` has an explicit zero fallback at line 71–73, but `GasTarget` has no equivalent guard:

```go
if kc.BaseFeeDenominator == 0 {
    baseFeeDenominator = new(big.Int).SetUint64(64)  // ← protected
}
// No analogous guard for gasTarget
``` [7](#0-6) 

When `gasTarget = 0` and `parentGasUsed > 0` (any block with transactions), the condition `parentGasUsed == gasTarget` is false, execution falls into the `parentGasUsed > gasTarget` branch, and `big.Int.Div` panics on a zero divisor. Go's `math/big` package panics unconditionally on division by zero.

**Call sites that trigger the panic:**

`VerifyMagmaHeader` (block validation) calls `NextMagmaBlockBaseFee` on every Magma-era block: [8](#0-7) 

The gas price oracle also calls it: [9](#0-8) 

---

### Impact Explanation

Once `kip71.gastarget = 0` is ratified and takes effect at the next epoch, every node that attempts to validate or produce a block with any gas usage panics. This crashes all honest nodes simultaneously, halting the chain. The corrupted value is the `GasTarget` field in the effective `KIP71Config` used for every block's base fee derivation — a protected chain-state parameter that governs fee settlement for all transactions.

---

### Likelihood Explanation

`kip71.gastarget` is listed as a **mutable** governance parameter: [10](#0-9) 

In `none` governance mode (default for private/test networks), any council member can cast this vote. In `single` mode (Mainnet), the governing node is required. The trigger is a semi-trusted council member in `none` mode, or a compromised/malicious governing node in `single` mode. The missing validation is the direct root cause regardless of who triggers it.

---

### Recommendation

Add a non-zero `FormatChecker` for `Kip71GasTarget`, mirroring the existing check for `Kip71BaseFeeDenominator`:

```go
Kip71GasTarget: {
    Canonicalizer: uint64Canonicalizer,
    FormatChecker: func(cv any) bool {
        v, ok := cv.(uint64)
        return ok && v != 0   // GasTarget is used as a divisor; zero must be rejected
    },
    ...
},
```

Additionally, add a zero guard in `NextMagmaBlockBaseFee` for defense-in-depth, analogous to the existing `BaseFeeDenominator` guard:

```go
if gasTarget == 0 {
    // Governance invariant violated; return lowerBoundBaseFee as safe fallback
    return makeEvenByFloor(lowerBoundBaseFee)
}
```

---

### Proof of Concept

1. Network operates in `none` governance mode (or governing node is compromised in `single` mode).
2. Council member calls `governance_vote("kip71.gastarget", 0)`.
3. `NewVoteData` succeeds: `noopFormatChecker` returns `true` for `uint64(0)`.
4. `VerifyVote` → `checkConsistency` returns `nil` for `Kip71GasTarget`.
5. Vote is inscribed in `header.Vote` at the next block the voter proposes.
6. At the next epoch boundary, the vote is ratified and `header.Governance` encodes `{"kip71.gastarget": 0}`.
7. From the following epoch, `GetParamSet(N).GasTarget == 0` for all `N`.
8. The first block with any gas used (virtually every block) triggers `NextMagmaBlockBaseFee` → `x.Div(x, new(big.Int).SetUint64(0))` → **panic** in all nodes.
9. All nodes crash; chain halts; consensus diverges.
