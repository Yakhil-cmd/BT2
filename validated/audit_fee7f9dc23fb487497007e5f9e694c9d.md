### Title
Unverified Peer-Supplied Staking Info Stored During Fast Sync Corrupts Reward Distribution — (`datasync/downloader/downloader.go`)

### Summary

During fast sync, `commitFastSyncData` stores `P2PStakingInfo` received from a remote peer directly into the staking DB without verifying its content against the canonical state root of the corresponding block. A malicious peer can supply fabricated staking info (wrong validator node IDs, wrong reward addresses, wrong staking amounts) for a correct block number, and the node will persist it as authoritative. Subsequent block processing that reads from this DB entry will compute wrong reward distributions, producing state roots that diverge from the canonical chain.

### Finding Description

In `commitFastSyncData` (called from `processFastSyncContent` during fast sync), for each downloaded block result that carries a `StakingInfo` field, the code unconditionally writes it to the DB:

```go
// datasync/downloader/downloader.go:1881-1883
if result.StakingInfo != nil {
    d.stakingModule.PutStakingInfoToDB(result.StakingInfo.BlockNum, staking.ToStakingInfo(result.StakingInfo))
    logger.Info("Imported new staking information", "number", result.StakingInfo.BlockNum)
}
``` [1](#0-0) 

The same pattern appears in the `SyncStakingInfo` recovery path:

```go
// datasync/downloader/downloader.go:1677
d.stakingModule.PutStakingInfoToDB(stakingInfo.BlockNum, staking.ToStakingInfo(stakingInfo))
``` [2](#0-1) 

The only check performed is that `stakingInfo.BlockNum` matches the expected block number in the recovery queue. No check is made that the `CouncilNodeAddrs`, `CouncilRewardAddrs`, `CouncilStakingAmounts`, `KEFAddr`, or `KIFAddr` fields match what the AddressBook contract actually returns for that block's state root.

The staking info is served by the peer via `handleStakingInfoRequestMsg` / `handleStakingInfoMsg`: [3](#0-2) 

Once stored, `GetStakingInfo` returns the DB entry directly for pre-Kaia blocks without re-deriving from state:

```go
// kaiax/staking/impl/getter.go:57-63
if !isKaia {
    if si := ReadStakingInfo(s.ChainKv, sourceNum); si != nil {
        s.stakingInfoCache.Add(sourceNum, si)
        return si, nil   // returned without state verification
    }
}
``` [4](#0-3) 

The staking info is the authoritative source for reward distribution and validator weighting. The `P2PStakingInfo` struct carries all fields that determine who receives block rewards: [5](#0-4) 

### Impact Explanation

The staking info DB entry is consumed by `GetStakingInfo` during `FinalizeState` for every block whose `sourceBlockNum` falls in the corrupted interval. With wrong `CouncilRewardAddrs` or `KEFAddr`/`KIFAddr`, the node computes a different state root than the canonical chain, causing it to reject all subsequent valid blocks (consensus divergence). If the node is a validator, it produces blocks with wrong reward distribution that other validators reject. In either case, KAIA block rewards are misdirected to attacker-controlled addresses for every block in the affected staking interval.

### Likelihood Explanation

Fast sync is a standard operational mode for new or recovering nodes. Any P2P peer the syncing node connects to can serve `StakingInfoMsg` responses. The peer is not required to be a validator or to hold any special privilege — it only needs to be a registered P2P peer (protocol version ≥ `kaia65`). The attack requires no compromised keys, no majority-validator collusion, and no admin access. The trigger is a single malicious peer responding to a `StakingInfoRequestMsg` with fabricated content.

### Recommendation

After receiving `P2PStakingInfo` from a peer, verify its content against the canonical state before persisting it. Specifically:

1. Retrieve the block header for `stakingInfo.BlockNum` from the local canonical chain.
2. Open the state at `header.Root`.
3. Call `getFromState(header, statedb)` to derive the expected `StakingInfo`.
4. Compare the peer-supplied fields against the locally derived values; reject and disconnect the peer on mismatch.
5. Only then call `PutStakingInfoToDB`.

This mirrors how block bodies and receipts are validated against the header's `TxHash` and `ReceiptHash` before acceptance.

### Proof of Concept

**Setup:** Node A is syncing in fast-sync mode. Attacker controls peer B.

1. Node A requests staking info for block hash `H(1000)` via `StakingInfoRequestMsg`.
2. Peer B responds with a `StakingInfoMsg` containing a `P2PStakingInfo` where `BlockNum=1000` (correct) but `CouncilRewardAddrs` are replaced with attacker-controlled addresses and `KEFAddr`/`KIFAddr` point to attacker wallets.
3. `handleStakingInfoMsg` decodes the message and calls `pm.downloader.DeliverStakingInfos`.
4. `commitFastSyncData` checks only `result.StakingInfo != nil` and calls `PutStakingInfoToDB(1000, fabricatedInfo)`.
5. Fast sync completes. Node A now has corrupted staking info for block 1000 in its DB.
6. When Node A processes block 1001 (pre-Kaia), `GetStakingInfo(1001)` computes `sourceNum=0` or `sourceNum=1000` (depending on interval), reads the corrupted DB entry, and distributes block rewards to attacker addresses.
7. The resulting state root differs from the canonical chain. Node A either rejects valid canonical blocks (consensus divergence) or, if it is a validator, produces invalid blocks that the rest of the network rejects.

**Corrupted value:** `StakingInfo.RewardAddrs`, `StakingInfo.KEFAddr`, `StakingInfo.KIFAddr`, `StakingInfo.StakingAmounts` — all written to `"stakingInfo" || Uint64LE(sourceNum)` in the misc DB without state-root verification. [6](#0-5) [7](#0-6) [8](#0-7)

func (d *Downloader) commitFastSyncData(results []*fetchResult, stateSync *stateSync) error {
	// Check for any early termination requests
	if len(results) == 0 {
		return nil
	}
	select {
	case <-d.quitCh:
		return errCancelContentProcessing
	case <-stateSync.done:
		if err := stateSync.Wait(); err != nil {
			return err
		}
	default:
	}
	// Retrieve the a batch of results to import
	first, last := results[0].Header, results[len(results)-1].Header
	logger.Debug("Inserting fast-sync blocks", "items", len(results),
		"firstnum", first.Number, "firsthash", first.Hash(),
		"lastnumn", last.Number, "lasthash", last.Hash(),
	)
	blocks := make([]*types.Block, len(results))
	receipts := make([]types.Receipts, len(results))
	for i, result := range results {
		blocks[i] = types.NewBlockWithHeader(result.Header).WithBody(result.Transactions)
		receipts[i] = result.Receipts
		if result.StakingInfo != nil {
			d.stakingModule.PutStakingInfoToDB(result.StakingInfo.BlockNum, staking.ToStakingInfo(result.StakingInfo))
			logger.Info("Imported new staking information", "number", result.StakingInfo.BlockNum)
		}
	}
	if index, err := d.blockchain.InsertReceiptChain(blocks, receipts); err != nil {
		logger.Debug("Downloaded item processing failed", "number", results[index].Header.Number, "hash", results[index].Header.Hash(), "err", err)
		return fmt.Errorf("%w: %v", errInvalidChain, err)
	}
	return nil
}

// handleStakingInfoRequestMsg handles staking information request message.
func handleStakingInfoRequestMsg(pm *ProtocolManager, p Peer, msg p2p.Msg) error {
	if pm.chainconfig.Istanbul == nil || pm.chainconfig.Istanbul.ProposerPolicy != uint64(istanbul.WeightedRandom) {
		return errResp(ErrUnsupportedEnginePolicy, "the engine is not istanbul or the policy is not weighted random")
	}

	// Decode the retrieval message
	msgStream := rlp.NewStream(msg.Payload, uint64(msg.Size))
	if _, err := msgStream.List(); err != nil {
		return err
	}
	// Gather state data until the fetch or network limits is reached
	var (
		hash         common.Hash
		bytes        int
		stakingInfos []rlp.RawValue
		lookups      int
	)
	for bytes < softResponseLimit && len(stakingInfos) < downloader.MaxStakingInfoFetch &&
		lookups < 2*downloader.MaxStakingInfoFetch {
		// Retrieve the hash of the next block
		if err := msgStream.Decode(&hash); err == rlp.EOL {
			break
		} else if err != nil {
			return errResp(ErrDecode, "msg %v: %v", msg, err)
		}

		lookups++
		// Retrieve the requested block's staking information, skipping if unknown to us
		header := pm.blockchain.GetHeaderByHash(hash)
		if header == nil {
			continue
		}
		number := header.Number.Uint64()
		var result *staking.P2PStakingInfo
		if pm.chainconfig.IsKaiaForkEnabled(header.Number) {
			st, err := pm.stakingModule.GetStakingInfo(number)
			if st == nil || err != nil {
				continue
			}
			result = staking.FromStakingInfoWithGini(st, false, pm.chainconfig.Governance.Reward.MinimumStake.Uint64())
		} else {
			st := pm.stakingModule.GetStakingInfoFromDB(number)
			if st == nil {
				continue
			}
			result = staking.FromStakingInfoWithGini(st, pm.chainconfig.Governance.Reward.UseGiniCoeff, pm.chainconfig.Governance.Reward.MinimumStake.Uint64())
		}

		// If known, encode and queue for response packet
		if encoded, err := rlp.EncodeToBytes(result); err != nil {
			logger.Error("Failed to encode staking info", "err", err)
		} else {
			stakingInfos = append(stakingInfos, encoded)
			bytes += len(encoded)
		}
	}
	return p.SendStakingInfoRLP(stakingInfos)
}

// handleStakingInfoMsg handles staking information response message.
func handleStakingInfoMsg(pm *ProtocolManager, p Peer, msg p2p.Msg) error {
	if pm.chainconfig.Istanbul == nil || pm.chainconfig.Istanbul.ProposerPolicy != uint64(istanbul.WeightedRandom) {
		return errResp(ErrUnsupportedEnginePolicy, "the engine is not istanbul or the policy is not weighted random")
	}

	// A batch of stakingInfos arrived to one of our previous requests
	var stakingInfos []*staking.P2PStakingInfo
	if err := msg.Decode(&stakingInfos); err != nil {
		return errResp(ErrDecode, "msg %v: %v", msg, err)
	}
	// Deliver all to the downloader
	if err := pm.downloader.DeliverStakingInfos(p.GetID(), stakingInfos); err != nil {
		logger.Debug("Failed to deliver staking information", "err", err)
	}
	return nil
}

func (s *StakingModule) GetStakingInfo(num uint64) (*staking.StakingInfo, error) {
	isKaia := s.ChainConfig.IsKaiaForkEnabled(new(big.Int).SetUint64(num))
	sourceNum := sourceBlockNum(num, isKaia, s.stakingInterval)

	// Try cache first
	if si, ok := s.stakingInfoCache.Get(sourceNum); ok {
		return si.(*staking.StakingInfo), nil
	}

	// Only before Kaia, try the database
	if !isKaia {
		if si := ReadStakingInfo(s.ChainKv, sourceNum); si != nil {
			s.stakingInfoCache.Add(sourceNum, si)
			return si, nil
		}
	}

	// Read from the state
	si, err := s.getFromStateByNumber(sourceNum)
	if err != nil {
		return nil, err
	}

	// Only before Kaia, write to database
	if !isKaia {
		WriteStakingInfo(s.ChainKv, sourceNum, si)
	}

	// Cache it
	s.stakingInfoCache.Add(sourceNum, si)
	return si, nil
}
