Both bug classes share the same root cause pattern: **security- or path-relevant metadata is trusted from a value that the remote/attacker fully controls, rather than being derived from an independently-verified source**, causing internal bookkeeping to diverge from the "real" state.

### Title
Skill update trusts attacker-controlled `github-path` frontmatter metadata to match remote skills, allowing wrong-skill content to overwrite an existing skill directory - ([File: pkg/cmd/skills/update/update.go])

### Summary
`gh skill update` determines which remote skill corresponds to a locally installed skill by comparing the `github-path` (`sourcePath`) value recorded in the local `SKILL.md` frontmatter against the `Path` field of skills discovered from the remote repository [1](#0-0) . This mirrors the `USDMPegRecovery` finding's root cause: an internal record (contract storage / frontmatter metadata) is used as the source of truth for a security-relevant match/withdraw operation, while the actual backing state (curve pool balances / remote repo content addressed by that path) can diverge from what was recorded, because the metadata was derived from data that isn't independently re-verified at use time.

### Finding Description
When installing or updating a skill, `gh` writes `github-path` into the skill's frontmatter via `InjectGitHubMetadata` [2](#0-1) . On a subsequent `gh skill update`, this value is read back out of the *local* `SKILL.md` file via `parseInstalledSkill` and trusted as `s.sourcePath` [3](#0-2) . The matching logic in `updateRun` then does:

```go
if s.sourcePath != "" {
    matched = remote.Path == s.sourcePath
} else {
    matched = remote.InstallName() == s.name
}
``` [4](#0-3) 

Because the repository owner controls the content of files in their own repo (including any `SKILL.md` a user might have installed from that repo, or that a user might have manually edited/merged), and because `github-path`/`github-tree-sha` fields are just YAML the repo publisher writes, the mapping between "locally recorded path" and "what actually gets discovered and downloaded" is not cross-checked against anything else (e.g., a hash of the installed content, or the repo's tree listing consistency at install time vs. update time). If the repository is restructured, or if a skill's `github-path` collides with a different skill's path due to publisher-controlled input, `updateSkillInPlace` will download whatever `discovery.DiscoverSkills` currently resolves for that path and atomically swap it into the existing skill's directory via `swapDirectoryContents` [5](#0-4) [6](#0-5) , replacing the user's existing, trusted skill content with unrelated (attacker-influenced) content from the same repo/path, without any content-integrity check tying the swap back to what the user originally reviewed and approved.

Unlike a hash/digest check (which would detect drift, similar to how `USDMPegRecovery` should have priced contributions off LP virtual price rather than raw storage numbers), here the "identity" of the content to install is decided purely by an attacker-influencable string (`Path`/`sourcePath`) recorded during a prior, and now stale, remote state.

### Impact Explanation
A successful mismatch causes `gh skill update` to silently replace the contents of a previously-installed, user-trusted skill directory with different content resolved from the same repository path, which is then made available for the agent to load/execute as a "skill" (per the "Skills (Agent Skills) System" — an explicitly in-scope area per the rules: extension/skill install and execution). This can lead to unexpected code/instructions being loaded by the coding agent under the guise of an update the user approved, without the content having been diffed or re-verified against the originally installed intent.

### Likelihood Explanation
This requires only that the remote repository owner (which is by definition attacker-controlled/untrusted content in the `gh skill install`/`update` model, since users install skills from arbitrary `owner/repo` sources) changes what is served at a given tree path, or that a path collision occurs across skill renames within the same repo — no MITM, no local privilege, and no leaked token is required. It is reachable during the normal, unprivileged `gh skill update` flow that a remote unprivileged attacker (repo owner) can trigger simply by publishing new content at a previously-used path.

### Recommendation
Do not rely solely on the locally recorded `github-path` (attacker-supplied metadata echoed from a prior fetch) to decide which remote object matches an installed skill. Additionally verify skill identity using data that is independent of the publisher's ability to rewrite history/paths — e.g., compare a content hash of the currently installed files against the recorded `SkillFolderHash`/`github-tree-sha` before trusting a path match, and treat any path-based match that arrives with an unexpectedly different skill `Name`/`Description`/hash lineage as an "install," prompting the user to confirm, rather than silently treating it as an "update" that atomically swaps the directory in place.

### Proof of Concept
Concrete exploitation could not be fully validated with static analysis alone: reproducing the collision requires (1) publishing a skill at path `P` with `github-tree-sha` `S1`, having a user install it, then (2) restructuring the same public repo so that a different skill (or attacker-modified content) resolves at the same discovered `Path` `P` at a later commit, and (3) confirming `discovery.DiscoverSkills` surfaces this as a match causing `remote.Path == s.sourcePath` to hold true in `updateRun` at [4](#0-3) . I was not able to trace `discovery.DiscoverSkills`/`discovery.Skill.Path` resolution logic in this session to confirm whether tree-path uniqueness is enforced elsewhere in the discovery layer, which would mitigate or fully prevent this collision. This should be verified in a Devin session with full repo access, examining `internal/skills/discovery` for any additional integrity checks before concluding severity.

func updateSkillInPlace(opts *UpdateOptions, u pendingUpdate, apiClient *api.Client, gitRoot, homeDir string) error {
	if u.local.dir == "" {
		return fmt.Errorf("cannot update %s: no install location recorded", u.local.name)
	}

	parent := filepath.Dir(u.local.dir)
	if err := os.MkdirAll(parent, 0o755); err != nil {
		return fmt.Errorf("could not ensure parent directory %s: %w", parent, err)
	}

	// Stage as a sibling of the existing skill directory so the swap stays
	// on the same filesystem and every rename is atomic.
	staging, err := os.MkdirTemp(parent, "."+u.skill.Name+".gh-skill-update-")
	if err != nil {
		return fmt.Errorf("could not create staging directory: %w", err)
	}
	defer os.RemoveAll(staging)

	installOpts := &installer.Options{
		Host:    u.local.repoHost,
		Owner:   u.local.owner,
		Repo:    u.local.repo,
		Ref:     u.resolved.Ref,
		SHA:     u.resolved.SHA,
		Skills:  []discovery.Skill{u.skill},
		Dir:     staging,
		GitRoot: gitRoot,
		HomeDir: homeDir,
		Client:  apiClient,
	}
	if _, err := installer.Install(installOpts); err != nil {
		return err
	}

	stagedSkillDir := filepath.Join(staging, u.skill.Name)
	if _, err := os.Stat(stagedSkillDir); err != nil {
		return fmt.Errorf("installer did not produce %s: %w", stagedSkillDir, err)
	}

	if err := os.MkdirAll(u.local.dir, 0o755); err != nil {
		return fmt.Errorf("could not ensure skill directory %s: %w", u.local.dir, err)
	}

	return swapDirectoryContents(u.local.dir, stagedSkillDir)

func swapDirectoryContents(dest, src string) error {
	backup, err := os.MkdirTemp(filepath.Dir(dest), "."+filepath.Base(dest)+".gh-skill-backup-")
	if err != nil {
		return fmt.Errorf("could not create backup directory: %w", err)
	}

	existing, err := os.ReadDir(dest)
	if err != nil {
		_ = os.RemoveAll(backup)
		return fmt.Errorf("could not read skill directory %s: %w", dest, err)
	}
	var movedOut []string
	for _, entry := range existing {
		if err := os.Rename(filepath.Join(dest, entry.Name()), filepath.Join(backup, entry.Name())); err != nil {
			restoreBackup(dest, backup, movedOut, nil)
			return fmt.Errorf("could not move %s aside: %w", entry.Name(), err)
		}
		movedOut = append(movedOut, entry.Name())
	}

	staged, err := os.ReadDir(src)
	if err != nil {
		restoreBackup(dest, backup, movedOut, nil)
		return fmt.Errorf("could not read staged skill directory %s: %w", src, err)
	}
	var movedIn []string
	for _, entry := range staged {
		from := filepath.Join(src, entry.Name())
		to := filepath.Join(dest, entry.Name())
		if err := os.Rename(from, to); err != nil {
			restoreBackup(dest, backup, movedOut, movedIn)
			return fmt.Errorf("could not move %s into place: %w", entry.Name(), err)
		}
		movedIn = append(movedIn, entry.Name())
	}

	_ = os.RemoveAll(backup)
	return nil
}

// parseInstalledSkill parses a SKILL.md file and returns an installedSkill.
func parseInstalledSkill(data []byte, name, dir string, host *registry.AgentHost, scope registry.Scope) (installedSkill, bool) {
	result, err := frontmatter.Parse(string(data))
	if err != nil {
		return installedSkill{
			name:        name,
			dir:         dir,
			host:        host,
			scope:       scope,
			metadataErr: fmt.Errorf("invalid SKILL.md: %w", err),
		}, true
	}

	s := installedSkill{
		name:  name,
		dir:   dir,
		host:  host,
		scope: scope,
	}

	if result.Metadata.Meta != nil {
		repoInfo, ok, repoErr := source.ParseMetadataRepo(result.Metadata.Meta)
		if repoErr != nil {
			s.metadataErr = repoErr
		} else if ok {
			if err := source.ValidateSupportedHost(repoInfo.RepoHost()); err != nil {
				s.metadataErr = err
			} else {
				s.repoHost = repoInfo.RepoHost()
				s.owner = repoInfo.RepoOwner()
				s.repo = repoInfo.RepoName()
			}
		}
		s.treeSHA, _ = result.Metadata.Meta["github-tree-sha"].(string)
		s.pinned, _ = result.Metadata.Meta["github-pinned"].(string)
		s.sourcePath, _ = result.Metadata.Meta["github-path"].(string)
	}

	return s, true
}

func InjectGitHubMetadata(content string, host, owner, repo, ref, treeSHA, pinnedRef, skillPath string) (string, error) {
	result, err := Parse(content)
	if err != nil {
		return "", err
	}

	if result.RawYAML == nil {
		result.RawYAML = make(map[string]interface{})
	}

	meta, _ := result.RawYAML["metadata"].(map[string]interface{})
	if meta == nil {
		meta = make(map[string]interface{})
	}
	delete(meta, "github-owner")
	meta["github-repo"] = source.BuildRepoURL(host, owner, repo)
	meta["github-ref"] = ref
	delete(meta, "github-sha")
	meta["github-tree-sha"] = treeSHA
	meta["github-path"] = skillPath
	if pinnedRef != "" {
		meta["github-pinned"] = pinnedRef
	} else {
		delete(meta, "github-pinned")
	}
	result.RawYAML["metadata"] = meta

	return Serialize(result.RawYAML, result.Body)
}
