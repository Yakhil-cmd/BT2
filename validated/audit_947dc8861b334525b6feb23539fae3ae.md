### Title
Governance vote of `kip71.gastarget = 0` causes division-by-zero panic in `NextMagmaBlockBaseFee`, halting block validation and production — (`params/kip71_config.go`)

### Summary

The `kip71.gastarget` governance parameter accepts any `uint64` value including zero because its `FormatChecker` is `noopFormatChecker` and `checkConsistency` skips all cross-parameter validation for it. A council member can ratify `GasTarget = 0` via a governance vote. After the epoch boundary where the change takes effect, any block with non-zero gas usage causes a division-by-zero panic inside `NextMagmaBlockBaseFee`, crashing every node that attempts to validate or produce that block and permanently halting the chain until a corrective governance vote is ratified — a process that takes at least one full epoch (604,800 blocks on Mainnet).

### Finding Description

**Root cause 1 — no lower-bound validation on `GasTarget`:**

`kaiax/gov/param.go` defines `Kip71GasTarget` with `FormatChecker: noopFormatChecker`, which unconditionally returns `true` for any value, including `0`. [1](#0-0) 

**Root cause 2 — `checkConsistency` explicitly skips `GasTarget`:**

`kaiax/gov/headergov/impl/header.go` lists `gov.Kip71GasTarget` in the "no further checks" branch of `checkConsistency`, so a vote of `0` passes header verification without any cross-parameter guard. [2](#0-1) 

**Root cause 3 — unguarded division by `gasTarget` in `NextMagmaBlockBaseFee`:**

`params/kip71_config.go` divides by `gasTarget` on two paths without a zero-guard:

```go
// parentGasUsed > gasTarget branch (line 102)
y := x.Div(x, new(big.Int).SetUint64(gasTarget))   // PANIC if gasTarget == 0

// parentGasUsed < gasTarget branch (line 120)
y := x.Div(x, new(big.Int).SetUint64(gasTarget))   // PANIC if gasTarget == 0
``` [3](#0-2) 

The only safe exit is the early-return at line 90 (`parentGasUsed == gasTarget`), which fires only when both are zero — i.e., when `MaxBlockGasUsedForBaseFee` is also zero or the block is completely empty. Any block with even one transaction produces `parentGasUsed > 0`, bypasses the early return, and hits the division.

**Call path that triggers the panic:**

`NextMagmaBlockBaseFee` is called from `VerifyMagmaHeader` during header validation, from block-production code computing the next base fee, and from the gas-price oracle (`isRelaxedNetwork`). [4](#0-3) 

`VerifyMagmaHeader` is invoked inside `validateHeader` in the block validator, meaning every honest node panics the moment it tries to validate or produce the first non-empty block after the governance change takes effect. [5](#0-4) 

**Governance vote acceptance path:**

`PartialParamSet.Add` calls `FormatChecker` before storing the value. Because `noopFormatChecker` always returns `true`, the value `0` is stored without error and propagated into the ratified `header.Governance` at the next epoch boundary. [6](#0-5) 

The ratified parameter is then merged into `GetParamSet`, which `NewRewardConfig` and `ToKip71Config` consume on every block. [7](#0-6) 

### Impact Explanation

After the epoch boundary where `GasTarget = 0` takes effect, every node that calls `NextMagmaBlockBaseFee` with a non-empty block panics with a runtime division-by-zero. Block production and validation both halt. No transactions can be processed, no rewards distributed, and no corrective governance vote can be ratified until the chain resumes — which itself requires the same broken path. The chain is effectively bricked for at least one full epoch (604,800 blocks ≈ one week on Mainnet).

This is the direct Kaia analog of M-13: a governance-controlled parameter set to an inconsistent value causes a core per-block function to fail irrecoverably, rendering the chain unusable.

### Likelihood Explanation

In `governance.governancemode = "none"` chains, any council member can cast the vote unilaterally. In `"single"` mode (Mainnet), only the governing node can vote, making the trigger privileged. The vulnerability is latent in all Magma-enabled deployments; the missing guard is a single-line omission that has no compensating check anywhere in the pipeline.

### Recommendation

1. **`kaiax/gov/param.go`**: Replace `noopFormatChecker` for `Kip71GasTarget` with a checker that rejects `0`:
   ```go
   FormatChecker: func(cv any) bool {
       v, ok := cv.(uint64)
       return ok && v > 0
   },
   ```

2. **`params/kip71_config.go`**: Add a defensive guard at the top of `NextMagmaBlockBaseFee`:
   ```go
   if kc.GasTarget == 0 {
       return makeEvenByFloor(lowerBoundBaseFee)
   }
   ```

3. **`kaiax/gov/headergov/impl/header.go`**: Add a `checkConsistency` case for `Kip71GasTarget` that rejects `0`, analogous to the existing `LowerBoundBaseFee`/`UpperBoundBaseFee` cross-checks. [8](#0-7) 

### Proof of Concept

1. Chain is post-Magma with `governance.governancemode = "none"` (or governing node in `"single"` mode).
2. Council member calls `governance_vote("kip71.gastarget", 0)`.
3. Vote passes `noopFormatChecker` and `checkConsistency` (no validation for `GasTarget`).
4. At the next epoch block, the vote is ratified and written to `header.Governance`.
5. `GetParamSet` now returns `GasTarget = 0` for all subsequent blocks.
6. The first block with any transaction: `parentGasUsed = min(gasUsed, MaxBlockGasUsedForBaseFee) > 0`.
7. `parentGasUsed > gasTarget (0)` → enters the `else if` branch.
8. `y := x.Div(x, new(big.Int).SetUint64(0))` → **runtime panic: integer divide by zero**.
9. Every node crashes. Chain halts. Recovery requires a new governance vote ratified over another full epoch. [9](#0-8) [1](#0-0) [10](#0-9)

func (kc *KIP71Config) VerifyMagmaHeader(headerBaseFee *big.Int, parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) error {

		return fmt.Errorf("header is missing baseFee")
	}
	// Verify the baseFee is correct based on the parent header.
	expectedBaseFee := kc.NextMagmaBlockBaseFee(parentHeaderNumber, parentHeaderBaseFee, parentHeaderGasUsed)
	if headerBaseFee.Cmp(expectedBaseFee) != 0 {
		return fmt.Errorf("invalid baseFee: have %s, want %s, parentBaseFee %s, parentGasUsed %d",
			headerBaseFee, expectedBaseFee, parentHeaderBaseFee, parentHeaderGasUsed)
	}
	return nil
}

func (kc *KIP71Config) NextMagmaBlockBaseFee(parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) *big.Int {
	// governance parameters
	lowerBoundBaseFee := new(big.Int).SetUint64(kc.LowerBoundBaseFee)
	upperBoundBaseFee := new(big.Int).SetUint64(kc.UpperBoundBaseFee)
	makeEvenByCeil(lowerBoundBaseFee)
	makeEvenByFloor(upperBoundBaseFee)

	// If the parent is the magma disabled block or genesis, then return the lowerBoundBaseFee (default 25ston)
	if parentHeaderNumber.Cmp(new(big.Int).SetUint64(0)) == 0 || parentHeaderBaseFee == nil {
		return makeEvenByFloor(lowerBoundBaseFee)
	}

	var baseFeeDenominator *big.Int
	if kc.BaseFeeDenominator == 0 {
		// To avoid panic, set the fluctuation range small
		baseFeeDenominator = new(big.Int).SetUint64(64)
	} else {
		baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
	}
	gasTarget := kc.GasTarget
	upperGasLimit := kc.MaxBlockGasUsedForBaseFee

	// check the case of upper/lowerBoundBaseFee is updated by governance mechanism
	parentBaseFee := parentHeaderBaseFee
	if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {
		parentBaseFee = upperBoundBaseFee
	} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
		parentBaseFee = lowerBoundBaseFee
	}

	// upper gas limit cut off the impulse of used gas to upper bound
	parentGasUsed := min(parentHeaderGasUsed, upperGasLimit)
	if parentGasUsed == gasTarget {
		return makeEvenByFloor(parentBaseFee)
	} else if parentGasUsed > gasTarget {
		// shortcut. If parentBaseFee is already reached upperbound, do not calculate.
		if parentBaseFee.Cmp(upperBoundBaseFee) == 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		// If the parent block used more gas than its target,
		// the baseFee of the next block should increase.
		// baseFeeDelta = max(1, parentBaseFee * (parentGasUsed - gasTarget) / gasTarget / baseFeeDenominator)
		gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := math.BigMax(x.Div(y, baseFeeDenominator), common.Big1)

		nextBaseFee := x.Add(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(upperBoundBaseFee) > 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	} else {
		// shortcut. If parentBaseFee is already reached lower bound, do not calculate.
		if parentBaseFee.Cmp(lowerBoundBaseFee) == 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		// Otherwise if the parent block used less gas than its target,
		// the baseFee of the next block should decrease.
		// baseFeeDelta = parentBaseFee * (gasTarget - parentGasUsed) / gasTarget / baseFeeDenominator
		gasUsedDelta := new(big.Int).SetUint64(gasTarget - parentGasUsed)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := x.Div(y, baseFeeDenominator)

		nextBaseFee := x.Sub(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(lowerBoundBaseFee) < 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	}

func (v *BlockValidator) verifySeals(header *types.Header) error {
	if header.Number.Uint64() == 0 {
		return nil
	}
	author, err := v.sealer.Author(header)
	if err != nil {
		return err
	}
	committers, err := v.sealer.Committers(header)
	if err != nil {
		return err
	}
	if len(committers) == 0 {
		return istanbul.ErrEmptyCommittedSeals
	}

	blockNum := header.Number.Uint64()

	var rules params.Rules
	if v.config != nil {
		rules = v.config.Rules(new(big.Int).SetUint64(blockNum))
	}

	// Skip module-dependent seal validation when gov/valset modules are not registered.
	if v.mValset == nil || v.mGov == nil {
		return nil
	}

func (p PartialParamSet) Add(name string, value any) error {
	param, ok := Params[ParamName(name)]
	if !ok {
		return ErrInvalidParamName
	}

	cv, err := param.Canonicalizer(value)
	if err != nil {
		return err
	}

	if !param.FormatChecker(cv) {
		return ErrInvalidParamValue
	}

	p[ParamName(name)] = cv
	return nil
}
