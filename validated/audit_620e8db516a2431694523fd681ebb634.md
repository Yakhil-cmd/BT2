### Title
Unvalidated `kip71.gastarget` Governance Parameter Enables Division-by-Zero Panic in `NextMagmaBlockBaseFee`, Permanently Halting the Chain — (File: `kaiax/gov/param.go`, `params/kip71_config.go`)

### Summary

The `kip71.gastarget` governance parameter uses `noopFormatChecker` (no range validation), while the analogous `kip71.basefeedenominator` parameter correctly enforces a non-zero `FormatChecker` **and** has a runtime guard in `NextMagmaBlockBaseFee`. A governance vote setting `kip71.gastarget = 0` passes every validation layer, is ratified at the next epoch, and then causes a Go runtime panic (division by zero) in `NextMagmaBlockBaseFee` on every subsequent block where `parentGasUsed > 0`, permanently halting the chain.

### Finding Description

**Root cause — missing lower-bound in `FormatChecker`:**

In `kaiax/gov/param.go`, `Kip71GasTarget` is registered with `noopFormatChecker`, accepting any `uint64` value including 0: [1](#0-0) 

In contrast, `Kip71BaseFeeDenominator` explicitly rejects zero: [2](#0-1) 

**No consistency check for `GasTarget`:**

`checkConsistency` in `headergov/impl/header.go` lists `gov.Kip71GasTarget` in the catch-all `return nil` branch — no cross-parameter or range check is applied: [3](#0-2) 

**Runtime guard exists for `BaseFeeDenominator` but not for `GasTarget`:**

`NextMagmaBlockBaseFee` in `params/kip71_config.go` explicitly guards against `BaseFeeDenominator == 0`: [4](#0-3) 

No equivalent guard exists for `GasTarget`. When `GasTarget == 0` and `parentGasUsed > 0`, execution reaches: [5](#0-4) 

`new(big.Int).SetUint64(gasTarget)` is zero, and `x.Div(x, zero)` triggers a Go runtime panic.

### Impact Explanation

`NextMagmaBlockBaseFee` is called from two places on every post-Magma block:

1. **Block production** — the proposer calls it to set `header.BaseFee`.
2. **Block verification** — every node calls `VerifyMagmaHeader` → `NextMagmaBlockBaseFee` to validate the incoming block's base fee. [6](#0-5) 

Once `GasTarget = 0` is ratified and the first non-empty block arrives (`parentGasUsed > 0`), every node panics. The chain cannot produce or import any further block. This is a permanent, unrecoverable chain halt — consensus divergence on all honest nodes — matching the allowed impact "consensus divergence on honest nodes."

The corrupted state value is `ParamSet.GasTarget = 0`, stored persistently in the header governance history and applied to every subsequent block.

### Likelihood Explanation

**`none` governance mode (semi-trusted trigger):** Any GC member can cast a vote via `governance_vote("kip71.gastarget", 0)`. The vote passes `FormatChecker` (`noopFormatChecker` → always true) and `checkConsistency` (falls into the `return nil` branch). After one epoch the parameter is ratified. This is a valid semi-trusted trigger: a single rogue or compromised GC member suffices.

**`single` governance mode (Mainnet/Kairos):** Only the governing node can vote, making this a privileged trigger for those networks. However, the code path and the missing guard are identical regardless of mode. [7](#0-6) 

### Recommendation

1. **Add a non-zero `FormatChecker` for `Kip71GasTarget`** in `kaiax/gov/param.go`, mirroring `Kip71BaseFeeDenominator`:

```go
Kip71GasTarget: {
    Canonicalizer: uint64Canonicalizer,
    FormatChecker: func(cv any) bool {
        v, ok := cv.(uint64)
        return ok && v > 0   // GasTarget must be positive to avoid division by zero
    },
    ...
},
```

2. **Add a runtime guard in `NextMagmaBlockBaseFee`** in `params/kip71_config.go`, analogous to the existing `BaseFeeDenominator` guard:

```go
gasTarget := kc.GasTarget
if gasTarget == 0 {
    gasTarget = DefaultGasTarget // or return lowerBoundBaseFee as a safe fallback
}
```

		blockNum                     = header.Number.Uint64()
	)

	vote, err := vb.ToVoteData()
	if err != nil {
		logger.Error("ToVoteData error", "num", blockNum, "vote", vb, "err", err)
		return err
	}

	if gov.DeprecatedAt(vote.Name(), h.ChainConfig.Rules(header.Number)) {
		logger.Error("Vote is deprecated", "num", blockNum, "name", vote.Name())
		return ErrDeprecatedVote
	}

	council, err := h.ValSet.GetCouncil(blockNum)
	if err != nil {
		return err
	}

	// check if the voter is in council
	if !slices.Contains(council, vote.Voter()) {
		return ErrInvalidKeyValue
	}

	// check if Voter is the block proposer.

	if err != nil {
		return err
	}

		return ErrInvalidVoter

		return ErrVotePermissionDenied

func (kc *KIP71Config) VerifyMagmaHeader(headerBaseFee *big.Int, parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) error {
	if headerBaseFee == nil {
		return fmt.Errorf("header is missing baseFee")
	}
	// Verify the baseFee is correct based on the parent header.
	expectedBaseFee := kc.NextMagmaBlockBaseFee(parentHeaderNumber, parentHeaderBaseFee, parentHeaderGasUsed)
	if headerBaseFee.Cmp(expectedBaseFee) != 0 {
		return fmt.Errorf("invalid baseFee: have %s, want %s, parentBaseFee %s, parentGasUsed %d",
			headerBaseFee, expectedBaseFee, parentHeaderBaseFee, parentHeaderGasUsed)
	}
	return nil
}
