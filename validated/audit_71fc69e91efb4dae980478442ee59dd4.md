### Title
Unbounded share accrual permanently freezes an entire lending market - ([File: common/src/rates/scaling.rs])

### Summary
A market can reach a state where the product of its scaled debt or supply shares and the corresponding index exceeds the `i128` RAY domain. `accrue_step` unconditionally converts both totals back to unscaled values before applying the configured index ceiling, so the first subsequent `update_indexes` call reverts with `MathOverflow`. Because every pool mutation performs `global_sync` first, repayment, withdrawal, liquidation, and all other operations on that market continue to revert permanently. [1](#0-0) [2](#0-1) 

### Finding Description
`scaled_to_original` computes `scaled * index / RAY` through `Ray::mul` and has no saturation or domain precondition protecting the multiplication. [3](#0-2)  Interest accrual calls it for both market-wide `borrowed` and `supplied` shares before calculating utilization, the borrow rate, or the capped next borrow index. [1](#0-0) 

The borrow index is nominally capped, but the cap is applied only after `scaled_to_original` has already multiplied the old share total by the old index. Consequently, a large valid market can overflow its aggregate value before the index reaches its protocol ceiling. The in-tree regression test demonstrates this state explicitly: after creating a one-billion whole-token, 18-decimal market at 98% utilization and letting interest accrue, `update_indexes` fails with `MathOverflow` while `borrow_index` remains below `MAX_BORROW_INDEX_RAY`. [4](#0-3) 

An unprivileged caller can trigger the transition through controller `update_indexes`; once the overflowing state exists, other users cannot rescue their positions because every market verb accrues before mutating. [5](#0-4) 

### Impact Explanation
This causes permanent freezing of all funds and debt operations in the affected `(hub, token)` market. Suppliers cannot withdraw, borrowers cannot repay, liquidators cannot liquidate or clean bad debt, and flash/strategy paths touching the market cannot complete. The existing proof test verifies both a withdrawal and a repayment continue to fail after the accrual cliff is reached. [6](#0-5) 

### Likelihood Explanation
The attacker does not need privileged access to trigger the final state transition, but must create or help create an extremely large borrowed market under a valid steep interest-rate configuration. The demonstrated setup uses one billion whole tokens and 98% utilization, which imposes a substantial capital requirement. Nevertheless, ordinary `supply`, `borrow`, and permissionless `update_indexes` entrypoints provide the complete trigger path, and innocent suppliers are frozen with no recovery entrypoint. [7](#0-6) [8](#0-7) 

### Recommendation
Bound total scaled `borrowed` and `supplied` shares so `scaled * MAX_INDEX / RAY` remains representable in `i128`, including headroom for minted revenue shares. Enforce the bound during supply, borrow, strategy debt creation, revenue accrual, market cap changes, and listing validation rather than only relying on nominal token caps. Accrual should also classify share-value overflow before calling `scaled_to_original`, with an explicit recovery path such as a governed bad-debt/settlement operation that does not itself perform the overflowing aggregate valuation.

### Proof of Concept
The existing regression test is a contract-level proof:

```rust
let mut t = LendingTest::new()
    .with_market(big("BIG18", 18, xlm_curve()))
    .with_market(col())
    .with_max_utilization_disabled_all_markets()
    .build();

lift_caps(&t, "BIG18", 18);
lift_caps(&t, "COL", 7);

let principal = BILLION * 10i128.pow(18);
t.supply_raw(BOB, "BIG18", principal);
let debt = principal / 100 * 98;
t.supply_raw(ALICE, "COL", BILLION * 10_000_000 * 3);
t.borrow_raw(ALICE, "BIG18", debt);

loop {
    t.advance_time(YEAR_SECS);
    if let Err(e) = t.try_update_indexes_for(&["BIG18"]) {
        assert_contract_error(Err(e), errors::MATH_OVERFLOW);
        break;
    }
}

assert_contract_error(t.try_withdraw_raw(BOB, "BIG18", 1), errors::MATH_OVERFLOW);
assert_contract_error(t.try_repay(ALICE, "BIG18", 1.0), errors::MATH_OVERFLOW);
```

This corresponds to permissionless controller `supply`, owner-controlled `borrow` for the attacker's own collateralized account, and permissionless `update_indexes`. The assertion that the stored borrow index remains below its ceiling proves the market did not reach the intended graceful saturation state; it became unusable because aggregate share valuation overflowed first. [9](#0-8)

pub(crate) fn global_sync(env: &Env, cache: &mut Cache) {
    if !cache.needs_accrual() {
        return;
    }

    let mut remaining = cache.elapsed_ms();
    while let Some(nonzero) = NonZeroU64::new(remaining) {
        let chunk = nonzero.get().min(MAX_COMPOUND_DELTA_MS);
        accrue_chunk(env, cache, chunk);
        remaining = remaining.saturating_sub(chunk);
    }

    cache.mark_accrued();
```

/// The cliff. A billion whole tokens is `1e36` raw ray; the value ceiling is
/// `i128::MAX`, 170 times that. At the XLM curve's steep segment the index
/// grows past 170x in a few years, and the next accrual panics inside
/// `scaled_to_original`. Every verb accrues first, so the market freezes:
/// no repay, no withdraw, no liquidation. The index cap never engages.
#[test]
fn a_whale_market_at_sustained_high_utilization_hits_the_ray_value_ceiling_before_the_index_cap() {
    let mut t = LendingTest::new()
        .with_market(big("BIG18", 18, xlm_curve()))
        .with_market(col())
        .with_max_utilization_disabled_all_markets()
        .build();
    lift_caps(&t, "BIG18", 18);
    lift_caps(&t, "COL", 7);
    let principal = BILLION * 10i128.pow(18);
    t.supply_raw(BOB, "BIG18", principal);
    let debt = principal / 100 * 98;
    t.supply_raw(ALICE, "COL", BILLION * 10_000_000 * 3);
    t.borrow_raw(ALICE, "BIG18", debt);

    let mut years = 0u32;
    let failure = loop {
        years += 1;
        assert!(
            years <= 40,
            "no cliff within 40 years; the bound in docs/reference/formulas.md is wrong"
        );
        t.advance_time(YEAR_SECS);
        if let Err(e) = t.try_update_indexes_for(&["BIG18"]) {
            break e;
        }
    };
    let failed: Result<(), soroban_sdk::Error> = Err(failure);
    assert_contract_error(failed, errors::MATH_OVERFLOW);
    let last = book(&t, "BIG18");
    assert!(
        last.borrow_index < MAX_BORROW_INDEX_RAY,
        "the index cap did not engage before the value overflow"
    );
    // The market is frozen: exits and repayments accrue first and hit the same panic.
    assert_contract_error(t.try_withdraw_raw(BOB, "BIG18", 1), errors::MATH_OVERFLOW);
    assert_contract_error(t.try_repay(ALICE, "BIG18", 1.0), errors::MATH_OVERFLOW);
```
