### Title
`gh attestation verify` fetches all attestation bundles concurrently with unbounded per-bundle size and unbounded goroutine fan-out, bounded only by attestation *count* - ([File: pkg/cmd/attestation/api/client.go])

### Summary
`GetByDigest` retrieves up to `maxLimitForFlag` (1000) attestations for a digest/owner/repo, then calls `fetchBundleFromAttestations`, which spawns one goroutine per attestation via an unbounded `errgroup.Group` to fetch each bundle's content from an externally supplied `BundleURL`. Each fetch (`getBundle`) reads the entire HTTP response body into memory with `io.ReadAll` before any parsing or cryptographic verification occurs, and there is no cap on individual bundle size or on total buffered bytes across the concurrent fetches — only a count limit is enforced.

### Finding Description
The bounding logic in `FetchParams.Validate` only constrains the *number* of attestations that will be processed (`p.Limit <= 0 || p.Limit > maxLimitForFlag` → reject) [1](#0-0) . Once attestations are fetched, `fetchBundleFromAttestations` iterates over all of them and issues one HTTP fetch per attestation in parallel with no concurrency or size limit set on the `errgroup.Group`: [2](#0-1) 

Each of those parallel fetches calls `getBundle`, which performs `io.ReadAll(resp.Body)` on the response from an attacker/blob-storage-supplied `BundleURL` with no `io.LimitReader` or byte-size ceiling before decompression and unmarshalling: [3](#0-2) 

This is structurally the same bug class as the Besu `FutureMessageBuffer` issue: the caller-facing knob (`Limit`) bounds *count* of buffered/fetched items, but nothing bounds the *byte size* of each item or the aggregate memory footprint of concurrently buffered content before any trust/verification decision is made.

### Impact Explanation
An attacker who controls (or can influence) the attestation set associated with a digest/owner/repo that a victim chooses to run `gh attestation verify` against (e.g., verifying an artifact obtained from, or attributed to, an attacker-controlled repo/org) can cause the CLI to concurrently fetch up to 1000 bundles, each of unbounded size, all fully buffered in memory simultaneously and before any cryptographic verification succeeds or fails. This can exhaust the memory of the machine running `gh attestation verify` (a developer workstation or, more critically, a CI runner performing supply-chain verification), causing a crash/DoS of that verification step.

### Likelihood Explanation
No special privilege is required beyond the attacker being able to have attestations (and their bundle content) associated with an artifact/repo/org that the victim is induced to verify against — a scenario the "attestation verification" and "downloads to disk" attack-surface categories are explicitly meant to cover. The victim only needs to run a normal `gh attestation verify` invocation pointed at attacker-influenced digest/owner/repo, which is a standard, expected usage pattern for supply-chain verification tooling.

### Recommendation
- Bound both the number of concurrent bundle fetches (e.g., `errgroup.Group.SetLimit(n)`) and the total in-flight bytes.
- Replace `io.ReadAll(resp.Body)` in `getBundle` with a size-capped read (e.g., `io.LimitReader` plus checking `Content-Length` where available), rejecting bundles above a sane maximum before decompression/unmarshalling.
- Track and cap cumulative bytes buffered across all attestations being processed for a single `verify` invocation, mirroring the byte-budget fix applied in Besu's `FutureMessageBuffer`.

### Proof of Concept
1. Attacker controls (or is attributed as owner/repo of) a digest with the maximum allowed number of attestations (`maxLimitForFlag` = 1000), each attestation's `BundleURL` pointing to a very large (multi-hundred-MB) response body hosted at an attacker/blob-storage-controlled endpoint.
2. Victim runs `gh attestation verify <artifact> --owner <attacker-owner>` (or `--repo`), a normal invocation of the CLI's built-in supply-chain verification feature.
3. `GetByDigest` → `getAttestations` fetches the full list of up to 1000 attestations (bounded only by count) [4](#0-3) .
4. `fetchBundleFromAttestations` launches ~1000 concurrent goroutines, each calling `getBundle`, which reads its full (large) response body into memory with no size limit [5](#0-4) .
5. The combined unbounded, concurrently-buffered bundle content exhausts available memory on the verifying host before any bundle signature is checked, crashing/hanging the `gh` process (and potentially the host/CI runner).

// FetchParams are the parameters for fetching attestations from the GitHub API
type FetchParams struct {
	Digest        string
	Limit         int
	Owner         string
	PredicateType string
	Repo          string
	Initiator     string
}

func (p *FetchParams) Validate() error {
	if p.Digest == "" {
		return fmt.Errorf("digest must be provided")
	}
	if p.Limit <= 0 || p.Limit > maxLimitForFlag {
		return fmt.Errorf("limit must be greater than 0 and less than or equal to %d", maxLimitForFlag)
	}
	if p.Repo == "" && p.Owner == "" {
		return fmt.Errorf("owner or repo must be provided")
	}
	return nil
}

func (c *LiveClient) getAttestations(params FetchParams) ([]*Attestation, error) {
	u, err := c.buildRequestURL(params)
	if err != nil {
		return nil, err
	}

	var attestations []*Attestation
	var resp AttestationsResponse
	bo := backoff.NewConstantBackOff(getAttestationRetryInterval)

	var pageURL safeurl.SafeURL = u

	// if no attestation or less than limit, then keep fetching
	for pageURL.String() != "" && len(attestations) < params.Limit {
		err := backoff.Retry(func() error {
			newURL, restErr := c.githubAPI.RESTWithNext(c.host, http.MethodGet, pageURL.String(), nil, &resp)
			if restErr != nil {
				if shouldRetry(restErr) {
					return restErr
				}
				return backoff.Permanent(restErr)
			}

			pageURL = safeurl.NewImmutableSafeURL(newURL)

			// filter by the initiator type
			if params.Initiator != "" {
				filtered := make([]*Attestation, 0, len(resp.Attestations))
				for _, att := range resp.Attestations {
					if att.Initiator == params.Initiator {
						filtered = append(filtered, att)
					}
				}
				resp.Attestations = filtered
			}
			attestations = append(attestations, resp.Attestations...)

			return nil
		}, backoff.WithMaxRetries(bo, 3))

		// bail if RESTWithNext errored out
		if err != nil {
			return nil, err
		}
	}

	if len(attestations) == 0 {
		return nil, ErrNoAttestationsFound
	}

	if len(attestations) > params.Limit {
		return attestations[:params.Limit], nil
	}

	return attestations, nil
}

func (c *LiveClient) fetchBundleFromAttestations(attestations []*Attestation) ([]*Attestation, error) {
	fetched := make([]*Attestation, len(attestations))
	g := errgroup.Group{}
	for i, a := range attestations {
		g.Go(func() error {
			if a.Bundle == nil && a.BundleURL == "" {
				return fmt.Errorf("attestation has no bundle or bundle URL")
			}

			// for now, we fall back to the bundle field if the bundle URL is empty
			if a.BundleURL == "" {
				c.logger.VerbosePrintf("Bundle URL is empty. Falling back to bundle field\n\n")
				fetched[i] = &Attestation{
					Bundle: a.Bundle,
				}
				return nil
			}

			// otherwise fetch the bundle with the provided URL
			b, err := c.getBundle(safeurl.NewImmutableSafeURL(a.BundleURL))
			if err != nil {
				return fmt.Errorf("failed to fetch bundle with URL: %w", err)
			}
			fetched[i] = &Attestation{
				Bundle: b,
			}

			return nil
		})
	}

	if err := g.Wait(); err != nil {
		return nil, err
	}

	return fetched, nil
}

func (c *LiveClient) getBundle(url safeurl.SafeURL) (*bundle.Bundle, error) {
	c.logger.VerbosePrintf("Fetching attestation bundle with bundle URL\n\n")

	var sgBundle *bundle.Bundle
	bo := backoff.NewConstantBackOff(getAttestationRetryInterval)
	err := backoff.Retry(func() error {
		resp, err := c.externalHttpClient.Get(url.String())
		if err != nil {
			return fmt.Errorf("request to fetch bundle from URL failed: %w", err)
		}

		if resp.StatusCode >= 500 && resp.StatusCode <= 599 {
			return fmt.Errorf("attestation bundle with URL %s returned status code %d", url.String(), resp.StatusCode)
		}

		defer resp.Body.Close()
		body, err := io.ReadAll(resp.Body)
		if err != nil {
			return fmt.Errorf("failed to read blob storage response body: %w", err)
		}

		var out []byte
		decompressed, err := snappy.Decode(out, body)
		if err != nil {
			return backoff.Permanent(fmt.Errorf("failed to decompress with snappy: %w", err))
		}

		var pbBundle v1.Bundle
		if err = protojson.Unmarshal(decompressed, &pbBundle); err != nil {
			return backoff.Permanent(fmt.Errorf("failed to unmarshal to bundle: %w", err))
		}

		c.logger.VerbosePrintf("Successfully fetched bundle\n\n")

		sgBundle, err = bundle.NewBundle(&pbBundle)
		if err != nil {
			return backoff.Permanent(fmt.Errorf("failed to create new bundle: %w", err))
		}

		return nil
	}, backoff.WithMaxRetries(bo, 3))

	return sgBundle, err
}
