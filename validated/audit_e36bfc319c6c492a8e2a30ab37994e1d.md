### Title
Single-Step `governance.governingnode` Change Without New-Address Council Validation Permanently Locks Governance — (`kaiax/gov/headergov/impl/header.go`)

---

### Summary

In `single` governance mode, the governing node can vote to change `governance.governingnode` to any arbitrary address in a single step. The `checkConsistency` function validates only that the **current** governing node is in the council, but never validates that the **new proposed** governing node address is in the council. If the new address is not a council member, it can never become a block proposer, can never cast a vote, and governance is permanently and irrecoverably locked.

---

### Finding Description

In `kaiax/gov/headergov/impl/header.go`, the `checkConsistency` function handles the `governance.governingnode` vote case: [1](#0-0) 

```go
case gov.GovernanceGoverningNode:
    params := h.GetParamSet(blockNum)
    if params.GovernanceMode != "single" {
        return nil
    }
    council, err := h.ValSet.GetCouncil(blockNum - 1)
    if err != nil {
        return err
    }
    if slices.Contains(council, params.GoverningNode) {
        return nil   // ← checks CURRENT governing node, not vote.Value()
    }
    return ErrGovNodeNotInValSetList
```

`params.GoverningNode` is the **current** governing node retrieved from `GetParamSet(blockNum)`. The **new** proposed address is `vote.Value()`. The function checks the current governing node against the council but never checks `vote.Value()` against the council.

This same function is invoked on both the API path (`api.go` line 74) and the block-verification path (`VerifyVote` → `checkConsistency`): [2](#0-1) [3](#0-2) 

In `single` mode, only the governing node can vote: [4](#0-3) [5](#0-4) 

The `valset` module enforces that only council members can be block proposers, and only proposers can embed votes in block headers: [6](#0-5) 

---

### Impact Explanation

If the governing node votes to change `governance.governingnode` to address `X` where `X ∉ council`:

1. The vote passes `checkConsistency` (current governing node is in council — check passes).
2. The vote is ratified at the next epoch boundary and takes effect at `(k+1)*epoch`.
3. `X` becomes the new governing node.
4. `X` is not in the council → `X` can never be selected as a block proposer.
5. `X` can never embed a `header.Vote` → `X` can never cast any governance vote.
6. In `single` mode, no other address can vote.
7. **Governance is permanently locked**: no further changes to `reward.mintingamount`, `reward.ratio`, `reward.minimumstake`, `governance.governancemode`, `governance.govparamcontract`, validator set parameters, or any other governance parameter are possible.

The corrupted protected-state value is `governance.governingnode` stored in the ratified `header.Governance` field at the epoch block, which propagates into `headergov.History` and is read by every subsequent `GetParamSet` call. [7](#0-6) 

---

### Likelihood Explanation

Mainnet and Kairos both operate in `single` mode with a single governing node: [8](#0-7) 

A single keystroke error (transposed hex digit, wrong address paste) by the governing node operator when calling `governance_vote("governance.governingnode", <wrong_address>)` is sufficient. The epoch delay (604,800 blocks ≈ 1 week on Mainnet) provides a window to notice the mistake, but once the epoch boundary passes and the `header.Governance` field is written, the change is irreversible with no recovery path.

---

### Recommendation

Add a council-membership check on the **new** proposed governing node value inside `checkConsistency`:

```go
case gov.GovernanceGoverningNode:
    params := h.GetParamSet(blockNum)
    if params.GovernanceMode != "single" {
        return nil
    }
    council, err := h.ValSet.GetCouncil(blockNum - 1)
    if err != nil {
        return err
    }
    if !slices.Contains(council, params.GoverningNode) {
        return ErrGovNodeNotInValSetList
    }
    // NEW: also validate the proposed new governing node is in the council
    newGovNode, ok := vote.Value().(common.Address)
    if !ok || !slices.Contains(council, newGovNode) {
        return ErrGovNodeNotInValSetList
    }
    return nil
```

Alternatively, adopt a two-step pattern: the current governing node proposes a `pendingGoverningNode`, and the pending address must confirm by casting an acceptance vote from a block it proposes (proving it is a valid council member and controls the key).

---

### Proof of Concept

**Setup**: Mainnet-like chain, `governance.governancemode = "single"`, `governance.governingnode = A`, `council = {A, B, C}`, `epoch = 604800`.

**Attack sequence**:

1. Governing node operator calls:
   ```
   governance_vote("governance.governingnode", "0xDEAD...BEEF")
   ```
   where `0xDEAD...BEEF` is a typo / wrong address not in `{A, B, C}`.

2. `checkConsistency` is called with `blockNum = N`:
   - `params.GoverningNode = A`
   - `council = {A, B, C}`
   - `slices.Contains(council, A)` → `true` → returns `nil` (no error)
   - `vote.Value() = 0xDEAD...BEEF` is **never checked**.

3. The vote is embedded in `header.Vote` when node A next proposes a block.

4. At epoch block `k*604800`, `header.Governance` is written with `{"governance.governingnode": "0xDEAD...BEEF"}`.

5. From block `(k+1)*604800` onward, `GetParamSet` returns `GoverningNode = 0xDEAD...BEEF`.

6. `0xDEAD...BEEF ∉ council` → it is never selected as proposer → it can never embed a vote → governance is permanently frozen. [9](#0-8) [2](#0-1)

func (h *headerGovModule) VerifyVote(header *types.Header) error {
	if len(header.Vote) == 0 {
		return nil
	}

	var (
		vb       headergov.VoteBytes = header.Vote
		blockNum                     = header.Number.Uint64()
	)

	vote, err := vb.ToVoteData()
	if err != nil {
		logger.Error("ToVoteData error", "num", blockNum, "vote", vb, "err", err)
		return err
	}

	if gov.DeprecatedAt(vote.Name(), h.ChainConfig.Rules(header.Number)) {
		logger.Error("Vote is deprecated", "num", blockNum, "name", vote.Name())
		return ErrDeprecatedVote
	}

	council, err := h.ValSet.GetCouncil(blockNum)
	if err != nil {
		return err
	}

	// check if the voter is in council
	if !slices.Contains(council, vote.Voter()) {
		return ErrInvalidKeyValue
	}

	// check if Voter is the block proposer.
	author, err := h.Chain.Sealer().Author(header)
	if err != nil {
		return err
	}
	if author != vote.Voter() {
		return ErrInvalidVoter
	}

	// In single mode, only the governing node can write header.Vote after Permissionless.
	params := h.GetParamSet(blockNum)
	if h.ChainConfig.IsPermissionlessForkEnabled(new(big.Int).SetUint64(blockNum)) &&
		params.GovernanceMode == "single" &&
		vote.Voter() != params.GoverningNode {
		return ErrVotePermissionDenied
	}

	return h.checkConsistency(blockNum, vote)

// checkConsistency checks if vote values are consistent with chain states such as other parameters and validator set.
func (h *headerGovModule) checkConsistency(blockNum uint64, vote headergov.VoteData) error {
	switch vote.Name() {
	case gov.GovernanceGoverningNode:
		params := h.GetParamSet(blockNum)

		// compare with governing node only in single mode.
		if params.GovernanceMode != "single" {
			return nil
		}

		// we'll use blockNum-1 for the blocknumber of GetCouncil since blockNum cannot be available(eg. vote)
		// it's definite that the valSet vote is not included in this block
		// so the council(blockNum - 1) and council(blockNum) should be same
		council, err := h.ValSet.GetCouncil(blockNum - 1)
		if err != nil {
			return err
		}

		if slices.Contains(council, params.GoverningNode) {
			return nil
		}
		return ErrGovNodeNotInValSetList
	case gov.Kip71LowerBoundBaseFee:
		params := h.GetParamSet(blockNum)
		if vote.Value().(uint64) > params.UpperBoundBaseFee {
			return ErrLowerBoundBaseFee
		} else {
			return nil
		}
	case gov.Kip71UpperBoundBaseFee:
		params := h.GetParamSet(blockNum)
		if vote.Value().(uint64) < params.LowerBoundBaseFee {
			return ErrUpperBoundBaseFee
		} else {
			return nil
		}
	case gov.AddValidator, gov.RemoveValidator:
		params := h.GetParamSet(blockNum)

		// compare with governing node only in single mode.
		if params.GovernanceMode != "single" {
			return nil
		}
		if slices.Contains(vote.Value().([]common.Address), params.GoverningNode) {
			return ErrGovNodeInValSetVoteValue
		}
		return nil
		// These votes are valid as long as it passes the format checks in NewVoteData(). No more checks here.
	case gov.GovernanceDeriveShaImpl, gov.GovernanceGovParamContract, gov.GovernanceGovernanceMode, gov.GovernanceUnitPrice,
		gov.IstanbulCommitteeSize, gov.IstanbulEpoch, gov.IstanbulPolicy,
		gov.Kip71BaseFeeDenominator, gov.Kip71GasTarget, gov.Kip71MaxBlockGasUsedForBaseFee,
		gov.RewardDeferredTxFee, gov.RewardKip82Ratio, gov.RewardMintingAmount, gov.RewardMinimumStake,
		gov.RewardProposerUpdateInterval, gov.RewardRatio, gov.RewardStakingRewardThreshold,
		gov.RewardStakingUpdateInterval, gov.RewardUseFlexReward, gov.RewardUseGiniCoeff:
		return nil
	default:
		return ErrInvalidKeyValue
	}
}

func (api *headerGovAPI) Vote(name string, value any) (string, error) {
	var (
		voter     = api.h.nodeAddress
		nextBlock = api.h.Chain.CurrentBlock().NumberU64() + 1
		gp        = api.h.GetParamSet(nextBlock)
		gMode     = gp.GovernanceMode
	)

	if gMode == "single" && voter != gp.GoverningNode {
		return "", ErrVotePermissionDenied
	}

	vote := headergov.NewVoteData(voter, name, value)
	if vote == nil {
		return "", ErrInvalidKeyValue
	}

	if gov.DeprecatedAt(vote.Name(), api.h.ChainConfig.Rules(new(big.Int).SetUint64(nextBlock))) {
		return "", ErrDeprecatedVote
	}

	err := api.h.checkConsistency(nextBlock, vote)
	if err != nil {
		return "", err
	}

	// TODO-kaiax: add removevalidator vote check

	api.h.PushMyVotes(vote)
	return "(kaiax) Your vote is prepared. It will be put into the block header or applied when your node generates a block as a proposer. Note that your vote may be duplicate.", nil
