### Title
`pallet_transaction_storage::store`/`renew` bypass the account/preimage authorization model entirely - ([File: substrate/frame/transaction-storage/src/lib.rs])

### Summary
The pallet's design (mirrored from the Polkadot Bulletin Chain use case, see the `TODO` link at line 63) is to restrict who may write "off-chain indexed" data via a permission system: only an account with an `AuthorizationScope::Account` grant, or anyone submitting content matching an `AuthorizationScope::Preimage` grant, should be able to call `store`/`renew`, bounded by the `AuthorizationExtent { transactions, bytes }` and an expiry block. However, `store` (call_index 0) and `renew` (call_index 1) only call `ensure_signed(origin)?` and charge a fee; they never read `Authorizations::<T>`, never decrement the granted extent, and never check expiry [2](#0-1) [3](#0-2) .

### Finding Description
The code comments in both `store` and `renew` explicitly acknowledge that authorization/size validation is supposed to happen in `pre_dispatch`/`pre_dispatch_signed`: *"In the case of a regular unsigned transaction, this should have been checked by pre_dispatch. In the case of a regular signed transaction, this should have been checked by pre_dispatch_signed."* [4](#0-3) . But no `ValidateUnsigned`, `SignedExtension`, or `TransactionExtension` implementation exists anywhere in this crate (nor is one wired to it in the mock runtime) [5](#0-4) , and the only `#[pallet::call]` entries are `store`, `renew`, and the inherent-only `check_proof` — there is no dispatchable to populate `Authorizations::<T>` in the first place [6](#0-5) .

This is the direct structural analog of CVE-2024-48645: a "function" (here, `store`/`renew`, the pallet's equivalent of the mod's "function files") that is supposed to require an authorization grant, but the missing-authorization check (CWE-862) means any caller who merely satisfies `ensure_signed` can invoke it — the intended access-control gate (`Authorizations`) is entirely dead code, never read on the write path.

### Impact Explanation
Any signed account can call `store`/`renew` and pay only the per-byte/per-entry fee (`ByteFee`/`EntryFee`), completely bypassing the intended authorization/quota system this pallet was built to enforce. In the Bulletin Chain design this authorization system is the actual gatekeeper for what's allowed to be indexed and retained by validators (an unpermissioned/expensive validator duty); bypassing it means unauthorized parties can force validators to fetch/prove/retain arbitrary chunked data up to `MaxTransactionSize`/`MaxBlockTransactions` limits, defeating the whole point of the permissioning model. Whether this rises to a *Critical/High* on a live Parity/Snowbridge bounty program depends on where `pallet_transaction_storage` is actually deployed with this authorization model as its security boundary; I could not confirm a currently deployed runtime relying on it (its only current consumers appear to be documentation/tests and the `TODO` referencing the separate `polkadot-bulletin-chain` repository, not part of this scan's scope).

### Likelihood Explanation
High for the code path itself — no privileged role, governance action, or off-chain infrastructure is needed; a normal signed account with enough balance to pay the fee reaches `store`/`renew` directly, and there is no code path enforcing the authorization/quota. The remaining uncertainty is only whether this crate as shipped in this repo is wired into any live runtime with the fee model being sufficient (i.e., whether the missing authorization check is actually load-bearing for security anywhere), which I cannot verify from the available index (this pallet's `Cargo.toml`/runtime consumers were not found in this scope).

### Recommendation
Add an authorization check in both `store` and `renew`: look up `Authorizations::<T>::get(&AuthorizationScope::Account(sender.clone()))` (or the `Preimage(content_hash)` scope for `store`), reject with `Error::<T>::AuthorizationNotFound` if absent or expired, decrement the `AuthorizationExtent.transactions`/`.bytes` counters, and add dispatchables (guarded by an appropriate origin, e.g. root/governance) to grant/refresh `Account`/`Preimage` authorizations, matching the already-defined `AccountAuthorized`/`PreimageAuthorized`/`*Refreshed`/`Expired*Removed` events.

### Proof of Concept
Not executed against a live network. Local reasoning path (matches existing test harness at `substrate/frame/transaction-storage/src/tests.rs`, using `mock.rs`'s `Test` runtime): call `TransactionStorage::store(RuntimeOrigin::signed(2), data)` for account `2`, which per `mock.rs` genesis has balance `100` and no entry whatsoever in `Authorizations::<Test>` (there's no call to create one). With `entry_fee = 200` > balance `100`, this particular mock genesis happens to make the call fail on the *fee*, not on authorization — which itself confirms the fee, not the authorization system, is the only functioning gate; increasing account `2`'s balance (or using account `1`, funded with `1_000_000_000`) would let `store` succeed with zero entries in `Authorizations::<Test>`, demonstrating the missing-authorization bypass. I was not able to execute this in a sandbox (no filesystem/terminal access in this session); the claim is based on direct code inspection of `store`/`renew` showing no read of the `Authorizations` map, corroborated by the whole-repo grep showing the authorization error/event identifiers are unused outside this one file.

	impl<T: Config> Pallet<T> {
		/// Index and store data off chain. Minimum data size is 1 byte, maximum is
		/// `MaxTransactionSize`. Data will be removed after `RetentionPeriod` blocks, unless
		/// `renew` is called.
		///
		/// Emits [`Stored`](Event::Stored) when successful.
		///
		/// ## Complexity
		///
		/// O(n*log(n)) of data size, as all data is pushed to an in-memory trie.
		#[pallet::call_index(0)]
		#[pallet::weight(T::WeightInfo::store(data.len() as u32))]
		pub fn store(origin: OriginFor<T>, data: Vec<u8>) -> DispatchResult {
			// In the case of a regular unsigned transaction, this should have been checked by
			// pre_dispatch. In the case of a regular signed transaction, this should have been
			// checked by pre_dispatch_signed.
			Self::ensure_data_size_ok(data.len())?;
			let sender = ensure_signed(origin)?;
			Self::apply_fee(sender, data.len() as u32)?;

			// Chunk data and compute storage root
			let chunks: Vec<_> = data.chunks(CHUNK_SIZE).map(|c| c.to_vec()).collect();
			let chunk_count = chunks.len() as u32;
			debug_assert_eq!(chunk_count, num_chunks(data.len() as u32));
			let root = sp_io::trie::blake2_256_ordered_root(chunks, sp_runtime::StateVersion::V1);

			let content_hash = sp_io::hashing::blake2_256(&data);
			let extrinsic_index =
				frame_system::Pallet::<T>::extrinsic_index().ok_or(Error::<T>::BadContext)?;
			sp_io::transaction_index::index(extrinsic_index, data.len() as u32, content_hash);

			let mut index = 0;
			BlockTransactions::<T>::mutate(|transactions| {
				if transactions.len() + 1 > T::MaxBlockTransactions::get() as usize {
					return Err(Error::<T>::TooManyTransactions);
				}
				let total_chunks = TransactionInfo::total_chunks(&transactions) + chunk_count;
				index = transactions.len() as u32;
				transactions
					.try_push(TransactionInfo {
						chunk_root: root,
						size: data.len() as u32,
						content_hash: content_hash.into(),
						block_chunks: total_chunks,
					})
					.map_err(|_| Error::<T>::TooManyTransactions)
			})?;
			Self::deposit_event(Event::Stored { index, content_hash });
			Ok(())
		}

		/// Renew previously stored data. Parameters are the block number that contains previous
		/// `store` or `renew` call and transaction index within that block. Transaction index is
		/// emitted in the `Stored` or `Renewed` event. Applies same fees as `store`.
		///
		/// Emits [`Renewed`](Event::Renewed) when successful.
		///
		/// ## Complexity
		///
		/// O(1).
		#[pallet::call_index(1)]
		#[pallet::weight(T::WeightInfo::renew())]
		pub fn renew(
			origin: OriginFor<T>,
			block: BlockNumberFor<T>,
			index: u32,
		) -> DispatchResultWithPostInfo {
			let sender = ensure_signed(origin)?;
			let info = Self::transaction_info(block, index).ok_or(Error::<T>::RenewedNotFound)?;

			// In the case of a regular unsigned transaction, this should have been checked by
			// pre_dispatch. In the case of a regular signed transaction, this should have been
			// checked by pre_dispatch_signed.
			Self::ensure_data_size_ok(info.size as usize)?;

			let extrinsic_index =
				frame_system::Pallet::<T>::extrinsic_index().ok_or(Error::<T>::BadContext)?;
			Self::apply_fee(sender, info.size)?;
			let content_hash = info.content_hash.into();
			sp_io::transaction_index::renew(extrinsic_index, content_hash);

			let mut index = 0;
			BlockTransactions::<T>::mutate(|transactions| {
				if transactions.len() + 1 > T::MaxBlockTransactions::get() as usize {
					return Err(Error::<T>::TooManyTransactions);
				}
				let chunks = num_chunks(info.size);
				let total_chunks = TransactionInfo::total_chunks(&transactions) + chunks;
				index = transactions.len() as u32;
				transactions
					.try_push(TransactionInfo {
						chunk_root: info.chunk_root,
						size: info.size,
						content_hash: info.content_hash,
						block_chunks: total_chunks,
					})
					.map_err(|_| Error::<T>::TooManyTransactions)
			})?;
			Self::deposit_event(Event::Renewed { index, content_hash });
			Ok(().into())
		}

		/// Check storage proof for block number `block_number() - RetentionPeriod`. If such a block
		/// does not exist, the proof is expected to be `None`.
		///
		/// ## Complexity
		///
		/// Linear w.r.t the number of indexed transactions in the proved block for random probing.
		/// There's a DB read for each transaction.
		#[pallet::call_index(2)]
		#[pallet::weight((T::WeightInfo::check_proof_max(), DispatchClass::Mandatory))]
		pub fn check_proof(
			origin: OriginFor<T>,
			proof: TransactionStorageProof,
		) -> DispatchResultWithPostInfo {
			ensure_none(origin)?;
			ensure!(!ProofChecked::<T>::get(), Error::<T>::DoubleCheck);

			// Get the target block metadata.
			let number = frame_system::Pallet::<T>::block_number();
			let period = Self::retention_period();
			let target_number = number.saturating_sub(period);
			ensure!(!target_number.is_zero(), Error::<T>::UnexpectedProof);
			let transactions =
				Transactions::<T>::get(target_number).ok_or(Error::<T>::MissingStateData)?;

			// Verify the proof with a "random" chunk (randomness is based on the parent hash).
			let parent_hash = frame_system::Pallet::<T>::parent_hash();
			Self::verify_chunk_proof(proof, parent_hash.as_ref(), transactions.to_vec())?;
			ProofChecked::<T>::put(true);
			Self::deposit_event(Event::ProofChecked);
			Ok(().into())
		}
	}
