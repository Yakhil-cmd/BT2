The Scylla CVE-2022-29240 root cause is a C++ decompression path that trusts an attacker-supplied "uncompressed length" field, allocates a buffer sized to that untrusted length, and only writes the actual (possibly smaller) decompressed bytes into it — leaving the unwritten tail as uninitialized memory that later gets read and potentially transmitted (auth bypass / info leak).

The closest analog in this codebase is `sp_maybe_compressed_blob::decompress` [1](#0-0)  which is used for PoV and runtime-code decompression in `cumulus/client/pov-recovery/src/lib.rs`, `cumulus/bin/pov-validator/src/main.rs`, and `substrate/client/executor/common/src/runtime_blob/runtime_blob.rs` [2](#0-1) . This function does not accept or trust any attacker-supplied "uncompressed size" field at all — it only uses `blob.len()` (the compressed input length) as a capacity hint for `Vec::with_capacity`, and the actual buffer contents are populated exclusively through the safe `Read::read_to_end` API, which only ever appends bytes that were genuinely decoded by the `zstd::Decoder` [3](#0-2) . There is no `unsafe` code, no `set_len`, and no `MaybeUninit` usage in this decompression path, so there is no mechanism by which uninitialized memory could be left in the output buffer and subsequently exposed — the Rust `Vec`/`Read` safety guarantees make the exact bug class structurally impossible here.

I also checked other decompression-adjacent code in the PVF worker and Snowbridge beacon-client paths for any raw/unsafe buffer pre-allocation tied to attacker-controlled length fields (`Vec::with_capacity`/`set_len`/`MaybeUninit` grep across `polkadot/node/core/pvf/**`) and found no such pattern that mirrors the Scylla flaw. Since there is no reachable code path where a user-controlled "claimed length" is used to size a buffer that is then only partially overwritten before being read/used, this bug class does not have a demonstrable analog in the Polkadot SDK.

fn read_from_decoder(
	decoder: impl Read,
	blob_len: usize,
	bomb_limit: usize,
) -> Result<Vec<u8>, Error> {
	let mut decoder = decoder.take((bomb_limit + 1) as u64);

	let mut buf = Vec::with_capacity(blob_len);
	decoder.read_to_end(&mut buf).map_err(|_| Error::Invalid)?;

	if buf.len() <= bomb_limit {
		Ok(buf)
	} else {
		Err(Error::PossibleBomb)
	}
}
