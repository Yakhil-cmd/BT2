### Title
Pre-Permissionless Single-Mode Governance Bypass: Non-Governing Council Member Can Seize GoverningNode Role — (`kaiax/gov/headergov/impl/header.go`)

---

### Summary

`VerifyVote` gates the single-mode restriction (only the governing node may vote) behind `IsPermissionlessForkEnabled`. Pre-Permissionless, any council member who becomes a block proposer can cast a governance vote in single mode, including a vote to change `governance.governingnode` to their own address. The ratification path (`getExpectedGovernance`) applies no single-mode filter, so the vote is ratified at the next epoch block and the attacker becomes the governing node.

---

### Finding Description

In `VerifyVote`, the single-mode authority check reads:

```go
// In single mode, only the governing node can write header.Vote after Permissionless.
if h.ChainConfig.IsPermissionlessForkEnabled(new(big.Int).SetUint64(blockNum)) &&
    params.GovernanceMode == "single" &&
    vote.Voter() != params.GoverningNode {
    return ErrVotePermissionDenied
}
``` [1](#0-0) 

The guard is conjunctive: all three conditions must be true to reject the vote. Pre-Permissionless, `IsPermissionlessForkEnabled` returns `false`, so the entire check is skipped. Any council member who is the block proposer can write any governance vote, including `governance.governingnode`.

The `checkConsistency` function for `GovernanceGoverningNode` only verifies that the *current* governing node is still in the council — it does not validate the *proposed new value* nor restrict who may cast the vote:

```go
case gov.GovernanceGoverningNode:
    params := h.GetParamSet(blockNum)
    if params.GovernanceMode != "single" {
        return nil
    }
    council, err := h.ValSet.GetCouncil(blockNum - 1)
    ...
    if slices.Contains(council, params.GoverningNode) {
        return nil
    }
    return ErrGovNodeNotInValSetList
``` [2](#0-1) 

The ratification function `getExpectedGovernance` collects all stored votes from the previous epoch with no single-mode filter:

```go
for _, voteBlock := range sortedVoteBlocks {
    vote := prevEpochVotes[voteBlock]
    govs.Add(string(vote.Name()), vote.Value())
}
``` [3](#0-2) 

The codebase's own test explicitly documents this as the current behavior:

```go
t.Run("pre-permissionless allows non-governing node", func(t *testing.T) {
    config.PermissionlessCompatibleBlock = nil
    ...
    err = h.VerifyVote(&types.Header{Number: big.NewInt(1), Vote: vb, Extra: extra})
    assert.NoError(t, err)
})
``` [4](#0-3) 

---

### Impact Explanation

After ratification, `GetParamSet` returns the attacker's address as `GoverningNode`. Post-Permissionless, the `ErrVotePermissionDenied` guard then enforces single-mode exclusively for the attacker's address, locking out the legitimate governing node from all future governance parameter changes. This is a durable, on-chain governance privilege escalation affecting all parameters controlled by header governance (minting amount, reward ratios, committee size, unit price, etc.). [5](#0-4) 

---

### Likelihood Explanation

- The attacker must be a council (GC) member — a semi-trusted but non-governing participant.
- The attacker must be a block proposer — this occurs in normal round-robin rotation; no special timing is required beyond waiting for one's proposer turn.
- The chain must be pre-Permissionless fork — this is the current state of Mainnet and Kairos, both of which operate in single mode.
- No majority-validator collusion, no key compromise, and no external service is required.

---

### Recommendation

Move the single-mode authority check out of the `IsPermissionlessForkEnabled` guard so it applies unconditionally whenever `GovernanceMode == "single"`:

```go
params := h.GetParamSet(blockNum)
if params.GovernanceMode == "single" && vote.Voter() != params.GoverningNode {
    return ErrVotePermissionDenied
}
```

Additionally, `getExpectedGovernance` should filter votes against the governing node when in single mode, so that even if a rogue vote is stored (e.g., from a chain imported before the fix), it is not ratified.

---

### Proof of Concept

1. Deploy a chain with `governance.governancemode = "single"`, `governance.governingnode = A`, council = `{A, B}`, `PermissionlessCompatibleBlock = nil`.
2. Node B (non-governing council member) calls `governance_vote("governance.governingnode", B_address)`.
3. When B becomes block proposer, the vote is written to `header.Vote`.
4. `VerifyVote` is called: voter B is in council ✓, B is the proposer ✓, `IsPermissionlessForkEnabled` = false → single-mode check skipped ✓, `checkConsistency` passes (A is still in council) ✓.
5. `PostInsertBlock → HandleVote → AddVote` stores the vote.
6. At the next epoch block, `getExpectedGovernance` includes B's vote; the epoch block proposer writes `header.Governance = {"governance.governingnode": B}`.
7. `VerifyGov` accepts it (matches expected). `HandleGov → AddGov` persists it.
8. `GetParamSet` now returns `GoverningNode = B`.
9. Post-Permissionless, B is the sole authorized governance voter; A is locked out. [6](#0-5)

func (h *headerGovModule) PostInsertBlock(b *types.Block) error {
	if len(b.Header().Vote) > 0 {
		var vb headergov.VoteBytes = b.Header().Vote
		vote, err := vb.ToVoteData()
		if err != nil {
			logger.Error("ToVoteData error", "vote", vb, "err", err)
			return err
		}
		err = h.HandleVote(b.NumberU64(), vote)
		if err != nil {
			logger.Error("HandleVote error", "vote", vb, "err", err)
			return err
		}
	}

	if len(b.Header().Governance) > 0 {
		var gb headergov.GovBytes = b.Header().Governance
		gov, err := gb.ToGovData()
		if err != nil {
			logger.Error("DeserializeHeaderGov error", "governance", gb, "err", err)
			return err
		}
		err = h.HandleGov(b.NumberU64(), gov)
		if err != nil {
			logger.Error("HandleGov error", "governance", gb, "err", err)
			return err
		}
	}

	return nil
}

func (h *headerGovModule) HandleVote(blockNum uint64, vote headergov.VoteData) error {
	// if governance vote (i.e., not validator vote), add to vote
	if _, ok := gov.Params[vote.Name()]; ok {
		h.AddVote(blockNum, vote)
		InsertVoteDataBlockNum(h.ChainKv, blockNum)
	}

	// if the vote was mine, remove it.
	h.removeMyVote(vote)

	return nil
}
