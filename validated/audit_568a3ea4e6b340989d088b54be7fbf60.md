### Title
Missing Minimum-Council-Size Check on `governance.removevalidator` Votes Allows Single Proposer to Drain Validator Set — (`kaiax/gov/headergov/impl/header.go`)

### Summary

The `checkConsistency` function that validates `governance.removevalidator` votes performs no check that the resulting council will retain a minimum number of validators sufficient for consensus. A single council member who becomes a block proposer can cast a vote removing all other validators in one atomic operation, reducing the council to one member and gaining permanent unilateral control over block production.

### Finding Description

In `kaiax/gov/headergov/impl/header.go`, the `checkConsistency` function handles `AddValidator` and `RemoveValidator` votes. For `RemoveValidator`, the only guard in `single` governance mode is that the governing node's address is not included in the removal list. No check verifies that the post-removal council size remains above any minimum threshold: [1](#0-0) 

The vote is then applied unconditionally in `applyVote` in `kaiax/valset/impl/getter_council.go`, which iterates the removal list and removes each address from the council in-place, with no floor on the resulting size: [2](#0-1) 

The `Vote` API in `kaiax/gov/headergov/impl/api.go` even contains an explicit `// TODO-kaiax: add removevalidator vote check` comment, confirming the guard is known to be absent: [3](#0-2) 

The council update takes effect at the very next block (not at an epoch boundary), as `applyVote` is called from `PostInsertBlock`: [4](#0-3) 

### Impact Explanation

After the vote is applied, `Council(N+1) = {governingNode}` (one validator). The Istanbul consensus quorum formula in `calcQuorumSize` returns `size` when `size < 4`, so with one qualified validator quorum equals 1: [5](#0-4) 

The sole remaining validator can now propose and commit every block without any other participant, constituting a complete validator privilege escalation. All future block rewards, transaction ordering, and state transitions are under the control of one address. In `none` governance mode where the governing node address is the zero address (not a real council member), the attacker can include themselves in the removal list, potentially emptying the council entirely and halting consensus permanently.

### Likelihood Explanation

The trigger is a single council member who wins a block proposal slot — a semi-trusted actor, not a majority. In `none` governance mode any council member can cast the vote; in `single` mode the governing node can do so. The vote accepts a list of addresses in one call (confirmed by the multi-address test path in `execution_test.go`), so a single block suffices. The effect is irreversible without an `addvalidator` vote, which itself requires a proposer slot. [6](#0-5) 

### Recommendation

Add a post-removal council-size check inside `checkConsistency` for `RemoveValidator` votes. Before accepting the vote, simulate the removal against the current council and reject it if the resulting council size would fall below a protocol-defined minimum (e.g., 1 or a BFT-safe floor such as 4). The check should be applied both in the `Vote` API path and in `VerifyVote` / `checkConsistency` so that a malicious proposer cannot bypass it by writing the vote directly into a block header.

### Proof of Concept

1. Chain starts with council `[A, B, C, D]` in `none` governance mode; governing node = `A`.
2. Validator `A` wins a proposer slot at block N.
3. `A` calls `governance_vote("governance.removevalidator", "B,C,D")`.
4. The vote is written into block N's `header.Vote`.
5. `VerifyVote` → `checkConsistency` → returns `nil` (no size check).
6. `PostInsertBlock` → `applyVote` removes B, C, D; council becomes `[A]`.
7. From block N+1 onward, `GetQualifiedValidators` returns `[A]`; `calcQuorumSize(1, committeeSize)` = 1.
8. `A` proposes and commits every subsequent block alone, controlling all state transitions and reward distribution. [7](#0-6) [8](#0-7) [3](#0-2)

func applyVote(header *types.Header, council *valset.AddressSet, governingNode common.Address) bool {
	voteKey, addresses, ok := parseValidatorVote(header)
	if !ok {
		return false
	}

	originalSize := council.Len()
	for _, address := range addresses {
		if address == governingNode {
			continue
		}
		switch voteKey {
		case gov.AddValidator:
			if !council.Contains(address) {
				council.Add(address)
			}
		case gov.RemoveValidator:
			if council.Contains(address) {
				council.Remove(address)
			}
		}
	}
	return originalSize != council.Len()

func calcQuorumSize(qualifiedLen int, committeeSize uint64) int {
	size := min(qualifiedLen, int(committeeSize))
	if size < 4 {
		return size
	}
	return int(math.Ceil(float64(2*size) / 3))
}
