### Title
Unsanitized attacker-controlled certificate extension strings (BuildConfigURI/BuildSignerURI) printed to terminal via PrintBulletPoints - (File: pkg/cmd/attestation/verify/verify.go)

### Summary
In `runVerify`, the human-readable output path extracts `BuildConfigURI` and `BuildSignerURI` from the Sigstore certificate extensions via `extractAttestationDetail` and prints the resulting strings through `opts.Logger.PrintBulletPoints`, which writes them with plain `fmt.Fprintln`/`fmt.Fprintf` with no ANSI/control-character sanitization. Since these extension values come from a certificate whose issuer is controllable by the user via `--cert-oidc-issuer` (a "custom OIDC issuer"), and are only weakly constrained by regex extraction, an attacker who controls a custom OIDC issuer/certificate can embed terminal control sequences or misleading text in these fields that get echoed verbatim to the victim's terminal.

### Finding Description
`runVerify` reads `v.VerificationResult.Signature.Certificate.Extensions.BuildConfigURI` / `BuildSignerURI` and passes them through `extractAttestationDetail`, which does nothing but regex-extract substrings (no character sanitization) [1](#0-0) . The extracted strings are placed directly into `rows` and printed via `opts.Logger.PrintBulletPoints(rows)` [2](#0-1) .

`Handler.PrintBulletPoints` builds the output with `fmt.Sprintf`/string concatenation and writes it with `fmt.Fprintln(h.IO.ErrOut, info)` — there is no call to any ANSI-sanitizing helper (e.g. `asciisanitizer.Sanitizer`, `iostreams.Untrusted`, or `ContainsEscapeSequence`) anywhere in this path [3](#0-2) . This is inconsistent with other parts of the codebase that explicitly treat externally-sourced strings as untrusted and sanitize them before terminal output, e.g. `iostreams.Untrusted.String()` [4](#0-3)  and `sanitizeForTerminal` in the skills list command [5](#0-4) , showing the project is aware of this exact class of risk elsewhere but this specific path was not brought in line with it.

However, the claim of an *authentication/identity bypass* (i.e., that the "✓ Verification succeeded" trust summary is falsely shown for an unrelated workflow) does not hold: `verifyCertExtensions` strictly enforces `SourceRepositoryOwnerURI` (and `SourceRepositoryURI` if provided) and `Issuer` against the values the victim supplied via `--owner`/`--repo`/`--cert-oidc-issuer` before the verification result is ever considered "verified" [6](#0-5) . `BuildConfigURI`/`BuildSignerURI` are display-only fields, not the trust boundary — the actual policy that gates "Verification succeeded" is `SourceRepositoryOwnerURI`/`SourceRepositoryURI`/`Issuer`/SAN checks in `EnforcementCriteria` and `verifyCertExtensions`, which a custom-issuer attacker cannot forge to impersonate a repo they don't own. So an attacker cannot make the victim believe an "unrelated workflow" attestation is legitimate through this bug — they can only control what text is echoed for their own successfully-verified attestation.

### Impact Explanation
This reduces to a terminal-output injection issue (misleading formatting, cursor manipulation, hidden/overwritten text in the CLI's stderr bullet-point display), not an authorization or verification bypass. Actual scoped impact: an attacker who controls a custom OIDC issuer and gets a victim to run `gh attestation verify --cert-oidc-issuer <attacker-issuer>` against their own (already correctly attributed) artifact could inject terminal escape sequences into the printed "Build workflow"/"Signer workflow" bullet lines, potentially obscuring or spoofing subsequent terminal content in that session. This does not achieve code execution, credential exfiltration, wrong-host routing, or a genuine attestation/verification bypass — the underlying cryptographic and identity checks (`SourceRepositoryOwnerURI`, `Issuer`) remain sound.

### Likelihood Explanation
Feasible only under a narrow precondition: the victim must explicitly pass `--cert-oidc-issuer` pointing at an issuer/instance the attacker controls, and the attacker must get the victim to verify one of the attacker's own artifacts/attestations (since the victim-supplied `--owner`/`--repo` still constrains `SourceRepositoryOwnerURI`). This limits it to self-inflicted or social-engineering scenarios rather than a remote-unprivileged compromise of an unrelated victim workflow.

### Recommendation
Sanitize `BuildConfigURI`/`BuildSignerURI`-derived strings (and any other certificate-extension-derived text) before printing, e.g., route them through `iostreams.Untrusted` or the `asciisanitizer.Sanitizer` transform (as already used in `pkg/cmd/skills/list/list.go` and `pkg/iostreams/untrusted.go`) prior to being passed to `Handler.PrintBulletPoints`/`Printf`/`Println`.

func (h *Handler) PrintBulletPoints(rows [][]string) (int, error) {
	if !h.IO.IsStdoutTTY() {
		return 0, nil
	}
	maxColLen := 0
	for _, row := range rows {
		if len(row[0]) > maxColLen {
			maxColLen = len(row[0])
		}
	}

	info := ""
	for _, row := range rows {
		dots := strings.Repeat(".", maxColLen-len(row[0]))
		info += fmt.Sprintf("%s:%s %s\n", row[0], dots, row[1])
	}
	return fmt.Fprintln(h.IO.ErrOut, info)
}

		return stripControl(u.raw)

	return sanitized

// sanitizeForTerminal replaces ASCII control characters in s with inert
// caret-style stand-ins so frontmatter values cannot inject terminal escapes.
func sanitizeForTerminal(s string) string {
	var buf bytes.Buffer
	r := transform.NewReader(bytes.NewReader([]byte(s)), &asciisanitizer.Sanitizer{})
	if _, err := io.Copy(&buf, r); err != nil {
		return "Unknown"
	}
	return buf.String()
}

func verifyCertExtensions(given, expected certificate.Summary) error {
	if !strings.EqualFold(expected.SourceRepositoryOwnerURI, given.SourceRepositoryOwnerURI) {
		return fmt.Errorf("expected SourceRepositoryOwnerURI to be %s, got %s", expected.SourceRepositoryOwnerURI, given.SourceRepositoryOwnerURI)
	}

	// if repo is set, compare the SourceRepositoryURI fields
	if expected.SourceRepositoryURI != "" && !strings.EqualFold(expected.SourceRepositoryURI, given.SourceRepositoryURI) {
		return fmt.Errorf("expected SourceRepositoryURI to be %s, got %s", expected.SourceRepositoryURI, given.SourceRepositoryURI)
	}

	// compare the OIDC issuers. If not equal, return an error depending
	// on if there is a partial match
	if !strings.EqualFold(expected.Issuer, given.Issuer) {
		if strings.Index(given.Issuer, expected.Issuer+"/") == 0 {
			return fmt.Errorf("expected Issuer to be %s, got %s -- if you have a custom OIDC issuer policy for your enterprise, use the --cert-oidc-issuer flag with your expected issuer", expected.Issuer, given.Issuer)
		}
		return fmt.Errorf("expected Issuer to be %s, got %s", expected.Issuer, given.Issuer)
	}
