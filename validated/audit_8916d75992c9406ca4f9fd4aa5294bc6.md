### Title
Unauthenticated `NType` Self-Declaration in PING Allows Bootnode CN/PN flatStorage Poisoning — (`networks/p2p/discover/udp.go`, `table_bond.go`, `table_data.go`)

### Summary
An attacker can send a crafted PING packet to a bootnode with `From.NType = NodeTypeCN` (or `NodeTypePN`). The bootnode's `ping.handle` passes this attacker-controlled value directly into `t.bond()`, which constructs a `Node` with the forged type and inserts it into the CN `flatStorage` after a successful ping/pong exchange. No code in the bond path validates that the claimed `NType` matches any authoritative source. The bootnode then serves this attacker node to legitimate CNs querying for CN peers via FINDNODE, enabling a bootnode-mediated eclipse attack on the CN peer set.

### Finding Description

**Step 1 — Inbound PING, no NType check in `preverify`:**

`ping.preverify` checks only expiration, network ID, and rate limiting. It never inspects `req.From.NType`. [1](#0-0) 

**Step 2 — `ping.handle` passes attacker-controlled NType verbatim:**

``` [2](#0-1) 

**Step 3 — `t.bond` constructs a Node with the forged type:**

```go

**Step 4 — `Bond` calls `pingpong(pinged=true, n)`, which pings the attacker and waits for a PONG:**

When `pinged=true`, `pingpong` still sends a PING to the attacker's address and waits for a PONG. The attacker controls their own UDP endpoint and can trivially respond. `waitping` is skipped. On success, `addNode(n)` is called with the forged `NType`. [4](#0-3) [5](#0-4) 

**Step 5 — `addNode` routes by `n.NType` into the CN `flatStorage`:**

```go

        for _, s := range tab.storages { s.add(n) }
        return
    } else {

            s.add(n)
        }

**Step 6 — `flatStorage` has no size cap:**

`flatStorage.add` uses `math.MaxInt64` as the push limit, so the attacker can insert an unbounded number of fake CN nodes. [7](#0-6) 

**Step 7 — Poisoned entries are served to legitimate CNs via FINDNODE:**

`findnode.handle` calls `t.closestNodes(req.Target, NodeTypeCN, ...)`, which reads directly from the poisoned CN `flatStorage` and returns attacker nodes to querying CNs. [8](#0-7) 

**Confirmation — zero NType validation in `table_bond.go`:**

`table_bond.go` contains no reference to `NType` at all. The bond path is entirely type-agnostic and performs no role verification. [9](#0-8) 

### Impact Explanation

The bootnode's CN `flatStorage` is the authoritative source of CN peer addresses served to all nodes that query it. Poisoning it with attacker-controlled entries means legitimate CNs receive attacker nodes as their initial CN peer candidates. With enough attacker entries (the storage is unbounded), legitimate CNs may fail to discover real consensus peers, leading to consensus isolation or divergence. This satisfies the "consensus divergence" impact gate.

### Likelihood Explanation

- The attack requires only a UDP socket and the ability to respond to a PING — no privileged access, no key compromise, no validator collusion.
- The attacker can repeat the attack with many distinct key pairs to fill the CN `flatStorage`.
- The rate limiter in `preverify` applies per source IP and only when `t.ourEndpoint.NType == NodeTypeBN && t.pingLimiter != nil`. An attacker using multiple IPs or targeting a BN without a configured rate limit bypasses even this partial mitigation. [11](#0-10) 

### Recommendation

1. **Reject `NodeTypeCN`/`NodeTypePN` self-declarations from inbound PINGs on a bootnode.** A bootnode cannot verify a peer's role from a PING packet alone; it should record the node as `NodeTypeUnknown` or `NodeTypeEN` and let role assignment happen through an authenticated out-of-band mechanism.
2. **Alternatively, validate NType against a permissioned registry** (e.g., the on-chain validator/proxy set) before inserting into typed storages.
3. **Cap `flatStorage` size** to bound the worst-case pollution.

### Proof of Concept

```

2. Craft a PING packet:

     Version    = 4

     From.TCP   = <attacker TCP port>

3. Send the PING to the bootnode's UDP endpoint.
4. The bootnode calls ping.handle → t.bond(true, attackerID, from, TCP, NodeTypeCN).
5. The bootnode pings the attacker back; the attacker responds with a valid PONG.
6. Bond succeeds; addNode inserts the attacker into CN flatStorage.
7. Send a FINDNODE(TargetType=NodeTypeCN) to the bootnode from any node.
8. Assert the attacker's node appears in the NEIGHBORS response.

func (req *ping) preverify(t *udp, from *net.UDPAddr, fromID NodeID) error {
	if expired(req.Expiration) {
		return errExpired
	}
	if req.NetworkID != t.networkID {
		logger.Debug("udp: ping: mismatch networkid", "local", t.networkID, "remote", req.NetworkID)
		mismatchNetworkCounter.Mark(1)
		return errMismatchNetwork
	}
	// Bootstrap nodes rate-limit discovery pings per source IP to bound
	// amplification/DoS against the UDP endpoint. Rejecting here prevents both
	// the pong reply and the bonding goroutine in handle().
	//
	// LAN/loopback sources are exempt: the limit protects an internet-reachable
	// BN from public ping floods, while co-located/local nodes legitimately share
	// a single private IP (e.g. many nodes behind one NAT, or localhost in tests)
	// and must not throttle one another. This mirrors the LAN exemption on the
	// inbound TCP connection throttle.
	//
	// The limit is otherwise applied to every (non-LAN) source IP, not just
	// unbonded ones: a UDP source IP is unauthenticated/spoofable and kaia's bond
	// is keyed by NodeID only, so a "bonded NodeID + spoofed source IP" packet
	// could otherwise bypass the limit and reflect a pong to the spoofed victim.
	if t.ourEndpoint.NType == NodeTypeBN && t.pingLimiter != nil && !netutil.IsLAN(from.IP) {
		if !t.pingLimiter.allow(from.IP, time.Now()) {
			logger.Trace("udp: ping: rate limited", "addr", from)
			pingRateLimitedCounter.Mark(1)
			return errPingRateLimited
		}
	}
	return nil

func (req *findnode) handle(t *udp, from *net.UDPAddr, fromID NodeID, mac []byte) error {
	// Determine "closest" nodes. The result will be the closest nodes for KademliaStorage, but random nodes for SimpleStorage.
	retrieveSize := findnodeRetrieveSize(req.TargetType)
	closest := t.closestNodes(req.Target, req.TargetType, retrieveSize)

	// Send neighbors in chunks with at most maxNeighbors per packet
	// to stay below the 1280 byte limit.
	p := neighbors{Expiration: uint64(time.Now().Add(expiration).Unix()), TargetType: req.TargetType}
	var sent bool
	for _, n := range closest {
		if netutil.CheckRelayIP(from.IP, n.IP) == nil {
			p.Nodes = append(p.Nodes, nodeToRPC(n))
		}
		if len(p.Nodes) == maxNeighbors {
			t.send(from, neighborsPacket, &p)
			p.Nodes = p.Nodes[:0]
			sent = true
		}
	}
	if len(p.Nodes) > 0 || !sent {
		t.send(from, neighborsPacket, &p)
	}
	return nil
}

func (tab *Table2) Bond(pinged bool, n *Node) error {
	if n.ID == tab.selfID {
		return errSelfBonding
	}
	// Do not accept inbound (i.e. remote pinged me) bonding requests before
	// populating from my seeds. It prevents remote nodes from filling up the table by spamming.
	if pinged && !tab.initialized() {
		return errTableNotReady
	}
	// Do not attempt bonding if the table is closed. Could happen after tab.Close() and before udp.close()
	// You can't write to the closed DB.
	if tab.closed.Load() {
		return errTableNotReady
	}

	// Skip if we're really sure that this node is reachable and completed the bonding process.
	if tab.canAssumeBonded(n.ID, n.IP) {
		return nil
	}

	// Deduplicate concurrent Bond() calls for the same node.
	_, err, _ := tab.bondGroup.Do(n.ID.String(), func() (interface{}, error) {
		err := tab.pingpong(pinged, n)
		if err == nil {
			tab.addNode(n)
			tab.recordBonded(n)
		}
		return nil, err
	})
	return err
}

func (tab *Table2) pingpong(pinged bool, n *Node) error {
	<-tab.bondslots                                // Acquire a bonding slot to limit network usage.
	defer func() { tab.bondslots <- struct{}{} }() // Release the bonding slot.

	// Ping the remote side and wait for a pong.
	if err := tab.udp.ping(n.ID, n.addr()); err != nil {
		return err
	}
	if !pinged {
		// Give the remote node a chance to ping us before we start
		// sending findnode requests. If they still remember us,
		// waitping will simply time out.
		tab.udp.waitping(n.ID, n.IP)
	}
	return nil
}
