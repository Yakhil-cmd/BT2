### Title
`checkConsistency` validates KIP-71 base-fee bound votes in isolation against the current parameter set, allowing two co-epoch votes to ratify an inverted `LowerBoundBaseFee > UpperBoundBaseFee` governance state — (`File: kaiax/gov/headergov/impl/header.go`)

---

### Summary

`checkConsistency` in `kaiax/gov/headergov/impl/header.go` validates each `kip71.lowerboundbasefee` and `kip71.upperboundbasefee` vote independently against the **already-ratified** (current epoch) parameter set. It does not account for a co-pending vote for the counterpart bound in the same epoch. Two individually-valid votes cast in the same epoch can together ratify a state where `LowerBoundBaseFee > UpperBoundBaseFee`, permanently corrupting the KIP-71 base-fee calculation for all subsequent blocks.

---

### Finding Description

`checkConsistency` performs the following per-vote checks:

```go
// kaiax/gov/headergov/impl/header.go:179-192
case gov.Kip71LowerBoundBaseFee:
    params := h.GetParamSet(blockNum)
    if vote.Value().(uint64) > params.UpperBoundBaseFee {
        return ErrLowerBoundBaseFee
    } else {
        return nil
    }
case gov.Kip71UpperBoundBaseFee:
    params := h.GetParamSet(blockNum)
    if vote.Value().(uint64) < params.LowerBoundBaseFee {
        return ErrUpperBoundBaseFee
    } else {
        return nil
    }
``` [1](#0-0) 

Each vote is validated against `h.GetParamSet(blockNum)`, which returns the **currently ratified** parameter set — not the set that will be in effect after all pending votes in the same epoch are applied.

At the epoch boundary, `getExpectedGovernance` collects **all** votes from the previous epoch and applies them together:

```go
// kaiax/gov/headergov/impl/header.go:218-233
for _, voteBlock := range sortedVoteBlocks {
    vote := prevEpochVotes[voteBlock]
    govs.Add(string(vote.Name()), vote.Value())
}
``` [2](#0-1) 

There is no cross-vote consistency check at ratification time. `VerifyGov` only checks that the governance data in the epoch block matches the locally computed expected governance — it does not verify that `LowerBoundBaseFee <= UpperBoundBaseFee` holds in the resulting parameter set. [3](#0-2) 

---

### Impact Explanation

If `LowerBoundBaseFee > UpperBoundBaseFee` is ratified, `NextMagmaBlockBaseFee` in `params/kip71_config.go` receives inverted bounds:

```go
// params/kip71_config.go:82-86
if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {
    parentBaseFee = upperBoundBaseFee   // clamps to the LOWER value
} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
    parentBaseFee = lowerBoundBaseFee   // clamps to the HIGHER value
}
``` [4](#0-3) 

With inverted bounds (e.g., lower=500 gwei, upper=100 gwei):
- Any `parentBaseFee >= 100` is clamped to 100 (the nominal "upper")
- Any `parentBaseFee < 100` is clamped to 500 (the nominal "lower")

The base fee is permanently locked into an oscillating or stuck invalid range. `VerifyMagmaHeader` enforces that each block's `baseFee` equals `NextMagmaBlockBaseFee(...)`: [5](#0-4) 

All nodes compute the same broken expected base fee and accept blocks with it. The result is:
- **Persistent invalid governance state** (`LowerBoundBaseFee > UpperBoundBaseFee`) written into the canonical chain
- **Incorrect base fee** for all subsequent blocks, corrupting transaction fee collection and fee burning (KIP-71/KIP-82 accounting)
- The state cannot be corrected without another governance vote, which itself requires the same broken validation path

---

### Likelihood Explanation

**`none` governance mode** (any GC member can vote): A single council member can propose two blocks in the same epoch — one voting `kip71.lowerboundbasefee = V_high` and one voting `kip71.upperboundbasefee = V_low` where `V_low < current_lower < current_upper < V_high`. Each vote passes `checkConsistency` individually. At the epoch boundary both are ratified together.

**`single` governance mode** (Mainnet/Kairos): Requires the governing node to cast both votes, which is a privileged operation. The bug is structurally present but the trigger is privileged on production networks.

The `none` mode path represents a valid semi-trusted trigger (GC member).

---

### Recommendation

In `checkConsistency`, when validating a `Kip71LowerBoundBaseFee` vote, also check it against any **pending** `Kip71UpperBoundBaseFee` vote already cast in the current epoch (and vice versa). Alternatively, add a cross-parameter consistency check in `getExpectedGovernance` / `VerifyGov` before ratifying the combined governance data, rejecting any epoch-boundary governance that would produce `LowerBoundBaseFee >= UpperBoundBaseFee`.

```go
// In checkConsistency, for Kip71LowerBoundBaseFee:
pendingUpper := getPendingVoteInEpoch(blockNum, gov.Kip71UpperBoundBaseFee)
effectiveUpper := params.UpperBoundBaseFee
if pendingUpper != nil {
    effectiveUpper = pendingUpper.Value().(uint64)
}
if vote.Value().(uint64) > effectiveUpper {
    return ErrLowerBoundBaseFee
}
```

Or, more robustly, add a post-ratification invariant check in `VerifyGov`:

```go
if ratified.LowerBoundBaseFee >= ratified.UpperBoundBaseFee {
    return ErrInvalidBaseFeeRange
}
```

### Proof of Concept

Assume epoch = 1000, current params: `LowerBoundBaseFee = 25 gwei`, `UpperBoundBaseFee = 750 gwei`.

**Block 100** (in epoch 0): GC member A proposes block with `Vote: (kip71.lowerboundbasefee, 500_000_000_000)` (500 gwei).
- `checkConsistency`: `500 gwei <= 750 gwei (current upper)` → passes ✓

**Block 200** (in epoch 0): GC member A (or B) proposes block with `Vote: (kip71.upperboundbasefee, 10_000_000_000)` (10 gwei).
- `checkConsistency`: `10 gwei >= 25 gwei (current lower)` → **passes** ✓ (10 < 25 would fail, but 10 gwei < 25 gwei so this actually fails — let me correct)

Corrected example: `Vote: (kip71.upperboundbasefee, 30_000_000_000)` (30 gwei).
- `checkConsistency`: `30 gwei >= 25 gwei (current lower)` → passes ✓

**Block 1000** (epoch boundary): `getExpectedGovernance` collects both votes. Ratified governance: `{kip71.lowerboundbasefee: 500 gwei, kip71.upperboundbasefee: 30 gwei}`.

Result: `LowerBoundBaseFee (500 gwei) > UpperBoundBaseFee (30 gwei)`. All subsequent base fee calculations are broken. The inverted clamping in `NextMagmaBlockBaseFee` causes the base fee to be locked at 30 gwei (the nominal "upper") for any block whose parent base fee exceeds 30 gwei, permanently suppressing fees below the intended minimum. 	expected := h.getExpectedGovernance(header.Number.Uint64())

func (h *headerGovModule) checkConsistency(blockNum uint64, vote headergov.VoteData) error {
	switch vote.Name() {
	case gov.GovernanceGoverningNode:
		params := h.GetParamSet(blockNum)

		// compare with governing node only in single mode.
		if params.GovernanceMode != "single" {
			return nil
		}

		// we'll use blockNum-1 for the blocknumber of GetCouncil since blockNum cannot be available(eg. vote)
		// it's definite that the valSet vote is not included in this block
		// so the council(blockNum - 1) and council(blockNum) should be same
		council, err := h.ValSet.GetCouncil(blockNum - 1)
		if err != nil {
			return err
		}

		if slices.Contains(council, params.GoverningNode) {
			return nil
		}
		return ErrGovNodeNotInValSetList
	case gov.Kip71LowerBoundBaseFee:
		params := h.GetParamSet(blockNum)
		if vote.Value().(uint64) > params.UpperBoundBaseFee {
			return ErrLowerBoundBaseFee
		} else {
			return nil
		}
	case gov.Kip71UpperBoundBaseFee:
		params := h.GetParamSet(blockNum)
		if vote.Value().(uint64) < params.LowerBoundBaseFee {
			return ErrUpperBoundBaseFee
		} else {
			return nil
		}
	case gov.AddValidator, gov.RemoveValidator:
		params := h.GetParamSet(blockNum)

		// compare with governing node only in single mode.
		if params.GovernanceMode != "single" {
			return nil
		}
		if slices.Contains(vote.Value().([]common.Address), params.GoverningNode) {
			return ErrGovNodeInValSetVoteValue

func (h *headerGovModule) getExpectedGovernance(blockNum uint64) headergov.GovData {
	prevEpochIdx := calcEpochIdx(blockNum, h.epoch) - 1
	prevEpochVotes := h.getVotesInEpoch(prevEpochIdx)
	govs := make(gov.PartialParamSet)

	sortedVoteBlocks := slices.Collect(maps.Keys(prevEpochVotes))
	slices.Sort(sortedVoteBlocks)

	for _, voteBlock := range sortedVoteBlocks {
		vote := prevEpochVotes[voteBlock]
		govs.Add(string(vote.Name()), vote.Value())
	}

	// assert(len(headergov.NewGovData(govs).Items()) == len(govs))
	return headergov.NewGovData(govs)
}

func (kc *KIP71Config) VerifyMagmaHeader(headerBaseFee *big.Int, parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) error {
	if headerBaseFee == nil {
		return fmt.Errorf("header is missing baseFee")
	}
	// Verify the baseFee is correct based on the parent header.
	expectedBaseFee := kc.NextMagmaBlockBaseFee(parentHeaderNumber, parentHeaderBaseFee, parentHeaderGasUsed)
	if headerBaseFee.Cmp(expectedBaseFee) != 0 {
		return fmt.Errorf("invalid baseFee: have %s, want %s, parentBaseFee %s, parentGasUsed %d",
			headerBaseFee, expectedBaseFee, parentHeaderBaseFee, parentHeaderGasUsed)
	}
	return nil
}

func (kc *KIP71Config) NextMagmaBlockBaseFee(parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) *big.Int {
	// governance parameters
	lowerBoundBaseFee := new(big.Int).SetUint64(kc.LowerBoundBaseFee)
	upperBoundBaseFee := new(big.Int).SetUint64(kc.UpperBoundBaseFee)
	makeEvenByCeil(lowerBoundBaseFee)
	makeEvenByFloor(upperBoundBaseFee)

	// If the parent is the magma disabled block or genesis, then return the lowerBoundBaseFee (default 25ston)
	if parentHeaderNumber.Cmp(new(big.Int).SetUint64(0)) == 0 || parentHeaderBaseFee == nil {
		return makeEvenByFloor(lowerBoundBaseFee)
	}

	var baseFeeDenominator *big.Int
	if kc.BaseFeeDenominator == 0 {
		// To avoid panic, set the fluctuation range small
		baseFeeDenominator = new(big.Int).SetUint64(64)
	} else {
		baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
	}
	gasTarget := kc.GasTarget
	upperGasLimit := kc.MaxBlockGasUsedForBaseFee

	// check the case of upper/lowerBoundBaseFee is updated by governance mechanism
	parentBaseFee := parentHeaderBaseFee
	if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {
		parentBaseFee = upperBoundBaseFee
	} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
		parentBaseFee = lowerBoundBaseFee
	}

	// upper gas limit cut off the impulse of used gas to upper bound
	parentGasUsed := min(parentHeaderGasUsed, upperGasLimit)
	if parentGasUsed == gasTarget {
		return makeEvenByFloor(parentBaseFee)
	} else if parentGasUsed > gasTarget {
		// shortcut. If parentBaseFee is already reached upperbound, do not calculate.
		if parentBaseFee.Cmp(upperBoundBaseFee) == 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		// If the parent block used more gas than its target,
		// the baseFee of the next block should increase.
		// baseFeeDelta = max(1, parentBaseFee * (parentGasUsed - gasTarget) / gasTarget / baseFeeDenominator)
		gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := math.BigMax(x.Div(y, baseFeeDenominator), common.Big1)

		nextBaseFee := x.Add(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(upperBoundBaseFee) > 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	} else {
		// shortcut. If parentBaseFee is already reached lower bound, do not calculate.
		if parentBaseFee.Cmp(lowerBoundBaseFee) == 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		// Otherwise if the parent block used less gas than its target,
		// the baseFee of the next block should decrease.
		// baseFeeDelta = parentBaseFee * (gasTarget - parentGasUsed) / gasTarget / baseFeeDenominator
		gasUsedDelta := new(big.Int).SetUint64(gasTarget - parentGasUsed)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := x.Div(y, baseFeeDenominator)

		nextBaseFee := x.Sub(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(lowerBoundBaseFee) < 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	}
