### Title
Whole-unit liquidation sizing leaves a narrow debt band permanently unliquidatable - (File: contracts/controller/src/positions/liquidation/math.rs)

### Summary
For an account whose only collateral asset has fewer than `MIN_BORROWABLE_ASSET_DECIMALS` decimals, liquidation planning tries to adjust a sub-unit seizure quote to one whole collateral unit. The implementation misses a boundary band: when the discounted unit value does not cover total debt plus per-leg rounding, but the unit value plus the margin does cover the debt, `whole_unit_repayment` returns the original quote instead of a whole-unit/full-debt quote. If that original quote backs less than one collateral unit, seizure rounds to zero, all repayment is released, and permissionless `liquidate` reverts.

### Finding Description
`liquidate` is callable by any authenticated liquidator with an account ID, positive `debt_payments`, and a `SeizeMode`; it requires only that the target is below HF 1. [1](#0-0) 

For a solvent, unhealthy account whose only supply position is a sub-3-decimal asset, `normalize_repayment_plan` calls `whole_unit_repayment` when the curve quote is below total debt. [2](#0-1)  That helper first promotes a full close only when `floor(U / (1 + bonus)) >= D + R`, where `R` is one base unit per debt leg. [3](#0-2)  Otherwise, it computes `raised = ceil((U + margin) / (1 + bonus))`, but if `raised >= D`, it returns the unchanged curve quote rather than treating the debt as coverable by one unit. [4](#0-3) 

This creates the gap:

```text
unit_at_bonus < D + R
D <= raised
curve_quote * (1 + bonus) < U + margin
```

In that state, the plan remains partial. During seizure sizing, a sub-3-decimal partial seizure is floored to whole units. [5](#0-4)  A curve quote below one unit therefore produces zero seizure, the plan drops the zero leg, `build_liquidation_plan` releases the now-unbacked repayment, and execution rejects the empty repayment result. [6](#0-5) [7](#0-6) 

### Impact Explanation
An unhealthy account can remain temporarily impossible to liquidate even when one collateral unit plus the configured margin can economically cover its debt. Neither borrower collateral nor liquidator repayment is stolen directly, but the borrower’s collateral/debt position is frozen in an unhealthy state until interest accrual or a price update moves `D`, `U`, or the bonus out of the band. Because liquidation is also a liveness requirement for containing bad debt, this is a Medium temporary-freezing impact.

### Likelihood Explanation
The account shape is unusual but valid: the collateral must be below 3 decimals and be the account’s only supply position, and the account must be solvent yet unhealthy due to its liquidation threshold. The arithmetic band is narrow because it is bounded by per-leg unit rounding and the one-millionth margin, but it can occur naturally as debt accrues. Once reached, every submitted liquidation repayment that follows the curve-sized quote fails; larger offers are normalized back to the same unexecutable quote.

### Recommendation
When `raised >= D`, treat the position as a one-unit full close or otherwise explicitly promote the quote to the amount needed to seize one unit, instead of returning `curve_repayment_usd`. Equivalently, collapse the condition so the second branch handles both `raised < D` and `raised >= D` consistently. Add a regression test for:

```text
unit_at_bonus < D + R
raised >= D
curve quote backs less than one unit
```

and assert that `liquidate` either repays/closes the position or fails for an intentional economic reason, not because seizure rounds to zero.

### Proof of Concept
Consider:

- Collateral token has 2 decimals, is the account’s only supply position, and holds at least one whole unit.
- One collateral unit is worth `U = $20`.
- Liquidation threshold is 95%, so weighted collateral is `$19`.
- Bonus is 5%, making `unit_at_bonus = floor(20 / 1.05) = $19.047619`.
- One debt leg has negligible per-base-unit value, so `R ≈ $0.0000001`.
- Total debt is `D = $19.04763`.

Then:

```text
C = $20 >= D
weighted collateral = $19 < D           => HF < 1
unit_at_bonus + R < D                   => no rule-1 full close
raised ~= $19.047639 >= D               => current code returns the old quote
```

Set the curve quote to `$10`. Its collateral backing is `$10.50`, far below one `$20` unit, so the partial seizure floors to zero units under the sub-3-decimal rule. `build_liquidation_plan` then releases the repayment, and `liquidate(liquidator, account_id, payments, SeizeMode::Transfer)` reverts for any offer governed by that quote. Interest accrual or a collateral/debt price change eventually exits the band, but until then an unhealthy position cannot be liquidated.
