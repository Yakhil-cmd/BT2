The only production consumer of confidential-ciphertext-like semantics, `confidential_asset.move`, is built on its own `confidential_balance`/`confidential_amount` abstractions (`CompressedBalance<Available>`, `CompressedAmount`, `CompressedRistretto`) and its own sigma-protocol/range-proof verification pipeline (`assert_valid_transfer_proof`, `assert_valid_withdrawal_proof`, `confidential_range_proofs::assert_valid_range_proof`), not the generic `Ciphertext`/`CompressedCiphertext` types from `ristretto255_elgamal` [3](#0-2) [4](#0-3) . All balance/amount updates in `confidential_asset` require passing a same-transaction sigma-protocol proof bound to the sender/session (`sigma_protocol_transfer::new_session`, `session.assert_verifies`) plus range proofs, before any ciphertext is accepted as valid — mixing points from two unrelated accounts' ciphertexts would fail these checks rather than being silently accepted.

Since the `ciphertext_from_points`/`ciphertext_from_compressed_points` constructors are not reachable from any unprivileged transaction entrypoint, authenticator, or approval-set check in the current production code — they are unused, general-purpose library primitives with no accompanying "fresh ciphertext bound to caller" invariant to violate — there is no transaction-admission path where forging a mix-and-match ciphertext via these functions corrupts sender/signer/replay/domain guarantees.

/// This module implements an ElGamal encryption API, over the Ristretto255 curve, that can be used with the
/// Bulletproofs module.
///
/// An ElGamal *ciphertext* is an encryption of a value `v` under a basepoint `G` and public key `Y = sk * G`, where `sk`
/// is the corresponding secret key, is `(v * G + r * Y, r * G)`, for a random scalar `r`.
///
/// Note that we place the value `v` "in the exponent" of `G` so that ciphertexts are additively homomorphic: i.e., so
/// that `Enc_Y(v, r) + Enc_Y(v', r') = Enc_Y(v + v', r + r')` where `v, v'` are plaintext messages, `Y` is a public key and `r, r'`
/// are the randomness of the ciphertexts.

module aptos_std::ristretto255_elgamal {
    use aptos_std::ristretto255::{Self, RistrettoPoint, Scalar, CompressedRistretto, point_compress};
    use std::option::Option;
    use std::vector;

    //
    // Structs
    //

    /// An ElGamal ciphertext.
    struct Ciphertext has drop {
        left: RistrettoPoint,   // v * G + r * Y
        right: RistrettoPoint,  // r * G
    }

    /// A compressed ElGamal ciphertext.
    struct CompressedCiphertext has store, copy, drop {
        left: CompressedRistretto,
        right: CompressedRistretto,
    }

    /// An ElGamal public key.
    struct CompressedPubkey has store, copy, drop {
        point: CompressedRistretto,
    }

        );

        session.assert_verifies(&stmt, &sigma);

    }

        sender: &signer,

        asset_type: Object<fungible_asset::Metadata>,

        compressed_ek_recip: &CompressedRistretto,

        Balance<Pending>,

        let TransferProof::V1 {
            compressed_new_balance, compressed_amount,
            compressed_ek_volun_auds,
            zkrp_new_balance, zkrp_amount, sigma
        } = proof;

        // Note: `update_auditor` already guarantees that `compressed_ek_eff_aud` is not the identity, but the voluntary

        compressed_ek_volun_auds.for_each_ref(|ek| {

        let num_volun_auditors = compressed_ek_volun_auds.length();

            *compressed_ek_sender, *compressed_ek_recip,
            compressed_old_balance, &compressed_new_balance,
            &compressed_amount,
            compressed_ek_eff_aud, &compressed_ek_volun_auds,
        );

        confidential_range_proofs::assert_valid_range_proof(compressed_new_balance.get_compressed_P(), &zkrp_new_balance);

        let session = sigma_protocol_transfer::new_session(
            sender, recipient_addr, asset_type, has_effective_auditor, num_volun_auditors,
        );
