### Title
Webhook signature verification is keyed on an unauthenticated payload field decoupled from the repository the event actually acts on - (File: app/controllers/shipit/webhooks_controller.rb)

### Summary
`WebhooksController#verify_signature` selects which organization's webhook secret to verify the HMAC signature against using `repository_owner`, a value read straight out of the still-unauthenticated JSON body (`params.dig('repository', 'owner', 'login')` or `params.dig('organization', 'login')`) [3](#0-2) . Once the signature check passes, `WebhooksController#create` dispatches the *entire* raw payload to handlers [4](#0-3) , and every handler resolves the target stacks/repository using a *different* field of the same payload: `payload.dig('repository', 'full_name')` [2](#0-1) , or `params.repository.full_name` in the PR handlers [5](#0-4) . Nothing enforces that `repository.owner.login` (used to pick the verification secret) and `repository.full_name`'s owner segment (used to pick the actually-affected repository/stack) refer to the same organization.

### Finding Description
Shipit supports a multi-tenant deployment where multiple GitHub organizations are configured, each with its own GitHub App and `webhook_secret`, selected dynamically per request via `Shipit.github_app_config(organization)` [6](#0-5) . An organization admin who has legitimately installed the Shipit GitHub App on their **own** organization ("org A") knows org A's `webhook_secret` (it is visible to them in their own GitHub App settings, and is exactly the value they were instructed to configure per `docs/setup.md`).

The binding that should hold is:
```
organization whose secret authenticated the HMAC == organization owning the repository the handler acts on
```

Because `verify_signature` derives the verification organization from `repository.owner.login` while every downstream handler derives the target repository from the independent `repository.full_name` field of the same JSON body, an attacker can submit a body such as:

```json
{
  "repository": {
    "owner": { "login": "org-a" },
    "full_name": "org-b/victim-repo"
  },
  "ref": "refs/heads/master",
  "after": "<attacker-chosen sha>"
}
```
signed with `X-Hub-Signature: sha1=<HMAC using org-a's known webhook_secret over this exact raw body>`.

`verify_signature` computes `repository_owner` as `"org-a"`, fetches `Shipit.github(organization: "org-a")`, and successfully verifies the signature against org A's secret [7](#0-6) . The request passes and is handed to `Shipit::Webhooks.for_event(event).each { |handler| handler.call(params) }` [4](#0-3) . `PushHandler#process` then resolves stacks via `Repository.from_github_repo_name(repository_name)` where `repository_name` is `payload.dig('repository', 'full_name')` — i.e. `"org-b/victim-repo"` — and calls `stack.sync_github(expected_head_sha: params.after)` on org B's stacks [8](#0-7) , with `expected_head_sha` fully attacker-controlled.

  def github(organization: github_default_organization)
    # Backward compatibility
    # nil signifies the single github app config schema is being used
    if github_default_organization.nil?
      config = secrets.github
    else
      config = github_app_config(organization)
      raise GithubOrganizationUnknown, organization if config.nil?
    end
    @github ||= {}
    @github[organization] ||= GitHubApp.new(organization, config)
  end

  def github_default_organization
    return nil unless secrets&.github

    org = secrets.github.keys.first
    TOP_LEVEL_GH_KEYS.include?(org) ? nil : org
  end

  def github_organizations
    return [nil] unless github_default_organization

    secrets.github.keys
  end

  def github_app_config(organization)
    github_config = secrets.github.deep_transform_keys(&:downcase)
    github_organization = organization.downcase.to_sym
    github_config[github_organization]
  end

    def verify_signature
      github_app = Shipit.github(organization: repository_owner)
      verified = github_app.verify_webhook_signature(
        request.headers['X-Hub-Signature'],
        request.raw_post

      head(422) unless verified

      Rails.logger.info([
        'WebhookController#verify_signature',

        "repository_owner=#{repository_owner}",
        "signature=#{request.headers['X-Hub-Signature']}",
        "status=#{status}"
      ].join(' '))
    rescue Shipit::GithubOrganizationUnknown => e

        "event=#{event}",
        "repository_owner=#{repository_owner}",
        "unknown_organization=#{e.message}",
        "status=#{status}"
      ].join(' '))
