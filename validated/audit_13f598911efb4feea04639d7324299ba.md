### Title
Symlinked repo files are silently excluded from the LLM security-review diff, bypassing the Stop-hook code review - ([File: plugins/security-guidance/hooks/gitutil.py])

### Summary
`_diff_pathspec` (used by `get_git_diff`, which internally relies on `_temp_index`) resolves every candidate review path with `os.path.realpath()` and drops it from the diff pathspec whenever the *resolved* path falls outside the repo working directory. Because a symlink's target — not its own location inside the repo — determines the realpath result, an attacker (or the coding agent acting on attacker-influenced instructions) can create/modify a symlink inside the repo whose target points outside the repo root. That file is silently dropped from the git diff pathspec, and if it's the only changed file that turn, `get_git_diff` returns `""`, which the Stop hook treats as "no changes since baseline" and skips the LLM security review entirely.

### Finding Description
`compute_v2_review_set` in `plugins/security-guidance/hooks/diffstate.py` computes `review_paths` as absolute, repo-root-relative paths of files git considers changed/untracked this turn: [1](#0-0) . These paths are handed to `get_git_diff(repo_root, content_base, paths=review_paths, untracked_paths=untracked)` in the Stop hook: [2](#0-1) .

`get_git_diff` restricts the actual `git diff` invocation to a pathspec computed by `_diff_pathspec`: [3](#0-2) .

`_diff_pathspec` calls `os.path.realpath(p)` on each candidate file and drops any path whose *resolved* location is outside `cwd`: [4](#0-3) 

The realpath resolution follows symlinks. If a repo-tracked or newly-created file is itself a symlink whose target resolves outside the repository root (e.g. `ln -s /tmp/x payload` or `ln -s ../../outside payload` inside the working tree), `os.path.realpath(p)` returns the external target, `os.path.relpath` yields a string starting with `..`, and the entry is silently discarded from `rel`. If this drop empties `rel`, `_diff_pathspec` returns `[]` (an *unrestricted* pathspec signal), and `get_git_diff` explicitly converts that into an empty diff: [5](#0-4) 

That `""` return propagates to the Stop hook as "no changes since baseline," which skips the review outright: [6](#0-5) 

Even when other legitimate files are also part of `review_paths` (so the pathspec isn't emptied entirely), the symlinked file itself is simply never included in the `-- <paths>` list passed to `git diff`, so its diff content never reaches `analyze_code_security`/the LLM reviewer — the file's change is invisible to the security control even though `compute_v2_review_set` correctly identified it as part of this turn's changes.

The code comment for this realpath logic ("realpath both sides so the macOS /var ↔ /private/var symlink doesn't make in-repo paths look external") shows the intent was narrowly to normalize `cwd`'s own symlink aliasing, not to handle symlinked *files* inside the repo — so a file-level symlink pointing outside the repo is an unintended escape of the scoping logic rather than a deliberate security boundary.

### Impact Explanation
This is a Security-control bypass: a single crafted symlink (fully within the capabilities of an unprivileged coding-agent session with normal filesystem write access to the working tree — no maintainer/admin/leaked-credential assumptions needed) can suppress the Stop-hook's LLM-based diff review for the turn, either partially (that one file's diff is never shown to the reviewer) or completely (if it's the only changed file, the whole review is skipped via the "no changes since baseline" path). This matches the "Security-control bypass that silently disables or routes around blocking, review, or permission boundaries" impact category — a malicious change delivered as/alongside a symlink can be committed or persisted without ever being surfaced to the code-security review pipeline.

### Likelihood Explanation
High feasibility and fully repeatable: creating a symlink whose target lies outside the repository is a routine filesystem operation requiring no special privileges, and the review path is reached on every normal Stop-hook execution once `ENABLE_STOP_REVIEW`/`ENABLE_CODE_SECURITY_REVIEW` are enabled (the default review flow). No race condition, timing, or elevated access is required — just placing/modifying a symlink with an out-of-repo target during a session.

### Recommendation
In `_diff_pathspec`, do not use `os.path.realpath()` on the candidate file paths to decide inclusion — only realpath `cwd` (to normalize the macOS `/var`↔`/private/var` alias) and compare the *literal* (non-symlink-resolved) path of each candidate file against the repo root, e.g. via `os.path.normpath`/`os.path.abspath` without following the final symlink component (`os.path.realpath(os.path.dirname(p))` joined with `os.path.basename(p)`, or use `os.path.commonpath` on the abspath). Ensure that symlinks that are themselves inside the repo are always included in the diff pathspec regardless of where their target points, so the LLM reviewer always sees the symlink's diff (creation/modification/target change). Additionally, treat "all candidates filtered out" distinctly from "no restriction requested" so it never silently degrades to `""`/skip — instead it should still emit a diff for whatever paths remain in scope, or explicitly flag the file as reviewable-but-diff-suppressed for telemetry/alerting.

### Proof of Concept
Unit test to add near the existing `_diff_pathspec`/`get_git_diff` tests:

```python
import os, subprocess, tempfile
from gitutil import _diff_pathspec, get_git_diff

def test_symlink_target_outside_repo_is_dropped_from_pathspec(tmp_path):
    repo = tmp_path / "repo"
    repo.mkdir()
    subprocess.run(["git", "init"], cwd=repo, check=True)
    subprocess.run(["git", "commit", "--allow-empty", "-m", "init"], cwd=repo, check=True)

    outside_target = tmp_path / "outside_target.txt"
    outside_target.write_text("secret")

    payload = repo / "payload"
    os.symlink(outside_target, payload)  # symlink INSIDE repo, target OUTSIDE repo

    # This file should be part of the review scope (it's the only change this turn)
    pathspec = _diff_pathspec(str(repo), [str(payload)])
    assert pathspec == [], "expected the escape bug: symlink dropped from pathspec"

    diff = get_git_diff(str(repo), "HEAD", paths=[str(payload)])
    # BUG: diff is "" even though `payload` is a genuine untracked/changed file
    # that should have been sent to the security reviewer.
    assert diff == ""
```

Expected (fixed) behavior: `pathspec` should still contain `payload` (or an equivalent literal-path pathspec entry), and `diff` should be non-empty, containing the symlink creation (`new file mode 120000` / `+outside_target.txt` target line), so the LLM review actually inspects the change instead of silently skipping it.

```python
def _diff_pathspec(cwd, paths):
    """Convert absolute touched-paths to repo-relative pathspec args for
    git diff. Paths outside cwd (e.g. ~/.claude/…) are dropped. Returns the
    list to splice after `--`, or [] for an unrestricted diff. realpath both
    sides so the macOS /var ↔ /private/var symlink doesn't make in-repo
    paths look external."""
    if not paths:
        return []
    cwd_abs = os.path.realpath(cwd)
    rel = []
    for p in paths:
        try:
            r = os.path.relpath(os.path.realpath(p), cwd_abs)
        except ValueError:
            continue
        if r.startswith(".."):
            continue
        rel.append(r)
    return ["--"] + rel if rel else []
```

```python
def get_git_diff(cwd, baseline_sha, full_context=False, paths=None, untracked_paths=None):
    """
    Get the git diff between the baseline SHA and the current working tree,
    including untracked (new) files.

    Uses a temporary copy of the git index (GIT_INDEX_FILE) so the user's
    real index is never modified. The temp index gets intent-to-add entries
    for untracked files, making them visible in the diff output. Cleanup
    is just deleting the temp file in a finally block.

    If `paths` is given, the diff is restricted to those paths (relative to
    cwd; absolute paths are converted, paths outside cwd are dropped).
    `untracked_paths` (repo-root-relative) is forwarded to _temp_index so it
    can add only those files instead of scanning the whole worktree.
    """
    pathspec = _diff_pathspec(cwd, paths)
    if paths and not pathspec:
        # Caller restricted to specific paths but none are inside this repo
        # (e.g. only ~/.claude/... edits). Returning "" flows to skip(6); an
        # empty pathspec would mean an UNRESTRICTED diff — the bug this whole
        # change exists to fix.
        return ""

    cmd = [*GIT_CMD, "diff", "--no-color", "--no-ext-diff", baseline_sha] + (["--unified=99999"] if full_context else []) + pathspec
```
