### Title
Unbounded `kip71.gastarget` Governance Parameter Causes Division-by-Zero Panic in `NextMagmaBlockBaseFee`, Halting Consensus — (`File: params/kip71_config.go`)

---

### Summary

The governance parameter `kip71.gastarget` accepts any `uint64` value including zero because its `FormatChecker` is `noopFormatChecker`. The value is used as a divisor in `NextMagmaBlockBaseFee()` with no zero-guard. Setting it to `0` via a governance vote causes `big.Int.Div` to panic on every subsequent block, crashing both block producers and block validators and halting the chain.

---

### Finding Description

`Kip71GasTarget` is registered in `kaiax/gov/param.go` with `FormatChecker: noopFormatChecker`, which unconditionally returns `true` for any value:

```go
// kaiax/gov/param.go
Kip71GasTarget: {
    Canonicalizer: uint64Canonicalizer,
    FormatChecker: noopFormatChecker,   // ← accepts any uint64, including 0
    ...
    DefaultValue: uint64(30000000),
},
``` [1](#0-0) 

By contrast, the sibling parameter `Kip71BaseFeeDenominator` explicitly rejects zero:

```go
Kip71BaseFeeDenominator: {
    Canonicalizer: uint64Canonicalizer,
    FormatChecker: func(cv any) bool {
        v, ok := cv.(uint64)
        return ok && v != 0   // ← explicit zero-guard
    },
    ...
},
``` [2](#0-1) 

Inside `NextMagmaBlockBaseFee`, `BaseFeeDenominator` also has a runtime zero-guard, but `GasTarget` does not:

```go
// params/kip71_config.go
if kc.BaseFeeDenominator == 0 {          // ← runtime guard for denominator
    baseFeeDenominator = new(big.Int).SetUint64(64)
} else {
    baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
}
gasTarget := kc.GasTarget                // ← no zero-guard
``` [3](#0-2) 

`gasTarget` is then used as a divisor in both the "above target" and "below target" branches:

```go
// parentGasUsed > gasTarget branch
y := x.Div(x, new(big.Int).SetUint64(gasTarget))   // line 102 — panics if gasTarget == 0

// parentGasUsed < gasTarget branch
y := x.Div(x, new(big.Int).SetUint64(gasTarget))   // line 120 — panics if gasTarget == 0
``` [4](#0-3) 

Go's `math/big.Int.Div` panics on a zero divisor. The only escape hatch is `parentGasUsed == gasTarget`, which requires `parentGasUsed == 0` — impossible on a live chain with any transactions.

---

### Impact Explanation

`NextMagmaBlockBaseFee` is called in two critical production paths:

**Block validation** (`blockchain/block_validator.go`):
```go
govParamSet := v.mGov.GetParamSet(header.Number.Uint64())
if err := govParamSet.ToKip71Config().VerifyMagmaHeader(
    header.BaseFee, parent.Number, parent.BaseFee, parent.GasUsed); err != nil {
    return err
}
``` [5](#0-4) 

**Block production** (`work/worker.go`):
```go
pset := self.govModule.GetParamSet(nextBlockNum.Uint64())
nextBaseFee = pset.ToKip71Config().NextMagmaBlockBaseFee(
    parent.Number(), parent.Header().BaseFee, parent.GasUsed())
``` [6](#0-5) 

After the governance epoch containing the `kip71.gastarget = 0` vote takes effect, every node on the network panics when processing the first block whose parent had `GasUsed > 0`. This causes a complete chain halt — consensus divergence on all honest nodes.

---

### Likelihood Explanation

In `governance.governancemode = "none"` (the permissive mode), any single GC member can cast the decisive vote. In `"single"` mode, the governing node alone can do so. The `checkConsistency` function in `kaiax/gov/headergov/impl/header.go` performs no additional validation for `Kip71GasTarget` beyond the `noopFormatChecker`:

```go
case gov.Kip71BaseFeeDenominator, gov.Kip71GasTarget, gov.Kip71MaxBlockGasUsedForBaseFee, ...:
    return nil   // ← no consistency check
``` [7](#0-6) 

The vote is accepted, ratified at the next epoch boundary, and takes effect one epoch later — at which point the chain halts irreversibly until a manual governance recovery vote is processed (which itself requires a non-panicking chain).

---

### Recommendation

Apply the same two-layer defense used for `Kip71BaseFeeDenominator`:

1. **`FormatChecker`** in `kaiax/gov/param.go`: reject zero.
   ```go
   Kip71GasTarget: {
       FormatChecker: func(cv any) bool {
           v, ok := cv.(uint64)
           return ok && v > 0
       },
   ```

2. **Runtime guard** in `params/kip71_config.go` inside `NextMagmaBlockBaseFee`:
   ```go
   if kc.GasTarget == 0 {
       gasTarget = 1  // or return lowerBoundBaseFee as a safe fallback
   } else {
       gasTarget = kc.GasTarget
   }
   ```

---

### Proof of Concept

1. In `governance.governancemode = "none"`, a GC member calls `governance_vote("kip71.gastarget", 0)`.
2. The vote passes `noopFormatChecker` and `checkConsistency` without error.
3. At the next epoch boundary the vote is ratified; it takes effect at `(epoch+1)*epoch`.
4. The first block after activation where `parent.GasUsed > 0` causes every node to execute:
   ```
   y := x.Div(x, new(big.Int).SetUint64(0))  // big.Int.Div panics: division by zero
   ```
   in both `validateHeader` (verifiers) and `commitNewWork` (proposer).
5. All nodes crash. The chain halts. No new blocks can be produced or accepted.
