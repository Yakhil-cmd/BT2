#No vulnerability found for this question.

**Rationale:** The scenario described is explicitly mitigated in the code. `createWorktree` at [1](#0-0)  documents and handles exactly this "wedge" case: before every `git worktree add` call, it first calls `removeWorktree`, which does `os.RemoveAll` on the worktree directory and then runs `git worktree prune --verbose` [2](#0-1) . The code comment explicitly states: "Avoid wedge cases where the worktree was created but this function error'd without cleaning up. The next time thru the sync loop fails to create the worktree and bails out. This manifests as: 'fatal: ... already exists'" [3](#0-2) .

Additionally, `createWorktree` is called with `--no-checkout` [4](#0-3) , meaning the actual file checkout that could exhaust disk happens later, via `git reset --hard` in `configureWorktree` [5](#0-4) , not during `worktree add` itself — so `worktree add`'s administrative bookkeeping succeeds quickly (creating only small metadata under `.git/worktrees/<hash>`) before any large content write occurs.

Since `currentWorktree()` derives state from the published symlink target rather than from git's internal worktree registry [6](#0-5) , a failed sync (before the symlink is updated) will cause the next sync loop iteration to retry the same hash, which triggers `removeWorktree` (RemoveAll + `worktree prune`) before re-adding. This self-heals the exact "broken .git/worktrees/<id> blocking future adds" condition described in the question, rather than permanently wedging. The e2e test suite also explicitly exercises crash/corruption recovery paths (e.g. `e2e::sync_crash_no_worktree_cleanup_retry`, `e2e::worktree_cleanup`) confirming this design intent [7](#0-6) .

```go
// removeWorktree is used to remove a worktree and its folder.
func (git *repoSync) removeWorktree(ctx context.Context, worktree worktree) error {
	// Clean up worktree, if needed.
	_, err := os.Stat(worktree.Path().String())
	switch {
	case os.IsNotExist(err):
		return nil
	case err != nil:
		return err
	}
	git.log.V(1).Info("removing worktree", "path", worktree.Path())
	if err := os.RemoveAll(worktree.Path().String()); err != nil {
		return fmt.Errorf("error removing directory: %w", err)
	}
	if _, _, err := git.Run(ctx, git.root, "worktree", "prune", "--verbose"); err != nil {
		return err
	}
	return nil
}
```

```go
// createWorktree creates a new worktree and checks out the given hash.  This
// returns the path to the new worktree.
func (git *repoSync) createWorktree(ctx context.Context, hash string) (worktree, error) {
	// Make a worktree for this exact git hash.
	worktree := git.worktreeFor(hash)

	// Avoid wedge cases where the worktree was created but this function
	// error'd without cleaning up.  The next time thru the sync loop fails to
	// create the worktree and bails out. This manifests as:
	//     "fatal: '/repo/root/nnnn' already exists"
	if err := git.removeWorktree(ctx, worktree); err != nil {
		return "", err
	}

	git.log.V(1).Info("adding worktree", "path", worktree.Path(), "hash", hash)
	_, _, err := git.Run(ctx, git.root, "worktree", "add", "--force", "--detach", worktree.Path().String(), hash, "--no-checkout")
	if err != nil {
		return "", err
	}

	return worktree, nil
}
```

```go
// currentWorktree reads the repo's link and returns a worktree value for it.
func (git *repoSync) currentWorktree() (worktree, error) {
	target, err := os.Readlink(git.link.String())
	if err != nil && !os.IsNotExist(err) {
		return "", err
	}
	if target == "" {
		return "", nil
	}
	if filepath.IsAbs(target) {
		return worktree(target), nil
	}
	linkDir, _ := git.link.Split()
	return worktree(linkDir.Join(target)), nil
}
```

```shellscript
function e2e::sync_crash_no_worktree_cleanup_retry() {
    # First sync
    GIT_SYNC \
        --one-time \
        --repo="file://$REPO" \
        --root="$ROOT" \
        --link="link"
```
