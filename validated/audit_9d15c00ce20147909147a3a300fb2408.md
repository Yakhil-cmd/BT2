### Title
Governing Node Can Point `governance.govparamcontract` to an Arbitrary Contract, Bypassing the Activation-Delay Protection on All Contract-Governance Parameters — (`kaiax/gov/contractgov/impl/getter.go`, `kaiax/gov/headergov/impl/header.go`)

### Summary

The `governance.govparamcontract` parameter is mutable via header governance and can be changed to any arbitrary address. The `contractGovModule` unconditionally trusts whatever `getAllParamsAt(blockNum)` returns from that address. A malicious contract at that address can return governance parameters with `activation = 0` (or any past block), bypassing the activation-delay protection that the legitimate `GovParam` contract enforces. Because contract-governance values override header-governance values in the final `GetParamSet` merge, the governing node can immediately alter critical chain parameters — minting amounts, reward ratios, unit price — without the advance-notice window that users and validators rely on.

### Finding Description

A malicious contract implementing the `getAllParamsAt(uint256)` interface can return any parameter values with any activation block (including block 0), and the node will accept them as long as they pass the `FormatChecker` (i.e., are valid values within the allowed range).

**Step 4 — Contract-governance values override header-governance values.**

### Impact Explanation

Once the malicious `govparamcontract` is active (after one epoch), the governing node can immediately alter:

- `reward.mintingamount` — controls how many KAIA are minted per block; setting it to an extreme value causes unbounded inflation or deflation of KAIA.
- `reward.ratio` — controls the split of block rewards between CN/KIF/KEF; setting it to `"100/0/0"` redirects all newly minted KAIA to the governing node's reward base.
- `reward.kip82ratio` — controls the proposer/staker split; can be set to `"100/0"` to drain staking rewards.
- `governance.unitprice` — controls the minimum gas price; setting it to 0 breaks fee collection.

All of these are protected-state impacts: unauthorized reward distribution and fee-parameter manipulation affecting KAIA and system-managed funds.

### Likelihood Explanation

- **Trigger**: The governing node (a single address in `single` governance mode on Mainnet and Kairos) must cast a vote for `governance.govparamcontract`. This vote takes effect after one epoch (~1 week on Mainnet).
- **Semi-trusted actor**: The governing node is semi-trusted. A compromised or malicious governing node key is the realistic threat model.
- **No on-chain guard**: There is no code path that validates the new contract address or enforces a minimum activation delay on values returned by the contract.
- **Stealth**: The `govparamcontract` change is visible on-chain, but the malicious contract's behavior (returning parameters with `activation = 0`) is not visible until it is queried, giving users no practical warning.

### Recommendation

1. **Validate the new `govparamcontract` address** in `checkConsistency`: verify that a contract exists at the address and that it implements the expected `getAllParamsAt` interface before accepting the vote.
2. **Enforce a minimum activation delay** in `contractGetAllParamsAtFromAddr`: reject any parameter whose `activation` block is less than `blockNum + minDelay` (e.g., one epoch), mirroring the delay that header governance already enforces.
3. **Alternatively**, implement the activation-delay check directly in the node (analogous to the FraxlendPair recommendation of embedding the timelock logic in the contract rather than trusting an external one).

### Proof of Concept

1. Governing node deploys `MaliciousGovParam` implementing `getAllParamsAt(uint256) returns (string[], bytes[])` that returns `["reward.mintingamount"]` / `[abi.encode(MAX_UINT256)]` for any block number.
2. Governing node calls `governance_vote("governance.govparamcontract", <MaliciousGovParam address>)`.
3. After one epoch, the vote is ratified and `govparamcontract` points to `MaliciousGovParam`.
4. From the next block onward, `contractGetAllParamsAtFromAddr` calls `MaliciousGovParam.getAllParamsAt(blockNum)`, which returns `reward.mintingamount = MAX_UINT256` with no activation delay.
5. `GetParamSet` merges this over the header-governance value; the reward module mints `MAX_UINT256` KAIA per block.

Relevant code path: `governance_vote` → `VerifyVote` (no address check) → header ratification after epoch → `contractAddrAt` returns malicious address → `contractGetAllParamsAtFromAddr` calls `getAllParamsAt` → `ParseContractCall` accepts values → `GetParamSet` merges contract values over header values → reward/fee modules use corrupted `ParamSet`. func (h *headerGovModule) VerifyVote(header *types.Header) error {
	if len(header.Vote) == 0 {
		return nil
	}

	var (
		vb       headergov.VoteBytes = header.Vote
		blockNum                     = header.Number.Uint64()
	)

	vote, err := vb.ToVoteData()
	if err != nil {
		logger.Error("ToVoteData error", "num", blockNum, "vote", vb, "err", err)
		return err
	}

	if gov.DeprecatedAt(vote.Name(), h.ChainConfig.Rules(header.Number)) {
		logger.Error("Vote is deprecated", "num", blockNum, "name", vote.Name())
		return ErrDeprecatedVote
	}

	council, err := h.ValSet.GetCouncil(blockNum)
	if err != nil {
		return err
	}

	// check if the voter is in council
	if !slices.Contains(council, vote.Voter()) {
		return ErrInvalidKeyValue
	}

	// check if Voter is the block proposer.
	author, err := h.Chain.Sealer().Author(header)
	if err != nil {
		return err
	}
	if author != vote.Voter() {
		return ErrInvalidVoter
	}

	// In single mode, only the governing node can write header.Vote after Permissionless.
	params := h.GetParamSet(blockNum)
	if h.ChainConfig.IsPermissionlessForkEnabled(new(big.Int).SetUint64(blockNum)) &&
		params.GovernanceMode == "single" &&
		vote.Voter() != params.GoverningNode {
		return ErrVotePermissionDenied
	}

	return h.checkConsistency(blockNum, vote)

func (c *contractGovModule) contractGetAllParamsAt(blockNum uint64) (gov.PartialParamSet, error) {
	addr, err := c.contractAddrAt(blockNum)
	if err != nil {
		return nil, err
	}
	if common.EmptyAddress(addr) {
		logger.Trace("ContractEngine disabled: GovParamContract address not set")
		return nil, nil
	}

	return c.contractGetAllParamsAtFromAddr(blockNum, addr)
}

func (c *contractGovModule) contractGetAllParamsAtFromAddr(blockNum uint64, addr common.Address) (gov.PartialParamSet, error) {
	chain := c.Chain
	if chain == nil {
		return nil, ErrNotReady
	}

	config := c.ChainConfig
	if !config.IsKoreForkEnabled(new(big.Int).SetUint64(blockNum)) {
		return nil, ErrNotReady
	}

	caller := backends.NewBlockchainContractBackend(chain, nil, nil)
	contract, err := govcontract.NewGovParamCaller(addr, caller)
	if err != nil {
		return nil, err
	}

	names, values, err := contract.GetAllParamsAt(nil, new(big.Int).SetUint64(blockNum))
	if err != nil {
		logger.Warn("ContractEngine disabled: getAllParams call failed", "err", err)
		return nil, nil
	}

	if len(names) != len(values) {
		logger.Warn("ContractEngine disabled: getAllParams result invalid", "len(names)", len(names), "len(values)", len(values))
		return nil, nil
	}

	ret := ParseContractCall(names, values)

	rules := config.Rules(new(big.Int).SetUint64(blockNum))
	for name := range ret {
		if gov.DeprecatedAt(name, rules) {
			logger.Warn("Ignoring deprecated parameter from contract governance", "name", name, "blockNum", blockNum)
			delete(ret, name)
		}
	}

	return ret, nil
}
