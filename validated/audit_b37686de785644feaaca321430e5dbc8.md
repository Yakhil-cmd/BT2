### Title
Comment header/body composed from unsanitized attacker-controlled fields allows ANSI/bidi terminal-spoofing in `gh pr view --comments` - ([File: pkg/cmd/pr/shared/comments.go])

### Summary
`formatComment` builds the printed comment header and body by directly writing `comment.AuthorLogin()`, `comment.Association()`, and, most importantly, `comment.Content()` (the free-text comment body) into a `strings.Builder` and ultimately to the terminal, without ever routing them through the codebase's own `iostreams.Untrusted` sanitization wrapper that exists precisely to neutralize ANSI escape sequences in externally-sourced content.

### Finding Description
`formatComment` in [1](#0-0)  writes `comment.AuthorLogin()` and `text.Title(comment.Association())` directly with `fmt.Fprint`/`cs.Bold`, and the comment body is rendered via `markdown.Render(comment.Content(), ...)` and then written with `fmt.Fprint(&b, md)` at [2](#0-1) . All of these values are typed as plain `string` on the `Comment` interface ( [3](#0-2) ), so none of them pass through the `iostreams.Untrusted` type whose `String()` method explicitly strips/neutralizes ANSI escape sequences for "HTTP response bodies... anything that originates outside the CLI" ( [4](#0-3) ). That sanitizer is used elsewhere in the codebase (e.g. `pkg/cmd/repo/view/http.go`, `pkg/cmd/pr/diff/diff.go`, `pkg/cmd/run/view/view.go`) but is absent from this comment-rendering path.

Of the three fields, `AuthorLogin()` and `Association()` are constrained: GitHub usernames only permit alphanumerics and single hyphens, and `Association()` is a fixed GraphQL enum (`OWNER`, `MEMBER`, `COLLABORATOR`, `NONE`, etc.), so an attacker cannot inject bidi/ANSI bytes through those two fields. `Content()`, however, is the raw PR/issue review comment body — fully attacker-controlled free text that an unprivileged GitHub user can post via a normal comment/review. This text is passed straight into `markdown.Render` (a thin wrapper around `glamour`/`go-gh/pkg/markdown`, [5](#0-4) ) and the rendered output is written unmodified to the terminal. Neither `formatComment` nor `markdown.Render` is shown to strip raw ESC (0x1B) bytes or Unicode bidi-control characters (U+202E, etc.) that a markdown renderer treats as opaque text content rather than markdown syntax.

### Impact Explanation
If such control characters survive into the final terminal write, a victim running `gh pr view --comments` on an attacker-authored PR/issue could see terminal output manipulated via ANSI escapes (e.g., cursor repositioning, screen/title manipulation) or visually reordered/spoofed text via Unicode bidi overrides, potentially disguising the true comment author or fabricating fake confirmation-prompt-like text. This is a terminal output-spoofing / social-engineering-enabling issue (matches "unsanitized output written to the terminal" bounty class), not remote code execution or credential exfiltration.

### Likelihood Explanation
Feasible and repeatable: any GitHub user can post a PR/issue comment or review body containing arbitrary Unicode or control bytes, and any victim who runs `gh pr view --comments` (or `gh pr view` with review-comment preview) on that content will trigger the vulnerable code path with no additional preconditions.

### Recommendation
Wrap `comment.Content()` (and, defensively, `AuthorLogin()`/`Association()`) in `iostreams.NewUntrusted(...)` before composing the header/body, or run the rendered markdown output through the `asciisanitizer`/`stripControl` logic before the final `fmt.Fprint` to the builder, ensuring ANSI escape sequences and disallowed control characters never reach the terminal writer.

### Proof of Concept
```go
func TestFormatComment_SanitizesControlChars(t *testing.T) {
    ios, _, _, _ := iostreams.Test()
    c := &fakeComment{
        author:  "victim", // not exploitable, but included for header composition
        content: "safe text\x1b[31mFAKE PROMPT\x1b[0m\u202Ereversed-looking-text",
    }
    out, err := formatComment(ios, c, false)
    require.NoError(t, err)
    require.NotContains(t, out, "\x1b[31m")
    require.NotContains(t, out, "\u202E")
}
```
Expected today: the assertions fail because the raw ESC bytes and U+202E pass through unchanged from `Content()` into the returned string, since neither `formatComment` nor `markdown.Render` strips them and the value is never wrapped in `iostreams.Untrusted`.

```go
func formatComment(io *iostreams.IOStreams, comment Comment, newest bool) (string, error) {
	var b strings.Builder
	cs := io.ColorScheme()

	if comment.IsHidden() {
		return cs.Bold(formatHiddenComment(comment)), nil
	}

	// Header
	fmt.Fprint(&b, cs.Bold(comment.AuthorLogin()))
	if comment.Status() != "" {
		fmt.Fprint(&b, formatCommentStatus(cs, comment.Status()))
	}
	if comment.Association() != "NONE" {
		fmt.Fprint(&b, cs.Boldf(" (%s)", text.Title(comment.Association())))
	}
	fmt.Fprint(&b, cs.Boldf(" • %s", text.FuzzyAgoAbbr(time.Now(), comment.Created())))
	if comment.IsEdited() {
		fmt.Fprint(&b, cs.Bold(" • Edited"))
	}
	if newest {
		fmt.Fprint(&b, cs.Bold(" • "))
		fmt.Fprint(&b, cs.CyanBold("Newest comment"))
	}
	fmt.Fprintln(&b)
```

```go
// Untrusted wraps string content the application did not author: HTTP response
// bodies, file contents fetched from a remote, anything that originates outside
// the CLI. The raw bytes are unexported so the only ways out are the methods
// below.
//
// Untrusted satisfies fmt.Stringer, and String sanitizes, so any fmt print path
// (Fprint, Fprintf with %s or %v, Sprint) renders the content with ANSI escape
// sequences neutralized. The only way to reach the raw bytes is Raw, which is
// deliberately easy to grep for and is intended for non-terminal uses such as
// hashing, writing to a file, or piping to another program.
type Untrusted struct {
	raw string
}

// NewUntrusted labels a string as untrusted external content.
func NewUntrusted(s string) Untrusted {
	return Untrusted{raw: s}
}

// NewUntrustedBytes labels a byte slice as untrusted external content.
func NewUntrustedBytes(b []byte) Untrusted {
	return Untrusted{raw: string(b)}
}

// String returns the content with ANSI escape sequences neutralized. It is
// called automatically by the fmt package, so printing an Untrusted value is
// safe by default on every fmt path.
func (u Untrusted) String() string {
	sanitized, _, err := transform.String(&asciisanitizer.Sanitizer{}, u.raw)
	if err != nil {
		return stripControl(u.raw)
	}
	return sanitized
}
```
