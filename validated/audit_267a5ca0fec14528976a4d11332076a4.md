### Title
Unbounded snappy decoded-length header allows memory-exhaustion DoS via attacker-supplied bundle body - ([File: pkg/cmd/attestation/api/client.go])

### Finding Description
`LiveClient.getBundle` fetches the attestation bundle from `a.BundleURL` with no size cap on the response (`io.ReadAll(resp.Body)` with no `io.LimitReader`/`http.MaxBytesReader`), then passes the entire body directly to `snappy.Decode(out, body)` with `out == nil`. [1](#0-0) 

`klauspost/compress/snappy`'s block-format `Decode` reads an unsigned varint "decoded length" header from the first few bytes of the input and, when `dst` is `nil`, allocates `make([]byte, dLen)` for that length *before* verifying that the remaining compressed bytes actually decompress to that size. On 64-bit hosts the length check only rejects values above `0xffffffff` (~4 GiB), so a handful of header bytes can force a multi-gigabyte allocation attempt regardless of the actual (small) size of the response body.

The `a.BundleURL` for an attestation is populated from the GitHub API response for attestations that the attacker (an unprivileged user) themselves uploaded to their own repository; the underlying blob content at that URL is attacker-controlled even though the URL's host is GitHub-owned, satisfying the "no MITM" constraint. When a victim runs `gh attestation verify` against that attacker's artifact/attestation, `fetchBundleFromAttestations` concurrently calls `getBundle` for every returned attestation via an `errgroup`, so a single malicious response — or several in parallel — can each trigger this oversized allocation. [2](#0-1) [3](#0-2) 

No existing control mitigates this: there is no response size limit, no pre-check of the snappy header against a sane maximum, and no context deadline wrapping the decode step in `getBundle`.

### Impact Explanation
Denial of service against the `gh` CLI process (and potentially the host, if repeated/parallel requests exhaust available memory) when a victim verifies an attacker-published attestation/artifact. This falls under a DoS impact class — not code execution or credential exposure — matching the scoped impact described in the prompt.

### Likelihood Explanation
Feasible and repeatable: the attacker only needs to upload an attestation to their own public repo/artifact with a bundle body containing a crafted snappy varint header specifying a large decoded length. Any victim who runs `gh attestation verify` against that artifact/digest triggers the vulnerable path with no privileged access required from the attacker.

### Recommendation
- Wrap `resp.Body` in `io.LimitReader` (or use `http.MaxBytesReader`-style limiting) before `io.ReadAll` to bound the compressed input size.
- Validate the snappy decoded length via `snappy.DecodedLen(body)` against a reasonable maximum (e.g., a few MB, consistent with expected bundle sizes) before calling `snappy.Decode`, rejecting oversized claims early.
- Consider passing a pre-sized `dst` buffer capped at the maximum acceptable bundle size instead of `nil`, so `Decode` cannot allocate beyond that bound.

    // but contains only a few actual bytes of "compressed" data.

    body = append(body, 0x00) // minimal/garbage literal tag

    mockClient := &mockHTTPClient{

                StatusCode: 200,
                Body:       io.NopCloser(bytes.NewReader(body)),
            }, nil
        },
    }
    c := &LiveClient{externalHttpClient: mockClient, logger: testLogger()}

    done := make(chan struct{})
    go func() {
        _, _ = c.getBundle(safeurl.NewImmutableSafeURL("https://example.com/bundle"))
        close(done)
    }()

    select {
    case <-done:
        // Expect: peak allocated memory should stay bounded (e.g. < a few MB),
        // verified via runtime.MemStats before/after, and/or the call should
        // return an error quickly instead of attempting a multi-GB allocation.
    case <-time.After(5 * time.Second):
        t.Fatal("getBundle did not return in time — likely stuck on oversized allocation")
    }

func (c *LiveClient) fetchBundleFromAttestations(attestations []*Attestation) ([]*Attestation, error) {
	fetched := make([]*Attestation, len(attestations))
	g := errgroup.Group{}
	for i, a := range attestations {
		g.Go(func() error {
			if a.Bundle == nil && a.BundleURL == "" {
				return fmt.Errorf("attestation has no bundle or bundle URL")
			}

			// for now, we fall back to the bundle field if the bundle URL is empty
			if a.BundleURL == "" {
				c.logger.VerbosePrintf("Bundle URL is empty. Falling back to bundle field\n\n")
				fetched[i] = &Attestation{
					Bundle: a.Bundle,
				}
				return nil
			}

			// otherwise fetch the bundle with the provided URL
			b, err := c.getBundle(safeurl.NewImmutableSafeURL(a.BundleURL))
			if err != nil {
				return fmt.Errorf("failed to fetch bundle with URL: %w", err)
			}
			fetched[i] = &Attestation{
				Bundle: b,
			}

			return nil
		})
	}

	if err := g.Wait(); err != nil {
		return nil, err
	}

	return fetched, nil
}
