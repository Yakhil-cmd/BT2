### No vulnerability found for this question.

**Reasoning:** The claimed binding — that `stack_id` passed to `Status.replicate_from_github!` should be derived from `Repository.from_github_repo_name(payload.repository.full_name)` — is not the actual intended invariant. The real invariant enforced by the code is `stack_id == commit.stack_id`, i.e. the write always targets the stack that legitimately owns the `Commit` row matched by `sha`. This holds unconditionally: `Commit#create_status_from_github!` calls `statuses.replicate_from_github!(stack_id, github_status)` where `statuses` is the commit's own association and `stack_id` is `commit.stack_id` [1](#0-0) , and `Status.replicate_from_github!` just persists against that value [2](#0-1) . The `repository` field never being consulted by `StatusHandler#process` is true [3](#0-2) , but that does not create a cross-tenant write, because the write is scoped to the commit's own real stack, not to anything derived from the payload.

Additionally, the described attacker capability — sending a webhook with an attacker-chosen, possibly bogus `repository.full_name` while it still reaches `StatusHandler#process` — is blocked upstream. `WebhooksController#verify_signature` computes `Shipit.github(organization: repository_owner)` from `params.dig('repository','owner','login')` and validates the HMAC signature against that organization's configured secret [4](#0-3) . An attacker with no access to any org's webhook secret cannot produce a validly-signed payload with an arbitrary `repository.full_name`; a genuine GitHub-signed payload's `repository` field reflects the real repository that generated the event, not attacker-chosen content. So the premise of the proof idea (forging `repository: {full_name: 'totally/bogus'}` while the request still passes signature verification and reaches the handler) is not achievable without already possessing secrets, which is explicitly out of scope.

    def verify_signature
      github_app = Shipit.github(organization: repository_owner)
      verified = github_app.verify_webhook_signature(
        request.headers['X-Hub-Signature'],
        request.raw_post
      )
      head(422) unless verified

      Rails.logger.info([
        'WebhookController#verify_signature',
        "event=#{event}",
        "repository_owner=#{repository_owner}",
        "signature=#{request.headers['X-Hub-Signature']}",
        "status=#{status}"
      ].join(' '))
    rescue Shipit::GithubOrganizationUnknown => e
      head(422)
      Rails.logger.warn([
        'WebhookController#verify_signature',
        'Webhook from unknown organization',
        "event=#{event}",
        "repository_owner=#{repository_owner}",
        "unknown_organization=#{e.message}",
        "status=#{status}"
      ].join(' '))
    end
