### Title
Gasless Swap Deadline Enforced Only at TxPool Admission Against Stale Block Timestamp, Not at Block-Building Time — (`kaiax/gasless/impl/tx_pool.go`, `kaiax/gasless/impl/builder.go`)

---

### Summary

The KIP-247 gasless module checks the `deadline` field of a `GaslessSwapTx` only once, at txpool admission, and compares it against the **last committed block's timestamp** (`g.Chain.CurrentBlock().Time()`). The block-building path (`ExtractTxBundles` → `IsExecutable` → `VerifyExecutable`) performs no deadline check at all. A user can craft a swap transaction whose deadline equals the last committed block's timestamp, pass the txpool gate, and have the bundle included in the next block — whose timestamp is strictly greater — causing the on-chain `swapForGas` call to revert while the proposer's `LendTx` (which already transferred KAIA to the user) cannot be unwound. The proposer loses the lent KAIA; the user keeps it without repaying.

---

### Finding Description

**Step 1 — Txpool admission check uses stale timestamp.**

`checkBalanceForSwap` in `kaiax/gasless/impl/tx_pool.go` enforces:

```go
// tx.deadline >= currentTimestamp
deadline := swapArgs.Deadline
if deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
    return fmt.Errorf("insufficient deadline: ...")
}
```

The comparison is `deadline >= lastCommittedBlock.Time`. A deadline equal to `lastCommittedBlock.Time` passes. The next block will have timestamp `lastCommittedBlock.Time + Δ` (at minimum 1 second on Kaia), so the deadline is already expired relative to the block that will actually execute the transaction.

**Step 2 — Block-building path never re-checks the deadline.**

`ExtractTxBundles` in `kaiax/gasless/impl/builder.go` calls `g.IsExecutable(approveTxs[addr], tx)`, which delegates to `VerifyExecutable`. `VerifyExecutable` checks conditions SP1–SP4 (sender, token, nonce, repay amount) but contains **no deadline check**:

```go
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
    // Sx, AP1, SP1, SP2, SP3, SP4 — no deadline check
    ...
    return nil
}
```

The bundle `[LendTx, (ApproveTx), SwapTx]` is assembled and committed to the block without verifying that `swapArgs.Deadline >= nextBlock.Time`.

**Step 3 — Bundle execution order and irreversibility.**

The bundle executes atomically in order:
1. `LendTx` — proposer transfers `lendAmount` KAIA to the user (irreversible once mined).
2. `ApproveTx` (optional) — user approves the router.
3. `SwapTx` — calls `GaslessSwapRouter.swapForGas(...)` on-chain.

If the on-chain `GaslessSwapRouter` contract enforces `require(block.timestamp <= deadline)` (standard AMM practice, and consistent with the parameter's purpose), `SwapTx` reverts. The EVM reverts only `SwapTx`'s state changes; `LendTx` is a separate transaction and its KAIA transfer is already finalized. The user retains the lent KAIA and pays nothing back.

**Step 4 — Concrete attack path.**

| Step | Actor | Action |
|------|-------|--------|
| 1 | User | Observes `lastBlock.Time = T` |
| 2 | User | Submits `SwapTx` with `deadline = T` |
| 3 | TxPool | `T >= T` → admission passes |
| 4 | Proposer | `ExtractTxBundles` → `VerifyExecutable` → no deadline check → bundle formed |
| 5 | Chain | Next block timestamp = `T + 1` |
| 6 | EVM | `LendTx` executes: proposer sends `lendAmount` KAIA to user |
| 7 | EVM | `SwapTx` executes: contract checks `block.timestamp (T+1) > deadline (T)` → reverts |
| 8 | Result | User keeps lent KAIA; proposer is not repaid |

The `lendAmount` is computed as:

```go
func lendAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
    r := new(big.Int)
    if approveTxOrNil != nil {
        r.Add(r, approveTxOrNil.Fee())
    }
    r.Add(r, swapTx.Fee())
    return r
}
```

For a swap with `gasLimit = 500,000` and `gasPrice = 50 Gkei`, `swapTx.Fee() = 25,000,000 Gkei = 0.025 KAIA`. With an approve tx, the total lent amount is larger. This is repeatable by any user for every gasless swap.

---

### Impact Explanation

The proposer (CN) suffers an unauthorized KAIA debit equal to `lendAmount(approveTxOrNil, swapTx)` per exploited bundle. The user receives this KAIA without repaying. Because the attack requires only a single crafted transaction (setting `deadline = lastBlock.Time`) and is repeatable across every block, the cumulative loss to proposers can be significant. This matches the allowed impact: **unauthorized transfer of KAIA from a system-managed fund (the proposer's lending balance)**.

---

### Likelihood Explanation

The attack requires no special privilege. Any user who can submit a legacy transaction to the txpool can exploit this. The condition `deadline = lastBlock.Time` is trivially constructable by reading the chain head. The `PendingTimeout` of 10 seconds does not mitigate this because the malicious tx is included in the very next block (within 1 second on Kaia), well before the timeout fires.

---

### Recommendation

1. **Fix the txpool deadline check** to use a forward-looking timestamp. Replace:
   ```go
   if deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
   ```
   with a check against the expected next block timestamp (e.g., `currentBlock.Time() + expectedBlockInterval`), or use strict inequality (`<= 0` instead of `< 0`) at minimum.

2. **Add a deadline check in `VerifyExecutable`** (and therefore in `ExtractTxBundles`) so that expired swap transactions are never bundled:
   ```go
   if swapArgs.Deadline.Cmp(g.Chain.CurrentBlock().Time()) <= 0 {
       return ErrDeadlineExpired
   }
   ```

3. **Add a deadline check in `ExtractTxBundles`** as a defense-in-depth measure before forming the bundle.

---

	err := g.VerifyExecutable(approveTxOrNil, swapTx)
	if err != nil {
		return false
	}
	return true
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
