### No vulnerability found for this question.

`borsh_ext_index` is a trivial `const fn` that casts an `ExtCosts` enum variant to its `usize` discriminant for use as an array index when serializing/deserializing `ProfileDataV3` profiling data via Borsh [1](#0-0) . It has no relationship whatsoever to prepaid gas accounting or limit enforcement — it's purely used inside `BorshDeserialize`/`BorshSerialize` impls to map ext-cost profiling values into/out of a fixed-size `Vec<u64>` for on-disk profile storage [2](#0-1) .

The actual invariant "total prepaid gas across a receipt never exceeds the configured maximum" is enforced in `runtime/runtime/src/action_validation.rs::validate_actions_with_mode`, which computes `total_prepaid_gas(actions)` (with overflow checking via `map_err(|_| ActionsValidationError::IntegerOverflow)`) and rejects the actions if it exceeds `limit_config.max_total_prepaid_gas` [3](#0-2) . This check runs for every new receipt (`ValidateReceiptMode::NewReceipt`), including receipts generated by `promise_batch_action_*` host calls, and is exercised by existing tests such as `test_validate_actions_too_much_gas` and `test_validate_actions_gas_overflow` [4](#0-3) .

There is no code path by which `borsh_ext_index` (a pure enum-to-index mapping used only for serialization) could influence, bypass, or interact with the prepaid-gas ceiling check. The question's premise misattributes the gas-limit invariant to an unrelated serialization helper function.

impl BorshDeserialize for ProfileDataV3 {
    fn deserialize_reader<R: std::io::Read>(rd: &mut R) -> std::io::Result<Self> {
        let actions_array: Vec<u64> = BorshDeserialize::deserialize_reader(rd)?;
        let ext_array: Vec<u64> = BorshDeserialize::deserialize_reader(rd)?;
        let wasm_gas: u64 = BorshDeserialize::deserialize_reader(rd)?;

        // Mapping raw arrays to enum maps.
        // The enum map could be smaller or larger than the raw array.
        // Extra values in the array that are unknown to the current binary will
        // be ignored. Missing values are filled with 0.
        let actions_profile = enum_map! {
            cost => Gas::from_gas(actions_array.get(borsh_action_index(cost)).copied().unwrap_or(0))
        };
        let wasm_ext_profile = enum_map! {
            cost => Gas::from_gas(ext_array.get(borsh_ext_index(cost)).copied().unwrap_or(0))
        };

        Ok(Self { actions_profile, wasm_ext_profile, wasm_gas: Gas::from_gas(wasm_gas) })
    }
}

impl BorshSerialize for ProfileDataV3 {
    fn serialize<W: std::io::Write>(&self, writer: &mut W) -> Result<(), std::io::Error> {
        let mut actions_costs: Vec<u64> = vec![0u64; ActionCosts::LENGTH];
        for (cost, gas) in &self.actions_profile {
            actions_costs[borsh_action_index(cost)] = gas.as_gas();
        }
        BorshSerialize::serialize(&actions_costs, writer)?;

        let mut ext_costs: Vec<u64> = vec![0u64; ExtCosts::LENGTH];
        for (cost, gas) in &self.wasm_ext_profile {
            ext_costs[borsh_ext_index(cost)] = gas.as_gas();
        }
        BorshSerialize::serialize(&ext_costs, writer)?;

        let wasm_cost: u64 = self.wasm_gas.as_gas();
        BorshSerialize::serialize(&wasm_cost, writer)
    }
}
