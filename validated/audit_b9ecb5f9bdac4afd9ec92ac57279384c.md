### Title
Off-by-one in `checkBalanceForSwap` deadline check allows attacker to grief proposer into unrecoverable KAIA lend loss — (`kaiax/gasless/impl/tx_pool.go`)

### Summary
`checkBalanceForSwap` accepts swap transactions whose `deadline` equals `currentBlock.Time()`. Because the next block's timestamp is strictly greater, the router contract reverts the swap. The proposer's LendTx has already committed, so the lend amount in KAIA is permanently lost.

### Finding Description
The deadline guard uses `deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0`, which passes when `deadline == currentBlock.Time()`. The comment above the check states the intended invariant is `deadline >= currentTimestamp`, but the correct invariant for inclusion in the *next* block must be `deadline > currentBlock.Time()`. The off-by-one means a deadline of exactly the current block timestamp is accepted at the mempool/txpool layer but will always be expired at execution time. [1](#0-0) 

### Impact Explanation
The proposer emits a LendTx transferring real KAIA to the attacker. The SwapTx reverts, so `amountRepay` is never paid back. The proposer suffers a net loss of `approveTx.Fee() + swapTx.Fee()` KAIA per bundle. An attacker with a whitelisted token balance can repeat this indefinitely to drain the proposer.

### Likelihood Explanation
The current block timestamp is publicly readable. Crafting a swap tx with `deadline = currentBlock.Time()` requires only a valid token balance and correct `amountRepay` encoding — both are straightforward for any user of the gasless system.

### Recommendation
Change the comparison to reject deadlines that are not strictly in the future relative to the current block:

```go
if deadline.Cmp(g.Chain.CurrentBlock().Time()) <= 0 {
    return fmt.Errorf("deadline expired: deadline=%s, currentBlock=%s", ...)
}
```

### Proof of Concept
1. Read `T = g.Chain.CurrentBlock().Time()`.
2. Craft a swap tx with `deadline = T`, valid `amountIn`, `minAmountOut >= amountRepay`, correct `amountRepay`.
3. Call `checkBalanceForSwap` — assert it returns `nil`.
4. Simulate block execution with `block.timestamp = T + 1`.
5. Assert the SwapTx reverts at the router.
6. Assert the LendTx succeeded and the proposer's KAIA balance decreased by `lendAmount`.
