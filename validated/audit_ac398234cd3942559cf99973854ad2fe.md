### Title
`RemoveValidator` Governance Vote Lacks Minimum Council Size Check, Allowing BFT Quorum Collapse — (`kaiax/gov/headergov/impl/header.go`)

---

### Summary

The `checkConsistency` function in the header governance module performs no minimum-council-size validation for `RemoveValidator` votes in `none` governance mode. A single council member can cast the last vote in an epoch to remove all other validators, reducing the council below the Istanbul BFT quorum threshold. This is directly inconsistent with staking-based demotion, which has an explicit safety floor preventing the qualified set from reaching zero. The developers have acknowledged the gap with a `TODO` comment in the same module.

---

### Finding Description

**Inconsistent protection — the analog to M-02:**

In the CDP system, redemptions skip the recovery-mode check that every other state-modifying operation must pass. In Kaia, `RemoveValidator` governance votes skip the minimum-council-size check that staking-based demotion enforces.

**Path 1 — staking-based demotion (protected):**

`getDemotedValidatorsIstanbul` in `kaiax/valset/impl/getter_demote.go` contains an explicit safety floor:

```go
// If all validators are demoted, then no one is demoted.
if demoted.Len() == len(council.List()) {
    demoted = valset.NewAddressSet(nil)
}
``` [1](#0-0) 

This guarantees that the qualified validator set can never reach zero through staking changes alone.

**Path 2 — `RemoveValidator` governance vote (unprotected):**

`checkConsistency` in `kaiax/gov/headergov/impl/header.go` handles `RemoveValidator` votes:

```go
case gov.AddValidator, gov.RemoveValidator:
    params := h.GetParamSet(blockNum)
    // compare with governing node only in single mode.
    if params.GovernanceMode != "single" {
        return nil   // ← zero checks in none mode
    }
    if slices.Contains(vote.Value().([]common.Address), params.GoverningNode) {
        return ErrGovNodeInValSetVoteValue
    }
    return nil
    // These votes are valid as long as it passes the format checks in NewVoteData(). No more checks here.
``` [2](#0-1) 

In `none` mode the function returns `nil` immediately — no check on the resulting council size whatsoever.

**The vote value accepts a list of addresses**, so a single vote can remove every other council member simultaneously:

```go
{name: gov.RemoveValidator, value: "0xAddr1,0xAddr2,0xAddr3,..."}
``` [3](#0-2) 

After the epoch, `applyVote` applies the removal unconditionally, writing the shrunken council to the DB:

```go
case gov.RemoveValidator:
    if council.Contains(address) {
        council.Remove(address)
    }
``` [4](#0-3) 

**The developers themselves flagged this gap** with a `TODO` in the `Vote` API:

```go
// TODO-kaiax: add removevalidator vote check
api.h.PushMyVotes(vote)
``` [5](#0-4) 

**BFT quorum consequence:**

Istanbul BFT quorum is `ceil(2 * effectiveSize / 3)`. For `effectiveSize < 4`, quorum equals the size itself. If the council is reduced to 1, quorum = 1 and that single node can finalize blocks unilaterally. If reduced to 0, `GetProposer` and `GetCommittee` return empty sets, halting consensus entirely.

```go
func calcQuorumSize(qualifiedLen int, committeeSize uint64) int {
    size := min(qualifiedLen, int(committeeSize))
    if size < 4 {
        return size   // quorum = 1 when council = 1
    }
    return int(math.Ceil(float64(2*size) / 3))
}
``` [6](#0-5) 

---

### Impact Explanation

A council member in `none` governance mode who casts the last `RemoveValidator` vote in an epoch can ratify removal of all other validators. The corrupted value is the council address set written to the chain DB via `writeCouncil`, which can be reduced to a single address. This breaks the BFT invariant that requires at least `ceil(2n/3)` honest signers, constituting an invalid validator-set state transition that causes consensus divergence on all honest nodes. The remaining single validator can produce and finalize blocks without any other validator's approval, permanently corrupting the canonical chain state.

---

### Likelihood Explanation

- Requires the chain to operate in `none` governance mode (not Mainnet/Kairos, which use `single` mode, but applicable to any other Kaia-based deployment using `none` mode).
- Requires being a council member — a semi-trusted actor with legitimate governance rights.
- The attacker only needs to ensure their `RemoveValidator` vote is the last one cast for that parameter in the epoch (trivially achievable by voting near the epoch boundary).
- The multi-address vote format means a single transaction removes the entire council.
- The `TODO` comment confirms the developers are aware this check is absent.

---

### Recommendation

Add a minimum council size check inside `checkConsistency` for `RemoveValidator` votes, regardless of governance mode:

```go
case gov.AddValidator, gov.RemoveValidator:
    // existing governing-node check ...

    if vote.Name() == gov.RemoveValidator {
        council, err := h.ValSet.GetCouncil(blockNum - 1)
        if err != nil {
            return err
        }
        toRemove := vote.Value().([]common.Address)
        remaining := council.Len() - len(toRemove)
        if remaining < MinCouncilSize { // e.g. 4 for BFT safety
            return ErrCouncilTooSmall
        }
    }
```

This mirrors the safety floor already present in `getDemotedValidatorsIstanbul` and closes the inconsistency.

---

### Proof of Concept

1. Deploy a Kaia chain with `governance.governancemode = "none"` and a council of 4 validators: `[A, B, C, D]`.
2. Council member `A` calls `governance_vote("governance.removevalidator", "B,C,D")` near the end of epoch 0 (ensuring it is the last `removevalidator` vote).
3. At the epoch-0 boundary block, `VerifyGov` accepts the ratification (no size check exists).
4. `applyVote` removes B, C, D from the council; `writeCouncil` persists `[A]`.
5. From epoch 1 onward, `GetQualifiedValidators` returns `[A]` only; `calcQuorumSize(1, committeeSize)` = 1.
6. Node A alone can propose and commit every block, with no other validator able to participate — BFT consensus is permanently broken. [7](#0-6) [8](#0-7) [1](#0-0)

	case gov.GovernanceGoverningNode:
		params := h.GetParamSet(blockNum)

		// compare with governing node only in single mode.
		if params.GovernanceMode != "single" {
			return nil

		// we'll use blockNum-1 for the blocknumber of GetCouncil since blockNum cannot be available(eg. vote)
		// it's definite that the valSet vote is not included in this block
		// so the council(blockNum - 1) and council(blockNum) should be same
		council, err := h.ValSet.GetCouncil(blockNum - 1)
		if err != nil {
			return err
		}

		if slices.Contains(council, params.GoverningNode) {
			return nil
		}
		return ErrGovNodeNotInValSetList
	case gov.Kip71LowerBoundBaseFee:

			return nil
		}

```go
func applyVote(header *types.Header, council *valset.AddressSet, governingNode common.Address) bool {
	voteKey, addresses, ok := parseValidatorVote(header)
	if !ok {
		return false
	}

	originalSize := council.Len()
	for _, address := range addresses {
		if address == governingNode {
			continue
		}
		switch voteKey {
		case gov.AddValidator:
			if !council.Contains(address) {
				council.Add(address)
			}
		case gov.RemoveValidator:
			if council.Contains(address) {
				council.Remove(address)
			}
		}
	}
	return originalSize != council.Len()
