### Title
Mutable `PfsThreshold` in `AddressBookV2` Retroactively Reclassifies Epoch-Accumulated PFS Scores, Causing Unintended Validator Forced Exit — (`kaiax/valset/impl/transition_context.go`)

---

### Summary

The `PfsThreshold` parameter stored in the `AddressBookV2` system contract is mutable via `UpdatePfsThreshold`. It is read fresh from contract state at every block and used in `applyViolationTransition` to classify a validator's accumulated PFS score as either a minor violation (`ValActive → ValPaused`) or a severe violation (`ValActive → ValExiting`). Because PFS scores accumulate over an entire epoch (~86 400 blocks) but the threshold can be changed at any block, lowering `PfsThreshold` mid-epoch retroactively reclassifies validators who built up scores under the old, higher threshold, forcing them into `ValExiting` — a state they would not have reached under the threshold in effect when the failures occurred.

---

### Finding Description

**Mutable parameter read at every block:**

`ReadABv2Snapshot` is called each block to populate `ABv2TransitionParam`, which includes `PfsThreshold`:

```go
// blockchain/system/addressbook_v2.go
return &ABv2Snapshot{
    ABv2TransitionParam: ABv2TransitionParam{
        PfsThreshold: res.PfsThreshold.Uint64(),
        ...
    },
}, nil
```

`PfsThreshold` can be changed at any time by the configurator role:

```go
// contracts/bindings/addressbookv2/AddressBookV2.go
func UpdatePfsThreshold(opts *bind.TransactOpts, newPfsThreshold *big.Int) (*types.Transaction, error) {
    return _AddressBookV2.contract.Transact(opts, "updatePfsThreshold", newPfsThreshold)
}
```

**Accumulated PFS scores evaluated against the current (possibly changed) threshold:**

In `applyViolationTransition`, the current `ctx.PfsThreshold` is compared against `pfs`, which is the cumulative score over `[epochStart(N), N]`:

```go
// kaiax/valset/impl/transition_context.go:333-343
if pfs >= ctx.PfsThreshold {
    if canDemoteActive(valset.ValExiting) {
        val.State = valset.ValExiting   // severe: forced exit
    }
} else {
    if canDemoteActive(valset.ValPaused) {
        val.State = valset.ValPaused    // minor: temporary pause
    }
}
```

PFS scores are epoch-local and reset to zero at each epoch boundary:

```go
// kaiax/vrank/README.md
// PFS(N)[addr] = len({x in [epochStart(N), N] : addr in pfReport(x)})
```

The scores are not stored in the ABv2 contract; they live in the vrank module's `pfsCache`. The threshold that governs their interpretation, however, is read live from the contract.

**The broken invariant:** A validator who accumulated PFS = 3 under `PfsThreshold = 5` (minor violation → `ValPaused`) is retroactively reclassified as a severe violator if `PfsThreshold` is lowered to 2 before the next proposal-failure block. The validator is then transitioned to `ValExiting` — a state that drains to `ValInactive` at the next epoch — instead of `ValPaused`, which would have allowed recovery.

---

### Impact Explanation

`ValExiting` drains to `ValInactive` at the next epoch boundary (T1 transition):

```go
// kaiax/valset/impl/transition_context.go:198-200
case valset.ValExiting:
    val.State = valset.ValInactive // T1
    val.IdleTimeout = ctx.BlockTime.Add(ctx.IdleTimeout)
```

A `ValInactive` validator is removed from the active set, loses all block-proposal and committee-participation rewards for the remainder of the epoch and beyond, and must wait out the `IdleTimeout` (default 30 days) before re-entering as `Registered`. This is a materially worse outcome than `ValPaused` (which has an 8-hour `PauseTimeout` and allows recovery to `ValInactive` with a fresh idle timer).

The corrupted value is the validator's `State` field written back to `AddressBookV2` via `WriteTransitionToABv2`: it is set to `ValExiting` (and subsequently `ValInactive`) when the correct value — given the threshold in effect when the PFS scores were accumulated — would have been `ValPaused`.

This falls within the allowed impact gate: **system-contract privilege escalation that changes protected chain state** (validator lifecycle state in `AddressBookV2`) and **invalid state transition on honest nodes** (the transition is invalid relative to the threshold under which the scores were earned).

---

### Likelihood Explanation

The configurator role in `AddressBookV2` is a designated governance/operations key. Legitimate reasons to lower `PfsThreshold` include tightening liveness requirements after a period of instability. The side-effect on mid-epoch accumulated scores is non-obvious: the configurator acts in good faith, unaware that validators who have already accumulated PFS scores between the new and old threshold will be immediately reclassified at the next proposal-failure block. With an epoch of 86 400 blocks (~24 hours), there is a large window during which the threshold change can interact with existing scores.

---

### Recommendation

Store the `PfsThreshold` that was in effect at `epochStart(N)` alongside the PFS scores (e.g., in the vrank checkpoint or as a separate field in `ABv2TransitionParam` snapshotted at epoch boundaries), and use that epoch-start value — not the live contract value — when evaluating violation severity for the remainder of the epoch. The live value should only take effect from the next epoch start, mirroring how header-governance parameter changes take effect at `(k+1)*epoch`.

```diff
// applyViolationTransition
- if pfs >= ctx.PfsThreshold {
+ if pfs >= ctx.EpochStartPfsThreshold {
```

---

### Proof of Concept

1. `PfsThreshold` is initialized to `5` in `AddressBookV2`.
2. Validator V accumulates PFS = 3 during the current epoch (three failed proposals). Under threshold = 5, this is a minor violation; the next proposal-failure block would transition V to `ValPaused`.
3. The configurator calls `UpdatePfsThreshold(2)` to tighten liveness requirements.
4. At the next block where a proposal failure occurs (`len(ctx.PfReport) > 0`), `applyViolationTransition` reads `ctx.PfsThreshold = 2` from the freshly snapshotted ABv2 state.
5. `pfs(V) = 3 >= ctx.PfsThreshold = 2` → severe violation branch fires → `V.State = ValExiting`.
6. At the next epoch boundary, T1 fires: `ValExiting → ValInactive`, `IdleTimeout = BlockTime + 30 days`.
7. V is removed from the active validator set, loses all block rewards for the epoch remainder and the next 30 days, and must re-register — an outcome that would not have occurred under the threshold in effect when the PFS scores were earned. [1](#0-0) [2](#0-1) [3](#0-2) [4](#0-3) [5](#0-4)

func (ctx *TransitionContext) applyTimeoutTransition(m valset.NodeMap) valset.NodeMap {
	newValidators := m.Copy()
	for _, val := range newValidators {
		switch val.State {
		case valset.ValReady, valset.ValInactive:
			if val.IdleTimeout.IsZero() {
				val.IdleTimeout = ctx.BlockTime.Add(ctx.IdleTimeout)
			}
			if !ctx.BlockTime.Before(val.IdleTimeout) {
				val.State = valset.Registered
				val.IdleTimeout = time.Time{}
			}
		case valset.ValPaused:
			if val.PausedTimeout.IsZero() {
				val.PausedTimeout = ctx.BlockTime.Add(ctx.PauseTimeout)
			}
			if !ctx.BlockTime.Before(val.PausedTimeout) {
				val.State = valset.ValInactive
				val.PausedTimeout = time.Time{}
				val.IdleTimeout = ctx.BlockTime.Add(ctx.IdleTimeout)
			}
		default:
			val.IdleTimeout = time.Time{}
			val.PausedTimeout = time.Time{}
		}
	}
	return newValidators

// ABv2TransitionParam is the subset of ABv2 reads consumed by the transition
// pipeline. NodeMap is passed separately as the mutable pipeline input.
type ABv2TransitionParam struct {
	EpochVACount uint64 // pipeline initial value; carried through on non-epoch blocks

	PfsThreshold            uint64
	CfsThreshold            uint64
	IdleTimeout             time.Duration
	PauseTimeout            time.Duration
	MaxValActivePausedCount uint64
}

// ABv2Snapshot holds the result of ReadABv2Snapshot.
type ABv2Snapshot struct {
	Nodes valset.NodeMap
	ABv2TransitionParam

	SuspendedValidators []common.Address
}

func (s *ABv2Snapshot) TransitionParam() ABv2TransitionParam {
	if s == nil {
		return ABv2TransitionParam{}
	}
	return s.ABv2TransitionParam
}

func NewNodeMapFromABv2(profiles []multicall.Profile, stakingAmounts []*big.Int) (valset.NodeMap, error) {
	if len(profiles) != len(stakingAmounts) {
		return nil, fmt.Errorf("profile/staking amount length mismatch: profiles=%d stakingAmounts=%d", len(profiles), len(stakingAmounts))
	}

	nodes := make(valset.NodeMap)
	for i, p := range profiles {
		nodeState := valset.NodeState(p.State)
		node := &valset.Node{
			State:         nodeState,
			StakingAmount: new(big.Int).Div(stakingAmounts[i], big.NewInt(params.KAIA)).Uint64(),
		}
		switch nodeState {
		case valset.ValReady, valset.ValInactive:
			if p.TimeoutAt.Sign() > 0 {
				node.IdleTimeout = time.Unix(p.TimeoutAt.Int64(), 0)
			}
		case valset.ValPaused:
			if p.TimeoutAt.Sign() > 0 {
				node.PausedTimeout = time.Unix(p.TimeoutAt.Int64(), 0)
			}
		}
		nodes[p.NodeId] = node
	}
	return nodes, nil
}

// ReadABv2Snapshot reads all node states, timeouts, max counts, and thresholds from ABv2 in a single MultiCall.
func ReadABv2Snapshot(
	statedb *state.StateDB,
	chain backends.BlockChainForCaller,
	header *types.Header,
) (*ABv2Snapshot, error) {
	caller, err := NewMultiCallContractCaller(statedb, chain, header)
	if err != nil {
		return nil, err
	}
	opts := &bind.CallOpts{BlockNumber: header.Number}

	res, err := caller.MultiCallNodeStatesPermissionless(opts)
	if err != nil {
		return nil, err
	}

	nodes, err := NewNodeMapFromABv2(res.Profiles, res.StakingAmounts)
	if err != nil {
		return nil, err
	}

	return &ABv2Snapshot{
		Nodes: nodes,
		ABv2TransitionParam: ABv2TransitionParam{
			PauseTimeout:            time.Duration(res.PauseTimeout.Int64()) * time.Second,
			IdleTimeout:             time.Duration(res.IdleTimeout.Int64()) * time.Second,
			PfsThreshold:            res.PfsThreshold.Uint64(),
			CfsThreshold:            res.CfsThreshold.Uint64(),
			EpochVACount:            res.EpochVACount.Uint64(),
			MaxValActivePausedCount: res.MaxValActivePausedCount.Uint64(),
		},
		SuspendedValidators: res.SuspendedValidators,
	}, nil
}
