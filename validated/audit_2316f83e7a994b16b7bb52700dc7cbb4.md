### Title
Accrual arithmetic overflow permanently freezes an overgrown debt market - ([File: common/src/rates/scaling.rs](common/src/rates/scaling.rs))

### Summary
A permissionless caller can create a market state in which the scaled debt balance multiplied by its growing borrow index exceeds `i128::MAX`, making `scaled_to_original` panic during the next accrual. Because every market mutation invokes `global_sync` before repayment, withdrawal, liquidation-related settlement, or another explicit index update, the failed first conversion permanently blocks the market. [1](#0-0) [2](#0-1) 

### Finding Description
`accrue_step` starts by converting the stored scaled borrow and supply balances into original values using the currently stored indexes. [3](#0-2)  `scaled_to_original` performs checked fixed-point multiplication and therefore panics with `MathOverflow` when `scaled * index / RAY` exceeds `i128::MAX`. [1](#0-0) 

The borrow-index cap does not prevent this condition: `update_borrow_index` clamps the newly computed index only after the previous scaled debt value has already been converted, and index bounding does not bound the resulting debt value. [4](#0-3) [5](#0-4)  Consequently, a sufficiently large scaled-debt balance at sustained high utilization can reach the RAY-value domain limit before `borrow_index` reaches `MAX_BORROW_INDEX_RAY`. [6](#0-5) 

The user-reachable sequence is:

1. Call `Controller::supply(caller, 0, spoke_id, [(collateral_asset, collateral_amount)])` to create a borrowing account. [7](#0-6) 
2. Use the same address to create or control a supplying account and call `supply(caller, supplier_account_id, spoke_id, [(target_asset, principal)])`. [7](#0-6) 
3. Call `borrow(caller, borrower_account_id, [(target_asset, debt)], Some(caller))` to place the target market at sustained high utilization. [8](#0-7) 
4. After the index has grown enough, call `update_indexes(caller, [target_asset])`; `markets::update_indexes` authorizes the permissionless caller and delegates accrual to the pool. [9](#0-8) [10](#0-9) 
5. The pool’s `update_indexes` executes `ops::market::accrue`, which calls `interest::global_sync`; that calls `accrue_step`, whose `scaled_to_original` multiplication overflows and reverts before `cache.commit()` can advance `last_timestamp`. [11](#0-10) [12](#0-11) [13](#0-12) 

### Impact Explanation
Once the state crosses the representable-value boundary, `repay`, `withdraw`, `borrow`, `flash_loan`, liquidation-driven pool withdrawal, `recapitalize`, `claim_revenue`, and any later `update_indexes` call on that market all begin by loading a synced market and therefore hit the same accrual panic before any debt-reducing state change can execute. [14](#0-13) [15](#0-14) 

Repayment cannot rescue the market because `repay::accounting` calls `ops::load_leg`, which performs `global_sync` before `resolve_repay` can burn any debt. [16](#0-15)  Withdrawal likewise syncs through `ops::load_leg` before shares can be burned. [17](#0-16) 

This permanently freezes supplier funds in the affected `(hub_id, asset)` market and makes the market unable to operate; it can also freeze borrower collateral indirectly because liquidation and withdrawal paths touching the failed market cannot complete. [18](#0-17) 

### Likelihood Explanation
The attack requires a market with enough legitimate token liquidity for `borrowed * borrow_index` to exceed `i128::MAX`, high utilization maintained until the index grows sufficiently, and no intervening accrual that changes the state before the cliff. [19](#0-18)  The project’s own long-horizon test demonstrates a concrete configuration: an 18-decimal asset, one billion whole supplied tokens, approximately 98% utilization, and repeated yearly index updates eventually produce `MathOverflow` below the borrow-index cap. [20](#0-19) 

The capital and dormancy requirements make exploitation costly and market-dependent, but no privileged call, leaked key, oracle manipulation, or malformed external dependency is required; a single address can control both the supplying and borrowing accounts and trigger the failure through `update_indexes`. [21](#0-20) [9](#0-8) 

### Recommendation
Bound market scaled balances or accrued original values so `borrowed * borrow_index` and `supplied * supply_index` cannot cross the `i128` RAY-value domain. The check should happen before debt grows into the unrepresentable region—for example, enforce a conservative `scaled_balance <= i128::MAX / MAX_INDEX` entry limit, or implement a saturation/early-stop path that commits the index and timestamp when the market reaches a protocol-defined numeric ceiling. [22](#0-21) [4](#0-3) 

At minimum, allow a recovery path that can burn debt or otherwise reduce `borrowed` without first calling `scaled_to_original` on the already-overflowing total, because the current ordering makes repayment itself unreachable after the boundary is crossed. [16](#0-15) [23](#0-22)

```rust
/// `i128::MAX`, 170 times that. At the XLM curve's steep segment the index
/// grows past 170x in a few years, and the next accrual panics inside
/// `scaled_to_original`. Every verb accrues first, so the market freezes:
/// no repay, no withdraw, no liquidation. The index cap never engages.
#[test]
fn a_whale_market_at_sustained_high_utilization_hits_the_ray_value_ceiling_before_the_index_cap() {
    let mut t = LendingTest::new()
        .with_market(big("BIG18", 18, xlm_curve()))
        .with_market(col())
        .with_max_utilization_disabled_all_markets()
        .build();
    lift_caps(&t, "BIG18", 18);
    lift_caps(&t, "COL", 7);
    let principal = BILLION * 10i128.pow(18);
    t.supply_raw(BOB, "BIG18", principal);
    let debt = principal / 100 * 98;
    t.supply_raw(ALICE, "COL", BILLION * 10_000_000 * 3);
    t.borrow_raw(ALICE, "BIG18", debt);

    let mut years = 0u32;
    let failure = loop {
        years += 1;
        assert!(
            years <= 40,
            "no cliff within 40 years; the bound in docs/reference/formulas.md is wrong"
        );
        t.advance_time(YEAR_SECS);
        if let Err(e) = t.try_update_indexes_for(&["BIG18"]) {
            break e;
        }
    };

    assert_contract_error(failed, errors::MATH_OVERFLOW);

    // The market is frozen: exits and repayments accrue first and hit the same panic.

    assert_contract_error(t.try_repay(ALICE, "BIG18", 1.0), errors::MATH_OVERFLOW);
    std::println!(

        last.borrow_index as f64 / RAY as f64
```

```rust
pub(crate) fn global_sync(env: &Env, cache: &mut Cache) {
    if !cache.needs_accrual() {
        return;
    }

    let mut remaining = cache.elapsed_ms();
    while let Some(nonzero) = NonZeroU64::new(remaining) {
        let chunk = nonzero.get().min(MAX_COMPOUND_DELTA_MS);
        accrue_chunk(env, cache, chunk);
        remaining = remaining.saturating_sub(chunk);
    }

    cache.mark_accrued();
```

```rust
/// Accrues interest, resolves the repay amount into burned debt shares and
/// overpayment, burns the shares, and credits the net repay to cash without
/// transferring the overpayment refund. Panics if a positive net repay would
/// burn zero scaled shares.
pub(crate) fn accounting(env: &Env, action: &PoolAction) -> RepayOutcome {
    let (mut cache, position) = ops::load_leg(env, action);
    let amount = action.amount;

    let (burned, overpayment) = cache.resolve_repay(amount, position);
    let net_repay = amount
        .checked_sub(overpayment)
        .unwrap_or_else(|| panic_with_error!(env, GenericError::MathOverflow));
    assert_with_error!(
        env,
        net_repay == 0 || burned.raw() > 0,
        GenericError::RepayRoundsToZeroShares
    );

    let position = position.checked_sub(env, burned);
    cache.burn_debt(burned);
```

```rust
pub(crate) fn accounting(
    env: &Env,
    is_liquidation: bool,
    entry: &PoolWithdrawEntry,
) -> WithdrawOutcome {
    require_nonneg_amount(env, entry.protocol_fee);
    let (mut cache, position) = ops::load_leg(env, &entry.action);

    let (burned, gross_amount) = resolve_close_or_partial(&cache, entry.action.amount, position);
    // Burn first: `protocol_fee_shares` caps the fee mint at `i128::MAX - supplied`.
    let remaining = burn_position(env, &mut cache, position, burned);

        env,
        &mut cache,
        gross_amount,
        is_liquidation,
        entry.protocol_fee,
    );

    // net settlement: it burns no shares and moves no cash.
```
