### Title
Governing Node Can Redirect `governance.governingnode` to a Non-Council Address, Permanently Locking Single-Mode Governance — (File: `kaiax/gov/headergov/impl/header.go`)

---

### Summary

In `single` governance mode, `checkConsistency` validates a `governance.governingnode` vote by checking that the **current** governing node is in the council, but never checks that the **proposed new** governing node (`vote.Value()`) is a council member. The governing node can therefore ratify a vote pointing `governance.governingnode` at any arbitrary address — including one that is not in the council and can never become a block proposer. Once the epoch boundary passes and the ratification takes effect, no address can ever embed a valid governance vote in a block header again, permanently freezing all governance-controlled chain parameters (minting amount, unit price, reward ratios, etc.).

---

### Finding Description

`checkConsistency` in `kaiax/gov/headergov/impl/header.go` handles the `GovernanceGoverningNode` case as follows:

```go
case gov.GovernanceGoverningNode:
    params := h.GetParamSet(blockNum)
    if params.GovernanceMode != "single" {
        return nil
    }
    council, err := h.ValSet.GetCouncil(blockNum - 1)
    if err != nil {
        return err
    }
    if slices.Contains(council, params.GoverningNode) {  // ← checks CURRENT node
        return nil
    }
    return ErrGovNodeNotInValSetList
``` [1](#0-0) 

The check `slices.Contains(council, params.GoverningNode)` tests whether the **current** governing node is in the council — a fact already guaranteed by the earlier voter-in-council check in `VerifyVote`. It never tests whether `vote.Value().(common.Address)` (the **incoming** new governing node) is a council member. [2](#0-1) 

`VerifyVote` also enforces that the voter must be the block proposer, and proposers must come from `QualifiedValidators`, which is a subset of the council: [3](#0-2) 

Therefore, once `governance.governingnode` is ratified to a non-council address X:

1. X is not in `Council(N)` for any future N.
2. `getDemotedValidatorsIstanbul` protects the governing node from demotion only when it is already in the council — the protection is inert for X. [4](#0-3) 

3. X can never be selected as a block proposer.
4. X can never embed a `header.Vote` that passes `VerifyVote`.
5. No governance parameter can ever be changed again in `single` mode.

The valset README explicitly states the invariant that is broken:

> "If the governance mode is 'single', the governing node is unconditionally qualified to allow governance parameter change under any circumstances." [5](#0-4) 

This invariant only holds when the governing node is a council member. The missing check in `checkConsistency` allows it to be violated.

---

### Impact Explanation

Once the malicious `governance.governingnode` vote is ratified at an epoch boundary, the following governance-controlled values are permanently frozen:

- `reward.mintingamount` — new KAIA issuance per block
- `reward.ratio` / `reward.kip82ratio` — distribution split among CN/KGF/KIR
- `governance.unitprice` — minimum gas price
- `governance.govparamcontract` — on-chain governance parameter contract pointer
- `kip71.*` — base-fee bounds and denominator

This constitutes a **governance privilege escalation** that permanently corrupts protected chain state: the `governance.governingnode` storage value is set to an address that can never exercise governance rights, and no other address can recover them in `single` mode.

---

### Likelihood Explanation

The governing node is a single semi-trusted entity. It requires no collusion, no compromised external service, and no majority-validator cooperation. The governing node simply calls `governance_vote("governance.governingnode", <non-council-address>)` via the public `governance_vote` RPC, waits to propose a block within the epoch, and the vote is automatically ratified at the next epoch boundary. The attack is a single unilateral action by the governing node.

---

### Recommendation

In `checkConsistency`, for the `GovernanceGoverningNode` case, replace the check on the current governing node with a check on the **proposed** new governing node:

```go
case gov.GovernanceGoverningNode:
    params := h.GetParamSet(blockNum)
    if params.GovernanceMode != "single" {
        return nil
    }
    council, err := h.ValSet.GetCouncil(blockNum - 1)
    if err != nil {
        return err
    }
    newGoverningNode := vote.Value().(common.Address)   // ← check the NEW value
    if slices.Contains(council, newGoverningNode) {
        return nil
    }
    return ErrGovNodeNotInValSetList
```

This ensures the incoming governing node is always a council member and can therefore propose blocks and embed future governance votes.

---

### Proof of Concept

Preconditions: chain running in `single` governance mode, epoch = 604800 blocks (Mainnet/Kairos). Governing node is `GN` (a council member). Address `X` is any address not in the council.

1. `GN` calls `governance_vote("governance.governingnode", X)` via the `governance_vote` JSON-RPC API. [6](#0-5) 

2. The API check passes because `voter == gp.GoverningNode`.
3. `checkConsistency` is called with `vote.Name() == GovernanceGoverningNode`. It fetches `params.GoverningNode` (= `GN`), confirms `GN` is in the council, and returns `nil` — never inspecting `vote.Value()` (= `X`). [1](#0-0) 

4. When `GN` next proposes a block, `PrepareHeader` embeds the vote in `header.Vote`. [7](#0-6) 

5. At the next epoch block, `getExpectedGovernance` collects the vote and `VerifyGov` ratifies it, writing `{"governance.governingnode": X}` into `header.Governance`. [8](#0-7) 

6. From `(epoch+1)*epoch` onward, `GetParamSet` returns `GoverningNode = X`.
7. `X` is not in the council. `VerifyVote` rejects any block header whose `Vote` field is signed by `X` (voter not in council). No governance vote can ever be included in a block again.
8. All governance-controlled parameters — minting amount, reward ratios, unit price, base-fee bounds — are permanently frozen at their current values with no recovery path in `single` mode.

func (h *headerGovModule) VerifyGov(header *types.Header) error {
	// (1)
	if header.Number.Uint64()%h.epoch != 0 {
		if len(header.Governance) > 0 {
			logger.Error("governance is not allowed in non-epoch block", "num", header.Number.Uint64())
			return ErrGovInNonEpochBlock
		} else {
			return nil
		}
	}

	// (2), (3)
	expected := h.getExpectedGovernance(header.Number.Uint64())
	if len(header.Governance) == 0 {
		if len(expected.Items()) != 0 {
			return ErrGovVerification
		}

		return nil
	}

	// (4)
	var gb headergov.GovBytes = header.Governance
	actual, err := gb.ToGovData()
	if err != nil {
		logger.Error("DeserializeHeaderGov error", "num", header.Number.Uint64(), "governance", gb, "err", err)
		return err
	}

	// (5)
	if !reflect.DeepEqual(expected, actual) {
		logger.Error("Governance mismatch", "expected", expected, "actual", actual)
		return ErrGovVerification
	}

	return nil
}

func (api *headerGovAPI) Vote(name string, value any) (string, error) {
	var (
		voter     = api.h.nodeAddress
		nextBlock = api.h.Chain.CurrentBlock().NumberU64() + 1
		gp        = api.h.GetParamSet(nextBlock)
		gMode     = gp.GovernanceMode
	)

	if gMode == "single" && voter != gp.GoverningNode {
		return "", ErrVotePermissionDenied
	}

	vote := headergov.NewVoteData(voter, name, value)
	if vote == nil {
		return "", ErrInvalidKeyValue
	}

	if gov.DeprecatedAt(vote.Name(), api.h.ChainConfig.Rules(new(big.Int).SetUint64(nextBlock))) {
		return "", ErrDeprecatedVote
	}

	err := api.h.checkConsistency(nextBlock, vote)
	if err != nil {
		return "", err
	}

	// TODO-kaiax: add removevalidator vote check

	api.h.PushMyVotes(vote)
	return "(kaiax) Your vote is prepared. It will be put into the block header or applied when your node generates a block as a proposer. Note that your vote may be duplicate.", nil
