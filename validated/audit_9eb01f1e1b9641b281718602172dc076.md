The reported CVE (BIT-golang-2021-29923 / CVE-2021-29923) is specific to Go's standard library `net.ParseIP`/`net.ParseCIDR`, which historically parsed IP address octets with leading zeros as octal, causing SSRF/access-control bypass in Go programs that used IP-based ACLs. This is a language/runtime-specific parsing defect in Go's stdlib.

The Polkadot SDK is a Rust codebase. Its IP-parsing code paths use Rust's `std::net::IpAddr::from_str` (e.g., in `get_proxy_ip` for extracting client IPs from `Forwarded`/`X-Forwarded-For`/`X-Real-Ip` headers) and the `multiaddr` crate's address parsers (e.g., `parse_str_addr`, `url_to_multiaddr`) rather than any Go-derived IP-parsing logic [1](#0-0) . Rust's standard library IPv4/IPv6 parser is strict about numeric octet syntax and does not exhibit the "extraneous leading zero → octal reinterpretation" behavior that the Go bug describes; it treats such malformed octets as parse errors rather than silently reinterpreting them, so the underlying misinterpretation root cause does not carry over.

I found no Rust component in this repository that reimplements or wraps Go's `net.ParseIP`/`ParseCIDR` semantics, nor any custom octet-parsing logic that mimics octal-leading-zero interpretation for IP-based access control (e.g., `rate-limit-whitelisted-ips` in `substrate/client/cli/src/params/rpc_params.rs` relies on the `ipnetwork`/std parsers) [2](#0-1) . Without a Go `net` package dependency or an equivalent custom IP-octet parser exhibiting the same flaw, there is no demonstrable analog to this CVE in the Polkadot SDK's production code.

pub(crate) fn get_proxy_ip<B>(req: &http::Request<B>) -> Option<IpAddr> {
	if let Some(ip) = req
		.headers()
		.get(&FORWARDED)
		.and_then(|v| v.to_str().ok())
		.and_then(|v| ForwardedHeaderValue::from_forwarded(v).ok())
		.and_then(|v| v.remotest_forwarded_for_ip())
	{
		return Some(ip);
	}

	if let Some(ip) = req
		.headers()
		.get(&X_FORWARDED_FOR)
		.and_then(|v| v.to_str().ok())
		.and_then(|v| ForwardedHeaderValue::from_x_forwarded_for(v).ok())
		.and_then(|v| v.remotest_forwarded_for_ip())
	{
		return Some(ip);
	}

	if let Some(ip) = req
		.headers()
		.get(&X_REAL_IP)
		.and_then(|v| v.to_str().ok())
		.and_then(|v| IpAddr::from_str(v).ok())
	{
		return Some(ip);
	}

	None
}
