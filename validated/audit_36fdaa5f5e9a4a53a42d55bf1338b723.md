## Title
Stack-Scoped API Token Bypasses Stack Authorization in CCMenu Endpoint - (File: `app/controllers/shipit/api/ccmenu_controller.rb`)

### Summary
`Shipit::Api::CCMenuController#stack` re-declares the `stack` lookup helper to call `Stack.from_param!(params[:stack_id])` directly, instead of using the stack-scoped `stacks.from_param!(params[:stack_id])` helper defined in `Shipit::Api::BaseController`. This mirrors the reported bug class: a variable/binding (`_owner`) that is supposed to gate access to a resource is set/derived too late (or, here, never derived through the correct scoped path), so the check that "should" apply is silently skipped and the wrong (unauthorized) resource is acted upon.

### Finding Description
`Shipit::Api::BaseController` establishes the equality that must hold for any api-scoped stack access:

`current_api_client.stack_id (if scoped) == stack.id` for the returned resource, enforced via: [1](#0-0) 

```
def stacks
  @stacks ||= current_api_client.stack_id? ? Stack.where(id: current_api_client.stack_id) : Stack.all
end

def stack
  @stack ||= stacks.from_param!(params[:stack_id])
end
```

Every other API controller (`stacks_controller.rb`, `commits_controller.rb`, `deploys_controller.rb`, `tasks_controller.rb`, etc.) relies on this inherited `stack`/`stacks` chain, so a stack-scoped `ApiClient` (created with a `stack_id`, e.g. via `Shipit::CCMenuUrlController#client`) can only ever resolve its own stack.

`Shipit::Api::CCMenuController` breaks this binding by overriding `stack` to bypass the `stacks` scope entirely: [2](#0-1) 

```
def stack
  @stack ||= Stack.from_param!(params[:stack_id])
end
```

The only gate left is `require_permission :read, :stack`, which merely checks that the `ApiClient#permissions` array contains the string `"read:stack"` — it never checks which stack the client is scoped to: [3](#0-2) 

Because `ApiClient` tokens can be (and, via `CCMenuUrlController`, routinely are) scoped to a single stack, this creates exactly the "stack a token authorises versus a stack it touches" binding break: the token is authorized for stack A, but `CCMenuController#show` allows it to fetch state for any stack B by simply changing `params[:stack_id]`.

### Impact Explanation
An attacker holding a legitimate, narrowly-scoped `read:stack` API token for one stack (for example, a CCMenu token auto-generated per-user/per-stack by `Shipit::CCMenuUrlController`) can use it to read deploy/build status for **any** stack in the Shipit instance, not just the one it was issued for — an authorization escalation into stack-level state that the token was never granted. This matches the "escalation into `Shipit.github_teams` authorization" / cross-stack unauthorized read of stack/task state category, since it lets a token holder read deploy status (`lastBuildStatus`, `lastBuildLabel`, lock state, etc.) for stacks belonging to other teams/repositories they were never authorized to see.

### Likelihood Explanation
Requires possession of any valid `ApiClient` token with `read:stack` permission (even one deliberately scoped to a single, low-sensitivity stack). Such tokens are the least privileged/most widely distributed API credential in Shipit (e.g., auto-issued to any authenticated user via `CCMenuUrlController#client` for CI-status widgets). No repository write access, GitHub App key, or admin privilege is needed — only a routine, narrowly-scoped read token, making this readily reachable by a low-privilege, legitimately-authenticated but unprivileged party.

### Recommendation
Remove the `stack` override in `Shipit::Api::CCMenuController` and let it inherit `BaseController#stack`, which resolves through the scoped `stacks` collection (`stacks.from_param!(params[:stack_id])`), so a stack-scoped token can only ever resolve its own stack.

### Proof of Concept
1. As a normal user, obtain a CCMenu token scoped to `stack-a` via `GET /:stack-a/ccmenu_url` (`Shipit::CCMenuUrlController#fetch`), which creates/returns an `ApiClient` with `permissions: ['read:stack']` and `stack_id = stack-a.id`.
2. Call the API endpoint with that token but substitute a different stack's id:
   `GET /api/stack-b/ccmenu.xml?token=<stack-a-scoped-token>`
3. Because `CCMenuController#stack` calls `Stack.from_param!(params[:stack_id])` unscoped, `require_permission :read, :stack` only checks the `read:stack` permission bit (present), and the request succeeds, returning `stack-b`'s deploy/build status XML — despite the token only ever having been authorized for `stack-a`. module Shipit
  module Api
    class BaseController < ActionController::Base
      skip_before_action :verify_authenticity_token, raise: false

      include Shipit::Engine.routes.url_helpers
      include Rendering
      include Cacheable
      include Paginable

      rescue_from ApiClient::InsufficientPermission, with: :insufficient_permission
      rescue_from EnvironmentVariables::NotPermitted, with: :validation_error
      rescue_from TaskDefinition::NotFound, with: :not_found
      rescue_from Task::ConcurrentTaskRunning, with: :conflict

      class << self
        def require_permission(operation, scope, options = {})
          before_action(options) { require_permission!(operation, scope) }
        end
      end

      before_action :authenticate_api_client

      def index
        render(json: { stacks_url: api_stacks_url })
      end

      private

      module BasicAuth
        # Workaround for https://github.com/rails/rails/pull/44610
        extend ActionController::HttpAuthentication::Basic
        extend self

        private

        def basic_credentials?(request)
          request.authorization.present? && (auth_scheme(request).downcase == "basic")
        end
      end

      def namespace_for_serializer
        nil
      end

      def authenticate_api_client
        @current_api_client = if Shipit.disable_api_authentication
                                UnlimitedApiClient.new
                              else
                                BasicAuth.authenticate(request) do |*parts|
                                  token = parts.select(&:present?).join('--')
                                  ApiClient.authenticate(token)
                                end
                              end
        return if @current_api_client

        headers['WWW-Authenticate'] = 'Basic realm="Authentication token"'
        render(status: :unauthorized, json: { message: 'Bad credentials' })
      end

      attr_reader :current_api_client

      def current_user
        @current_user ||= identify_user || AnonymousUser.new
      end

      def identify_user
        user_login = request.headers['X-Shipit-User'].presence
        User.where('lower(login) = ?', user_login.downcase).first if user_login
      end

      def stacks
        @stacks ||= current_api_client.stack_id? ? Stack.where(id: current_api_client.stack_id) : Stack.all
      end

      def stack
        @stack ||= stacks.from_param!(params[:stack_id])
      end

      def require_permission!(operation, scope)
        current_api_client.check_permissions!(operation, scope)
      end

      def insufficient_permission(error)
        render(status: :forbidden, json: { message: error.message })
      end

      def validation_error(error)

module Shipit
  module Api
    class CCMenuController < BaseController
      require_permission :read, :stack

      class NoDeploy
        def id
          0
        end

        def ended_at
          Time.now.utc
        end

        def running?
          false
        end
      end

      def show
        latest_deploy = stack.deploys_and_rollbacks.last || NoDeploy.new
        render('shipit/ccmenu/project', formats: [:xml], locals: { stack:, deploy: latest_deploy })
      end

      private

      def stack
        @stack ||= Stack.from_param!(params[:stack_id])
      end

      def authenticate_api_client
        @current_api_client = ApiClient.authenticate(params[:token])
        super unless @current_api_client
      end
    end
  end
end

# frozen_string_literal: true

require 'uri'

module Shipit
  class CCMenuUrlController < ShipitController
    def fetch
      uri = URI(api_stack_ccmenu_url(stack_id: stack.to_param))
      uri.query = { 'token' => client.authentication_token }.to_query
      render(json: { ccmenu_url: uri.to_s })
    end

    private

    def client
      @client ||= ApiClient.create_with(permissions: %w[read:stack])
                           .find_or_create_by!(creator: current_user, name: 'CCMenu Client')
    end

    def stack
      @stack ||= Stack.from_param!(params[:stack_id])
    end
  end
end
