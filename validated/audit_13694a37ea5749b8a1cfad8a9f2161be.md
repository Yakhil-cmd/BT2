### Title
Gasless SwapTx Deadline and Slippage Constraints Not Re-Validated at Block-Building Time, Causing Proposer KAIA Loss — (`kaiax/gasless/impl/builder.go`)

---

### Summary

The `GaslessModule` (KIP-247) validates a user's `deadline` and exchange-rate (`minAmountOut`) constraints only at **tx-pool admission** time via `checkBalanceForSwap()`. At **block-building** time, `ExtractTxBundles()` calls only `IsExecutable()` / `VerifyExecutable()`, which re-checks nonce ordering and repay-amount arithmetic but never re-checks the deadline or slippage bounds. The proposer's LendTx (a real KAIA transfer to the user) is unconditionally prepended to the bundle and executed first. If the SwapTx then reverts on-chain because the deadline has expired or the exchange rate has moved past `minAmountOut`, the proposer permanently loses the lent KAIA with no repayment.

---

### Finding Description

**Pool-admission checks (run once, stale by block time):**

`checkBalanceForSwap()` enforces:
- `minAmountOut >= amountRepay` (always)
- `amountIn >= router.GetAmountIn(minAmountOut)` (only if `BalanceCheckLevel >= 2`)
- token balance / allowance (only if `BalanceCheckLevel >= 1`)
- `deadline >= currentBlock.Time()` (always) [1](#0-0) 

**Block-building checks (run at inclusion, incomplete):**

`ExtractTxBundles()` calls `IsExecutable()` → `VerifyExecutable()`, which checks only nonce ordering (SP3) and `amountRepay == repayAmount(...)` (SP4). It does **not** re-check `deadline`, `minAmountOut`, or the live exchange rate. [2](#0-1) [3](#0-2) 

**LendTx is generated and prepended unconditionally:**

```go
bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
```

The lend transaction transfers `ApproveTx.Fee() + SwapTx.Fee()` of KAIA from the proposer to the user **before** the swap executes. [4](#0-3) [5](#0-4) 

**`BalanceCheckLevel` is operator-configurable and can be set to 0:** [6](#0-5) 

Even at the default `BalanceCheckLevelAll`, the checks are only performed at admission, not at inclusion.

---

### Impact Explanation

When a gasless bundle is included in a block:

1. **LendTx executes**: proposer sends `lendAmount` KAIA to the user. This state change is final.
2. **SwapTx reverts** (deadline expired, or `minAmountOut` not met due to price movement): the EVM reverts the swap, so no repayment occurs.
3. **Net result**: the proposer (CN) loses `lendAmount = ApproveTx.Fee() + SwapTx.Fee()` KAIA. The user retains the lent KAIA.

This is an unauthorized transfer of KAIA from the proposer's account. With many such transactions (e.g., a user deliberately submitting SwapTxs with very short deadlines or near-boundary `minAmountOut` values), the cumulative loss is proportional to the gas fees of all reverted bundles.

---

### Likelihood Explanation

**Natural occurrence**: Any SwapTx that sits in the pending pool for longer than its `deadline` will trigger this. Given the `PendingTimeout = 10 * time.Second` and `QueueTimeout = 10 * time.Second` timeouts in the module, a tx can remain pending for up to 10 seconds before being dropped — but the block proposer may include it before the drop fires. [7](#0-6) 

**Deliberate exploitation**: An unprivileged user can:
1. Submit a SwapTx with `deadline = currentTime + 1 block` and `minAmountOut` set near the current exchange rate.
2. Wait one block (or sandwich with a price-moving trade in the same block).
3. The proposer's `ExtractTxBundles` includes the bundle; LendTx executes; SwapTx reverts.

No privileged access is required. The trigger is a valid, well-formed SwapTx.

---

### Recommendation

Re-validate the deadline and slippage constraints inside `ExtractTxBundles()` before generating the LendTx, using the pending block's timestamp and the live exchange rate from the router contract. Specifically, call `checkBalanceForSwap()` (or an equivalent) at bundle-extraction time, and skip the bundle if any constraint fails — analogous to the "hold order" fix applied in the Bracket.fi case.

---

### Proof of Concept

```
Block N-1: exchange rate = 1 Token → 1000 WKAIA

User submits SwapTx:
  amountIn     = 1e18 Token
  minAmountOut = 999 WKAIA   (just above amountRepay)
  amountRepay  = 998 WKAIA
  deadline     = block N timestamp + 1 second

Pool admission (block N-1):
  checkBalanceForSwap passes:
    minAmountOut (999) >= amountRepay (998) ✓
    amountIn >= router.GetAmountIn(999)     ✓  (rate is 1:1000)
    deadline >= currentTime                 ✓

Block N is built 2 seconds later (deadline expired):
  ExtractTxBundles calls IsExecutable → VerifyExecutable:
    nonce check                             ✓
    amountRepay == repayAmount(...)         ✓
    deadline check                          NOT PERFORMED
  Bundle is included.

Execution order in block N:
  1. LendTx: proposer → user  998 WKAIA  (KAIA leaves proposer, FINAL)
  2. SwapTx: swapForGas() reverts (deadline expired)
     → no repayment

Result: proposer loses 998 WKAIA; user keeps it.
``` [8](#0-7) [9](#0-8) [10](#0-9)

func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil

func lendAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	r := new(big.Int)

	// R2 = ApproveTx.Fee() if exists
	if approveTxOrNil != nil {
		r.Add(r, approveTxOrNil.Fee())
	}

	// R3 = SwapTx.Fee()
	r.Add(r, swapTx.Fee())

	// LendAmount = R2 + R3
	return r

type GaslessConfig struct {
	// all tokens are allowed if AllowedTokens is nil while all are disallowed if empty slice
	AllowedTokens         []common.Address `toml:",omitempty"`
	Disable               bool
	MaxBundleTxsInPending uint
	MaxBundleTxsInQueue   uint
	BalanceCheckLevel     int
}

func DefaultGaslessConfig() *GaslessConfig {
	return &GaslessConfig{
		AllowedTokens:         nil,
		Disable:               false,
		MaxBundleTxsInPending: 100,
		MaxBundleTxsInQueue:   200,
		BalanceCheckLevel:     BalanceCheckLevelAll,
	}
}

func (cfg *GaslessConfig) ShouldCheckToken() bool {
	return cfg.BalanceCheckLevel >= BalanceCheckLevelTokenBalanceAndAllowance
}

func (cfg *GaslessConfig) ShouldCheckSwapAmount() bool {
	return cfg.BalanceCheckLevel >= BalanceCheckLevelSwapAmount
}

func (cfg *GaslessConfig) ShouldCheckSenderCode() bool {
	return cfg.BalanceCheckLevel >= BalanceCheckLevelAll
}
