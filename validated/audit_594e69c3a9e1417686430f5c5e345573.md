The Traefik report concerns HTTP reverse-proxy header trust bypassing an authentication middleware — a pattern tied to `ForwardAuth`/`X-Forwarded-Prefix` semantics that has no structural analog in the Polkadot SDK's runtime dispatch, XCM, or FRAME origin model. The closest surface-level match in this codebase is the RPC server's proxy-header handling in `get_proxy_ip` [1](#0-0)  gated by the `rpc_rate_limit_trust_proxy_headers` flag [2](#0-1) , used only to decide whether to disable RPC rate-limiting for a connection [3](#0-2) . This is:

- Config-only and opt-in (defaults to `false`, must be explicitly enabled by a node operator) [4](#0-3) .
- Not an authentication or authorization boundary — it only affects rate-limit throttling, not runtime dispatch, XCM origin resolution, or any consensus-relevant state transition.
- Not reachable by an unprivileged external attacker as a "real user entry" (signed extrinsic, contract call, XCM execute/send) — it's a node-operator RPC infrastructure decision, not chain state logic.

There is no `ForwardAuth`-like middleware, no `X-Forwarded-Prefix`-style trust-boundary header reused across chained processing steps, and no authorization decision in FRAME/XCM/Cumulus that inherits an attacker-controlled forwarded-header value. The bug class (header-based auth bypass via improperly-rebuilt trust boundary) does not translate into a demonstrable Critical/High-impact analog (theft, unbacked issuance, unauthorized dispatch, irreversible freezing, or deterministic chain failure) in this codebase.

/// Extracts the IP addr from the HTTP request.
///
/// It is extracted in the following order:
/// 1. `Forwarded` header.
/// 2. `X-Forwarded-For` header.
/// 3. `X-Real-Ip`.
pub(crate) fn get_proxy_ip<B>(req: &http::Request<B>) -> Option<IpAddr> {
	if let Some(ip) = req
		.headers()
		.get(&FORWARDED)
		.and_then(|v| v.to_str().ok())
		.and_then(|v| ForwardedHeaderValue::from_forwarded(v).ok())
		.and_then(|v| v.remotest_forwarded_for_ip())
	{
		return Some(ip);
	}

	if let Some(ip) = req
		.headers()
		.get(&X_FORWARDED_FOR)
		.and_then(|v| v.to_str().ok())
		.and_then(|v| ForwardedHeaderValue::from_x_forwarded_for(v).ok())
		.and_then(|v| v.remotest_forwarded_for_ip())
	{
		return Some(ip);
	}

	if let Some(ip) = req
		.headers()
		.get(&X_REAL_IP)
		.and_then(|v| v.to_str().ok())
		.and_then(|v| IpAddr::from_str(v).ok())
	{
		return Some(ip);
	}

	None
}
