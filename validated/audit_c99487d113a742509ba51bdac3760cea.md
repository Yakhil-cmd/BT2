### Title
Unchecked error from `os.RemoveAll` when disabling sparse-checkout can silently leave a stale sparse-checkout filter active, causing partial content to be published - (File: main.go)

### Summary
The `configureWorktree` function in `main.go` unsets sparse-checkout by deleting the sparse-checkout config file with `os.RemoveAll(gitSparseConfigPath)`, but the returned error is never checked, mirroring the "unchecked error from `Clear`" bug class described in the Allora M-2 report (an operation whose failure is silently ignored, letting a stale/dirty state persist and be acted upon as if it had succeeded). [1](#0-0) 

### Finding Description
`configureWorktree` toggles sparse-checkout on/off for a worktree based on `git.sparseFile`. When sparse-checkout should be disabled (`git.sparseFile == ""`), the code calls:

```go
if git.sparseFile == "" {
    os.RemoveAll(gitSparseConfigPath)
} else {
    ...
}
``` [2](#0-1) 

The return value of `os.RemoveAll` (an `error`) is discarded entirely — unlike almost every other filesystem/git operation in this function and file, which check and propagate errors (see the surrounding `os.WriteFile`, `os.Mkdir`, `os.Create`, `io.Copy`, and `git.Run` calls in the same function, all of which return on error) [3](#0-2) . If `RemoveAll` fails (e.g. permission problems, a busy/locked file, or a partial filesystem failure), the stale `sparse-checkout` file under `.git/worktrees/<hash>/info/sparse-checkout` remains on disk with its old (previously configured) sparse patterns, while `core.sparseCheckout` may still be enabled from a prior `git sparse-checkout init` call made in an earlier sync cycle (see the `else` branch calling `sparse-checkout init`) [4](#0-3) . Execution continues unconditionally to the subsequent `git reset --hard <hash> --` call that checks out the worktree [5](#0-4) , which will now only materialize the old sparse subset of files rather than the full tree the operator now expects, exactly the "operation continues without properly resetting state" pattern flagged in the source report.

### Impact Explanation
Because the worktree is subsequently published via `publishSymlink` [6](#0-5)  and `SyncRepo` reports `changed=true`/success with no error surfaced [7](#0-6) , consumers relying on the published symlink receive an incomplete checkout (missing files outside the stale sparse pattern) while git-sync's logs and exit status indicate a successful sync. This matches the "publishing wrong or partial content" impact category, and it happens silently — there is no log line indicating the cleanup failed, unlike other error paths in this file that explicitly call `git.log.Error(...)`.

### Likelihood Explanation
This requires only a normal (non-malicious) operator workflow: running git-sync with `--git-sync-sparse-checkout-file` set, then reconfiguring/restarting it without that flag (or clearing it), combined with a transient filesystem failure that makes `os.RemoveAll` fail (e.g. permission-denied on the mounted `--root` volume, a file held open, or an I/O error). No attacker-controlled ref content is needed to trigger the code path — the sparse-checkout toggle itself is reachable on every sync when `sparseFile` changes state, so the missing error check is a latent correctness bug affecting normal reconfiguration rather than a targeted exploit.

### Recommendation
Check and propagate the error from `os.RemoveAll(gitSparseConfigPath)`, and additionally run `git sparse-checkout disable` (or explicitly unset `core.sparseCheckout`) so that stale sparse patterns cannot silently persist even if the file removal itself is skipped or fails:

```go
if git.sparseFile == "" {
    if err := os.RemoveAll(gitSparseConfigPath); err != nil {
        return fmt.Errorf("error removing sparse-checkout config: %w", err)
    }
}
```

### Proof of Concept
1. Start git-sync with `--git-sync-sparse-checkout-file=/patterns` so `configureWorktree` writes `gitSparseConfigPath` and runs `sparse-checkout init` [4](#0-3) , restricting the checked-out tree.
2. Restart/reconfigure git-sync without `--git-sync-sparse-checkout-file` (`git.sparseFile == ""`), while making the `.git/worktrees/<hash>/info` directory temporarily non-writable (e.g., `chmod 500` on that directory or an underlying read-only bind mount race) so `os.RemoveAll(gitSparseConfigPath)` fails.
3. Because the error is discarded, `configureWorktree` proceeds to `git reset --hard <hash> --` [5](#0-4)  and returns `nil`; `SyncRepo` publishes the symlink and logs "updated successfully" [8](#0-7) , even though the worktree still only contains the previously sparse-checked-out subset of files rather than the full repository content requested by the new configuration.

// publishSymlink atomically sets link to point at the specified target.  If the
// link existed, this returns the previous target.
func (git *repoSync) publishSymlink(worktree worktree) error {
	targetPath := worktree.Path()
	linkDir, linkFile := git.link.Split()

	// Make sure the link directory exists.
	if err := os.MkdirAll(linkDir.String(), defaultDirMode); err != nil {
		return fmt.Errorf("error making symlink dir: %w", err)
	}

	// linkDir is absolute, so we need to change it to a relative path.  This is
	// so it can be volume-mounted at another path and the symlink still works.
	targetRelative, err := filepath.Rel(linkDir.String(), targetPath.String())
	if err != nil {
		return fmt.Errorf("error converting to relative path: %w", err)
	}

	const tmplink = "tmp-link"
	git.log.V(2).Info("creating tmp symlink", "dir", linkDir, "link", tmplink, "target", targetRelative)
	if err := os.Symlink(targetRelative, filepath.Join(linkDir.String(), tmplink)); err != nil {
		return fmt.Errorf("error creating symlink: %w", err)
	}

	git.log.V(2).Info("renaming symlink", "root", linkDir, "oldName", tmplink, "newName", linkFile)
	if err := os.Rename(filepath.Join(linkDir.String(), tmplink), git.link.String()); err != nil {
		return fmt.Errorf("error replacing symlink: %w", err)
	}

	return nil
}

// configureWorktree applies some configuration (e.g. sparse checkout) to
// the specified worktree and checks out the specified hash and submodules.
func (git *repoSync) configureWorktree(ctx context.Context, worktree worktree) error {
	hash := worktree.Hash()

	// The .git file in the worktree directory holds a reference to
	// /git/.git/worktrees/<worktree-dir-name>. Replace it with a reference
	// using relative paths, so that other containers can use a different volume
	// mount name.
	var rootDotGit string
	if rel, err := filepath.Rel(worktree.Path().String(), git.root.String()); err != nil {
		return err
	} else {
		rootDotGit = filepath.Join(rel, ".git")
	}
	gitDirRef := []byte("gitdir: " + filepath.Join(rootDotGit, "worktrees", hash) + "\n")
	if err := os.WriteFile(worktree.Path().Join(".git").String(), gitDirRef, 0644); err != nil {
		return err
	}

	// If sparse checkout is requested, configure git for it, otherwise
	// unconfigure it.
	gitInfoPath := filepath.Join(git.root.String(), ".git/worktrees", hash, "info")
	gitSparseConfigPath := filepath.Join(gitInfoPath, "sparse-checkout")
	if git.sparseFile == "" {
		os.RemoveAll(gitSparseConfigPath)
	} else {
		// This is required due to the undocumented behavior outlined here:
		// https://public-inbox.org/git/CAPig+cSP0UiEBXSCi7Ua099eOdpMk8R=JtAjPuUavRF4z0R0Vg@mail.gmail.com/t/
		git.log.V(1).Info("configuring worktree sparse checkout")
		checkoutFile := git.sparseFile

		source, err := os.Open(checkoutFile)
		if err != nil {
			return err
		}
		defer source.Close()

		if _, err := os.Stat(gitInfoPath); os.IsNotExist(err) {
			err := os.Mkdir(gitInfoPath, defaultDirMode)
			if err != nil {
				return err
			}
		}

		destination, err := os.Create(gitSparseConfigPath)
		if err != nil {
			return err
		}
		defer destination.Close()

		_, err = io.Copy(destination, source)
		if err != nil {
			return err
		}

		args := []string{"sparse-checkout", "init"}
		if _, _, err = git.Run(ctx, worktree.Path(), args...); err != nil {
			return err
		}
	}

	// Reset the worktree's working copy to the specific ref.
	git.log.V(1).Info("setting worktree HEAD", "hash", hash)
	if _, _, err := git.Run(ctx, worktree.Path(), "reset", "--hard", hash, "--"); err != nil {
		return err
	}
