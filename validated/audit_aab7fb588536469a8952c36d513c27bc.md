### Title
Silent Swallowing of `PostInsertBlock` Errors in Miner Path Causes Stale Validator-Set / Governance State — (`File: work/worker.go`)

### Summary

In `work/worker.go`, the miner's `handleFinalizedBlock` loop calls every registered `ExecutionModule.PostInsertBlock` but **discards the returned error**, only logging it. The identical loop in `blockchain/blockchain.go`'s `insertChain` (the sync path) correctly propagates the error and aborts chain insertion. This asymmetry means that when a locally-mined block triggers a `PostInsertBlock` failure, the block is durably written to the chain while the privileged module state (validator council, governance parameter cache, staking info) is silently left stale.

### Finding Description

**Vulnerable code — miner path (`work/worker.go` lines 553–558):**

```go
// Invoke ExecutionModules after executing a block
for _, module := range self.executionModules {
    if err := module.PostInsertBlock(block); err != nil {
        logger.Error("Failed to call PostInsertBlock", "err", err)
        // error is dropped; execution continues
    }
}
``` [1](#0-0) 

**Correct code — sync path (`blockchain/blockchain.go` lines 2209–2214):**

```go
for _, module := range bc.executionModules {
    if err := module.PostInsertBlock(block); err != nil {
        return i, events, coalescedLogs, err   // error propagated
    }
}
``` [2](#0-1) 

The execution modules registered on the worker include `kaiax/valset` (`ValsetModule.PostInsertBlock`), `kaiax/gov` (`GovModule.PostInsertBlock` → `headerGovModule.PostInsertBlock`), and `kaiax/staking` (`StakingModule.PostInsertBlock`). Each of these writes protected persistent state:

- `valset.postInsertBlockPermissioned` writes the updated council (validator set) to the DB after applying any `AddValidator`/`RemoveValidator` vote carried in the block header. [3](#0-2) 
- `valset.postInsertBlockPermissionless` calls `v.Chain.StateAt` and `getTransitionResult` to cache the next-block validator transition from AddressBookV2. [4](#0-3) 
- `headergov.PostInsertBlock` records governance votes and ratified governance data into the in-memory cache and DB. [5](#0-4) 
- `staking.PostInsertBlock` persists the staking info for the new block. [6](#0-5) 

### Impact Explanation

If `PostInsertBlock` fails for a locally-mined block N:

1. **Stale validator council**: `GetCouncil(N)` and `GetQualifiedValidators(N)` return the pre-vote council. The proposer node's `SubmitTransactions` uses `GetQualifiedValidators` to decide whether to produce the next block. [7](#0-6)  A stale council means the node may incorrectly include or exclude itself, causing it to skip a block it should propose or attempt one it should not — **consensus divergence on an honest node**.

2. **Stale governance parameters**: `GetParamSet` returns outdated values. Downstream consumers include reward distribution (`FinalizeState` reads `ProposerPolicy`, `MintingAmount`, `Ratio`) and block-seal verification (`CommitteeSize`). [8](#0-7)  A stale `MintingAmount` or `Ratio` causes the proposer to distribute incorrect reward amounts — **wrong reward distribution affecting KAIA balances**.

3. **Stale staking info**: Reward addresses and staking amounts used in `FinalizeState` to set `header.Rewardbase` and distribute staker rewards are computed from stale data. [9](#0-8) 

The block is already durably committed to the DB before `PostInsertBlock` is called (via `WriteBlockWithState`), so the on-chain state and the module's persistent/in-memory state diverge permanently until a restart or rewind.

### Likelihood Explanation

`PostInsertBlock` can fail in the miner path through:

- `valset.postInsertBlockPermissionless`: `v.Chain.StateAt(header.Root)` or `getTransitionResult` (which calls AddressBookV2 via EVM) can return an error if the contract call reverts or the state trie is temporarily unavailable. [4](#0-3) 
- `headergov.PostInsertBlock`: `vb.ToVoteData()` returns `ErrInvalidVoteData` / `ErrInvalidRlp` if the vote bytes are malformed. Although `VerifyVote` runs before insertion, the miner path writes the vote bytes itself via `PrepareHeader` — a bug there could produce bytes that pass `VerifyVote` but fail `ToVoteData` in a different code path. [10](#0-9) 

The divergence between the two call sites is the root cause; any transient or logic-triggered error in these modules silently corrupts the proposer node's protected state.

### Recommendation

Replace the silent-swallow pattern in `work/worker.go` with the same error-propagation pattern used in `blockchain/blockchain.go`:

```go
for _, module := range self.executionModules {
    if err := module.PostInsertBlock(block); err != nil {
        logger.Error("Failed to call PostInsertBlock", "err", err)
        // halt further processing; the node must resync or restart
        return
    }
}
```

Alternatively, if non-fatal modules exist, distinguish fatal (valset, gov, staking) from non-fatal (auction, randao) and only abort on fatal failures.

### Proof of Concept

1. Run a node with `istanbul.policy = 2` (WeightedRandom) and Permissionless fork enabled.
2. Arrange for `ValsetModule.postInsertBlockPermissionless` to return an error on the next locally-mined block (e.g., by temporarily making `getTransitionResult` fail via a mock or by corrupting the AddressBookV2 state).
3. Observe that `handleFinalizedBlock` logs the error but continues; the block is written to the chain.
4. Query `GetQualifiedValidators(N+1)` — it returns the stale set from before the failed `PostInsertBlock`.
5. The proposer node's next-block committee selection diverges from all peer nodes that correctly processed the block via `insertChain`.

func (v *ValsetModule) postInsertBlockPermissionless(block *types.Block) error {
	header := block.Header()
	nextNum := header.Number.Uint64() + 1
	parentStatedb, err := v.Chain.StateAt(header.Root)
	if err != nil {
		return err
	}
	_, err = v.getTransitionResult(nextNum, parentStatedb) // to cache the transition result
	return err
}

func (h *headerGovModule) PostInsertBlock(b *types.Block) error {
	if len(b.Header().Vote) > 0 {
		var vb headergov.VoteBytes = b.Header().Vote
		vote, err := vb.ToVoteData()
		if err != nil {
			logger.Error("ToVoteData error", "vote", vb, "err", err)
			return err
		}
		err = h.HandleVote(b.NumberU64(), vote)
		if err != nil {
			logger.Error("HandleVote error", "vote", vb, "err", err)
			return err
		}
	}

	if len(b.Header().Governance) > 0 {
		var gb headergov.GovBytes = b.Header().Governance
		gov, err := gb.ToGovData()
		if err != nil {
			logger.Error("DeserializeHeaderGov error", "governance", gb, "err", err)
			return err
		}
		err = h.HandleGov(b.NumberU64(), gov)
		if err != nil {
			logger.Error("HandleGov error", "governance", gb, "err", err)
			return err
		}
	}

	return nil
}

func (r *RewardModule) FinalizeState(header *types.Header, state *state.StateDB, txs []*types.Transaction, receipts []*types.Receipt) error {
	if r.GovModule.GetParamSet(header.Number.Uint64()).ProposerPolicy == uint64(istanbul.WeightedRandom) && common.EmptyHash(header.Root) {
		qualified, err := r.ValsetModule.GetQualifiedValidators(header.Number.Uint64())
		if err != nil {
			return err
		}
		useRewardAddress := valset.NewAddressSet(qualified).Contains(r.NodeAddress)

		if rewardAddr := r.GetRewardAddress(header.Number.Uint64(), r.NodeAddress); useRewardAddress && rewardAddr != (common.Address{}) {
			header.Rewardbase = rewardAddr
			logger.Trace("Use reward address for nodeValidator", "header.Number", header.Number.Uint64(), "nodeAddress", r.NodeAddress, "rewardbase", header.Rewardbase)
		} else {
			logger.Trace("No reward address for nodeValidator. Use node's rewardbase.", "header.Number", header.Number.Uint64(), "nodeAddress", r.NodeAddress, "rewardbase", header.Rewardbase)
		}
	}

	spec, err := r.GetDeferredReward(header, txs, receipts)
	if err != nil {
		return err
	}
	if err := spec.Validate(); err != nil {
		return err
	}
	for addr, amount := range spec.Rewards {
		state.AddBalance(addr, amount)
	}
	return nil

func (r *RewardModule) GetRewardAddress(num uint64, nodeId common.Address) common.Address {
	sInfo, err := r.StakingModule.GetStakingInfo(num)
	if err != nil {
		return common.Address{}
	}

	for idx, id := range sInfo.NodeIds {
		if id == nodeId {
			return sInfo.RewardAddrs[idx]
		}
	}
	return common.Address{}
}
