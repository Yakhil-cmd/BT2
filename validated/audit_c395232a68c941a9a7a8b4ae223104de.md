**Rationale:**

The premise that a `public` dispatch-target function's visibility or signature can change post-registration via a module upgrade is false. Move's module upgrade compatibility checker enforces at publish time that public function visibility must remain public and signatures cannot change: [1](#0-0) [2](#0-1) 

This is confirmed by the dedicated upgrade-compatibility test suite, which asserts a `public fun f(){}` -> `public fun f(u: u16){}` upgrade (changing signature) aborts with `BACKWARD_INCOMPATIBLE_MODULE_UPDATE`, and that public visibility can never be downgraded: [3](#0-2) 

So a module upgrade that changes a `dispatch_target`'s parameter types or demotes it from `public` while keeping the same `module_name`/`function_name` is rejected by the VM's own module-publish compatibility check before it can ever be committed on-chain — the described "upgrade" transaction itself never gets admitted, and `check_dispatch_type_compatibility_impl` / `FunctionInfo` never sees a mismatched stale binding.

Additionally, this scenario requires the attacker to be the owner/publisher of the dispatch-target module (a privileged actor performing module governance/upgrade), not an unprivileged transaction, authenticator, or API input, which the review's boundary conditions and decision standard explicitly exclude (`"Reject anything that needs a privileged signer... or pre-existing approval right"`).

fn change_function_signature() {
    let result = check_upgrade("fun f(){}", "fun f(u: u16){}");
    assert_success!(result);

    let result = check_upgrade("public fun f(){}", "public fun f(u: u16){}");
    assert_vm_status!(result, StatusCode::BACKWARD_INCOMPATIBLE_MODULE_UPDATE);

    let result = check_upgrade("public(friend) fun f(){}", "public(friend) fun f(u: u16){}");
    assert_success!(result);

    let result = check_upgrade("entry fun f(){}", "entry fun f(u: u16){}");
    assert_vm_status!(result, StatusCode::BACKWARD_INCOMPATIBLE_MODULE_UPDATE);

    let result = check_upgrade("public entry fun f(){}", "public entry fun f(u: u16){}");
    assert_vm_status!(result, StatusCode::BACKWARD_INCOMPATIBLE_MODULE_UPDATE);

    let result = check_upgrade(
        "public(friend) entry fun f(){}",
        "public(friend) entry fun f(u: u16){}",
    );
