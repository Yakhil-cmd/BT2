Based on my research, the polkadot-sdk repository has no analogous attack surface. The reported CVE concerns snipe-it's PHP `ExternalUrl` validation rule for webhook URLs, allowing an authenticated super-admin to trigger SSRF via IPv6 transition addresses (NAT64/6to4/Teredo) that bypass private-IP filtering.

The closest constructs in polkadot-sdk are all node-operator/config-level, not attacker-reachable via unprivileged extrinsics, contracts, or XCM:

- P2P discovery address filtering uses `IpNetwork::is_global()` to decide whether to publish/accept addresses in the DHT or as external addresses [1](#0-0) [2](#0-1) [3](#0-2) . These control which addresses a node advertises to peers, not requests made on behalf of an attacker-supplied target from a privileged actor.
- CLI-level relay-chain RPC URL validation only checks the scheme is `ws`/`wss` [4](#0-3) , configured by the node operator at startup, not by any on-chain actor.
- `--no-private-ip` / `--allow-private-ip` CLI flags govern outbound P2P dialing policy set by the node operator [5](#0-4) .
- The offchain worker `http` module provides an HTTP request API used by runtime offchain workers, which are configured/authorized by node operators, not driven by arbitrary user-submitted URLs from unsigned/signed extrinsics [6](#0-5) .

None of these expose an unprivileged, attacker-controlled entry point (signed extrinsic, contract call, or XCM message) that accepts a URL/address and performs an outbound request to an attacker-chosen internal target — the core mechanism of the reported SSRF. There is no FRAME pallet, contract precompile, or XCM transactor in this codebase that takes a user-supplied URL for server-side fetching under privileged webhook-style semantics. Forcing this web-app SSRF bug class onto the FRAME/XCM/P2P surfaces here would not be a genuine analog.

/// An HTTP request builder.
#[derive(Clone, PartialEq, Eq, Debug)]
pub struct Request<'a, T = Vec<&'static [u8]>> {
	/// Request method
	pub method: Method,
	/// Request URL
	pub url: &'a str,
	/// Body of the request
	pub body: T,
	/// Deadline to finish sending the request
	pub deadline: Option<Timestamp>,
	/// Request list of headers.
	headers: Vec<header::Header>,
}

impl<T: Default> Default for Request<'static, T> {
	fn default() -> Self {
		Request {
			method: Method::Get,
			url: "http://localhost",
			headers: Vec::new(),
			body: Default::default(),
			deadline: None,
		}
	}
}

impl<'a> Request<'a> {
	/// Start a simple GET request
	pub fn get(url: &'a str) -> Self {
