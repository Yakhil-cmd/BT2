The CVE-2020-26163 report describes a web-application vulnerability class (HTTP `Host`/`Origin` header trust leading to password-reset link spoofing and account takeover) in a Ruby on Rails app. This bug class requires: a password-reset flow that derives a trusted URL from attacker-controlled `Host`/`Origin` headers, and a token sent to a victim's email that can be redirected to an attacker's domain.

Polkadot SDK has no analogous flow. The only place where `Host`/`Origin`-style headers are handled is the JSON-RPC server's optional host filter and CORS layer [1](#0-0)  and CORS origin allow-list [2](#0-1) , configured via CLI parameters such as `--rpc-cors` [3](#0-2) . This is:

- A node-operator/config-only security control (host filtering is only enabled when CORS is set, and it is explicitly a local-machine allowlist for `localhost`/`127.0.0.1`/`[::1]`) [4](#0-3) , not a user-facing authentication/password-reset mechanism.
- Not reachable through any signed extrinsic, XCM message, or contract call — the prompt requires a genuine runtime entry point (extrinsic, XCM, contract deploy/call) with no privileged prerequisite, which does not exist here.
- Explicitly excluded by the scan's rejection criteria for config-only/dependency-only findings.

There is no token-based account-recovery or session mechanism in the Polkadot SDK that consumes `Host`/`Origin` headers to construct a trusted redirect or reset link, so the CVE's violated invariant (untrusted header used to build a security-sensitive URL delivered to a victim) has no demonstrable analog in this codebase.

pub(crate) fn host_filtering(enabled: bool, addr: SocketAddr) -> Option<HostFilterLayer> {
	if enabled {
		// NOTE: The listening addresses are whitelisted by default.

		let hosts = [
			format!("localhost:{}", addr.port()),
			format!("127.0.0.1:{}", addr.port()),
			format!("[::1]:{}", addr.port()),
		];

		Some(HostFilterLayer::new(hosts).expect("Valid hosts; qed"))
	} else {
		None
	}
}

pub(crate) fn try_into_cors(
	maybe_cors: Option<Vec<String>>,
) -> Result<CorsLayer, Box<dyn StdError + Send + Sync>> {
	if let Some(cors) = maybe_cors {
		let mut list = Vec::new();

		for origin in cors {
			list.push(HeaderValue::from_str(&origin)?)
		}

		Ok(CorsLayer::new().allow_origin(AllowOrigin::list(list)))
	} else {
		// allow all cors
		Ok(CorsLayer::permissive())
	}
}

impl RpcParams {
	/// Returns the RPC CORS configuration.
	pub fn rpc_cors(&self, is_dev: bool) -> crate::Result<Option<Vec<String>>> {
		Ok(self
			.rpc_cors
			.clone()
			.unwrap_or_else(|| {
				if is_dev {
					log::warn!("Running in --dev mode, RPC CORS has been disabled.");
					Cors::All
				} else {
					Cors::List(vec![
						"http://localhost:*".into(),
						"http://127.0.0.1:*".into(),
						"https://localhost:*".into(),
						"https://127.0.0.1:*".into(),
						"https://polkadot.js.org".into(),
					])
				}
			})
			.into())
	}
