### Title
Artifact name of `.git` allows attacker-controlled files to be extracted into the victim's real `.git` directory, enabling git-hook code execution - (File: pkg/cmd/run/download/download.go)

### Summary
`runDownload` isolates each artifact into a subdirectory named after the artifact via `absoluteDestinationDir.Join(a.Name)`, and `safepaths.Absolute.Join` (and the downstream `ghzip.ExtractZip`) only reject paths that *lexically* traverse outside the base directory using `filepath.Rel`/`HasPrefix("..")` checks. Nothing prevents an artifact literally named `.git` (or `.ssh`) from resolving to the victim's actual `.git`/`.ssh` directory when `--dir` defaults to `.` and the command is run inside a git working tree or home directory. This lets an unprivileged workflow author who controls artifact names/content in a CI run cause `gh run download` to write attacker-chosen files (e.g. `hooks/pre-commit`) directly into the victim's real `.git/hooks`, which git will execute on the next `git commit`.

### Finding Description
The relevant call chain is: [1](#0-0) 

`isolateArtifacts` returns true whenever multiple/all artifacts are requested (the default with no `-n`/`-p` flags), so `destDir` becomes `absoluteDestinationDir.Join(a.Name)` where `a.Name` is the attacker-controlled artifact name from the workflow run. This is only guarded against `PathTraversalError`: [2](#0-1) 

`isSubpathOf` uses `filepath.Rel` and rejects only paths whose relative form starts with `..` — i.e., pure lexical containment. A literal, non-traversing child name like `.git` or `.ssh` passes this check without error because it *is* a subpath of the destination directory; the check has no concept of "sensitive/reserved directory names."

Once `destDir` is `CWD/.git`, `opts.Platform.Download` eventually calls `ghzip.ExtractZip`, which performs the same non-hardened join per zip entry and then materializes files: [3](#0-2) [4](#0-3) 

`os.MkdirAll(dest.String(), dirMode)` for directory entries succeeds silently whether or not `.git`/`.git/hooks` already exists — it does not fail or warn when the target coincides with an existing sensitive directory. `os.OpenFile(..., O_WRONLY|O_CREATE|O_EXCL, ...)` will then create a brand-new file (e.g. `hooks/pre-commit`) if none exists yet at that path inside the real `.git` directory, without any indication to the user that this collided with the repository's control directory.

No component in the chain (`runDownload`, `safepaths.Absolute.Join`, `ghzip.ExtractZip`) checks artifact/zip-entry names against a denylist of sensitive directory names such as `.git`, `.ssh`, `.github`, etc. The protection is purely against `..`-style lexical traversal, not against semantic path confinement with legitimately-named sensitive subdirectories.

### Impact Explanation
If the victim runs `gh run download` (no `-n`/`-p`, or multiple names/patterns matched) with the default `--dir .` while the current working directory is a git working tree, and a malicious/compromised workflow uploads an artifact literally named `.git` containing a `hooks/pre-commit` (or `hooks/post-checkout`, etc.) entry that does not already exist in the victim's `.git/hooks`, the tool will write that attacker-controlled hook file directly into the victim's real git hooks directory. The next local git operation that triggers that hook (e.g. `git commit`) executes attacker-controlled code on the victim's machine — this is arbitrary file write leading to local code execution, a legitimate high-impact class (file write outside intended path / code execution).

### Likelihood Explanation
- Preconditions: victim must run `gh run download` with the default isolate-by-name behavior (true whenever no single `-n` name is given) inside a directory that is a git working tree (or, for `.ssh`, the user's home directory), and the specific hook file must not already exist (so `O_EXCL` doesn't fail).
- Feasibility: any GitHub Actions workflow author (including an untrusted PR/fork workflow that a maintainer might inspect artifacts from, or any user with push access to a repo they control) can freely name an uploaded artifact `.git` and set arbitrary internal file paths (e.g. `hooks/pre-commit`) inside the artifact zip — this requires no special privilege beyond being able to run a workflow that uploads an artifact.
- Repeatable: deterministic given the same inputs; not reliant on race conditions.

### Recommendation
Harden `runDownload`/`safepaths.Absolute.Join` (or add an explicit check before isolating by artifact name) to reject artifact names and zip entry path components that match sensitive/reserved directory names such as `.git`, `.ssh`, `.github`, or more generally to detect when the resolved destination collides with an existing directory that wasn't created by this download (e.g., refuse to write into a pre-existing directory not created during this run, or require `--clobber`-style explicit confirmation). At minimum, sanitize/reject artifact names beginning with `.` before using them as a directory component, and consider using a temp-directory-then-atomic-rename strategy so extraction never touches pre-existing sensitive paths directly.

func (a Absolute) Join(elem ...string) (Absolute, error) {
	joinedAbsolutePath, err := ParseAbsolute(filepath.Join(append([]string{a.path}, elem...)...))
	if err != nil {
		return Absolute{}, fmt.Errorf("failed to parse joined path: %w", err)
	}

	isSubpath, err := joinedAbsolutePath.isSubpathOf(a)
	if err != nil {
		return Absolute{}, err
	}

	if !isSubpath {
		return Absolute{}, PathTraversalError{
			Base:  a,
			Elems: elem,
		}
	}

	return joinedAbsolutePath, nil
}

func (a Absolute) isSubpathOf(dir Absolute) (bool, error) {
	relativePath, err := filepath.Rel(dir.path, a.path)
	if err != nil {
		return false, err
	}
	return !strings.HasPrefix(relativePath, ".."), nil
}

func extractZipFile(zf *zip.File, dest safepaths.Absolute) (extractErr error) {
	zm := zf.Mode()
	if zm.IsDir() {
		extractErr = os.MkdirAll(dest.String(), dirMode)
		return
	}

	var f io.ReadCloser
	f, extractErr = zf.Open()
	if extractErr != nil {
		return
	}
	defer f.Close()

	if extractErr = os.MkdirAll(filepath.Dir(dest.String()), dirMode); extractErr != nil {
		return
	}

	var df *os.File
	if df, extractErr = os.OpenFile(dest.String(), os.O_WRONLY|os.O_CREATE|os.O_EXCL, getPerm(zm)); extractErr != nil {
		return
	}

	defer func() {
		if err := df.Close(); extractErr == nil && err != nil {
			extractErr = err
		}
	}()

	_, extractErr = io.Copy(df, f)
	return
}
