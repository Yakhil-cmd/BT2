### Title
Validator Can Self-Evict (or Remove Any Peer) from Council via `governance.removevalidator` in `none` Governance Mode — (`kaiax/gov/headergov/impl/header.go`)

---

### Summary

In `none` governance mode, `checkConsistency` returns `nil` immediately for `AddValidator`/`RemoveValidator` votes without performing any check on the vote value. This allows any council member who becomes a block proposer to include their own address — or any other non-governing-node council member's address — in a `governance.removevalidator` vote, permanently removing them from the validator council. The only guard (`ErrGovNodeInValSetVoteValue`) is gated behind `params.GovernanceMode == "single"` and is therefore entirely absent in `none` mode. A TODO comment in the same module explicitly acknowledges the missing check.

---

### Finding Description

**Root cause — `checkConsistency` in `kaiax/gov/headergov/impl/header.go`:** [1](#0-0) 

```go
case gov.AddValidator, gov.RemoveValidator:
    params := h.GetParamSet(blockNum)
    // compare with governing node only in single mode.
    if params.GovernanceMode != "single" {
        return nil   // ← no check whatsoever in "none" mode
    }
    if slices.Contains(vote.Value().([]common.Address), params.GoverningNode) {
        return ErrGovNodeInValSetVoteValue
    }
    return nil
```

When `GovernanceMode == "none"`, the function exits at `return nil` before any address-level validation. The voter's own address is never compared against the vote value.

**Execution — `applyVote` in `kaiax/valset/impl/getter_council.go`:** [2](#0-1) 

```go
for _, address := range addresses {
    if address == governingNode {
        continue   // only the governingNode is shielded
    }
    switch voteKey {
    case gov.RemoveValidator:
        if council.Contains(address) {
            council.Remove(address)   // voter's own address is not shielded
        }
    }
}
```

The voter's own address receives no special treatment. If a proposer embeds their own address in the `RemoveValidator` vote value, `applyVote` removes them from the council and persists the change to the chain DB.

**Acknowledged missing check — `kaiax/gov/headergov/impl/api.go`:** [3](#0-2) 

```go

if err != nil {
    return "", err
}

api.h.PushMyVotes(vote)
```

The TODO appears immediately after `checkConsistency` returns, confirming that the `removevalidator` path is known to be incomplete.

### Impact Explanation

The corrupted value is `Council(N)` — the persistent validator-set entry written to the chain DB by `writeCouncil` in `applyBlock`. [4](#0-3) 

In `none` mode the last vote in an epoch wins. A council member who is the last proposer to vote in an epoch can unilaterally:

1. **Self-evict** — remove their own address from the council, permanently losing validator status.
2. **Evict peers** — remove any other non-governing-node council member, shrinking the active validator set without any quorum requirement.

Both outcomes are a governance privilege escalation that permanently changes protected chain state (the council/validator set). A sufficiently motivated attacker who controls one council seat and can predict or wait for a proposer slot near epoch end can reduce the council to a single member, gaining de-facto sole control over block production.

---

### Likelihood Explanation

- Requires the attacker to be a council member (semi-trusted, but the bug class is "missing self-dealing check on a semi-trusted actor").
- Requires the attacker to become a block proposer — normal rotation, no additional privilege.
- In `none` mode all council members may vote; no extra permission is needed beyond being a proposer.
- `none` mode is the default (`params.DefaultGovernanceMode`) for newly deployed chains. [5](#0-4) 

(The post-Permissionless single-mode guard shown above does not apply to `none` mode chains.)

---

### Recommendation

In `checkConsistency`, add a self-removal guard that applies in **all** governance modes, not only `single`:

```go
case gov.AddValidator, gov.RemoveValidator:
    // Prevent self-dealing: the proposer/voter must not appear in the vote value.
    if slices.Contains(vote.Value().([]common.Address), vote.Voter()) {
        return ErrSelfValSetVote
    }
    params := h.GetParamSet(blockNum)
    if params.GovernanceMode != "single" {
        return nil
    }
    if slices.Contains(vote.Value().([]common.Address), params.GoverningNode) {
        return ErrGovNodeInValSetVoteValue
    }
    return nil
```

Apply the same guard in the `Vote` API (resolving the existing TODO) and add a corresponding check in `VerifyVote` so that blocks carrying a self-removal vote are rejected during header verification.

---

### Proof of Concept

1. Chain is deployed with `governance.governancemode = "none"` (the default).
2. Council = `[A, B, C, D]`. Validator A is a council member.
3. Validator A becomes the block proposer for block N (normal rotation).
4. Validator A calls `governance_vote("governance.removevalidator", A.address)`.
5. `checkConsistency` hits the `AddValidator, gov.RemoveValidator` case, reads `GovernanceMode == "none"`, and returns `nil` — no error.
6. The vote is queued and inscribed in `header.Vote` of block N when A proposes.
7. `VerifyVote` passes (voter is in council, voter is the proposer, no consistency error).
8. `applyVote` iterates the address list: `A != governingNode`, so `council.Remove(A)` executes.
9. `writeCouncil` persists `Council(N) = [B, C, D]` to the chain DB.
10. From block N+1 onward, Validator A is permanently removed from the council and can no longer participate in consensus — achieved with a single proposer slot and no quorum. [6](#0-5) [1](#0-0) [7](#0-6)

```go
func applyVote(header *types.Header, council *valset.AddressSet, governingNode common.Address) bool {
	voteKey, addresses, ok := parseValidatorVote(header)
	if !ok {
		return false
	}

	originalSize := council.Len()
	for _, address := range addresses {
		if address == governingNode {
			continue
		}
		switch voteKey {
		case gov.AddValidator:
			if !council.Contains(address) {
				council.Add(address)
			}
		case gov.RemoveValidator:
			if council.Contains(address) {
				council.Remove(address)
			}
		}
	}
	return originalSize != council.Len()
```
