### No vulnerability found for this question.

**Analysis**: `FilterByHosts` in [1](#0-0)  compares hosts using `rr.RepoHost()`, which delegates to `Remote.RepoHost()` → `ghrepo.Interface.RepoHost()` [2](#0-1) . The underlying `ghRepo` is constructed by `ghrepo.FromURL`, which derives the hostname exclusively from `u.Hostname()` [3](#0-2) .

Go's `net/url.URL.Hostname()` method already strips the port unconditionally and never includes userinfo (userinfo is stored separately in `u.User` and is never part of `Host`/`Hostname()`). This means the `port and userinfo in hostname` scenario suggested by the question (e.g. `github.com:443@evil.tld`) is parsed by Go's `url.Parse` such that `Hostname()` correctly returns `evil.tld` (the actual authority host), not `github.com`. So there is no discrepancy introduced by `FromURL`/`RepoHost` between the "trust key" and the real host — both are derived from the same normalized `u.Hostname()` value at parse time, before `RepoHost()` is ever consumed by `FilterByHosts` or any consumer (e.g., `ghinstance.HostPrefix`, GraphQL/REST client host selection) [4](#0-3) .

For SSH-style/scp-like git remote URLs, `git.ParseURL` performs its own normalization that also strips the port suffix from `u.Host` prior to `ghrepo.FromURL` being invoked [5](#0-4) , keeping the same consistency.

Since `FilterByHosts` and `RepoHost()` never independently re-parse or retain port/userinfo separately from the value used for connection targeting (both flow from the same single `u.Hostname()` call at parse time), there is no exploitable inconsistency between the trust key and the connection target within this function. The attacker cannot make `FilterByHosts` classify a remote as trusted for `github.com` while the actual dial target differs, because there is only one normalized host value computed and used everywhere downstream.

func (r Remotes) FilterByHosts(hosts []string) Remotes {
	filtered := make(Remotes, 0)
	for _, rr := range r {
		for _, host := range hosts {
			if strings.EqualFold(rr.RepoHost(), host) {
				filtered = append(filtered, rr)
				break
			}
		}
	}
	return filtered
}

func FromURL(u *url.URL) (Interface, error) {
	if u.Hostname() == "" {
		return nil, fmt.Errorf("no hostname detected")
	}

	parts := strings.SplitN(strings.Trim(u.Path, "/"), "/", 3)
	if len(parts) != 2 {
		return nil, fmt.Errorf("invalid path: %s", u.Path)
	}

	return NewWithHost(parts[0], strings.TrimSuffix(parts[1], ".git"), u.Hostname()), nil
}
