### Title
Webhook signature verification fails open when `webhook_secret` is unset - ([File: lib/shipit/github_app.rb])

### Summary
`GitHubApp#verify_webhook_signature` returns `true` unconditionally whenever the resolved organization's `webhook_secret` is blank, meaning any POST to `/webhooks` with an arbitrary or missing `X-Hub-Signature` is accepted as authentic for that organization. This is a fail-open design (documented as "Backward compatibility") rather than a fail-closed authentication check.

### Finding Description
The broken binding: the code should guarantee `verify_webhook_signature(sig, body) == true` **iff** `sig` is a valid HMAC-SHA1 of `body` under the org's `webhook_secret`. Instead: [1](#0-0) 

`return true unless webhook_secret` short-circuits the entire check whenever `@webhook_secret = @config[:webhook_secret].presence` is `nil` (set at init: [2](#0-1) ). The call path is `WebhooksController#verify_signature` → `Shipit.github(organization: repository_owner).verify_webhook_signature(...)` [3](#0-2) , resolving the org config via `Shipit.github_app_config`/`Shipit.github` [4](#0-3) . If the org's config exists (so `GithubOrganizationUnknown` is not raised) but `webhook_secret` is blank/nil — the documented default in `config/secrets.development.example.yml` (`webhook_secret: # nil`) — every unsigned/arbitrarily-signed webhook for that org is accepted and dispatched to `Shipit::Webhooks.for_event(event).each { |handler| handler.call(params) }` [5](#0-4) , e.g. triggering `GithubSyncJob` on a spoofed push, or handlers for `pull_request`/`check_suite`/`status` events with attacker-chosen payload content.

No other guard exists on this path: `drop_unhandled_event` only checks the event type is handled, not signature validity, and `check_if_ping` only special-cases the `ping` event [6](#0-5) .

### Impact Explanation
For any organization whose GitHub App config lacks a `webhook_secret`, an unauthenticated internet attacker can submit arbitrary, unsigned webhook payloads that are processed as genuine events for that org's repositories — e.g. forcing `GithubSyncJob` enqueues, creating `Membership`/`Team` records, or feeding fabricated `pull_request`/`status`/`check_suite` data into registered handlers. This is a full authentication bypass of the webhook trust boundary, scoped to whichever organization(s) have this config gap; it is repeatable per request and per repository owned by that org's namespace.

### Likelihood Explanation
This requires the specific misconfiguration that the deployment operator has installed a GitHub App/org entry in `secrets.github` without setting `webhook_secret` — which is exactly the shipped example default (`config/secrets.development.example.yml`, `webhook_secret: # nil`) and is called out as "optional" in `docs/setup.md`. Given this precondition, exploitation cost is a single unauthenticated HTTP POST with any/no signature header; no other Shipit secret is required.

### Recommendation
Fail closed instead of open: require `webhook_secret` to be present for any configured organization and reject (422) verification attempts when it is missing, rather than treating an absent secret as "verified." At minimum, log/alert loudly and refuse webhook processing until `webhook_secret` is configured, since this is a per-tenant trust boundary.

test "#verify_webhook_signature fails open when secret unset" do
  app = GitHubApp.new("org", { webhook_secret: nil })

  # no X-Hub-Signature header set at all
  assert_enqueued_with(job: GithubSyncJob) do
    post :create, body: body, as: :json
  end
  assert_response :ok

    def verify_webhook_signature(signature, message)
      return true unless webhook_secret

      algorithm, signature = signature.split("=", 2)
      return false unless algorithm == 'sha1'

      SecureCompare.secure_compare(signature, OpenSSL::HMAC.hexdigest(algorithm, webhook_secret, message))
    end

  def github(organization: github_default_organization)
    # Backward compatibility
    # nil signifies the single github app config schema is being used
    if github_default_organization.nil?
      config = secrets.github
    else
      config = github_app_config(organization)
      raise GithubOrganizationUnknown, organization if config.nil?
    end
    @github ||= {}
    @github[organization] ||= GitHubApp.new(organization, config)
  end

  def github_default_organization
    return nil unless secrets&.github

    org = secrets.github.keys.first
    TOP_LEVEL_GH_KEYS.include?(org) ? nil : org
  end

  def github_organizations
    return [nil] unless github_default_organization

    secrets.github.keys
  end

  def github_app_config(organization)
    github_config = secrets.github.deep_transform_keys(&:downcase)
    github_organization = organization.downcase.to_sym
    github_config[github_organization]
  end
