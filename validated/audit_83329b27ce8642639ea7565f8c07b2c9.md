**Analysis:**

`pseudo_script_module_id()` returns a shared static `ModuleId` (`SCRIPT_MODULE_ID`) used purely as a placeholder identifier to represent "this is a script, not a module" in generic code paths that expect a `ModuleId` [1](#0-0) . It is consumed only in Move VM/loader/compiler-infrastructure contexts — e.g. `LoadedFunctionOwner::module_or_script_id()` for display/error-message purposes [2](#0-1) , script-to-module/module-to-script conversion utilities [3](#0-2) , and the compiler model's script naming [4](#0-3) .

Critically, actual script code caching in the VM/block-executor is keyed by a `[u8; 32]` hash of the script bytecode via a separate `ScriptCache`, not by `ModuleId` [5](#0-4) , and the module cache (keyed by `ModuleId`) is only used for actual on-chain modules, not scripts [6](#0-5) . There is no per-sender or per-sequence admission bookkeeping (mempool, vm-validator, sequence/expiry/chain-id checks) anywhere keyed on equality to `SCRIPT_MODULE_ID`; no matches were found in `mempool`, `vm-validator`, or `aptos-vm` crates for this symbol.

Since the shared pseudo module id is never used to bind or disambiguate transaction sender, signer, sequence number, chain-id, or replay state during admission — it is strictly an internal VM/loader labeling convention consistent across all scripts by design — there is no path by which an unprivileged attacker's script transaction can cause cross-transaction sender/signer/sequence/replay confusion at the admission boundary.

/// `name` assigned in the produced module.
pub fn script_into_module(compiled_script: CompiledScript, name: &str) -> CompiledModule {
    let mut script = compiled_script;

    // Add the "<SELF>" identifier if it isn't present.
    let self_ident_idx = match script
        .identifiers
        .iter()
        .position(|ident| ident.as_ident_str().as_str() == name)
    {
        Some(idx) => IdentifierIndex::new(idx as u16),
        None => {
            let idx = IdentifierIndex::new(script.identifiers.len() as u16);
            script
                .identifiers
                .push(Identifier::new(name.to_string()).unwrap());
            idx
        },
    };

    // Add a dummy address if none exists.
    let dummy_addr = pseudo_script_module_id().address;
    let dummy_addr_idx = match script
        .address_identifiers
        .iter()
        .position(|addr| addr == &dummy_addr)
    {
        Some(idx) => AddressIdentifierIndex::new(idx as u16),
        None => {
            let idx = AddressIdentifierIndex::new(script.address_identifiers.len() as u16);
            script.address_identifiers.push(dummy_addr);
            idx
        },
    };
