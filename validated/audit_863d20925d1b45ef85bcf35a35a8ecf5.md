Based on my research, the closest structural analog to the SUSD-vault "unfair loss redistribution" bug in this repository is the `sui_system::staking_pool` accounting logic, where SUI staked/rewards are tracked via a global `PoolTokenExchangeRate` (share-price-like mechanism) rather than per-user balances.

However, unlike the reported SUSD vault bug, this code already contains explicit mitigations for exactly this bug class:

- Withdrawals are computed off a table of historical exchange rates (`pool_token_exchange_rate_at_epoch`), and any shortfall when a pool's `sui_balance` can't cover `pending_total_sui_withdraw` is recorded in an explicit `UnderflowSuiBalance` bookkeeping field rather than silently letting the last withdrawer eat 100% of the loss. [1](#0-0) 
- That recorded underflow is deducted at the next epoch boundary in `process_pending_stake`, which recomputes `pool_token_balance` from the latest exchange rate — spreading the loss proportionally across the pool's remaining token holders rather than concentrating it on whoever withdraws last. [2](#0-1) 
- `redeem_fungible_staked_sui` / `calculate_fungible_staked_sui_withdraw_amount` explicitly clamps `principal_amount` to `total_sui_amount` and asserts an `EInvariantFailure` if `principal_withdraw_amount + rewards_withdraw_amount` would exceed the entitled amount, preventing any single withdrawer from over-extracting at others' expense.

/// Called at epoch boundaries to process pending stake withdraws requested during the epoch.
/// Also called immediately upon withdrawal if the pool is inactive.
fun process_pending_stake_withdraw(pool: &mut StakingPool) {
    pool.sui_balance = if (pool.sui_balance >= pool.pending_total_sui_withdraw) {
        pool.sui_balance - pool.pending_total_sui_withdraw
    } else {
        let diff = pool.pending_total_sui_withdraw - pool.sui_balance;
        // While this key is expected to be removed in the next call to `process_pending_stake`,
        // we do not call `process_pending_stake` for inactive pools — skip the bookkeeping.
        if (!pool.is_inactive()) {
            pool.extra_fields.add(UnderflowSuiBalance {}, diff);
        };
        0
    };

    pool.pool_token_balance = if (pool.pool_token_balance >= pool.pending_pool_token_withdraw) {
        pool.pool_token_balance - pool.pending_pool_token_withdraw
    } else {
        0
    };

    pool.pending_total_sui_withdraw = 0;
    pool.pending_pool_token_withdraw = 0;
}

/// Called at epoch boundaries to process the pending stake.
public(package) fun process_pending_stake(pool: &mut StakingPool) {
    // Use the most up to date exchange rate with the rewards deposited and withdraws effectuated.
    let latest_exchange_rate = PoolTokenExchangeRate {
        sui_amount: pool.sui_balance,
        pool_token_amount: pool.pool_token_balance,
    };

    // This key is only present if the `sui_balance` underflowed, hence, the current value of `sui_balance`
    // is `0`. Pool token balance will be recalculated automatically for `0` value.
    let sui_diff = {
        let key = UnderflowSuiBalance {};
        if (pool.extra_fields.contains(key)) pool.extra_fields.remove(key) else 0
    };

    pool.sui_balance = pool.sui_balance + pool.pending_stake - sui_diff;
    pool.pool_token_balance = latest_exchange_rate.get_token_amount(pool.sui_balance);
    pool.pending_stake = 0;
}
