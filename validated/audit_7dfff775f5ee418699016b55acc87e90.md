### Title
Unhandled slice-index panic when parsing attacker-supplied attestation predicate `workflow.repository` field - ([File: pkg/cmd/attestation/inspect/bundle.go])

### Summary
`gh attestation inspect` parses the in-toto predicate of a (deliberately unverified/"unsafe") Sigstore bundle and extracts the org/repo name from a user-controlled JSON string field. The extraction logic assumes the string always has an "owner/repo" shape and indexes into a slice without checking its length, causing an out-of-bounds panic on malformed input.

### Finding Description
`getAttestationDetail` unmarshals the DSSE envelope statement's predicate from the bundle into the `Predicate` struct, taking `BuildDefinition.ExternalParameters.Workflow.Repository` straight from attacker-supplied bundle content [1](#0-0) . This value is fed to `getOrgAndRepo`, which strips a known prefix and then splits on `/`, unconditionally returning `parts[0]` and `parts[1]` with no length check on `parts`: [2](#0-1) 

If the `repository` string in the predicate is, for example, exactly `"https://github.com/"` or `"https://github.com/onlyowner"` (no `/`, or with the prefix but no second path segment), `strings.Split(after, "/")` returns a slice with fewer than 2 elements, and `parts[1]` panics with "index out of range".

Crucially, `runInspect` explicitly processes bundles using an *unsafe* policy that skips real verification before this parsing happens, since the goal of `inspect` is to allow inspecting bundles without trusted materials: [3](#0-2) 

This mirrors the go-merkledag issue's bug class: state derived from external/untrusted input is used in a way that isn't validated before being handled by a code path (`getOrgAndRepo`) that cannot return a graceful error for that unchecked condition, resulting in a panic instead of an error.

### Impact Explanation
An attacker who can get a victim to run `gh attestation inspect` against a crafted or attacker-hosted Sigstore bundle (a local file, or one fetched from an OCI registry / attestations API depending on how bundles are sourced) can crash the `gh` CLI process via a runtime panic (denial of service) simply by shaping the `workflow.repository` field of the in-toto predicate to omit a `/`-delimited repo segment. No valid signature or trust chain is required since inspection intentionally uses an unsafe policy prior to this code running.

### Likelihood Explanation
Likelihood is moderate-to-high: `gh attestation inspect` is a documented, normal command whose entire purpose is to look at attestation bundles that may not yet be trusted (including ones a user downloaded from somewhere or received from a third party), and the vulnerable field is fully attacker-controlled JSON content within the DSSE payload, requiring no special privileges to craft.

### Recommendation
In `getOrgAndRepo` (pkg/cmd/attestation/inspect/bundle.go), validate `len(parts) == 2` (or use `strings.Cut`/`strings.SplitN` and check the `ok`/length result) before indexing, returning a descriptive error such as `fmt.Errorf("unexpected repository format: %s", repoURL)` when the shape doesn't match, instead of allowing an out-of-bounds panic.

### Proof of Concept
1. Construct a Sigstore bundle whose DSSE envelope payload is an in-toto statement with predicate:
```json
{
  "buildDefinition": {
    "externalParameters": { "workflow": { "repository": "https://github.com/" } }
  }
}
```
2. Run `gh attestation inspect <bundle-file>` (or trigger the same code path via `gh attestation inspect` against an attestation fetched with `--bundle-from-oci`/API depending on the source flag used).
3. `runInspect` → `getAttestationDetail` → `getOrgAndRepo` executes `strings.Split("", "/")`, yielding `[""]`, and the subsequent `parts[1]` access panics, crashing the CLI instead of returning the intended `error`.

func getOrgAndRepo(tenant, repoURL string) (string, string, error) {
	var after string
	var found bool
	if tenant == "" {
		after, found = strings.CutPrefix(repoURL, "https://github.com/")
		if !found {
			return "", "", fmt.Errorf("failed to get org and repo from %s", repoURL)
		}
	} else {
		after, found = strings.CutPrefix(repoURL,
			fmt.Sprintf("https://%s.ghe.com/", tenant))
		if !found {
			return "", "", fmt.Errorf("failed to get org and repo from %s", repoURL)
		}
	}

	parts := strings.Split(after, "/")
	return parts[0], parts[1], nil
}
