### Title
Unauthenticated `NType` Wire Field Allows Sybil Injection into CN `flatStorage` — (`networks/p2p/discover/table_bond.go`, `udp.go`, `table_data.go`)

---

### Summary

A malicious peer that has established a UDP bond with a CN node can return a NEIGHBORS response whose `rpcNode` entries carry attacker-chosen `NType=NodeTypeCN`. Because `nodeFromRPC` copies the wire field verbatim and `addNode` routes solely on `n.NType`, every attacker-controlled node that survives the ping/pong bond check is inserted into `tab.storages[NodeTypeCN]` — the `flatStorage` that backs `ClosestNodes(NodeTypeCN)`. No on-chain validator-set check exists anywhere in this path.

---

### Finding Description

**Step 1 — Entry point (public P2P).**
`doRefresh()` unconditionally calls `simpleRefresh(NodeTypeCN)` on a periodic ticker. [1](#0-0) 

`simpleRefresh` calls `lookup(tab.selfID, NodeTypeCN, false, ...)`, which seeds from the existing CN storage and then calls `findNodes`. [2](#0-1) 

**Step 2 — FINDNODE sent to attacker-controlled seed.**
`findNodes` dispatches `findNodesOnce(seed, targetID, NodeTypeCN, max)` for each seed. The attacker only needs to be a bonded seed — achievable by sending a single PING to the victim CN, since `ping.handle` calls `go t.bond(true, ...)` with no NType restriction. [3](#0-2) 

**Step 3 — `nodeFromRPC` copies `NType` verbatim.**
Inside `findnode`'s pending callback, each `rpcNode` from the NEIGHBORS response is passed to `nodeFromRPC`. The only checks are port range, relay-IP, and netrestrict. The `NType` field is taken directly from the wire:

```go
n := NewNode(rn.ID, rn.IP, rn.UDP, rn.TCP, nil, rn.NType)
``` [4](#0-3) 

There is no call to any validator-set or staking module. The `neighbors.TargetType` field is validated against the pending request's `targetType` in `loop()`, but that only checks the packet-level type tag — it does not constrain the per-entry `rpcNode.NType` values inside the packet. [5](#0-4) 

**Step 4 — `bondall` → `Bond` → `addNode` with attacker-supplied NType.**
`findNodesOnce` calls `bondall(r)` on the returned nodes. `bondall` calls `Bond(false, n)` for each. `Bond` only verifies UDP reachability (ping/pong); on success it calls `addNode(n)`. [6](#0-5) [7](#0-6) 

**Step 5 — `addNode` routes on `n.NType` with no guard.**
`addNode` dispatches to `tab.storages[n.NType]`. If `n.NType == NodeTypeCN`, the node lands in the CN `flatStorage`. [8](#0-7) 

**Step 6 — `flatStorage` has no capacity limit.**
`flatStorage.add` uses `math.MaxInt64` as the cap, so the storage grows without bound as Sybil nodes are inserted. [9](#0-8) 

**Step 7 — Corrupted storage propagates to other CNs.**
`ClosestNodes(NodeTypeCN, ...)` (called by `findnode.handle` when another CN sends a FINDNODE) reads directly from this `flatStorage`. Because `flatStorage.closest` returns random entries, Sybil nodes dominate responses once they fill the storage. [10](#0-9) [11](#0-10) 

---

### Impact Explanation

The CN `flatStorage` is the sole source of CN peer candidates served to other CNs during discovery. Filling it with Sybil nodes claiming `NodeTypeCN` displaces legitimate validator entries. CNs that rely on discovery to find peers (e.g., after a restart or when static peers are unavailable) will receive Sybil addresses, fail to establish validator-to-validator connections, and degrade the CN-CN mesh required for Istanbul BFT quorum. Because `flatStorage` is unbounded and `revalidateOnce` only evicts nodes that fail a ping (which attacker nodes can pass), the corruption is durable across refresh cycles.

---

### Likelihood Explanation

The attacker needs only:
1. A UDP socket reachable by the victim CN (to establish a bond via PING).
2. A set of Sybil nodes that respond to PING/PONG (no private key or validator status required).

Both are achievable by any internet-connected party. No privileged access, governance key, or validator collusion is required.

---

### Recommendation

Validate `rpcNode.NType` against the on-chain validator/staking registry before accepting a node into a type-specific storage. At minimum, nodes claiming `NodeTypeCN` should be cross-checked against the current validator set before `addNode` is called. Alternatively, strip the `NType` field from inbound `rpcNode` entries entirely and derive it locally from the on-chain registry, treating the wire field as advisory only.

### Proof of Concept

```
1. Attacker sends PING to victim CN → bond established (ping.handle calls go t.bond).
2. Victim CN's refreshLoop fires simpleRefresh(NodeTypeCN).
3. Attacker is selected as a seed (it is bonded).
4. Victim sends FINDNODE(TargetType=NodeTypeCN) to attacker.
5. Attacker replies with NEIGHBORS(TargetType=NodeTypeCN, Nodes=[100 × rpcNode{NType=NodeTypeCN, ...}])
   where each rpcNode points to an attacker-controlled host that responds to PING.
6. nodeFromRPC creates 100 Node objects with NType=NodeTypeCN verbatim.
7. bondall pings each; all respond → Bond succeeds → addNode(n) called 100 times.
8. tab.storages[NodeTypeCN] now contains 100 Sybil entries.
9. Next CN that sends FINDNODE(NodeTypeCN) to victim receives Sybil addresses.

Property assertion: after step 8, tab.storages[NodeTypeCN].all() contains NodeIDs
not present in the on-chain validator set.
```

func (tab *Table2) bondall(nodes []*Node) []*Node {
	rc := make(chan *Node, len(nodes))
	wg := sync.WaitGroup{}
	for i := range nodes {
		wg.Add(1)
		n := nodes[i]
		go func(n *Node) {
			defer wg.Done()
			if err := tab.Bond(false, n); err == nil {
				rc <- n
			}
		}(n)
	}
	wg.Wait()
	close(rc)

	result := make([]*Node, 0, len(nodes))
	for n := range rc {
		result = append(result, n)
	}
	return result
}

func (tab *Table2) Bond(pinged bool, n *Node) error {
	if n.ID == tab.selfID {
		return errSelfBonding
	}
	// Do not accept inbound (i.e. remote pinged me) bonding requests before
	// populating from my seeds. It prevents remote nodes from filling up the table by spamming.
	if pinged && !tab.initialized() {
		return errTableNotReady
	}
	// Do not attempt bonding if the table is closed. Could happen after tab.Close() and before udp.close()
	// You can't write to the closed DB.
	if tab.closed.Load() {
		return errTableNotReady
	}

	// Skip if we're really sure that this node is reachable and completed the bonding process.
	if tab.canAssumeBonded(n.ID, n.IP) {
		return nil
	}

	// Deduplicate concurrent Bond() calls for the same node.
	_, err, _ := tab.bondGroup.Do(n.ID.String(), func() (interface{}, error) {
		err := tab.pingpong(pinged, n)
		if err == nil {
			tab.addNode(n)
			tab.recordBonded(n)
		}
		return nil, err
	})
	return err
