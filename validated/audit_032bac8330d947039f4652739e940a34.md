### Title
Governing Node Can Be Voted to `address(0)`, Permanently Locking Single-Mode Governance — (`kaiax/gov/param.go`, `kaiax/gov/headergov/impl/header.go`)

### Summary

In `single` governance mode, the governing node can cast a valid `governance.governingnode` vote with the value `0x0000000000000000000000000000000000000000`. The `FormatChecker` for `GovernanceGoverningNode` accepts any `common.Address` including the zero address, and `checkConsistency` validates only that the **current** governing node is in the council — it never validates the **new value** being voted in. Once ratified, `params.GoverningNode` becomes `address(0)`, and every subsequent vote is rejected by `VerifyVote` and the `Vote()` API because no real validator can equal `address(0)`. Governance is permanently and irrecoverably locked.

### Finding Description

**Step 1 — Vote accepted without zero-address guard**

`NewVoteData` in `kaiax/gov/headergov/vote.go` calls the `Canonicalizer` then the `FormatChecker` for the parameter. For `GovernanceGoverningNode`, the `FormatChecker` is:

```go
FormatChecker: func(cv any) bool {
    _, ok := cv.(common.Address)
    return ok   // accepts address(0) — no zero-address rejection
},
```

`address(0)` is a valid `common.Address`, so the check passes.

**Step 2 — `checkConsistency` validates the wrong address**

`checkConsistency` in `kaiax/gov/headergov/impl/header.go` (lines 159–178) checks whether the **current** governing node is in the council, not whether the **proposed new value** is safe:

```go
case gov.GovernanceGoverningNode:
    params := h.GetParamSet(blockNum)
    if params.GovernanceMode != "single" {
        return nil
    }
    council, err := h.ValSet.GetCouncil(blockNum - 1)
    ...
    if slices.Contains(council, params.GoverningNode) { // checks CURRENT GN
        return nil                                       // new value (address(0)) never validated
    }
    return ErrGovNodeNotInValSetList
```

As long as the current governing node is in the council (the normal operating state), the vote for `address(0)` passes all validation.

**Step 3 — Vote is ratified and takes effect**

After one epoch, `getExpectedGovernance` collects the vote and writes `governance.governingnode = 0x000...000` into `header.Governance`. `VerifyGov` accepts it because it matches the locally derived expected governance. `PostInsertBlock` → `HandleGov` → `AddGov` persists it. From the next epoch, `GetParamSet` returns `GoverningNode = address(0)`.

**Step 4 — All future votes are permanently blocked**

`VerifyVote` (post-Permissionless hardfork, which is active on Mainnet/Kairos):

```go
if h.ChainConfig.IsPermissionlessForkEnabled(...) &&
    params.GovernanceMode == "single" &&
    vote.Voter() != params.GoverningNode {   // always true: no real validator == address(0)
    return ErrVotePermissionDenied
}
```

The `Vote()` API enforces the same check:

```go
if gMode == "single" && voter != gp.GoverningNode {
    return "", ErrVotePermissionDenied
}
```

No real validator address can equal `address(0)`, so every governance vote is rejected forever.

**Step 5 — Secondary effect: governing-node demotion protection silently fails**

`getDemotedValidatorsIstanbul` in `kaiax/valset/impl/getter_demote.go` (lines 99–102) protects the governing node from demotion:

```go
if singleMode && demoted.Contains(governingNode) {
    demoted.Remove(governingNode)
}
```

Since `address(0)` is never in the council, `demoted.Contains(address(0))` is always `false`. The protection is a no-op. All validators with insufficient stake can be demoted simultaneously, potentially breaking consensus liveness.

### Impact Explanation

- **Governance privilege escalation / permanent destruction**: The `governance.governingnode` protected state is irrecoverably transferred to an uncontrollable address. No governance parameter (`unitprice`, `mintingamount`, `ratio`, `committeesize`, validator set, etc.) can ever be changed again.
- **Validator set management frozen**: `governance.addvalidator` and `governance.removevalidator` votes are also blocked, preventing any council changes.
- **Demotion protection broken**: The governing-node demotion exemption in `getDemotedValidatorsIstanbul` silently stops working, which can cause all validators to be simultaneously demoted if staking falls below minimum, breaking block production.

### Likelihood Explanation

The governing node in `single` mode is a semi-trusted privileged actor — it is the only entity that can vote. The trigger requires the governing node to cast this specific vote, either:
- **Accidentally**: The `governance_vote` API accepts `"0x0000000000000000000000000000000000000000"` as a valid address string with no warning.
- **Maliciously**: A compromised or rogue governing node can permanently destroy governance as an exit action.

The default value of `GovernanceGoverningNode` is explicitly `address(0)` in the codebase, making it a natural "reset" value that an operator might mistakenly vote for. No on-chain or API-level guard prevents it.

### Recommendation

Add a zero-address rejection in the `FormatChecker` for `GovernanceGoverningNode`:

```go
GovernanceGoverningNode: {
    Canonicalizer: addressCanonicalizer,
    FormatChecker: func(cv any) bool {
        addr, ok := cv.(common.Address)
        if !ok {
            return false
        }
        return addr != (common.Address{}) // reject address(0)
    },
    ...
},
```

Additionally, add a check in `checkConsistency` that the **new value** (`vote.Value()`) is a member of the current council:

```go
case gov.GovernanceGoverningNode:
    ...
    newGovNode := vote.Value().(common.Address)
    if !slices.Contains(council, newGovNode) {
        return ErrGovNodeNotInValSetList
    }
    return nil
```

### Proof of Concept

```
Precondition: chain running in single governance mode with governing node GN.

1. GN calls: governance_vote("governance.governingnode", "0x0000000000000000000000000000000000000000")
   - NewVoteData: addressCanonicalizer converts string → common.Address{} ✓
   - FormatChecker: _, ok := cv.(common.Address) → ok=true ✓
   - checkConsistency: slices.Contains(council, params.GoverningNode) → true (current GN is in council) ✓
   - Vote is queued in myVotes.

2. GN proposes a block → header.Vote = RLP(GN, "governance.governingnode", address(0))
   - VerifyVote passes all checks (voter is GN, GN is in council, consistency passes).

3. At epoch boundary, getExpectedGovernance collects the vote.
   - header.Governance = {"governance.governingnode": "0x000...000"}
   - VerifyGov: matches expected → accepted.
   - PostInsertBlock → HandleGov → AddGov persists it.

4. From next epoch: GetParamSet returns GoverningNode = address(0).

5. Any subsequent governance_vote call:
   - api.Vote(): voter != gp.GoverningNode (address(0)) → ErrVotePermissionDenied
   - VerifyVote(): vote.Voter() != params.GoverningNode → ErrVotePermissionDenied

Result: Governance is permanently locked. No parameter can ever be changed.
        getDemotedValidatorsIstanbul: demoted.Contains(address(0)) = false → demotion protection broken.
```

```go
func (h *headerGovModule) checkConsistency(blockNum uint64, vote headergov.VoteData) error {
	switch vote.Name() {
	case gov.GovernanceGoverningNode:
		params := h.GetParamSet(blockNum)

		// compare with governing node only in single mode.
		if params.GovernanceMode != "single" {
			return nil
		}

		// we'll use blockNum-1 for the blocknumber of GetCouncil since blockNum cannot be available(eg. vote)
		// it's definite that the valSet vote is not included in this block
		// so the council(blockNum - 1) and council(blockNum) should be same

		if err != nil {
			return err
		}

		if slices.Contains(council, params.GoverningNode) {
			return nil
		}
		return ErrGovNodeNotInValSetList
```

```go
func (api *headerGovAPI) Vote(name string, value any) (string, error) {
	var (
		voter     = api.h.nodeAddress
		nextBlock = api.h.Chain.CurrentBlock().NumberU64() + 1
		gp        = api.h.GetParamSet(nextBlock)
		gMode     = gp.GovernanceMode
	)

	if gMode == "single" && voter != gp.GoverningNode {
		return "", ErrVotePermissionDenied
	}

	vote := headergov.NewVoteData(voter, name, value)
	if vote == nil {
		return "", ErrInvalidKeyValue
	}

	if gov.DeprecatedAt(vote.Name(), api.h.ChainConfig.Rules(new(big.Int).SetUint64(nextBlock))) {
		return "", ErrDeprecatedVote
	}

	err := api.h.checkConsistency(nextBlock, vote)
	if err != nil {
		return "", err
	}

	// TODO-kaiax: add removevalidator vote check

	api.h.PushMyVotes(vote)
	return "(kaiax) Your vote is prepared. It will be put into the block header or applied when your node generates a block as a proposer. Note that your vote may be duplicate.", nil
```
