### Title
Missing HTTPS-only enforcement on Copilot API URL allows transport-security downgrade of token-bearing requests - ([File: pkg/cmd/agent-task/shared/capi.go])

### Finding Description
`resolveCapiURL` queries the GraphQL `viewer.copilotEndpoints.api` field from the configured host and returns whatever string value the server provides, without validating its URL scheme: [1](#0-0) 

The returned string is passed unmodified to `capi.NewCAPIClient(..., capiBaseURL)`: [2](#0-1) 

`NewCAPIClient` stores `capiBaseURL` verbatim and wires it into a `capiTransport` that attaches the bearer token to every request whose host matches `capiBaseURL`'s host, but it performs no scheme check: [3](#0-2) 

`jobsBasePathV1` concatenates `capiBaseURL` directly with a fixed suffix: [4](#0-3) 

This is then handed to `safeurl.JoinPathWithHostPrefix`, whose `String()` renders the host prefix "as given" with no scheme validation — it only percent-encodes the path components, not the prefix: [5](#0-4) 

Finally, `http.NewRequestWithContext` is called with this URL and the request (with `Authorization: Bearer <token>` header attached by `capiTransport.RoundTrip`) is issued via `c.httpClient.Do(req)`: [6](#0-5) [7](#0-6) 

At no point in this call chain (`resolveCapiURL` → `NewCAPIClient` → `jobsBasePathV1` → `safeurl.JoinPathWithHostPrefix` → `http.NewRequestWithContext`) is the scheme of `capiBaseURL` checked to be `https`. If Go's `http.Client` is configured to follow non-`https` schemes (e.g., plain `http`), the bearer token is transmitted in the clear. Go's `net/http` transport will also reject genuinely unknown custom schemes at `Do()` time (returning an error rather than making the request), so the primary concrete risk is a downgrade to `http://`, not arbitrary custom-scheme dispatch.

### Impact Explanation
If the value returned by `copilotEndpoints.api` on the configured host is `http://evil/api` (or any non-TLS endpoint), the CLI will send `CreateJob`/`GetJob` requests, including the `Authorization: Bearer <token>` header, in plaintext to that endpoint. This is a token/credential-exposure risk over an insecure transport — matching the "sensitive data exposure" / "insecure transport of credentials" bounty impact class. Impact is scoped to environments where the attacker can influence the GraphQL response for the host the victim's `gh` is configured against (e.g., a malicious or compromised GitHub Enterprise Server deployment, or a host reachable that returns attacker content), consistent with the stated precondition.

### Likelihood Explanation
Requires the victim to run `gh` against a host (typically a GHE instance) whose GraphQL `viewer.copilotEndpoints.api` response is attacker-influenced, and to run an agent-task command that resolves the Copilot API URL. This is a narrower precondition than a standard github.com attack, but it is explicitly listed as an accepted attacker capability ("controls responses from a host the victim points gh at"). Once that precondition holds, the downgrade is deterministic and repeatable — every `CreateJob`/`GetJob` call will use the attacker-supplied scheme with no validation.

### Recommendation
In `resolveCapiURL` (pkg/cmd/agent-task/shared/capi.go), parse the returned `Api` value with `url.Parse` and reject/reject-with-error any value whose scheme is not `https` before returning it. Additionally, consider enforcing the same check defensively inside `capi.NewCAPIClient` or `jobsBasePathV1` as defense-in-depth, so any future caller of the CAPI client cannot be pointed at a non-HTTPS endpoint.

func NewCAPIClient(httpClient *http.Client, token string, host string, capiBaseURL string) *CAPIClient {
	httpClient.Transport = newCAPITransport(token, capiBaseURL, httpClient.Transport)
	return &CAPIClient{
		httpClient:  httpClient,
		host:        host,
		capiBaseURL: capiBaseURL,
	}
}

// capiTransport adds the Copilot auth headers
type capiTransport struct {
	rp       http.RoundTripper
	token    string
	capiHost string
}

func newCAPITransport(token string, capiBaseURL string, rp http.RoundTripper) *capiTransport {
	capiHost := ""
	if u, err := url.Parse(capiBaseURL); err == nil {
		capiHost = u.Host
	}
	return &capiTransport{
		rp:       rp,
		token:    token,
		capiHost: capiHost,
	}
}

func (ct *capiTransport) RoundTrip(req *http.Request) (*http.Response, error) {
	req.Header.Set("Authorization", "Bearer "+ct.token)

	// Since this RoundTrip is reused for both Copilot API and
	// GitHub API requests, we conditionally add the integration
	// ID only when performing requests to the Copilot API.
	if req.URL.Host == ct.capiHost {
		req.Header.Add("Copilot-Integration-Id", "copilot-4-cli")

		// Ensure we are not using GitHub API versions while targeting CAPI.
		req.Header.Set("X-GitHub-Api-Version", "2026-01-09")
	}
	return ct.rp.RoundTrip(req)
}

// joinPathWithHostPrefix builds a full REST API URL by prepending hostPrefix to the path produced by
// JoinPath. A single slash is ensured at the join between hostPrefix and the path so they separate
// cleanly without doubling up. When hostPrefix is empty, the JoinPath result is returned intact, and
// when the joined path is empty, hostPrefix is returned intact. hostPrefix is used verbatim while each
// component is percent-encoded.
func joinPathWithHostPrefix(hostPrefix string, components ...string) string {
	path := joinPath(components...)
	if hostPrefix == "" {
		return path
	}
	if path == "" {
		return hostPrefix
	}
	if !strings.HasSuffix(hostPrefix, "/") {
		return hostPrefix + "/" + path
	}
	return hostPrefix + path
}
