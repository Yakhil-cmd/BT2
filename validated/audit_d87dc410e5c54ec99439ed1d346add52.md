## Title
Arbiter dispute data leaks plaintext contact info to the ArbStore even though it was encrypted for the arbiter only - (File: arbiter_contract.js)

### Summary
In `arbiter_contract.js`, `openDispute()` builds a dispute payload that is sent in plaintext (as normal, unencrypted JSON over HTTP) to the ArbStore hosting service, while a *separately encrypted* copy of the same sensitive fields (including `my_contact_info` and `peer_contact_info`, which can hold personal contact data such as an email address) is prepared specifically for the arbiter's device pubkey. The plaintext copy of these same fields is nevertheless also placed directly on the outer `data` object that is transmitted to the ArbStore, defeating the encryption and exposing party contact info to a service that was not supposed to see it in the clear.

### Finding Description
`openDispute(hash, cb)` [1](#0-0)  resolves two distinct entities for a contract dispute:
- the **arbiter**, whose `device_pub_key` is fetched via `arbiters.getInfo()` [2](#0-1) 
- the **ArbStore**, a separate hosting service resolved via `fillArbstoreAddresses()` / `getArbstoreAddresses()`, which uses `hub/get_arbstore_url` and `hub/get_arbstore_address` to obtain a distinct `arbstore_address`/`arbstore_device_address` [3](#0-2) 

When building the dispute submission, the code explicitly encrypts the contract's contact fields to the **arbiter's** pubkey (not the ArbStore's):
```
encrypted_contract: device.createEncryptedPackage({
    title: objContract.title,
    text: objContract.text,
    creation_date: objContract.creation_date,
    plaintiff_party_name: objContract.my_party_name,
    respondent_party_name: objContract.peer_party_name,
    my_contact_info: objContract.my_contact_info,
    peer_contact_info: objContract.peer_contact_info,
}, objArbiter.device_pub_key),
``` [4](#0-3) 

Immediately after, however, the same `my_contact_info` and `peer_contact_info` are also placed on the outer, unencrypted `data` object:
```
my_contact_info: objContract.my_contact_info,
peer_contact_info: objContract.peer_contact_info
``` [5](#0-4) 

This whole `data` object is then JSON-serialized and POSTed in the clear to the ArbStore's `/api/dispute/new` HTTP endpoint via `httpRequest(url, "/api/dispute/new", dataJSON, ...)` [6](#0-5) . Because the design intentionally encrypts these very fields for the arbiter's eyes only (via `objArbiter.device_pub_key`), the parallel plaintext duplication means the ArbStore operator — an entity distinct from and not necessarily trusted the same as the arbiter — can read both parties' contact info (which per the `sent_mnemonics`/`original_addresses` schema in this codebase includes email-like data) without ever needing to be a Team/Arbiter admin equivalent. This mirrors the Mattermost bug class: a field meant to be sanitized/visible only to a privileged role (there: Team Admin; here: the arbiter) is exposed in full to a lower-privileged party (there: any authenticated user; here: the ArbStore host) through an endpoint/request that fails to withhold it.

### Impact Explanation
Any party operating (or compromising) an ArbStore endpoint learns the plaintext contact information (which may include email addresses, pairing codes, or other PII) of both contract counterparties for every dispute routed through it, even though the protocol design clearly intended that information to be confidential to the arbiter (hence the separate `device.createEncryptedPackage` step). This is an unauthorized information disclosure (CWE-200 analog) reachable by any user who opens an arbiter contract dispute — a normal, unprivileged wallet action — with no additional capability required from the ArbStore beyond being registered as the hub-resolved arbstore endpoint for that arbiter.

### Likelihood Explanation
Likelihood is high for any dispute flow: `openDispute()` is invoked whenever a contract party calls the standard "open dispute" wallet action, and the leak occurs unconditionally as part of building the POST body — no attacker-controlled input or race condition is needed, just observing/controlling the ArbStore HTTP endpoint that legitimately receives the request.

### Recommendation
Remove the plaintext `my_contact_info`/`peer_contact_info` fields from the outer `data` object sent to the ArbStore's `/api/dispute/new` endpoint; rely solely on the `encrypted_contract` package (encrypted to the arbiter's `device_pub_key`) to convey this sensitive information, so the ArbStore relay cannot read it.

### Proof of Concept
1. Two wallets negotiate and accept an arbiter contract, exchanging `my_contact_info` (e.g., an email address) as allowed by the `arbiter_contract_offer`/`arbiter_contract_response` flow [7](#0-6) .
2. One party calls `arbiter_contract.openDispute(hash, cb)`.
3. Inspect the outbound HTTP POST body built at lines 277-303 of `arbiter_contract.js`; observe that `data.my_contact_info` and `data.peer_contact_info` are present in cleartext alongside the (correctly) encrypted `data.encrypted_contract`.
4. Any operator of the ArbStore host resolved via `hub/get_arbstore_url`/`hub/get_arbstore_address` receives and can log/read these plaintext contact fields, despite not being the intended arbiter.

function getArbstoreAddresses(arbiter_address, cb) {
	device.requestFromHub("hub/get_arbstore_url", arbiter_address, function(err, url){
		if (err)
			return cb(err);
		device.requestFromHub("hub/get_arbstore_address", arbiter_address, function(err, arbstore_address){
			if (err) {
				return cb(err);
			}
			httpRequest(url, "/api/get_device_address", "", function(err, arbstore_device_address) {
				if (err) {
					console.warn("no arbstore_device_address", err);
					return cb(err);
				}
				cb(null, { arbstore_address, arbstore_device_address });
			});
		});
	});
}

function fillArbstoreAddresses(objContract, cb) {
	if (!cb)
		return new Promise(resolve => fillArbstoreAddresses(objContract, resolve));
	if (objContract.arbstore_device_address && objContract.arbstore_address)
		return cb();
	getArbstoreAddresses(objContract.arbiter_address, function(err, result) {
		if (err)
			return cb(err);
		var { arbstore_address, arbstore_device_address } = result;
		objContract.arbstore_address = arbstore_address;
		objContract.arbstore_device_address = arbstore_device_address;
		db.query("UPDATE wallet_arbiter_contracts SET arbstore_address=?, arbstore_device_address=? WHERE hash=?", [arbstore_address, arbstore_device_address, objContract.hash], function () { cb(); });
	});
}

function openDispute(hash, cb) {
	getByHash(hash, function(objContract){
		if (!["paid", "in_dispute"].includes(objContract.status))
			return cb("contract can't be disputed");
		device.requestFromHub("hub/get_arbstore_url", objContract.arbiter_address, function(err, url){
			if (err)
				return cb(err);
			arbiters.getInfo(objContract.arbiter_address, async function(err, objArbiter) {
				if (err)
					return cb(err);
				err = await fillArbstoreAddresses(objContract);
				if (err)
					return cb(err);
				device.getOrGeneratePermanentPairingInfo(function(pairingInfo){
					var my_pairing_code = pairingInfo.device_pubkey + "@" + pairingInfo.hub + "#" + pairingInfo.pairing_secret;
					var data = {
						contract_hash: hash,
						unit: objContract.unit,
						my_address: objContract.my_address,
						peer_address: objContract.peer_address,
						me_is_payer: objContract.me_is_payer,
						my_pairing_code: objContract.my_pairing_code,
						peer_pairing_code: objContract.peer_pairing_code,
						encrypted_contract: device.createEncryptedPackage({
							title: objContract.title,
							text: objContract.text,
							creation_date: objContract.creation_date,
							plaintiff_party_name: objContract.my_party_name,
							respondent_party_name: objContract.peer_party_name,
							my_contact_info: objContract.my_contact_info,
							peer_contact_info: objContract.peer_contact_info,
						}, objArbiter.device_pub_key),
						my_contact_info: objContract.my_contact_info,
						peer_contact_info: objContract.peer_contact_info
					};
					db.query("SELECT 1 FROM assets WHERE unit IN(?) AND is_private=1 LIMIT 1", [objContract.asset], function(rows){
						if (rows.length > 0) {
							data.asset = objContract.asset;
							data.amount = objContract.amount;
						}
						var dataJSON = JSON.stringify(data);
						httpRequest(url, "/api/dispute/new", dataJSON, function(err, resp) {
							if (err)
								return cb(err);

							setField(hash, "status", "in_dispute", function(objContract) {
								shareUpdateToPeer(hash, "status");
								// listen for arbiter response
								db.query("INSERT "+db.getIgnore()+" INTO my_watched_addresses (address) VALUES (?)", [objContract.arbiter_address]);
								cb(null, resp, objContract);
							});
						});
					});
				});
			});
		});
	});
}
