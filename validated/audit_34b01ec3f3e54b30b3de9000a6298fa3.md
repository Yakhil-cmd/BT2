### Title
Path traversal via release asset name in `gh release download` allows arbitrary file write outside destination directory - (File: pkg/cmd/release/download/download.go)

### Summary
`destinationWriter.makePath` builds the destination file path with raw `filepath.Join(w.dir, name)`, where `name` is the GitHub Release asset's `Name` field taken directly from the API response. Unlike other download paths in the codebase (`pkg/cmd/run/download/download.go`, `internal/zip/zip.go`, `internal/skills/installer/installer.go`), which all validate joined paths with `internal/safepaths.Absolute.Join` to reject `..` traversal, this code path performs no such check, so a malicious asset name containing `../` segments can escape `opts.Destination`.

### Finding Description
The call chain is `downloadRun` → `downloadAssets` → `downloadAsset` → `dest.Copy(a.Name, resp.Body)` → `makePath`: [1](#0-0) 

`makePath` simply does `filepath.Join(w.dir, name)` with no bounds checking, and `Copy` uses this path to `os.MkdirAll` the parent directory and then `os.OpenFile`/`io.Copy` the asset bytes into it: [2](#0-1) 

The asset `name` originates from `release.Assets[].Name`, populated straight from the GitHub API JSON for the release, which is fully controlled by whoever publishes the release (an unprivileged attacker who can create repos/releases). The only filtering applied before use is a glob pattern match and a Windows-reserved-filename check: [3](#0-2) 

Neither of these blocks `..` path segments. This is a direct contrast to the same repository's own established pattern for path confinement, e.g. `pkg/cmd/run/download/download.go`, which explicitly joins with `safepaths.Absolute.Join` and returns an error on `PathTraversalError`: [4](#0-3) 

and `internal/zip/zip.go`'s `ExtractZip`, which uses the same safe-join mechanism for zip archive entries: [5](#0-4) 

No equivalent guard exists in `destinationWriter.makePath`/`Copy`, so `filepath.Join(w.dir, "../../.ssh/authorized_keys")` will resolve to a path outside `w.dir`, and the file will be written/overwritten there.

### Impact Explanation
An attacker who can publish a release (their own repo, or any repo whose releases are downloaded via `gh release download`) can craft an asset with a name like `../../.ssh/authorized_keys` or `../../../.git/hooks/pre-commit`. When a victim runs `gh release download OWNER/REPO` against that release, the tool will write the attacker's asset content outside the chosen destination directory, potentially overwriting sensitive files (SSH authorized_keys, shell profiles, git hooks) — an arbitrary file write/overwrite vulnerability that can lead to code execution or persistence on the victim's machine.

### Likelihood Explanation
Feasible and repeatable: the only precondition is that the victim runs `gh release download` against a repository/release controlled by the attacker (including via `-R owner/repo`), which is a standard, expected use case (e.g., downloading assets from a public/forked repo). No additional privileges, tokens, or social engineering beyond convincing the victim to download from the attacker's release are required — publishing a release with a maliciously named asset is trivial via the GitHub UI/API.

### Recommendation
Validate/normalize the asset `name` before joining it into a filesystem path in `destinationWriter.makePath`, mirroring the existing `internal/safepaths.Absolute.Join` pattern used in `pkg/cmd/run/download/download.go` and `internal/zip/zip.go`: parse `w.dir` as a `safepaths.Absolute`, join with `name`, and reject (or skip) any asset whose resolved path is not a subpath of the destination directory, returning a `PathTraversalError`-derived error to the caller instead of proceeding with the write.

func (w destinationWriter) Copy(name string, r io.Reader) (copyErr error) {
	fp := w.makePath(name)
	if fp == "-" {
		if w.allowEscapes {
			_, copyErr = io.Copy(w.stdout, r)
			return
		}
		copyErr = iostreams.CopyGuardedContent(w.stdout, r, w.isTTY)
		if binErr, ok := errors.AsType[iostreams.BinaryTerminalError](copyErr); ok {
			copyErr = fmt.Errorf("%w; use `--output` to save it to a file, or pass --allow-escape-sequences to output it anyway", binErr)
		} else if errors.Is(copyErr, iostreams.ErrEscapeSequence) {
			copyErr = errors.New("the asset contains terminal escape sequences; use `--output` to save it to a file, or pass --allow-escape-sequences to output it anyway")
		}
		return
	}
	if copyErr = w.check(fp); copyErr != nil {
		return
	}

	if dir := filepath.Dir(fp); dir != "." {
		if copyErr = os.MkdirAll(dir, 0755); copyErr != nil {
			return
		}
	}

	var f *os.File
	if f, copyErr = os.OpenFile(fp, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, 0644); copyErr != nil {
		return
	}

	defer func() {
		if err := f.Close(); copyErr == nil && err != nil {
			copyErr = err
		}
	}()

	_, copyErr = io.Copy(f, r)
	return
}
