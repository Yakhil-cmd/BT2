I searched for any Polkadot SDK equivalent of the Nginx-UI SSRF pattern — an authenticated/user-controlled request that causes the node to make an outbound network call to an attacker-supplied internal URL via a header like `X-Node-ID`. The closest constructs are:

- The offchain worker HTTP API (`sp_io::offchain::http_request_start` / `sp_runtime::offchain::http::Request`), which lets **node-side, non-deterministic offchain worker code** issue HTTP requests to an arbitrary URL. [1](#0-0)  This is not reachable from a signed extrinsic or any user-facing dispatch path — it's opt-in node software behavior explicitly documented as non-deterministic and outside the state-transition function.  There's no attacker-controlled runtime storage value that feeds into the URL used by any shipped pallet's offchain worker in this codebase.
- `sc-rpc-server`'s proxy-header handling (`get_proxy_ip`, `rpc_rate_limit_trust_proxy_headers`) only trusts `X-Forwarded-For`/`Forwarded`/`X-Real-Ip` headers for rate-limit bypass decisions when a node operator explicitly opts in; it never forwards a request to an attacker-specified URL. [2](#0-1) 
- `NodeHealthProxy` only rewrites `/health` and `/health/readiness` requests into a fixed local `system_health` RPC call; it doesn't take a destination URL from user input at all. [3](#0-2) 

None of these match the required threat model: an unprivileged, signed-extrinsic-reachable path where a user registers an arbitrary internal URL (analogous to `POST /api/nodes`) and then triggers the runtime/node to forward an authenticated request to that URL via a header (analogous to `X-Node-ID`). Polkadot SDK has no "cluster node" or dispatchable-created endpoint whose URL is later used as a server-side forwarding target for subsequent API calls — that concept doesn't exist in FRAME, XCM, or the client RPC stack as implemented here.

/// Extracts the IP addr from the HTTP request.
///
/// It is extracted in the following order:
/// 1. `Forwarded` header.
/// 2. `X-Forwarded-For` header.
/// 3. `X-Real-Ip`.
pub(crate) fn get_proxy_ip<B>(req: &http::Request<B>) -> Option<IpAddr> {
	if let Some(ip) = req
		.headers()
		.get(&FORWARDED)
		.and_then(|v| v.to_str().ok())
		.and_then(|v| ForwardedHeaderValue::from_forwarded(v).ok())
		.and_then(|v| v.remotest_forwarded_for_ip())
	{
		return Some(ip);
	}

	if let Some(ip) = req
		.headers()
		.get(&X_FORWARDED_FOR)
		.and_then(|v| v.to_str().ok())
		.and_then(|v| ForwardedHeaderValue::from_x_forwarded_for(v).ok())
		.and_then(|v| v.remotest_forwarded_for_ip())
	{
		return Some(ip);
	}

	if let Some(ip) = req
		.headers()
		.get(&X_REAL_IP)
		.and_then(|v| v.to_str().ok())
		.and_then(|v| IpAddr::from_str(v).ok())
	{
		return Some(ip);
	}

	None
}
