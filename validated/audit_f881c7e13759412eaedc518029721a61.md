### Title
Unhandled exception in header-size calculation crashes node on malformed unit - ([File: validation.js])

### Summary
Analogous to CVE-2023-37019 (Open5GS MME crash via a malformed S1AP field triggering an unguarded assertion), `ocore`'s `validate()` function computes the header size of every incoming unit via `objectLength.getHeadersSize(objUnit)` without wrapping the call in a `try/catch`, while the very next check (`getTotalPayloadSize`) *is* wrapped in `try/catch`. `getHeadersSize`/`getLength` throws a raw `Error` whenever it encounters a non-finite JS number (e.g. `Infinity`, produced by JSON literals such as `1e400`), an object with a non-own property, or a key whose value is `undefined`. Because `earned_headers_commission_recipients` (an attacker-supplied field on any multi-authored unit) is not type/finite-validated until much later in `validateHeadersCommissionRecipients`, a remote unprivileged unit poster can supply a crafted numeric value that reaches `getLength` before any sanitizing check and throws synchronously and uncaught.

### Finding Description
`validate()` performs the header/payload-commission size checks synchronously, before any mutex-protected asynchronous validation begins: [1](#0-0) 

Note the asymmetry: `getTotalPayloadSize` is guarded by `try/catch`, but the preceding `getHeadersSize` call is not.

`getHeadersSize` clones the whole unit (minus a few fields) and feeds it to `getLength`, which recursively throws on any non-finite number, non-own property, or `undefined` value it encounters: [2](#0-1) [3](#0-2) 

The fields left inside `objHeader` after `getHeadersSize` deletes a small set of keys include `earned_headers_commission_recipients`, whose structural/type validation (`isPositiveInteger` check on `earned_headers_commission_share`, checking `hasFieldsExcept`, sortedness, sum=100, etc.) only happens later, inside `validateHeadersCommissionRecipients`, which is called from within the mutex-locked `async.series` — strictly *after* the synchronous header-size check has already run: [4](#0-3) [5](#0-4) 

Because JSON permits numeric literals with exponents large enough that `JSON.parse` produces `Infinity` (e.g. `1e400`), an attacker can post/relay a unit with `authors.length > 1` and an `earned_headers_commission_recipients` entry containing `earned_headers_commission_share: 1e400`. When `validate()` reaches line 257, `getHeadersSize` → `getLength` → `_getLength` hits `case "number": if (!isFinite(value)) throw Error("invalid number: " + value);` and throws synchronously, outside of any `try/catch`, propagating up through `validate()` uncaught.

This mirrors the CVE-2023-37019 pattern precisely: a required-but-unchecked structural detail (there, `Supported TAs`; here, a numeric field validated too late) allows a remotely delivered, syntactically valid but semantically malformed message to hit an unguarded fatal path (`assert()` there, `throw Error()` here) before the normal validation-error path (`return callbacks.ifUnitError(...)`) can catch it.

### Impact Explanation
`validate()` is invoked on every incoming unit/joint from peers and from locally submitted transactions. An uncaught synchronous `Error` thrown mid-validation is not converted into a `callbacks.ifUnitError`/`ifJointError` response; it propagates up the call stack. Depending on whether the calling context (e.g., `network.js` joint-processing code) has a surrounding try/catch or domain, this can crash the Node.js process or leave the node in an inconsistent state (e.g., with `mutex` locks or DB transactions never released, since the `mutex.lock`/`conn` machinery starts only after this check). A remote party who can get *any* node to validate such a unit (posting it directly, or having it relayed/gossiped) can repeatedly crash the target node — a network-wide denial-of-service against nodes that process new units, matching the "network unable to confirm new units" acceptance criterion.

### Likelihood Explanation
The trigger requires only: (1) a unit with more than one author (a normal, permitted multi-sig configuration) and an `earned_headers_commission_recipients` array (already mandatory in that case), and (2) one recipient's `earned_headers_commission_share` set to a JSON numeric literal that parses to `Infinity` (e.g. `1e400`), or any other field surviving into `objHeader` with an out-of-range/non-finite numeric value. No signatures need to be valid, no special privileges are needed — this is reachable by any unprivileged unit poster before authors/authentifiers are even checked, since the throw happens in the synchronous section of `validate()`, prior to `validateAuthors`.

### Recommendation
Wrap the `getHeadersSize(objUnit)` call (both occurrences at line 257–258) in the same `try/catch` pattern already used for `getTotalPayloadSize`, converting any thrown error into `callbacks.ifJointError(...)`/`ifUnitError(...)`. Additionally, move/duplicate finite-number validation for all numeric fields that can end up in `objHeader` (in particular `earned_headers_commission_recipients[].earned_headers_commission_share`) ahead of the `getHeadersSize` call, or make `getLength`/`_getLength` tolerant (return a sentinel/throw a caught, recoverable validation error) instead of raising a bare `Error`.

### Proof of Concept
Send (post directly or relay) a serial unit joint with two authors and:
```json
{
  "unit": { 
    "...": "valid otherwise-well-formed unit fields",
    "authors": [ { "address": "AAAA..." }, { "address": "BBBB..." } ],
    "earned_headers_commission_recipients": [
      { "address": "AAAA...", "earned_headers_commission_share": 1e400 },
      { "address": "BBBB...", "earned_headers_commission_share": 1 }
    ]
  }
}
```
`JSON.parse` turns `1e400` into `Infinity`. When this joint reaches `validate()`, execution reaches: [6](#0-5) 
which calls `getHeadersSize(objUnit)` → `getLength` → `_getLength`, hitting the `!isFinite(value)` branch in: [7](#0-6) 
and throwing `Error("invalid number: Infinity")` uncaught, before any of the later structural checks in `validateHeadersCommissionRecipients` get a chance to reject the malformed share value.

**Note on verification limits**: I was unable to directly inspect what wraps `validate()` calls at the network layer (e.g., in `network.js`) to confirm whether any outer try/catch prevents a full process crash versus only aborting a single connection handler; this affects the precise blast radius (single-connection failure vs. full node crash) but does not change the fact that a remotely-triggerable, unguarded `throw` exists on a codepath that is deliberately try/catch-guarded one line later for the analogous payload-size computation — itself strong evidence this is an unintentional gap.

function validateHeadersCommissionRecipients(objUnit, cb){
	if (objUnit.authors.length > 1 && typeof objUnit.earned_headers_commission_recipients !== "object")
		return cb("must specify earned_headers_commission_recipients when more than 1 author");
	if ("earned_headers_commission_recipients" in objUnit){
		if (!isNonemptyArray(objUnit.earned_headers_commission_recipients))
			return cb("empty earned_headers_commission_recipients array");
		var total_earned_headers_commission_share = 0;
		var prev_address = "";
		for (var i=0; i<objUnit.earned_headers_commission_recipients.length; i++){
			var recipient = objUnit.earned_headers_commission_recipients[i];
			if (!isPositiveInteger(recipient.earned_headers_commission_share))
				return cb("earned_headers_commission_share must be positive integer");
			if (hasFieldsExcept(recipient, ["address", "earned_headers_commission_share"]))
				return cb("unknown fields in recipient");
			if (!isValidAddress(recipient.address))
				return cb("invalid recipient address checksum");
			if (recipient.address <= prev_address)
				return cb("recipient list must be sorted by address");
			total_earned_headers_commission_share += recipient.earned_headers_commission_share;
			prev_address = recipient.address;
		}
		if (total_earned_headers_commission_share !== 100)
			return cb("sum of earned_headers_commission_share is not 100");
	}
	cb();
}

function getLength(value, bWithKeys) {
	let cache = new WeakMap();  // object to length
	function _getLength(value) {
		if (value === null)
			return 0;
		switch (typeof value) {
			case "string":
				return value.length;
			case "number":
				if (!isFinite(value))
					throw Error("invalid number: " + value);
				return 8;
				//return value.toString().length;
			case "object":
				// return cached result if already processed
				if (cache.has(value))
					return cache.get(value);
				var len = 0;
				if (Array.isArray(value))
					value.forEach(function (element) {
						len += _getLength(element);
					});
				else
					for (var key in value) {
						if (!Object.prototype.hasOwnProperty.call(value, key))
							throw Error("object has non-own property " + key + " in " + JSON.stringify(value));
						if (typeof value[key] === "undefined")
							throw Error("undefined at " + key + " of " + JSON.stringify(value));
						if (bWithKeys)
							len += key.length;
						len += _getLength(value[key]);
					}
				cache.set(value, len);  // memoize for future references
				return len;
			case "boolean":
				return 1;
			default:
				throw Error("unknown type=" + (typeof value) + " of " + value);
		}
	}
	return _getLength(value);
}
