### Title
Missing Zero-Address Validation for `governance.governingnode` Vote Permanently Locks Single-Mode Governance — (`File: kaiax/gov/param.go`)

---

### Summary

The `FormatChecker` for the `GovernanceGoverningNode` governance parameter accepts `address(0)` as a valid vote value. In `single` governance mode (used by Mainnet and Kairos), if the governing node votes to change `governance.governingnode` to `address(0)`, governance is permanently and irrecoverably locked: no real node can ever cast another valid vote, and no governance parameter can ever be changed again.

---

### Finding Description

In `kaiax/gov/param.go`, the `GovernanceGoverningNode` parameter is defined with a `FormatChecker` that only verifies the value is of type `common.Address`:

```go
GovernanceGoverningNode: {
    Canonicalizer: addressCanonicalizer,
    FormatChecker: func(cv any) bool {
        _, ok := cv.(common.Address)
        return ok   // accepts address(0) — no zero-address guard
    },
    DefaultValue: common.HexToAddress("0x0000000000000000000000000000000000000000"),
},
``` [1](#0-0) 

The test suite in `kaiax/gov/headergov/vote_test.go` explicitly confirms that `"0x0000000000000000000000000000000000000000"` is treated as a valid vote value for `GovernanceGoverningNode`:

```go
{name: gov.GovernanceGoverningNode, value: "0x0000000000000000000000000000000000000000"},
``` [2](#0-1) 

The `checkConsistency` function in `kaiax/gov/headergov/impl/header.go` for `GovernanceGoverningNode` only verifies that the **current** governing node is in the council — it does not validate that the **new proposed value** is non-zero or is a council member:

```go
case gov.GovernanceGoverningNode:
    params := h.GetParamSet(blockNum)
    if params.GovernanceMode != "single" {
        return nil
    }
    council, err := h.ValSet.GetCouncil(blockNum - 1)
    ...
    if slices.Contains(council, params.GoverningNode) {
        return nil   // checks current node, not the new value
    }
    return ErrGovNodeNotInValSetList
``` [3](#0-2) 

The `Vote()` API in `kaiax/gov/headergov/impl/api.go` calls `NewVoteData` (which runs `FormatChecker`) and then `checkConsistency`. Neither rejects `address(0)` as the new governing node: [4](#0-3) 

Once the vote is ratified at the next epoch block, `ParamSet.GoverningNode` is set to `common.Address{}` (all zeros). In `single` mode, the `VerifyVote` path enforces:

```go
if h.ChainConfig.IsPermissionlessForkEnabled(...) &&
    params.GovernanceMode == "single" &&
    vote.Voter() != params.GoverningNode {
    return ErrVotePermissionDenied
}
``` [5](#0-4) 

Since no real node controls `address(0)`, no future vote can ever pass `vote.Voter() != params.GoverningNode`, and the `Vote()` API also rejects all callers at the same check: [6](#0-5) 

Governance is permanently frozen.

---

### Impact Explanation

After ratification of a `governance.governingnode = address(0)` vote in single mode:

- **No governance parameter can ever be changed again** — `UnitPrice`, `MintingAmount`, `RewardRatio`, `GovParamContract`, `LowerBoundBaseFee`, `UpperBoundBaseFee`, and all other mutable parameters are permanently frozen at their current values.
- **Reward distribution is permanently fixed** — `reward.mintingamount` and `reward.ratio` cannot be adjusted, affecting all future KAIA issuance and validator/fund splits.
- **The `GovParamContract` address cannot be updated** — contract governance (KIP-81) is also locked.
- This constitutes permanent corruption of protected governance state, matching the allowed impact: *"governance privilege escalation that changes protected chain state."*

The corrupted storage value is `ParamSet.GoverningNode = common.Address{}` persisted via `header.Governance` at the epoch block, propagated to all nodes via `HandleGov`. [7](#0-6) 

---

### Likelihood Explanation

The trigger is the current governing node — a semi-trusted GC member with legitimate voting rights. The scenario is reachable via:

1. **Operator error**: A misconfigured governance script or tooling bug passes `address(0)` as the new governing node address.
2. **Compromised key**: An attacker who gains access to the governing node's key can execute this as a griefing attack.
3. **Intentional self-removal**: A governing node wishing to renounce governance without a proper successor.

The `governance_vote` RPC API is publicly callable by the governing node operator and requires no special on-chain transaction beyond the node being the block proposer. The vote is inscribed in `header.Vote` and ratified automatically at the next epoch block with no further confirmation step.

---

### Recommendation

Add a non-zero address check to the `FormatChecker` for `GovernanceGoverningNode` in `kaiax/gov/param.go`:

```go
GovernanceGoverningNode: {
    Canonicalizer: addressCanonicalizer,
    FormatChecker: func(cv any) bool {
        addr, ok := cv.(common.Address)
        if !ok {
            return false
        }
        return addr != (common.Address{}) // reject address(0)
    },
    ...
},
```

Additionally, add a consistency check in `checkConsistency` to verify the **new** governing node value is a current council member (not just that the current governing node is in the council):

```go
case gov.GovernanceGoverningNode:
    newNode, _ := vote.Value().(common.Address)
    if newNode == (common.Address{}) {
        return ErrInvalidKeyValue
    }
    // also verify newNode is in council
``` [1](#0-0) [8](#0-7)

### Proof of Concept

**Pre-conditions**: Chain is in `single` governance mode (Mainnet/Kairos default). The governing node operator controls the node.

**Steps**:

1. The governing node calls the `governance_vote` RPC:
   ```json
   {"method": "governance_vote", "params": ["governance.governingnode", "0x0000000000000000000000000000000000000000"]}
   ```

2. `Vote()` in `api.go` calls `NewVoteData(voter, "governance.governingnode", "0x0000000000000000000000000000000000000000")`.

3. `NewVoteData` runs `addressCanonicalizer` → produces `common.Address{}`. `FormatChecker` returns `true` (it is a `common.Address`). Vote is accepted. [9](#0-8) 

4. `checkConsistency` checks if the **current** governing node is in the council → it is → returns `nil`. No error.

5. The vote is inscribed in `header.Vote` when the governing node proposes a block.

6. At the next epoch block, `getExpectedGovernance` collects the vote and produces `GovData{GovernanceGoverningNode: address(0)}`. `VerifyGov` confirms it matches. The epoch block's `header.Governance` is set. [10](#0-9) 

7. All nodes call `HandleGov`, persisting `GoverningNode = address(0)` to DB and cache.

8. From the next epoch onward, `GetParamSet(N).GoverningNode == address(0)`.

9. Any subsequent `governance_vote` call by any real node fails:
   ```
   if gMode == "single" && voter != gp.GoverningNode {
       return "", ErrVotePermissionDenied  // voter != address(0) always
   }
   ``` [6](#0-5) 

10. Any block containing a `header.Vote` from a real node fails `VerifyVote` with `ErrVotePermissionDenied`. Governance is permanently locked.

func (h *headerGovModule) checkConsistency(blockNum uint64, vote headergov.VoteData) error {

	case gov.GovernanceGoverningNode:

			return err
		}

func (api *headerGovAPI) Vote(name string, value any) (string, error) {
	var (
		voter     = api.h.nodeAddress
		nextBlock = api.h.Chain.CurrentBlock().NumberU64() + 1
		gp        = api.h.GetParamSet(nextBlock)
		gMode     = gp.GovernanceMode
	)

	if gMode == "single" && voter != gp.GoverningNode {
		return "", ErrVotePermissionDenied
	}

	vote := headergov.NewVoteData(voter, name, value)
	if vote == nil {
		return "", ErrInvalidKeyValue
	}

	if gov.DeprecatedAt(vote.Name(), api.h.ChainConfig.Rules(new(big.Int).SetUint64(nextBlock))) {
		return "", ErrDeprecatedVote
	}

	err := api.h.checkConsistency(nextBlock, vote)
	if err != nil {
		return "", err
	}

	// TODO-kaiax: add removevalidator vote check

	api.h.PushMyVotes(vote)
	return "(kaiax) Your vote is prepared. It will be put into the block header or applied when your node generates a block as a proposer. Note that your vote may be duplicate.", nil

func NewVoteData(voter common.Address, name string, value any) VoteData {
	param, ok := gov.Params[gov.ParamName(name)]
	if !ok {
		param, ok = gov.ValidatorParams[gov.ParamName(name)]
		if !ok {
			logger.Error("Invalid vote name", "name", name)
			return nil
		}
	}

	cv, err := param.Canonicalizer(value)
	if err != nil {
		logger.Error("Canonicalize error", "name", name, "value", value, "err", err)
		return nil
	}

	if !param.FormatChecker(cv) {
		logger.Error("Format check error", "name", name, "value", value)
		return nil
	}

	return &voteData{
		voter: voter,
		name:  gov.ParamName(name),
		value: cv,
	}
