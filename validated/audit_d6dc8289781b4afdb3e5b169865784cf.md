### Title
Gasless Swap Deadline Checked Only at Pool Admission, Not at Block-Building Time — Proposer Loses Lent KAIA on Expired Swap Execution - (File: `kaiax/gasless/impl/builder.go`, `kaiax/gasless/impl/tx_pool.go`)

---

### Summary

The `checkBalanceForSwap` function validates `tx.deadline >= currentBlock.Time()` once, at transaction pool admission. `ExtractTxBundles` and `IsExecutable` never re-check the deadline at block-building time. A user can submit a gasless swap transaction with a deadline equal to the current block timestamp, which passes the pool check but is already expired for the next block. The proposer's node generates a `[LendTx, ApproveTx, SwapTx]` bundle, lends KAIA to the user, and the swap reverts on-chain because `GaslessSwapRouter` forwards the deadline to UniswapV2Router02, which enforces `require(deadline >= block.timestamp)`. The proposer's lent KAIA is never repaid.

---

### Finding Description

**Pool admission check (one-time, stale):**

In `kaiax/gasless/impl/tx_pool.go`, `checkBalanceForSwap` performs:

```go
// tx.deadline >= currentTimestamp
deadline := swapArgs.Deadline
if deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
    return fmt.Errorf("insufficient deadline: ...")
}
``` [1](#0-0) 

This check uses `g.Chain.CurrentBlock().Time()` — the timestamp of the **current** block at pool admission. A transaction with `deadline == currentBlock.Time()` passes this check. The next block will have a strictly higher timestamp, so the deadline is already expired when the transaction is included.

**Block-building path — no deadline re-check:**

`ExtractTxBundles` in `kaiax/gasless/impl/builder.go` iterates pending transactions and calls only `g.IsExecutable(approveTxs[addr], tx)`:

```go
} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
    bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
    ...
    bundles = append(bundles, b)
}
``` [2](#0-1) 

`IsExecutable` / `VerifyExecutable` checks nonce ordering, token matching, and repay amount — but **never the deadline**: [3](#0-2) 

**On-chain execution path:**

`GaslessSwapRouter.swapForGas(token, amountIn, minAmountOut, amountRepay, deadline)` accepts the deadline and passes it to UniswapV2Router02 internally. UniswapV2Router02 enforces `require(deadline >= block.timestamp, 'UniswapV2Router: EXPIRED')`. The Go binding confirms the deadline is a live parameter forwarded to the contract: [4](#0-3) 

**Bundle execution order:**

The bundle is `[LendTx (proposer → user), ApproveTx, SwapTx]`. LendTx and ApproveTx execute successfully. SwapTx reverts because the deadline is expired. The proposer's lent KAIA is never repaid. [5](#0-4) 

---

### Impact Explanation

The proposer (block builder) loses KAIA equal to the lend amount. The lend amount covers gas fees for the entire bundle: `(gasLimitLend + gasLimitApprove + gasLimitSwap) × gasPrice`. Based on the integration test parameters (21,000 + 100,000 + 500,000 gas at 50 Gkei), this is approximately 0.031 KAIA per attack. The attack is repeatable with different nonces, allowing a user to drain the proposer's KAIA balance over time. This constitutes an unauthorized transfer of KAIA from the proposer to the attacker (the lent amount is transferred via LendTx and never recovered).

---

### Likelihood Explanation

Any user who can submit a gasless swap transaction can trigger this. The attacker sets `deadline = currentBlock.Time()` (or any value between the current block timestamp and the next block timestamp). The pool check passes because the condition is `deadline < currentBlock.Time()` (strict less-than), so equality passes. The next block's timestamp is always strictly greater, so the deadline is expired at execution time. No special privilege is required. The attack is deterministic and requires only a single transaction submission per lend cycle.

---

### Recommendation

Add a deadline check in `ExtractTxBundles` before generating the lend bundle. The check should compare the swap transaction's decoded deadline against the pending block's expected timestamp (or conservatively against `currentBlock.Time() + 1`):

```go
} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
    swapArgs, ok := decodeSwapTx(tx, g.signer)
    if !ok || swapArgs.Deadline.Cmp(g.Chain.CurrentBlock().Time()) <= 0 {
        // deadline already expired or will expire in next block
        targetTxHash = tx.Hash()
        continue
    }
    bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
    ...
}
```

Additionally, the pool should periodically evict gasless swap transactions whose deadlines have expired (analogous to the existing `evictionInterval` mechanism for queued transactions).

---

### Proof of Concept

1. Observe that `checkBalanceForSwap` uses `g.Chain.CurrentBlock().Time()` for the deadline check (strict `< 0` comparison, so `deadline == currentBlock.Time()` passes).
2. Submit a gasless swap transaction with `deadline = chain.CurrentBlock().Time()` (exactly the current block timestamp). The pool accepts it.
3. The transaction is promoted to pending and picked up by `ExtractTxBundles`, which calls only `IsExecutable` — no deadline check.
4. The proposer generates bundle `[LendTx, ApproveTx, SwapTx]` and includes it in the next block (which has `timestamp > deadline`).
5. `LendTx` executes: proposer transfers KAIA to user.
6. `ApproveTx` executes: user approves token spending.
7. `SwapTx` reverts: `GaslessSwapRouter` → UniswapV2Router02 → `require(deadline >= block.timestamp)` fails.
8. Proposer's lent KAIA is unrecovered. Repeat with nonce+2 to drain further.

The integration test at `tests/gasless_test.go` line 162 sets `deadline = chain.CurrentBlock().Time() + 300`, explicitly avoiding this edge case — confirming the code authors are aware of deadline sensitivity but did not guard the block-building path. [6](#0-5)

func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
```
