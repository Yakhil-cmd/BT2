### Title
Wrong Variable Checked in `GovernanceGoverningNode` Consistency Validation Allows Setting Non-Council Member as Governing Node — (`File: kaiax/gov/headergov/impl/header.go`)

---

### Summary

`checkConsistency` in `kaiax/gov/headergov/impl/header.go` checks whether the **current** governing node (`params.GoverningNode`) is in the council instead of checking whether the **proposed new** governing node (`vote.Value().(common.Address)`) is in the council. This is the direct Kaia analog of the external "wrong account checked" bug class. In single-mode governance (Kaia Mainnet and Kairos), the check is a no-op in normal operation and allows the governing node to ratify a vote that sets any arbitrary address — including a non-council member — as the new governing node, permanently locking the on-chain governance system.

---

### Finding Description

In `checkConsistency`, the `GovernanceGoverningNode` branch reads:

```go
// kaiax/gov/headergov/impl/header.go  lines 159-178
case gov.GovernanceGoverningNode:
    params := h.GetParamSet(blockNum)
    if params.GovernanceMode != "single" {
        return nil
    }
    council, err := h.ValSet.GetCouncil(blockNum - 1)
    if err != nil {
        return err
    }
    if slices.Contains(council, params.GoverningNode) {   // ← WRONG: checks current GN
        return nil
    }
    return ErrGovNodeNotInValSetList
``` [1](#0-0) 

The intent of the guard is to reject a vote whose **proposed value** is not a council member. The correct check is `slices.Contains(council, vote.Value().(common.Address))`. Instead, the code checks `params.GoverningNode` — the **current** governing node — which is always a council member in normal operation, making the guard permanently vacuous.

Contrast this with the correctly-written `AddValidator`/`RemoveValidator` branch immediately below, which correctly uses `vote.Value()`:

```go
case gov.AddValidator, gov.RemoveValidator:
    ...
    if slices.Contains(vote.Value().([]common.Address), params.GoverningNode) {
        return ErrGovNodeInValSetVoteValue
    }
``` [2](#0-1) 

The vote value for `GovernanceGoverningNode` is canonicalized to `common.Address` by `addressCanonicalizer`: [3](#0-2) 

`VerifyVote` calls `checkConsistency` as its final gate after verifying the voter is the block proposer and is in the council: [4](#0-3) 

---

### Impact Explanation

In single-mode governance (the mode used by Kaia Mainnet and Kairos), only the governing node may cast votes post-Permissionless fork. The governing node can cast a `governance.governingnode` vote whose value is any 20-byte address — including `address(0)`, an EOA with no staking, or an attacker-controlled address that is not a council member. Because `checkConsistency` checks the **current** governing node's council membership (always true), `VerifyVote` accepts the block. At the next epoch boundary, `header.Governance` ratifies the vote and the new governing node address takes effect. If the new address is not a validator, no further governance votes can ever be cast (single mode requires the governing node to be the block proposer), permanently freezing all on-chain governance parameters — minting amount, reward ratio, unit price, committee size, validator set, etc.

This matches the allowed impact gate: **governance privilege escalation that changes protected chain state**.

---

### Likelihood Explanation

The governing node is a single entity. No majority-validator collusion is required. The attack requires only that the governing node (or an attacker who has compromised the governing node's key) submit one specially crafted block. The bug is silent — no error is returned, no log is emitted — and there is no existing test covering the case where the vote value is a non-council address.

---

### Recommendation

Replace the wrong-variable check with the vote value:

```go
case gov.GovernanceGoverningNode:
    params := h.GetParamSet(blockNum)
    if params.GovernanceMode != "single" {
        return nil
    }
    council, err := h.ValSet.GetCouncil(blockNum - 1)
    if err != nil {
        return err
    }
    // Check the PROPOSED new governing node, not the current one.
    if slices.Contains(council, vote.Value().(common.Address)) {
        return nil
    }
    return ErrGovNodeNotInValSetList
```

Add a test case:
```go
{desc: "invalid governingnode (not in council)", vote: headergov.NewVoteData(validVoter, string(gov.GovernanceGoverningNode), nonCouncilAddr.Hex()), expectedError: ErrGovNodeNotInValSetList},
```

### Proof of Concept

1. Chain is in single-mode governance; `params.GoverningNode = validVoter`; `council = [validVoter]`.
2. Governing node calls `governance_vote("governance.governingnode", "0xdeadbeef...dead")` where `0xdeadbeef...dead` is not in the council.
3. When the governing node proposes the next block, `PrepareHeader` embeds the vote in `header.Vote`.
4. `VerifyVote` is called by all peers:
   - Voter is in council ✓
   - Voter is the block proposer ✓
   - `checkConsistency`: `slices.Contains(council, params.GoverningNode)` → `slices.Contains([validVoter], validVoter)` → `true` → returns `nil` ✓ (**bug fires here**)
5. At the next epoch block, `VerifyGov` accepts the ratification; `header.Governance = {"governance.governingnode": "0xdeadbeef...dead"}`.
6. From `(epoch+1)*epoch` onward, `GetParamSet` returns `GoverningNode = 0xdeadbeef...dead`.
7. No council member can ever cast a valid vote again (post-Permissionless single mode requires `vote.Voter() == params.GoverningNode`, and `0xdeadbeef...dead` is never the block proposer). Governance is permanently frozen. [5](#0-4)

func (h *headerGovModule) VerifyVote(header *types.Header) error {
	if len(header.Vote) == 0 {
		return nil
	}

	var (
		vb       headergov.VoteBytes = header.Vote
		blockNum                     = header.Number.Uint64()
	)

	vote, err := vb.ToVoteData()
	if err != nil {
		logger.Error("ToVoteData error", "num", blockNum, "vote", vb, "err", err)
		return err
	}

	if gov.DeprecatedAt(vote.Name(), h.ChainConfig.Rules(header.Number)) {
		logger.Error("Vote is deprecated", "num", blockNum, "name", vote.Name())
		return ErrDeprecatedVote
	}

	council, err := h.ValSet.GetCouncil(blockNum)
	if err != nil {
		return err
	}

	// check if the voter is in council
	if !slices.Contains(council, vote.Voter()) {
		return ErrInvalidKeyValue
	}

	// check if Voter is the block proposer.
	author, err := h.Chain.Sealer().Author(header)
	if err != nil {
		return err
	}
	if author != vote.Voter() {
		return ErrInvalidVoter
	}

	// In single mode, only the governing node can write header.Vote after Permissionless.
	params := h.GetParamSet(blockNum)
	if h.ChainConfig.IsPermissionlessForkEnabled(new(big.Int).SetUint64(blockNum)) &&
		params.GovernanceMode == "single" &&
		vote.Voter() != params.GoverningNode {
		return ErrVotePermissionDenied
	}

	return h.checkConsistency(blockNum, vote)
}
