No size limits exist anywhere in the OCI attestation-fetching path, and no bounded reader is used before `io.ReadAll`.

### Title
Unbounded memory growth via attacker-controlled OCI referrers index and layer blobs in `GetAttestations` - ([File: pkg/cmd/attestation/artifact/oci/client.go])

### Summary
`LiveClient.GetAttestations` iterates over every entry in `refManifest.Manifests` returned by the registry's referrers API and, for each entry matching the sigstore bundle artifact type, calls `io.ReadAll(layer0)` on the uncompressed layer with no byte cap and no limit on the number of iterations. An attacker who controls the referrers index/layers for a publicly reachable registry artifact (e.g. via `gh attestation verify --bundle-from-oci` against an attacker-hosted or attacker-influenced image) can supply many entries and/or very large layer blobs to force the victim's `gh` process to allocate unbounded memory.

### Finding Description
In [1](#0-0) , `GetAttestations` calls `remote.Referrers` and then loops over `refManifest.Manifests` without bounding the number of entries processed. For each entry whose `ArtifactType` has the sigstore bundle prefix, it fetches the referrer image, gets its first layer, and reads the entire uncompressed layer into memory via `io.ReadAll(layer0)` at [2](#0-1) . There is no per-blob size cap (e.g. `io.LimitReader`), no total memory/byte budget across all processed manifests, and no cap on the number of manifests processed from the referrers index. Since the referrers index and its referenced blobs are served by the registry the victim points `gh` at (attacker-controlled per the threat model — "controls responses from a host the victim points gh at" / a public registry image the attacker owns), the attacker fully controls both the count of manifests and the size of each layer blob returned. Repeatedly pointing `refDesc.Digest` at the same huge blob, or supplying hundreds/thousands of referrer entries each with large layers, causes the victim's `gh` process to buffer arbitrarily large amounts of data in memory across the loop iterations, since none of the earlier buffers are needed after unmarshalling but nothing prevents concurrent/serial huge allocations exhausting available memory. No existing validation (host allowlist, safeurl, size checks) mitigates this in the attestation OCI fetch path.

### Impact Explanation
This maps to a resource-exhaustion / local denial-of-service impact on the victim's machine while running an ordinary verification command (`gh attestation verify --bundle-from-oci`) against attacker-supplied/attacker-controlled artifact metadata. It does not achieve code execution, credential exfiltration, or file write outside intended paths, but it does allow an unprivileged attacker (who merely needs to publish/control a registry image the victim is induced to verify) to cause memory exhaustion, crashing the `gh` process or degrading the host, purely through crafted registry responses.

### Likelihood Explanation
Feasible and repeatable: the attacker only needs to host or control a public OCI image with a large/malicious referrers index (well within reach of "attacker controls referrers index size/content for a public registry image", satisfying the unprivileged-attacker threat model). Every invocation of `gh attestation verify --bundle-from-oci` against that image triggers the same unbounded read path deterministically.

### Recommendation
Bound resource consumption in `GetAttestations`: (1) cap the number of `refManifest.Manifests` entries processed (or the total number of sigstore-bundle-typed entries), (2) replace `io.ReadAll(layer0)` with a size-limited read (e.g., `io.ReadAll(io.LimitReader(layer0, maxBundleSize))` and reject/error if the layer exceeds a reasonable maximum bundle size, e.g. a few MB), and (3) enforce an aggregate byte budget across all processed attestations in a single `GetAttestations` call.

### Proof of Concept
Go test using `httpmock`/a stub OCI registry (or a fake `remote.Referrers` transport):
1. Serve a referrers index (`refManifest.Manifests`) containing e.g. 500 entries, each with `ArtifactType` = `application/vnd.dev.sigstore.bundle.v0.3+json` and `Digest` pointing to the same manifest digest.
2. That manifest resolves (via `remote.Image`) to a single layer whose uncompressed content is, e.g., 200MB of filler bytes (or a small `bundle.Bundle` JSON padded to that size, expecting `UnmarshalJSON` to fail after allocation — the DoS occurs regardless of JSON validity since `io.ReadAll` fully buffers first).
3. Call `LiveClient.GetAttestations(ref, digest)` and observe/measure process RSS growth scaling with `500 * 200MB` (~100GB) or, for a more portable assertion, instrument via a wrapped reader that tracks total bytes read and assert no cap is applied (bytes read == 500*layerSize) rather than actually allocating that much memory in CI.
4. Assert expected fix behavior: `GetAttestations` should return an error (e.g., "referrer layer exceeds maximum allowed size" or "too many referrer entries") well before consuming that much memory, and the wrapped-reader byte count should be bounded by a constant regardless of attacker-supplied entry count/size.

func (c LiveClient) GetAttestations(ref name.Reference, digest string) ([]*api.Attestation, error) {
	attestations := make([]*api.Attestation, 0)

	transportOpts := []remote.Option{remote.WithAuthFromKeychain(authn.DefaultKeychain)}
	referrers, err := remote.Referrers(ref.Context().Digest(digest), transportOpts...)
	if err != nil {
		return attestations, fmt.Errorf("error getting referrers: %w", err)
	}
	refManifest, err := referrers.IndexManifest()
	if err != nil {
		return attestations, fmt.Errorf("error getting referrers manifest: %w", err)
	}

	for _, refDesc := range refManifest.Manifests {
		if !strings.HasPrefix(refDesc.ArtifactType, "application/vnd.dev.sigstore.bundle") {
			continue
		}

		refImg, err := remote.Image(ref.Context().Digest(refDesc.Digest.String()), remote.WithAuthFromKeychain(authn.DefaultKeychain))
		if err != nil {
			return attestations, fmt.Errorf("error getting referrer image: %w", err)
		}
		layers, err := refImg.Layers()
		if err != nil {
			return attestations, fmt.Errorf("error getting referrer image: %w", err)
		}

		if len(layers) > 0 {
			layer0, err := layers[0].Uncompressed()
			if err != nil {
				return attestations, fmt.Errorf("error getting referrer image: %w", err)
			}
			defer layer0.Close()

			bundleBytes, err := io.ReadAll(layer0)

			if err != nil {
				return attestations, fmt.Errorf("error getting referrer image: %w", err)
			}

			b := &bundle.Bundle{}
			err = b.UnmarshalJSON(bundleBytes)

			if err != nil {
				return attestations, fmt.Errorf("error unmarshalling bundle: %w", err)
			}

			a := api.Attestation{Bundle: b}
			attestations = append(attestations, &a)
		} else {
			return attestations, fmt.Errorf("error getting referrer image: no layers found")
		}
	}
	return attestations, nil
