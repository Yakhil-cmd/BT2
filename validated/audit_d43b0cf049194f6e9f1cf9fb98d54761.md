### Title
`flash_position` lets borrowers open leveraged debt without the `multiply` strategy fee - (File: `contracts/controller/src/strategies/flash_position.rs`)

### Summary
An unprivileged user can reproduce `multiply`’s economically equivalent borrow-and-collateralize flow through `flash_position`, but `flash_position` deliberately invokes the pool with `charge_fee = false`. Because the receiver is caller-selected and may swap the borrowed asset externally before returning collateral to the controller, any positive `flashloan_fee` configured for strategy borrowing can be bypassed without privileged access. [1](#0-0) [2](#0-1) 

### Finding Description
`multiply` mints debt through `borrow_into_controller(..., true, ...)`, which causes `create_strategy` to withhold `flashloan_fee` as protocol revenue before forwarding the proceeds. [3](#0-2) [4](#0-3) 

`flash_position` mints the same kind of account debt through `borrow_into_controller(..., false, ...)`, forwards the full measured receipt to an attacker-controlled WASM receiver, invokes `execute_flash_position`, and deposits measured collateral returned to the controller. [5](#0-4) [6](#0-5) 

The pool honors `charge_fee = false` by returning a zero fee, while still minting debt for the full requested principal and debiting only `amount - fee`. [7](#0-6) [8](#0-7) 

The account cannot simply disappear with the borrowed assets: the transaction must leave nonzero debt in the flashed market plus collateral and pass the same post-operation solvency gates. [9](#0-8) [10](#0-9) [11](#0-10) 

### Impact Explanation
Every borrower who would otherwise use `multiply` can retain the entire strategy fee by executing the swap inside their own flash-position receiver rather than through the configured router. For a positive `flashloan_fee`, the skipped amount is neither transferred to the user as a separate rebate nor booked through `add_protocol_revenue`; the user simply receives `amount` instead of `amount - fee`, causing a repeatable loss of expected protocol revenue proportional to borrowed principal. [4](#0-3) [12](#0-11) 

### Likelihood Explanation
The path requires only caller authentication, an active flashloanable debt market, a caller-controlled WASM contract implementing `execute_flash_position`, and enough resulting collateral to satisfy ordinary solvency checks. [13](#0-12) [14](#0-13) 

No privileged call, leaked key, oracle manipulation, or special market state is required; the bypass can be used whenever `multiply` would otherwise be viable. [15](#0-14) 

### Recommendation
Charge the same strategy-opening fee in `flash_position` by passing `charge_fee = true` to `borrow_into_controller`, or add an equivalent fee parameter to the `execute_flash_position` settlement. If fee-free flash positions are intentionally required, prevent them from reproducing the `multiply` opening path—for example by restricting acceptable receivers/routes or otherwise distinguishing callback-created collateralization from router-created leverage—while preserving atomic unwind behavior. [16](#0-15) [17](#0-16) 

### Proof of Concept
1. Configure a market with `is_flashloanable = true` and `flashloan_fee > 0`; a direct `multiply` call borrows `A` but receives only `A - fee` for swapping into collateral. [2](#0-1) [18](#0-17) 
2. The borrower calls `flash_position(caller, 0, spoke_id, PositionMode::Multiply, debt, A, receiver, data, collaterals, refund_assets)` with `receiver` set to their deployed contract. [19](#0-18) 
3. The controller calls `create_strategy` with `charge_fee = false`, so the pool mints `A` of debt and transfers the full `A` to the controller rather than retaining a fee. [20](#0-19) [7](#0-6) 
4. The controller forwards the measured full amount to `receiver` and invokes `execute_flash_position`. [21](#0-20) [14](#0-13) 
5. Inside the callback, `receiver` swaps the debt asset into the desired collateral on an external venue and transfers at least the listed `min_amount` of that collateral back to the controller. [6](#0-5) 
6. The controller deposits those measured receipts, leaves the flashed debt open, and finalizes only if the account is solvent; the resulting debt-plus-collateral account pays no `flashloan_fee`, unlike the equivalent `multiply` route. [22](#0-21) [23](#0-22)

pub(crate) fn process_flash_position(
    env: &Env,
    caller: &Address,
    params: FlashPositionParams<'_>,
) -> u64 {
    require_authorized_caller(env, caller);

    let FlashPositionParams {
        account_id,
        spoke_id,
        mode,
        debt,
        amount,
        receiver,
        data,
        collaterals,
        refund_assets,
    } = params;

    require_positive_amount(env, amount);
    config::require_hub_active(env, debt.hub_id);
    assert_with_error!(
        env,
        matches!(
            mode,
            PositionMode::Multiply | PositionMode::Long | PositionMode::Short
        ),
        CollateralError::InvalidPositionMode
    );
    require_wasm_receiver(env, receiver);

    let controller = env.current_contract_address();
    assert_with_error!(
        env,
        *receiver != controller,
        FlashLoanError::InvalidFlashloanReceiver
    );

    let mut cache = Context::new(env);
    let pool_addr = cache.cached_pool_address();
    assert_with_error!(
        env,
        *receiver != pool_addr,
        FlashLoanError::InvalidFlashloanReceiver
    );
    // Caller-selected receivers require flash loans enabled; multiply uses
    // the configured router and does not require this flag.
    assert_with_error!(
        env,
        cache.cached_pool_sync_data(debt).params.is_flashloanable,
        FlashLoanError::FlashloanNotEnabled
    );

/// Mints fee-free debt, verifies the controller receipt against the pool result,
/// then forwards it and returns the receiver's measured receipt.
fn mint_and_forward(
    env: &Env,
    account: &mut Account,
    debt: &HubAssetKey,
    amount: i128,
    receiver: &Address,
    cache: &mut Context,
) -> i128 {
    let controller = env.current_contract_address();
    let before = token::Client::new(env, &debt.asset).balance(&controller);

    let reported = borrow_into_controller(
        env,
        account,
        debt,
        amount,
        false,
        PositionAction::FlashPos,
        cache,
    );

    let measured = balance_delta_since(env, &debt.asset, &controller, before);
    assert_with_error!(env, measured == reported, GenericError::InternalError);
    assert_with_error!(env, measured > 0, GenericError::AmountMustBePositive);

    let forwarded = transfer_amount_measured(
        env,
        &debt.asset,
        &controller,
        receiver,
        measured,
        GenericError::AmountMustBePositive,
    );
    assert_with_error!(env, forwarded > 0, GenericError::AmountMustBePositive);
    forwarded

fn collect_collateral_deposits(
    env: &Env,
    controller: &Address,
    collaterals: &Vec<(HubAssetKey, i128)>,
    before: &Map<Address, i128>,
) -> Vec<(HubAssetKey, i128)> {
    let mut deposits: Vec<(HubAssetKey, i128)> = Vec::new(env);
    for (hub_asset, min_amount) in collaterals.iter() {
        let baseline = before
            .get(hub_asset.asset.clone())
            .unwrap_or_else(|| panic_with_error!(env, GenericError::InternalError));
        let delta = balance_delta_since(env, &hub_asset.asset, controller, baseline);
        assert_with_error!(
            env,
            delta >= min_amount,
            StrategyError::CollateralMinimumNotMet
        );
        if delta > 0 {
            deposits.push_back((hub_asset, delta));
        }
    }
    assert_with_error!(
        env,
        !deposits.is_empty(),
        StrategyError::CollateralMinimumNotMet
    );
    deposits

/// Computes the strategy fee from `flashloan_fee` bps when `charge_fee` is true;
/// returns 0 otherwise (does not consult the market flash-loan enable flag).
///
/// Panics if the fee would exceed principal when charging.
fn compute_fee(env: &Env, cache: &Cache, amount: i128, charge_fee: bool) -> i128 {
    if !charge_fee {
        return 0;
    }
    let fee = Bps::from(i128::from(cache.params().flashloan_fee)).flash_loan_fee_on(env, amount);
    assert_with_error!(env, fee <= amount, FlashLoanError::StrategyFeeExceeds);
    fee
