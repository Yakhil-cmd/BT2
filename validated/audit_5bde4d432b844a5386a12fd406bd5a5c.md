### Title
Unauthenticated `ServiceChainParentChainInfoResponseMsg` Allows Any Bridge Peer to Corrupt the Parent Operator Nonce, Permanently Stalling Bridge Transfers — (`node/sc/sub_bridge_handler.go`)

---

### Summary

`SubBridgeHandler.handleParentChainInfoResponseMsg` unconditionally overwrites the parent-chain operator nonce with the value supplied in a `ServiceChainParentChainInfoResponseMsg` P2P message. The only admission check is a P2P handshake that verifies network-ID and chain-ID — both public values. Any peer that passes this handshake can send a crafted response carrying an arbitrary nonce, permanently corrupting the nonce used to sign every subsequent bridge transaction and stalling all cross-chain value transfers.

---

### Finding Description

`SubBridgeHandler.HandleMainMsg` dispatches `ServiceChainParentChainInfoResponseMsg` directly to `handleParentChainInfoResponseMsg`: [1](#0-0) 

Inside that handler, the decoded `pcInfo.Nonce` is written to the parent operator account through three code paths — none of which validate the received value against the actual on-chain nonce: [2](#0-1) 

The three paths are:

| Condition | Action |
|---|---|
| `poolNonce > 0` and `poolNonce < pcInfo.Nonce` | `setParentOperatorNonce(pcInfo.Nonce)` — attacker-controlled |
| `poolNonce == 0` and `currentNonce > pcInfo.Nonce` | `setParentOperatorNonce(pcInfo.Nonce)` — **decreases** nonce |
| `poolNonce == 0` and `currentNonce <= pcInfo.Nonce` | `setParentOperatorNonce(pcInfo.Nonce)` — attacker-controlled |

`setParentOperatorNonce` has no bounds or sanity check: [3](#0-2) 

The same message also overwrites `remoteGasPrice` and the KIP-71 config via `setRemoteChainValues`: [4](#0-3) 

The peer admission check performed in `SubBridge.handle` only verifies network-ID, protocol version, and chain-ID — all public values: [5](#0-4) 

The handshake itself: [6](#0-5) 

There is no cryptographic proof that the responding peer is the legitimate parent-chain node. The sub-bridge accepts the message from any peer that passes the handshake, including an attacker who connects to the sub-bridge's P2P port.

The corrupted nonce is then embedded in every new bridge transaction: [7](#0-6) 

---

### Impact Explanation

The parent operator nonce is the sole sequencing key for all bridge transactions (value transfers and chain-data anchoring). Setting it to `math.MaxUint64` causes every subsequently generated transaction to carry a nonce that the parent chain will reject as too high. Setting it to a value below the current on-chain nonce causes rejection as too low. In either case:

- **Value-transfer transactions** stall; VT recovery will keep retrying with the same wrong nonce.
- **Anchoring transactions** are permanently lost — the code explicitly notes there is no automatic retry mechanism for anchoring: [8](#0-7) 

The bridge is permanently halted until an operator manually restarts the sub-bridge node and re-syncs the nonce. This constitutes persistent corruption of bridge-operator nonce state that breaks cross-chain transfers — a direct match for the "key/nonce consumption affecting bridged assets" impact gate.

---

### Likelihood Explanation

The attacker needs only to:

1. Discover the sub-bridge's P2P endpoint (standard Kaia P2P port, typically public).
2. Connect using the `servicechain/2` protocol with the correct `NetworkId` and `ChainID` (both public).
3. Send one well-formed `ServiceChainParentChainInfoResponseMsg` RLP message with `Nonce = math.MaxUint64`.

No privileged access, no validator key, and no majority collusion is required. The attack is a single unsolicited P2P message.

---

### Recommendation

1. **Authenticate the source**: Only accept `ServiceChainParentChainInfoResponseMsg` from peers whose identity has been cryptographically verified as the configured parent-chain operator address (e.g., via ECDSA-signed challenge during handshake).
2. **Validate the received nonce**: Before applying `pcInfo.Nonce`, verify it against the actual on-chain nonce fetched from the parent chain's RPC/state. Reject values that deviate beyond a safe threshold.
3. **Rate-limit nonce updates**: Accept at most one nonce update per sync cycle; ignore unsolicited responses.
4. **Bound-check the nonce**: Reject any `pcInfo.Nonce` that is higher than `currentNonce + maxPendingTxs` or lower than `currentNonce - 1`.

---

```go
func (sbh *SubBridgeHandler) handleParentChainInfoResponseMsg(p BridgePeer, msg p2p.Msg) error {
	var pcInfo parentChainInfo
	if err := msg.Decode(&pcInfo); err != nil {
		logger.Error("failed to decode", "err", err)
		return errResp(ErrDecode, "msg %v: %v", msg, err)
	}
	sbh.LockParentOperator()
	defer sbh.UnLockParentOperator()

	poolNonce := sbh.subbridge.bridgeTxPool.GetMaxTxNonce(sbh.GetParentOperatorAddr())
	if poolNonce > 0 {
		poolNonce += 1
		// just check
		if sbh.getParentOperatorNonce() > poolNonce {
			logger.Error("parent chain operator nonce is bigger than the chain pool nonce.", "BridgeTxPoolNonce", poolNonce, "mainChainAccountNonce", sbh.getParentOperatorNonce())
		}
		if poolNonce < pcInfo.Nonce {
			// BridgeTxPool journal miss txs which already sent to parent-chain
			logger.Error("chain pool nonce is less than the parent chain nonce.", "chainPoolNonce", poolNonce, "receivedNonce", pcInfo.Nonce)
			sbh.setParentOperatorNonce(pcInfo.Nonce)
		} else {
			// BridgeTxPool journal has txs which don't receive receipt from parent-chain
			sbh.setParentOperatorNonce(poolNonce)
		}
	} else if sbh.getParentOperatorNonce() > pcInfo.Nonce {
		logger.Error("parent chain operator nonce is bigger than the received nonce.", "mainChainAccountNonce", sbh.getParentOperatorNonce(), "receivedNonce", pcInfo.Nonce)
		sbh.setParentOperatorNonce(pcInfo.Nonce)
	} else {
		// there is no tx in bridgetTxPool, so parent-chain's nonce is used
		sbh.setParentOperatorNonce(pcInfo.Nonce)
	}
	sbh.setParentOperatorNonceSynced(true)
	sbh.setRemoteChainValues(pcInfo)
	logger.Info("ParentChainNonceResponse", "receivedNonce", pcInfo.Nonce, "gasPrice", pcInfo.GasPrice, "mainChainAccountNonce", sbh.getParentOperatorNonce())
	return nil
```

```go
func (sb *SubBridge) handle(p BridgePeer) error {
	// Ignore maxPeers if this is a trusted peer
	if sb.peers.Len() >= sb.maxPeers && !p.GetP2PPeer().Info().Networks[p2p.ConnDefault].Trusted {
		return p2p.DiscTooManyPeers
	}
	p.GetP2PPeer().Log().Debug("Kaia peer connected", "name", p.GetP2PPeer().Name())

	// Execute the handshake
	var (
		head   = sb.blockchain.CurrentHeader()
		hash   = head.Hash()
		number = head.Number.Uint64()
		td     = sb.blockchain.GetTd(hash, number)
	)

	err := p.Handshake(sb.networkId, sb.getChainID(), td, hash)
	if err != nil {
		p.GetP2PPeer().Log().Debug("Kaia peer handshake failed", "err", err)
		fmt.Println(err)
		return err
	}

	// Register the peer locally
	if err := sb.peers.Register(p); err != nil {
		// if starting node with unlock account, can't register peer until finish unlock
		p.GetP2PPeer().Log().Info("Kaia peer registration failed", "err", err)
		fmt.Println(err)
		return err
	}
	defer sb.removePeer(p.GetID())

	sb.handler.RegisterNewPeer(p)

	p.GetP2PPeer().Log().Info("Added a P2P Peer", "peerID", p.GetP2PPeerID())

	// main loop. handle incoming messages.
	for {
		if err := sb.handleMsg(p); err != nil {
			p.GetP2PPeer().Log().Debug("Kaia message handling failed", "err", err)
			return err
		}
	}
```

```go
func (p *baseBridgePeer) readStatus(network uint64, status *statusData) error {
	msg, err := p.rw.ReadMsg()
	if err != nil {
		return err
	}
	if msg.Code != StatusMsg {
		return errResp(ErrNoStatusMsg, "first msg has code %x (!= %x)", msg.Code, StatusMsg)
	}
	if msg.Size > ProtocolMaxMsgSize {
		return errResp(ErrMsgTooLarge, "%v > %v", msg.Size, ProtocolMaxMsgSize)
	}
	// Decode the handshake and make sure everything matches
	if err := msg.Decode(&status); err != nil {
		return errResp(ErrDecode, "msg %v: %v", msg, err)
	}
	if status.NetworkId != network {
		return errResp(ErrNetworkIdMismatch, "%d (!= %d)", status.NetworkId, network)
	}
	if int(status.ProtocolVersion) != p.version {
		return errResp(ErrProtocolVersionMismatch, "%d (!= %d)", status.ProtocolVersion, p.version)
	}
	return nil
}
```
