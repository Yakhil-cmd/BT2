### Title
Unvalidated P2P-Delivered StakingInfo Accepted Into Reward-Distribution Database — (`datasync/downloader/queue.go`)

---

### Summary

`DeliverStakingInfos` in `queue.go` accepts `P2PStakingInfo` objects from remote peers during block sync and stores them in the local database with a `validate` function that unconditionally returns `nil`. The stored staking info is later used—without re-reading from state—to compute KAIA block rewards and treasury fund allocations. A malicious peer can inject fabricated staking info (altered reward addresses, inflated staking amounts, or redirected KEF/KIF addresses) that the victim node will use verbatim for reward distribution.

---

### Finding Description

During full-sync (pre-Kaia hardfork), the downloader fetches `StakingInfo` from peers and delivers it through `queue.DeliverStakingInfos`: [1](#0-0) 

The `validate` callback—which in every other delivery path checks the data against the block header—is a deliberate no-op here, explicitly marked with a `TODO`: [2](#0-1) 

Compare this to `DeliverReceipts`, which validates the receipt root against `header.ReceiptHash` before accepting data: [3](#0-2) 

The accepted staking info is written directly to the database in the recovery path as well, with only a `BlockNum` ordering check and no content validation: [4](#0-3) 

`GetStakingInfo` then reads from the database first (before Kaia HF), bypassing state verification entirely: [5](#0-4) 

The staking info read from DB is passed directly into `assignStakingRewards` / `assignStakingRewardsFlex`, which compute per-address KAIA reward allocations: [6](#0-5) 

The `RewardAddrs`, `StakingAmounts`, `KEFAddr`, and `KIFAddr` fields from the fabricated `StakingInfo` are used without any cross-check against the actual on-chain state: [7](#0-6) 

---

### Impact Explanation

A malicious peer can send a `P2PStakingInfo` response with:
- **Altered `CouncilRewardAddrs`**: redirects validator block rewards to attacker-controlled addresses.
- **Inflated `CouncilStakingAmounts`**: gives one validator a disproportionate share of staking rewards.
- **Replaced `KEFAddr` / `KIFAddr`**: redirects treasury fund allocations (KEF, KIF) to attacker addresses.

The victim node stores this in its database and uses it for every block in the affected staking interval (up to `StakingUpdateInterval` = 86,400 blocks on mainnet), causing systematic misdirection of minted KAIA and fee distributions.

---

### Likelihood Explanation

- Trigger requires only a network-level peer connection during sync—no validator key, no majority collusion, no privileged access.
- The `TODO-Kaia-Snapsync update validation logic` comment confirms the gap is known and unresolved.
- The attack surface is the pre-Kaia hardfork sync path, which is exercised by any node syncing historical blocks or recovering staking info via `SyncStakingInfo`.

---

### Recommendation

Implement content validation in `DeliverStakingInfos` analogous to `DeliverReceipts`. The correct approach is to re-derive the staking info from the block's state root and compare it against the peer-supplied data before writing to the database:

```go
validate := func(index int, header *types.Header) error {
    si := stakingInfoList[index]
    // Re-derive from state and compare
    expected, err := s.getFromStateByNumber(si.BlockNum)
    if err != nil {
        return err
    }
    if !stakingInfoEqual(expected, staking.ToStakingInfo(si)) {
        return errInvalidStakingInfo
    }
    return nil
}
```

Alternatively, at minimum, verify that the `BlockNum` in the delivered `P2PStakingInfo` matches the canonical block hash and that the staking amounts are consistent with the staking contract balances recorded in the block's state root.

---

### Proof of Concept

1. Attacker runs a Kaia node and connects as a peer to a victim syncing pre-Kaia blocks.
2. When the victim sends a `StakingInfoRequestMsg`, the attacker responds with a `StakingInfoMsg` containing a `P2PStakingInfo` where `CouncilRewardAddrs[0]` is replaced with an attacker-controlled address and `CouncilStakingAmounts[0]` is set to `math.MaxUint64`.
3. `handleStakingInfoMsg` on the victim decodes and delivers this to `downloader.DeliverStakingInfos`: [8](#0-7) 

4. `queue.DeliverStakingInfos` calls `validate(...)` which returns `nil` unconditionally, and the fabricated info is stored in `result.StakingInfo`.
5. `PostInsertBlock` calls `GetStakingInfo`, which finds the fabricated entry in the database and returns it without re-reading from state: [9](#0-8) 

6. The reward module calls `GetStakingInfo` and passes the fabricated `StakingInfo` to `getDeferredRewardFull`, which distributes minted KAIA to the attacker's address for every block in the staking interval.

```go
func (s *StakingModule) GetStakingInfo(num uint64) (*staking.StakingInfo, error) {
	isKaia := s.ChainConfig.IsKaiaForkEnabled(new(big.Int).SetUint64(num))
	sourceNum := sourceBlockNum(num, isKaia, s.stakingInterval)

	// Try cache first
	if si, ok := s.stakingInfoCache.Get(sourceNum); ok {
		return si.(*staking.StakingInfo), nil
	}

	// Only before Kaia, try the database
	if !isKaia {
		if si := ReadStakingInfo(s.ChainKv, sourceNum); si != nil {
			s.stakingInfoCache.Add(sourceNum, si)
			return si, nil
		}
	}

	// Read from the state
	si, err := s.getFromStateByNumber(sourceNum)
	if err != nil {
		return nil, err
	}

	// Only before Kaia, write to database
	if !isKaia {
		WriteStakingInfo(s.ChainKv, sourceNum, si)
	}

	// Cache it
	s.stakingInfoCache.Add(sourceNum, si)
	return si, nil
}
```

```go
func assignStakingRewards(config *reward.RewardConfig, stakersReward *big.Int, si *staking.StakingInfo) (map[common.Address]*big.Int, *big.Int) {
	var (
		cns               = si.ConsolidatedNodes()
		minStake          = config.MinimumStake.Uint64()
		totalExcessInt    = uint64(0) // sum of excess stakes (the amount over minStake) over all stakers
		cnTotalStakingMap = make(map[common.Address]uint64)
		isPrague          = config.Rules.IsPrague
	)
	for _, cn := range cns {
		// If the CNStaking is less than minStake, skip it.
		if cn.StakingAmount >= minStake {
			// Calculate total staking amount once
			cnTotalStakingAmount := cn.StakingAmount
			if isPrague && cn.CLStakingInfo != nil {
				cnTotalStakingAmount += cn.CLStakingInfo.CLStakingAmount
			}
			totalExcessInt += cnTotalStakingAmount - minStake
			cnTotalStakingMap[cn.RewardAddr] = cnTotalStakingAmount
		}
	}

	var (
		totalExcess = new(big.Int).SetUint64(totalExcessInt)
		remaining   = new(big.Int).Set(stakersReward)
		alloc       = make(map[common.Address]*big.Int)
	)
	for _, cn := range cns {
		cnTotalStakingAmount := cnTotalStakingMap[cn.RewardAddr]
		if cnTotalStakingAmount > minStake {
			// The KAIA unit will cancel out:
			// reward (kei) = excess (KAIA) * stakersReward (kei) / totalExcess (KAIA)
			excess := new(big.Int).SetUint64(cnTotalStakingAmount - minStake)
			if reward := new(big.Int).Div(new(big.Int).Mul(excess, stakersReward), totalExcess); reward.Sign() > 0 {
				if isPrague && cn.CLStakingInfo != nil {
					// The remaining amount will be added to the cnAmount.
					cnAmount, clAmount := cn.Split(reward)
					alloc[cn.RewardAddr] = cnAmount
					alloc[cn.CLStakingInfo.CLPoolAddr] = clAmount
				} else {
					alloc[cn.RewardAddr] = reward
				}
				remaining.Sub(remaining, reward)
			}
		}
	}
	return alloc, remaining
```

```go
// handleStakingInfoMsg handles staking information response message.
func handleStakingInfoMsg(pm *ProtocolManager, p Peer, msg p2p.Msg) error {
	if pm.chainconfig.Istanbul == nil || pm.chainconfig.Istanbul.ProposerPolicy != uint64(istanbul.WeightedRandom) {
		return errResp(ErrUnsupportedEnginePolicy, "the engine is not istanbul or the policy is not weighted random")
	}

	// A batch of stakingInfos arrived to one of our previous requests
	var stakingInfos []*staking.P2PStakingInfo
	if err := msg.Decode(&stakingInfos); err != nil {
		return errResp(ErrDecode, "msg %v: %v", msg, err)
	}
	// Deliver all to the downloader
	if err := pm.downloader.DeliverStakingInfos(p.GetID(), stakingInfos); err != nil {
		logger.Debug("Failed to deliver staking information", "err", err)
	}
	return nil
```

```go
func (s *StakingModule) PostInsertBlock(block *types.Block) error {
	isKaia := s.ChainConfig.IsKaiaForkEnabled(block.Number())
	if !isKaia {
		// Make sure the staking info for the new block is persisted.
		// The StakingInfo(sourceNum) will be persisted here, even if GetStakingInfo is never called elsewhere.
		if _, err := s.GetStakingInfo(block.NumberU64()); err != nil {
			return err
		}
	}
	return nil
}
```
