### Title
Accrued debt-value overflow permanently freezes all exits for a large market - (File: common/src/rates/index.rs)

### Summary
Interest accrual multiplies total scaled debt by the updated borrow index using bounded `i128` arithmetic, so a sufficiently large borrowed position can make `borrowed * new_borrow_index` exceed `i128::MAX` before the borrow-index cap is reached. [1](#0-0)  Every pool position operation loads the market through `ops::load_leg()`, which invokes `global_sync()` before repayment, withdrawal, borrowing, or liquidation accounting. [2](#0-1)  Once the accrual panics, the affected market cannot process repayments, withdrawals, liquidations, bad-debt cleanup, or parameter updates. [3](#0-2) 

### Finding Description
`calculate_supplier_rewards()` computes both the old and new aggregate debt values before subtracting accrued interest. [1](#0-0)  The borrow index itself is capped only after `update_borrow_index()` computes it, so the index cap does not prevent aggregate debt-value overflow. [4](#0-3)  The protocol explicitly permits up to roughly 170.14 billion whole tokens at 18 decimals before token-to-RAY conversion overflows, and separately acknowledges that accrued market totals may overflow before either index reaches its ceiling. [5](#0-4)  Consequently, a market near the representable RAY limit can enter a state in which every subsequent accrual panics. [6](#0-5) 

### Impact Explanation
This is a permanent freezing-of-funds condition for the affected market. Suppliers cannot withdraw because `withdraw::accounting()` first calls `ops::load_leg()`, which performs the failing accrual. [7](#0-6)  Borrowers cannot repay because `repay::accounting()` follows the same synchronized-market path before burning debt shares. [8](#0-7)  Liquidation and bad-debt cleanup are also blocked because pool seizure synchronizes the market before socializing debt or reclassifying supply. [9](#0-8)  Replacing the rate model does not provide an in-protocol escape because `replace_rate_model()` accrues under the old model before installing the replacement. [10](#0-9) 

### Likelihood Explanation
An unprivileged caller can create the condition only in a market whose configured caps and token supply admit a near-maximum RAY-denominated book. The in-repository scenario uses approximately one billion 18-decimal tokens supplied, approximately 98% borrowed, and sustained high-utilization accrual until aggregate debt exceeds the RAY value domain. [11](#0-10)  The public `update_indexes` path is permissionless apart from caller authorization and forwards the selected market to pool accrual. [12](#0-11)  The requirement of extraordinary liquidity and prolonged high utilization makes the likelihood lower than ordinary liquidation failures, but the resulting market-wide freeze is permanent absent an upgrade or migration.

### Recommendation
Bound scaled debt against the maximum value that can be multiplied by the configured index range, or make accrual saturate at `i128::MAX` instead of panicking. A safer design would split accrual into representable chunks, cap the borrow index at the point where `borrowed * borrow_index` remains representable, and preserve an emergency repay/settlement path that does not require calculating the full overflowing aggregate.

### Proof of Concept
The checked-in reproduction constructs an 18-decimal market, supplies `BILLION * 10^18`, supplies collateral to a borrower, and borrows approximately 98% of the supplied liquidity. [13](#0-12)  It then advances time until `update_indexes` fails with `MATH_OVERFLOW`; the borrow index remains below `MAX_BORROW_INDEX_RAY`, proving the aggregate-value multiplication fails before the index cap protects the market. [14](#0-13)  Subsequent `withdraw` and `repay` calls fail with the same overflow because both operations accrue before modifying the position. [15](#0-14)

/// Applies `interest_factor` to `old_index` to produce the new borrow index,
/// capped at `MAX_BORROW_INDEX_RAY`.
pub fn update_borrow_index(env: &Env, old_index: Ray, interest_factor: Ray) -> Ray {
    let new_index = old_index.mul(env, interest_factor);
    if new_index.raw() > MAX_BORROW_INDEX_RAY {
        return Ray::from(MAX_BORROW_INDEX_RAY);
    }
    new_index
}

pub fn calculate_supplier_rewards(
    env: &Env,
    params: &MarketParams,
    borrowed: Ray,
    new_borrow_index: Ray,
    old_borrow_index: Ray,
) -> (Ray, Ray) {
    let old_total_debt = borrowed.mul(env, old_borrow_index);
    let new_total_debt = borrowed.mul(env, new_borrow_index);

    let accrued_interest = new_total_debt.checked_sub(env, old_total_debt);

    let protocol_fee = params.reserve_factor.apply_to_ray(env, accrued_interest);
    let supplier_rewards = accrued_interest.checked_sub(env, protocol_fee);

/// Loads a market cache and accrues interest through the current ledger time.
pub(crate) fn synced_market(env: &Env, hub_asset: &HubAssetKey) -> Cache {
    let mut cache = Cache::load(env, hub_asset);
    interest::global_sync(env, &mut cache);
    cache
}

/// Renews instance TTL, then loads and accrues the market.
pub(crate) fn renewed_market(env: &Env, hub_asset: &HubAssetKey) -> Cache {
    renew_instance(env);
    synced_market(env, hub_asset)
}

/// Validates `action.amount ≥ 0`, syncs the market, and returns (cache, scaled position).
pub(crate) fn load_leg(env: &Env, action: &PoolAction) -> (Cache, Ray) {
    require_nonneg_amount(env, action.amount);
    let cache = synced_market(env, &action.hub_asset);
    (cache, Ray::from(action.position.scaled_amount))

/// `i128::MAX`, 170 times that. At the XLM curve's steep segment the index
/// grows past 170x in a few years, and the next accrual panics inside
/// `scaled_to_original`. Every verb accrues first, so the market freezes:
/// no repay, no withdraw, no liquidation. The index cap never engages.
#[test]
fn a_whale_market_at_sustained_high_utilization_hits_the_ray_value_ceiling_before_the_index_cap() {
    let mut t = LendingTest::new()
        .with_market(big("BIG18", 18, xlm_curve()))
        .with_market(col())
        .with_max_utilization_disabled_all_markets()
        .build();
    lift_caps(&t, "BIG18", 18);
    lift_caps(&t, "COL", 7);
    let principal = BILLION * 10i128.pow(18);
    t.supply_raw(BOB, "BIG18", principal);
    let debt = principal / 100 * 98;
    t.supply_raw(ALICE, "COL", BILLION * 10_000_000 * 3);
    t.borrow_raw(ALICE, "BIG18", debt);

    let mut years = 0u32;
    let failure = loop {
        years += 1;
        assert!(
            years <= 40,
            "no cliff within 40 years; the bound in docs/reference/formulas.md is wrong"
        );
        t.advance_time(YEAR_SECS);
        if let Err(e) = t.try_update_indexes_for(&["BIG18"]) {
            break e;
        }
    };
    let failed: Result<(), soroban_sdk::Error> = Err(failure);
    assert_contract_error(failed, errors::MATH_OVERFLOW);
    let last = book(&t, "BIG18");
    assert!(
        last.borrow_index < MAX_BORROW_INDEX_RAY,
        "the index cap did not engage before the value overflow"
    );
    // The market is frozen: exits and repayments accrue first and hit the same panic.
    assert_contract_error(t.try_withdraw_raw(BOB, "BIG18", 1), errors::MATH_OVERFLOW);
    assert_contract_error(t.try_repay(ALICE, "BIG18", 1.0), errors::MATH_OVERFLOW);
    std::println!(
        "ray-value cliff reached after {years} years at 98 percent utilization on the XLM curve; last index x{:.1}",
        last.borrow_index as f64 / RAY as f64
    );

pub(crate) fn global_sync(env: &Env, cache: &mut Cache) {
    if !cache.needs_accrual() {
        return;
    }

    let mut remaining = cache.elapsed_ms();
    while let Some(nonzero) = NonZeroU64::new(remaining) {
        let chunk = nonzero.get().min(MAX_COMPOUND_DELTA_MS);
        accrue_chunk(env, cache, chunk);
        remaining = remaining.saturating_sub(chunk);
    }

    cache.mark_accrued();
}

pub(crate) fn accounting(env: &Env, action: &PoolAction) -> RepayOutcome {
    let (mut cache, position) = ops::load_leg(env, action);
    let amount = action.amount;

    let (burned, overpayment) = cache.resolve_repay(amount, position);
    let net_repay = amount
        .checked_sub(overpayment)
        .unwrap_or_else(|| panic_with_error!(env, GenericError::MathOverflow));
    assert_with_error!(
        env,
        net_repay == 0 || burned.raw() > 0,
        GenericError::RepayRoundsToZeroShares
    );

    let position = position.checked_sub(env, burned);
    cache.burn_debt(burned);

    cache.credit_cash(net_repay);
