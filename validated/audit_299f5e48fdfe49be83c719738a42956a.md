The external report's root cause is a classic **asymmetric counter bug**: a counter (`noOfBorrowers`) is incremented only on first entry (`hasDeposited` gate) but decremented unconditionally whenever balance returns to zero, allowing repeated deposit/withdraw cycles by the same account to drift the counter to zero (or underflow) while genuine borrowers still exist — causing DoS on withdrawals and debt-state corruption.

I searched Sui's codebase for structurally similar patterns: object/child counters, accumulator object counts, and borrower/deposit-tracking analogs. The closest conceptual matches are:

- `accumulator_metadata::record_accumulator_object_changes` in `crates/sui-framework/packages/sui-framework/sources/accumulator_metadata.move`, which tracks net accumulator object creation/destruction, but this is guarded by explicit `assert!(*current_count + objects_created >= objects_destroyed, EInvariantViolation)` checks rather than being incremented/decremented via independently-gated code paths. [1](#0-0) 
- The address/object balance accumulator lifecycle, where account existence is tied directly to `balance > 0` vs `balance == 0` transitions (create on first deposit, delete when balance settles to zero), not to an independently-incremented/decremented counter — so there's no separate "hasDeposited" flag that could desync from the actual balance state. [2](#0-1) 
- Post-execution invariant checks (`check_address_balance_changes`) that reconcile every accumulator withdrawal/deposit event against input reservations and PTB-authorized splits/merges, aborting the transaction (`invariant_violation!`) rather than allowing silent state corruption.

fun record_accumulator_object_changes(
    accumulator_root: &mut AccumulatorRoot,
    objects_created: u64,
    objects_destroyed: u64,
) {
    let key = AccumulatorObjectCountKey();
    if (dynamic_field::exists(accumulator_root.id_mut(), key)) {
        let current_count: &mut u64 = dynamic_field::borrow_mut(accumulator_root.id_mut(), key);
        assert!(*current_count + objects_created >= objects_destroyed, EInvariantViolation);
        *current_count = *current_count + objects_created - objects_destroyed;
    } else {
        assert!(objects_created >= objects_destroyed, EInvariantViolation);
        dynamic_field::add(accumulator_root.id_mut(), key, objects_created - objects_destroyed);
    };
}
