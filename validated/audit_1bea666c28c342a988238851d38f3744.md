## Finding: Stack-overflow DoS via unbounded recursive `cloneDeep`/`getSourceString` on unvalidated deeply-nested unit before depth check

### Title
Unbounded recursion in unit-hash computation causes stack-overflow DoS on any posted joint - (File: `validation.js`, `object_hash.js`, `string_utils.js`)

### Summary
`validate()` in [1](#0-0)  computes `objectHash.getUnitHash(objUnit)` on the raw, attacker-controlled `objUnit` **before** the node performs any nesting-depth/size validation. The depth guard `isTooDeeplyNestedOrHasTooManyNodes(objUnit)` only runs afterwards, at [2](#0-1) . This mirrors the SnakeYAML bug class (CVE-2022-38750): recursive processing of untrusted nested input with no depth bound, executed prior to any mitigation, leading to a stack-overflow crash.

### Finding Description
`getUnitHash` calls `getStrippedUnit` → `getUnitContentHash` → `getNakedUnit`, and `getNakedUnit` performs `var objNakedUnit = _.cloneDeep(objUnit);` **before** stripping message payloads: [3](#0-2) . Lodash's `cloneDeep` recurses once per nesting level of the input object with no depth limit, so it walks the full untrusted `objUnit` — including arbitrarily deep `messages[i].payload` content — prior to the payload being deleted.

Separately, even once payload hashes are checked later in the same function (`getPayloadForHash` → `objectHash.getBase64Hash` → `getSourceString`/`getJsonSourceString`), those functions are themselves naive unbounded recursive tree-walkers: [4](#0-3)  (`getSourceString`/`extractComponents`) and [5](#0-4)  (`getJsonSourceString`/`stringify`).

The only protection against deep nesting, `isTooDeeplyNestedOrHasTooManyNodes`, is applied at [2](#0-1)  — strictly after the vulnerable `getUnitHash` call at line 133 and, notably, also after `_.cloneDeep` has already recursed to unbounded depth. Since JavaScript recursion depth (and lodash's internal stack usage) is bounded by the V8 call stack, a sufficiently deep nested object (e.g., tens of thousands of nested arrays/objects) supplied inside a posted unit's message payload will overflow the stack and crash the Node.js process handling `validate()`, before the mitigation check has a chance to reject the unit.

### Impact Explanation
Any unprivileged party able to post a unit/joint to the network (a normal wallet or light client submitting a transaction) can trigger this code path via `validate(objJoint, ...)`, which is the first-line validation entry point for every incoming unit. A crafted joint with deep nesting in `unit.messages[i].payload` causes a stack overflow and process crash in any full node that receives and validates it, which is a network-wide denial of service — nodes crash repeatedly on relay/re-broadcast of the malicious unit, matching the "network unable to confirm new units" impact criterion.

### Likelihood Explanation
High likelihood: `validate()` is invoked on every joint received from peers/light clients with no prior gating, `objUnit` is fully attacker-controlled JSON, and `_.cloneDeep`/`getSourceString`/`getJsonSourceString` have no depth limiting of their own. Constructing a deeply nested JSON payload (e.g., `{"a":{"a":{"a": ... }}}` thousands of levels deep) is trivial.

### Recommendation
Perform the `isTooDeeplyNestedOrHasTooManyNodes` (and general size) check on `objUnit`/`objJoint` **before** any hash computation (`objectHash.getUnitHash`, `getBase64Hash`, `getPayloadForHash`) is invoked — i.e., move the check in [2](#0-1)  ahead of line 133. Additionally, harden `getNakedUnit`'s use of `_.cloneDeep` (or the shared `cloneDeep` in `string_utils.js`) and `getSourceString`/`getJsonSourceString`/`extractComponents`/`stringify` with an explicit recursion-depth limit, so they fail fast on pathological input rather than relying solely on a caller-side pre-check that can be bypassed by reordering or by other callers (e.g., `getDeviceMessageHashToSign`, `private_profile.js`) that hash untrusted objects without first calling the depth-limit check.

### Proof of Concept
1. Construct a unit joint whose `unit.messages[0].payload` contains a deeply nested structure, e.g. programmatically build `payload = {}` and nest it 50,000 levels deep (`payload.a.a.a...`), while otherwise keeping the joint minimally well-formed enough to pass the early string/type checks that precede line 133 (unit is object, `objUnit.unit` present, `isStringOfLength`).
2. Submit this joint to a node via the standard "new joint" path that calls `validation.js`'s `validate(objJoint, callbacks)`.
3. `objectHash.getUnitHash(objUnit)` (line 133) triggers `getNakedUnit` → `_.cloneDeep(objUnit)`, which recurses into the deeply nested payload before it is stripped, exhausting the call stack (`RangeError: Maximum call stack size exceeded`) and crashing/hanging the validating process — reproducing the DoS pattern described in CVE-2022-38750 but against ocore's own recursive object utilities instead of SnakeYAML.

```javascript
function getSourceString(obj) {
	var arrComponents = [];
	function extractComponents(variable){
		if (variable === null)
			throw Error("null value in "+JSON.stringify(obj));
		switch (typeof variable){
			case "string":
				if (variable.includes(STRING_JOIN_CHAR))
					throw Error("00 byte in string value in " + JSON.stringify(obj));
				arrComponents.push("s", variable);
				break;
			case "number":
				if (!isFinite(variable))
					throw Error("invalid number: " + variable);
				arrComponents.push("n", variable.toString());
				break;
			case "boolean":
				arrComponents.push("b", variable.toString());
				break;
			case "object":
				if (Array.isArray(variable)){
					if (variable.length === 0)
						throw Error("empty array in "+JSON.stringify(obj));
					arrComponents.push('[');
					for (var i=0; i<variable.length; i++)
						extractComponents(variable[i]);
					arrComponents.push(']');
				}
				else{
					var keys = Object.keys(variable).sort();
					if (keys.length === 0)
						throw Error("empty object in "+JSON.stringify(obj));
					keys.forEach(function(key){
						if (typeof variable[key] === "undefined")
							throw Error("undefined at "+key+" of "+JSON.stringify(obj));
						if (key.includes(STRING_JOIN_CHAR))
							throw Error("00 byte in object key in " + JSON.stringify(obj));
						arrComponents.push(key);
						extractComponents(variable[key]);
					});
				}
				break;
			default:
				throw Error("getSourceString: unknown type="+(typeof variable)+" of "+variable+", object: "+JSON.stringify(obj));
		}
	}

	extractComponents(obj);
	return arrComponents.join(STRING_JOIN_CHAR);
```

```javascript
function getJsonSourceString(obj, bAllowEmpty) {
	let cache = new WeakMap();  // object to stringified result
	function stringify(variable){
		if (variable === null)
			throw Error("null value in "+JSON.stringify(obj));
		switch (typeof variable){
			case "string":
				return toWellFormedJsonStringify(variable);
			case "number":
				if (!isFinite(variable))
					throw Error("invalid number: " + variable);
			case "boolean":
				return variable.toString();
			case "object":
				// return cached result if already processed
				if (cache.has(variable))
					return cache.get(variable);
				let result;
				if (Array.isArray(variable)){
					if (variable.length === 0 && !bAllowEmpty)
						throw Error("empty array in "+JSON.stringify(obj));
					result = '[' + variable.map(stringify).join(',') + ']';
				}
				else{
					var keys = Object.keys(variable).sort();
					if (keys.length === 0 && !bAllowEmpty)
						throw Error("empty object in "+JSON.stringify(obj));
					result = '{' + keys.map(function(key){ return toWellFormedJsonStringify(key)+':'+stringify(variable[key]) }).join(',') + '}';
				}
				cache.set(variable, result);  // memoize for future references
				return result;
			default:
				throw Error("getJsonSourceString: unknown type="+(typeof variable)+" of "+variable+", object: "+JSON.stringify(obj));
		}
	}

	return stringify(obj);
}
```
