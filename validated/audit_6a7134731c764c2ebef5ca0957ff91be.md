### Title
`gh extension remove` path traversal via unsanitized extension name allows arbitrary directory deletion - ([File: pkg/cmd/extension/manager.go])

### Finding Description
`Manager.Remove` computes the deletion target as `filepath.Join(m.installDir(), name)` after passing `name` through `normalizeExtension`, and then calls `os.RemoveAll(targetDir)`. [1](#0-0) 

`normalizeExtension` only guarantees the string starts with the literal prefix `"gh-"`; it performs no validation against path separators or `..` segments: [2](#0-1) 

Because the prefix is concatenated directly onto the attacker-supplied string (e.g. `"gh-" + "../../../../etc/passwd"` → `"gh-../../../../etc/passwd"`), `filepath.Join`/`filepath.Clean` treats `"gh-.."` as an ordinary path segment (it is *not* literally `".."`), which one subsequent `".."` cancels out, and any additional `".."` segments continue walking up the directory tree past `installDir()` (`dataDir()/extensions`) and past `dataDir()` itself, ultimately reaching the filesystem root and then descending into an attacker-chosen absolute path (e.g. `/home/victim/.ssh`, project directories, etc.). `cleanExtensionUpdateDir`/`UpdateDir` has the identical flaw since it also just calls `normalizeExtension` and `filepath.Join`. [3](#0-2) [4](#0-3) 

No allowlist, `safepaths`-style confinement check, or rejection of separator/`..` characters exists anywhere on this path before `os.Lstat`/`os.RemoveAll` are invoked, so nothing in the existing code stops the escape.

### Impact Explanation
If a victim is convinced to run `gh extension remove <crafted-name>` (e.g. copy-pasted from a malicious README/issue as a "fix" instruction), and the crafted name resolves via traversal to an existing directory on disk, `os.RemoveAll` will recursively delete that directory and all its contents — an arbitrary, destructive filesystem write (deletion) outside the intended `extensions` directory. This matches the "file write/overwrite outside the intended path" bounty impact class (here, destructive deletion rather than write, but confinement is equally broken).

### Likelihood Explanation
This requires the victim to actually type or paste a specially-crafted extension name into an otherwise ordinary `gh extension remove` invocation — no other attacker capability (no token, no MITM, no admin rights) is needed. The attack is fully reproducible: any string containing enough `../` sequences after the `gh-` prefix will walk outside `installDir()`. The realistic bar is the social-engineering step of getting the victim to run the exact command with attacker-chosen text, which is explicitly listed as in-scope in the preconditions (attacker-published README/issue instructions consumed as "ordinary gh command usage").

### Recommendation
In `normalizeExtension` (or immediately in `Remove`, `InstallLocal`, `UpdateDir`), reject/strip any name containing path separators (`/`, `\`) or `..` segments before constructing paths, and/or validate that `filepath.Join(installDir(), name)` remains lexically prefixed by `installDir()` (e.g. via `filepath.Rel` and checking it doesn't start with `..`) before calling `os.Lstat`/`os.RemoveAll`. Apply the same confinement check to `UpdateDir`/`cleanExtensionUpdateDir`.

### Proof of Concept
```go
func TestRemove_PathTraversal(t *testing.T) {
    tempDir := t.TempDir()
    dataDir := filepath.Join(tempDir, "data")
    require.NoError(t, os.MkdirAll(filepath.Join(dataDir, "extensions"), 0755))

    // victim directory OUTSIDE installDir that should never be touched
    victimDir := filepath.Join(tempDir, "victim-secrets")
    require.NoError(t, os.MkdirAll(victimDir, 0755))
    require.NoError(t, os.WriteFile(filepath.Join(victimDir, "id_rsa"), []byte("secret"), 0600))

    m := &Manager{
        dataDir:   func() string { return dataDir },
        updateDir: func() string { return filepath.Join(tempDir, "state", "extensions") },
    }

    // crafted name attacker tells victim to run:
    // gh extension remove '../../victim-secrets'
    craftedName := "../../victim-secrets"

    err := m.Remove(craftedName)
    require.NoError(t, err)

    // Assert the directory OUTSIDE installDir was deleted -> proves traversal
    _, statErr := os.Stat(victimDir)
    require.True(t, os.IsNotExist(statErr), "expected victimDir to be deleted due to path traversal, confinement failed")
}
```
Expected (current, vulnerable) behavior: the test passes, showing `victimDir` (outside `installDir()`) is deleted. After applying confinement validation, `Remove` should instead return an error such as `no extension found` or `invalid extension name`, and `victimDir` should remain intact.

func (m *Manager) Remove(name string) error {
	name = normalizeExtension(name)
	targetDir := filepath.Join(m.installDir(), name)
	if _, err := os.Lstat(targetDir); os.IsNotExist(err) {
		return fmt.Errorf("no extension found: %q", targetDir)
	}
	if m.dryRunMode {
		return nil
	}
	if err := m.cleanExtensionUpdateDir(name); err != nil {
		return err
	}
	return os.RemoveAll(targetDir)
}

// normalizeExtension makes sure that the provided extension name is prefixed with "gh-".
func normalizeExtension(name string) string {
	if !strings.HasPrefix(name, "gh-") {
		name = "gh-" + name
	}
	return name
}
