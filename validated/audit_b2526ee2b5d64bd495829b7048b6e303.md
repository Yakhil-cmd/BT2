### Title
Governing Node Can Vote Itself Out of Governance by Setting `governance.governingnode` to a Non-Council Address — (`File: kaiax/gov/headergov/impl/header.go`)

---

### Summary

In `single` governance mode, `checkConsistency` validates that the **current** governing node is in the council before allowing a `governance.governingnode` vote, but never validates that the **new** governing node (the vote value) is in the council. The governing node can therefore ratify a vote that replaces itself with an address that is not a council member. After the epoch boundary, the new governing node is not in the council, can never become a block proposer, and can never cast a vote — permanently locking all header governance in `single` mode.

---

### Finding Description

`checkConsistency` in `kaiax/gov/headergov/impl/header.go` handles the `governance.governingnode` vote case as follows:

```go
case gov.GovernanceGoverningNode:
    params := h.GetParamSet(blockNum)
    if params.GovernanceMode != "single" {
        return nil
    }
    council, err := h.ValSet.GetCouncil(blockNum - 1)
    if err != nil {
        return err
    }
    if slices.Contains(council, params.GoverningNode) {  // checks CURRENT node
        return nil
    }
    return ErrGovNodeNotInValSetList
``` [1](#0-0) 

The guard checks `params.GoverningNode` — the **current** governing node — against the council. It does not check `vote.Value().(common.Address)` — the **proposed new** governing node — against the council. A vote proposing a non-council address passes this check unconditionally as long as the current governing node is in the council (which it must be to be the proposer and cast the vote in the first place).

After the epoch boundary, `GetParamSet` returns the new governing node address. In `single` mode, `VerifyVote` enforces:

```go
if h.ChainConfig.IsPermissionlessForkEnabled(...) &&
    params.GovernanceMode == "single" &&
    vote.Voter() != params.GoverningNode {
    return ErrVotePermissionDenied
}
``` [2](#0-1) 

Since the new governing node is not in the council, it can never be selected as a block proposer (council membership is a prerequisite for proposer selection). It therefore can never embed a `header.Vote`, and governance is permanently frozen.

The `applyVote` function in `kaiax/valset/impl/getter_council.go` also protects the **current** governing node from removal via `governance.removevalidator`, but this protection does not extend to the scenario where the governing node is replaced with a non-council address via a `governance.governingnode` vote. [3](#0-2) 

---

### Impact Explanation

After the malicious vote is ratified at the next epoch boundary:

- `GetParamSet(N)` returns `GoverningNode = X` where `X ∉ Council`
- `VerifyVote` rejects every future governance vote because `vote.Voter() != params.GoverningNode` for any council member, and `X` can never be a proposer
- No governance parameter can ever be changed again in `single` mode: `reward.mintingamount`, `reward.ratio`, `governance.unitprice`, `kip71.*`, `istanbul.committeesize`, `governance.addvalidator`, `governance.removevalidator`, etc.
- Reward distribution parameters (minting amount, CN/KIF/KEF ratio) are permanently frozen at their last ratified values — a direct impact on KAIA issuance and distribution [4](#0-3) 

---

### Likelihood Explanation

The trigger is the governing node casting a single `governance.governingnode` vote with a non-council address as the value. This is a valid, well-formed vote that passes all format checks (`NewVoteData` accepts any 20-byte address) and all consistency checks (only the current governing node's council membership is verified). The governing node is a semi-trusted actor with the explicit authority to cast governance votes; no additional privilege or collusion is required. The scenario can occur accidentally (e.g., a typo in the target address) or maliciously. [5](#0-4) 

---

### Recommendation

In `checkConsistency`, for the `GovernanceGoverningNode` case in `single` mode, additionally verify that the **vote value** (the proposed new governing node) is a member of the current council before accepting the vote:

```go
case gov.GovernanceGoverningNode:
    params := h.GetParamSet(blockNum)
    if params.GovernanceMode != "single" {
        return nil
    }
    council, err := h.ValSet.GetCouncil(blockNum - 1)
    if err != nil {
        return err
    }
    if !slices.Contains(council, params.GoverningNode) {
        return ErrGovNodeNotInValSetList
    }
    // NEW: also verify the proposed new governing node is in the council
    newGovNode := vote.Value().(common.Address)
    if !slices.Contains(council, newGovNode) {
        return ErrGovNodeNotInValSetList
    }
    return nil
``` [6](#0-5)

### Proof of Concept

**Setup**: Chain in `single` mode, governing node `G` in council `[G, A, B]`, epoch = 604800.

1. `G` calls `governance_vote("governance.governingnode", "0xdeadbeef...dead")` where `0xdeadbeef...dead` is not in the council.
2. `VerifyVote` passes: `G` is in council, `G` is the proposer, `G == params.GoverningNode`.
3. `checkConsistency` passes: `params.GovernanceMode == "single"`, `slices.Contains(council, G) == true` → returns `nil`.
4. The vote is embedded in `header.Vote` of the block proposed by `G`.
5. At the next epoch block, `getExpectedGovernance` collects the vote and ratifies it; `header.Governance` contains `{"governance.governingnode": "0xdeadbeef...dead"}`.
6. From `(epoch+1)*epoch` onward, `GetParamSet(N).GoverningNode == 0xdeadbeef...dead`.
7. Any council member `A` attempts `governance_vote("governance.unitprice", 100)`:
   - `VerifyVote` reaches the single-mode check: `vote.Voter() = A != params.GoverningNode = 0xdeadbeef...dead` → `ErrVotePermissionDenied`.
8. `0xdeadbeef...dead` is not in the council, is never selected as proposer, and can never embed a vote.
9. Governance is permanently frozen. `reward.mintingamount`, `reward.ratio`, and all other governance parameters are immutable. [7](#0-6) [5](#0-4)

func (h *headerGovModule) VerifyVote(header *types.Header) error {
	if len(header.Vote) == 0 {
		return nil
	}

	var (
		vb       headergov.VoteBytes = header.Vote
		blockNum                     = header.Number.Uint64()
	)

	vote, err := vb.ToVoteData()
	if err != nil {
		logger.Error("ToVoteData error", "num", blockNum, "vote", vb, "err", err)
		return err
	}

	if gov.DeprecatedAt(vote.Name(), h.ChainConfig.Rules(header.Number)) {
		logger.Error("Vote is deprecated", "num", blockNum, "name", vote.Name())
		return ErrDeprecatedVote
	}

	council, err := h.ValSet.GetCouncil(blockNum)
	if err != nil {
		return err
	}

	// check if the voter is in council
	if !slices.Contains(council, vote.Voter()) {
		return ErrInvalidKeyValue
	}

	// check if Voter is the block proposer.
	author, err := h.Chain.Sealer().Author(header)
	if err != nil {
		return err
	}
	if author != vote.Voter() {
		return ErrInvalidVoter
	}

	// In single mode, only the governing node can write header.Vote after Permissionless.
	params := h.GetParamSet(blockNum)
	if h.ChainConfig.IsPermissionlessForkEnabled(new(big.Int).SetUint64(blockNum)) &&
		params.GovernanceMode == "single" &&
		vote.Voter() != params.GoverningNode {
		return ErrVotePermissionDenied
	}

	return h.checkConsistency(blockNum, vote)

// checkConsistency checks if vote values are consistent with chain states such as other parameters and validator set.
func (h *headerGovModule) checkConsistency(blockNum uint64, vote headergov.VoteData) error {
	switch vote.Name() {
	case gov.GovernanceGoverningNode:
		params := h.GetParamSet(blockNum)

		// compare with governing node only in single mode.
		if params.GovernanceMode != "single" {
			return nil
		}

		// we'll use blockNum-1 for the blocknumber of GetCouncil since blockNum cannot be available(eg. vote)
		// it's definite that the valSet vote is not included in this block
		// so the council(blockNum - 1) and council(blockNum) should be same
		council, err := h.ValSet.GetCouncil(blockNum - 1)
		if err != nil {
			return err
		}

		if slices.Contains(council, params.GoverningNode) {
			return nil
		}
		return ErrGovNodeNotInValSetList
	case gov.Kip71LowerBoundBaseFee:
		params := h.GetParamSet(blockNum)
		if vote.Value().(uint64) > params.UpperBoundBaseFee {
			return ErrLowerBoundBaseFee
		} else {
			return nil
		}
	case gov.Kip71UpperBoundBaseFee:
		params := h.GetParamSet(blockNum)
		if vote.Value().(uint64) < params.LowerBoundBaseFee {
			return ErrUpperBoundBaseFee
		} else {
			return nil
		}
	case gov.AddValidator, gov.RemoveValidator:
		params := h.GetParamSet(blockNum)

		// compare with governing node only in single mode.
		if params.GovernanceMode != "single" {
			return nil
		}
		if slices.Contains(vote.Value().([]common.Address), params.GoverningNode) {
			return ErrGovNodeInValSetVoteValue
		}
		return nil
