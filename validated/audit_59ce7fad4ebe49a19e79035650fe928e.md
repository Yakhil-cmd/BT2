### Title
Pre-Permissionless `VerifyVote` Omits Single-Mode Governing-Node Check, Allowing Any Council Member to Ratify Unauthorized Governance Parameter Changes — (`File: kaiax/gov/headergov/impl/header.go`)

---

### Summary

In `single` governance mode, the `VerifyVote` function enforces the governing-node restriction **only after the Permissionless hardfork**. Before that fork, any council member who becomes a block proposer can embed a governance vote in the block header. Because `getExpectedGovernance` collects and ratifies **all** votes from the previous epoch without filtering by governing node, the unauthorized vote is deterministically ratified at the epoch boundary and takes effect on all nodes. The `governance_vote` API correctly rejects non-governing-node callers in single mode, but this is a client-side gate only — the consensus-layer check is absent pre-permissionless.

---

### Finding Description

**Broken invariant:** In `single` governance mode, only the address stored in `governance.governingnode` may cast a governance vote. This invariant is enforced at the API layer unconditionally, but at the consensus layer only after the Permissionless hardfork.

**API layer (correct):**

```go
// kaiax/gov/headergov/impl/api.go:61-63
if gMode == "single" && voter != gp.GoverningNode {
    return "", ErrVotePermissionDenied
}
``` [1](#0-0) 

**Consensus layer (`VerifyVote`) — missing pre-permissionless check:**

```go
// kaiax/gov/headergov/impl/header.go:101-107
// In single mode, only the governing node can write header.Vote after Permissionless.
params := h.GetParamSet(blockNum)
if h.ChainConfig.IsPermissionlessForkEnabled(new(big.Int).SetUint64(blockNum)) &&
    params.GovernanceMode == "single" &&
    vote.Voter() != params.GoverningNode {
    return ErrVotePermissionDenied
}
``` [2](#0-1) 

The guard is gated on `IsPermissionlessForkEnabled`. Before that fork, the condition is `false` and the check is skipped entirely. A non-governing-node council member who is the current block proposer can write any valid governance vote to `header.Vote` and `VerifyVote` will accept it.

The test explicitly documents this as the current behavior:

```go
// kaiax/gov/headergov/impl/header_test.go:126-133
t.Run("pre-permissionless allows non-governing node", func(t *testing.T) {
    config.PermissionlessCompatibleBlock = nil
    h := newHeaderGovModule(t, config)
    vote := headergov.NewVoteData(validVoter, string(gov.GovernanceUnitPrice), uint64(100))
    ...
    err = h.VerifyVote(&types.Header{Number: big.NewInt(1), Vote: vb, Extra: extra})
    assert.NoError(t, err)  // passes — no governing-node check
})
``` [3](#0-2) 

**Ratification path — no governing-node filter:**

`getExpectedGovernance` collects every vote stored for the previous epoch and ratifies the last one per parameter name. It performs no check on the voter's identity or governance mode:

```go
// kaiax/gov/headergov/impl/header.go:218-233
func (h *headerGovModule) getExpectedGovernance(blockNum uint64) headergov.GovData {
    prevEpochIdx := calcEpochIdx(blockNum, h.epoch) - 1
    prevEpochVotes := h.getVotesInEpoch(prevEpochIdx)
    govs := make(gov.PartialParamSet)
    sortedVoteBlocks := slices.Collect(maps.Keys(prevEpochVotes))
    slices.Sort(sortedVoteBlocks)
    for _, voteBlock := range sortedVoteBlocks {
        vote := prevEpochVotes[voteBlock]
        govs.Add(string(vote.Name()), vote.Value())  // no voter identity check
    }
    return headergov.NewGovData(govs)
}
``` [4](#0-3) 

`VerifyGov` then enforces that the epoch block's `header.Governance` **exactly matches** `getExpectedGovernance`. This means the unauthorized vote is not only accepted — it is **mandatory** in the ratification output, and all honest nodes will apply it. [5](#0-4) 

---

### Impact Explanation

A non-governing-node council member can unilaterally change any governance parameter that passes format and consistency checks, including:

- `reward.mintingamount` — inflate the per-block token mint, increasing their own staking rewards
- `reward.ratio` — redirect the GC/KIF/KEF split to favor validators
- `reward.kip82ratio` — shift the proposer/staker reward split
- `governance.unitprice` — manipulate the base fee floor
- `governance.governingnode` — transfer governance control to themselves (the consistency check only verifies the **current** governing node is in council, not the proposed new one) [6](#0-5) 

The last point is particularly severe: a council member can vote to replace the governing node with their own address, permanently seizing single-mode governance authority over the chain.

---

### Likelihood Explanation

**Preconditions:**
1. Chain is running in `single` governance mode (Kaia Mainnet and Kairos testnet both use `single` mode).
2. The Permissionless hardfork has **not** yet been activated on the target chain.
3. The attacker controls a council node (i.e., is a Governance Council member).

**Trigger:** The attacker modifies their node's `PrepareHeader` to bypass the `PushMyVotes` queue (or patches the `Vote` API check) and directly writes a crafted vote into `header.Vote` when they become the block proposer. Since proposer selection is deterministic and council members are known, the attacker can predict when they will propose.

**No external dependencies:** The attack requires only that the attacker's block is accepted by the network, which it will be since `VerifyVote` does not reject it.

---

### Recommendation

Remove the `IsPermissionlessForkEnabled` gate from the single-mode governing-node check in `VerifyVote`. The restriction should apply for all blocks in single mode, regardless of fork state:

```go
// kaiax/gov/headergov/impl/header.go
params := h.GetParamSet(blockNum)
if params.GovernanceMode == "single" && vote.Voter() != params.GoverningNode {
    return ErrVotePermissionDenied
}
```

Additionally, `getExpectedGovernance` should filter votes by governing node when the governance mode at the epoch boundary is `single`, to prevent any previously-stored unauthorized votes from being ratified.

---

### Proof of Concept

**Setup:** Single-mode chain, pre-Permissionless. Council = `[GoverningNode, AttackerNode, ...]`. Attacker controls `AttackerNode`.

**Step 1:** Attacker patches their node's `PrepareHeader` to write a vote directly into `header.Vote`, bypassing the `PushMyVotes` queue and the `Vote` API's governing-node check.

**Step 2:** Attacker waits until `AttackerNode` is selected as the block proposer (deterministic under WeightedRandom/RoundRobin).

**Step 3:** Attacker's node proposes a block with:
```
header.Vote = encode({voter: AttackerNode, name: "reward.mintingamount", value: 100_000_000_000_000_000_000})
```

**Step 4:** All other nodes call `VerifyVote`. The check at lines 103–107 is skipped because `IsPermissionlessForkEnabled` returns `false`. The vote passes. The block is accepted.

**Step 5:** At the next epoch block, `getExpectedGovernance` collects the attacker's vote. `VerifyGov` requires the epoch block to include it in `header.Governance`. All nodes apply the ratified parameter change.

**Result:** `reward.mintingamount` is now set to an attacker-chosen value, taking effect from the next epoch. The attacker receives inflated block rewards on every subsequent block. [7](#0-6) [8](#0-7) [9](#0-8)

func (h *headerGovModule) VerifyVote(header *types.Header) error {
	if len(header.Vote) == 0 {
		return nil
	}

	var (
		vb       headergov.VoteBytes = header.Vote
		blockNum                     = header.Number.Uint64()
	)

	vote, err := vb.ToVoteData()
	if err != nil {
		logger.Error("ToVoteData error", "num", blockNum, "vote", vb, "err", err)
		return err
	}

	if gov.DeprecatedAt(vote.Name(), h.ChainConfig.Rules(header.Number)) {
		logger.Error("Vote is deprecated", "num", blockNum, "name", vote.Name())
		return ErrDeprecatedVote
	}

	council, err := h.ValSet.GetCouncil(blockNum)
	if err != nil {
		return err
	}

	// check if the voter is in council
	if !slices.Contains(council, vote.Voter()) {
		return ErrInvalidKeyValue
	}

	// check if Voter is the block proposer.
	author, err := h.Chain.Sealer().Author(header)
	if err != nil {
		return err
	}
	if author != vote.Voter() {
		return ErrInvalidVoter
	}

	// In single mode, only the governing node can write header.Vote after Permissionless.
	params := h.GetParamSet(blockNum)
	if h.ChainConfig.IsPermissionlessForkEnabled(new(big.Int).SetUint64(blockNum)) &&
		params.GovernanceMode == "single" &&
		vote.Voter() != params.GoverningNode {
		return ErrVotePermissionDenied
	}

	return h.checkConsistency(blockNum, vote)
}

func (h *headerGovModule) VerifyGov(header *types.Header) error {
	// (1)
	if header.Number.Uint64()%h.epoch != 0 {
		if len(header.Governance) > 0 {
			logger.Error("governance is not allowed in non-epoch block", "num", header.Number.Uint64())
			return ErrGovInNonEpochBlock
		} else {
			return nil
		}
	}

	// (2), (3)
	expected := h.getExpectedGovernance(header.Number.Uint64())
	if len(header.Governance) == 0 {
		if len(expected.Items()) != 0 {
			return ErrGovVerification
		}

		return nil
	}

	// (4)
	var gb headergov.GovBytes = header.Governance
	actual, err := gb.ToGovData()
	if err != nil {
		logger.Error("DeserializeHeaderGov error", "num", header.Number.Uint64(), "governance", gb, "err", err)
		return err
	}

	// (5)
	if !reflect.DeepEqual(expected, actual) {
		logger.Error("Governance mismatch", "expected", expected, "actual", actual)
		return ErrGovVerification
	}

	return nil
}
