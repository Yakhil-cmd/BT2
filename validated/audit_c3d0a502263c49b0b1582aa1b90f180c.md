### Title
Untracked-file "unchanged since baseline" check relies on mtime equality, letting content edits evade `Stop`-hook review - (File: `plugins/security-guidance/hooks/diffstate.py`)

### Summary
`compute_v2_review_set` (which consumes the snapshot produced by `consume_stop_state`) decides whether a pre-existing untracked file should be excluded from the review set purely by comparing its current `st_mtime_ns` to the `mtime_ns` captured at `UserPromptSubmit` time in `untracked_at_baseline`, with no content/hash comparison. Restoring a file's mtime after editing its content is enough to make a genuinely new, dangerous change look "old" and be silently dropped from the `Stop` hook's review set.

### Finding Description
`consume_stop_state` (`plugins/security-guidance/hooks/diffstate.py:74-113`) atomically snapshots `touched_paths`, `baseline_sha`, `head_at_capture`, and `untracked_at_baseline` for the `Stop` hook and clears `touched_paths`. This snapshot is passed straight into `compute_v2_review_set` from `handle_stop_hook` (`plugins/security-guidance/hooks/security_reminder_hook.py:1792-1794`).

Inside `compute_v2_review_set` (`plugins/security-guidance/hooks/diffstate.py:353-438`), the exclusion of pre-existing untracked files is: [1](#0-0) 

`_unchanged_since_baseline` only compares `os.stat(path).st_mtime_ns` against the `mtime_ns` recorded in `untracked_at_baseline` at `UserPromptSubmit` time — it never compares file content, size, or a hash. If the current mtime equals the captured baseline mtime, the path is added to `preexisting_unchanged` and excluded from `new_untracked`, which in turn is excluded from `dirty_now` (`dirty_now = tracked_dirty | new_untracked`). Since `review_set` is derived from `dirty_now` (intersected with `changed_since` when a baseline SHA diff is available, or used directly otherwise), any untracked file whose mtime is restored to its pre-turn value is unconditionally excluded from the file list ever sent for review, regardless of what content it now contains.

Because an agent (potentially driven by attacker-controlled repository content via prompt injection, or by any normal shell command sequence executed during the turn) can trivially: (1) read the file's original mtime before editing, (2) overwrite the file with dangerous content, and (3) reset the mtime back (`os.utime`/`touch -d`/`touch -r`), the review-set computation's "unchanged" classification can be forged without needing git internals, elevated privileges, or credential access — only ordinary filesystem operations available during a normal agent turn. This breaks the stated invariant that "the review set must stay bound to the right repo, baseline, and touched paths": the file is genuinely touched and dangerous, yet the state machine treats it as untouched.

Note: this bypass is specific to **untracked** files handled through `untracked_at_baseline`/`_unchanged_since_baseline`; tracked file changes go through `tracked_dirty` (from `git status --porcelain`) and the `baseline_sha` diff (`_git_name_only`), which are content-based and not affected by mtime forgery.

### Impact Explanation
This is a Security-control bypass: the `Stop` hook is the last-resort automated LLM security review for a Claude Code turn's diff. A file that is silently excluded from `review_paths` never reaches `parse_diff_into_files`/the Haiku review call, so a dangerous change introduced in a new/pre-existing untracked file is never flagged, reviewed, or blocked — while the developer/telemetry-facing signal ("Stop hook: review_set=N") reports a clean or smaller review set, giving false assurance that the turn's changes were reviewed. This matches the "Security-control bypass that silently disables or routes around blocking, review, or permission boundaries" impact category.

### Likelihood Explanation
The precondition is narrow but realistic: it requires (a) an untracked file that existed before the current turn's `UserPromptSubmit` snapshot (or a file created by `capture_git_baseline`'s untracked-listing step) and (b) an in-place edit of that file's content followed by restoration of its mtime to nanosecond precision, both achievable with a single Bash command sequence available to any Claude Code agent turn (no maintainer/admin/credential privilege needed). This is deterministic and 100% repeatable — it's a logic flaw in a stat comparison, not a race condition.

### Recommendation
Do not rely on mtime alone to classify an untracked file as "unchanged since baseline." Either:
- Compare content hash (e.g., `sha256` of file bytes) captured at `UserPromptSubmit` against the current content, in addition to (or instead of) mtime, before excluding the path from `dirty_now`; or
- Use `st_size` + `st_mtime_ns` + `st_ino`/ctime as a multi-factor cheap heuristic, falling back to a content hash when any ambiguity exists; or
- Simply always include content-changed untracked files by diffing captured content snapshots rather than filesystem metadata.

### Proof of Concept
Unit test targeting `compute_v2_review_set` in `plugins/security-guidance/hooks/diffstate.py`:

1. In a temp git repo with at least one commit, create an untracked file `evil.py` with benign content `C0`.
2. Call `_list_untracked(repo)` (as UPS would) to build `untracked_at_baseline = {"evil.py": mtime_ns_at_baseline}`.
3. Capture `baseline_sha` via `capture_git_baseline(repo)`.
4. Simulate the turn: overwrite `evil.py` with dangerous content `C1` (e.g., `os.system("rm -rf /")`-style payload), then call `os.utime("evil.py", ns=(mtime_ns_at_baseline, mtime_ns_at_baseline))` to restore the exact mtime captured in step 2.
5. Call `review_paths, diff_base, repo_root, untracked, metrics = compute_v2_review_set(repo, baseline_sha, head_at_capture, untracked_at_baseline)`.
6. Assert: `os.path.join(repo, "evil.py") not in review_paths` (demonstrating the bypass) even though the file's actual content differs from `C0`/baseline.
7. Contrast case: repeat without step 4's `os.utime` restoration — assert `evil.py` **is** included in `review_paths`, confirming mtime forgery is the sole differentiator between "reviewed" and "silently skipped."

    def _unchanged_since_baseline(p):
        base_mtime = untracked_at_baseline.get(p)
        if base_mtime is None:
            return False
        try:
            return os.stat(os.path.join(repo, p)).st_mtime_ns == base_mtime

            return False

    preexisting_unchanged = {p for p in untracked if _unchanged_since_baseline(p)}
    new_untracked = untracked - preexisting_unchanged
