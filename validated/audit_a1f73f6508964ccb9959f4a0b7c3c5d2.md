The fzf CVE describes a quadratic-complexity DoS in an HTTP `--listen` server that accepts and concatenates untrusted request bodies from local malicious clients. Polkadot SDK has no analogous attacker-facing HTTP listener in its runtime/extrinsic path: the closest matching subsystem, the offchain worker HTTP API in `substrate/client/offchain/src/api/http.rs`, is an outbound HTTP *client* invoked by the node itself (not attacker-controlled input reachable via a signed extrinsic, XCM message, or contract call), and its body writes/reads operate on bounded caller-supplied chunks passed through `hyper`/`bytes` primitives rather than manual quadratic string concatenation [1](#0-0) . There is no reachable, unprivileged runtime entry point (signed extrinsic, contract call, or XCM instruction) that feeds attacker-controlled data into a request/response body assembled via repeated string/byte concatenation in a single-threaded server, so the fzf bug class does not have a real analog per the exclusion criteria for generic resource-exhaustion/flooding scenarios in the scan instructions.

		&mut self,
		request_id: HttpRequestId,
		chunk: &[u8],
		deadline: Option<Timestamp>,
	) -> Result<(), HttpError> {
		// Extract the request from the list.
		// Don't forget to add it back if necessary when returning.
		let mut request = self.requests.remove(&request_id).ok_or(HttpError::Invalid)?;

		let mut deadline = timestamp::deadline_to_future(deadline);
		// Closure that writes data to a sender, taking the deadline into account. Can return `Ok`
		// (if the body has been written), or `DeadlineReached`, or `IoError`.
		// If `IoError` is returned, don't forget to remove the request from the list.
		let mut poll_sender = move |sender: &mut Sender| -> Result<(), HttpError> {
			let mut when_ready = future::maybe_done(future::poll_fn(|cx| sender.poll_ready(cx)));
			futures::executor::block_on(future::select(&mut when_ready, &mut deadline));
			match when_ready {
				future::MaybeDone::Done(Ok(())) => {},
				future::MaybeDone::Done(Err(_)) => return Err(HttpError::IoError),
				future::MaybeDone::Future(_) | future::MaybeDone::Gone => {
					debug_assert!(matches!(deadline, future::MaybeDone::Done(..)));
					return Err(HttpError::DeadlineReached);
				},
			};

			futures::executor::block_on(
				async {
					future::poll_fn(|cx|  sender.poll_ready(cx)).await?;
					sender.start_send(Ok(hyper::body::Frame::data(hyper::body::Bytes::from(chunk.to_owned()))))
				}
			)
			.map_err(|_| {
				tracing::error!(target: "offchain-worker::http", "HTTP sender refused data despite being ready");
				HttpError::IoError
			})
		};
