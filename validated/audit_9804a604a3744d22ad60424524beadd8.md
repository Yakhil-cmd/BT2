### Title
Terminal escape sequence injection via unsanitized file/directory names in `printTreeDir` - (File: `pkg/cmd/skills/install/install.go`)

### Summary
`printTreeDir` writes `entry.Name()` directly into the terminal with `fmt.Fprintf` without any escape-sequence sanitization, unlike other renderers in the same package (`pkg/cmd/skills/list/list.go`) that call `sanitizeForTerminal` before printing attacker-influenced strings. A malicious skill repository can include a file or directory whose name contains ANSI/OSC control sequences that get written verbatim to the victim's terminal during `gh skill install`.

### Finding Description
`installer.Install` downloads the skill's files from the attacker-controlled repository tree onto disk, preserving their original entry names. After installation, `installRun` calls `printFileTree(opts.IO.ErrOut, cs, result.Dir, result.Installed)` [1](#0-0) , which walks the installed directory tree with `os.ReadDir` and prints each entry's name:

```go
func printTreeDir(w io.Writer, cs *iostreams.ColorScheme, dir, indent string) {
	entries, err := os.ReadDir(dir)
	...
	name := entry.Name()
	if entry.IsDir() {
		fmt.Fprintf(w, "%s%s%s\n", indent, cs.Muted(connector), cs.Bold(name+"/"))
		printTreeDir(w, cs, filepath.Join(dir, name), indent+cs.Muted(childIndent))
	} else {
		fmt.Fprintf(w, "%s%s%s\n", indent, cs.Muted(connector), name)
	}
}
``` [2](#0-1) 

`name` is written raw, with no call to any sanitization routine. The codebase already has a precedent function, `sanitizeForTerminal`, defined in `pkg/cmd/skills/list/list.go`, that strips/neutralizes ASCII control characters from similarly attacker-influenced fields (`skill.skillName`, `skill.source`) before rendering them in a table [3](#0-2) . That sanitization is not applied in `install.go`'s `printFileTree`/`printTreeDir`.

Because file/directory names on Linux/macOS filesystems may contain arbitrary bytes other than `/` and NUL, an attacker who publishes a public skill repository (or a fork/branch referenced by the victim) can name a file or directory inside `skills/<name>/` with embedded escape sequences (e.g., `\x1b]0;fake title\x07`, cursor-repositioning sequences like `\x1b[2K\x1b[1A`, or synthetic line content designed to visually overwrite/obscure real output). When the victim runs `gh skill install owner/repo`, these bytes flow: `installer.Install` (writes files with attacker-chosen names) → `printFileTree` → `printTreeDir` → `os.ReadDir` → raw `fmt.Fprintf(w, ..., name)` → victim's terminal.

### Impact Explanation
This enables terminal output spoofing/forgery on the victim's terminal immediately following skill installation. Depending on the terminal emulator, an attacker-controlled name could: move the cursor to overwrite or hide legitimate warning text (such as the review-hint / prompt-injection warnings printed right after by `printReviewHint`), spoof the terminal title, or otherwise manipulate what the user perceives, potentially masking security warnings or presenting fabricated status text that could influence a subsequent trust decision (e.g., whether to review/trust the installed skill). This matches a terminal/output-injection impact class (UI/prompt spoofing) rather than direct code execution or credential theft; the severity is bounded by what escape sequences a given terminal emulator honors, but it is a genuine, exploitable output-sanitization gap that the codebase explicitly guards against elsewhere.

### Likelihood Explanation
- Preconditions: the victim must run `gh skill install` (or `gh skill install --from-local`) against a repository/directory controlled by the attacker, which is the normal expected usage of this feature (installing skills from arbitrary GitHub repos is the command's entire purpose).
- Feasibility: creating a file or directory with control-character bytes in its name is straightforward via `git` on Linux/macOS (git allows arbitrary bytes except `/` and NUL in tree entry names); no special privileges are required, matching the "unprivileged remote attacker publishes a repo" threat model.
- Repeatability: deterministic — every installation of the crafted skill triggers the tree print unconditionally, since `printFileTree` is called after every successful install with no output filtering.

### Recommendation
Sanitize `entry.Name()` (and any other filesystem-derived or otherwise attacker-influenced string) before writing it to the terminal in `printTreeDir`/`printFileTree`, reusing the existing `sanitizeForTerminal` helper (or extracting it into a shared internal package so both `list.go` and `install.go` use the same sanitizer). Apply this consistently to all `fmt.Fprintf`/`fmt.Fprintln` calls in `install.go` that print skill/file names sourced from repository content (e.g., also review `existingSkillPrompt`, `printReviewHint`'s `name` loop, and `friendlyDir`/`kiroResourcePath` outputs for the same class of issue).

### Proof of Concept
```go
func TestPrintTreeDir_SanitizesControlSequences(t *testing.T) {
	dir := t.TempDir()
	maliciousName := "legit\x1b]0;FAKE PROMPT\x07file.txt"
	if err := os.WriteFile(filepath.Join(dir, maliciousName), []byte("data"), 0o644); err != nil {
		t.Fatal(err)
	}

	var buf bytes.Buffer
	io, _, _, _ := iostreams.Test()
	cs := io.ColorScheme()

	printTreeDir(&buf, cs, dir, "  ")

	out := buf.String()
	if strings.Contains(out, "\x1b]") || strings.Contains(out, "\x07") {
		t.Fatalf("terminal escape sequence leaked into output: %q", out)
	}
}
```
Expected (current, failing) behavior: the raw ESC (`\x1b`) and BEL (`\x07`) bytes appear unmodified in `buf.String()`, confirming the injection reaches the writer used for the victim's terminal (`opts.IO.ErrOut`). After applying `sanitizeForTerminal` to `name` in `printTreeDir`, the test should pass with the control bytes replaced/stripped.

func printTreeDir(w io.Writer, cs *iostreams.ColorScheme, dir, indent string) {
	entries, err := os.ReadDir(dir)
	if err != nil {
		fmt.Fprintf(w, "%s%s\n", indent, cs.Muted("(could not read directory)"))
		return
	}
	for i, entry := range entries {
		isLast := i == len(entries)-1
		connector := "├── "
		childIndent := "│   "
		if isLast {
			connector = "└── "
			childIndent = "    "
		}
		name := entry.Name()
		if entry.IsDir() {
			fmt.Fprintf(w, "%s%s%s\n", indent, cs.Muted(connector), cs.Bold(name+"/"))
			printTreeDir(w, cs, filepath.Join(dir, name), indent+cs.Muted(childIndent))
		} else {
			fmt.Fprintf(w, "%s%s%s\n", indent, cs.Muted(connector), name)
		}
	}
}

// sanitizeForTerminal replaces ASCII control characters in s with inert
// caret-style stand-ins so frontmatter values cannot inject terminal escapes.
func sanitizeForTerminal(s string) string {
	var buf bytes.Buffer
	r := transform.NewReader(bytes.NewReader([]byte(s)), &asciisanitizer.Sanitizer{})
	if _, err := io.Copy(&buf, r); err != nil {
		return "Unknown"
	}
	return buf.String()
}
