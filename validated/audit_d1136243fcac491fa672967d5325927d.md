### Title
Off-by-One in Epoch Block Guard Causes Stale `epochVACount` in ABv2, Corrupting Violation-Transition Slot Limits — (`kaiax/valset/impl/transition.go`)

### Summary

`writeTransitionToABv2` uses `isVrankEpoch(num)` to decide whether to force-write the `epochVACount` snapshot to AddressBookV2, but the epoch transition itself fires when `isVrankEpoch(num+1)` is true. The guard is off by one block, producing two symmetric errors at every VRank epoch boundary: the mandatory `epochVACount` write is skipped at the actual epoch block (`num = VRankEpoch - 1`), and an erroneous write with `epochVACount = 0` is issued one block later (`num = VRankEpoch`). The stale or zeroed `epochVACount` is then read back from ABv2 and fed into `slotLimitsFor`, which computes `MaxSlotAvailable` and `MinActiveCount` for the violation transition. With `epochVACount = 0`, both limits collapse to zero, silently blocking all per-block validator demotions (min-stake and PFS violations) for the block immediately following each epoch boundary.

### Finding Description

**Root cause — the mismatched epoch predicate**

`newTransitionContext` sets `IsEpoch` using `isVrankEpoch(nextNum)` where `nextNum = headNum + 1`:

```go
// kaiax/valset/impl/transition.go:126-134
func (v *ValsetModule) newTransitionContext(header *types.Header, ...) *TransitionContext {
    headNum := header.Number.Uint64()
    nextNum := headNum + 1
    ...
    ctx.SetBlockCtx(header, v.isVrankEpoch(nextNum))   // epoch fires at (num+1) % VRankEpoch == 0
```

The epoch transition therefore fires at blocks `num = VRankEpoch-1, 2·VRankEpoch-1, …` and sets `epochVACountForWrite` to the new active-validator count.

The skip guard in `writeTransitionToABv2` uses `isVrankEpoch(num)` — one block off:

```go
// kaiax/valset/impl/transition.go:227-231
// Skip the call if no changes and not an epoch block (epoch blocks need
// the epochVACount snapshot update regardless)
if len(diff) == 0 && !v.isVrankEpoch(num) {
    return nil
}
```

`isVrankEpoch(num)` fires at `num = 0, VRankEpoch, 2·VRankEpoch, …` — exactly one block after the actual epoch transition.

**Two concrete failure modes per epoch boundary**

| Block | Epoch transition fires? | `epochVACountForWrite` | `isVrankEpoch(num)` | Outcome |
|---|---|---|---|---|
| `VRankEpoch - 1` | **Yes** | new VA count | **false** | If `diff` is empty → call **skipped**, `epochVACount` in ABv2 **not updated** |
| `VRankEpoch` | No | 0 | **true** | Call **always made** with `epochVACount = 0` → ABv2 stores **0** |

**Downstream impact — slot limits collapse to zero**

`ReadABv2Snapshot` reads `EpochVACount` from ABv2 and passes it to `slotLimitsFor`:

```go
// kaiax/valset/impl/transition.go:137
ctx.SetSlotsCtx(slotLimitsFor(abv2result.EpochVACount))
```

```go
// kaiax/valset/impl/transition_context.go:419-428
func maxSlotAvailable(n uint64) uint64 {
    if n < 4 {
        return 0          // ← 0 when n == 0
    }
    return (n/3 + 1) / 2
}
func minActiveCount(n uint64) uint64 {
    if n < 4 {
        return n          // ← 0 when n == 0
    }
    return (2*n + 2) / 3
}
```

With `epochVACount = 0`, `slotLimitsFor(0)` returns `(MaxSlotAvailable=0, MinActiveCount=0)`.

In `applyViolationTransition`, the slot check is:

```go
// kaiax/valset/impl/transition_context.go:274-280
hasSlot = func(state valset.NodeState) bool {
    return newValidators.CountByState(state) < ctx.MaxSlotAvailable  // X < 0 → always false
}
canDemoteActive = func(targetState valset.NodeState) bool {
    return hasSlot(targetState) && ...
}
```

`hasSlot` always returns `false` when `MaxSlotAvailable = 0`, so **no validator can be demoted** to `ValExiting` or `ValPaused` via the violation transition at the block immediately following each VRank epoch boundary.

### Impact Explanation

At every VRank epoch boundary (every 86 400 blocks, roughly once per day on mainnet), the block at `num = VRankEpoch` writes `epochVACount = 0` to AddressBookV2. On the next block, the violation transition runs with `MaxSlotAvailable = 0`, silently suppressing all demotions:

- A `ValActive` validator that dropped below `MinimumStake` is **not** moved to `ValExiting`.
- A `ValActive` validator with a severe PFS violation (proposal failures ≥ threshold) is **not** moved to `ValExiting` or `ValPaused`.

This constitutes a periodic, automatic validator-privilege escalation: misbehaving or under-staked validators retain their `ValActive` status for one extra block at each epoch boundary, bypassing the KIP-286 enforcement mechanism. The corrupted `epochVACount = 0` is written to the ABv2 system contract (on-chain state), making the corruption persistent until the next legitimate `processSystemTransition` call overwrites it.

### Likelihood Explanation

The condition is deterministic and unconditional: every VRank epoch boundary (block `num = VRankEpoch, 2·VRankEpoch, …`) triggers the erroneous write. No attacker action is required. The only uncertainty is whether the ABv2 Solidity contract's `processSystemTransition` ignores a zero `epochVACount` argument; if it does, the impact degrades to Case 1 (stale `epochVACount` when diff is empty at `VRankEpoch - 1`), which is still a real but less frequent bug.

### Recommendation

Replace the epoch-block predicate in `writeTransitionToABv2` with the same expression used to set `IsEpoch`, or use `tr.epochVACountForWrite != 0` as the canonical signal:

```go
// Before (wrong — off by one):
if len(diff) == 0 && !v.isVrankEpoch(num) {
    return nil
}

// After (correct — mirrors newTransitionContext):
if len(diff) == 0 && tr.epochVACountForWrite == 0 {
    return nil
}
```

This ensures the `processSystemTransition` call is made if and only if there are state changes **or** the epoch transition produced a new `epochVACount` to persist.

### Proof of Concept

Given `VRankEpoch = 86400`:

1. At block 86399 (`VRankEpoch - 1`): `isVrankEpoch(86400) = true` → epoch transition fires, `epochVACountForWrite = N` (current active count). If all validators maintain their states, `diff` is empty. `isVrankEpoch(86399) = false` → `processSystemTransition` is **skipped**. ABv2 retains the previous epoch's `epochVACount`.

2. At block 86400 (`VRankEpoch`): `isVrankEpoch(86401) = false` → no epoch transition, `epochVACountForWrite = 0`. `isVrankEpoch(86400) = true` → `processSystemTransition` is **called** with `epochVACount = 0`. ABv2 stores `epochVACount = 0`.

3. At block 86401: `ReadABv2Snapshot` reads `EpochVACount = 0`. `slotLimitsFor(0) = (0, 0)`. In `applyViolationTransition`, `hasSlot(ValExiting)` evaluates `CountByState(ValExiting) < 0` → `false`. A validator with staking below `MinimumStake` that should transition `ValActive → ValExiting` is silently skipped. The validator retains `ValActive` status for this block.

```go
func (ctx *TransitionContext) ApplyAllTransitions(nodes valset.NodeMap) *TransitionResult {
	epochVACountForWrite := uint64(0)

	if ctx.IsEpoch {
		nodes = ctx.applyEpochTransition(nodes)
		// After the epoch transition the active-validator count changes, so

	nodes = ctx.applyTimeoutTransition(nodes)

	return &TransitionResult{
		Nodes:                nodes,
		epochVACountForWrite: epochVACountForWrite,
	}
```

```go
// Internal use only — call via the orchestrator after applyEpochTransition on epoch blocks.
func (ctx *TransitionContext) applyViolationTransition(m valset.NodeMap) valset.NodeMap {
	var (
		newValidators = m.Copy()
		// Slot/count helpers check the in-progress state of newValidators.
		// Counts change as validators transition within the loop, so these cannot be replaced with a contract call.
		hasSlot = func(state valset.NodeState) bool {
			return newValidators.CountByState(state) < ctx.MaxSlotAvailable
		}
		// canDemoteActive additionally ensures enough ValActive remain for consensus.
		// Used only when transitioning FROM ValActive (reducing active count).
		canDemoteActive = func(targetState valset.NodeState) bool {
			return hasSlot(targetState) && newValidators.CountByState(valset.ValActive) > ctx.MinActiveCount
		}
	)
```

```go
// #region SlotMath
//
// Slot limit calculations for node state transitions. Go port of
// kaia-system-contracts/contracts-v3.0/src/libraries/SlotMath.sol — kept in lockstep
// with that contract since the orchestrator and ABv2 must agree on slot math.
//
// For n >= 4 (standard BFT with f = floor(n/3) > 0):
//
//	minActiveCount   = ceil(2n/3)             = (2n + 2) / 3
//	totalBudget      = n - minActiveCount     = floor(n/3) = n / 3
//	maxSlotAvailable = ceil(totalBudget / 2)  = (n/3 + 1) / 2
//
// For n < 4 (BFT fault tolerance f = 0; all nodes must remain active):
//
//	minActiveCount   = n
//	maxSlotAvailable = 0

// minActiveCount returns the minimum number of active nodes required for
// BFT liveness given epochVACount n.
func minActiveCount(n uint64) uint64 {
	if n < 4 {
		return n
	}
	return (2*n + 2) / 3
}

// maxSlotAvailable returns the maximum number of nodes allowed in
// ValPaused or ValExiting state each given epochVACount n.
func maxSlotAvailable(n uint64) uint64 {
	if n < 4 {
		return 0
	}
	return (n/3 + 1) / 2
}

// slotLimitsFor returns (maxSlotAvailable, minActiveCount) for epochVACount n.
func slotLimitsFor(n uint64) (uint64, uint64) {
	return maxSlotAvailable(n), minActiveCount(n)
}
```

```go
// EncodeProcessSystemTransition encodes the processSystemTransition call with the given node state changes.
// epochVACount is the VA count after epoch transition (newSF); 0 for non-epoch blocks.
func EncodeProcessSystemTransition(
	rules params.Rules,
	nodes valset.NodeMap,
	epochVACount uint64,
) (common.Address, *types.Transaction, error) {
	nodeIds := make([]common.Address, 0, len(nodes))
	for addr := range nodes {
		nodeIds = append(nodeIds, addr)
	}
	// Sort for deterministic ABI encoding across all nodes
	sort.Slice(nodeIds, func(i, j int) bool {
		return bytes.Compare(nodeIds[i].Bytes(), nodeIds[j].Bytes()) < 0
	})

	var (
		newStates  = make([]uint8, len(nodeIds))
		timeoutAts = make([]*big.Int, len(nodeIds))
	)
	for idx, addr := range nodeIds {
		vs := nodes[addr]
		newStates[idx] = vs.State.ToUint8()
		var timeout time.Time
		switch vs.State {
		case valset.ValPaused:
			timeout = vs.PausedTimeout
		case valset.ValReady, valset.ValInactive:
			timeout = vs.IdleTimeout
		}
		if timeout.IsZero() {
			timeoutAts[idx] = big.NewInt(0)
		} else {
			timeoutAts[idx] = big.NewInt(timeout.Unix())
		}
	}

	data, err := AddressBookV2ABI.Pack("processSystemTransition", nodeIds, newStates, timeoutAts, new(big.Int).SetUint64(epochVACount))
	if err != nil {
		return common.Address{}, nil, err
	}
	return encodeSystemMessage(rules, AddressBookAddr, data)
}
```
