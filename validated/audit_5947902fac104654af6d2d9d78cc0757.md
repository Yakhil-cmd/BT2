### Title
`checkConsistency` for `GovernanceGoverningNode` vote validates the current governing node's council membership but not the new governing node's — allowing permanent single-mode governance bricking — (`kaiax/gov/headergov/impl/header.go`)

### Summary

In `single` governance mode, the current governing node is the sole authority that can cast ratified votes. When a `governance.governingnode` vote is submitted, `checkConsistency` verifies that the **current** governing node is in the council, but never validates that the **new** governing node (the vote value) is also a council member. Because only council members can be block proposers, a non-council governing node can never embed a vote in a block header, permanently freezing all governance parameter changes.

### Finding Description

`checkConsistency` in `kaiax/gov/headergov/impl/header.go` handles the `GovernanceGoverningNode` case as follows:

```go
case gov.GovernanceGoverningNode:
    params := h.GetParamSet(blockNum)
    if params.GovernanceMode != "single" {
        return nil
    }
    council, err := h.ValSet.GetCouncil(blockNum - 1)
    if err != nil {
        return err
    }
    if slices.Contains(council, params.GoverningNode) {  // checks CURRENT node
        return nil
    }
    return ErrGovNodeNotInValSetList
``` [1](#0-0) 

The guard `slices.Contains(council, params.GoverningNode)` checks whether the **current** `params.GoverningNode` is in the council. It does not inspect `vote.Value()`, which is the **proposed new** governing node address. Any address — including one that is not a council member, does not exist, or is the zero address — is accepted as a valid new governing node.

`VerifyVote` enforces that the voter is a council member and the block proposer, and in single mode (post-Permissionless) that the voter equals the current governing node:

```go
if h.ChainConfig.IsPermissionlessForkEnabled(new(big.Int).SetUint64(blockNum)) &&
    params.GovernanceMode == "single" &&
    vote.Voter() != params.GoverningNode {
    return ErrVotePermissionDenied
}
``` [2](#0-1) 

These checks constrain **who can vote**, not **what value is valid**. The new governing node value passes all validation.

Once the vote is ratified at the next epoch boundary, `GetParamSet` returns the new address as `GoverningNode`. Because `VerifyVote` requires the voter to be a council member and a block proposer, and because `applyVote` only modifies the council via `AddValidator`/`RemoveValidator` votes (not `GovernanceGoverningNode`), a non-council governing node can never be selected as proposer and can never embed a vote in a block header. [3](#0-2) 

The `governance_vote` API also enforces `voter != gp.GoverningNode` to reject non-governing-node callers, but the new governing node's node process would still fail at `VerifyVote` because it is not in the council. [4](#0-3) 

### Impact Explanation

After the malicious or erroneous `governance.governingnode` vote is ratified:

- In `single` mode, only the governing node may cast ratified votes.
- The new governing node is not a council member and can never be a block proposer.
- No governance vote can ever be embedded in a block header again.
- All governance parameters — `reward.mintingamount`, `reward.ratio`, `reward.kip82ratio`, `governance.unitprice`, `istanbul.committeesize`, and all others — are permanently frozen at their current values.
- The governing node address cannot be changed back because doing so requires a ratified vote, which requires the (now-invalid) governing node to be a proposer.
- Recovery requires a coordinated hard fork.

This is a permanent, irreversible corruption of the on-chain governance state with direct impact on reward distribution and all chain parameters.

### Likelihood Explanation

The trigger is the current governing node (a semi-trusted party) casting a `governance.governingnode` vote with a non-council address as the value. This can happen:

1. **Accidentally**: An operator mistypes or pastes a wrong address into `governance_vote("governance.governingnode", "<wrong-addr>")`.
2. **Maliciously**: A compromised or rogue governing node deliberately transfers governance to an uncontrollable address to freeze the chain's governance.

The `governance_vote` RPC is a public API endpoint on the governing node. No additional on-chain permission beyond being the current governing node is required. [5](#0-4) 

### Recommendation

In `checkConsistency`, for the `GovernanceGoverningNode` case, additionally verify that the proposed new governing node address (`vote.Value()`) is a member of the current council:

```go
case gov.GovernanceGoverningNode:
    params := h.GetParamSet(blockNum)
    if params.GovernanceMode != "single" {
        return nil
    }
    council, err := h.ValSet.GetCouncil(blockNum - 1)
    if err != nil {
        return err
    }
    if !slices.Contains(council, params.GoverningNode) {
        return ErrGovNodeNotInValSetList
    }
    // NEW: also validate the proposed new governing node is in council
    newGovNode, ok := vote.Value().(common.Address)
    if !ok || !slices.Contains(council, newGovNode) {
        return ErrGovNodeNotInValSetList
    }
    return nil
``` [6](#0-5) 

### Proof of Concept

1. Chain is in `single` governance mode. `GoverningNode = A` (a council member). Council = `{A, B, C}`.
2. Node A calls `governance_vote("governance.governingnode", "0xDEAD...BEEF")` where `0xDEAD...BEEF` is not in the council.
3. `checkConsistency` runs: `slices.Contains(council, params.GoverningNode)` → `slices.Contains({A,B,C}, A)` → `true` → returns `nil` (no error). The vote value `0xDEAD...BEEF` is never checked.
4. Node A proposes a block containing this vote. `VerifyVote` passes (A is in council, A is proposer, A is governing node).
5. At the next epoch block, `getExpectedGovernance` collects the vote and ratifies it. `header.Governance` now contains `{"governance.governingnode": "0xDEAD...BEEF"}`.
6. From `(k+1)*epoch` onward, `GetParamSet` returns `GoverningNode = 0xDEAD...BEEF`.
7. Any subsequent `governance_vote` call from any node fails: non-governing-node callers get `ErrVotePermissionDenied`; the new governing node `0xDEAD...BEEF` is not in the council and can never be a proposer, so its votes are rejected by `VerifyVote` with `ErrInvalidKeyValue`.
8. Governance is permanently frozen. All reward and chain parameters are immutable without a hard fork.

// checkConsistency checks if vote values are consistent with chain states such as other parameters and validator set.
func (h *headerGovModule) checkConsistency(blockNum uint64, vote headergov.VoteData) error {
	switch vote.Name() {
	case gov.GovernanceGoverningNode:
		params := h.GetParamSet(blockNum)

		// compare with governing node only in single mode.
		if params.GovernanceMode != "single" {
			return nil
		}

		// we'll use blockNum-1 for the blocknumber of GetCouncil since blockNum cannot be available(eg. vote)
		// it's definite that the valSet vote is not included in this block
		// so the council(blockNum - 1) and council(blockNum) should be same
		council, err := h.ValSet.GetCouncil(blockNum - 1)
		if err != nil {
			return err
		}

		if slices.Contains(council, params.GoverningNode) {
			return nil
		}
		return ErrGovNodeNotInValSetList
	case gov.Kip71LowerBoundBaseFee:
		params := h.GetParamSet(blockNum)
		if vote.Value().(uint64) > params.UpperBoundBaseFee {
			return ErrLowerBoundBaseFee
		} else {
			return nil
		}
	case gov.Kip71UpperBoundBaseFee:
		params := h.GetParamSet(blockNum)
		if vote.Value().(uint64) < params.LowerBoundBaseFee {
			return ErrUpperBoundBaseFee
		} else {
			return nil
		}
	case gov.AddValidator, gov.RemoveValidator:
		params := h.GetParamSet(blockNum)

		// compare with governing node only in single mode.
		if params.GovernanceMode != "single" {
			return nil
		}
		if slices.Contains(vote.Value().([]common.Address), params.GoverningNode) {
			return ErrGovNodeInValSetVoteValue
		}
		return nil
		// These votes are valid as long as it passes the format checks in NewVoteData(). No more checks here.
	case gov.GovernanceDeriveShaImpl, gov.GovernanceGovParamContract, gov.GovernanceGovernanceMode, gov.GovernanceUnitPrice,
		gov.IstanbulCommitteeSize, gov.IstanbulEpoch, gov.IstanbulPolicy,
		gov.Kip71BaseFeeDenominator, gov.Kip71GasTarget, gov.Kip71MaxBlockGasUsedForBaseFee,
		gov.RewardDeferredTxFee, gov.RewardKip82Ratio, gov.RewardMintingAmount, gov.RewardMinimumStake,
		gov.RewardProposerUpdateInterval, gov.RewardRatio, gov.RewardStakingRewardThreshold,
		gov.RewardStakingUpdateInterval, gov.RewardUseFlexReward, gov.RewardUseGiniCoeff:
		return nil
	default:
		return ErrInvalidKeyValue
	}
}

func applyVote(header *types.Header, council *valset.AddressSet, governingNode common.Address) bool {
	voteKey, addresses, ok := parseValidatorVote(header)
	if !ok {
		return false
	}

	originalSize := council.Len()
	for _, address := range addresses {
		if address == governingNode {
			continue
		}
		switch voteKey {
		case gov.AddValidator:
			if !council.Contains(address) {
				council.Add(address)
			}
		case gov.RemoveValidator:
			if council.Contains(address) {
				council.Remove(address)
			}
		}
	}
	return originalSize != council.Len()

func (api *headerGovAPI) Vote(name string, value any) (string, error) {
	var (
		voter     = api.h.nodeAddress
		nextBlock = api.h.Chain.CurrentBlock().NumberU64() + 1
		gp        = api.h.GetParamSet(nextBlock)
		gMode     = gp.GovernanceMode
	)

	if gMode == "single" && voter != gp.GoverningNode {
		return "", ErrVotePermissionDenied
	}

	vote := headergov.NewVoteData(voter, name, value)
	if vote == nil {
		return "", ErrInvalidKeyValue
	}

	if gov.DeprecatedAt(vote.Name(), api.h.ChainConfig.Rules(new(big.Int).SetUint64(nextBlock))) {
		return "", ErrDeprecatedVote
	}

	err := api.h.checkConsistency(nextBlock, vote)
	if err != nil {
		return "", err
	}

	// TODO-kaiax: add removevalidator vote check

	api.h.PushMyVotes(vote)
	return "(kaiax) Your vote is prepared. It will be put into the block header or applied when your node generates a block as a proposer. Note that your vote may be duplicate.", nil
