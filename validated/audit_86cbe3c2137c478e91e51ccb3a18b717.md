### Title
Unverified Peer-Supplied `P2PStakingInfo` Written to DB Without State-Root Validation, Corrupting Staking Reward Distribution — (`datasync/downloader/downloader.go`)

---

### Summary

`SyncStakingInfo` and `commitFastSyncData` in `datasync/downloader/downloader.go` accept `P2PStakingInfo` structs from a remote peer and persist them directly to the local database via `PutStakingInfoToDB` with no cryptographic or state-root verification. The only guard is a block-number ordering check. The stored staking info is subsequently consumed by `GetStakingInfo` (which prefers the DB over on-chain state for pre-Kaia blocks) to drive `assignStakingRewards`, directly determining how many KAIA each validator's reward address receives.

---

### Finding Description

**Root cause — `SyncStakingInfo`:** [1](#0-0) 

The goroutine receives `[]*staking.P2PStakingInfo` from a peer, checks only that `stakingInfo.BlockNum` matches the expected sequence position, then calls `PutStakingInfoToDB` unconditionally. No field of the struct — `CouncilStakingAmounts`, `CouncilRewardAddrs`, `CouncilNodeAddrs` — is verified against the actual AddressBook contract state at the block's state root.

**Root cause — `commitFastSyncData`:** [2](#0-1) 

During fast sync the same `PutStakingInfoToDB` call is made for every `fetchResult.StakingInfo` that arrives from a peer, again with no state-root check.

**Consumption path:**

`GetStakingInfo` for pre-Kaia blocks reads the DB before falling back to state: [3](#0-2) 

The returned `StakingInfo` flows into `getDeferredRewardFull` → `assignStakingRewards`, which uses `cn.StakingAmount` and `cn.RewardAddr` to compute and credit KAIA: [4](#0-3) 

**`P2PStakingInfo` wire format** carries all reward-relevant fields with no integrity binding: [5](#0-4) 

**Handler** delivers the raw peer message directly to the downloader without any additional check: [6](#0-5) 

---

### Impact Explanation

A malicious peer can supply a `P2PStakingInfo` with:

- **Inflated `CouncilStakingAmounts`** for a chosen validator → that validator's `excess` stake dominates `totalExcess`, capturing a disproportionate share of the stakers' KAIA budget every block.
- **Substituted `CouncilRewardAddrs`** → staking rewards are credited to attacker-controlled addresses instead of legitimate validators.
- **Injected `CouncilNodeAddrs`** → a non-validator is inserted into the reward set.

The corrupted value is the `StakingAmounts []uint64` field persisted to `"stakingInfo" || Uint64LE(num)` in the misc DB: [7](#0-6) 

This directly corrupts the KAIA reward distribution for every block in the affected staking interval (up to `StakingUpdateInterval` blocks, default 86 400 blocks ≈ one day of blocks).

---

### Likelihood Explanation

- **`commitFastSyncData`**: triggered automatically during fast sync whenever a peer attaches staking info to a block at a staking-interval boundary. Any connected peer is a potential attacker; no operator action is required.
- **`SyncStakingInfo`**: requires an operator to invoke the recovery API with a specific peer ID, but the peer ID is operator-supplied and the peer is not authenticated beyond P2P connection.
- Scope is limited to pre-Kaia-hardfork blocks (the DB path is bypassed post-Kaia). On networks that have not yet activated the Kaia hardfork, or during state regeneration of historical pre-Kaia blocks, the corrupted staking info is used for live reward distribution.

---

### Recommendation

After receiving `P2PStakingInfo` from a peer, re-derive the staking info from the canonical state at the claimed block number and compare it field-by-field before persisting:

```go
// After receiving stakingInfo from peer:
canonical, err := s.stakingModule.getFromStateByNumber(stakingInfo.BlockNum)
if err != nil || !stakingInfoEqual(canonical, staking.ToStakingInfo(stakingInfo)) {
    return errors.New("peer staking info does not match canonical state")
}
d.stakingModule.PutStakingInfoToDB(stakingInfo.BlockNum, staking.ToStakingInfo(stakingInfo))
```

Alternatively, include a cryptographic commitment (e.g., a hash of the staking info) in the block header so that the received data can be verified against the committed value without a full state re-execution.

---

### Proof of Concept

1. Attacker runs a Kaia node and connects to a victim node that is fast-syncing (pre-Kaia hardfork chain).
2. When the victim requests staking info for block `N` (a staking-interval boundary), the attacker's `handleStakingInfoRequestMsg` handler returns a crafted `P2PStakingInfo` with `CouncilStakingAmounts[attacker_index] = math.MaxUint64` and `CouncilRewardAddrs[attacker_index] = attacker_address`.
3. The victim's `handleStakingInfoMsg` → `DeliverStakingInfos` → `commitFastSyncData` writes the falsified record to DB with no verification.
4. For all subsequent blocks in the staking interval, `GetStakingInfo` returns the falsified record from DB (cache hit), `assignStakingRewards` computes `excess = MaxUint64 - minStake ≈ MaxUint64`, `totalExcess ≈ MaxUint64`, so the attacker's validator captures nearly 100 % of the stakers' KAIA budget, credited to `attacker_address`. func (d *Downloader) SyncStakingInfo(id string, from, to uint64) error {
	if d.isStakingInfoRecovery {
		return errors.New("already syncing")
	}
	logger.Info("start syncing staking infos", "from", from, "to", to)
	d.isStakingInfoRecovery = true

	config := d.blockchain.Config()
	if config != nil && (config.IsKaiaForkEnabled(big.NewInt(int64(from))) || config.IsKaiaForkEnabled(big.NewInt(int64(to)))) {
		return fmt.Errorf("staking info recovery is only available before Kaia fork block (from: %v, to: %v)", from, to)
	}

	var (
		blockNums   []uint64
		blockHashes []common.Hash
	)
	stakingUpdateInterval := params.DefaultStakeUpdateInterval
	if config != nil && config.Governance != nil && config.Governance.Reward != nil {
		stakingUpdateInterval = config.Governance.Reward.StakingUpdateInterval
	}
	from = calcStakingBlockNumber(from, stakingUpdateInterval)
	for i := from; i <= to; i += stakingUpdateInterval {
		blockHash := d.stateDB.ReadCanonicalHash(i)
		if blockHash == (common.Hash{}) {
			d.isStakingInfoRecovery = false
			return fmt.Errorf("failed to retrieve block hash by number (blockNumber: %v)", i)
		}
		has := d.stakingModule.GetStakingInfoFromDB(i) != nil
		if !has {
			blockNums = append(blockNums, i)
			blockHashes = append(blockHashes, blockHash)
		}
	}

	if len(blockNums) == 0 && len(blockHashes) == 0 {
		d.isStakingInfoRecovery = false
		return fmt.Errorf("there is no staking info to be synced")
	}

	conn := d.peers.Peer(id)
	if conn == nil {
		d.isStakingInfoRecovery = false
		return errors.New("the given peer is not registered")
	}

	d.stakingInfoRecoveryBlocks = blockNums
	d.stakingInfoRecoveryTotal = len(blockNums)
	d.stakingInfoRecoveryCh = make(chan []*staking.P2PStakingInfo, 1)

	go func() {
		defer func() {
			d.isStakingInfoRecovery = false
			d.stakingInfoRecoveryBlocks = []uint64{}
			d.stakingInfoRecoveryTotal = 0
		}()

		fixed := 0
		for {
			timer := time.NewTimer(30 * time.Second)
			if len(blockHashes) > MaxStakingInfoFetch {
				go conn.peer.RequestStakingInfo(blockHashes[:MaxStakingInfoFetch])
				logger.Info("requested staking infos", "num", MaxStakingInfoFetch)
				blockHashes = blockHashes[MaxStakingInfoFetch:]
			} else if len(blockHashes) > 0 {
				go conn.peer.RequestStakingInfo(blockHashes)
				logger.Info("requested staking infos", "num", len(blockHashes))
				blockHashes = []common.Hash{}
			} else {
				logger.Error("no more requests, but not completed", "not completed", len(d.stakingInfoRecoveryBlocks))
				return
			}

			select {
			case <-timer.C:
				logger.Error("timeout")
				return
			case stakingInfos := <-d.stakingInfoRecoveryCh:
				logger.Info("received stakinginfos", "len", len(stakingInfos))
				for _, stakingInfo := range stakingInfos {
					if d.stakingInfoRecoveryBlocks[0] != stakingInfo.BlockNum {
						logger.Error("failed to receive expected block", "expected", d.stakingInfoRecoveryBlocks[0], "actual", stakingInfo.BlockNum)
						return
					}
					d.stakingModule.PutStakingInfoToDB(stakingInfo.BlockNum, staking.ToStakingInfo(stakingInfo))
					fixed++
					d.stakingInfoRecoveryBlocks = d.stakingInfoRecoveryBlocks[1:]
				}

				if len(d.stakingInfoRecoveryBlocks) == 0 {
					logger.Info("syncing staking info is finished", "fixed", fixed)
					return
				}
			}
		}
	}()
	return nil
}

func assignStakingRewards(config *reward.RewardConfig, stakersReward *big.Int, si *staking.StakingInfo) (map[common.Address]*big.Int, *big.Int) {
	var (
		cns               = si.ConsolidatedNodes()
		minStake          = config.MinimumStake.Uint64()
		totalExcessInt    = uint64(0) // sum of excess stakes (the amount over minStake) over all stakers
		cnTotalStakingMap = make(map[common.Address]uint64)
		isPrague          = config.Rules.IsPrague
	)
	for _, cn := range cns {
		// If the CNStaking is less than minStake, skip it.
		if cn.StakingAmount >= minStake {
			// Calculate total staking amount once
			cnTotalStakingAmount := cn.StakingAmount
			if isPrague && cn.CLStakingInfo != nil {
				cnTotalStakingAmount += cn.CLStakingInfo.CLStakingAmount
			}
			totalExcessInt += cnTotalStakingAmount - minStake
			cnTotalStakingMap[cn.RewardAddr] = cnTotalStakingAmount
		}
	}

	var (
		totalExcess = new(big.Int).SetUint64(totalExcessInt)
		remaining   = new(big.Int).Set(stakersReward)
		alloc       = make(map[common.Address]*big.Int)
	)
	for _, cn := range cns {
		cnTotalStakingAmount := cnTotalStakingMap[cn.RewardAddr]
		if cnTotalStakingAmount > minStake {
			// The KAIA unit will cancel out:
			// reward (kei) = excess (KAIA) * stakersReward (kei) / totalExcess (KAIA)
			excess := new(big.Int).SetUint64(cnTotalStakingAmount - minStake)
			if reward := new(big.Int).Div(new(big.Int).Mul(excess, stakersReward), totalExcess); reward.Sign() > 0 {
				if isPrague && cn.CLStakingInfo != nil {
					// The remaining amount will be added to the cnAmount.
					cnAmount, clAmount := cn.Split(reward)
					alloc[cn.RewardAddr] = cnAmount
					alloc[cn.CLStakingInfo.CLPoolAddr] = clAmount
				} else {
					alloc[cn.RewardAddr] = reward
				}
				remaining.Sub(remaining, reward)
			}
		}
	}
	return alloc, remaining

// handleStakingInfoMsg handles staking information response message.
func handleStakingInfoMsg(pm *ProtocolManager, p Peer, msg p2p.Msg) error {
	if pm.chainconfig.Istanbul == nil || pm.chainconfig.Istanbul.ProposerPolicy != uint64(istanbul.WeightedRandom) {
		return errResp(ErrUnsupportedEnginePolicy, "the engine is not istanbul or the policy is not weighted random")
	}

	// A batch of stakingInfos arrived to one of our previous requests
	var stakingInfos []*staking.P2PStakingInfo
	if err := msg.Decode(&stakingInfos); err != nil {
		return errResp(ErrDecode, "msg %v: %v", msg, err)
	}
	// Deliver all to the downloader
	if err := pm.downloader.DeliverStakingInfos(p.GetID(), stakingInfos); err != nil {
		logger.Debug("Failed to deliver staking information", "err", err)
	}
	return nil
