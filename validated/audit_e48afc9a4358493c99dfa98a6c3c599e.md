### Title
Content-Type spoofing bypasses `CopyGuardedContent` escape-sequence guard when color output is disabled - ([File: pkg/cmd/api/api.go])

### Summary
`processResponse` in `pkg/cmd/api/api.go` decides whether to sanitize response bytes based solely on the server-supplied `Content-Type` header (`isJSON`), trusting that "true JSON" responses are safe because they'll later be JSON-parsed. When `isJSON` is true but `opts.IO.ColorEnabled()` is false (e.g. `NO_COLOR` set, `--color=never`, or a terminal without detected color support even though it is still a TTY), the code takes the `else` branch and performs a raw `io.Copy(bodyWriter, responseBody)` with **no JSON parsing and no `CopyGuardedContent` call**, so a malicious/compromised host can send arbitrary control bytes labeled as `application/json` straight to the victim's terminal.

### Finding Description

There are two paths that are supposed to keep raw/dangerous bytes off the terminal:
1. `isJSON && opts.IO.ColorEnabled()` → `jsoncolor.Write`, which uses `encoding/json.Decoder.Token()` to strictly parse the stream; malformed non-JSON bytes (e.g. a lone `0x1B` control byte outside a JSON string) cause `dec.Token()` to return a decode error and abort before any output is emitted: [3](#0-2) 
2. `!isJSON` → `iostreams.CopyGuardedContent`, which sniffs for binary content and scans text for `0x1B` escape bytes before writing anything: [4](#0-3) 

The gap is the **third combination**: `isJSON == true` (attacker sets `Content-Type: application/json`) **and** `ColorEnabled() == false` (e.g. `NO_COLOR=1`, `--color=never`, or a TTY without recognized color support). In that case neither guard applies — the code falls to the bare `else { io.Copy(bodyWriter, responseBody) }` at line 542, streaming the response body byte-for-byte with no JSON validation and no escape-sequence check, even if `opts.IO.IsStdoutTTY()` is true. Since `Content-Type` is attacker-controlled (the victim explicitly points `gh api` at a host they configured, e.g. a GHE-style host via `--hostname`/`GH_HOST`, or a full URL argument), the attacker can label an arbitrary byte stream (not even valid JSON) as `application/json` and have it echoed verbatim to the terminal, defeating the “output safety” invariant that the code comment at lines 530–533 asserts (“A raw non-JSON body is the only response the transport does not sanitize”) — that assumption is false because the JSON branch itself only sanitizes when colorization is also active.

### Impact Explanation
This allows terminal escape-sequence injection (ANSI/OSC sequences) into the victim's terminal when running `gh api` with color disabled against an attacker-controlled or attacker-influenced host, potentially enabling terminal title/clipboard manipulation, hidden prompt injection, or in vulnerable terminal emulators, more severe terminal-escape-based attacks. This matches a "terminal escape sequence injection leading to output/terminal manipulation" bounty class; it is a guard-bypass rather than direct RCE.

### Likelihood Explanation
Requires the victim to run `gh api` against a host the attacker controls or influences (an accepted attacker capability per the rules) with color output disabled — a common, realistic condition (`NO_COLOR` env var, `--color=never`, CI/minimal terminals, or terminals not detected as color-capable while still being a TTY). No special privileges beyond controlling the target host's HTTP response are needed, and the attack is fully repeatable/deterministic.

### Recommendation
Do not treat `isJSON` (header-derived) as sufficient proof that content is safe to stream unguarded. Either: (a) always route the `else` (`io.Copy`) branch through `CopyGuardedContent` regardless of `isJSON` when writing to `bodyWriter`, or (b) validate that the body is actually well-formed JSON (e.g., via a bounded parse/sniff) before allowing the unguarded raw copy, falling back to `CopyGuardedContent` otherwise.

func CopyGuardedContent(w io.Writer, r io.Reader, isTTY bool) error {
	head := make([]byte, contentSniffLen)
	n, err := io.ReadFull(r, head)
	if err != nil && !errors.Is(err, io.EOF) && !errors.Is(err, io.ErrUnexpectedEOF) {
		return err
	}
	head = head[:n]

	if mime, ok := BinaryContentType(head); ok {
		if isTTY {
			return BinaryTerminalError{MIME: mime}
		}
		if _, err := w.Write(head); err != nil {
			return err
		}
		_, err := io.Copy(w, r)
		return err
	}

	rest, err := io.ReadAll(r)
	if err != nil {
		return err
	}
	content := append(head, rest...)
	if ContainsEscapeSequence(content) {
		return ErrEscapeSequence
	}
	_, err = w.Write(content)
	return err
