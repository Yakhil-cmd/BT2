### Title
Arbiter-contract escrow funds can be permanently frozen with no on-chain timeout if the arbiter or counterparty never acts - ([File: arbiter_contract.js])

### Summary
The `arbiter_contract` module builds a shared-address escrow whose spending definition only allows release of funds via (a) mutual agreement of both parties, or (b) the arbiter posting a `data_feed` verdict. There is no on-chain timestamp/expiry clause in the definition itself that lets the paying party unilaterally reclaim funds if the arbiter never resolves the dispute (or disappears) and the counterparty never cooperates. This mirrors the SKALE report's bug class: an unprivileged party's funds become dependent on a third party meeting a condition that may never be satisfied, with no protocol-level escape hatch, resulting in funds being frozen indefinitely.

### Finding Description
When two peers create an arbiter contract, `deriveSharedAddress()` builds the on-chain spending condition for the shared escrow address as an `or` of five branches: mutual signature by both parties, a "complete"/"cancel" branch requiring `has output` (public assets), and two branches requiring `in data feed` from the **arbiter address** for `CONTRACT_<hash>` or `CONTRACT_DONE_<hash>` [1](#0-0) . For private assets the "complete"/"cancel" branches likewise depend on a `data_feed` (`CONTRACT_DONE_...`) posted by the counterparty rather than a straightforward payment condition [2](#0-1) .

Once money is paid into this shared address via `pay()` [3](#0-2) , the only ways out are:
1. Both parties cooperate (`complete()`, which needs the counterparty's/offeror's cooperation to build/sign the payout, or relies on the arbiter's data feed value) [4](#0-3) .
2. A dispute is opened and the **arbiter** posts a `CONTRACT_<hash>` data-feed verdict identifying the winner [5](#0-4) , [6](#0-5) .

There is no branch in the shared-address definition that allows a party to reclaim funds unilaterally after a timeout. The wallet does store a `ttl` field (default 168 hours) in `wallet_arbiter_contracts` [7](#0-6) , but this `ttl` is purely local wallet metadata used before a contract is signed/paid (it is never referenced in `deriveSharedAddress()` and is not encoded into the on-chain definition as a `timestamp`/`not before` clause) — a search of `arbiter_contract.js` for `timestamp`, `not before`, or `expiry` confirms none is used to gate the escrow's spending conditions. If the arbiter becomes unresponsive, loses their key, refuses to act, or the counterparty simply never agrees to a mutual release, the payer's funds in the shared address are permanently locked with no on-chain fallback — analogous to the SKALE MSR delegation lock where token holders cannot exit if the validator (a similarly relied-upon third party) never satisfies a required condition.

### Impact Explanation
Funds sent to the arbiter-contract shared address can be frozen indefinitely (permanent, not merely delayed) whenever the arbiter is unavailable, non-cooperative, or compromised, and the counterparty does not agree to a mutual settlement. Since this is a core primitive shipped with `ocore` for arbitrated escrow payments (used by any private-payment counterparty relying on the arbiter-contract feature), the impact is AA/contract fund freezing for legitimate, unprivileged users — matching the "AA fund loss or freezing" impact class.

### Likelihood Explanation
Likelihood is realistic though not guaranteed: it requires only an unresponsive/malicious/disappearing arbiter (a normal deployment risk, not a "malicious peer/node" network-layer attack) combined with a counterparty who does not cooperate to sign a mutual release — both plausible and outside the payer's control, exactly as in the SKALE case where a validator's failure to meet MSR is outside the delegator's control. No special privileges are needed to trigger it; it results from normal use of the shipped escrow feature.

### Recommendation
Add a time-based escape clause to the shared-address definition generated in `deriveSharedAddress()`, e.g. an additional `or` branch allowing the payer (or both original parties by majority/timeout) to reclaim the escrowed funds unilaterally after a defined on-chain `timestamp` has elapsed without arbiter resolution or mutual completion, similar to how `ttl` is already tracked in the wallet database but currently unenforced on-chain. This provides a guaranteed exit path independent of arbiter or counterparty cooperation.

### Proof of Concept
1. Two parties create and sign an arbiter contract; the payer calls `pay()`, sending funds to the generated shared address whose definition is built by `deriveSharedAddress()` (arbiter_contract.js:454-574).
2. A dispute arises; `openDispute()` is called and the request is sent to the arbstore/arbiter (arbiter_contract.js:262-319).
3. The arbiter never publishes a `data_feed` message with key `CONTRACT_<hash>` (e.g., is offline, loses keys, or simply refuses), and the counterparty never cooperates to co-sign a `complete()`/refund transaction.
4. Because the shared address's definition (arbiter_contract.js:465-538) has no branch permitting single-party withdrawal after any elapsed time, the funds in the shared address remain permanently unspendable — verifiable by inspecting that `deriveSharedAddress()` only contains the mutual-signature, "has output", and arbiter-data-feed branches, with no `timestamp`/`not before` condition anywhere in `arbiter_contract.js`.

function pay(hash, walletInstance, arrSigningDeviceAddresses, cb) {
	getByHash(hash, function(objContract) {
		if (!objContract.shared_address || objContract.status !== "signed" || !objContract.me_is_payer)
			return cb("contract can't be paid");
		var opts = {
			asset: objContract.asset,
			to_address: objContract.shared_address,
			amount: objContract.amount,
			spend_unconfirmed: walletInstance.spendUnconfirmed ? 'all' : 'own'
		};
		if (arrSigningDeviceAddresses.length)
			opts.arrSigningDeviceAddresses = arrSigningDeviceAddresses;
		walletInstance.sendMultiPayment(opts, function(err, unit){								
			if (err)
				return cb(err);
			setField(objContract.hash, "status", "paid", function(objContract){
				cb(null, objContract, unit);
			});
			// listen for peer announce to withdraw funds
			storage.readAssetInfo(db, objContract.asset, function(assetInfo) {
				if (assetInfo && assetInfo.is_private)
					db.query("INSERT "+db.getIgnore()+" INTO my_watched_addresses (address) VALUES (?)", [objContract.peer_address]);
			});
		});
	});

function complete(hash, walletInstance, arrSigningDeviceAddresses, cb) {
	getByHash(hash, async function(objContract) {
		if (objContract.status !== "paid" && objContract.status !== "in_dispute")
			return cb("contract can't be completed");
		const err = await fillArbstoreAddresses(objContract);
		if (err)
			return cb(err);
		storage.readAssetInfo(db, objContract.asset, function(assetInfo) {
			var opts;
			new Promise((resolve, reject) => {
				if (assetInfo && assetInfo.is_private) {
					var value = {};
					value["CONTRACT_DONE_" + objContract.hash] = objContract.peer_address;
					opts = {
						spend_unconfirmed: walletInstance.spendUnconfirmed ? 'all' : 'own',
						paying_addresses: [objContract.my_address],
						signing_addresses: [objContract.my_address],
						change_address: objContract.my_address,
						messages: [{
							app: 'data_feed',
							payload_location: "inline",
							payload_hash: objectHash.getBase64Hash(value, true),
							payload: value
						}]
					};
					resolve();
				} else {
					opts = {
						spend_unconfirmed: walletInstance.spendUnconfirmed ? 'all' : 'own',
						paying_addresses: [objContract.shared_address],
						change_address: objContract.shared_address,
						asset: objContract.asset
					};
					if (objContract.me_is_payer && !(assetInfo && (assetInfo.fixed_denominations || assetInfo.is_private))) { // complete
						require("./wallet_defined_by_addresses.js").readSharedAddressDefinition(objContract.shared_address, function (arrDefinition) {
							const index = objContract.is_incoming ? 2 : 1;
							const peer_amount = arrDefinition[1][index][1][1][1].amount;
							const arbstore_amount = arrDefinition[1][index][1][2] && arrDefinition[1][index][1][2][0] === 'has' ? arrDefinition[1][index][1][2][1].amount : 0;
							if (!isFinite(peer_amount) || !isFinite(arbstore_amount))
								throw new Error("invalid amounts in shared address definition: " + JSON.stringify(arrDefinition));
							if (peer_amount + arbstore_amount !== objContract.amount)
								throw new Error(`amounts in shared address definition do not sum up to contract amount: ${peer_amount} + ${arbstore_amount} !== ${objContract.amount}`);
							if (arbstore_amount > peer_amount)
								throw new Error(`arbstore cut is more than 50% of the total amount, peer_amount: ${peer_amount}, arbstore_amount: ${arbstore_amount}`);
							if (arbstore_amount === 0) {
								opts.to_address = objContract.peer_address;
								opts.amount = objContract.amount;
							} else {
								opts[objContract.asset && objContract.asset != "base" ? "asset_outputs" : "base_outputs"] = [
									{ address: objContract.peer_address, amount: peer_amount},
									{ address: objContract.arbstore_address, amount: arbstore_amount},
								];
							}
							resolve();
						});
					} else { // refund
						opts.to_address = objContract.peer_address;
						opts.amount = objContract.amount;
						resolve();
					}
				}
			}).then(() => {
				if (arrSigningDeviceAddresses.length)
					opts.arrSigningDeviceAddresses = arrSigningDeviceAddresses;
				walletInstance.sendMultiPayment(opts, function(err, unit){
					if (err)
						return cb(err);
					var status = objContract.me_is_payer ? "completed" : "cancelled";
					setField(objContract.hash, "status", status, function(objContract){
						cb(null, objContract, unit);
					});
				});
			}).catch(err => {
				cb(err);
			});
		});
	});
}

function parseWinnerFromUnit(contract, objUnit) {
	if (objUnit.authors[0].address !== contract.arbiter_address) {
		return;
	}
	var key = "CONTRACT_" + contract.hash;
	var winner;
	objUnit.messages.forEach(function(message){
		if (message.app !== "data_feed" || !message.payload || !message.payload[key]) {
			return;
		}
		winner = message.payload[key];
	});
	if (!winner || (winner !== contract.my_address && winner !== contract.peer_address)) {
		return;
	}
	return winner;
}
