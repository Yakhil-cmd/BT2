### Title
Terminal escape/control sequence injection via unsanitized skill metadata in `checkOverwrite`/`existingSkillPrompt` prompts - (File: pkg/cmd/skills/install/install.go)

### Summary
`existingSkillPrompt` builds a confirmation prompt string by directly interpolating `incoming.DisplayName()` and a `sourceName` derived from attacker-controlled `SKILL.md` frontmatter (`github-repo`, `github-ref`) with no control-character or ANSI/OSC stripping, then passes it straight into `opts.Prompter.Confirm(prompt, false)`, which renders it to the terminal via the `huh` prompter.

### Finding Description
`checkOverwrite` [1](#0-0)  calls `existingSkillPrompt` for every already-installed skill name that collides with an incoming install. `existingSkillPrompt` reads the previously-installed `SKILL.md`, parses its frontmatter with `frontmatter.Parse`, and extracts `github-ref` and repo info via `source.ParseMetadataRepo` — all attacker-controlled fields from a published skill — and formats them unsanitized into the prompt text: [2](#0-1) .

This string is then passed to `opts.Prompter.Confirm(prompt, false)` [3](#0-2) , which in the `huh` prompter implementation sets it directly as a form `Title(prompt)` with no sanitization step in between [4](#0-3) . Similarly `fmt.Fprintf(opts.IO.ErrOut, "Skipping %s\n", s.DisplayName())` writes `DisplayName()` (also attacker-influenced) directly to the terminal.

Unlike other output paths in the codebase (e.g. `pkg/cmd/skills/list/list.go`, `pkg/cmd/skills/preview/preview.go`, `pkg/iostreams/untrusted.go`) which reference sanitize/untrusted-content helpers before rendering attacker-supplied text, no equivalent call is present in `checkOverwrite`/`existingSkillPrompt`. I was not able to fully confirm, within the available tool budget, whether `pkg/iostreams/untrusted.go`'s sanitization is applied anywhere upstream of this specific code path (e.g., inside `discovery.Skill.DisplayName()` or `frontmatter.Parse`), which would materially affect whether this is exploitable in practice.

### Impact Explanation
If unsanitized, this would allow raw terminal control/escape sequences (e.g., OSC 8 hyperlinks with non-http schemes, terminal title reporting, bracketed-paste manipulation) embedded in a skill's name or frontmatter to be emitted to the victim's terminal when they re-run `gh skills install` over an already-installed, attacker-published skill. Depending on the victim's terminal emulator, this could range from cosmetic terminal corruption up to arbitrary command injection via terminal-emulator-specific auto-execute behaviors — this class of bug is typically scoped as an information/terminal integrity issue in `gh` itself, escalating to RCE only if the victim's specific terminal emulator has an exploitable OSC/DCS handling bug.

### Likelihood Explanation
Exploitation requires the victim to have already installed the attacker's malicious skill once (so the malicious `SKILL.md` frontmatter exists on disk locally) and then re-run install for a skill with the same name, triggering the overwrite-confirmation prompt. This narrows the practical attack surface compared to a first-run/fresh-download scenario, and the ultimate impact is heavily terminal-emulator-dependent rather than guaranteed RCE purely from `gh`'s code.

### Recommendation
Sanitize all attacker-controlled strings (`DisplayName()`, repo full name, ref, and any frontmatter-derived text) before interpolating them into any prompt title or writing them to `opts.IO.ErrOut`/`opts.IO.Out`, using the existing sanitization utilities in `pkg/iostreams/untrusted.go` (or equivalent control-character stripping) prior to calling `existingSkillPrompt`, `Confirm`, and the `fmt.Fprintf` skip message.

```go
func TestExistingSkillPromptSanitizesControlChars(t *testing.T) {
    dir := t.TempDir()
    skillDir := filepath.Join(dir, "evil-skill")
    require.NoError(t, os.MkdirAll(skillDir, 0o755))
    payload := "\x1b]8;;file:///etc/passwd\x1b\\clickme\x1b]8;;\x1b\\"
    md := fmt.Sprintf("---\ngithub-repo: owner/repo\ngithub-ref: %s\n---\nbody", payload)
    require.NoError(t, os.WriteFile(filepath.Join(skillDir, "SKILL.md"), []byte(md), 0o644))

    prompt := existingSkillPrompt(dir, discovery.Skill{Name: "evil-skill"})
    require.NotContains(t, prompt, "\x1b]8", "OSC 8 hyperlink sequences must be stripped from prompt text")
    require.NotContains(t, prompt, "\x1b", "raw escape sequences must not reach the terminal renderer")
}
```
Expected: the assertions currently fail because no sanitization is applied, confirming the raw escape sequence reaches the rendered prompt text unmodified.

```go
func checkOverwrite(opts *InstallOptions, skills []discovery.Skill, targetDir string, canPrompt bool) ([]discovery.Skill, error) {
	var existing, fresh []discovery.Skill
	for _, s := range skills {
		dir := filepath.Join(targetDir, s.Name)
		if _, err := os.Stat(dir); err == nil {
			existing = append(existing, s)
		} else {
			fresh = append(fresh, s)
		}
	}

	if len(existing) == 0 {
		return skills, nil
	}

	if opts.Force {
		return skills, nil
	}

	if !canPrompt {
		names := make([]string, len(existing))
		for i, s := range existing {
			names[i] = s.DisplayName()
		}
		return nil, fmt.Errorf("skills already installed: %s (use --force to overwrite)", strings.Join(names, ", "))
	}

	var confirmed []discovery.Skill
	for _, s := range existing {
		prompt := existingSkillPrompt(targetDir, s)
		ok, err := opts.Prompter.Confirm(prompt, false)
		if err != nil {
			return nil, err
		}
		if ok {
			confirmed = append(confirmed, s)
		} else {
			fmt.Fprintf(opts.IO.ErrOut, "Skipping %s\n", s.DisplayName())
		}
	}

	return append(fresh, confirmed...), nil
}
```

```go
func existingSkillPrompt(targetDir string, incoming discovery.Skill) string {
	skillFile := filepath.Join(targetDir, incoming.Name, "SKILL.md")
	data, err := os.ReadFile(skillFile)
	if err != nil {
		return fmt.Sprintf("Skill %q already exists. Overwrite?", incoming.DisplayName())
	}

	result, err := frontmatter.Parse(string(data))
	if err != nil || result.Metadata.Meta == nil {
		return fmt.Sprintf("Skill %q already exists. Overwrite?", incoming.DisplayName())
	}

	repoInfo, _, err := source.ParseMetadataRepo(result.Metadata.Meta)
	ref, _ := result.Metadata.Meta["github-ref"].(string)
	if err != nil {
		return fmt.Sprintf("Skill %q already exists. Overwrite?", incoming.DisplayName())
	}

	if repoInfo != nil {
		sourceName := ghrepo.FullName(repoInfo)
		if ref != "" {
			sourceName += "@" + ref
		}
		return fmt.Sprintf("Skill %q already installed from %s. Overwrite?", incoming.DisplayName(), sourceName)
	}

	return fmt.Sprintf("Skill %q already exists. Overwrite?", incoming.DisplayName())
}
```

```go
func (p *huhPrompter) buildConfirmForm(prompt string, defaultValue bool) (*huh.Form, *bool) {
	result := defaultValue
	form := p.newForm(
		huh.NewGroup(
			huh.NewConfirm().
				Title(prompt).
				Value(&result),
		),
	)
	return form, &result
}

func (p *huhPrompter) Confirm(prompt string, defaultValue bool) (bool, error) {
	form, result := p.buildConfirmForm(prompt, defaultValue)
	err := p.runForm(form)
	if err != nil {
		return false, err
	}
	return *result, nil
}
```
