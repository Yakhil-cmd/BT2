### Title
Untracked-file review bypass via mtime forgery in `_unchanged_since_baseline` - ([File: plugins/security-guidance/hooks/diffstate.py])

### Summary
`compute_v2_review_set` excludes a pre-existing untracked file from the review set solely on the basis of an `st_mtime_ns` equality check against a snapshot taken at `UserPromptSubmit` (`untracked_at_baseline`). Because this check uses filesystem-supplied, attacker-controllable timestamp metadata instead of content hashing, a file that is pre-staged before the baseline snapshot and later rewritten with malicious content — while its mtime is restored to the exact baseline nanosecond value — is treated as "unchanged" and silently dropped from `dirty_now`/`review_set`, skipping the security review entirely.

### Finding Description
`_list_untracked` (diffstate.py:319-351) snapshots untracked/not-ignored files as `{repo-relative path: st_mtime_ns}` at UPS time; this is stored as `untracked_at_baseline` [1](#0-0) . At Stop, `compute_v2_review_set` computes `_unchanged_since_baseline(p)`, which simply re-stats the file and compares `st_mtime_ns` to the stored baseline value [2](#0-1) . Files judged "unchanged" this way (`preexisting_unchanged`) are subtracted from `untracked` to form `new_untracked`, and only `new_untracked` (not the raw `untracked` set) is folded into `dirty_now` and later into `changed_since` [3](#0-2) . Since `git stash create` never captures untracked files, there is no independent content-based signal (e.g., blob hash/diff) backing this exclusion — `st_mtime_ns` equality is the *only* gate. `review_set = dirty_now & changed_since` therefore fully excludes the file if it is judged unchanged by this metadata check, regardless of its actual content [4](#0-3) .

An attacker (or prompt-injected agent action) with write access to the working tree between baseline capture and Stop can: (1) ensure a malicious-but-benign-looking untracked file already exists before the turn so it's captured with mtime `T` in `untracked_at_baseline`; (2) during the turn, overwrite the file's content with an unsafe payload; (3) restore the exact nanosecond mtime `T` via `os.utime(path, ns=(T, T))` or `touch -r`. Nanosecond-precision `utimensat` is standard on Linux, so exact reproduction of `st_mtime_ns` is trivial and requires no elevated privilege — only ordinary filesystem write access, which is the stated precondition.

### Impact Explanation
This defeats the intended invariant that "review scope must not be spoofable via filesystem metadata." An unsafe/injected code change can be smuggled into an untracked file and reach Stop without ever entering `review_set`, meaning the security-guidance review pipeline (and any downstream vulnerability-flagging/blocking behavior gated on `review_set`) never inspects the malicious content. This is a security-review bypass — the security-relevant impact is that Claude Code's own safety net for uncommitted/untracked edits can be evaded by trust-boundary-crossing content (e.g., a prompt-injected shell action) that both writes and re-times a file.

### Likelihood Explanation
Feasible and repeatable: it requires (a) a pre-existing untracked file present before the session's UPS baseline capture, and (b) an action during the turn that both edits the file and resets `st_mtime_ns` to the previously observed value. Both are ordinary filesystem operations reachable via a normal Bash/Edit tool call, including one driven by prompt-injected repository content instructing such a rewrite-and-touch sequence. No race condition or timing granularity issue is even required, since the attacker can directly stat-and-restore the exact nanosecond value.

### Recommendation
Replace or augment the mtime-equality check with a content-based comparison (e.g., store and compare a content hash/blob id, or file size + hash, captured at UPS instead of/along with mtime) so an attacker cannot spoof "unchanged" status purely via timestamp metadata. At minimum, treat mtime match as necessary but not sufficient, always cross-checking `size` and a fast digest of file contents against the baseline snapshot before excluding a file from `dirty_now`/`review_set`.

### Proof of Concept
Unit test plan for `_list_untracked` + `compute_v2_review_set`:
1. In a temp git repo, create untracked file `f` with content `"benign"`.
2. Call `_list_untracked(repo)` to obtain `untracked_at_baseline = {"f": T}`.
3. Overwrite `f` with content `"malicious payload"`.
4. Restore timestamp: `os.utime(os.path.join(repo, "f"), ns=(T, T))`.
5. Call `compute_v2_review_set(repo, baseline_sha, head_at_capture, untracked_at_baseline)`.
6. Assert `"f"` (as absolute path) is present in the returned `review_paths` / `review_set`. Expected (bug) result: `"f"` is absent because `_unchanged_since_baseline("f")` returns `True`, demonstrating the review-scope bypass.

def _list_untracked(cwd):
    """Repo-root-relative untracked (and not-ignored) path → mtime_ns, or {}
    on error. Used at UPS to snapshot the pre-turn untracked set so the Stop
    hook can exclude unchanged pre-existing untracked files from review.
    mtime is captured so an in-place edit during the turn is still reviewed.

    Uses ls-files (not status) for the UPS path: the index diff isn't needed,
    and ls-files --others only walks the worktree against .gitignore."""
    try:
        repo = _git_toplevel(cwd) or cwd
        r = subprocess.run(
            [*GIT_CMD, "-c", "core.quotePath=false", "ls-files",
             "--others", "--exclude-standard", "-z"],
            cwd=repo, capture_output=True, text=True, timeout=15,
        )
        if r.returncode != 0:
            debug_log(f"_list_untracked rc={r.returncode}: {r.stderr[:200]}")
            return {}
        out = {}
        for p in r.stdout.split("\0"):
            if not p:
                continue
            try:
                out[p] = os.stat(os.path.join(repo, p)).st_mtime_ns
            except OSError:
                out[p] = 0
            if len(out) >= UNTRACKED_BASELINE_CAP:
                debug_log(f"_list_untracked: capped at {UNTRACKED_BASELINE_CAP}")
                break
        return out
