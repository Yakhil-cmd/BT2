`unstake-sbtc` specifically is not even routed to any of the lock-mutating handlers in `handle_contract_call` — it only triggers `global_context.log_pox_action(staker)` for post-condition bookkeeping, since it never touches the STX lock (only sBTC custody, which is handled purely inside `pox-5.clar`). So there is no reachable path from any pox-5 `contract-call?` (stake, register-for-bond, unstake, unstake-sbtc, stake-update, claim-rewards) into `parse_pox_increase`. The alleged target function is simply not on the pox-5 call graph.

/// Handle special cases when calling into the PoX-5 API contract
pub fn handle_contract_call(
    global_context: &mut GlobalContext,
    sender_opt: Option<&PrincipalData>,
    _contract_id: &QualifiedContractIdentifier,
    function_name: &str,
    _args: &[Value],
    value: &Value,
) -> Result<(), VmExecutionError> {
    // Execute function specific logic to complete the lock-up. Only the ops
    // with a lock/event side effect appear here.
    let lock_event_opt = match function_name {
        "stake" | "register-for-bond" => {
            handle_lockup_pox_v5(global_context, function_name, value)?
        }
        "stake-update" => handle_stake_lockup_update_pox_v5(global_context, function_name, value)?,
        "unstake" => handle_unstake_pox_v5(global_context, function_name, value)?,
        _ => None,
    };

    // Record a position-altering PoX action for the affected staker (always
    // `tx-sender`, i.e. `sender_opt`), so that transaction-level `Pox`
    // post-conditions and `with-pox` allowances can constrain them. Recorded
    // whether or not the call succeeded, so an allowance can gate even a failed
    // attempt.
    if matches!(
        function_name,
        "unstake" | "unstake-sbtc" | "update-bond-registration" | "announce-l1-early-exit"
    ) {
        if let Some(staker) = sender_opt {
            global_context.log_pox_action(staker)?;
        }
    }

    // append the lockup event
    if let Some((batch, _)) = global_context.event_batches.last_mut() {
        if let Some(lock_event) = lock_event_opt {
            batch.events.push(lock_event);
        }
    }

    Ok(())
}
