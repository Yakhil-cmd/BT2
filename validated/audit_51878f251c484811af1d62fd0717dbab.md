### Title
Missing Zero-Value Validation for `kip71.gastarget` Governance Parameter Causes Network-Halting Panic in Base Fee Computation — (`kaiax/gov/param.go`, `params/kip71_config.go`)

---

### Summary

The `Kip71GasTarget` governance parameter uses `noopFormatChecker` (always returns `true`), allowing a valid governance vote to set `kip71.gastarget = 0`. Once ratified, every subsequent call to `NextMagmaBlockBaseFee` with any non-zero `parentGasUsed` performs an integer division by zero, panicking and crashing all nodes. The analogous parameter `Kip71BaseFeeDenominator` has both a non-zero `FormatChecker` **and** a runtime zero-guard in `NextMagmaBlockBaseFee`; `Kip71GasTarget` has neither.

---

### Finding Description

**Root cause — missing `FormatChecker` for `Kip71GasTarget`:**

`kaiax/gov/param.go` defines every governance parameter with a `Canonicalizer` and a `FormatChecker`. `Kip71BaseFeeDenominator` correctly rejects zero:

```go
Kip71BaseFeeDenominator: {
    Canonicalizer: uint64Canonicalizer,
    FormatChecker: func(cv any) bool {
        v, ok := cv.(uint64)
        return ok && v != 0          // ← zero rejected
    },
    ...
},
``` [1](#0-0) 

`Kip71GasTarget` uses `noopFormatChecker`, which unconditionally returns `true`, so `0` is accepted:

```go
Kip71GasTarget: {
    Canonicalizer: uint64Canonicalizer,
    FormatChecker: noopFormatChecker,   // ← accepts any value, including 0
    ...
    DefaultValue: uint64(30000000),
},
``` [2](#0-1) 

**No cross-parameter consistency check for `kip71.gastarget`:**

`checkConsistency` in `kaiax/gov/headergov/impl/header.go` validates `Kip71LowerBoundBaseFee` and `Kip71UpperBoundBaseFee` against each other, but places `Kip71GasTarget` in the unconditional `return nil` bucket with no additional checks:

```go
case gov.Kip71BaseFeeDenominator, gov.Kip71GasTarget, gov.Kip71MaxBlockGasUsedForBaseFee,
    ...
    return nil
``` [3](#0-2) 

**Division by zero in `NextMagmaBlockBaseFee`:**

`params/kip71_config.go` has a runtime guard for `BaseFeeDenominator == 0` (lines 71–76) but no equivalent guard for `gasTarget`. When `parentGasUsed > gasTarget` (i.e., `parentGasUsed > 0` when `gasTarget == 0`), the function divides by `gasTarget`:

```go
gasTarget := kc.GasTarget          // == 0 after malicious vote
...
} else if parentGasUsed > gasTarget {
    gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
    x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
    y := x.Div(x, new(big.Int).SetUint64(gasTarget))  // ← panic: divide by zero
``` [4](#0-3) 

The same unguarded division appears in the `parentGasUsed < gasTarget` branch:

```go
y := x.Div(x, new(big.Int).SetUint64(gasTarget))   // line 120
``` [5](#0-4) 

`NextMagmaBlockBaseFee` is called on every block in two critical paths:

1. **Block verification** — `VerifyMagmaHeader` → `NextMagmaBlockBaseFee` (all nodes crash verifying any block)
2. **Tx pool update** — `tx_pool.go` line 576 calls `NextMagmaBlockBaseFee` on every new head [6](#0-5) 

---

### Impact Explanation

Once `kip71.gastarget = 0` is ratified and takes effect, every block produced on a live network will have `parentGasUsed > 0`. The panic in `NextMagmaBlockBaseFee` crashes every node that attempts to verify or build on that block. The result is a permanent, irrecoverable network halt: no new blocks can be produced or verified, all KAIA transfers, bridge settlements, and governance operations are frozen. This matches the allowed impact category: **invalid block acceptance / consensus divergence on honest nodes** and **persistent corruption of canonical execution**.

---

### Likelihood Explanation

In `single` governance mode (Mainnet and Kairos), only the single governing node needs to be compromised or act maliciously. In `none` mode, any council member can cast the decisive vote. This is not majority-validator collusion — a single semi-trusted actor suffices. The vote passes all existing validation layers because `noopFormatChecker` accepts `0` and `checkConsistency` performs no check on `kip71.gastarget`.

---

### Recommendation

1. **Add a non-zero `FormatChecker` for `Kip71GasTarget`** in `kaiax/gov/param.go`, mirroring `Kip71BaseFeeDenominator`:
   ```go
   Kip71GasTarget: {
       Canonicalizer: uint64Canonicalizer,
       FormatChecker: func(cv any) bool {
           v, ok := cv.(uint64)
           return ok && v != 0
       },
       ...
   },
   ```

2. **Add a runtime zero-guard in `NextMagmaBlockBaseFee`** in `params/kip71_config.go`, analogous to the existing `BaseFeeDenominator` guard:
   ```go
   if kc.GasTarget == 0 {
       // Defensive: governance should have rejected this, but avoid panic
       return makeEvenByFloor(lowerBoundBaseFee)
   }
   ```

---

### Proof of Concept

1. Governing node calls `governance_vote("kip71.gastarget", 0)` via RPC.
2. `NewVoteData` canonicalizes `0` → `uint64(0)`; `noopFormatChecker(uint64(0))` returns `true` → vote accepted and stored.
3. Vote is inscribed in `header.Vote` when the governing node proposes a block.
4. `VerifyVote` on peer nodes calls `checkConsistency` for `Kip71GasTarget` → falls into the `return nil` case → vote accepted by all peers.
5. At the next epoch block, the vote is ratified; `GasTarget = 0` is written to `header.Governance` and persisted.
6. `GasTarget = 0` becomes effective for the following epoch.
7. On the first block of the new epoch, any node calling `NextMagmaBlockBaseFee` with `parentGasUsed > 0` (virtually guaranteed on a live network) executes:
   ```
   y := x.Div(x, new(big.Int).SetUint64(0))
   // runtime panic: integer divide by zero
   ```
8. All nodes crash. The network is permanently halted.
