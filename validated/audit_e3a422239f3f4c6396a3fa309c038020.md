### Title
`gh pr view` writes attacker-controlled PR title/body directly to `IO.Out`, bypassing the `asciisanitizer` pipeline that `newContentWriter` provides - ([File: pkg/cmd/pr/view/view.go])

### Summary
`printHumanPrPreview` and `printRawPrPreview` in `pkg/cmd/pr/view/view.go` write the glamour-rendered PR body, the raw PR body, and the PR title directly to `opts.IO.Out` via `fmt.Fprintf`/`fmt.Fprintln`, never through `opts.IO.ContentOut`. `newContentWriter` in `pkg/iostreams/iostreams.go:503` correctly wraps a writer with `asciisanitizer.Sanitizer` when sanitization is enabled, but that sanitized writer is simply never used for this output path.

### Finding Description
`IOStreams.Out` is a raw passthrough writer to stdout (with only Windows ANSI-to-console translation, not content sanitization) [1](#0-0) . The dedicated sanitized writer for untrusted content is `ContentOut`, built by `newContentWriter`, which wraps the underlying writer with `transform.NewWriter(out, &asciisanitizer.Sanitizer{})` when sanitization is enabled [2](#0-1) .

In `pkg/cmd/pr/view/view.go`, `printHumanPrPreview` renders `pr.Body` (fully attacker-controlled: an issue/PR body an attacker authored) through `markdown.Render` (glamour) and then writes the result with `fmt.Fprintf(out, "\n%s\n", md)` where `out := opts.IO.Out` [3](#0-2) . The PR title is likewise written unsanitized: `fmt.Fprintf(out, "%s %s#%d\n", cs.Bold(pr.Title), ...)` [4](#0-3) . `printRawPrPreview` (used for non-TTY output, e.g., piped/redirected) also writes the raw, unrendered `pr.Body` straight to `out` with `fmt.Fprintln(out, pr.Body)` [5](#0-4) .

None of these paths route through `opts.IO.ContentOut`, so `newContentWriter`'s sanitizer is never invoked for the PR title/body content. Glamour's rendering does not strip or escape raw ANSI control bytes embedded in markdown text (e.g., inside a code fence, autolink, or reference-link target) — it treats them as literal bytes to be styled/output, so ESC sequences authored by the attacker survive rendering and are written verbatim to the user's terminal.

### Impact Explanation
An attacker who authors a PR title or body containing raw ANSI/OSC escape sequences (e.g., inside a fenced code block) can have those sequences delivered unmodified to the terminal of any user who runs `gh pr view` against that PR. This enables terminal escape sequence injection: cursor repositioning, screen clearing, hidden/overwritten text, terminal title spoofing, or OSC-based hyperlink/clipboard tricks — potentially used to spoof prompts or disguise malicious confirmation requests, matching the "Terminal output/prompt spoofing" bounty class.

### Likelihood Explanation
Fully attacker-controlled and remotely triggerable: any unprivileged GitHub user can open a PR/issue with a crafted title or body containing ANSI escapes, and any victim running `gh pr view <number>` (interactively, the default human-preview path, or via `gh pr view --json`-less redirected output using `printRawPrPreview`) will trigger the vulnerable code path. No special permissions, admin rights, or social engineering beyond opening a PR are required, making this highly likely to reproduce.

### Recommendation
Route PR title/body/comment output in `pkg/cmd/pr/view/view.go` through `opts.IO.ContentOut` (or wrap the values in `iostreams.Untrusted`/its `String()` method) instead of writing to `opts.IO.Out` directly, so the existing `asciisanitizer`-backed sanitizer (already implemented via `newContentWriter`) is actually applied to all attacker-controlled markdown/text before it reaches the terminal. Apply the same fix to `printRawPrPreview` and to the comment/review listing paths for consistency.

### Proof of Concept
```go
// pkg/cmd/pr/view/view_test.go (illustrative)
func TestPRView_ANSIEscapeNotSanitized(t *testing.T) {
    pr := &api.PullRequest{
        Title: "Legit title \x1b[8mhidden\x1b[0m",
        Body:  "```\n\x1b]0;pwned\x07malicious title\n```",
        // ... other required fields
    }
    ios, _, stdout, _ := iostreams.Test()
    ios.SetStdoutTTY(true)
    opts := &ViewOptions{IO: ios, Now: time.Now}

    err := printHumanPrPreview(opts, ghrepo.New("OWNER", "REPO"), pr)
    require.NoError(t, err)

    // Expected (secure) assertion — currently FAILS because escapes pass through:
    require.NotContains(t, stdout.String(), "\x1b[8m")
    require.NotContains(t, stdout.String(), "\x1b]0;")
}
```
Running this against the current implementation shows the raw ESC bytes present in `stdout`, confirming the sanitizer (`asciisanitizer.Sanitizer` via `ContentOut`/`newContentWriter`) is never applied to the `gh pr view` output stream.

// newContentWriter returns the writer to wire up as ContentOut. When
// sanitize is true it inserts an asciisanitizer in front of the underlying
// writer; otherwise it returns the underlying writer directly so writes
// reach stdout unchanged.
func newContentWriter(out io.Writer, sanitize bool) io.Writer {
	if !sanitize {
		return out
	}
	return transform.NewWriter(out, &asciisanitizer.Sanitizer{})
}

func printHumanPrPreview(opts *ViewOptions, baseRepo ghrepo.Interface, pr *api.PullRequest) error {
	out := opts.IO.Out
	cs := opts.IO.ColorScheme()

	// Header (Title and State)
	fmt.Fprintf(out, "%s %s#%d\n", cs.Bold(pr.Title), ghrepo.FullName(baseRepo), pr.Number)
	fmt.Fprintf(out,
		"%s • %s wants to merge %s into %s from %s • %s\n",
		shared.StateTitleWithColor(cs, *pr),
		pr.Author.DisplayName(),
		text.Pluralize(pr.Commits.TotalCount, "commit"),
		pr.BaseRefName,
		pr.HeadRefName,
		text.FuzzyAgo(opts.Now(), pr.CreatedAt),
	)

	// added/removed
	fmt.Fprintf(out,
		"%s %s",
		cs.Green("+"+strconv.Itoa(pr.Additions)),
		cs.Red("-"+strconv.Itoa(pr.Deletions)),
	)

	// checks
	checks := pr.ChecksStatus()
	if summary := shared.PrCheckStatusSummaryWithColor(cs, checks); summary != "" {
		fmt.Fprintf(out, " • %s\n", summary)
	} else {
		fmt.Fprintln(out)
	}

	// Reactions
	if reactions := shared.ReactionGroupList(pr.ReactionGroups); reactions != "" {
		fmt.Fprint(out, reactions)
		fmt.Fprintln(out)
	}

	// Metadata
	if reviewers := prReviewerList(*pr, cs); reviewers != "" {
		fmt.Fprint(out, cs.Bold("Reviewers: "))
		fmt.Fprintln(out, reviewers)
	}
	if assignees := prAssigneeList(*pr); assignees != "" {
		fmt.Fprint(out, cs.Bold("Assignees: "))
		fmt.Fprintln(out, assignees)
	}
	if labels := prLabelList(*pr, cs); labels != "" {
		fmt.Fprint(out, cs.Bold("Labels: "))
		fmt.Fprintln(out, labels)
	}
	if projects := prProjectList(*pr); projects != "" {
		fmt.Fprint(out, cs.Bold("Projects: "))
		fmt.Fprintln(out, projects)
	}
	if pr.Milestone != nil {
		fmt.Fprint(out, cs.Bold("Milestone: "))
		fmt.Fprintln(out, pr.Milestone.Title)
	}

	// Auto-Merge status
	autoMerge := pr.AutoMergeRequest
	if autoMerge != nil {
		var mergeMethod string
		switch autoMerge.MergeMethod {
		case "MERGE":
			mergeMethod = "a merge commit"
		case "REBASE":
			mergeMethod = "rebase and merge"
		case "SQUASH":
			mergeMethod = "squash and merge"
		default:
			mergeMethod = fmt.Sprintf("an unknown merge method (%s)", autoMerge.MergeMethod)
		}
		fmt.Fprintf(out,
			"%s %s by %s, using %s\n",
			cs.Bold("Auto-merge:"),
			cs.Green("enabled"),
			autoMerge.EnabledBy.Login,
			mergeMethod,
		)
	}

	// Body
	var md string
	var err error
	if pr.Body == "" {
		md = fmt.Sprintf("\n  %s\n\n", cs.Muted("No description provided"))
	} else {
		md, err = markdown.Render(pr.Body,
			markdown.WithTheme(opts.IO.TerminalTheme()),
			markdown.WithWrap(opts.IO.TerminalWidth()))
		if err != nil {
			return err
		}
	}
	fmt.Fprintf(out, "\n%s\n", md)
