**Analysis:** The root cause in the Putty report is Solidity/ERC20-specific: some ERC20 tokens revert on zero-value `transferFrom`, and the protocol unconditionally calls `safeTransferFrom` for the strike amount without checking it's positive, letting a malicious maker create a permanently-unexercisable zero-strike call and keep the premium.

This bug class does not transplant to Sui's Move object model. Sui's `Coin<T>`/`Balance<T>` primitives are native objects, not externally-controlled contract calls with arbitrary logic — zero-value transfers are explicitly first-class and always succeed: `coin::zero`, `coin::destroy_zero`, `balance::zero`, `balance::destroy_zero`, and `coin::split`/`balance::split` with a zero amount are supported by design and never abort or revert. [1](#0-0) [2](#0-1) 
There is no analog of "some tokens revert on zero transfer" for native Move coins, so a Move-based options/derivatives contract on Sui cannot be forced into the same "premium theft via unexercisable zero-strike leg" pattern purely from framework-level coin semantics.

The only place where real external-token semantics with possible zero-amount reverts exist is the EVM side of the Sui Bridge (`SuiBridge.sol`, `BridgeLimiter.sol`), which calls arbitrary registered ERC20 tokens. [3](#0-2) [4](#0-3) 
However, token support/allowlisting and any resulting stuck-message behavior there is controlled by the validator committee (bridge governance), which is explicitly out of scope ("malicious peers, nodes, validators, bridge authorities, admins, or governance quorums"), and does not constitute unauthorized fund theft, object corruption, or a bridge-message-forgery/mint-bypass matching the Critical/High gate.

No reachable, unprivileged-user root cause matching this bug class exists in this repository under the allowed impact scope.

/// Split a `Balance` and take a sub balance from it.
public fun split<T>(self: &mut Balance<T>, value: u64): Balance<T> {
    assert!(self.value >= value, ENotEnough);
    self.value = self.value - value;
    Balance { value }
}

/// Withdraw all balance. After this the remaining balance must be 0.
public fun withdraw_all<T>(self: &mut Balance<T>): Balance<T> {
    let value = self.value;
    split(self, value)
}

/// Destroy a zero `Balance`.
public fun destroy_zero<T>(balance: Balance<T>) {
    assert!(balance.value == 0, ENonZero);
    let Balance { value: _ } = balance;
}

        override
        onlyOwner

        uint256 usdAmount = calculateAmountInUSD(tokenID, amount);
        require(

        );

        uint32 _currentHour = currentHour();

        // garbage collect most recently expired hour if possible
        uint256 key = getChainHourTimestampKey(chainID, _currentHour - 25);
        if (chainHourlyTransferAmount[key] > 0) {
