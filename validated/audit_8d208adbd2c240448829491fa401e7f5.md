### Title
Unbounded recursive stringification in `getSourceString`/`getJsonSourceString` allows stack-consumption DoS via deeply nested unit before depth checks run - ([File: string_utils.js])

### Summary
The reported jq bug (CVE-2016-4074) is a stack-consumption crash in `jv_dump_term` caused by unbounded recursion while serializing a crafted, deeply nested JSON value. `ocore--020` has an analogous unbounded-recursion serializer, `getSourceString` (and its JSON-mode sibling `getJsonSourceString`), whose internal `extractComponents`/`stringify` helpers recurse once per nesting level with no depth limit of their own. Depth protection exists elsewhere in the codebase (`isTooDeeplyNestedOrHasTooManyNodes`, `MAX_DEPTH` in AA validation, `count % 100` throttling in formula evaluation), but on the primary unit-validation path in `validation.js`, the unbounded recursive hash/stringify call happens *before* the depth-limiting check.

### Finding Description
`getSourceString` in `string_utils.js` recursively walks an arbitrary object/array via the inner `extractComponents` function with no depth ceiling: [1](#0-0) 

`getJsonSourceString` has the identical unbounded-recursion pattern via its own `stringify` closure: [2](#0-1) 

The unit-validation entry point `validate()` in `validation.js` computes the unit hash — which internally calls `getUnitHash` → `getBase64Hash` → `getSourceString`/`getJsonSourceString` (via `object_hash.js`) — at line 133, **before** the nesting/size guard `isTooDeeplyNestedOrHasTooManyNodes(objUnit)` is invoked at line 154: [3](#0-2) [4](#0-3) [5](#0-4) 

So the sequence for any incoming unit is: parse → `getUnitHash(objUnit)` (fully recursive, unbounded) → *then* `isTooDeeplyNestedOrHasTooManyNodes` (bounded, depth 100). If an attacker crafts a unit whose `messages[].payload` (or other nested field reachable by an unprivileged poster) contains a JSON structure nested far beyond depth 100 (e.g., thousands of nested arrays/objects, as demonstrated feasible by the existing test cases for formula evaluation depth), the recursive hash computation can exhaust the V8 call stack and crash the process with a `RangeError: Maximum call stack size exceeded` (or, depending on engine/build, a native stack overflow) before the code ever reaches the depth guard that was specifically designed to prevent this class of attack.

This mirrors the jq analog precisely: a "dump"/serialization routine (`jv_dump_term` ≈ `getSourceString`/`getJsonSourceString`) recurses without a depth bound over attacker-controlled JSON, and the crash occurs during the dump/hash step rather than during a prior validated parse step.

Whether the `network.js` "joint" message path (which does call `isTooDeeplyNestedOrHasTooManyNodes(objJoint)` at line 2874, before `handleOnlineJoint`) fully shields all callers of `validation.js`'s `validate()` was not fully confirmed — there are additional callers in `aa_composer.js`, `composer.js`, `divisible_asset.js`, `formula/index.js`, and `indivisible_asset.js` whose ordering relative to the nested-depth check could not be verified within the available iterations.

### Impact Explanation
A crash triggered by stack exhaustion during hash/serialization of a single posted unit is a process-level denial of service on any full node (or light node performing self-checks) that processes the crafted unit — this can stop the affected node from validating/confirming further units, i.e. "a network unable to confirm new units" if triggered broadly, satisfying the required impact bar. It is reachable by any unprivileged unit poster since unit content (message payloads) is attacker-controlled data that flows straight into `getUnitHash`/`getSourceString` during validation.

### Likelihood Explanation
Medium-to-High: constructing a deeply nested JSON payload (nested arrays/objects thousands of levels deep, as already exercised in `test/formula.test.js:6415-6462` for the formula depth=2000 case) is trivial for any user composing/posting a unit. The only mitigating factor is that the `isTooDeeplyNestedOrHasTooManyNodes` check does exist in the codebase generally (showing awareness of this bug class) but is ordered *after* the vulnerable hash computation on the `validation.js` unit-validation path.

### Recommendation
Move the `isTooDeeplyNestedOrHasTooManyNodes(objUnit)` check in `validation.js` to occur immediately after parsing/before any call to `objectHash.getUnitHash`/`getChash160`/`getBase64Hash`, so no recursive stringification runs on unbounded-depth data. Additionally, add an explicit depth counter/limit inside `extractComponents` (in `getSourceString`) and `stringify` (in `getJsonSourceString`) themselves, mirroring the depth guard already present in `isTooDeeplyNestedOrHasTooManyNodes`, so these low-level serialization primitives are safe regardless of call order or future callers.

### Proof of Concept
Construct and submit (via the normal unit-posting path, e.g., a "joint" p2p message or light-wallet unit submission) a unit whose message payload is a JSON array nested well beyond the depth cap enforced by `isTooDeeplyNestedOrHasTooManyNodes` (depthLimit=100), e.g. an array nested 5,000+ levels deep such as `[[[...[1]...]]]`. When `validation.js`'s `validate()` runs `objectHash.getUnitHash(objUnit)` to verify `objUnit.unit === objectHash.getUnitHash(objUnit)` at line 133, the recursive `extractComponents`/`stringify` walk in `string_utils.js` recurses once per nesting level before the depth check at line 154 ever executes, exhausting the call stack and crashing the validating process.

function getSourceString(obj) {
	var arrComponents = [];
	function extractComponents(variable){
		if (variable === null)
			throw Error("null value in "+JSON.stringify(obj));
		switch (typeof variable){
			case "string":
				if (variable.includes(STRING_JOIN_CHAR))
					throw Error("00 byte in string value in " + JSON.stringify(obj));
				arrComponents.push("s", variable);
				break;
			case "number":
				if (!isFinite(variable))
					throw Error("invalid number: " + variable);
				arrComponents.push("n", variable.toString());
				break;
			case "boolean":
				arrComponents.push("b", variable.toString());
				break;
			case "object":
				if (Array.isArray(variable)){
					if (variable.length === 0)
						throw Error("empty array in "+JSON.stringify(obj));
					arrComponents.push('[');
					for (var i=0; i<variable.length; i++)
						extractComponents(variable[i]);
					arrComponents.push(']');
				}
				else{
					var keys = Object.keys(variable).sort();
					if (keys.length === 0)
						throw Error("empty object in "+JSON.stringify(obj));
					keys.forEach(function(key){
						if (typeof variable[key] === "undefined")
							throw Error("undefined at "+key+" of "+JSON.stringify(obj));
						if (key.includes(STRING_JOIN_CHAR))
							throw Error("00 byte in object key in " + JSON.stringify(obj));
						arrComponents.push(key);
						extractComponents(variable[key]);
					});
				}
				break;
			default:
				throw Error("getSourceString: unknown type="+(typeof variable)+" of "+variable+", object: "+JSON.stringify(obj));
		}
	}

	extractComponents(obj);
	return arrComponents.join(STRING_JOIN_CHAR);
}

function getJsonSourceString(obj, bAllowEmpty) {
	let cache = new WeakMap();  // object to stringified result
	function stringify(variable){
		if (variable === null)
			throw Error("null value in "+JSON.stringify(obj));
		switch (typeof variable){
			case "string":
				return toWellFormedJsonStringify(variable);
			case "number":
				if (!isFinite(variable))
					throw Error("invalid number: " + variable);
			case "boolean":
				return variable.toString();
			case "object":
				// return cached result if already processed
				if (cache.has(variable))
					return cache.get(variable);
				let result;
				if (Array.isArray(variable)){
					if (variable.length === 0 && !bAllowEmpty)
						throw Error("empty array in "+JSON.stringify(obj));
					result = '[' + variable.map(stringify).join(',') + ']';
				}
				else{
					var keys = Object.keys(variable).sort();
					if (keys.length === 0 && !bAllowEmpty)
						throw Error("empty object in "+JSON.stringify(obj));
					result = '{' + keys.map(function(key){ return toWellFormedJsonStringify(key)+':'+stringify(variable[key]) }).join(',') + '}';
				}
				cache.set(variable, result);  // memoize for future references
				return result;
			default:
				throw Error("getJsonSourceString: unknown type="+(typeof variable)+" of "+variable+", object: "+JSON.stringify(obj));
		}
	}

	return stringify(obj);
}

function getBase64Hash(obj, bJsonBased) {
	var sourceString = bJsonBased ? getJsonSourceString(obj) : getSourceString(obj)
	return crypto.createHash("sha256").update(sourceString, "utf8").digest("base64");
