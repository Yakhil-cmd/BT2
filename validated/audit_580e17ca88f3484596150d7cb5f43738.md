### Title
Staking Reward Overwrite for Shared CLPoolAddr in Prague Reward Distribution — (`File: kaiax/reward/impl/getter.go`)

---

### Summary

In `assignStakingRewards` and `assignStakingRewardsFlex`, the CL (consensus liquidity) staking reward allocation for a given `CLPoolAddr` is written with a plain map assignment (`alloc[...] = clAmount`) rather than an accumulation. If two consolidated validators share the same `CLPoolAddr`, or if a validator's `CLPoolAddr` equals another validator's `RewardAddr`, the first validator's CL staking reward is silently overwritten and never distributed — effectively destroyed.

---

### Finding Description

Both `assignStakingRewards` and `assignStakingRewardsFlex` build an `alloc map[common.Address]*big.Int` and then iterate over `ConsolidatedNodes()`. For each node that has a `CLStakingInfo` under the Prague hardfork, the reward is split and written as:

```go
// kaiax/reward/impl/getter.go  (assignStakingRewards, lines 523-525)
cnAmount, clAmount := cn.Split(reward)
alloc[cn.RewardAddr] = cnAmount                    // assignment, not +=
alloc[cn.CLStakingInfo.CLPoolAddr] = clAmount      // assignment, not +=
``` [1](#0-0) 

The identical pattern appears in `assignStakingRewardsFlex`:

```go
// kaiax/reward/impl/getter.go  (assignStakingRewardsFlex, lines 475-477)
cnAmount, clAmount := cn.Split(reward)
alloc[cn.RewardAddr] = cnAmount
alloc[cn.CLStakingInfo.CLPoolAddr] = clAmount
``` [2](#0-1) 

`ConsolidatedNodes()` guarantees that each `cn.RewardAddr` is unique across the slice (nodes with the same reward address are merged), so the `alloc[cn.RewardAddr] = cnAmount` line is safe. However, **`CLPoolAddr` is not subject to any uniqueness guarantee** in the consolidation logic:

```go
// kaiax/staking/staking_info.go  consolidateNodes()
// "One CLStakingInfo per validator is guaranteed by CLRegistry."
// — uniqueness is per-nodeId, NOT per-CLPoolAddr
cmap[r].CLStakingInfo = clsi
``` [3](#0-2) 

Two distinct validators can therefore register the same `CLPoolAddr` in CLRegistry. When the reward loop processes them in sequence:

1. **CN1** (RewardAddr `R1`, CLPoolAddr `P`): `alloc[P] = clAmount1`
2. **CN2** (RewardAddr `R2`, CLPoolAddr `P`): `alloc[P] = clAmount2` — **overwrites** `clAmount1`

After the loop, `alloc[P]` holds only `clAmount2`. `clAmount1` is gone from the map and is never passed to `spec.IncRecipient`, so it is never credited to any address via `state.AddBalance`. [4](#0-3) 

A secondary variant: if `CLPoolAddr` of CN1 equals `RewardAddr` of CN2, the same overwrite occurs between the CL reward of CN1 and the CN reward of CN2, depending on iteration order.

---

### Impact Explanation

- **Asset impact**: KAIA staking rewards that should be credited to a CL pool address are silently destroyed — not minted to any recipient — every block in which the collision occurs.
- **Scope**: Affects `FinalizeState` → `GetDeferredReward` → `getDeferredRewardFullKore` / `getDeferredRewardFullFlex` on every block after the Prague hardfork when two validators share a `CLPoolAddr`.
- **Corrupted value**: `alloc[CLPoolAddr]` holds only the last-written `clAmount` instead of the sum of all `clAmount` values for that address. The deficit equals the sum of all overwritten `clAmount` values.

---

### Likelihood Explanation

- The CLRegistry mock (`CLRegistryMock.sol`) returns arbitrary `clPools` addresses with no uniqueness check visible in the repository.
- The `consolidateNodes()` comment explicitly states uniqueness is guaranteed only per `CLNodeId`, not per `CLPoolAddr`.
- In the permissionless validator set (post-Permissionless hardfork), any validator can register a CL pool address, including one already used by another validator.
- Even in the permissioned network, two GC members could accidentally configure the same CL pool contract.

---

### Recommendation

Replace the plain map assignment with an accumulation pattern, consistent with how `IncRecipient` works elsewhere in the reward spec:

```go
// Instead of:
alloc[cn.CLStakingInfo.CLPoolAddr] = clAmount

// Use:
if existing, ok := alloc[cn.CLStakingInfo.CLPoolAddr]; ok {
    alloc[cn.CLStakingInfo.CLPoolAddr] = new(big.Int).Add(existing, clAmount)
} else {
    alloc[cn.CLStakingInfo.CLPoolAddr] = clAmount
}
```

Apply the same fix to `alloc[cn.RewardAddr] = cnAmount` for the Prague+CL branch, and to both `assignStakingRewards` and `assignStakingRewardsFlex`.

Alternatively, introduce a helper analogous to `IncRecipient` for the `alloc` map and use it consistently.

---

### Proof of Concept

Given a Prague-enabled chain with two validators:

| Field | CN1 | CN2 |
|---|---|---|
| NodeId | N1 | N2 |
| RewardAddr | R1 | R2 |
| StakingAmount | 10 M KAIA | 10 M KAIA |
| CLPoolAddr | **P** | **P** (same) |
| CLStakingAmount | 5 M KAIA | 5 M KAIA |

Both validators exceed `minStake`. `ConsolidatedNodes()` returns two entries with distinct `RewardAddr` but identical `CLPoolAddr = P`.

In `assignStakingRewards` (or `assignStakingRewardsFlex`):

```
Iteration 1 (CN1):
  reward = X
  cnAmount1, clAmount1 = cn1.Split(X)   // e.g. 2/3 X, 1/3 X
  alloc[R1] = cnAmount1
  alloc[P]  = clAmount1                 // e.g. 100 KAIA

Iteration 2 (CN2):
  reward = X
  cnAmount2, clAmount2 = cn2.Split(X)   // same split
  alloc[R2] = cnAmount2
  alloc[P]  = clAmount2                 // OVERWRITES: 100 KAIA lost
```

`alloc` returned: `{R1: cnAmount1, R2: cnAmount2, P: clAmount2}`.

`clAmount1` (100 KAIA) is never added to any balance. It is destroyed every block. Over a year at ~1-second block times, this amounts to ~3.15 billion blocks × 100 KAIA = material loss. [5](#0-4) [6](#0-5) [7](#0-6)

// assignStakingRewardsFlex assigns staking rewards to stakers according to their staking amounts.
// Returns the allocation and the remainder.
func assignStakingRewardsFlex(config *reward.RewardConfig, budget *big.Int, si *staking.StakingInfo) (map[common.Address]*big.Int, *big.Int) {
	var (
		minStake  = config.MinimumStake.Uint64()
		threshold = config.StakingRewardThreshold.Uint64()
		isPrague  = config.Rules.IsPrague

		cns            = si.ConsolidatedNodes()
		excessInt      = make(map[common.Address]uint64)
		totalExcessInt = uint64(0)
	)

	// Calculate the excess stakes (the amount over the threshold) for each CN.
	for _, cn := range cns {
		// If the CNStaking is less than minStake, skip it. Even if (CNStaking + CLStaking) could be more than minStake,
		// the CNStaking alone must be at least minStake to be eligible.
		if cn.StakingAmount < minStake {
			continue
		}

		amount := cn.StakingAmount
		if isPrague && cn.CLStakingInfo != nil {
			amount += cn.CLStakingInfo.CLStakingAmount
		}

		// Excess is the amount over the threshold (not over minStake).
		if amount > threshold {
			excessInt[cn.RewardAddr] = amount - threshold
			totalExcessInt += excessInt[cn.RewardAddr]
		}
	}

	// Distribute the budget to the CNs based on the excess stakes.
	var (
		totalExcess = new(big.Int).SetUint64(totalExcessInt)
		remaining   = new(big.Int).Set(budget)
		alloc       = make(map[common.Address]*big.Int)
	)
	for _, cn := range cns {
		if excessInt[cn.RewardAddr] <= 0 {
			continue
		}
		excess := new(big.Int).SetUint64(excessInt[cn.RewardAddr])

		// The KAIA unit will cancel out:
		// reward (kei) = excess (KAIA) * budget (kei) / totalExcess (KAIA)
		reward := new(big.Int).Div(new(big.Int).Mul(excess, budget), totalExcess)
		if reward.Sign() <= 0 {
			continue
		}

		// If Prague and CL is configured for this CN, split the reward between CN and CL.
		if isPrague && cn.CLStakingInfo != nil {
			cnAmount, clAmount := cn.Split(reward)
			alloc[cn.RewardAddr] = cnAmount
			alloc[cn.CLStakingInfo.CLPoolAddr] = clAmount
		} else {
			alloc[cn.RewardAddr] = reward
		}
		remaining.Sub(remaining, reward)
	}
	return alloc, remaining
}

// assignStakingRewards assigns staking rewards to stakers according to their staking amounts.
// Returns the allocation and the remainder.
func assignStakingRewards(config *reward.RewardConfig, stakersReward *big.Int, si *staking.StakingInfo) (map[common.Address]*big.Int, *big.Int) {
	var (
		cns               = si.ConsolidatedNodes()
		minStake          = config.MinimumStake.Uint64()
		totalExcessInt    = uint64(0) // sum of excess stakes (the amount over minStake) over all stakers
		cnTotalStakingMap = make(map[common.Address]uint64)
		isPrague          = config.Rules.IsPrague
	)
	for _, cn := range cns {
		// If the CNStaking is less than minStake, skip it.
		if cn.StakingAmount >= minStake {
			// Calculate total staking amount once
			cnTotalStakingAmount := cn.StakingAmount
			if isPrague && cn.CLStakingInfo != nil {
				cnTotalStakingAmount += cn.CLStakingInfo.CLStakingAmount
			}
			totalExcessInt += cnTotalStakingAmount - minStake
			cnTotalStakingMap[cn.RewardAddr] = cnTotalStakingAmount
		}
	}

	var (
		totalExcess = new(big.Int).SetUint64(totalExcessInt)
		remaining   = new(big.Int).Set(stakersReward)
		alloc       = make(map[common.Address]*big.Int)
	)
	for _, cn := range cns {
		cnTotalStakingAmount := cnTotalStakingMap[cn.RewardAddr]
		if cnTotalStakingAmount > minStake {
			// The KAIA unit will cancel out:
			// reward (kei) = excess (KAIA) * stakersReward (kei) / totalExcess (KAIA)
			excess := new(big.Int).SetUint64(cnTotalStakingAmount - minStake)
			if reward := new(big.Int).Div(new(big.Int).Mul(excess, stakersReward), totalExcess); reward.Sign() > 0 {
				if isPrague && cn.CLStakingInfo != nil {
					// The remaining amount will be added to the cnAmount.
					cnAmount, clAmount := cn.Split(reward)
					alloc[cn.RewardAddr] = cnAmount
					alloc[cn.CLStakingInfo.CLPoolAddr] = clAmount
				} else {
					alloc[cn.RewardAddr] = reward
				}
				remaining.Sub(remaining, reward)
			}
		}
	}
	return alloc, remaining
}

func (si *StakingInfo) consolidateNodes() *[]consolidatedNode {
	// because Go map is not ordered, rList keeps track of the occurrence order of RewardAddrs.
	// to later arrange the consolidatedNodes.
	cmap := make(map[common.Address]*consolidatedNode)
	rList := make([]common.Address, 0, len(si.RewardAddrs))
	nToR := make(map[common.Address]common.Address)

	for i, n := range si.NodeIds {
		r := si.RewardAddrs[i]
		// Unique nodeId is guaranteed by AddressBook.
		nToR[n] = r
		if cn, ok := cmap[r]; ok {
			cn.NodeIds = append(cn.NodeIds, n)
			cn.StakingContracts = append(cn.StakingContracts, si.StakingContracts[i])
			cn.StakingAmount += si.StakingAmounts[i]
		} else {
			cmap[r] = &consolidatedNode{
				NodeIds:          []common.Address{n},
				StakingContracts: []common.Address{si.StakingContracts[i]},
				RewardAddr:       r,
				StakingAmount:    si.StakingAmounts[i],
			}
			rList = append(rList, r)
		}
	}

	// CLStakingInfo can only exist after Prague HF.
	if len(si.CLStakingInfos) > 0 {
		for _, clsi := range si.CLStakingInfos {
			// If the nodeId of CLStakingInfo is not found in nToR, it means the validator is not in the AddressBook.
			// So we skip it.
			if r, ok := nToR[clsi.CLNodeId]; ok {
				// One CLStakingInfo per validator is guaranteed by CLRegistry.
				cmap[r].CLStakingInfo = clsi
			}
		}
	}

	carr := make([]consolidatedNode, 0, len(cmap))
	for _, r := range rList {
		carr = append(carr, *cmap[r])
	}
	return &carr
}
