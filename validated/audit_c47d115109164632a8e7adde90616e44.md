### Title
Missing Validation for `kip71.gastarget = 0` Governance Vote Causes Division-by-Zero Panic Halting the Chain — (`params/kip71_config.go`, `kaiax/gov/headergov/impl/header.go`, `kaiax/gov/param.go`)

---

### Summary

A governance vote setting `kip71.gastarget` to `0` is accepted without any validation. Once the vote takes effect, every subsequent call to `NextMagmaBlockBaseFee` with any non-zero gas used performs an integer division by zero (`big.Int.Div` with divisor 0), causing a runtime panic on all nodes. This permanently halts the chain, preventing all state transitions, transfers, and withdrawals. The developers explicitly guarded against `BaseFeeDenominator = 0` with a fallback, but applied no analogous guard for `GasTarget = 0`.

---

### Finding Description

**Step 1 — No validation on `kip71.gastarget` votes.**

In `kaiax/gov/param.go`, the `Kip71GasTarget` parameter uses `noopFormatChecker`, which unconditionally returns `true` for any value including `0`: [1](#0-0) 

In `kaiax/gov/headergov/impl/header.go`, `checkConsistency` places `gov.Kip71GasTarget` in the "no more checks here" branch, returning `nil` for any value: [2](#0-1) 

`Kip71GasTarget` is absent from both `AlwaysDeprecated` and `PermissionlessDeprecated`, so it is a live, voteable parameter in any governance mode. [3](#0-2) 

**Step 2 — Division by zero in `NextMagmaBlockBaseFee` when `GasTarget = 0`.**

In `params/kip71_config.go`, when `parentGasUsed > 0` and `gasTarget = 0`, the condition `parentGasUsed > gasTarget` is always true. The code then divides by `gasTarget`: [4](#0-3) 

`new(big.Int).SetUint64(0)` is a zero `big.Int`. Go's `big.Int.Div` panics on a zero divisor. This panic occurs in every call path that processes a block with any gas used.

**Step 3 — Contrast with the existing `BaseFeeDenominator = 0` guard.**

The developers explicitly handled `BaseFeeDenominator = 0` with a fallback to `64`: [5](#0-4) 

No analogous guard exists for `GasTarget = 0`.

**Step 4 — All block-processing paths call `NextMagmaBlockBaseFee`.**

The function is called during block production in `work/worker.go`: [6](#0-5) 

And during block validation via `VerifyMagmaHeader`: [7](#0-6) 

Once `GasTarget = 0` takes effect, every node panics on the first block containing any transaction, halting the chain permanently.

---

### Impact Explanation

All honest nodes panic when computing or verifying the base fee for any block with non-zero gas used. The chain halts permanently. No state transitions, transfers, or withdrawals can occur. This matches the allowed impact gate: "persistent corruption... that breaks canonical execution, withdrawals, transfers, or settlement."

---

### Likelihood Explanation

In `governance.governancemode = "none"`, any validator can cast this vote without special privilege. In `"single"` mode, the governing node (a semi-trusted party) can cast it. The vote passes all existing checks silently. The effect is delayed by one epoch, making it non-obvious until the chain halts. This is directly analogous to the Zerem bug: a misconfigured or malicious parameter value is accepted without constraint and causes irreversible breakage.

---

### Recommendation

Add a minimum-value constraint for `Kip71GasTarget` in its `FormatChecker` (e.g., `v > 0`) in `kaiax/gov/param.go`, and add a corresponding guard in `NextMagmaBlockBaseFee` analogous to the existing `BaseFeeDenominator == 0` fallback:

```go
// In NextMagmaBlockBaseFee, after setting gasTarget:
if gasTarget == 0 {
    // Avoid division by zero; treat as if gas usage equals target
    return makeEvenByFloor(parentBaseFee)
}
```

And in `kaiax/gov/param.go`:

```go
Kip71GasTarget: {
    FormatChecker: func(cv any) bool {
        v, ok := cv.(uint64)
        return ok && v > 0
    },
    ...
}
```

---

### Proof of Concept

1. In `governance.governancemode = "none"`, any validator calls `governance_vote("kip71.gastarget", 0)`.
2. `checkConsistency` returns `nil` (no check for `Kip71GasTarget`). Vote is stored.
3. At the next epoch boundary, `GasTarget = 0` is written into the governance history.
4. The next block that includes any transaction (gas used > 0) triggers `NextMagmaBlockBaseFee`.
5. Inside the function: `parentGasUsed > 0 = gasTarget` → enters the `parentGasUsed > gasTarget` branch → executes `x.Div(x, new(big.Int).SetUint64(0))` → **runtime panic: integer divide by zero**.
6. All nodes crash. The chain halts. All pending transfers and withdrawals are permanently blocked. [8](#0-7) [9](#0-8) [1](#0-0)

func (kc *KIP71Config) VerifyMagmaHeader(headerBaseFee *big.Int, parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) error {
	if headerBaseFee == nil {
		return fmt.Errorf("header is missing baseFee")
	}
	// Verify the baseFee is correct based on the parent header.
	expectedBaseFee := kc.NextMagmaBlockBaseFee(parentHeaderNumber, parentHeaderBaseFee, parentHeaderGasUsed)
	if headerBaseFee.Cmp(expectedBaseFee) != 0 {
		return fmt.Errorf("invalid baseFee: have %s, want %s, parentBaseFee %s, parentGasUsed %d",
			headerBaseFee, expectedBaseFee, parentHeaderBaseFee, parentHeaderGasUsed)
	}
	return nil
}

func (kc *KIP71Config) NextMagmaBlockBaseFee(parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) *big.Int {
	// governance parameters
	lowerBoundBaseFee := new(big.Int).SetUint64(kc.LowerBoundBaseFee)
	upperBoundBaseFee := new(big.Int).SetUint64(kc.UpperBoundBaseFee)
	makeEvenByCeil(lowerBoundBaseFee)
	makeEvenByFloor(upperBoundBaseFee)

	// If the parent is the magma disabled block or genesis, then return the lowerBoundBaseFee (default 25ston)
	if parentHeaderNumber.Cmp(new(big.Int).SetUint64(0)) == 0 || parentHeaderBaseFee == nil {
		return makeEvenByFloor(lowerBoundBaseFee)
	}

	var baseFeeDenominator *big.Int
	if kc.BaseFeeDenominator == 0 {
		// To avoid panic, set the fluctuation range small
		baseFeeDenominator = new(big.Int).SetUint64(64)
	} else {
		baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
	}
	gasTarget := kc.GasTarget
	upperGasLimit := kc.MaxBlockGasUsedForBaseFee

	// check the case of upper/lowerBoundBaseFee is updated by governance mechanism
	parentBaseFee := parentHeaderBaseFee
	if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {
		parentBaseFee = upperBoundBaseFee
	} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
		parentBaseFee = lowerBoundBaseFee
	}

	// upper gas limit cut off the impulse of used gas to upper bound
	parentGasUsed := min(parentHeaderGasUsed, upperGasLimit)
	if parentGasUsed == gasTarget {
		return makeEvenByFloor(parentBaseFee)
	} else if parentGasUsed > gasTarget {
		// shortcut. If parentBaseFee is already reached upperbound, do not calculate.
		if parentBaseFee.Cmp(upperBoundBaseFee) == 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		// If the parent block used more gas than its target,
		// the baseFee of the next block should increase.
		// baseFeeDelta = max(1, parentBaseFee * (parentGasUsed - gasTarget) / gasTarget / baseFeeDenominator)
		gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := math.BigMax(x.Div(y, baseFeeDenominator), common.Big1)
