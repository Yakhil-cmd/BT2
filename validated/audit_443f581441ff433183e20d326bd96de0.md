The premise doesn't match the actual codebase. There is no `TypeInfoResource` struct with a derived `PartialEq`/`Eq` implementation used as a gas-payer coin-type authorization gate in this repository:

- The only `TypeInfo`-related struct is the Move struct `TypeInfo` in `aptos-move/framework/aptos-stdlib/sources/type_info.move`, which has `has copy, drop, store` abilities (no `PartialEq`/`Eq` — Move doesn't have Rust-style derives at all), and it's used for informational purposes like `type_of<T>()` and `type_name<T>()`, not for gating fee-payer authorization. [1](#0-0) 

- The Rust-side native implementation in `aptos-move/framework/natives/src/type_info.rs` implements `type_of<T>()` by converting a `TypeTag::Struct` to the Move `TypeInfo` value; it does not define a comparable `TypeInfoResource` struct, and there's no equality-based gate here either. [2](#0-1) 

- Gas-payer authorization in `aptos-move/framework/aptos-framework/sources/transaction_validation.move` is done via authentication-key hash comparisons (`fee_payer_public_key_hash == account::get_authentication_key(fee_payer_address)`), not via `TypeInfo`/coin-type string or struct comparisons. [3](#0-2) 

- The only place `type_info::type_of` is referenced in the epilogue logic is to fetch `AptosCoin`'s address for supply accounting in a Move spec (formal verification), not as an admission/authorization equality check against attacker-controlled data. [4](#0-3) 

Since no such `TypeInfoResource` equality-based gas-payer coin-type gate exists in the admission path (mempool, vm-validator, or prologue/epilogue), there's no divergence between struct-equality and string-normalized comparison to exploit at the transaction admission boundary.

fn native_type_of(
    context: &mut SafeNativeContext,
    ty_args: &[Type],
    arguments: VecDeque<Value>,
) -> SafeNativeResult<SmallVec<[Value; 1]>> {
    debug_assert!(ty_args.len() == 1);
    debug_assert!(arguments.is_empty());

    context.charge(TYPE_INFO_TYPE_OF_BASE)?;

    let type_tag = context.type_to_type_tag(&ty_args[0])?;

    if context.eval_gas(TYPE_INFO_TYPE_OF_PER_BYTE_IN_STR) > 0.into() {
        let type_tag_str = type_tag.to_canonical_string();
        // Ideally, we would charge *before* the `type_to_type_tag()` and `type_tag.to_string()` calls above.
        // But there are other limits in place that prevent this native from being called with too much work.
        context
            .charge(TYPE_INFO_TYPE_OF_PER_BYTE_IN_STR * NumBytes::new(type_tag_str.len() as u64))?;
    }

    if let TypeTag::Struct(struct_tag) = type_tag {
        Ok(type_of_internal(&struct_tag).expect("type_of should never fail."))
    } else {
        Err(SafeNativeError::abort_with_message(
            super::status::NFE_EXPECTED_STRUCT_TYPE_TAG,
            format!(
                "Expected a struct type, found: {}",
                type_tag.to_short_string()
            ),
        ))
    }
}
