## Title
Cross-Stack Information Disclosure via CCMenu API Endpoint Bypassing ApiClient Stack Scope Binding - ([File: app/controllers/shipit/api/ccmenu_controller.rb])

### Summary
The `Api::BaseController` establishes a binding between the stack(s) an `ApiClient` token is authorized to access and the stack actually resolved for a request: `stacks` is scoped to `current_api_client.stack_id` when the client is stack-scoped, and `stack` is derived from that scoped collection via `stacks.from_param!(params[:stack_id])`. `Api::CCMenuController` overrides `stack` to instead resolve directly from the global `Stack` model, `Stack.from_param!(params[:stack_id])`, breaking the equality between "stack a token authorizes" and "stack it touches."

### Finding Description
`Api::BaseController#stacks` restricts the visible stack set for a stack-scoped `ApiClient`: [1](#0-0) 

`Api::CCMenuController` requires only the `read:stack` permission string (via `require_permission :read, :stack`) but overrides `stack` to bypass the scoped `stacks` collection entirely, resolving any stack by ID directly: [2](#0-1) 

`ApiClient#check_permissions!` only checks whether the string `"read:stack"` is present in the client's `permissions` array — it never checks which specific `stack_id` the client is bound to: [3](#0-2) 

As a result, the equality the system intends to enforce is:
```
current_api_client.stack_id == stack.id  (must hold for stack-scoped clients)
```
but `CCMenuController#stack` computes `stack.id` independently of `current_api_client.stack_id`, so the equality is never checked for this controller. Any valid `ApiClient` token with `read:stack` permission — even one created scoped to a single, unrelated stack — can supply an arbitrary `stack_id` in the request path and receive that other stack's CCMenu XML (build status, last build label/time, activity, web URL), regardless of the token's own `stack_id` binding.

### Impact Explanation
This is a stack-scope escalation: a token authorized to read only one specific stack can read build/deploy state (`lastBuildStatus`, `lastBuildLabel`, `lastBuildTime`, `activity`, `webUrl`) for any other stack in the installation, including stacks belonging to different repositories/teams the token owner should not have access to. This matches the "High" impact category of unauthorized read of stack state via escalation past the token's authorized scope.

### Likelihood Explanation
Any party that already possesses (or is issued) a legitimately scoped `ApiClient` token with `read:stack` — the lowest permission tier, commonly handed out for tools like CI dashboards (see `CCMenuUrlController` provisioning a scoped `read:stack` client) — can immediately exploit this by changing the `stack_id` route segment. No additional privilege or secret is required beyond the token they were already given for their own stack. [4](#0-3) 

### Recommendation
Remove the `stack` override in `Api::CCMenuController` (or reimplement it using the scoped `stacks` collection, i.e. `stacks.from_param!(params[:stack_id])`) so that stack-scoped `ApiClient` tokens cannot resolve stacks outside of `current_api_client.stack_id`.

### Proof of Concept
1. Create/obtain an `ApiClient` with `permissions: ['read:stack']` and `stack_id` set to Stack A (e.g., via `CCMenuUrlController#client`, which provisions exactly such a client).
2. Using that client's Basic-Auth token, request `GET /api/stacks/<owner>/<repo-B>/<env-B>/ccmenu` for Stack B (a different stack the client is not scoped to).
3. `require_permission :read, :stack` passes because the token has the `read:stack` string in its permissions.
4. `CCMenuController#stack` resolves Stack B directly via `Stack.from_param!`, bypassing the `current_api_client.stack_id` restriction enforced elsewhere in `BaseController#stacks`.
5. The response renders Stack B's CCMenu XML (build status/label/time/activity), disclosing state the token was never authorized to read.

module Shipit
  module Api
    class CCMenuController < BaseController
      require_permission :read, :stack

      class NoDeploy
        def id
          0
        end

        def ended_at
          Time.now.utc
        end

        def running?
          false
        end
      end

      def show
        latest_deploy = stack.deploys_and_rollbacks.last || NoDeploy.new
        render('shipit/ccmenu/project', formats: [:xml], locals: { stack:, deploy: latest_deploy })
      end

      private

      def stack
        @stack ||= Stack.from_param!(params[:stack_id])
      end

      def authenticate_api_client
        @current_api_client = ApiClient.authenticate(params[:token])
        super unless @current_api_client
      end
    end
  end
end
