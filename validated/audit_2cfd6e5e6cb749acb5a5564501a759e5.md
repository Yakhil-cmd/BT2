### Title
Wrong Address Checked in `GovernanceGoverningNode` Consistency Validation Allows Setting Governing Node to Non-Council Address — (`File: kaiax/gov/headergov/impl/header.go`)

---

### Summary

In `checkConsistency`, the `GovernanceGoverningNode` case validates that the governing node is a council member, but checks the **current** governing node (`params.GoverningNode`) instead of the **proposed new** governing node (`vote.Value().(common.Address)`). Because the current governing node is always in the council, the check is a permanent no-op. A vote to set the governing node to any arbitrary address — including one not in the council — passes validation and is ratified, permanently locking governance in `single` mode.

---

### Finding Description

`checkConsistency` in `kaiax/gov/headergov/impl/header.go` handles the `GovernanceGoverningNode` vote case as follows:

```go
case gov.GovernanceGoverningNode:
    params := h.GetParamSet(blockNum)
    if params.GovernanceMode != "single" {
        return nil
    }
    council, err := h.ValSet.GetCouncil(blockNum - 1)
    if err != nil {
        return err
    }
    if slices.Contains(council, params.GoverningNode) {  // ← BUG: checks current node, not vote.Value()
        return nil
    }
    return ErrGovNodeNotInValSetList
``` [1](#0-0) 

The vote payload for `governance.governingnode` carries the **new** governing node address as `vote.Value().(common.Address)`, canonicalized via `addressCanonicalizer`. [2](#0-1) 

The guard is supposed to reject a vote that would install a non-council address as the governing node. Instead it checks `params.GoverningNode` — the **current** governing node — which is always a council member (it is the block proposer and must be in the council to cast the vote in the first place). The condition therefore always evaluates to `true` and always returns `nil`, making the guard a dead letter.

The correct check is:
```go
if slices.Contains(council, vote.Value().(common.Address)) {
    return nil
}
```

---

### Impact Explanation

In `single` governance mode (Mainnet and Kairos), only the governing node may cast governance votes post-Permissionless hardfork. [3](#0-2) 

If the governing node is ratified to an address that is not in the council:

1. The new governing node cannot propose blocks (it is not a council member).
2. No other council member can cast governance votes in `single` mode.
3. All governance parameters — `reward.mintingamount`, `reward.ratio`, `reward.kip82ratio`, `governance.unitprice`, `governance.govparamcontract`, etc. — become permanently frozen.
4. The `governance.governingnode` protected state value is set to an invalid address, a persistent corruption of chain governance state.

This satisfies the allowed impact gate: **governance privilege escalation that changes protected chain state**, and **invalid state transition accepted by honest nodes**.

---

### Likelihood Explanation

The trigger is the current governing node casting a `governance.governingnode` vote with a non-council address as the value. This is a semi-trusted actor (a single council member with special voting rights). No majority-validator collusion is required. The broken check passes at `VerifyVote` → `checkConsistency` on every honest node, so the vote is accepted into a block, propagated, and ratified at the next epoch boundary. [4](#0-3) 

The ratification path writes the bad address into `header.Governance` at the epoch block, which is then stored and applied by `PostInsertBlock` → `HandleGov` → `AddGov`. [5](#0-4) 

---

### Recommendation

Replace the checked address in the `GovernanceGoverningNode` case of `checkConsistency`:

```go
// Before (wrong — always true):
if slices.Contains(council, params.GoverningNode) {

// After (correct — checks the proposed new governing node):
if slices.Contains(council, vote.Value().(common.Address)) {
``` [6](#0-5) 

---

### Proof of Concept

**Setup:** Mainnet-equivalent chain in `single` governance mode. Council = `{A, B, C}`. Current governing node = `A`. Attacker-controlled address = `X` (not in council).

1. Node `A` (governing node, block proposer) calls `governance_vote("governance.governingnode", X)`.
2. `A` proposes a block with `header.Vote = encode(voter=A, name="governance.governingnode", value=X)`.
3. `VerifyVote` is called on all honest nodes. It reaches `checkConsistency`:
   - `params.GovernanceMode == "single"` → enters the check.
   - `council = {A, B, C}`.
   - `slices.Contains(council, params.GoverningNode)` = `slices.Contains({A,B,C}, A)` = **true** → returns `nil` (no error).
   - The vote for `X` is accepted.
4. At the next epoch block, `getExpectedGovernance` collects the vote and writes `header.Governance = {"governance.governingnode": X}`.
5. `VerifyGov` passes (the governance bytes match what the local node computed).
6. `PostInsertBlock` → `HandleGov` → `AddGov` stores `governingnode = X`.
7. From the next epoch onward, `GetParamSet` returns `GoverningNode = X`. In post-Permissionless single mode, only `X` may vote. `X` is not in the council and cannot propose blocks. Governance is permanently locked.

// VerifyVote checks the following:
// (1) voter must be in valset,
// (2) integrity of the voter (the voter must be the block proposer),
// (3) the vote value must be consistent compared to the latest ParamSet.
func (h *headerGovModule) VerifyVote(header *types.Header) error {
	if len(header.Vote) == 0 {
		return nil
	}

	var (
		vb       headergov.VoteBytes = header.Vote
		blockNum                     = header.Number.Uint64()
	)

	vote, err := vb.ToVoteData()
	if err != nil {
		logger.Error("ToVoteData error", "num", blockNum, "vote", vb, "err", err)
		return err
	}

	if gov.DeprecatedAt(vote.Name(), h.ChainConfig.Rules(header.Number)) {
		logger.Error("Vote is deprecated", "num", blockNum, "name", vote.Name())
		return ErrDeprecatedVote
	}

	council, err := h.ValSet.GetCouncil(blockNum)
	if err != nil {
		return err
	}

	// check if the voter is in council
	if !slices.Contains(council, vote.Voter()) {
		return ErrInvalidKeyValue
	}

	// check if Voter is the block proposer.
	author, err := h.Chain.Sealer().Author(header)
	if err != nil {
		return err
	}
	if author != vote.Voter() {
		return ErrInvalidVoter
	}

	// In single mode, only the governing node can write header.Vote after Permissionless.
	params := h.GetParamSet(blockNum)
	if h.ChainConfig.IsPermissionlessForkEnabled(new(big.Int).SetUint64(blockNum)) &&
		params.GovernanceMode == "single" &&
		vote.Voter() != params.GoverningNode {
		return ErrVotePermissionDenied
	}

	return h.checkConsistency(blockNum, vote)
}
