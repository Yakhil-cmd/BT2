### Title
Unvalidated `ServiceChainCall` P2P Message Enables Arbitrary RPC Injection into Main Bridge Node — (`File: node/sc/main_bridge_handler.go`)

### Summary

`MainBridgeHandler.handleCallMsg` writes raw bytes from a P2P `ServiceChainCall` message directly into the main bridge's internal RPC server pipe with no validation of the JSON-RPC method, namespace, or parameters. The internal RPC server has the full public `kaia`/`klay` API surface registered, including `kaia_sendRawTransaction` and `kaia_sendTransaction`. Any peer that passes the bridge handshake — which only checks `NetworkId` and `ProtocolVersion`, not chain ID or genesis hash — can invoke any of those methods.

### Finding Description

`NewMainBridge` creates an internal `net.Pipe()` and starts an RPC server on one end:

```go
mb.rpcServer = rpc.NewServer()
p1, p2 := net.Pipe()
mb.rpcConn = p1
go mb.rpcServer.ServeCodec(rpc.NewCodec(p2), 0)
```

`SetComponents` then registers every public `kaia`/`klay` API onto that server:

```go
if api.Public && (api.Namespace == "klay" || api.Namespace == "kaia") {
    mb.rpcServer.RegisterName(api.Namespace, api.Service)
    ...
}
```

When a bridge peer sends a `ServiceChainCall` message, `handleCallMsg` decodes the raw bytes and writes them verbatim to `mb.rpcConn`:

```go
data := make([]byte, msg.Size)
err := msg.Decode(&data)
...
_, err = mbh.mainbridge.rpcConn.Write(data)
```

No check is made on what JSON-RPC method is being requested, what namespace it targets, or whether the calling peer is the legitimate sub-bridge. The bridge peer handshake (`baseBridgePeer.readStatus`) only validates `NetworkId` and `ProtocolVersion` — it does **not** check `ChainID` or genesis hash, unlike the regular Kaia peer handshake.

### Impact Explanation

The internal RPC server exposes `kaia_sendRawTransaction`, `kaia_sendTransaction`, `kaia_sendTransactionAsFeePayer`, and every other public kaia API. Bridge operator accounts are routinely kept unlocked on the main bridge node to automate anchoring and value-transfer signing. An attacker who reaches the bridge P2P port and passes the weak handshake can craft a `ServiceChainCall` payload such as:

```json
{"jsonrpc":"2.0","method":"kaia_sendTransaction",
 "params":[{"from":"<bridge_operator_addr>","to":"<attacker>","value":"0x..."}],
 "id":1}
```

Because the account is unlocked, the RPC server signs and submits the transaction, transferring KAIA from the bridge operator account to the attacker. This satisfies the allowed-impact gate: **unauthorized transfer of KAIA from a system-managed (bridge operator) account**.

### Likelihood Explanation

The bridge P2P port must be reachable by the sub-bridge, so it is network-exposed. The handshake requires only a matching `NetworkId` (public) and `ProtocolVersion` (public). No cryptographic proof of identity as the legitimate sub-bridge is required. Any attacker on the same network segment — or with any route to the bridge P2P port — can complete the handshake and send arbitrary `ServiceChainCall` messages.

### Recommendation

1. **Allowlist RPC methods**: Before writing to `rpcConn`, parse the JSON-RPC payload and reject any method not in an explicit allowlist (e.g., only `kaia_getTransactionCount`, `kaia_gasPrice`).
2. **Restrict the internal RPC server**: Register only the read-only methods the sub-bridge legitimately needs; do not register write methods (`sendRawTransaction`, `sendTransaction`, etc.) on the bridge-internal server.
3. **Strengthen peer authentication**: Verify the connecting peer's identity (e.g., via a pre-shared node ID or chain-ID check) before accepting `ServiceChainCall` messages.

```go
func (mbh *MainBridgeHandler) handleCallMsg(p BridgePeer, msg p2p.Msg) error {
	logger.Trace("mainbridge writes the rpc call message to rpc server", "msg.Size", msg.Size, "msg", msg)
	data := make([]byte, msg.Size)
	err := msg.Decode(&data)
	if err != nil {
		logger.Error("error in mainbridge message handler", "err", err)
		return err
	}

	// Write to RPC server pipe
	_, err = mbh.mainbridge.rpcConn.Write(data)
	if err != nil {
		logger.Error("failed to write to the rpc server pipe", "err", err)
		return err
	}
	return nil
```

```go
func (p *baseBridgePeer) readStatus(network uint64, status *statusData) error {
	msg, err := p.rw.ReadMsg()
	if err != nil {
		return err
	}
	if msg.Code != StatusMsg {
		return errResp(ErrNoStatusMsg, "first msg has code %x (!= %x)", msg.Code, StatusMsg)
	}
	if msg.Size > ProtocolMaxMsgSize {
		return errResp(ErrMsgTooLarge, "%v > %v", msg.Size, ProtocolMaxMsgSize)
	}
	// Decode the handshake and make sure everything matches
	if err := msg.Decode(&status); err != nil {
		return errResp(ErrDecode, "msg %v: %v", msg, err)
	}
	if status.NetworkId != network {
		return errResp(ErrNetworkIdMismatch, "%d (!= %d)", status.NetworkId, network)
	}
	if int(status.ProtocolVersion) != p.version {
		return errResp(ErrProtocolVersionMismatch, "%d (!= %d)", status.ProtocolVersion, p.version)
	}
	return nil
}
```
