### Title
Missing Deadline Re-Validation in `ExtractTxBundles` Allows Expired Gasless Swap Transactions to Drain Proposer KAIA — (`File: kaiax/gasless/impl/builder.go`)

---

### Summary

The gasless module (`kaiax/gasless`) validates a swap transaction's `deadline` field only once, at txpool admission time, inside `checkBalanceForSwap`. The block-building path (`ExtractTxBundles`) never re-checks the deadline before constructing a bundle. A swap transaction admitted with a valid deadline can remain in the pending pool until the deadline expires, then be bundled by the proposer. The proposer's `LendTx` (which transfers KAIA to the user) executes successfully, but the `SwapTx` reverts inside `GaslessSwapRouter.swapForGas` because `block.timestamp > deadline`. The proposer is left unrepaid, losing the lent KAIA.

---

### Finding Description

**Admission-time-only deadline check**

`checkBalanceForSwap` in `kaiax/gasless/impl/tx_pool.go` performs the deadline guard:

```go
// tx.deadline >= currentTimestamp
deadline := swapArgs.Deadline
if deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
    return fmt.Errorf("insufficient deadline: deadline=%s, want=%s", ...)
}
``` [1](#0-0) 

This is called only from `GetCheckBalance()`, which is invoked at txpool admission: [2](#0-1) 

**No deadline re-check at block-building time**

`ExtractTxBundles` in `builder.go` iterates over pending transactions and calls only `IsExecutable(approveTxs[addr], tx)` before constructing the bundle. There is no deadline check: [3](#0-2) 

`IsExecutable` delegates to `VerifyExecutable`, which checks nonce ordering and `amountRepay` constraints but never inspects the `deadline` field.

**No periodic deadline eviction**

`PreReset` drops transactions based on wall-clock `PendingTimeout`/`QueueTimeout` since promotion, not based on the swap's `deadline` value: [4](#0-3) 

A user can set `deadline = currentBlock.Time() + 1` (one second from now). The tx passes admission, but `PendingTimeout` is a much longer wall-clock window. The tx remains in the pool after the deadline expires.

**Execution consequence**

The gasless bundle structure is `[LendTx, (ApproveTx), SwapTx]`. The `LendTx` is generated by the proposer and transfers KAIA to the user: [5](#0-4) 

When the bundle executes:
1. `LendTx` succeeds → proposer's KAIA is transferred to the user.
2. `SwapTx` calls `GaslessSwapRouter.swapForGas(token, amountIn, minAmountOut, amountRepay, deadline)`.
3. The router (which internally calls UniswapV2Router02 swap functions that enforce `require(deadline >= block.timestamp)`) reverts.
4. The proposer is not repaid `amountRepay`.

The `SwapForGas` ABI confirms the deadline parameter is forwarded to the on-chain contract: [6](#0-5) 

---

### Impact Explanation

The block proposer (CN) loses the KAIA amount lent via `LendTx`. The `SwapTx` reverts, so `amountRepay` is never transferred back. The user retains both the lent KAIA and their original tokens. This is an unauthorized loss of KAIA from the proposer's account caused by a missing deadline guard in the block-building path.

---

### Likelihood Explanation

Any user can trigger this by submitting a gasless swap transaction with a short deadline (e.g., `deadline = currentBlock.Time() + 1`). The transaction passes admission, enters the pending pool, and the deadline expires before the next block is built. Because `ExtractTxBundles` does not re-check the deadline, the proposer unknowingly includes the expired bundle. Kaia's 1-second block time makes the window tight but non-zero; under any network congestion or pool delay, the window widens significantly.

---

### Recommendation

Add a deadline re-check inside `ExtractTxBundles` before constructing a bundle:

```go
// In ExtractTxBundles, after decoding swapArgs:
swapArgs, ok := decodeSwapTx(tx, g.signer)
if !ok {
    continue
}
// Re-validate deadline against the current block time
if swapArgs.Deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
    continue // skip expired swap tx; do not build bundle
}
```

Alternatively, add a deadline re-check in `PreReset` so that swap transactions whose `deadline < currentBlock.Time()` are dropped from the pool before they can be bundled.

---

### Proof of Concept

1. User submits a gasless swap tx with `deadline = currentBlock.Time() + 1` (one second from now). The tx passes `checkBalanceForSwap` because `deadline >= currentBlock.Time()`.
2. Due to any pool delay (e.g., the tx is queued waiting for an ApproveTx, or the pool is busy), the tx remains in the pending pool for >1 second.
3. The proposer calls `ExtractTxBundles`. `IsExecutable` passes (nonce and amountRepay are valid). The bundle `[LendTx, SwapTx]` is constructed.
4. The block is executed:
   - `LendTx`: proposer sends `amountRepay` KAIA to the user. ✓
   - `SwapTx`: `GaslessSwapRouter.swapForGas(…, deadline=T+1)` is called at block timestamp `T+2`. The router enforces `require(block.timestamp <= deadline)` → **reverts**.
5. The proposer's KAIA is gone; the user keeps it. The proposer's nonce is consumed by the LendTx with no repayment.

// PreReset removes timed out tx from the tx pool and knownTxs.
func (g *GaslessModule) PreReset(oldHead, newHead *types.Header) []common.Hash {
	g.knownTxsMu.Lock()
	defer g.knownTxsMu.Unlock()

	drops := make([]common.Hash, 0)

	for hash, knownTx := range *g.knownTxs {
		// remove pending timed out tx from tx pool
		if knownTx.status == TxStatusPending && knownTx.elapsedPromotedTime() >= PendingTimeout {
			drops = append(drops, hash)
		}
		// remove queue timed out tx from tx pool
		if knownTx.status == TxStatusQueue && knownTx.elapsedAddedTime() >= QueueTimeout {
			drops = append(drops, hash)
		}
		// remove known timed out tx from knownTxs
		if knownTx.elapsedPromotedOrAddedTime() >= KnownTxTimeout {
			g.knownTxs.delete(hash)
		}
	}

	return drops
}

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles
}
```
