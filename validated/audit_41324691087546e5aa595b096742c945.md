### Title
Path traversal via unsanitized asset/archive-member name in `filepath.Join` - ([File: pkg/cmd/release/download/download.go])

### Summary
`(destinationWriter).makePath` builds the write path with a bare `filepath.Join(w.dir, name)` where `name` originates from a release asset's `Name` field (or, for archives, from a server-supplied `Content-Disposition` filename passed through `filepath.Base`). Unlike the sibling `gh run download` command, which routes artifact names through `internal/safepaths.Absolute.Join` to explicitly reject traversal, `gh release download` performs no traversal check at all, so a crafted asset name such as `../../.bashrc` resolves outside the destination directory.

### Finding Description
In `downloadRun`, release assets are enumerated from `release.Assets` and only filtered by glob pattern (`matchAny`) and a Windows-reserved-filename check (`isWindowsReservedFilename`); no check rejects `..` segments or absolute paths. [1](#0-0) 

The name then flows unmodified into `downloadTarget.name` → `downloadAsset` → `dest.Check`/`dest.Copy` → `makePath`, which does:
```go
func (w destinationWriter) makePath(name string) string {
	if w.file == "" {
		return filepath.Join(w.dir, name)
	}
	return w.file
}
``` [2](#0-1) 

`filepath.Join` calls `Clean` internally, so `filepath.Join("outdir", "../../.bashrc")` collapses to a path outside `outdir` rather than being rejected. `Copy` then creates any needed parent directories with `os.MkdirAll(dir, 0755)` and writes attacker-controlled bytes with `os.OpenFile(fp, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, 0644)`. [3](#0-2) 

For the archive-mode path, if the asset name is empty, the filename is instead derived from the `Content-Disposition` response header via `mime.ParseMediaType`, then `filepath.Base` is applied — this specific branch is bounded because `filepath.Base` strips directory components. But the asset-name branch (the common, per-file download path with individual `release.Assets[].Name`) has no equivalent sanitization. [4](#0-3) 

By contrast, the analogous `gh run download` command explicitly guards against this via `safepaths.Absolute.Join`, which returns a `PathTraversalError` if the joined path would escape the base directory: [5](#0-4) [6](#0-5) 

This confirms `gh release download` lacks the protection its sibling command already implements for the same class of attacker-controlled name.

An attacker who can publish a GitHub release (in their own public repo, fork, etc.) and attach/name an asset (e.g., via the Releases API `name` parameter, which is independent of the uploaded file's local filename) can set the asset name to a traversal string like `../../.bashrc` or `..\..\..\` (Windows) or an absolute path. When the victim runs `gh release download` against that release, the resulting write path escapes the chosen `--dir`.

### Impact Explanation
This allows arbitrary file write/overwrite outside the intended download directory under the invoking user's privileges — e.g., overwriting shell startup files, git hooks in a nearby repository, SSH `authorized_keys`, or gh's own config, potentially escalating to code execution on next shell/git invocation. This matches a Critical-severity "arbitrary file write outside intended directory, escalating to code execution" impact class.

### Likelihood Explanation
Preconditions are minimal: any GitHub user can create a public repository and publish a release with an asset whose `name` field contains traversal sequences (the release asset name is attacker-supplied metadata, distinct from any local file path used during upload). The victim only needs to run an ordinary `gh release download` command pointed at that repository/tag — no special flags, no elevated privileges, and it is fully repeatable since the write occurs deterministically based on the crafted name.

### Recommendation
Sanitize/validate the asset name in `downloadRun` before use (e.g., reject names containing `..` path segments or that are absolute/rooted, similar to how `isWindowsReservedFilename` already screens names), or better, adopt the same defense used by `gh run download`: parse `w.dir` via `safepaths.ParseAbsolute` and join the asset name with `safepaths.Absolute.Join`, rejecting any `PathTraversalError` before writing. Apply this to both the per-asset name path and to any server-supplied `Content-Disposition` filename used for archives.

### Proof of Concept
```go
func TestMakePath_RejectsTraversal(t *testing.T) {
	w := destinationWriter{dir: t.TempDir()}
	fp := w.makePath("../../.bashrc")
	// Current behavior: fp resolves outside w.dir, e.g. "/home/victim/.bashrc"
	abs, _ := filepath.Abs(fp)
	root, _ := filepath.Abs(w.dir)
	if !strings.HasPrefix(abs, root) {
		t.Fatalf("path traversal: %s escapes root %s", abs, root)
	}
}
```
Integration-level PoC: use `httpmock` to stub the release-assets API response with an asset `{"name": "../../.bashrc", "url": ".../assets/1"}`, run `downloadRun` with `opts.Destination` set to a temp subdirectory, and assert that a file is written outside that subdirectory (e.g., in its parent), and/or that `dest.Check`/`dest.Copy` do not return an error rejecting the traversal — demonstrating the missing invariant "every written path must remain inside the chosen root."

func (w destinationWriter) Copy(name string, r io.Reader) (copyErr error) {
	fp := w.makePath(name)
	if fp == "-" {
		if w.allowEscapes {
			_, copyErr = io.Copy(w.stdout, r)
			return
		}
		copyErr = iostreams.CopyGuardedContent(w.stdout, r, w.isTTY)
		if binErr, ok := errors.AsType[iostreams.BinaryTerminalError](copyErr); ok {
			copyErr = fmt.Errorf("%w; use `--output` to save it to a file, or pass --allow-escape-sequences to output it anyway", binErr)
		} else if errors.Is(copyErr, iostreams.ErrEscapeSequence) {
			copyErr = errors.New("the asset contains terminal escape sequences; use `--output` to save it to a file, or pass --allow-escape-sequences to output it anyway")
		}
		return
	}
	if copyErr = w.check(fp); copyErr != nil {
		return
	}

	if dir := filepath.Dir(fp); dir != "." {
		if copyErr = os.MkdirAll(dir, 0755); copyErr != nil {
			return
		}
	}

	var f *os.File
	if f, copyErr = os.OpenFile(fp, os.O_WRONLY|os.O_CREATE|os.O_TRUNC, 0644); copyErr != nil {
		return
	}

```go
func (a Absolute) Join(elem ...string) (Absolute, error) {
	joinedAbsolutePath, err := ParseAbsolute(filepath.Join(append([]string{a.path}, elem...)...))
	if err != nil {
		return Absolute{}, fmt.Errorf("failed to parse joined path: %w", err)
	}

	isSubpath, err := joinedAbsolutePath.isSubpathOf(a)
	if err != nil {
		return Absolute{}, err
	}

	if !isSubpath {
		return Absolute{}, PathTraversalError{
			Base:  a,
			Elems: elem,
		}
	}

	return joinedAbsolutePath, nil
}
