## Finding: Unhandled `throw` on non-finite number in `earned_headers_commission_recipients` crashes the node when computing header size

### Title
Uncaught exception / process crash from a single posted unit via non-finite number in `earned_headers_commission_recipients` - (File: `validation.js`, `object_length.js`)

### Summary
`validation.js` computes the serialized size of a unit's header via `objectLength.getHeadersSize(objUnit)` **before** the unit's `earned_headers_commission_recipients` field has been structurally validated, and **without** the try/catch that protects the equivalent payload-size computation right below it. `object_length.js`'s `getLength()` throws a plain `Error` whenever it encounters a JSON number that is not finite (e.g. `Infinity`, produced by a literal such as `1e400` which is syntactically valid JSON but overflows the IEEE-754 double range). Because this throw is synchronous and uncaught anywhere in the call chain from `network.js`'s joint-handling code, it propagates to Node's `uncaughtException` handler, which is deliberately configured to **re-throw and crash the process**.

Note the asymmetry: `getTotalPayloadSize` is wrapped in `try/catch` "to make sure ..." while `getHeadersSize` is called bare, twice, with no protection.

`object_length.js`'s `getLength` recursively walks the object and throws on any non-finite number: [2](#0-1) [3](#0-2)

This field is one of the fields explicitly allowed at the unit level: [4](#0-3) 

Its actual structural/type validation (`validateHeadersCommissionRecipients`) happens only later, inside the `async.series` pipeline that runs after the size checks: [5](#0-4) 

So an attacker-crafted unit can set `earned_headers_commission_recipients: [{address: "<valid addr>", earned_headers_commission_share: 1e400}]`. `JSON.parse` accepts `1e400` as a syntactically valid number literal but it overflows to `Infinity` (the double-precision analog of the int32 shape overflow in the original TensorFlow `AvgPool3DGrad` CVE). When `getHeadersSize` reaches this value, `getLength`'s `case "number"` branch throws `Error("invalid number: Infinity")` synchronously, before any of `hasFieldsExcept`/type checks for that field have run.

This exception is not caught anywhere between `object_length.js` and the network layer. `network.js` invokes validation directly and unconditionally: [6](#0-5) 

and process-wide: [7](#0-6) 

The `uncaughtException` handler explicitly re-throws to crash the process ("crash the process to avoid ending up in an inconsistent state"). Any full node (and any light node relaying/validating such a unit) that receives this single malformed unit — whether pushed via `justsaying 'joint'` or via `handlePostedJoint` from a device/light client — will crash.

### Impact Explanation
This is a remotely triggerable, single-unit denial-of-service against any ocore node (full or light) that processes the malicious joint: the node process crashes deterministically, matching the "network unable to confirm new units" impact class. Since the crash occurs during basic unit validation (reachable by any unprivileged peer who can post/broadcast a unit), a coordinated broadcast of such a unit can crash many/most nodes simultaneously, halting network confirmation.

### Likelihood Explanation
High feasibility: no signatures, special privileges, or asset ownership are required — only the ability to construct and broadcast a syntactically valid unit JSON containing a numeric field with an out-of-double-range literal (e.g., `1e400`). `earned_headers_commission_recipients` is an ordinary allowed top-level unit field and is reachable by any unit poster before deeper structural validation occurs.

### Recommendation
- Wrap the `objectLength.getHeadersSize(objUnit)` calls in `validation.js` in the same defensive `try/catch` pattern already used for `getTotalPayloadSize`, converting the thrown error into a `ifJointError`/`ifUnitError` callback instead of letting it propagate.
- Additionally (defense in depth), validate the type/finiteness of all numeric fields (including `earned_headers_commission_share` inside `earned_headers_commission_recipients`) before they reach any size/length computation, not just after it in `validateHeadersCommissionRecipients`.

### Proof of Concept
Construct and broadcast (e.g. via `justsaying 'joint'` or posted joint) a unit whose top-level object includes:
```json
{
  "unit": { ... valid otherwise ... ,
    "earned_headers_commission_recipients": [
      { "address": "<VALID_ADDRESS>", "earned_headers_commission_share": 1e400 }
    ]
  }
}
```
`JSON.parse` turns `1e400` into `Infinity`. When the receiving node calls `validation.validate()`, `objectLength.getHeadersSize(objUnit)` walks this field via `getLength`, hits the non-finite number, and throws `Error("invalid number: Infinity")` uncaught, crashing the node process via the `uncaughtException` handler in `network.js`.

function getLength(value, bWithKeys) {
	let cache = new WeakMap();  // object to length
	function _getLength(value) {
		if (value === null)
			return 0;
		switch (typeof value) {
			case "string":
				return value.length;
			case "number":
				if (!isFinite(value))
					throw Error("invalid number: " + value);
				return 8;
				//return value.toString().length;
			case "object":
				// return cached result if already processed
				if (cache.has(value))
					return cache.get(value);
				var len = 0;
				if (Array.isArray(value))
					value.forEach(function (element) {
						len += _getLength(element);
					});
				else
					for (var key in value) {
						if (!Object.prototype.hasOwnProperty.call(value, key))
							throw Error("object has non-own property " + key + " in " + JSON.stringify(value));
						if (typeof value[key] === "undefined")
							throw Error("undefined at " + key + " of " + JSON.stringify(value));
						if (bWithKeys)
							len += key.length;
						len += _getLength(value[key]);
					}
				cache.set(value, len);  // memoize for future references
				return len;
			case "boolean":
				return 1;
			default:
				throw Error("unknown type=" + (typeof value) + " of " + value);
		}
	}
	return _getLength(value);
}
