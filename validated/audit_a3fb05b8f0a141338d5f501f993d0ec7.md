### Title
Bool `false` Vote Encoding Mismatch in `ToVoteBytes` Causes `VerifyVote` to Reject Valid Blocks — (File: `kaiax/gov/headergov/vote.go`)

---

### Summary

`ToVoteBytes()` RLP-encodes a `bool(false)` governance vote value as `0x80` (the RLP empty-string byte). `ToVoteData()` decodes the `Value` field as `[]byte`, which interprets `0x80` as `[]byte{}` (empty slice). The `boolCanonicalizer` only accepts `[]byte{0x01}` or `[]byte{0x00}`, so `[]byte{}` fails with `ErrCanonicalizeByteToBool`. Any block whose `header.Vote` encodes a `false` boolean governance parameter therefore fails `VerifyVote()` → `VerifyHeader()`, causing validators to reject a block that the proposer considers valid — a consensus divergence. The non-deprecated parameter `RewardUseFlexReward` (`reward.useflexreward`) is the reachable trigger.

---

### Finding Description

**Encoding side — `ToVoteBytes()`** [1](#0-0) 

The function converts `*big.Int` and `[]common.Address` values to wire-safe types before RLP encoding, but has **no special handling for `bool`**. A `bool(false)` value is passed directly to `rlp.EncodeToBytes` as an `any` field. The RLP encoder calls `writeBool`: [2](#0-1) 

`false` → `0x80` (the RLP encoding for zero / empty string).

**Decoding side — `ToVoteData()`** [3](#0-2) 

The `Value` field is decoded as `[]byte`. The RLP decoder interprets `0x80` as an empty byte string → `[]byte{}`.

**Canonicalization — `boolCanonicalizer`** [4](#0-3) 

Only `[]byte{0x01}` → `true` and `[]byte{0x00}` → `false` are accepted. `[]byte{}` hits the `else` branch and returns `ErrCanonicalizeByteToBool`. `NewVoteData()` returns `nil`, and `ToVoteData()` returns `ErrInvalidVoteData`.

**Verification path** [5](#0-4) 

`VerifyVote()` calls `vb.ToVoteData()` at line 71. On failure it returns the error immediately — before the deprecation check at line 77. `VerifyHeader()` calls `VerifyVote()` at line 21: [6](#0-5) 

Any block with a `false` bool vote in `header.Vote` is rejected by every node that calls `VerifyHeader()`.

**Affected non-deprecated parameter**

`RewardUseFlexReward` (`reward.useflexreward`) uses `boolCanonicalizer` and is **not** in `AlwaysDeprecated` or `PermissionlessDeprecated`: [7](#0-6) [8](#0-7) 

`RewardDeferredTxFee` and `RewardUseGiniCoeff` are always-deprecated, so the deprecation check at line 77 would fire first for them — but `RewardUseFlexReward` is live.

The test suite itself acknowledges the round-trip is broken for bool params: [9](#0-8)

### Impact Explanation

**Consensus divergence / governance liveness:**

1. The governing node calls `governance_vote("reward.useflexreward", false)` via the API.
2. The vote is stored in-memory as `voteData{value: bool(false)}`.
3. When the governing node becomes the proposer, `PrepareHeader()` calls `ToVoteBytes()`, which succeeds (produces `0x80`) and writes the bytes to `header.Vote`.
4. The block is sealed and broadcast.
5. Every validator calls `VerifyHeader()` → `VerifyVote()` → `ToVoteData()` → **fails** → block rejected.
6. The proposer does not call `VerifyHeader()` on its own block before broadcasting; it considers the block valid.
7. Result: **consensus divergence** — proposer accepts, all validators reject. The round fails; a new proposer is elected. The governing node will keep re-inserting the vote into subsequent proposals, causing repeated round failures.

**Reward distribution impact:**

`reward.useflexreward` controls the flexible reward scheme (KIP-226 / Osaka hardfork). If it is currently `true` and the governing node needs to revert it to `false`, the bug makes that governance action permanently unexecutable, locking the reward distribution into the flex-reward path. [10](#0-9)

### Likelihood Explanation

- Requires the governing node to vote for `reward.useflexreward = false` (a valid, non-deprecated governance action).
- The default value of `UseFlexReward` is `false`, so the scenario arises when a chain has previously set it to `true` and the governing node attempts to revert it.
- The governing node is a semi-trusted actor with legitimate governance rights; no attacker privilege is required.
- The bug is deterministic: every attempt to include such a vote produces the same failure.

### Recommendation

In `ToVoteBytes()`, add explicit handling for `bool` values — mirroring the existing handling for `*big.Int` and `[]common.Address` — to convert them to a `[]byte` representation that survives the `[]byte` decode path:

```go
// In ToVoteBytes(), alongside the existing type conversions:
} else if cv, ok := vote.value.(bool); ok {
    if cv {
        v.Value = []byte{0x01}
    } else {
        v.Value = []byte{0x00}
    }
}
```

This ensures `false` is encoded as `[]byte{0x00}` (RLP: `0x80` for empty string is replaced by the explicit single-byte `0x00`), which `boolCanonicalizer` already accepts.

Alternatively, update `boolCanonicalizer` to accept `[]byte{}` as `false`, but this is less safe as it conflates an empty/missing value with an explicit `false`.

### Proof of Concept

```
1. Governing node calls: governance_vote("reward.useflexreward", false)
   → voteData{name: "reward.useflexreward", value: bool(false)}

2. ToVoteBytes() encodes:
   rlp.EncodeToBytes({Validator: addr, Key: "reward.useflexreward", Value: false})
   → Value field: writeBool(false) → 0x80
   → header.Vote = [... 0x80 ...]

3. ToVoteData() decodes:
   var v struct { Validator common.Address; Key string; Value []byte }
   rlp.DecodeBytes(header.Vote, &v)
   → v.Value = []byte{}   (0x80 decoded as empty RLP string)

4. NewVoteData(addr, "reward.useflexreward", []byte{})
   → boolCanonicalizer([]byte{})
   → bytes.Equal([]byte{}, []byte{0x01}) = false
   → bytes.Equal([]byte{}, []byte{0x00}) = false
   → return nil, ErrCanonicalizeByteToBool
   → NewVoteData returns nil

5. ToVoteData returns ErrInvalidVoteData

6. VerifyVote returns ErrInvalidVoteData
   VerifyHeader returns ErrInvalidVoteData
   → All validators reject the proposer's block
   → Consensus divergence; repeated round failures
```

func (vote *voteData) ToVoteBytes() (VoteBytes, error) {
	v := &struct {
		Validator common.Address
		Key       string
		Value     any
	}{
		Validator: vote.voter,
		Key:       string(vote.name),
		Value:     vote.value,
	}

	if cv, ok := vote.value.(*big.Int); ok {
		v.Value = cv.String()
	} else if cv, ok := vote.value.([]common.Address); ok {
		// concat all addresses into []byte
		concatBytes := make([]byte, 0, len(cv)*common.AddressLength)
		for _, addr := range cv {
			concatBytes = append(concatBytes, addr.Bytes()...)
		}
		v.Value = concatBytes
	}

	return rlp.EncodeToBytes(v)
}
