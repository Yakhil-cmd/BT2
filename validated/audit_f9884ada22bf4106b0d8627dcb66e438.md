### Title
`LowerBoundBaseFee > UpperBoundBaseFee` Achievable via Same-Epoch Dual Governance Votes, Breaking the Fee Market — (`kaiax/gov/headergov/impl/header.go`)

---

### Summary

The per-vote `checkConsistency` guard in `headerGovModule` validates each KIP-71 bound vote against the **current** (pre-epoch) counterpart, but does not validate the **combined** result of two votes cast in the same epoch. A governing node (or two GC members in `none` mode) can cast one vote raising `kip71.lowerboundbasefee` and one vote lowering `kip71.upperboundbasefee` in the same epoch; each vote passes its individual check, but their joint application at the epoch boundary produces `LowerBoundBaseFee > UpperBoundBaseFee`. This inverted state permanently corrupts the on-chain base-fee market until a corrective governance vote is ratified.

---

### Finding Description

`checkConsistency` in `kaiax/gov/headergov/impl/header.go` enforces two per-vote guards:

```go
case gov.Kip71LowerBoundBaseFee:
    params := h.GetParamSet(blockNum)
    if vote.Value().(uint64) > params.UpperBoundBaseFee {
        return ErrLowerBoundBaseFee
    }
case gov.Kip71UpperBoundBaseFee:
    params := h.GetParamSet(blockNum)
    if vote.Value().(uint64) < params.LowerBoundBaseFee {
        return ErrUpperBoundBaseFee
    }
``` [1](#0-0) 

Each check compares the new value against the **current** (already-effective) counterpart. Votes do not take effect until the epoch boundary; `GetParamSet(blockNum)` returns the pre-epoch values throughout the entire epoch. [2](#0-1) 

`getExpectedGovernance` collects all votes from the previous epoch and applies them together at the epoch block with no cross-parameter validation:

```go
for _, voteBlock := range sortedVoteBlocks {
    vote := prevEpochVotes[voteBlock]
    govs.Add(string(vote.Name()), vote.Value())
}
``` [3](#0-2) 

`PartialParamSet.Add` only calls the per-parameter `FormatChecker`, which is `noopFormatChecker` for both KIP-71 bounds — no cross-parameter check exists at application time: [4](#0-3) [5](#0-4) 

---

### Impact Explanation

When `LowerBoundBaseFee > UpperBoundBaseFee` is committed to chain state, `NextMagmaBlockBaseFee` in `params/kip71_config.go` produces erratic base fees:

```go
parentBaseFee := parentHeaderBaseFee
if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {
    parentBaseFee = upperBoundBaseFee   // e.g. 100 gwei
} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
    parentBaseFee = lowerBoundBaseFee   // e.g. 600 gwei
}
``` [6](#0-5) 

With inverted bounds (upper=100, lower=600), every `parentBaseFee ≥ 100` is clamped to 100, and every `parentBaseFee < 100` is clamped to 600. The subsequent increase/decrease logic then caps or floors against the inverted bounds, causing the base fee to oscillate between 100 and 600 gwei in a single block — a complete breakdown of the EIP-1559-style fee market. `VerifyMagmaHeader` accepts these incorrect base fees because it only checks that the header value matches `NextMagmaBlockBaseFee`: [7](#0-6) 

The corrupted state persists on-chain and is accepted by all honest nodes, since all nodes apply the same governance change at the same epoch boundary. Every transaction's gas price validation is affected for the duration of the misconfiguration.

---

### Likelihood Explanation

- **`none` governance mode**: Any two GC members can independently vote for conflicting bounds in the same epoch without coordinating. Neither vote is individually invalid.
- **`single` governance mode**: The governing node must cast both votes in the same epoch, which could occur accidentally during a planned fee-range adjustment (e.g., intending to narrow the range by raising the lower bound and lowering the upper bound simultaneously).
- The epoch on Mainnet/Kairos is 604,800 blocks (~1 week), giving ample time for both votes to be cast.

---

### Recommendation

Validate the **combined** result of all KIP-71 bound votes at the epoch boundary before committing governance, or add a cross-parameter check inside `getExpectedGovernance` / `VerifyGov`:

```go
// In VerifyGov or getExpectedGovernance, after collecting all epoch votes:
if newLower, ok1 := govs[gov.Kip71LowerBoundBaseFee]; ok1 {
    effectiveUpper := /* new upper from govs, or current params.UpperBoundBaseFee */
    if newLower.(uint64) > effectiveUpper.(uint64) {
        return ErrLowerBoundBaseFee
    }
}
// symmetric check for UpperBoundBaseFee
```

Alternatively, `checkConsistency` should check the new vote value against **both** the current counterpart **and** any pending same-epoch vote for the counterpart.

---

### Proof of Concept

**Setup:** Mainnet-like chain, `none` governance mode, epoch = 604800, current params: `LowerBoundBaseFee = 25 gwei`, `UpperBoundBaseFee = 750 gwei`.

**Step 1 — Block 100 (epoch 0):** GC member A votes `kip71.lowerboundbasefee = 600 gwei`.
- `checkConsistency`: `600 <= 750 (current upper)` → **passes**.

**Step 2 — Block 200 (epoch 0):** GC member B votes `kip71.upperboundbasefee = 100 gwei`.
- `checkConsistency`: `100 >= 25 (current lower)` → **passes**.

**Step 3 — Block 604800 (epoch boundary):** `getExpectedGovernance` collects both votes and writes `header.Governance = {lowerboundbasefee: 600, upperboundbasefee: 100}`. `VerifyGov` accepts it (it only checks that the governance matches the locally-derived vote set, not cross-parameter validity). [8](#0-7) 

**Step 4 — Block 604801 onward:** `GetParamSet` returns `LowerBoundBaseFee = 600 gwei`, `UpperBoundBaseFee = 100 gwei`. `NextMagmaBlockBaseFee` oscillates the base fee between 100 and 600 gwei per block. `VerifyMagmaHeader` accepts every such block. The fee market is broken for all users until a corrective governance vote takes effect one full epoch later.

func (h *headerGovModule) getExpectedGovernance(blockNum uint64) headergov.GovData {
	prevEpochIdx := calcEpochIdx(blockNum, h.epoch) - 1
	prevEpochVotes := h.getVotesInEpoch(prevEpochIdx)
	govs := make(gov.PartialParamSet)

	sortedVoteBlocks := slices.Collect(maps.Keys(prevEpochVotes))
	slices.Sort(sortedVoteBlocks)

	for _, voteBlock := range sortedVoteBlocks {
		vote := prevEpochVotes[voteBlock]
		govs.Add(string(vote.Name()), vote.Value())
	}

	// assert(len(headergov.NewGovData(govs).Items()) == len(govs))
	return headergov.NewGovData(govs)
}

func (kc *KIP71Config) VerifyMagmaHeader(headerBaseFee *big.Int, parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) error {
	if headerBaseFee == nil {
		return fmt.Errorf("header is missing baseFee")
	}
	// Verify the baseFee is correct based on the parent header.
	expectedBaseFee := kc.NextMagmaBlockBaseFee(parentHeaderNumber, parentHeaderBaseFee, parentHeaderGasUsed)
	if headerBaseFee.Cmp(expectedBaseFee) != 0 {
		return fmt.Errorf("invalid baseFee: have %s, want %s, parentBaseFee %s, parentGasUsed %d",
			headerBaseFee, expectedBaseFee, parentHeaderBaseFee, parentHeaderGasUsed)
	}
	return nil
}
