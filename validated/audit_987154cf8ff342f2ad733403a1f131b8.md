### Title
`IsOfficial` trusts owner string alone and ignores repo host, letting an attacker-controlled remote spoof the "official extension" telemetry signal - (File: pkg/extensions/official.go)

### Finding Description
`IsOfficial` decides whether an extension is GitHub-owned purely by comparing `name`/`owner` strings against the `OfficialExtensions` table, with no reference to which host the extension actually came from: [1](#0-0) 

The `owner` value it receives is produced elsewhere by parsing the extension's git remote URL with `git.ParseURL` + `ghrepo.FromURL` (as done for the analogous "installed" check in `browse.go`): [2](#0-1) 

`ghrepo.FromURL` derives the returned `Interface`'s owner strictly from the first path segment of the URL, and the hostname from `u.Hostname()` — the two are stored independently and nothing downstream cross-checks that "owner == github" implies "host == github.com": [3](#0-2) 

Consequently, any git remote URL whose path begins with `/github/...` — regardless of the actual hostname (e.g. a self-hosted git server, an enterprise instance the attacker controls, or a crafted URL with unusual userinfo) — produces `ghRepo{owner: "github", hostname: <attacker-host>}`. When that value flows into `ext.Owner()` and then into `extensions.IsOfficial(ext.Name(), ext.Owner())` in `pkg/cmd/root/extension.go`, the name/owner match succeeds and `DisableTelemetry` is skipped, exactly as the comment at the call site intends only for genuinely GitHub-owned extensions: [4](#0-3) 

No code path validates `RepoHost()` against `github.com` before calling `IsOfficial`; the function signature itself (`func IsOfficial(name, owner string) bool`) structurally discards host information, so the check cannot distinguish `github/gh-stack` on `github.com` from `github/gh-stack` on `attacker.example`.

### Impact Explanation
The only concrete effect of `IsOfficial` returning `true` in this codebase is enabling telemetry annotation on the extension command (`cmd.Annotations["telemetry"]`), as shown by the existing test matrix that only varies `extName`/`extOwner` strings, never host: [5](#0-4) 

This is a trust/authenticity-signal bypass: telemetry (and any future code that treats `IsOfficial` as an authenticity oracle) can be fooled into treating third-party, attacker-hosted content as GitHub-owned. It does not by itself grant code execution, credential exfiltration, or file write — impact is limited to the "wrong-account"/misclassification category, matching a low-severity authorization/trust-signal defect rather than a high-impact compromise.

### Likelihood Explanation
This requires the victim to install an extension from a URL the attacker controls whose path happens to start with `/github/` on a non-github.com host (e.g. `gh extension install https://attacker.example/github/gh-stack`) or otherwise via any mechanism that populates `ext.Owner()` from an unvalidated `ghrepo.FromURL` result. Extension installation from arbitrary git URLs is a supported gh feature, so the precondition is plausible but requires the victim to actively choose to install from a non-github.com source, lowering real-world likelihood while remaining fully reproducible.

### Recommendation
Change `IsOfficial` to require the extension's host to be `github.com` in addition to name/owner, e.g. accept a `ghrepo.Interface` (or explicit host parameter) and compare `ghinstance` normalized host, so owner/name string coincidence on a non-GitHub host can never satisfy the check. Update `pkg/cmd/root/extension.go` to pass through the extension's host (from `Extension.URL()`/`ghrepo.FromURL`) rather than only `Owner()`.

### Proof of Concept
```go
func TestIsOfficial_HostNotValidated(t *testing.T) {
    u, _ := git.ParseURL("https://attacker.example/github/gh-stack.git")
    r, err := ghrepo.FromURL(u)
    require.NoError(t, err)

    // owner resolves to "github" even though host is attacker-controlled
    assert.Equal(t, "github", r.RepoOwner())
    assert.Equal(t, "attacker.example", r.RepoHost())

    // IsOfficial only looks at name/owner, ignoring host — this should be false
    // for a non-github.com origin but currently returns true.
    assert.True(t, extensions.IsOfficial("stack", r.RepoOwner()))
}
```
Expected (fixed) behavior: `IsOfficial` (or its replacement taking a `ghrepo.Interface`) should return `false` because `r.RepoHost() != "github.com"`, proving the current implementation conflates owner-string equality with genuine GitHub origin.

func IsOfficial(name, owner string) bool {
	if owner == "" {
		return false
	}
	for _, ext := range OfficialExtensions {
		if ext.Name == name && strings.EqualFold(ext.Owner, owner) {
			return true
		}
	}
	return false
}

// FromURL extracts the GitHub repository information from a git remote URL
func FromURL(u *url.URL) (Interface, error) {
	if u.Hostname() == "" {
		return nil, fmt.Errorf("no hostname detected")
	}

	parts := strings.SplitN(strings.Trim(u.Path, "/"), "/", 3)
	if len(parts) != 2 {
		return nil, fmt.Errorf("invalid path: %s", u.Path)
	}

	return NewWithHost(parts[0], strings.TrimSuffix(parts[1], ".git"), u.Hostname()), nil
}
