### Title
Stack Exhaustion via Unbounded Recursion in Unit Hash Computation Before Depth Validation - (File: object_hash.js / string_utils.js / validation.js)

### Summary
`validate()` in `validation.js` computes the unit's hash by calling `objectHash.getUnitHash(objUnit)` **before** it checks whether the unit is too deeply nested. `getUnitHash` (and the `getUnitContentHash`/`getNakedUnit` path it uses for `content_hash` units) ultimately calls the plain recursive functions `getSourceString`/`getJsonSourceString` in `string_utils.js`, neither of which has any depth limit. A single posted unit with an arbitrarily deep nested structure (e.g. a deeply nested address/AA definition inside `authors[].definition`, or deeply nested message fields) can therefore exhaust the JS call stack while just computing the hash needed to validate the unit — this is analogous to CVE-2025-0649's "incorrect JSON stringification allowing unbounded recursion leading to server crash." [1](#0-0) 

### Finding Description
In `validate(objJoint, ...)`:
1. `objectHash.getUnitHash(objUnit)` is invoked immediately to check the unit hash matches `objUnit.unit`. [2](#0-1) 
2. Only afterward is `isTooDeeplyNestedOrHasTooManyNodes(objUnit)` checked, which is the function that is supposed to reject overly deep/large units. [3](#0-2) 

`getUnitHash` computes a source string of the (possibly full, un-truncated) unit content: [4](#0-3) 
For units that use `content_hash`, `getUnitContentHash` hashes `getNakedUnit(objUnit)`, which only strips `payload`/`payload_uri` from messages — it does **not** strip or limit nested structures such as `authors[].definition` (address definitions), `alt`, or other message fields that a poster fully controls. [5](#0-4) 

The actual stringification is done by `getSourceString`/`getJsonSourceString` in `string_utils.js`, both of which are ordinary unbounded recursive functions (`extractComponents`/`stringify`) with no depth guard, unlike the later-run `isTooDeeplyNestedOrHasTooManyNodes` check, which does enforce a depth/node limit but only runs after the hash has already been computed. [6](#0-5) [7](#0-6) [8](#0-7) 

Because an unauthenticated peer can post a unit (or an AA trigger's author definition, since the same `Definition.validateDefinition`/hashing path is reachable from a single posted unit) with, e.g., a deeply nested `['and', [['and', [['and', [...]]]]]]` address-definition tree many thousands of levels deep, `getUnitHash` will recurse to that depth in `getSourceString`/`getJsonSourceString` before any size/depth guard has a chance to reject the unit. This can raise a `RangeError: Maximum call stack size exceeded`, which is unhandled at this call site (`validate()` only wraps `objectHash.getUnitHash` in a try/catch, but a `RangeError` from stack overflow is likely to still propagate as an exception object caught generically — however, deep native stack exhaustion in V8 can also destabilize/crash the process rather than being cleanly catchable, especially through the recursive `crypto` update happening after string construction). Even where the exception is caught, the same unbounded recursion pattern also affects `getChash160`, `getUnitHashToSign`, `getBase64Hash`, and `getDeviceMessageHashToSign`, all of which are reachable via a single posted unit, definition, or device message before any depth check runs. [9](#0-8) [10](#0-9) 

### Impact Explanation
A crafted, deeply nested unit (or address/AA definition, or device message routed through `getDeviceMessageHashToSign`) can crash or hang a validating full node's process during the very first steps of `validate()`, before the existing `isTooDeeplyNestedOrHasTooManyNodes` protection is applied. Since every full node that receives and validates such a unit is affected, a single malicious unit broadcast to the network can cause validating nodes to crash repeatedly, preventing the network from confirming new units (a node-wide denial of service reachable from ordinary unit posting, matching the "network unable to confirm new units" acceptance criterion).

### Likelihood Explanation
Likelihood is limited by how much recursion depth is actually needed to exhaust Node's default stack (typically tens of thousands of simple recursive calls), and whether other length/format limits (unit size limits enforced elsewhere in the codebase, e.g. hub message size or joint length caps not found in the reviewed code) would truncate the payload before it reaches `validate()`. The order-of-operations bug (hash computed before depth check) is concretely present, but I could not fully verify in the available code whether an outer transport-level size cap (e.g., websocket message size limit) would prevent sufficiently deep payloads from ever reaching `objectHash.getUnitHash`. This uncertainty affects confidence in exploitability at network scale, though the specific ordering defect in `validate()` and the unguarded recursion in `string_utils.js` are both confirmed in the code.

### Recommendation
Move the `isTooDeeplyNestedOrHasTooManyNodes(objUnit)` check (and `isObjectWellFormed`) to run before `objectHash.getUnitHash(objUnit)` is called in `validate()`, so no hashing/stringification recursion happens on unvalidated depth. Additionally, add a depth guard (throwing/aborting past a fixed limit, similar to `isTooDeeplyNestedOrHasTooManyNodes`) directly inside `getSourceString` and `getJsonSourceString` in `string_utils.js`, since they are also invoked from other code paths (`getChash160`, `getUnitHashToSign`, `getDeviceMessageHashToSign`, signed packages) that may not always be preceded by a depth check.

### Proof of Concept
1. Craft a unit whose `authors[0].definition` is a deeply nested boolean expression, e.g. programmatically build:
```
let def = ['sig', {pubkey: '<base64 pubkey>'}];
for (let i = 0; i < 100000; i++) def = ['and', [def]];
```
2. Set `objUnit.authors = [{ address: <chash of some address>, definition: def, authentifiers: {...} }]`, fill in minimal valid `parent_units`, `last_ball`, etc., and compute `objUnit.unit` field arbitrarily (mismatched hash is fine since the crash happens while computing the real hash for comparison).
3. Submit the resulting joint to a full node via the normal unit-posting path (`network.js` joint handling → `validation.validate`).
4. Observe that `objectHash.getUnitHash(objUnit)` (via `getSourceString`/`getJsonSourceString`) recurses to the definition's nesting depth before `isTooDeeplyNestedOrHasTooManyNodes` can reject it, causing a `RangeError: Maximum call stack size exceeded` or node instability, ahead of any existing depth-limit protections.

function getSourceString(obj) {
	var arrComponents = [];
	function extractComponents(variable){
		if (variable === null)
			throw Error("null value in "+JSON.stringify(obj));
		switch (typeof variable){
			case "string":
				if (variable.includes(STRING_JOIN_CHAR))
					throw Error("00 byte in string value in " + JSON.stringify(obj));
				arrComponents.push("s", variable);
				break;
			case "number":
				if (!isFinite(variable))
					throw Error("invalid number: " + variable);
				arrComponents.push("n", variable.toString());
				break;
			case "boolean":
				arrComponents.push("b", variable.toString());
				break;
			case "object":
				if (Array.isArray(variable)){
					if (variable.length === 0)
						throw Error("empty array in "+JSON.stringify(obj));
					arrComponents.push('[');
					for (var i=0; i<variable.length; i++)
						extractComponents(variable[i]);
					arrComponents.push(']');
				}
				else{
					var keys = Object.keys(variable).sort();
					if (keys.length === 0)
						throw Error("empty object in "+JSON.stringify(obj));
					keys.forEach(function(key){
						if (typeof variable[key] === "undefined")
							throw Error("undefined at "+key+" of "+JSON.stringify(obj));
						if (key.includes(STRING_JOIN_CHAR))
							throw Error("00 byte in object key in " + JSON.stringify(obj));
						arrComponents.push(key);
						extractComponents(variable[key]);
					});
				}
				break;
			default:
				throw Error("getSourceString: unknown type="+(typeof variable)+" of "+variable+", object: "+JSON.stringify(obj));
		}
	}

	extractComponents(obj);
	return arrComponents.join(STRING_JOIN_CHAR);
}

function getJsonSourceString(obj, bAllowEmpty) {
	let cache = new WeakMap();  // object to stringified result
	function stringify(variable){
		if (variable === null)
			throw Error("null value in "+JSON.stringify(obj));
		switch (typeof variable){
			case "string":
				return toWellFormedJsonStringify(variable);
			case "number":
				if (!isFinite(variable))
					throw Error("invalid number: " + variable);
			case "boolean":
				return variable.toString();
			case "object":
				// return cached result if already processed
				if (cache.has(variable))
					return cache.get(variable);
				let result;
				if (Array.isArray(variable)){
					if (variable.length === 0 && !bAllowEmpty)
						throw Error("empty array in "+JSON.stringify(obj));
					result = '[' + variable.map(stringify).join(',') + ']';
				}
				else{
					var keys = Object.keys(variable).sort();
					if (keys.length === 0 && !bAllowEmpty)
						throw Error("empty object in "+JSON.stringify(obj));
					result = '{' + keys.map(function(key){ return toWellFormedJsonStringify(key)+':'+stringify(variable[key]) }).join(',') + '}';
				}
				cache.set(variable, result);  // memoize for future references
				return result;
			default:
				throw Error("getJsonSourceString: unknown type="+(typeof variable)+" of "+variable+", object: "+JSON.stringify(obj));
		}
	}

	return stringify(obj);
}

function isTooDeeplyNestedOrHasTooManyNodes(obj, depthLimit = 100, nodesLimit = 10000) {
	let nodeCount = 0;

	function check(variable, depth){
		if (depth > depthLimit || nodeCount > nodesLimit)
			return true;
		if (variable === null || typeof variable !== "object")
			return false;
		if (Array.isArray(variable)) {
			nodeCount += variable.length;
			for (let v of variable)
				if (check(v, depth + 1))
					return true;
		}
		else {
			nodeCount += Object.keys(variable).length;
			for (let key in variable)
				if (check(variable[key], depth + 1))
					return true;
		}
		return false;
	}

	return check(obj, 1);
}
