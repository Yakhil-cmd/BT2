**Rationale:** The CVE describes an application-level design flaw in Turms Server's `BaseAdminService`/`AdminInfo` classes, which cache plaintext administrator passwords in memory as an authentication-performance optimization <cite repo="Ellentat/polkadot-sdk--012" path="" start="" end="" />. This is a chat-server-specific admin login system with no structural analog in Polkadot SDK.

The closest conceptually related code in this repo is the node keystore subsystem, which stores keys/seeds and passwords, but it differs fundamentally from the CVE's scenario:

- Keystore passwords and seeds are wrapped in `SecretString`/`ExposeSecret`, a type specifically designed to avoid casual plaintext exposure, and are only accessible via explicit `expose_secret()` calls [1](#0-0) [2](#0-1) .
- The keystore password/seed material is node-operator-supplied local configuration (CLI args, files, or interactive prompt) [3](#0-2) [4](#0-3) , not something reachable via a signed extrinsic, contract call, or XCM message from an untrusted network participant.
- There is no "administrator authentication service" analog reachable through a real user entry point (signed extrinsic, permitted XCM, contract call) in this codebase; the keystore is a client-side/node-local component used for signing, not an on-chain or network-facing authentication boundary.

Because the prompt requires demonstrating the vulnerability through an actual attacker-reachable entry point (signed extrinsic, enabled contract call, permitted XCM execution, or public proof submission) with no privileged access, and no such entry point exists for this bug class (plaintext credential caching by a privileged local-config component), there is no valid Polkadot SDK analog to report.

impl KeystoreParams {
	/// Get the keystore configuration for the parameters
	pub fn keystore_config(&self, config_dir: &Path) -> Result<KeystoreConfig> {
		let password = if self.password_interactive {
			Some(SecretString::new(input_keystore_password()?))
		} else if let Some(ref file) = self.password_filename {
			let password = fs::read_to_string(file).map_err(|e| format!("{}", e))?;
			Some(SecretString::new(password))
		} else {
			self.password.clone()
		};

		let path = self
			.keystore_path
			.clone()
			.unwrap_or_else(|| config_dir.join(DEFAULT_KEYSTORE_CONFIG_PATH));

		Ok(KeystoreConfig::Path { path, password })
	}

	/// helper method to fetch password from `KeyParams` or read from stdin
	pub fn read_password(&self) -> error::Result<Option<SecretString>> {
		let (password_interactive, password) = (self.password_interactive, self.password.clone());

		let pass = if password_interactive {
			let password = rpassword::prompt_password("Key password: ")?;
			Some(SecretString::new(password))
		} else {
			password
		};

		Ok(pass)
	}
