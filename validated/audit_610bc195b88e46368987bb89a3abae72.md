### Title
Unguarded Division by Zero in `NextMagmaBlockBaseFee` When `kip71.gastarget` Is Set to Zero via Governance — (`params/kip71_config.go`)

---

### Summary

`NextMagmaBlockBaseFee` divides by the governance-controlled `GasTarget` parameter without a zero-guard. The sibling parameter `BaseFeeDenominator` has an explicit zero-check that falls back to a safe default, but `GasTarget` has none. Because the governance format-checker for `kip71.gastarget` is `noopFormatChecker` (accepts any `uint64`, including 0), a governing node can set `GasTarget = 0`. The next block with any non-zero gas used then triggers a `big.Int.Div` panic inside `NextMagmaBlockBaseFee`, crashing every node that attempts to validate it and halting the chain.

---

### Finding Description

**Root cause — asymmetric zero-guard between `BaseFeeDenominator` and `GasTarget`:**

`BaseFeeDenominator` has an explicit zero-check:

```go
// params/kip71_config.go lines 71-76
if kc.BaseFeeDenominator == 0 {
    baseFeeDenominator = new(big.Int).SetUint64(64)
} else {
    baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
}
``` [1](#0-0) 

`GasTarget` has no such guard and is used directly as a divisor on lines 102 and 120:

```go
y := x.Div(x, new(big.Int).SetUint64(gasTarget))  // line 102 (increase path)
y := x.Div(x, new(big.Int).SetUint64(gasTarget))  // line 120 (decrease path)
``` [2](#0-1) 

The only early-exit is `if parentGasUsed == gasTarget` (line 90), which only fires when both are 0. Any block with `parentGasUsed > 0` and `gasTarget = 0` falls into the `parentGasUsed > gasTarget` branch and hits the unguarded division. [3](#0-2) 

**Governance allows `GasTarget = 0`:**

The `Kip71GasTarget` parameter entry uses `noopFormatChecker`, which accepts any `uint64` value including 0: [4](#0-3) 

In contrast, `Kip71BaseFeeDenominator` explicitly rejects 0 with `return ok && v != 0`: [5](#0-4) 

---

### Impact Explanation

`NextMagmaBlockBaseFee` is called from `VerifyMagmaHeader` inside `blockchain/block_validator.go` during block header validation. A `big.Int.Div` call with a zero divisor panics unconditionally in Go. Once `GasTarget = 0` takes effect and any block with non-zero gas is produced, every node that validates that block crashes. This is a **consensus divergence / chain halt**: all honest nodes crash simultaneously and cannot resume processing blocks until the software is patched or the governance parameter is corrected.

The function is also called from `blockchain/tx_pool.go`, `work/worker.go`, `node/cn/gasprice/gasprice.go`, and `node/cn/gasprice/feehistory.go`, widening the crash surface. [6](#0-5) 

---

### Likelihood Explanation

In Kaia's default "single" governance mode (mainnet configuration), a single governing node can submit and immediately apply governance parameter changes. The `noopFormatChecker` on `Kip71GasTarget` provides no on-chain or off-chain rejection of the value 0. A malicious or compromised governing node can trigger this with one governance transaction. The asymmetry with `BaseFeeDenominator` (which is protected) makes this an oversight rather than an intentional design choice.

---

### Recommendation

Add a zero-guard for `GasTarget` in `NextMagmaBlockBaseFee`, mirroring the existing guard for `BaseFeeDenominator`:

```go
gasTarget := kc.GasTarget
if gasTarget == 0 {
    // Avoid division by zero; treat as if parentGasUsed == gasTarget
    return makeEvenByFloor(parentBaseFee)
}
```

Additionally, update the `FormatChecker` for `Kip71GasTarget` in `kaiax/gov/param.go` to reject 0, consistent with `Kip71BaseFeeDenominator`:

```go
Kip71GasTarget: {
    FormatChecker: func(cv any) bool {
        v, ok := cv.(uint64)
        return ok && v != 0
    },
    ...
}
``` [4](#0-3) 

---

### Proof of Concept

1. Chain is post-Magma hardfork with `kip71.gastarget` currently at its default (`30_000_000`).
2. The governing node submits a governance vote setting `kip71.gastarget = 0`. Because `noopFormatChecker` accepts any `uint64`, the vote is accepted and stored.
3. After the governance epoch boundary, `GetParamSet` returns `GasTarget = 0` for new blocks.
4. A block is produced with `header.GasUsed > 0` (any normal transaction block).
5. Every node calls `VerifyMagmaHeader` → `NextMagmaBlockBaseFee` with `parentHeaderGasUsed > 0` and `kc.GasTarget = 0`.
6. `parentGasUsed = min(parentHeaderGasUsed, upperGasLimit) > 0`, so `parentGasUsed > gasTarget (0)` is true.
7. Execution reaches `x.Div(x, new(big.Int).SetUint64(0))` → **panic: division by zero**.
8. All nodes crash. Chain halts.

The corrupted value is the `header.BaseFee` field: it can never be computed or verified again, making every subsequent block invalid and preventing any state transition, reward distribution, or withdrawal from completing.

```go
func (kc *KIP71Config) NextMagmaBlockBaseFee(parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) *big.Int {
	// governance parameters
	lowerBoundBaseFee := new(big.Int).SetUint64(kc.LowerBoundBaseFee)
	upperBoundBaseFee := new(big.Int).SetUint64(kc.UpperBoundBaseFee)
	makeEvenByCeil(lowerBoundBaseFee)
	makeEvenByFloor(upperBoundBaseFee)

	// If the parent is the magma disabled block or genesis, then return the lowerBoundBaseFee (default 25ston)
	if parentHeaderNumber.Cmp(new(big.Int).SetUint64(0)) == 0 || parentHeaderBaseFee == nil {
		return makeEvenByFloor(lowerBoundBaseFee)
	}

	var baseFeeDenominator *big.Int
	if kc.BaseFeeDenominator == 0 {
		// To avoid panic, set the fluctuation range small
		baseFeeDenominator = new(big.Int).SetUint64(64)
	} else {
		baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
	}
	gasTarget := kc.GasTarget
	upperGasLimit := kc.MaxBlockGasUsedForBaseFee

	// check the case of upper/lowerBoundBaseFee is updated by governance mechanism
	parentBaseFee := parentHeaderBaseFee
	if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {
		parentBaseFee = upperBoundBaseFee
	} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
		parentBaseFee = lowerBoundBaseFee
	}

	// upper gas limit cut off the impulse of used gas to upper bound
	parentGasUsed := min(parentHeaderGasUsed, upperGasLimit)
	if parentGasUsed == gasTarget {
		return makeEvenByFloor(parentBaseFee)
	} else if parentGasUsed > gasTarget {
		// shortcut. If parentBaseFee is already reached upperbound, do not calculate.
		if parentBaseFee.Cmp(upperBoundBaseFee) == 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		// If the parent block used more gas than its target,
		// the baseFee of the next block should increase.
		// baseFeeDelta = max(1, parentBaseFee * (parentGasUsed - gasTarget) / gasTarget / baseFeeDenominator)
		gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := math.BigMax(x.Div(y, baseFeeDenominator), common.Big1)

		nextBaseFee := x.Add(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(upperBoundBaseFee) > 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	} else {
		// shortcut. If parentBaseFee is already reached lower bound, do not calculate.
		if parentBaseFee.Cmp(lowerBoundBaseFee) == 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		// Otherwise if the parent block used less gas than its target,
		// the baseFee of the next block should decrease.
		// baseFeeDelta = parentBaseFee * (gasTarget - parentGasUsed) / gasTarget / baseFeeDenominator
		gasUsedDelta := new(big.Int).SetUint64(gasTarget - parentGasUsed)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := x.Div(y, baseFeeDenominator)

		nextBaseFee := x.Sub(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(lowerBoundBaseFee) < 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	}
}
