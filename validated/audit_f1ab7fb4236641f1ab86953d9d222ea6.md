### Title
Supply-index floor clamp leaves wiped supply shares redeemable, letting bad-debt survivors drain fresh pool cash - (File: contracts/pool/src/interest.rs)

### Summary
The use-after-free bug class maps onto XOXNO Lending as a **share-after-write-off** condition: when bad debt is socialized, `apply_bad_debt_to_supply_index` clamps the supply index at `SUPPLY_INDEX_FLOOR_RAW` (`RAY/1000`) instead of zeroing it, so the scaled supply shares of wiped suppliers — shares whose backing was already consumed by the write-off — remain "live" and redeemable against any cash later credited to the pool. Any unprivileged address holding a wiped position can call `withdraw` and extract tokens that economically belong to later depositors.

### Finding Description
`apply_bad_debt_to_supply_index` computes the post-socialization index as `supply_index * (total_supplied_value - capped_bad_debt) / total_supplied_value`, then floors it: `cache.set_supply_index(new_supply_index.max(Ray::from(SUPPLY_INDEX_FLOOR_RAW)))` [1](#0-0) . In a full wipeout (`capped == total_supplied_value`) the mathematically correct index is 0 — every supplier's claim is destroyed — but the clamp resurrects a residual claim of `scaled * RAY/1000` for every surviving supply position. The scaled `supplied` total and each account's scaled shares are not burned in proportion; only the index moves [2](#0-1) .

On the withdrawal path, `accounting` resolves the payout with `cache.resolve_withdrawal(amount, position)` using that floored index, burns shares, then `gate_and_debit` enforces only `require_reserves`, the utilization gate, and `require_supply_for_debt` before `debit_cash` [3](#0-2) . None of these guards protects a wiped market:

- `require_utilization_below_max` early-returns when `borrowed` unscale to zero — exactly the post-cleanup state where debt was burned [4](#0-3) .
- `require_supply_for_debt` only panics when `supplied == 0 && borrowed != 0`; scaled supply remains nonzero [5](#0-4) .
- `require_reserves` checks only `cash >= amount`, which becomes satisfiable the moment any fresh deposit or repayment credits cash [6](#0-5) .

The pool's own test suite demonstrates the mechanics: after the floor clamp, `unscale_supply_floor(old_scaled)` yields a positive "stranded" claim on zero cash, and once a fresh deposit credits cash the wiped holder's withdrawal "drains exactly the fresh deposit," leaving the honest claim undercollateralized [7](#0-6) . The equivalent seize-side wipeout scenario is also demonstrated [8](#0-7) .

### Impact Explanation
Theft of user funds / protocol insolvency. Bad-debt socialization (reachable via permissionless `clean_bad_debt`, liquidation seizure, or governance `force_socialize_bad_debt`) caps the index decrease at the floor, preserving ~0.1% phantom claims for every wiped supplier. When a fresh supplier deposits into the dead market — or when `recapitalize` credits cash without minting shares — a wiped-position holder withdraws and converts a claim whose backing was already written off into real tokens. Each residual withdrawal directly reduces the cash available for honest claims; the market's books are insolvent the moment fresh cash arrives (`unscale_supply_floor(supplied) > cash`) [9](#0-8) .

### Likelihood Explanation
Requires a market wipeout where bad debt ≥ total supplied value, which pushes `new_supply_index` below the floor — plausible in thin/young markets or after a sharp price crash, since permissionless `clean_bad_debt` exists for dust-collateral accounts and liquidation/seizure applies the same socialization. The residual is capped at ~0.1% of pre-wipe supply, bounding per-market theft, but the attacker needs no privilege and can repeat across markets and across multiple wiped positions they control. The main mitigating factor: if entry ops (supply) enforce `require_backed_market`, fresh deposits into an insolvent wiped market revert, converting the impact into a permanently frozen market until someone recapitalizes — I did not fully confirm whether `require_backed_market` is asserted on the supply path, so the theft-vs-freeze branch is the residual uncertainty.

### Recommendation
In `apply_bad_debt_to_supply_index`, when `capped == total_supplied_value` (full wipeout), zero the scaled supply state: set `supply_index` to the floor *and* burn `cache.supplied()` (and all per-position scaled shares) so no residual claim survives; alternatively allow the index to reach a true zero and guard `unscale_*`/`calculate_scaled_supply` against division by zero. At minimum, add `require_backed_market` (or a `backing_shortfall == 0` check) to every op that can credit cash or pay out claims — `withdraw`, `seize`, `recapitalize` consumption — so phantom claims can never settle against real reserves.

### Proof of Concept
1. Market M: Alice supplies 1,000 units (`scaled = 1000*RAY/index`), attacker-controlled borrower builds debt position, price crash makes debt unrecoverable.
2. Permissionless cleanup/liquidation writes off the full debt: `apply_bad_debt_to_supply_index` computes `remaining = 0`, `new_supply_index = 0`, clamps to `SUPPLY_INDEX_FLOOR_RAW` [10](#0-9) . Debt shares burned; Alice's and the attacker's scaled supply shares remain stored.
3. Alice's `unscale_supply_floor(scaled)` now returns `scaled * RAY/1000` ≈ 1 unit — a positive claim on an empty market; `cash == 0` masks it.
4. Bob (or `recapitalize`) deposits/credits cash. Pool books: owed `supplied * floor_index > cash`.
5. Attacker (or Alice) calls controller `withdraw` on the wiped position with `amount = i128::MAX`: `resolve_withdrawal` computes gross from the floored index, `require_reserves` passes against Bob's cash, utilization check early-returns (no debt), `debit_cash` and `transfer_out` pay real tokens [11](#0-10) .
6. Final state: `cash < unscale_supply_floor(remaining_supplied)` — the fresh depositor's claim is unpayable. This is exactly the sequence encoded in `test_raw_cache_floor_clamp_strands_claim_without_supply_guard` [12](#0-11) .

pub(crate) fn apply_bad_debt_to_supply_index(cache: &mut Cache, bad_debt: Ray) {
    let total_supplied_value = cache.supplied().mul(cache.env(), cache.supply_index());

    if total_supplied_value == Ray::ZERO {
        return;
    }

    let capped = bad_debt.min(total_supplied_value);
    let remaining = total_supplied_value.checked_sub(cache.env(), capped);

    let reduction_factor = remaining.div_floor(cache.env(), total_supplied_value);
    let new_supply_index = cache
        .supply_index()
        .mul_floor(cache.env(), reduction_factor);

    cache.set_supply_index(new_supply_index.max(Ray::from(SUPPLY_INDEX_FLOOR_RAW)));
}

fn test_raw_cache_floor_clamp_strands_claim_without_supply_guard() {
    let t = TestSetup::new();
    t.as_contract(|| {
        let old_scaled_raw = 1_000 * RAY;
        let mut cache = t.fresh_cache(PoolStateRaw {
            supplied: old_scaled_raw,
            borrowed: 0,
            revenue: 0,
            borrow_index: RAY,
            supply_index: RAY,
            last_timestamp: 0,
            cash: 0,
        });
        let old_scaled = Ray::from(old_scaled_raw);

        apply_bad_debt_to_supply_index(&mut cache, Ray::from(5_000 * RAY));
        assert_eq!(
            cache.supply_index().raw(),
            SUPPLY_INDEX_FLOOR_RAW,
            "wipeout clamps supply_index UP to RAY/1000 instead of resetting shares to 0",
        );

        let stranded = cache.unscale_supply_floor(old_scaled);
        assert!(stranded > 0, "floor clamp leaves S_old a phantom claim");
        assert_eq!(
            cache.cash(),
            0,
            "no cash yet: invariant only masked by require_reserves"
        );

        let fresh_cash = stranded;
        let fresh_scaled = cache.calculate_scaled_supply(fresh_cash);
        cache.mint_supply(fresh_scaled);
        cache.credit_cash(fresh_cash);

        let fresh_claim = cache.unscale_supply_floor(fresh_scaled);
        assert_eq!(
            fresh_claim, fresh_cash,
            "fresh supplier's claim equals deposit"
        );

        let (burn, gross) = cache.resolve_withdrawal(i128::MAX, old_scaled);
        cache.require_reserves(gross);
        cache.burn_supply(burn);
        cache.debit_cash(gross);

        assert!(gross > 0, "stranded wiped position pays out real tokens");
        assert_eq!(gross, fresh_cash, "S_old drains exactly the fresh deposit");
        assert!(
            cache.cash() < fresh_claim,
            "pool cash ({}) can no longer cover fresh supplier claim ({}): funds lost",
            cache.cash(),
            fresh_claim,
        );
    });
}

    t.as_contract(|| {
        let alice_scaled_raw = 1_000 * RAY;
        let borrowed_scaled_raw = 1_000 * RAY;
        let mut cache = t.fresh_cache(PoolStateRaw {
            supplied: alice_scaled_raw,
            borrowed: borrowed_scaled_raw,
            revenue: 0,
            borrow_index: RAY,
            supply_index: RAY,
            last_timestamp: 0,
            cash: 0,

        let borrow_scaled = Ray::from(borrowed_scaled_raw);

        let bad_debt = cache.unscale_borrow_ceil_ray(borrow_scaled);
        apply_bad_debt_to_supply_index(&mut cache, bad_debt);

            SUPPLY_INDEX_FLOOR_RAW,

            cache.cash(),
            0,
            "empty market: claim masked by require_reserves"

        let bob_scaled = cache.calculate_scaled_supply(deposit);
        cache.mint_supply(bob_scaled);
        cache.credit_cash(deposit);

        let total_owed = cache.unscale_supply_floor(cache.supplied());

        assert!(
            cache.cash() < bob_claim,
            "cash {} cannot cover Bob's honest claim {}: fresh depositor lost funds",
            cache.cash(),
            bob_claim

pub(crate) fn accounting(
    env: &Env,
    is_liquidation: bool,
    entry: &PoolWithdrawEntry,
) -> WithdrawOutcome {
    require_nonneg_amount(env, entry.protocol_fee);
    let (mut cache, position) = ops::load_leg(env, &entry.action);

    let (burned, gross_amount) = resolve_close_or_partial(&cache, entry.action.amount, position);
    // Burn first: `protocol_fee_shares` caps the fee mint at `i128::MAX - supplied`.
    let remaining = burn_position(env, &mut cache, position, burned);
    let net_transfer = withhold_liquidation_fee(
        env,
        &mut cache,
        gross_amount,
        is_liquidation,
        entry.protocol_fee,
    );

    // A footprint-only close must not add a utilization gate to same-market
    // net settlement: it burns no shares and moves no cash.
    let empty_close = position.raw() == 0 && entry.action.amount == i128::MAX;
    gate_and_debit(env, &mut cache, net_transfer, is_liquidation || empty_close);

    let snapshot = cache.commit();
    let mutation = cache.position_mutation(remaining, gross_amount);
    WithdrawOutcome {
        cache,
        mutation,
        snapshot,
        net_transfer,
    }
}

/// Maps requested amount and position to shares burned and gross asset amount.
/// Panics if a nonzero gross amount would burn zero shares.
fn resolve_close_or_partial(cache: &Cache, amount: i128, position: Ray) -> (Ray, i128) {
    let (burned, gross_amount) = cache.resolve_withdrawal(amount, position);
    assert_with_error!(
        cache.env(),
        gross_amount == 0 || burned.raw() > 0,
        GenericError::WithdrawRoundsToZeroShares
    );
    (burned, gross_amount)
}

/// Burns `burned` from market supply and returns the user's remaining scaled position.
fn burn_position(env: &Env, cache: &mut Cache, position: Ray, burned: Ray) -> Ray {
    cache.burn_supply(burned);
    position.checked_sub(env, burned)
}

/// Enforces reserve, utilization, and solvency guards, then debits cash for
/// the net transfer. Liquidations and footprint-only closes skip utilization.
fn gate_and_debit(env: &Env, cache: &mut Cache, net_transfer: i128, skip_utilization_check: bool) {
    cache.require_reserves(net_transfer);

    if !skip_utilization_check {
        guards::require_utilization_below_max(env, cache);
    }
    guards::require_supply_for_debt(env, cache);
    cache.debit_cash(net_transfer);
}

pub(crate) fn require_utilization_below_max(env: &Env, cache: &Cache) {
    if cache.supplied() == Ray::ZERO || cache.params().max_utilization >= Ray::ONE {
        return;
    }

    let borrowed = cache.borrowed().mul_ceil(env, cache.borrow_index());
    if borrowed == Ray::ZERO {
        return;
    }
    let supplied = cache.supplied().mul_floor(env, cache.supply_index());
    assert_with_error!(
        env,
        supplied > Ray::ZERO && borrowed.div_ceil(env, supplied) <= cache.params().max_utilization,
        CollateralError::UtilizationAboveMax
    );
}

/// Asset units by which supplier claims exceed cash + debt (0 if solvent).
pub(crate) fn backing_shortfall(cache: &Cache) -> i128 {
    let supplied_claim = cache.unscale_supply_floor(cache.supplied());
    let outstanding_debt = cache.unscale_borrow_ceil(cache.borrowed());
    let backing = cache.cash().saturating_add(outstanding_debt);
    supplied_claim.saturating_sub(backing).max(0)
}
