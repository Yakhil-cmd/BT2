### Title
Case-insensitive filename collision in `installSkill` allows attacker blob to silently overwrite `SKILL.md` after metadata injection - ([File: internal/skills/installer/installer.go])

### Summary
`installSkill` matches the metadata-injection target with an exact, case-sensitive string comparison (`filepath.Base(relPath) == "SKILL.md"`), while the actual file write goes through `safepaths.Absolute.Join`, which only guards against `..` traversal and performs no case-folding or Unicode normalization. On a case-insensitive filesystem (macOS/Windows), a git tree containing both `SKILL.md` and a differently-cased variant (e.g. `skill.md`) in the same skill directory produces two distinct `SkillFile` entries and two distinct `destPath` strings that resolve to the same on-disk inode, letting the second write silently replace the first.

### Finding Description
`DiscoverSkillFiles` (internal/skills/discovery/discovery.go:813-841) enumerates every blob under the skill's tree SHA and returns each with its literal `Path` as given by the GitHub tree API, without any deduplication or case normalization. `installSkill` (internal/skills/installer/installer.go:251-309) then iterates `files` in that order and for each entry:

1. Computes `relPath := strings.TrimPrefix(file.Path, skill.Path+"/")` (line 278).
2. Resolves `destPath` via `safeSkillDir.Join(relPath)` (line 280), which only rejects paths that escape the base directory (`internal/safepaths/absolute.go:38-57`) — it does not detect that two different `relPath` strings can map to the same filesystem entry on case-insensitive volumes.
3. Only injects GitHub provenance metadata when `filepath.Base(relPath) == "SKILL.md"` (exact case, line 296) via `frontmatter.InjectGitHubMetadata`.
4. Writes the (possibly un-injected) content with `os.WriteFile(destPath, ...)` (line 303).

If an attacker's tree contains both `skills/foo/SKILL.md` (legitimate-looking, metadata-injected) and `skills/foo/skill.md` (or `Skill.md`, or a Unicode-normalization variant that HFS+/APFS/NTFS treat as equal), both pass `safepaths` checks as distinct valid children of `skillDir`. Only the entry whose base name is exactly `SKILL.md` gets `InjectGitHubMetadata` applied; the other is written raw. On a case-insensitive filesystem, both `os.WriteFile` calls target the same file, so whichever entry is processed last (order depends on GitHub tree API ordering, which is not guaranteed to put `SKILL.md` last, so an attacker can also just choose which name they don't decorate) determines the final on-disk content — potentially leaving the attacker's raw, non-metadata-stamped payload as the file the agent actually loads as `SKILL.md`.

### Impact Explanation
This allows an attacker-controlled repository to bypass the intended provenance/metadata stamping (`InjectGitHubMetadata`) that is meant to mark installed skill files with their source repo/ref/SHA. The final content read as `SKILL.md` can be attacker content that never went through the injection safeguard, undermining the tool's provenance guarantee for skill files it installs onto the victim's machine. This is a file-write-outside-of-intended-content-guarantee issue (write of unexpected/unstamped content to the expected skill path), not a directory-traversal file write.

### Likelihood Explanation
Requires: (1) the victim's OS/filesystem to be case-insensitive (default on macOS/Windows, common), and (2) the attacker to publish a repo/ref with two blobs differing only in case (or Unicode normalization) within the same matched skill directory. Both preconditions are fully within an unprivileged attacker's control (they just author the repository tree) and require no victim interaction beyond running `gh skill install` against the attacker's repo/ref.

### Recommendation
When enumerating `DiscoverSkillFiles`, detect and reject (or dedupe with an explicit conflict error) entries whose `relPath` collide under `strings.EqualFold` (and ideally Unicode NFC normalization) before writing to disk, or perform the `SKILL.md` provenance check using the same case-insensitive comparison used for filesystem lookup, applying it consistently regardless of processing order. Alternatively, install files by rejecting a skill tree outright if it contains multiple blobs whose lowercased-normalized relative paths collide.

### Proof of Concept
Add a test using `httpmock` to stub two REST calls: `GET /repos/o/r/git/trees/{treeSHA}?recursive=true` returning a tree with entries `{"path":"SKILL.md","type":"blob","sha":"aaa"}` and `{"path":"skill.md","type":"blob","sha":"bbb"}`, plus `GET /repos/o/r/git/blobs/aaa` and `.../bbb` returning distinct base64 content (`aaa` = legit frontmatter, `bbb` = attacker payload with no frontmatter). Run `installSkill` against a target directory, then assert:
- Two `os.WriteFile` calls occur with different `destPath` strings (`.../SKILL.md` and `.../skill.md`).
- On a case-insensitive filesystem simulation (or literal test on macOS/Windows CI), reading back `skillDir/SKILL.md` shows the content of whichever entry was processed last, and if that is the `skill.md` entry, the file lacks the `InjectGitHubMetadata` stamp — demonstrating the safeguard bypass. func (a Absolute) Join(elem ...string) (Absolute, error) {
	joinedAbsolutePath, err := ParseAbsolute(filepath.Join(append([]string{a.path}, elem...)...))
	if err != nil {
		return Absolute{}, fmt.Errorf("failed to parse joined path: %w", err)
	}

	isSubpath, err := joinedAbsolutePath.isSubpathOf(a)
	if err != nil {
		return Absolute{}, err
	}

	if !isSubpath {
		return Absolute{}, PathTraversalError{
			Base:  a,
			Elems: elem,
		}
	}

	return joinedAbsolutePath, nil
}

func (a Absolute) isSubpathOf(dir Absolute) (bool, error) {
	relativePath, err := filepath.Rel(dir.path, a.path)
	if err != nil {
		return false, err
	}
	return !strings.HasPrefix(relativePath, ".."), nil
}

func DiscoverSkillFiles(client *api.Client, host, owner, repo, treeSHA, skillPath string) ([]SkillFile, error) {
	apiPath, err := safeurl.JoinPath("repos", owner, repo, "git", "trees", treeSHA)
	if err != nil {
		return nil, err
	}
	apiPath.SetQuery("recursive", "true")
	var tree treeResponse
	if err := client.REST(host, "GET", apiPath.String(), nil, &tree); err != nil {
		return nil, fmt.Errorf("could not fetch skill tree: %w", err)
	}

	if tree.Truncated {
		// Recursive fetch was truncated. Fall back to walking subtrees individually.
		return walkTree(client, host, owner, repo, treeSHA, skillPath, 0)
	}

	var files []SkillFile
	for _, entry := range tree.Tree {
		if entry.Type == "blob" {
			files = append(files, SkillFile{
				Path: skillPath + "/" + entry.Path,
				SHA:  entry.SHA,
				Size: entry.Size,
			})
		}
	}

	return files, nil
}
