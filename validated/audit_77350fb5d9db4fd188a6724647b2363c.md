The Gotenberg bug is an SSRF where a case-sensitive `^https?://` deny-list regex is bypassed by uppercase URL schemes because Go's `net/url.Parse()` normalizes scheme case before making the outbound connection. This requires an attacker-controlled webhook/download URL that the server itself dereferences over HTTP against a deny-list of private IP ranges.

Polkadot SDK has no equivalent architecture reachable from a real attacker entry point (signed extrinsic, XCM execute/send, contract call, or proof submission):

- URL-scheme validation in this codebase is either compile-time/CLI-config surface (e.g. `validate_relay_chain_url` in `cumulus/client/cli/src/lib.rs:263-275` restricting `--relay-chain-rpc-urls` to `ws`/`wss`, and `url_to_string_with_port` in `cumulus/client/relay-chain-rpc-interface/src/reconnecting_ws_client.rs:66-82`), which is operator/node-config input, not attacker input via extrinsics. [1](#0-0) [2](#0-1) 
- Or it's node-name validation for CLI (`is_node_name_valid` in `substrate/client/cli/src/commands/run_cmd.rs:360-384`), also not attacker-reachable via any dispatched call. [3](#0-2) 
- The offchain-worker HTTP API (`substrate/primitives/runtime/src/offchain/http.rs`, `substrate/client/offchain/src/api/http.rs`) allows outbound HTTP requests, but this code runs in the runtime's offchain-worker context, controlled by the node operator, not driven by untrusted extrinsic/XCM payloads with an SSRF deny-list to bypass. [4](#0-3) 

There is no FRAME pallet, XCM executor, or contracts/revive host function in this codebase that takes an attacker-supplied URL/webhook and dereferences it over the network against a deny-list of private IPs — the core mechanism the Gotenberg advisory exploits (server-side outbound HTTP fetch gated by a regex deny-list on unprivileged, attacker-controlled input) does not exist as an analog in the Polkadot SDK's runtime/dispatch surface.

fn url_to_string_with_port(url: Url) -> Option<String> {
	// This is already validated on CLI side, just defensive here
	if (url.scheme() != "ws" && url.scheme() != "wss") || url.host_str().is_none() {
		tracing::warn!(target: LOG_TARGET, ?url, "Non-WebSocket URL or missing host.");
		return None;
	}

	// Either we have a user-supplied port or use the default for 'ws' or 'wss' here
	Some(format!(
		"{}://{}:{}{}{}",
		url.scheme(),
		url.host_str()?,
		url.port_or_known_default()?,
		url.path(),
		url.query().map(|query| format!("?{}", query)).unwrap_or_default()
	))
}

pub fn is_node_name_valid(_name: &str) -> std::result::Result<(), &str> {
	let name = _name.to_string();

	if name.is_empty() {
		return Err("Node name cannot be empty");
	}

	if name.chars().count() >= crate::NODE_NAME_MAX_LENGTH {
		return Err("Node name too long");
	}

	let invalid_chars = r"[\\.@]";
	let re = Regex::new(invalid_chars).unwrap();
	if re.is_match(&name) {
		return Err("Node name should not contain invalid chars such as '.' and '@'");
	}

	let invalid_patterns = r"^https?:";
	let re = Regex::new(invalid_patterns).unwrap();
	if re.is_match(&name) {
		return Err("Node name should not contain urls");
	}

	Ok(())
}

	}
}
