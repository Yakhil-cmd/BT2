### Title
`collectStakingAmounts` Ignores Consensus-Liquidity Staking, Causing Incorrect Validator Demotion Between Prague and Permissionless Hardforks — (`File: kaiax/valset/impl/getter_demote.go`)

---

### Summary

`collectStakingAmounts` only reads `cn.StakingAmount` (CNStaking from AddressBook) and silently drops `cn.CLStakingInfo.CLStakingAmount` (consensus-liquidity staking introduced by Prague/KIP-226). After the Prague hardfork but before the Permissionless hardfork, the permissioned demotion path is still active and the `StakingInfo` it receives already contains populated `CLStakingInfos`. Because the function never adds the CL component, any validator whose CNStaking alone falls below `minStake` is incorrectly demoted even when its total stake (CNStaking + CLStaking) meets or exceeds the threshold.

---

### Finding Description

**Hardfork ordering** (from `params/config.go`):

```
Istanbul → Magma → Kore → Randao → Kaia → Prague → Osaka → Permissionless
``` [1](#0-0) 

**Permissioned path is active until Permissionless fork.** `GetDemotedValidators` dispatches to the permissioned path for every block before `IsPermissionlessForkEnabled`:

```go
func (v *ValsetModule) GetDemotedValidators(num uint64) ([]common.Address, error) {
    if v.Chain.Config().IsPermissionlessForkEnabled(new(big.Int).SetUint64(num)) {
        return v.getDemoted(num)
    }
    demoted, err := v.getDemotedPermissioned(num)
    ...
}
``` [2](#0-1) 

**Staking module already populates CLStakingInfos for permissioned Prague blocks.** In `getFromState`, when `isForPrague` is true, the CL registry is queried and the result is passed into `parseCallResult`, which stores it in `StakingInfo.CLStakingInfos`:

```go
var clRes clRegistryResult
if isForPrague {
    clRes, err = readCLInfo()
    ...
}
return parseCallResult(num, abRes.TypeList, abRes.AddressList, abRes.StakingAmounts, clRes, abRes.SpareAddress)
``` [3](#0-2) 

**`collectStakingAmounts` ignores the CL component entirely:**

```go
func collectStakingAmounts(nodes []common.Address, si *staking.StakingInfo) map[common.Address]float64 {
    cns := si.ConsolidatedNodes()
    stakingAmounts := make(map[common.Address]float64, len(nodes))
    for _, node := range nodes {
        stakingAmounts[node] = 0
    }
    for _, cn := range cns {
        for _, node := range cn.NodeIds {
            if _, ok := stakingAmounts[node]; ok {
                stakingAmounts[node] = float64(cn.StakingAmount) // ← CLStakingAmount never added
            }
        }
    }
    return stakingAmounts
}
``` [4](#0-3) 

This result is fed directly into the demotion check:

```go
stakingAmounts = collectStakingAmounts(council.List(), si)
for _, node := range council.List() {
    if uint64(stakingAmounts[node]) < minStake {
        demoted.Add(node)
    }
}
``` [5](#0-4) 

**Contrast with the reward module**, which correctly adds CLStaking after Prague:

```go
cnTotalStakingAmount := cn.StakingAmount
if isPrague && cn.CLStakingInfo != nil {
    cnTotalStakingAmount += cn.CLStakingInfo.CLStakingAmount
}
``` [6](#0-5) 

`collectStakingAmounts` has no equivalent Prague guard.

---

### Impact Explanation

A validator with `CNStaking = 4,000,000 KAIA` and `CLStaking = 2,000,000 KAIA` has a total of `6,000,000 KAIA`, which exceeds a `minStake` of `5,000,000 KAIA`. However, `collectStakingAmounts` returns `4,000,000` for that node, so `getDemotedValidatorsIstanbul` marks it as demoted. The demoted set is consumed by `getRoundCommitteeState` in the consensus core:

```go
demoted, err := c.valsetModule.GetDemotedValidators(seq)
qualified = valset.NewAddressSet(council).Subtract(valset.NewAddressSet(demoted))
``` [7](#0-6) 

Consequences:
- The validator is excluded from the committee and cannot propose blocks.
- The validator receives no proposer rewards for the affected blocks — a direct KAIA reward loss.
- The qualified validator set written into block headers is incorrect, which `VerifyHeader` enforces post-Permissionless fork, meaning honest nodes that compute the correct set would reject blocks produced with the wrong set. [8](#0-7) 

---

### Likelihood Explanation

The window is the period between the Prague hardfork activation and the Permissionless hardfork activation. On Kaia mainnet these are separate deployments. Any validator that participates in consensus liquidity (KIP-226) while keeping its CNStaking contract balance below `minStake` — a plausible operational choice — triggers the bug without any privileged action. The trigger is a normal on-chain state that any validator can reach.

---

### Recommendation

In `collectStakingAmounts`, add the CL staking amount when it is present, mirroring the pattern already used in `assignStakingRewards`:

```go
for _, cn := range cns {
    for _, node := range cn.NodeIds {
        if _, ok := stakingAmounts[node]; ok {
            total := float64(cn.StakingAmount)
            if cn.CLStakingInfo != nil {
                total += float64(cn.CLStakingInfo.CLStakingAmount)
            }
            stakingAmounts[node] = total
        }
    }
}
``` [4](#0-3) 

---

### Proof of Concept

1. Deploy a chain with Prague active and Permissionless not yet active (`WeightedRandom` policy, `minStake = 5,000,000 KAIA`).
2. Register validator `V` in AddressBook with `CNStaking = 4,000,000 KAIA` and in CLRegistry with `CLStaking = 2,000,000 KAIA` (total `6,000,000 KAIA > minStake`).
3. Call `GetDemotedValidators(N)` for any block `N` in the Prague-to-Permissionless window.
4. Observe that `V` appears in the demoted set despite its total stake exceeding `minStake`.
5. Confirm that `assignStakingRewards` (reward module) correctly treats `V` as eligible with `6,000,000 KAIA`, demonstrating the inconsistency between the two modules. [9](#0-8) [10](#0-9)

func getDemotedValidatorsIstanbul(council *valset.AddressSet, si *staking.StakingInfo, pset gov.ParamSet) *valset.AddressSet {
	var (
		demoted        = valset.NewAddressSet(nil)
		singleMode     = pset.GovernanceMode == "single"
		governingNode  = pset.GoverningNode
		minStake       = pset.MinimumStake.Uint64() // in KAIA
		stakingAmounts = collectStakingAmounts(council.List(), si)
	)

	// First filter by staking amounts.
	for _, node := range council.List() {
		if uint64(stakingAmounts[node]) < minStake {
			demoted.Add(node)
		}
	}

	// If all validators are demoted, then no one is demoted.
	if demoted.Len() == len(council.List()) {
		demoted = valset.NewAddressSet(nil)
	}

	// Under single governance mode, governing node cannot be demoted.
	if singleMode && demoted.Contains(governingNode) {
		demoted.Remove(governingNode)
	}
	return demoted
```
