### Title
Unauthenticated `ServiceChainParentChainInfoResponseMsg` Allows Any Bridge Peer to Corrupt Parent Operator Nonce, Halting Bridge Value Transfers — (File: `node/sc/sub_bridge_handler.go`)

---

### Summary

The sub-bridge P2P handler accepts `ServiceChainParentChainInfoResponseMsg` messages from **any** connected bridge peer without verifying that the sender is the legitimate parent-chain node. The handler unconditionally overwrites the parent operator's nonce and gas-price with attacker-supplied values. Setting the nonce to an arbitrarily large value causes every subsequent bridge transaction (value-transfer handles and anchoring) to be built with an invalid nonce, permanently halting bridge operations and locking bridged assets.

---

### Finding Description

`SubBridgeHandler.HandleMainMsg` dispatches incoming P2P messages by message code. When a `ServiceChainParentChainInfoResponseMsg` arrives it calls `handleParentChainInfoResponseMsg` with no prior check on the identity or role of the sending peer:

```
case ServiceChainParentChainInfoResponseMsg:
    if err := sbh.handleParentChainInfoResponseMsg(p, msg); err != nil { … }
``` [1](#0-0) 

Inside `handleParentChainInfoResponseMsg`, the function decodes a `parentChainInfo` struct (containing `Nonce`, `GasPrice`, `KIP71Config`, `IsMagmaEnabled`) directly from the peer message and writes the received nonce into the parent operator account:

```go
sbh.setParentOperatorNonce(pcInfo.Nonce)   // line 292 / 299 / 302
sbh.setParentOperatorNonceSynced(true)      // line 304
sbh.setRemoteChainValues(pcInfo)            // line 305
``` [2](#0-1) 

`setParentOperatorNonce` writes directly into `pAccount.nonce` and marks `isNonceSynced = true`: [3](#0-2) 

`setRemoteChainValues` overwrites the gas price and the entire KIP71 config used for every subsequent bridge transaction: [4](#0-3) 

The only authentication performed during the P2P handshake is a check that `NetworkId` and `ProtocolVersion` match — both values are self-reported by the connecting peer: [5](#0-4) 

There is no cryptographic proof that the peer is the actual parent-chain node, no role check, and no chain-ID verification at the message-handling layer (the chain-ID check in `RegisterNewPeer` is also self-reported and trivially spoofed): [6](#0-5) 

The corrupted nonce is then embedded into every anchoring and value-transfer transaction built by `genUnsignedChainDataAnchoringTx`: [7](#0-6) 

---

### Impact Explanation

Setting `pcInfo.Nonce = math.MaxUint64` causes every bridge transaction submitted to the parent chain to carry an astronomically high nonce. The parent chain rejects all such transactions as "nonce too high". Because `nonceSynced` is set to `true`, the child chain stops requesting a fresh nonce from the real parent chain and continues building invalid transactions indefinitely.

Concrete corrupted values:
- `pAccount.nonce` → attacker-supplied `uint64` (e.g. `2^64 - 1`)
- `pAccount.gasPrice` → attacker-supplied value (e.g. `0`, causing gas-price-below-base-fee rejection)
- `pAccount.kip71Config.UpperBoundBaseFee` → attacker-supplied value

Effect on bridged assets:
- All pending KAIA / ERC-20 / ERC-721 value-transfer handle transactions fail on the parent chain → assets remain locked in the bridge contract indefinitely.
- Anchoring transactions also fail → child-chain state is no longer anchored to the parent chain.

---

### Likelihood Explanation

The sub-bridge P2P port is reachable by any node that knows the enode URL (standard Kaia P2P discovery). The handshake requires only a matching `NetworkId` and `ProtocolVersion`, both of which are public constants. An attacker needs only to:

1. Connect to the sub-bridge port.
2. Complete the trivial handshake.
3. Send one crafted `ServiceChainParentChainInfoResponseMsg` RLP packet.

No privileged key, no validator seat, no majority collusion is required.

---

### Recommendation

1. **Authenticate the peer role**: After the handshake, record which peer was explicitly configured as the parent-chain peer (via `subbridge_addPeer`). In `HandleMainMsg`, reject `ServiceChainParentChainInfoResponseMsg` from any peer that is not the configured parent-chain peer.

2. **Validate the received nonce**: Before accepting `pcInfo.Nonce`, verify it against the on-chain nonce obtained through the authenticated RPC backend (`remoteBackend.PendingNonceAt`). Reject values that deviate beyond a small threshold.

3. **Separate response routing**: Only process `ServiceChainParentChainInfoResponseMsg` if the node itself previously sent a `ServiceChainParentChainInfoRequestMsg` to that specific peer (request-response correlation).

---

### Proof of Concept

```
# 1. Discover the sub-bridge enode URL (public P2P discovery or operator docs).
# 2. Connect with a custom Kaia P2P client, send StatusMsg with matching NetworkId/ProtocolVersion.
# 3. Send the following RLP-encoded message:

    Nonce:          0xFFFFFFFFFFFFFFFF,   // uint64 max

# 4. The child-chain sub-bridge handler calls handleParentChainInfoResponseMsg,

# 5. Every subsequent bridge tx (value-transfer, anchoring) is built with nonce 2^64-1.
# 6. Parent chain rejects all txs → bridge halts → bridged assets locked.

func (sbh *SubBridgeHandler) HandleMainMsg(p BridgePeer, msg p2p.Msg) error {
	// Handle the message depending on its contents
	switch msg.Code {
	case ServiceChainResponse:
		logger.Trace("received rpc ServiceChainResponse")
		data := make([]byte, msg.Size)
		err := msg.Decode(&data)
		if err != nil {
			logger.Error("failed to decode the p2p ServiceChainResponse message", "err", err)
			return nil
		}
		logger.Trace("send rpc response to the rpc client")
		_, err = sbh.subbridge.rpcConn.Write(data)
		if err != nil {
			return err
		}
		return nil
	case StatusMsg:
		return nil
	case ServiceChainParentChainInfoResponseMsg:
		logger.Debug("received ServiceChainParentChainInfoResponseMsg")
		if err := sbh.handleParentChainInfoResponseMsg(p, msg); err != nil {
			return err
		}

	case ServiceChainReceiptResponseMsg:
		logger.Debug("received ServiceChainReceiptResponseMsg")
		if err := sbh.handleParentChainReceiptResponseMsg(p, msg); err != nil {
			return err
		}
	case ServiceChainInvalidTxResponseMsg:
		logger.Debug("received ServiceChainInvalidTxResponseMsg")
		if err := sbh.handleParentChainInvalidTxResponseMsg(msg); err != nil {
			return err
		}
	default:
		return errResp(ErrInvalidMsgCode, "%v", msg.Code)
	}
	return nil

func (sbh *SubBridgeHandler) handleParentChainInfoResponseMsg(p BridgePeer, msg p2p.Msg) error {
	var pcInfo parentChainInfo
	if err := msg.Decode(&pcInfo); err != nil {
		logger.Error("failed to decode", "err", err)
		return errResp(ErrDecode, "msg %v: %v", msg, err)
	}
	sbh.LockParentOperator()
	defer sbh.UnLockParentOperator()

	poolNonce := sbh.subbridge.bridgeTxPool.GetMaxTxNonce(sbh.GetParentOperatorAddr())
	if poolNonce > 0 {
		poolNonce += 1
		// just check
		if sbh.getParentOperatorNonce() > poolNonce {
			logger.Error("parent chain operator nonce is bigger than the chain pool nonce.", "BridgeTxPoolNonce", poolNonce, "mainChainAccountNonce", sbh.getParentOperatorNonce())
		}
		if poolNonce < pcInfo.Nonce {
			// BridgeTxPool journal miss txs which already sent to parent-chain
			logger.Error("chain pool nonce is less than the parent chain nonce.", "chainPoolNonce", poolNonce, "receivedNonce", pcInfo.Nonce)
			sbh.setParentOperatorNonce(pcInfo.Nonce)
		} else {
			// BridgeTxPool journal has txs which don't receive receipt from parent-chain
			sbh.setParentOperatorNonce(poolNonce)
		}
	} else if sbh.getParentOperatorNonce() > pcInfo.Nonce {
		logger.Error("parent chain operator nonce is bigger than the received nonce.", "mainChainAccountNonce", sbh.getParentOperatorNonce(), "receivedNonce", pcInfo.Nonce)
		sbh.setParentOperatorNonce(pcInfo.Nonce)
	} else {
		// there is no tx in bridgetTxPool, so parent-chain's nonce is used
		sbh.setParentOperatorNonce(pcInfo.Nonce)
	}
	sbh.setParentOperatorNonceSynced(true)
	sbh.setRemoteChainValues(pcInfo)
	logger.Info("ParentChainNonceResponse", "receivedNonce", pcInfo.Nonce, "gasPrice", pcInfo.GasPrice, "mainChainAccountNonce", sbh.getParentOperatorNonce())
	return nil

func (p *baseBridgePeer) readStatus(network uint64, status *statusData) error {
	msg, err := p.rw.ReadMsg()
	if err != nil {
		return err
	}
	if msg.Code != StatusMsg {
		return errResp(ErrNoStatusMsg, "first msg has code %x (!= %x)", msg.Code, StatusMsg)
	}
	if msg.Size > ProtocolMaxMsgSize {
		return errResp(ErrMsgTooLarge, "%v > %v", msg.Size, ProtocolMaxMsgSize)
	}
	// Decode the handshake and make sure everything matches
	if err := msg.Decode(&status); err != nil {
		return errResp(ErrDecode, "msg %v: %v", msg, err)
	}
	if status.NetworkId != network {
		return errResp(ErrNetworkIdMismatch, "%d (!= %d)", status.NetworkId, network)
	}
	if int(status.ProtocolVersion) != p.version {
		return errResp(ErrProtocolVersionMismatch, "%d (!= %d)", status.ProtocolVersion, p.version)
	}
	return nil
}
