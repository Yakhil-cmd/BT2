### Title
Unauthenticated unit can crash a full node via an unguarded `throw` in header-size validation - (File: `validation.js`)

### Summary
`validation.js` computes and checks the unit's "headers commission" with `objectLength.getHeadersSize(objUnit)` **without a try/catch**, while the structurally identical sibling check for `payload_commission` right below it **is** wrapped in try/catch. `getHeadersSize()` (in `object_length.js`) calls `getLength()`, which synchronously `throw`s on conditions that the codebase's own unit-hash verification (done earlier, and safely wrapped in try/catch) does not reject the same way. Any uncaught synchronous exception that escapes `validate()` is turned into a full process crash by the global `process.on('uncaughtException', …)` handler in `network.js`, which explicitly re-throws to kill the node. This mirrors the CVE-2020-13950 pattern: two different parsers/validators disagree on the same crafted input, and the mismatch reaches an unguarded fault path that terminates the process — except here the "crash" is a deliberate `throw err` that kills the whole ocore full node (hub, witness, or wallet backend), not just one worker.

`getHeadersSize()` builds a `cloneDeep`d header object (dropping `messages`/`parent_units`) and feeds it to `getLength()`: [2](#0-1) 

`getLength()` throws on non-finite numbers, `undefined` values, and on any property reached via `for…in` that fails `Object.prototype.hasOwnProperty`: [3](#0-2) 

Earlier in `validate()`, the unit's integrity is checked via `objectHash.getUnitHash(objUnit)`, wrapped in try/catch: [4](#0-3) 

That hash path (`object_hash.js` → `getNakedUnit`/`getStrippedUnit`/`getUnitContentHash`) also uses `_.cloneDeep` (lodash) on the same `objUnit`, then serializes via `getJsonSourceString`/`getSourceString`, which enumerate properties with `Object.keys()` (own-enumerable only) rather than `for…in` + `hasOwnProperty`: [5](#0-4) [6](#0-5) [7](#0-6) 

Because `Object.keys()` never returns inherited properties while `for…in` does, the two functions can disagree about the same cloned object: content that becomes "invisible" to the hash-serializer (so unit-hash verification quietly succeeds/ignores it) can still be visible to `getLength()`'s `for…in` scan, which then throws `"object has non-own property … in …"`. The codebase is evidently aware that naively cloning an object containing a literal `"__proto__"` key can convert that own key into a real prototype-chain link during a plain `obj[key] = value` assignment (a well-known JS footgun), because it ships its own hardened `cloneDeep` in `string_utils.js` that special-cases `"__proto__"` with `Object.defineProperty` specifically to keep it as an own property: [8](#0-7) 
Yet `object_length.js` and `object_hash.js` still use the unguarded `require('lodash')` `_.cloneDeep` instead of this hardened helper: [9](#0-8) [10](#0-9) 

If a unit contains a JSON object with an own key literally named `"__proto__"` somewhere inside the header-relevant fields (e.g. inside `authors`, `witnesses`, `earned_headers_commission_recipients`, etc.), and lodash's `cloneDeep` assigns it via `out[key] = value` (turning it into a real prototype link rather than an own property), then:
- `getUnitHash()`'s `Object.keys()`-based serializer never sees that inherited property → the hash computation "succeeds" and can still match the attacker-precomputed `objUnit.unit` (the attacker computes their own hash using the same ignoring behavior) → the unit passes the try/catch-guarded hash check.
- `getHeadersSize()`'s `for…in` scan on the header-derived object *does* see the inherited (non-own) property → `getLength()` throws `"object has non-own property … in …"`.

This throw is not caught anywhere between `validate()` and the outer event/mutex handling in `network.js`'s `handleJoint()`, so it becomes an uncaught exception that reaches: [11](#0-10) 
which deliberately re-throws to crash the process ("crash the process to avoid ending up in an inconsistent state").

### Impact Explanation
A single crafted unit — postable by any peer via ordinary broadcast/`hub/deliver`-style validation, or via `handlePostedJoint`/`handleJoint` — can crash any full node (hub, witness, or any node validating incoming units) that receives and attempts to validate it, before the unit is even accepted or rejected cleanly. Because `validate()` is invoked from the standard unit-intake path reachable by an unprivileged unit poster, this is a network-wide denial of service: a properly-formed-looking unit (passing hash checks) can take down every node that tries to validate it, halting confirmation of new units on affected nodes (matches the "network unable to confirm new units" acceptance criterion).

### Likelihood Explanation
Exploitability hinges on a subtlety of lodash's `_.cloneDeep` implementation with a literal `"__proto__"` key, which was not independently verified against the exact lodash version pinned by this repository — this is a genuine gap in my analysis. However, the codebase's own defensive re-implementation of `cloneDeep` in `string_utils.js` (explicitly to keep `"__proto__"` as an own property) is strong circumstantial evidence that the maintainers know plain `_.cloneDeep` does not safely handle this case, and `object_length.js`/`object_hash.js` still use the unguarded lodash variant. Independent of the exact trigger, the structural bug is unambiguous and directly verifiable: `getHeadersSize()` at `validation.js:257` is the only unit-size computation performed with no surrounding try/catch, so any exception from `getLength()` (a function containing multiple `throw` statements) reachable at that point crashes the node.

### Recommendation
- Wrap the `getHeadersSize(objUnit)` call at `validation.js:257` in the same try/catch pattern used for `getTotalPayloadSize()` a few lines below, converting any thrown error into `callbacks.ifJointError(...)` instead of letting it propagate.
- Replace `_.cloneDeep` with the hardened `cloneDeep` from `string_utils.js` (or an equivalent that safely handles `"__proto__"`/prototype-chain keys) in `object_length.js` and `object_hash.js`.
- Make `getLength()`'s own-property check and `getJsonSourceString()`/`getSourceString()`'s enumeration semantics consistent (both should use `Object.keys()` or both should explicitly reject non-own properties before the point where the unit-hash check has already accepted the object), so the two validators cannot disagree on the same cloned unit.

### Proof of Concept
Conceptual PoC (subject to confirming lodash's exact `cloneDeep` behavior for the pinned version):
1. Craft a unit whose header-relevant portion (e.g. an object nested in `earned_headers_commission_recipients` or another header field that survives into both `getNakedUnit()` and `getHeadersSize()`'s `objHeader`) contains a JSON object with an own key literally `"__proto__"` mapping to an object value, e.g. `{"__proto__": {"x": 1}}`.
2. Compute `objUnit.unit` by running the attacker's own copy of `objectHash.getUnitHash()` over the crafted unit (this succeeds because `Object.keys()`-based serialization silently drops the inherited property introduced by lodash's clone, so it's consistent with what the victim node will also compute).
3. Submit the unit to a node via the normal joint/unit submission path (`handlePostedJoint`/`handleJoint` → `validation.validate`).
4. `validate()` passes the try/catch-guarded hash check at `validation.js:131-138` (hash matches, since both attacker and node ignore the inherited property the same way).
5. `validate()` reaches the unguarded `objectLength.getHeadersSize(objUnit)` call at `validation.js:257`; `_.cloneDeep` reproduces the same prototype-link artifact in `objHeader`, and `getLength()`'s `for…in` + `hasOwnProperty` check detects the inherited property and throws `Error("object has non-own property ...")`.
6. The exception is uncaught, propagates out of `validate()`/`handleJoint()`, and is caught by `process.on('uncaughtException', …)` in `network.js`, which re-throws and crashes the node process.

function getLength(value, bWithKeys) {
	let cache = new WeakMap();  // object to length
	function _getLength(value) {
		if (value === null)
			return 0;
		switch (typeof value) {
			case "string":
				return value.length;
			case "number":
				if (!isFinite(value))
					throw Error("invalid number: " + value);
				return 8;
				//return value.toString().length;
			case "object":
				// return cached result if already processed
				if (cache.has(value))
					return cache.get(value);
				var len = 0;
				if (Array.isArray(value))
					value.forEach(function (element) {
						len += _getLength(element);
					});
				else
					for (var key in value) {
						if (!Object.prototype.hasOwnProperty.call(value, key))
							throw Error("object has non-own property " + key + " in " + JSON.stringify(value));
						if (typeof value[key] === "undefined")
							throw Error("undefined at " + key + " of " + JSON.stringify(value));
						if (bWithKeys)
							len += key.length;
						len += _getLength(value[key]);
					}
				cache.set(value, len);  // memoize for future references
				return len;
			case "boolean":
				return 1;
			default:
				throw Error("unknown type=" + (typeof value) + " of " + value);
		}
	}
	return _getLength(value);
}

function getSourceString(obj) {
	var arrComponents = [];
	function extractComponents(variable){
		if (variable === null)
			throw Error("null value in "+JSON.stringify(obj));
		switch (typeof variable){
			case "string":
				if (variable.includes(STRING_JOIN_CHAR))
					throw Error("00 byte in string value in " + JSON.stringify(obj));
				arrComponents.push("s", variable);
				break;
			case "number":
				if (!isFinite(variable))
					throw Error("invalid number: " + variable);
				arrComponents.push("n", variable.toString());
				break;
			case "boolean":
				arrComponents.push("b", variable.toString());
				break;
			case "object":
				if (Array.isArray(variable)){
					if (variable.length === 0)
						throw Error("empty array in "+JSON.stringify(obj));
					arrComponents.push('[');
					for (var i=0; i<variable.length; i++)
						extractComponents(variable[i]);
					arrComponents.push(']');
				}
				else{
					var keys = Object.keys(variable).sort();
					if (keys.length === 0)
						throw Error("empty object in "+JSON.stringify(obj));
					keys.forEach(function(key){
						if (typeof variable[key] === "undefined")
							throw Error("undefined at "+key+" of "+JSON.stringify(obj));
						if (key.includes(STRING_JOIN_CHAR))
							throw Error("00 byte in object key in " + JSON.stringify(obj));
						arrComponents.push(key);
						extractComponents(variable[key]);
					});
				}
				break;
			default:
				throw Error("getSourceString: unknown type="+(typeof variable)+" of "+variable+", object: "+JSON.stringify(obj));
		}
	}

	extractComponents(obj);
	return arrComponents.join(STRING_JOIN_CHAR);
}

function getJsonSourceString(obj, bAllowEmpty) {
	let cache = new WeakMap();  // object to stringified result
	function stringify(variable){
		if (variable === null)
			throw Error("null value in "+JSON.stringify(obj));
		switch (typeof variable){
			case "string":
				return toWellFormedJsonStringify(variable);
			case "number":
				if (!isFinite(variable))
					throw Error("invalid number: " + variable);
			case "boolean":
				return variable.toString();
			case "object":
				// return cached result if already processed
				if (cache.has(variable))
					return cache.get(variable);
				let result;
				if (Array.isArray(variable)){
					if (variable.length === 0 && !bAllowEmpty)
						throw Error("empty array in "+JSON.stringify(obj));
					result = '[' + variable.map(stringify).join(',') + ']';
				}
				else{
					var keys = Object.keys(variable).sort();
					if (keys.length === 0 && !bAllowEmpty)
						throw Error("empty object in "+JSON.stringify(obj));
					result = '{' + keys.map(function(key){ return toWellFormedJsonStringify(key)+':'+stringify(variable[key]) }).join(',') + '}';
				}
				cache.set(variable, result);  // memoize for future references
				return result;
			default:
				throw Error("getJsonSourceString: unknown type="+(typeof variable)+" of "+variable+", object: "+JSON.stringify(obj));
		}
	}

	return stringify(obj);
}

function cloneDeep(val) {
	var k, out, tmp;

	if (Array.isArray(val)) {
		out = Array(k=val.length);
		while (k--) out[k] = (tmp=val[k]) && typeof tmp === 'object' ? cloneDeep(tmp) : tmp;
		return out;
	}

//	if (Object.prototype.toString.call(val) === '[object Object]') {
	if (typeof val === 'object' && val !== null) {
		out = {}; // null
		for (k in val) {
		//	if (!Object.hasOwn(val, k)) continue;
			if (k === '__proto__') {
				Object.defineProperty(out, k, {
					value: cloneDeep(val[k]),
					configurable: true,
					enumerable: true,
					writable: true,
				});
			} else {
				out[k] = (tmp=val[k]) && typeof tmp === 'object' ? cloneDeep(tmp) : tmp;
			}
		}
		return out;
	}

	return val === 0 ? 0 : val; // replace -0
}
