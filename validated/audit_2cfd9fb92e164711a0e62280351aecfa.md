**Analysis:**

The referenced file `types/src/validator_performances.rs` does not exist in this repository — no file by that name was found via search.

The actual mechanism in question is `record_fee` in `aptos-move/framework/aptos-framework/sources/stake.move`, which is declared `public(friend)` and immediately calls `system_addresses::assert_vm(vm)`, restricting invocation to the VM signer only [1](#0-0) . There is no entry function, script, or any unprivileged transaction/authenticator/API path that can invoke `record_fee` — it is only ever called internally by the VM during gas-payer epilogue processing, and the `fee_distribution_validator_indices` it receives come from VM-internal validator-set bookkeeping, not from unprivileged user input.

Additionally, `pending_fee_by_validator` is a `BigOrderedMap` and `borrow_mut` aborts if the key (validator index) is not already present, which is exactly what the existing test `test_transaction_fee_non_validator` demonstrates via `#[expected_failure(abort_code = 0x10002, location = 0x1::big_ordered_map)]` [2](#0-1) . This confirms the framework already has a built-in bound check: out-of-set indices abort rather than silently corrupting another validator's slot.

Separately, the actual "gas payer" binding for fee charging (distinct from `record_fee`'s validator reward indices) is resolved in `transaction_validation.move`'s epilogue functions using `signer::address_of(&gas_payer)`, which is derived from the VM-validated fee-payer signer set at prologue time, not from attacker-supplied indices [3](#0-2) .

Since `record_fee` cannot be reached by any unprivileged transaction, authenticator, API, or proof input — it requires the VM's own privileged signer — this does not meet the admission-boundary criteria required by the decision standard.

    public(friend) fun record_fee(
        vm: &signer,
        fee_distribution_validator_indices: vector<u64>,
        fee_amounts_octa: vector<u64>
    ) acquires PendingTransactionFee {
        // Operational constraint: can only be invoked by the VM.
        system_addresses::assert_vm(vm);

        assert!(
            fee_distribution_validator_indices.length() == fee_amounts_octa.length()
        );

        let num_validators_to_distribute = fee_distribution_validator_indices.length();
        let pending_fee = borrow_global_mut<PendingTransactionFee>(@aptos_framework);
        let i = 0;
        while (i < num_validators_to_distribute) {
            let validator_index = fee_distribution_validator_indices[i];
            let fee_octa = fee_amounts_octa[i];
            pending_fee.pending_fee_by_validator.borrow_mut(&validator_index).add(
                fee_octa
            );
            i += 1;
        }
    }
