## Title
Copilot API bearer token sent to attacker-controlled host over plaintext HTTP when server-supplied `capiBaseURL` uses `http://` scheme - ([File: pkg/cmd/agent-task/capi/client.go])

## Summary
`resolveCapiURL` returns the `viewer.copilotEndpoints.api` string verbatim from a GraphQL response, and `NewCAPIClient`/`newCAPITransport` build the CAPI request scheme/host directly from that string with no scheme (HTTPS) enforcement. If the configured host (a compromised or malicious GHES instance the victim points `gh` at) returns an `http://` URL, all CAPI requests — including the `Authorization: Bearer <token>` header — are sent in plaintext to that host.

## Finding Description
`resolveCapiURL` in [1](#0-0)  queries `CopilotEndpoints` and returns `resp.Viewer.CopilotEndpoints.Api` with no validation beyond non-empty. This value flows unmodified into `capi.NewCAPIClient(httpClient, token, host, capiBaseURL)` at [2](#0-1) .

`NewCAPIClient` stores `capiBaseURL` as-is and wraps the transport: [3](#0-2) . `newCAPITransport` only extracts `u.Host` via `url.Parse`, discarding/ignoring the scheme entirely: [4](#0-3) . The `RoundTrip` method unconditionally sets the `Authorization: Bearer <token>` header on every request regardless of scheme, before checking `req.URL.Host == ct.capiHost` only to decide whether to add the `Copilot-Integration-Id` header: [5](#0-4) .

The actual outbound request URLs are built by `safeurl.JoinPathWithHostPrefix(c.capiBaseURL, ...)`, e.g. in `CreateJob`, `GetJob`, `ListLatestSessionsForViewer`, `GetSession`, `GetSessionLogs`, `ListSessionsByResourceID` ( [6](#0-5)  and [7](#0-6) ). `joinPathWithHostPrefix` in the `safeurl` package explicitly states the host prefix "is used verbatim" and only percent-encodes path components — it does not validate or enforce the scheme: [8](#0-7) . So if `capiBaseURL` is `http://attacker.example`, every request (including the Authorization header) is sent to `http://attacker.example/...` in cleartext.

No component in this chain — `resolveCapiURL`, `NewCAPIClient`, `newCAPITransport`, or `safeurl.JoinPathWithHostPrefix` — rejects or upgrades a non-HTTPS scheme.

## Impact Explanation
If a GHES/enterprise host the victim has configured `gh` against (or a MITM/compromised endpoint on that host, per the given threat model of "controls responses from a host the victim points gh at") returns an `http://` Copilot API URL from the `CopilotEndpoints` GraphQL query, the victim's active GitHub/Copilot API bearer token is transmitted over plaintext HTTP for every subsequent Copilot agent-task API call (`gh agent-task` create/list/status/logs). This is a token/credential disclosure over an unencrypted channel — matching a credential exfiltration impact class — to any network position capable of observing traffic to that host (e.g., an on-path network observer, which is a lesser but still real capability difference from full MITM of the whole session).

## Likelihood Explanation
Requires the victim's `gh` to be configured against a host (GHES or otherwise) whose GraphQL `copilotEndpoints.api` response returns an `http://` URL — i.e., the host itself is attacker-controlled or compromised. This is a narrower precondition than a typical unprivileged remote-content attack (it needs control over the enterprise/GHES server's GraphQL response, not just a published repo/PR/gist), but is explicitly within scope per the task's stated precondition ("misconfigured GHES instance under attacker control" / "host the victim points gh at"). Given that precondition, exploitation is fully deterministic and repeatable — no additional user interaction beyond running normal `gh agent-task` commands is needed.

## Recommendation
Validate `capiBaseURL` in `resolveCapiURL` (or in `NewCAPIClient`/`newCAPITransport`) to require `https` scheme, rejecting or erroring on any other scheme before it is used to construct requests. Additionally, harden `newCAPITransport`/`RoundTrip` to refuse to send the `Authorization` header unless `req.URL.Scheme == "https"`, as defense in depth independent of how `capiBaseURL` was obtained.

## Proof of Concept
```go
func TestNewCAPITransport_RejectsNonHTTPSCapiBaseURL(t *testing.T) {
    var capturedAuth string
    srv := httptest.NewServer(http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
        capturedAuth = r.Header.Get("Authorization")
        w.WriteHeader(http.StatusOK)
    }))
    defer srv.Close()

    // srv.URL is http://127.0.0.1:PORT — simulating an attacker-controlled
    // GHES response returning a non-HTTPS Copilot API URL.
    httpClient := &http.Client{}
    client := capi.NewCAPIClient(httpClient, "secret-token", "github.example.com", srv.URL)

    _, _ = client.GetSessionLogs(context.Background(), "00000000-0000-0000-0000-000000000000")

    if strings.HasPrefix(srv.URL, "http://") && capturedAuth == "Bearer secret-token" {
        t.Fatalf("token was sent in cleartext to non-HTTPS capiBaseURL host: %q", capturedAuth)
    }
}
```
Expected (fixed) behavior: `NewCAPIClient`/`resolveCapiURL` should reject the `http://` URL up front (returning an error) so this request is never made; current behavior sends the bearer token in plaintext, which the test above demonstrates by capturing the `Authorization` header at the plaintext HTTP server.

// resolveCapiURL queries the GitHub API for the Copilot API endpoint URL.
func resolveCapiURL(httpClient *http.Client, host string) (string, error) {
	apiClient := api.NewClientFromHTTP(httpClient)

	var resp struct {
		Viewer struct {
			CopilotEndpoints struct {
				Api string `graphql:"api"`
			} `graphql:"copilotEndpoints"`
		} `graphql:"viewer"`
	}

	if err := apiClient.Query(host, "CopilotEndpoints", &resp, nil); err != nil {
		return "", err
	}

	if resp.Viewer.CopilotEndpoints.Api == "" {
		return "", errors.New("empty Copilot API URL returned")
	}

	return resp.Viewer.CopilotEndpoints.Api, nil
}

func newCAPITransport(token string, capiBaseURL string, rp http.RoundTripper) *capiTransport {
	capiHost := ""
	if u, err := url.Parse(capiBaseURL); err == nil {
		capiHost = u.Host
	}

		rp:       rp,
		token:    token,

	}

func (ct *capiTransport) RoundTrip(req *http.Request) (*http.Response, error) {
	req.Header.Set("Authorization", "Bearer "+ct.token)

	// Since this RoundTrip is reused for both Copilot API and
	// GitHub API requests, we conditionally add the integration
	// ID only when performing requests to the Copilot API.
	if req.URL.Host == ct.capiHost {
		req.Header.Add("Copilot-Integration-Id", "copilot-4-cli")

		// Ensure we are not using GitHub API versions while targeting CAPI.
		req.Header.Set("X-GitHub-Api-Version", "2026-01-09")
	}
	return ct.rp.RoundTrip(req)
}

// joinPathWithHostPrefix builds a full REST API URL by prepending hostPrefix to the path produced by
// JoinPath. A single slash is ensured at the join between hostPrefix and the path so they separate
// cleanly without doubling up. When hostPrefix is empty, the JoinPath result is returned intact, and
// when the joined path is empty, hostPrefix is returned intact. hostPrefix is used verbatim while each
// component is percent-encoded.
func joinPathWithHostPrefix(hostPrefix string, components ...string) string {
	path := joinPath(components...)
	if hostPrefix == "" {
		return path
	}
	if path == "" {
		return hostPrefix
	}
	if !strings.HasSuffix(hostPrefix, "/") {
		return hostPrefix + "/" + path
	}
	return hostPrefix + path
}
