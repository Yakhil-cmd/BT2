### Title
Extension name derived from `path.Base(cloneURL)` is joined into `installDir()` without confinement, allowing single-level directory traversal - (File: pkg/cmd/extension/manager.go)

### Finding Description
In `Manager.installGit`, the on-disk extension directory name is derived purely from the clone URL rather than validated: `name := strings.TrimSuffix(path.Base(cloneURL), ".git")` followed by `targetDir := filepath.Join(m.installDir(), name)`. [1](#0-0) 

`cloneURL` is built from the parsed `ghrepo.Interface` via `ghrepo.FormatRemoteURL(repo, protocol)`, which just concatenates `owner + "/" + name + ".git"` with no charset validation of `name`. [2](#0-1) 

The repo object itself comes from `ghrepo.FromFullName` → `repository.ParseWithHost`, which (per the test cases in this repo) only validates the *number* of `/`-separated segments (2 or 3), not the character content of the owner/name segments. [3](#0-2) 

If the resolved repository name is exactly `..`, `path.Base(cloneURL)` returns `...git` (the literal string `..` + `.git`), and `strings.TrimSuffix(..., ".git")` strips it back down to `..`. `filepath.Join(m.installDir(), "..")` then resolves to the parent of the extensions directory (i.e., `dataDir()` itself), escaping the intended confinement. There is no `filepath.Rel`/prefix check anywhere in `installGit`, `installBin`, or `Remove` to prevent this — the same unguarded `filepath.Join(m.installDir(), name)` pattern is repeated in `installBin` (line 346) and `Remove` (line 580). [4](#0-3) [5](#0-4) 

### Impact Explanation
If reachable, `m.gitClient.Clone(cloneURL, []string{targetDir})` would attempt to clone attacker content directly into `dataDir()` (the parent of the extensions directory), and `Remove`/`cleanExtensionUpdateDir` would perform `os.RemoveAll` on that same escaped path. This matches the "file write/overwrite outside intended path" impact class. However, actual exploitability is constrained by external factors not present in this codebase: (1) real GitHub repository names cannot be `.` or `..` (server-side GitHub naming rules), so this is only reachable against a host the attacker fully controls (a custom `GH_HOST`/GHE instance) that the victim is pointed at, or possibly against `gh extension install <full-URL>` if hasScript/isBinExtension checks against that attacker-controlled host succeed; and (2) `git clone` refuses to clone into a non-empty target directory, which limits real overwrite capability since `dataDir()` is normally non-empty.

### Likelihood Explanation
Low-to-moderate. It requires the victim to run `gh extension install` against a full URL or host under attacker control (not plain github.com, since GitHub itself would reject a repo literally named `..`), which is a narrower precondition than a purely github.com-hosted attack. The traversal is also limited to exactly one directory level (`..`), not arbitrary depth, since `path.Base`/`TrimSuffix` only ever yields a single path component.

### Recommendation
Do not derive the install directory name from `path.Base(cloneURL)`; use `repo.RepoName()` directly (which is already available in `installGit`), and add an explicit confinement check before any filesystem operation: reject names that are empty, `.`, `..`, contain path separators, or where `filepath.Clean(filepath.Join(installDir, name))` does not have `installDir` as a strict prefix (via `filepath.Rel` with no leading `..`). Apply the same check uniformly in `installGit`, `installBin`, `InstallLocal`, and `Remove`.

```go
func (m *Manager) installGit(repo ghrepo.Interface, target string) error {
	protocol := m.config.GitProtocol(repo.RepoHost()).Value
	cloneURL := ghrepo.FormatRemoteURL(repo, protocol)

	var commitSHA string
	if target != "" {
		var err error
		commitSHA, err = fetchCommitSHA(m.client, repo, target)
		if err != nil {
			return err
		}
	}

	name := strings.TrimSuffix(path.Base(cloneURL), ".git")
	targetDir := filepath.Join(m.installDir(), name)

	if err := m.cleanExtensionUpdateDir(name); err != nil {
		return err
	}

	_, err := m.gitClient.Clone(cloneURL, []string{targetDir})
```

```go
func (m *Manager) Remove(name string) error {
	name = normalizeExtension(name)
	targetDir := filepath.Join(m.installDir(), name)
	if _, err := os.Lstat(targetDir); os.IsNotExist(err) {
		return fmt.Errorf("no extension found: %q", targetDir)
	}
	if m.dryRunMode {
		return nil
	}
	if err := m.cleanExtensionUpdateDir(name); err != nil {
		return err
	}
	return os.RemoveAll(targetDir)
}
```

```go
func FormatRemoteURL(repo Interface, protocol string) string {
	if protocol == "ssh" {
		if tenant, found := ghinstance.TenantName(repo.RepoHost()); found {
			return fmt.Sprintf("%s@%s:%s/%s.git", tenant, repo.RepoHost(), repo.RepoOwner(), repo.RepoName())
		}
		return fmt.Sprintf("git@%s:%s/%s.git", repo.RepoHost(), repo.RepoOwner(), repo.RepoName())
	}
	return fmt.Sprintf("%s%s/%s.git", ghinstance.HostPrefix(repo.RepoHost()), repo.RepoOwner(), repo.RepoName())
```
