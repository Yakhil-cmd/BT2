### Title
Gasless SwapTx Deadline Not Re-Validated at Block-Building Time Allows Proposer KAIA Loss via Expired Bundle Execution — (`kaiax/gasless/impl/builder.go`, `kaiax/gasless/impl/tx_pool.go`)

---

### Summary

The Kaia gasless module (`kaiax/gasless`, KIP-247) enforces the `deadline` field of a `GaslessSwapTx` only at **txpool admission time**, comparing it against the last finalized block's timestamp. The check is never repeated at **block-building time** inside `ExtractTxBundles`. A user can submit a SwapTx whose deadline is at or just above `CurrentBlock().Time()`, pass the txpool gate, and still be bundled into the next block after the deadline has expired. Because the proposer's `LendTx` (a plain KAIA transfer to the user) executes unconditionally before the SwapTx, and the SwapTx reverts on-chain when the `GaslessSwapRouter` contract enforces the expired deadline, the proposer loses the lent KAIA while the user retains it without repaying.

---

### Finding Description

**Txpool-only deadline gate (`tx_pool.go`)**

`checkBalanceForSwap` is the sole location where the deadline is validated:

```go
// tx.deadline >= currentTimestamp
deadline := swapArgs.Deadline
if deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
    return fmt.Errorf("insufficient deadline: deadline=%s, want=%s", ...)
}
``` [1](#0-0) 

This check uses `g.Chain.CurrentBlock().Time()` — the timestamp of the **already-finalized** block, not the block being built. Kaia produces blocks roughly every second, so the next block's timestamp will be `CurrentBlock().Time() + Δ`. A SwapTx with `deadline == CurrentBlock().Time()` satisfies `deadline >= CurrentBlock().Time()` (passes the `< 0` guard) but is already expired relative to the next block.

**No re-check at block-building time (`builder.go`)**

`ExtractTxBundles` calls `IsExecutable` → `VerifyExecutable` to validate the bundle. `VerifyExecutable` checks sender match, token match, nonce ordering, and repay amount — but **never the deadline**: [2](#0-1) [3](#0-2) 

The deadline field decoded from the SwapTx is stored in `SwapArgs.Deadline` but is never consulted during bundle construction.

**Bundle execution order**

The bundle is always ordered `[LendTx, (ApproveTx), SwapTx]`: [4](#0-3) 

`LendTx` is a plain KAIA transfer from the proposer to the user: [5](#0-4) 

It executes unconditionally. If SwapTx subsequently reverts (because `GaslessSwapRouter.swapForGas` enforces the deadline on-chain — the function signature explicitly carries `deadline`), the proposer's KAIA is already gone: [6](#0-5) 

**`BalanceCheckLevel` does not gate the deadline check**

The deadline check in `checkBalanceForSwap` is unconditional — it is not wrapped by `ShouldCheckToken()`, `ShouldCheckSwapAmount()`, or `ShouldCheckSenderCode()`. Lowering `BalanceCheckLevel` does not remove it. The gap is purely temporal (txpool vs. block-building), not configurational: [7](#0-6) 

---

### Impact Explanation

The proposer (validator) loses the lent KAIA amount (`LendAmount = ApproveTx.Fee() + SwapTx.Fee()`) with no recovery path. The user retains the lent KAIA without repaying. This is an unauthorized KAIA transfer from a system-managed fund (the proposer's balance, which the protocol relies on to front gas for gasless users). The `lendAmount` function shows the exact value at risk: [8](#0-7) 

---

### Likelihood Explanation

A user can deliberately craft a SwapTx with `deadline = CurrentBlock().Time()` (or `CurrentBlock().Time() + 1`). This passes the txpool gate (`deadline >= CurrentBlock().Time()` is satisfied) but is expired by the time the next block is sealed. The proposer's standard code path (`ExtractTxBundles`) has no guard against this, so the expired bundle is included without any warning. No privileged access is required — any user who can submit a valid-looking SwapTx can trigger this.

---

### Recommendation

1. **Re-validate the deadline at block-building time** inside `ExtractTxBundles` (or `VerifyExecutable`) using the **pending block's timestamp** (i.e., `parentHeader.Time + blockInterval`), not `CurrentBlock().Time()`.
2. **Tighten the txpool gate** to use strict inequality (`deadline > CurrentBlock().Time()`) so a deadline equal to the current block timestamp is rejected immediately.
3. Consider adding a deadline re-check in `IsReady` as well, so stale SwapTxs are evicted from the pending pool before they can be bundled.

---

### Proof of Concept

1. Observe `CurrentBlock().Time()` = `T`.
2. Submit `SwapTx` with `deadline = T`. Txpool check: `T.Cmp(T) == 0`, which is not `< 0` → **accepted**.
3. Next block is built at timestamp `T+1`. `ExtractTxBundles` calls `IsExecutable` → `VerifyExecutable` → **no deadline check** → bundle is formed.
4. Block is committed: `LendTx` transfers KAIA to user (succeeds). `SwapTx` calls `GaslessSwapRouter.swapForGas(..., deadline=T)` with `block.timestamp = T+1 > T` → contract reverts.
5. User retains lent KAIA. Proposer's balance is reduced by `lendAmount` with no repayment.

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles

func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil

func lendAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	r := new(big.Int)

	// R2 = ApproveTx.Fee() if exists
	if approveTxOrNil != nil {
		r.Add(r, approveTxOrNil.Fee())
	}

	// R3 = SwapTx.Fee()
	r.Add(r, swapTx.Fee())

	// LendAmount = R2 + R3
	return r
```
