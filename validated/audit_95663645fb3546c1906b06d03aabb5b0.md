### Title
Unbounded recursion in `getSourceString` reachable before depth checks during unit hash validation - (File: string_utils.js, object_hash.js, validation.js)

### Summary
`validation.js`'s `validate()` function computes `objectHash.getUnitHash(objUnit)` at line 133 to verify the unit hash **before** it calls `isTooDeeplyNestedOrHasTooManyNodes(objUnit)` at line 154, which is the only depth/size guard for incoming units.

### Finding Description
`getUnitHash()` (`object_hash.js:60-65`) calls `getStrippedUnit`/`getUnitContentHash`/`getNakedUnit`, which end up calling `getBase64Hash` → `getSourceString` (or `getJsonSourceString`) on the raw, attacker-supplied unit object. `getSourceString` (`string_utils.js:11-60`) walks the object tree via the inner `extractComponents` function with **no depth limit and no node-count limit** — recursion continues for every nested array/object level. This hashing step runs at `validation.js:131-138`, which is *before* `isTooDeeplyNestedOrHasTooManyNodes(objUnit)` is invoked at `validation.js:154`. An unprivileged peer posting a unit (or `network.js`'s `case 'joint'` handler forwarding it to `handleOnlineJoint`/`validate`) can therefore submit a small but deeply nested unit payload (e.g., deeply nested `messages[].payload` object/array structure) whose hash computation alone exhausts the call stack / triggers excessive recursion and memory allocation of `arrComponents`, before the existing depth guard has any chance to reject it. ### Impact Explanation
This mirrors the CVE's bug class: recursion over untrusted nested data with no bound, performed in a code path that executes prior to any size/depth validation. Because `getUnitHash` is invoked unconditionally on every incoming joint (unit poster, AA trigger units, etc. all pass through `validate()`), a deeply nested but small unit can cause a `RangeError: Maximum call stack size exceeded` or excessive memory consumption in `arrComponents`, potentially crashing or hanging the node process handling unit validation — a node inability to validate/confirm units (denial of service against validation), which matches the "network unable to confirm new units" acceptance criterion.

### Likelihood Explanation
Likelihood is limited: `getSourceString` throws on `null`, empty objects/arrays and non-serializable values, so constructing a valid deeply-nested unit that still parses as JSON and passes JS type checks up to the hashing step requires care (e.g., nested arrays each containing one non-empty element, or nested single-key objects) but is straightforward to construct. The attack requires only sending an unsigned/unverified joint over the wire, reachable by any peer, no special privilege needed.

### Recommendation
Reorder the checks in `validate()` so that `isTooDeeplyNestedOrHasTooManyNodes(objUnit)` (and `isObjectWellFormed`) run **before** `objectHash.getUnitHash(objUnit)` is computed, ensuring depth/size limits are enforced prior to any recursive hashing/serialization of untrusted unit data. Additionally, add an explicit depth (and/or node count) limit inside `getSourceString`/`extractComponents` (and `getJsonSourceString`) itself, mirroring the `MAX_DEPTH` pattern already used in `aa_validation.js` and `formula/validation.js`, so that any other caller of `getSourceString` on untrusted data is protected regardless of call order.

### Proof of Concept
1. Construct a joint whose `unit.messages[0].payload` (or another untrusted field reachable before the depth check, e.g. nested `parent_units`/`authors` structure serialized through `getNakedUnit`) contains extremely deep nesting, for example an array nested `N` times deep (`N` in the tens of thousands), each level containing exactly one element to avoid the "empty array" throw in `getSourceString`.
2. Send this joint via the `'joint'` case in `network.js` `handleJustsaying`, which forwards it to `handleOnlineJoint` → `validation.validate(objJoint, ...)`.
3. `validate()` calls `objectHash.getUnitHash(objUnit)` at `validation.js:133`, which recurses through `getSourceString`'s `extractComponents` for every nesting level before `isTooDeeplyNestedOrHasTooManyNodes` is ever reached, causing a stack overflow or excessive CPU/memory use in the node process handling the joint.

function getSourceString(obj) {
	var arrComponents = [];
	function extractComponents(variable){
		if (variable === null)
			throw Error("null value in "+JSON.stringify(obj));
		switch (typeof variable){
			case "string":
				if (variable.includes(STRING_JOIN_CHAR))
					throw Error("00 byte in string value in " + JSON.stringify(obj));
				arrComponents.push("s", variable);
				break;
			case "number":
				if (!isFinite(variable))
					throw Error("invalid number: " + variable);
				arrComponents.push("n", variable.toString());
				break;
			case "boolean":
				arrComponents.push("b", variable.toString());
				break;
			case "object":
				if (Array.isArray(variable)){
					if (variable.length === 0)
						throw Error("empty array in "+JSON.stringify(obj));
					arrComponents.push('[');
					for (var i=0; i<variable.length; i++)
						extractComponents(variable[i]);
					arrComponents.push(']');
				}
				else{
					var keys = Object.keys(variable).sort();
					if (keys.length === 0)
						throw Error("empty object in "+JSON.stringify(obj));
					keys.forEach(function(key){
						if (typeof variable[key] === "undefined")
							throw Error("undefined at "+key+" of "+JSON.stringify(obj));
						if (key.includes(STRING_JOIN_CHAR))
							throw Error("00 byte in object key in " + JSON.stringify(obj));
						arrComponents.push(key);
						extractComponents(variable[key]);
					});
				}
				break;
			default:
				throw Error("getSourceString: unknown type="+(typeof variable)+" of "+variable+", object: "+JSON.stringify(obj));
		}
	}

	extractComponents(obj);
	return arrComponents.join(STRING_JOIN_CHAR);
}
