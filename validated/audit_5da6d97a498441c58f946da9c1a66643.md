### Title
Missing scheme/host validation on Copilot API URL allows Authorization token disclosure over plaintext HTTP - ([File: pkg/cmd/agent-task/capi/client.go])

### Summary
`resolveCapiURL` in `pkg/cmd/agent-task/shared/capi.go` takes the `Api` string from the `CopilotEndpoints` GraphQL response verbatim and passes it as `capiBaseURL` into `capi.NewCAPIClient`, which never validates the URL scheme. `newCAPITransport` in `pkg/cmd/agent-task/capi/client.go` only extracts `u.Host` from `url.Parse(capiBaseURL)` and never checks `u.Scheme`, so if the server returns an `http://` URL (or any host), the `Authorization: Bearer <token>` header will be attached to plaintext requests to that host.

### Finding Description
The flow is: `CapiClientFunc` (`pkg/cmd/agent-task/shared/capi.go:21-45`) calls `resolveCapiURL(cachedClient, host)` which issues a GraphQL query and returns `resp.Viewer.CopilotEndpoints.Api` unmodified [1](#0-0) . That string is passed straight into `capi.NewCAPIClient(httpClient, token, host, capiBaseURL)` [2](#0-1) .

`NewCAPIClient` installs `newCAPITransport(token, capiBaseURL, httpClient.Transport)` as the client's `RoundTripper` [3](#0-2) . `newCAPITransport` parses `capiBaseURL` with `url.Parse` and stores only `u.Host`; it never validates `u.Scheme == "https"` [4](#0-3) .

At request time, `RoundTrip` unconditionally sets the `Authorization: Bearer <token>` header on every outgoing request handled by this transport (not just CAPI requests) before delegating to the wrapped `RoundTripper` [5](#0-4) . Actual request URLs are built from `capiBaseURL` via `safeurl.JoinPathWithHostPrefix(c.capiBaseURL, ...)`, which uses the host prefix (including scheme) "as given" without any TLS enforcement [6](#0-5) [7](#0-6) .

There is no allowlist of hosts or schemes anywhere in this path — `resolveCapiURL`'s only validation is that the string is non-empty [8](#0-7) , confirmed by the existing test suite, which only exercises `https://` URLs and an empty-string case [9](#0-8) .

### Impact Explanation
If the `viewer.copilotEndpoints.api` GraphQL field returned by the configured GitHub host is attacker-influenced (e.g., a malicious or compromised GHES instance the victim has pointed `gh` at), the CLI will send the user's live OAuth/PAT token in plaintext, cleartext `Authorization: Bearer` headers to whatever host and scheme the response specifies — including a completely different attacker-controlled domain over `http://`. This matches a credential/token exfiltration impact class since the token becomes observable to any network-path attacker (or is sent directly to an attacker's host if it names one), not just to the intended, TLS-protected Copilot API endpoint.

### Likelihood Explanation
This requires the response to the `CopilotEndpoints` GraphQL query — served by the GitHub host the victim's `gh` is authenticated against — to return an `http://` or attacker-chosen URL. This is only feasible if the victim's `gh` is pointed at an attacker-controlled or compromised GHES/Enterprise instance (a scenario the question's own preconditions call out). It is not exploitable against genuine github.com, since that server is not attacker-controlled. Given that precondition, exploitation is fully deterministic and repeatable — no timing or race conditions involved, and no additional validation anywhere in the call chain (`resolveCapiURL`, `NewCAPIClient`, `newCAPITransport`, `safeurl.JoinPathWithHostPrefix`) would block it.

### Recommendation
Validate the resolved Copilot API URL before use: in `resolveCapiURL` (or in `newCAPITransport`), parse the URL and reject/refuse to proceed unless `u.Scheme == "https"`. Consider also restricting the accepted host to the expected GHES/GitHub domain (derived from the configured `host`) rather than trusting an arbitrary server-supplied host, mirroring the host-allowlisting patterns already used elsewhere (e.g., `ghinstance`/`safeurl` host handling).

```go
// resolveCapiURL queries the GitHub API for the Copilot API endpoint URL.
func resolveCapiURL(httpClient *http.Client, host string) (string, error) {
	apiClient := api.NewClientFromHTTP(httpClient)

	var resp struct {
		Viewer struct {
			CopilotEndpoints struct {
				Api string `graphql:"api"`
			} `graphql:"copilotEndpoints"`
		} `graphql:"viewer"`
	}

	if err := apiClient.Query(host, "CopilotEndpoints", &resp, nil); err != nil {
		return "", err
	}

	if resp.Viewer.CopilotEndpoints.Api == "" {
		return "", errors.New("empty Copilot API URL returned")
	}

	return resp.Viewer.CopilotEndpoints.Api, nil
}
```

```go
func newCAPITransport(token string, capiBaseURL string, rp http.RoundTripper) *capiTransport {
```

```go
// joinPathWithHostPrefix builds a full REST API URL by prepending hostPrefix to the path produced by
// JoinPath. A single slash is ensured at the join between hostPrefix and the path so they separate
// cleanly without doubling up. When hostPrefix is empty, the JoinPath result is returned intact, and
// when the joined path is empty, hostPrefix is returned intact. hostPrefix is used verbatim while each
// component is percent-encoded.
func joinPathWithHostPrefix(hostPrefix string, components ...string) string {
	path := joinPath(components...)
	if hostPrefix == "" {
		return path
	}
	if path == "" {
		return hostPrefix
	}
	if !strings.HasSuffix(hostPrefix, "/") {
		return hostPrefix + "/" + path
	}
	return hostPrefix + path
}
```
