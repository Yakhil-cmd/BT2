The Casdoor report describes an SSRF in a webhook URL handler within Casdoor, a Go-based IAM/OAuth service — this is not a dependency of `polkadot-sdk` and no `casdoor` references exist in this codebase.

Looking for an analog: the SSRF bug class requires a server-side component making outbound HTTP requests to a URL controllable by an unprivileged attacker. `polkadot-sdk`'s only outbound-HTTP-capable component is the offchain worker HTTP API [1](#0-0)  exposed to runtime offchain worker logic via `sp_io::offchain::http_request_start` [2](#0-1)  and the `sp_runtime::offchain::http::Request` builder [3](#0-2) .

This mechanism is not analogous to the Casdoor webhook SSRF because:
- Offchain worker code runs off-chain and is node-operator-configured; it is not deterministic on-chain logic reachable by a signed extrinsic from an unprivileged user.
- No pallet or runtime entry point in the indexed code takes attacker-supplied extrinsic data and feeds it as a URL into `http_request_start` (or any outbound network call) as part of dispatchable/on-chain execution.
- Client-side execution is only reachable through user inputs per the report's own scope note, and no such reachable path from a signed extrinsic to an SSRF-capable outbound request was found.

Since there is no real user entry point (signed extrinsic, contract call, or XCM message) that drives an attacker-controlled URL into a server-side outbound request, there is no demonstrable analog to the Casdoor webhook SSRF in this codebase.

impl<'a, I: AsRef<[u8]>, T: IntoIterator<Item = I>> Request<'a, T> {
	/// Send the request and return a handle.
	///
	/// Err is returned in case the deadline is reached
	/// or the request timeouts.
	pub fn send(self) -> Result<PendingRequest, HttpError> {
		let meta = &[];

		// start an http request.
		let id = sp_io::offchain::http_request_start(self.method.as_ref(), self.url, meta)
			.map_err(|_| HttpError::IoError)?;

		// add custom headers
		for header in &self.headers {
			sp_io::offchain::http_request_add_header(id, header.name(), header.value())
				.map_err(|_| HttpError::IoError)?
		}

		// write body
		for chunk in self.body {
			sp_io::offchain::http_request_write_body(id, chunk.as_ref(), self.deadline)?;
		}

		// finalize the request
		sp_io::offchain::http_request_write_body(id, &[], self.deadline)?;

		Ok(PendingRequest { id })
	}
