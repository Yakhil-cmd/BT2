The Footium report describes a centralized, owner-controlled `mint()` function with no supply cap — essentially the contract owner (a privileged role) intentionally being allowed to mint without limit. This bug class requires a privileged actor exercising a permission they already hold by design, which is explicitly excluded by the scan's constraints ("no privileged role, governance control"). 

Searching the Polkadot SDK analogs (`pallet-nfts`, `pallet-uniques`, `pallet-assets`, `pallet-balances`) shows that minting is already permission-gated and, where relevant, supply-capped:
- `pallet-nfts`/`pallet-uniques` support an optional `max_supply` per collection, enforced in `do_mint` via `Error::MaxSupplyReached`, and minting requires the `Issuer` role unless `MintType::Public` is explicitly configured. [1](#0-0) [2](#0-1) [3](#0-2) 
- `pallet-assets::do_mint` checks the caller against the registered `issuer` before increasing supply. [4](#0-3) 
- `fungible::Mutate::mint_into` only checked-adds against `total_issuance`, with no attacker-facing unprivileged entry point that bypasses these checks. [5](#0-4) 

The one example of an unrestricted "anyone can mint" function found (`mint_unsafe`) is explicitly documentation/tutorial code labeled "Not a great idea," not production runtime logic, and is excluded per the scan's rules on tutorial/example code. [6](#0-5) 

No unprivileged, attacker-reachable path was found where a Polkadot SDK production pallet allows unbounded minting without an existing supply-cap or issuer-permission check that would need to be bypassed — which would require a privileged prerequisite excluded from scope.

	/// Increase the balance of `who` by exactly `amount`, minting new tokens. If that isn't
	/// possible then an `Err` is returned and nothing is changed.
	fn mint_into(who: &AccountId, amount: Self::Balance) -> Result<Self::Balance, DispatchError> {
		Self::total_issuance().checked_add(&amount).ok_or(ArithmeticError::Overflow)?;
		let actual = Self::increase_balance(who, amount, Exact)?;
		Self::set_total_issuance(Self::total_issuance().saturating_add(actual));
		Self::done_mint_into(who, amount);
		Ok(actual)
	}
