### Title
Governance Vote for `kip71.gastarget = 0` Causes Division-by-Zero Panic in `NextMagmaBlockBaseFee`, Halting All Nodes — (`params/kip71_config.go`)

---

### Summary

The `Kip71GasTarget` governance parameter has `noopFormatChecker` (accepts any value including 0) and is not deprecated, so a valid GC member can ratify `kip71.gastarget = 0` through the normal header-governance vote path. Once effective, every call to `NextMagmaBlockBaseFee` for a block with any gas used triggers an integer division-by-zero panic in Go's `big.Int.Div`, crashing all nodes and permanently halting the chain.

---

### Finding Description

**Step 1 — No minimum guard on `Kip71GasTarget`.**

`kaiax/gov/param.go` defines the parameter table. `Kip71BaseFeeDenominator` has an explicit non-zero check, but `Kip71GasTarget` uses `noopFormatChecker`:

```go
// kaiax/gov/param.go
Kip71BaseFeeDenominator: {
    FormatChecker: func(cv any) bool {
        v, ok := cv.(uint64)
        return ok && v != 0          // ← zero is rejected
    },
    ...
},
Kip71GasTarget: {
    FormatChecker: noopFormatChecker, // ← zero is accepted
    ...
},
``` [1](#0-0) 

**Step 2 — `Kip71GasTarget` is not deprecated and passes all consistency checks.**

`AlwaysDeprecated` and `PermissionlessDeprecated` do not include `Kip71GasTarget`. The `checkConsistency` function explicitly lists it in the "no further checks" branch:

```go
case gov.Kip71BaseFeeDenominator, gov.Kip71GasTarget, gov.Kip71MaxBlockGasUsedForBaseFee, ...:
    return nil
``` [2](#0-1) [3](#0-2) 

**Step 3 — Vote API accepts the value and inscribes it in the block header.**

`headergov/impl/api.go` calls `NewVoteData` → `noopFormatChecker` → passes; `DeprecatedAt` returns false; `checkConsistency` returns nil. The vote is queued and written to `header.Vote` when the node proposes a block. [4](#0-3) 

**Step 4 — After the epoch, `GasTarget = 0` becomes the effective parameter.**

At the next epoch block the ratified governance data is written to `header.Governance` and applied. All nodes update their `ParamSet` with `GasTarget = 0`. [5](#0-4) 

**Step 5 — Division-by-zero panic in `NextMagmaBlockBaseFee`.**

`params/kip71_config.go` uses `GasTarget` as a divisor. There is a guard for `BaseFeeDenominator == 0` (lines 71-76) but **no guard for `GasTarget == 0`**:

```go
gasTarget := kc.GasTarget                          // = 0
parentGasUsed := min(parentHeaderGasUsed, upperGasLimit)
if parentGasUsed == gasTarget {                    // only true if parentGasUsed == 0
    return makeEvenByFloor(parentBaseFee)
} else if parentGasUsed > gasTarget {              // true for any block with transactions
    gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
    x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
    y := x.Div(x, new(big.Int).SetUint64(gasTarget)) // ← PANIC: division by zero
``` [6](#0-5) 

`NextMagmaBlockBaseFee` is called from `VerifyMagmaHeader`, which is invoked during block validation and block production on every node. [7](#0-6) 

---

### Impact Explanation

Once `kip71.gastarget = 0` takes effect, every block that contains at least one transaction (i.e., `parentGasUsed > 0`) causes a Go runtime panic in `big.Int.Div` inside `NextMagmaBlockBaseFee`. This function is called during both block production (`work/worker.go`) and block validation (`blockchain/block_validator.go`). All honest nodes crash simultaneously, producing a permanent chain halt — an invalid state transition / consensus divergence on all honest nodes.

---

### Likelihood Explanation

The trigger requires a valid GC member (in `none` governance mode) or the governing node (in `single` mode) to cast a governance vote for `kip71.gastarget = 0`. This is a semi-trusted role, analogous to the "owner" in the external report. The vote passes every validation layer without error. The impact is irreversible once the epoch boundary is crossed: no subsequent governance vote can take effect because the chain is already halted.

---

### Recommendation

Add a non-zero minimum guard to `Kip71GasTarget`'s `FormatChecker`, mirroring the existing guard on `Kip71BaseFeeDenominator`:

```go
Kip71GasTarget: {
    Canonicalizer: uint64Canonicalizer,
    FormatChecker: func(cv any) bool {
        v, ok := cv.(uint64)
        return ok && v > 0   // reject zero to prevent division-by-zero
    },
    ...
},
```

Additionally, add a defensive zero-check inside `NextMagmaBlockBaseFee` itself before using `gasTarget` as a divisor, so that a misconfigured genesis or a future code path cannot trigger the same panic:

```go
if gasTarget == 0 {
    // fallback: treat as if gas used equals target (no fee change)
    return makeEvenByFloor(parentBaseFee)
}
``` [8](#0-7) 

---

### Proof of Concept

1. Chain is running in `none` governance mode (or attacker controls the governing node in `single` mode).
2. Call `governance_vote("kip71.gastarget", 0)` via the JSON-RPC API on a GC member node.
3. The vote is accepted: `NewVoteData` → `noopFormatChecker` returns `true`; `DeprecatedAt` returns `false`; `checkConsistency` returns `nil`.
4. The vote is inscribed in `header.Vote` when the GC member proposes a block.
5. At the next epoch block, the vote is ratified and `header.Governance` encodes `{"kip71.gastarget": 0}`.
6. Starting from `(k+1)*epoch`, all nodes use `GasTarget = 0` in `NextMagmaBlockBaseFee`.
7. The first block with any transaction (`parentGasUsed > 0`) causes `big.Int.Div(x, big.NewInt(0))` → Go runtime panic → all nodes crash → chain permanently halted.

func (kc *KIP71Config) VerifyMagmaHeader(headerBaseFee *big.Int, parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) error {
	if headerBaseFee == nil {
		return fmt.Errorf("header is missing baseFee")
	}
	// Verify the baseFee is correct based on the parent header.
	expectedBaseFee := kc.NextMagmaBlockBaseFee(parentHeaderNumber, parentHeaderBaseFee, parentHeaderGasUsed)
	if headerBaseFee.Cmp(expectedBaseFee) != 0 {
		return fmt.Errorf("invalid baseFee: have %s, want %s, parentBaseFee %s, parentGasUsed %d",
			headerBaseFee, expectedBaseFee, parentHeaderBaseFee, parentHeaderGasUsed)
	}
	return nil
}
