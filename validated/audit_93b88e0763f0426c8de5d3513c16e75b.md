Confirmed: `Shipit.github_teams` is a memoized array resolved once via `Team.find_or_create_by_handle` [1](#0-0) , which looks up existing rows by `organization`/`slug` or fetches the real team from the GitHub API via `find_team_on_github` (an authenticated Octokit call scoped to the configured organization) before creating it [2](#0-1) . Authorization in `User#authorized?` and `force_github_authentication` keys off `Shipit.github_teams.map(&:id)` — the Rails primary key `id`, not `github_id` or `slug` — checked against the `memberships` join table [3](#0-2) [4](#0-3) .

`MembershipHandler#find_or_create_team!` creates/looks up a `Team` by `github_id: params.team.id` from the attacker-controlled payload [5](#0-4) . Since `params.team.id` is a real GitHub team id space and the attacker cannot forge a `github_id` that collides with an already-resolved privileged team's `github_id` (those were fetched directly from GitHub's API for the configured org, not from webhook input), this webhook-created team will always be a distinct row with a distinct primary key `id`, which is never present in the pre-computed `Shipit.github_teams.map(&:id)` array. Reusing a `slug` like `eng` that happens to match a privileged handle format has no effect, because slug is never used at authorization-check time — only at boot-time resolution via `find_or_create_by_handle`, which requires a legitimate GitHub API round-trip against the configured organization, not attacker input.

So the binding the question worries about — "does anything re-resolve `Shipit.github_teams` by slug instead of id?" — is false: the only consumer, `User#authorized?`, filters strictly by primary-key `id`, and that array is fixed at process boot (memoized), not touched by webhook processing at all.

    class << self
      def find_or_create_by_handle(handle)
        organization, slug = handle.split('/').map(&:downcase)
        find_by(organization:, slug:) || fetch_and_create_from_github(organization, slug)
      end

      def fetch_and_create_from_github(organization, slug)
        return unless github_team = find_team_on_github(organization, slug)

        create!(github_team:, organization:)
      end

      def find_team_on_github(organization, slug)
        gh_api = Shipit.github(organization:).api
        teams = Shipit::OctokitIterator.new(github_api: gh_api) { gh_api.org_teams(organization, per_page: 100) }
        teams.find { |t| t.slug == slug }
      rescue Octokit::NotFound
      end
