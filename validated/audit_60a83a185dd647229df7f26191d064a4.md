### Title
Static Node Permanent Eviction via On-Path TCP Failure Injection — (`networks/p2p/dialsched.go`)

### Summary
`DialSched.markDialFailure` permanently removes a static node from `ds.static` after only 4 consecutive TCP-level dial failures. An on-path attacker who drops SYN packets for approximately two minutes can silently and durably partition a CN from its validator peers, with no automatic recovery until the operator intervenes or restarts the node.

### Finding Description

`dialMaxRetries` is set to 3. [1](#0-0) 

Every time `dialOnce` encounters a TCP error it calls `markDialFailure`, which increments `connFails[id]` and, once the counter exceeds `dialMaxRetries`, calls `ds.static.remove(id)`: [2](#0-1) 

`getCandidates` seeds its candidate list exclusively from `ds.static.all()`, so a removed node is never dialed again: [3](#0-2) 

`connFails[id]` is reset in exactly two places:

- `markPeerConnected` — only reachable if the connection actually succeeds (impossible while the attacker is active): [4](#0-3) 

- `addStatic` — only reachable via explicit operator action (`admin_addPeer` or node restart): [5](#0-4) 

There is no automatic re-addition, exponential back-off cap, or watchdog that re-seeds `ds.static` from `static-nodes.json` at runtime.

The `dialBackoff` of 30 seconds is set unconditionally in `markDialEnd` (called via `defer` in `dialOnce`): [6](#0-5) 

This means the attacker only needs to sustain the SYN-drop for four dial windows (~2 minutes total) to trigger permanent eviction.

### Impact Explanation

Static nodes in the CN mesh are the primary mechanism by which Consensus Nodes maintain validator-to-validator connectivity. Permanent eviction of one or more static CN peers from `ds.static` severs the outbound dial path to those validators. Because the eviction persists until the node is restarted or an operator manually calls `admin_addPeer`, the affected CN is durably partitioned from the consensus mesh, causing a liveness failure (inability to participate in or drive block production) for the duration of the partition.

### Likelihood Explanation

The attacker must be on the network path between the victim CN and the target static node (e.g., via BGP hijacking, ISP-level interception, or control of an intermediate router). Validator IP addresses are often discoverable from public bootnode records or chain explorer data. Once on-path, the attacker only needs to drop TCP SYN packets for four 30-second dial windows (~2 minutes). No cryptographic material, governance keys, or validator collusion is required. The attack is silent — the victim node logs a warning but takes no corrective action.

### Recommendation

1. **Never permanently evict static nodes.** Static nodes represent operator-configured trust anchors. Replace permanent removal with an exponential back-off cap (e.g., max 10 minutes between retries) so the node keeps attempting to reconnect indefinitely.
2. **Distinguish transient from permanent failure.** Only evict a static node if the failure is clearly non-transient (e.g., cryptographic handshake rejection), not a TCP-level connection error.
3. **Periodic re-seeding.** Periodically re-read `static-nodes.json` and re-add any nodes that were evicted due to dial failures, so the system self-heals without operator intervention.

func (ds *DialSched) dialOnce(n *discover.Node, flags connFlag) {
	defer ds.markDialEnd(n.ID)

	if ds.dialer == nil || ds.backend == nil {
		ds.markDialFailure(n.ID)
		return
	}

	var err error
	if len(n.TCPs) > 1 {
		err = ds.dialMulti(n, flags)
	} else {
		err = ds.dial(n, flags)
	}

	// Multi-channel peers can request redial after updating listen ports.
	if err == errUpdateDial {
		err = ds.dialMulti(n, flags)
	}
	logger.Debug("Dialed node", "id", n.ID, "type", n.NType, "addresses", n.TCPs, "err", err)

	if err != nil {
		ds.markDialFailure(n.ID)
	}
	// We don't call markPeerConnected() here. If dial()-SetupConn() succeeds, the Server will call OnPeerConnected()-markPeerConnected().

func (ds *DialSched) markDialFailure(id discover.NodeID) {
	dialFailCounter.Inc(1)

	ds.mu.Lock()
	defer ds.mu.Unlock()

	ds.connectedAll.remove(id)
	ds.connectedOutbound.remove(id)

	if n := ds.static.get(id); n != nil {
		ds.connFails[id]++
		if ds.connFails[id] > dialMaxRetries {
			logger.Warn("Removing static node after too many connection failures", "node", n.String())
			ds.static.remove(id)
		}
	}
}
