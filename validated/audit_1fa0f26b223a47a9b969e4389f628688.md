### Title
`data_feed`/`in_data_feed` oscript functions return oracle values with no built-in freshness/staleness check - (File: `formula/evaluation.js`, `data_feeds.js`)

### Summary
The oscript `data_feed[[...]]` and `in_data_feed[[...]]` functions, used by AAs to read externally-posted price/data-feed values, provide no mechanism to verify how old the returned value is in wall-clock time. Callers can only filter by `min_mci` (a DAG position) and cannot obtain the feed post's timestamp as part of the lookup itself, mirroring the reported `PriceOracle.getPrice` flaw where a Chainlink round is consumed without checking `updatedAt`.

### Finding Description
`case 'data_feed'` in `getDataFeed()` [1](#0-0)  resolves an oracle value by calling `dataFeeds.readDataFeedValue()`, whose parameters are limited to `oracles`, `feed_name`, `feed_value`, `min_mci`, `ifseveral`, `what`, `type`, `ifnone` — validated in `validateDataFeed()` [2](#0-1)  and restricted such that `what` can only be `'value'` or `'unit'` [3](#0-2) . There is no `feed_timestamp`/`max_age` parameter that would let an AA reject a value that hasn't been refreshed recently.

`readDataFeedValue`/`readDataFeedByAddress` in `data_feeds.js` [4](#0-3) [5](#0-4)  select the latest matching feed entry purely by `min_mci`/`max_mci` and DAG ordering (`latest_included_mc_index`, `level`), never by real elapsed time. `readDataFeedValueByParams`, used by getters, behaves the same way [6](#0-5) .

To reconstruct freshness, an AA author must separately fetch the posting unit via `what='unit'` and then call `unit[unit_hash].timestamp` [7](#0-6) , an extra, easy-to-omit step that costs additional formula complexity and is not enforced anywhere in validation or the runtime. Even the bundled reference AA sample `futures_contract.oscript`, which explicitly comments "`data_feed will abort if the exchange rate not posted yet`", only guards against the feed never having been posted — it performs no check that the last posted value is recent, and instead hardcodes an unrelated maturity date comparison against `timestamp` [8](#0-7) .

This is the same root cause as the M-1 Iron Bank finding: the oracle-consumption primitive silently returns "the latest known value" with no built-in staleness gate, delegating all freshness enforcement to the (frequently negligent) integrator.

### Impact Explanation
Any AA that uses `data_feed[[...]]` for pricing, collateralization, redemption, or exchange-rate calculations (lending pools, synthetic assets, bonded curves, stablecoins) can act on an arbitrarily old value if the referenced oracle address stops posting or is delayed, without the AA or its users being able to detect this from the `data_feed` call itself. This can lead to funds being minted/redeemed/exchanged at a stale rate, producing under-collateralization, bad debt, or direct value extraction from the AA's balance — i.e., concrete AA fund loss, matching the "bad debt" impact described in the source report.

### Likelihood Explanation
Likelihood is moderate-to-high: this is a routine oversight, not an exotic corner case. Since freshness checking requires an extra `unit[...]` lookup that most AA authors are unlikely to add (as shown by the shipped sample AA not implementing it correctly), any live oracle-dependent AA that stops receiving fresh price posts (oracle downtime, censorship, network partition, deliberate abandonment) will silently keep serving stale prices to any user/trigger able to interact with it — no privileged access or malicious peer/node behavior is required, only normal use of the public `trigger`/AA-call path.

### Recommendation
Extend the `data_feed` oscript primitive (and its validation in `formula/validation.js` and implementation in `data_feeds.js`/`formula/evaluation.js`) with an optional `max_age` (or `min_timestamp`) parameter that is checked against the posting unit's `timestamp` (or `objValidationState.last_ball_timestamp` at read time) before returning a value, defaulting `ifnone`-style behavior (abort or fallback) when the freshest matching entry is older than the allowed threshold. Document clearly that `min_mci` alone does not guarantee recency in real time.

### Proof of Concept
1. Deploy an AA whose logic reads `$price = data_feed[[oracles='<oracle_address>', feed_name='GBYTE_USD']];` and uses `$price` directly to compute payout/exchange amounts, without any accompanying `unit[...].timestamp` freshness check (as in `futures_contract.oscript`).
2. The oracle posts a price once and then stops posting (goes offline, is compromised, or is simply abandoned) while the real market price diverges substantially.
3. Any user can still trigger the AA; `data_feed[[...]]` returns the last known (now stale) value with no error, because `readDataFeedValue`/`readDataFeedByAddress` only look for the most recent entry within `[min_mci, max_mci]` and never validate real-world recency [9](#0-8) .
4. The AA computes payouts/conversions using the outdated price, allowing the triggering user to extract value at the stale rate, draining the AA's balance or causing bad debt for other participants.

function readDataFeedByAddress(address, feed_name, value, min_mci, max_mci, ifseveral, objResult, handleResult){
	var bLimitedPrecision = (max_mci < constants.aa2UpgradeMci);
	var bAbortIfSeveral = (ifseveral === 'abort');
	var key_prefix;
	if (value === null){
		key_prefix = 'dfv\n'+address+'\n'+feed_name;
	}
	else{
		var prefixed_value;
		if (typeof value === 'string'){
			var float = string_utils.toNumber(value, bLimitedPrecision);
			if (float !== null)
				prefixed_value = 'n\n'+string_utils.encodeDoubleInLexicograpicOrder(float);
			else
				prefixed_value = 's\n'+value;
		}
		else
			prefixed_value = 'n\n'+string_utils.encodeDoubleInLexicograpicOrder(value);
		key_prefix = 'df\n'+address+'\n'+feed_name+'\n'+prefixed_value;
	}
	var options = {
		gte: key_prefix+'\n'+string_utils.encodeMci(max_mci),
		lte: key_prefix+'\n'+string_utils.encodeMci(min_mci),
		limit: bAbortIfSeveral ? 2 : 1
	};
	var handleData = function(data){
		if (bAbortIfSeveral && objResult.value !== undefined){
			objResult.bAbortedBecauseOfSeveral = true;
			return;
		}
		var mci = string_utils.getMciFromDataFeedKey(data.key);
		if (objResult.value === undefined || ifseveral === 'last' && mci > objResult.mci){
			if (value !== null){
				objResult.value = string_utils.getValueFromDataFeedKey(data.key);
				objResult.unit = data.value;
			}
			else{
				var arrParts = data.value.split('\n');
				objResult.value = string_utils.getFeedValue(arrParts[0], bLimitedPrecision); // may convert to number
				objResult.unit = arrParts[1];
			}
			objResult.mci = mci;
		}
	};
	kvstore.createReadStream(options)
	.on('data', handleData)
	.on('end', function(){
		handleResult(objResult.bAbortedBecauseOfSeveral);
	})
	.on('error', function(error){
		throw Error('error from data stream: '+error);
	});
}

function readDataFeedValueByParams(params, max_mci, unstable_opts, cb) {
	var oracles = params.oracles;
	if (!oracles)
		return cb("no oracles in readDataFeedValueByParams");
	if (!ValidationUtils.isNonemptyArray(oracles))
		return cb("oracles must be non-empty array");
	if (!oracles.every(ValidationUtils.isValidAddress))
		return cb("some oracle addresses are not valid");
	if (oracles.length > 10)
		return cb("too many oracles");
	var feed_name = params.feed_name;
	if (!feed_name || typeof feed_name !== 'string')
		return cb("empty feed_name or not a string");
	var value = null;
	if ('feed_value' in params) {
		value = params.feed_value;
		if (!isValidValue(value))
			return cb("bad feed_value: " + util.inspect(value, { depth: 5 }));
	}
	var min_mci = 0;
	if ('min_mci' in params) {
		min_mci = params.min_mci;
		if (!ValidationUtils.isNonnegativeInteger(min_mci))
			return cb("bad min_mci: " + util.inspect(min_mci, { depth: 5 }));
	}
	var ifseveral = 'last';
	if ('ifseveral' in params) {
		ifseveral = params.ifseveral;
		if (ifseveral !== 'abort' && ifseveral !== 'last')
			return cb("bad ifseveral: " + util.inspect(ifseveral, { depth: 5 }));
	}
	var what = 'value';
	if ('what' in params) {
		what = params.what;
		if (what !== 'unit' && what !== 'value')
			return cb("bad what: " + util.inspect(what, { depth: 5 }));
	}
	var type = 'auto';
	if ('type' in params) {
		type = params.type;
		if (type !== 'string' && type !== 'auto')
			return cb("bad df type: " + util.inspect(type, { depth: 5 }));
	}
	if ('ifnone' in params && !isValidValue(params.ifnone))
		return cb("bad ifnone: " + util.inspect(params.ifnone, { depth: 5 }));
	readDataFeedValue(oracles, feed_name, value, min_mci, max_mci, unstable_opts, ifseveral, Math.round(Date.now() / 1000), function (objResult) {
		if (objResult.bAbortedBecauseOfSeveral)
			return cb("several values found");
		if (objResult.value !== undefined) {
			if (what === 'unit')
				return cb(null, objResult.unit);
			if (type === 'string')
				return cb(null, objResult.value.toString());
			return cb(null, objResult.value);
		}
		if ('ifnone' in params && params.ifnone !== 'abort') {
			return cb(null, params.ifnone); // the type of ifnone (string, number, boolean) is preserved
		}
		cb("data feed " + feed_name + " not found");
	});
}
