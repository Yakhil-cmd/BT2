### Title
Missing `BlockNum`-to-header validation in `DeliverStakingInfos` allows a malicious FastSync peer to corrupt the staking epoch DB — (`datasync/downloader/queue.go`, `datasync/downloader/downloader.go`)

### Summary
During FastSync, staking info is fetched from remote peers by block hash. The delivery validation callback for staking infos is an explicit no-op (marked `TODO-Kaia-Snapsync`). `commitFastSyncData` writes staking info to the DB using the peer-supplied `BlockNum` field rather than the locally-known `result.Header.Number`. A malicious peer can serve a `P2PStakingInfo` with an arbitrary `BlockNum`, writing attacker-controlled staking data at any pre-Kaia DB slot.

### Finding Description
`queue.DeliverStakingInfos` passes a no-op `validate` function to the generic `deliver` helper:

```go
validate := func(index int, header *types.Header) error {
    // TODO-Kaia-Snapsync update validation logic
    return nil
}
```

No check is made that `stakingInfoList[index].BlockNum == header.Number.Uint64()`. The result is stored in `fetchResult.StakingInfo` verbatim.

`commitFastSyncData` then calls:
```go
d.stakingModule.PutStakingInfoToDB(result.StakingInfo.BlockNum, staking.ToStakingInfo(result.StakingInfo))
```

The DB key is the peer-supplied `BlockNum`, not `result.Header.Number`. A peer that responds to a request for block hash `H(X)` with a `P2PStakingInfo{BlockNum: Y, CouncilNodeAddrs: [attacker...]}` causes `WriteStakingInfo(db, Y, attackerData)`.

### Impact Explanation
`GetStakingInfo(num)` for pre-Kaia blocks reads from the DB at `sourceNum`. If the DB slot for `sourceNum` contains attacker-controlled data, the wrong `NodeIds`, `RewardAddrs`, and `StakingAmounts` are returned. This is used directly for:
- Weighted-random validator set selection (`GetQualifiedValidators`)
- Block reward distribution (`FinalizeState` → `GetDeferredReward`)

An attacker can exclude honest validators from rewards or inject attacker-controlled reward addresses into the distribution for any pre-Kaia staking epoch.

### Likelihood Explanation
The attacker only needs to be a reachable P2P peer during a victim node's FastSync. No privileged access, governance keys, or validator collusion is required. The attack is silent — the victim node logs "Imported new staking information" with the attacker-supplied block number and continues syncing normally.

### Recommendation
In `queue.DeliverStakingInfos`, replace the no-op validate function with:
```go
validate := func(index int, header *types.Header) error {
    if stakingInfoList[index].BlockNum != header.Number.Uint64() {
        return errInvalidStakingInfo
    }
    return nil
}
```
Additionally, in `commitFastSyncData` and `commitPivotBlock`, assert `result.StakingInfo.BlockNum == result.Header.Number.Uint64()` before calling `PutStakingInfoToDB`, and use `result.Header.Number.Uint64()` as the DB key rather than the peer-supplied value.

### Proof of Concept
1. Construct a `fetchResult` with `Header.Number = 1000` and `StakingInfo.BlockNum = 2000` (attacker-controlled council addresses).
2. Call `commitFastSyncData([result], ...)`.
3. Assert `ReadStakingInfo(db, 2000)` returns the attacker's council addresses.
4. Assert `ReadStakingInfo(db, 1000)` returns nil (the correct slot is empty).
5. Call `GetStakingInfo(num)` for a block whose `sourceNum` is 2000; observe attacker addresses returned for validator selection.

	sourceNum := sourceBlockNum(num, isKaia, s.stakingInterval)

	// Try cache first
	if si, ok := s.stakingInfoCache.Get(sourceNum); ok {
		return si.(*staking.StakingInfo), nil

	if !isKaia {
		if si := ReadStakingInfo(s.ChainKv, sourceNum); si != nil {
			s.stakingInfoCache.Add(sourceNum, si)
			return si, nil
		}
	}

func handleStakingInfoMsg(pm *ProtocolManager, p Peer, msg p2p.Msg) error {
	if pm.chainconfig.Istanbul == nil || pm.chainconfig.Istanbul.ProposerPolicy != uint64(istanbul.WeightedRandom) {
		return errResp(ErrUnsupportedEnginePolicy, "the engine is not istanbul or the policy is not weighted random")
	}

	// A batch of stakingInfos arrived to one of our previous requests
	var stakingInfos []*staking.P2PStakingInfo
	if err := msg.Decode(&stakingInfos); err != nil {
		return errResp(ErrDecode, "msg %v: %v", msg, err)
	}
	// Deliver all to the downloader
	if err := pm.downloader.DeliverStakingInfos(p.GetID(), stakingInfos); err != nil {
		logger.Debug("Failed to deliver staking information", "err", err)
	}
	return nil
