### Title
Missing Zero-Value Guard on `kip71.gastarget` Governance Parameter Causes Division-by-Zero Panic in Block Validation — (File: `params/kip71_config.go`)

---

### Summary

`NextMagmaBlockBaseFee` uses `GasTarget` as a divisor in two integer-division expressions. The sibling parameter `BaseFeeDenominator` has an explicit non-zero `FormatChecker` in the governance layer, but `Kip71GasTarget` uses `noopFormatChecker`, allowing a governance vote to set it to zero. When any block with non-zero gas usage is subsequently validated, the function panics with a division-by-zero, halting every honest node.

---

### Finding Description

In `params/kip71_config.go`, `NextMagmaBlockBaseFee` explicitly guards `BaseFeeDenominator == 0` with a fallback value: [1](#0-0) 

However, `GasTarget` receives no such guard and is used as a divisor on two paths: [2](#0-1) [3](#0-2) 

In the governance parameter registry, `Kip71BaseFeeDenominator` explicitly rejects zero: [4](#0-3) 

But `Kip71GasTarget` uses `noopFormatChecker`, accepting any `uint64` value including zero: [5](#0-4) 

`Kip71GasTarget` is absent from both `AlwaysDeprecated` and `PermissionlessDeprecated`, so it remains a live, voteable parameter: [6](#0-5) 

The panic path is:

1. `parentGasUsed = min(parentHeaderGasUsed, MaxBlockGasUsedForBaseFee)` — with the default `MaxBlockGasUsedForBaseFee = 60,000,000`, any block containing at least one transaction yields `parentGasUsed > 0`.
2. `parentGasUsed > gasTarget (== 0)` → enters the "increase" branch.
3. `x.Div(x, new(big.Int).SetUint64(0))` → **runtime panic: integer divide by zero**.

`NextMagmaBlockBaseFee` is called from `VerifyMagmaHeader` during every block import: [7](#0-6) 

A panic there propagates through the consensus engine's header-verification path, crashing every node that attempts to import the first post-activation block with any gas usage.

---

### Impact Explanation

Once the governance vote ratifies `kip71.gastarget = 0` and the parameter takes effect, every honest node panics on the next block that includes at least one transaction. This is a **consensus divergence / chain halt** — an invalid-block-acceptance failure that prevents canonical execution from continuing. No transaction can be settled, no reward distributed, and no state transition finalized until the node software is patched and restarted with a corrected parameter.

---

### Likelihood Explanation

The governing node in `single` mode (the configuration of Kaia Mainnet and Kairos) can unilaterally cast a vote via `governance_vote`. The vote is ratified at the next epoch boundary and takes effect one epoch later. There is no on-chain or off-chain guard that rejects `kip71.gastarget = 0` before it is written into the ratified parameter set. The inconsistency with `BaseFeeDenominator`'s explicit zero-check makes this a plausible misconfiguration rather than a deliberate attack.

---

### Recommendation

Add a non-zero `FormatChecker` for `Kip71GasTarget`, mirroring the existing guard on `Kip71BaseFeeDenominator`:

```go
Kip71GasTarget: {
    Canonicalizer: uint64Canonicalizer,
    FormatChecker: func(cv any) bool {
        v, ok := cv.(uint64)
        return ok && v != 0   // GasTarget is used as a divisor; zero must be rejected
    },
    ...
},
```

Additionally, add a defensive guard inside `NextMagmaBlockBaseFee` analogous to the existing `BaseFeeDenominator` guard:

```go
if gasTarget == 0 {
    // Governance misconfiguration; fall back to a safe non-zero value
    gasTarget = kc.MaxBlockGasUsedForBaseFee
    if gasTarget == 0 {
        return makeEvenByFloor(parentBaseFee) // no adjustment possible
    }
}
```

---

### Proof of Concept

1. The governing node calls `governance_vote("kip71.gastarget", 0)`.
2. The vote is inscribed in a block header and ratified at the next epoch block.
3. At epoch+1, `GetParamSet` returns `GasTarget = 0`.
4. `TxPool.reset()` calls `pset.ToKip71Config().NextMagmaBlockBaseFee(...)` with any non-zero `newHead.GasUsed`.
5. Inside `NextMagmaBlockBaseFee`: `parentGasUsed = min(gasUsed, 60_000_000) > 0`; `parentGasUsed > gasTarget (0)` → `x.Div(x, big.NewInt(0))` → **panic**.
6. Simultaneously, every peer node importing the same block calls `VerifyMagmaHeader` → `NextMagmaBlockBaseFee` → same panic.
7. All honest nodes crash; the chain halts. [8](#0-7) [5](#0-4)

```go
	if headerBaseFee == nil {
		return fmt.Errorf("header is missing baseFee")
	}
	// Verify the baseFee is correct based on the parent header.
	expectedBaseFee := kc.NextMagmaBlockBaseFee(parentHeaderNumber, parentHeaderBaseFee, parentHeaderGasUsed)
	if headerBaseFee.Cmp(expectedBaseFee) != 0 {
		return fmt.Errorf("invalid baseFee: have %s, want %s, parentBaseFee %s, parentGasUsed %d",
			headerBaseFee, expectedBaseFee, parentHeaderBaseFee, parentHeaderGasUsed)
	}
	return nil
}
```

```go
func (kc *KIP71Config) NextMagmaBlockBaseFee(parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) *big.Int {
	// governance parameters
	lowerBoundBaseFee := new(big.Int).SetUint64(kc.LowerBoundBaseFee)
	upperBoundBaseFee := new(big.Int).SetUint64(kc.UpperBoundBaseFee)
	makeEvenByCeil(lowerBoundBaseFee)
	makeEvenByFloor(upperBoundBaseFee)

	// If the parent is the magma disabled block or genesis, then return the lowerBoundBaseFee (default 25ston)
	if parentHeaderNumber.Cmp(new(big.Int).SetUint64(0)) == 0 || parentHeaderBaseFee == nil {
		return makeEvenByFloor(lowerBoundBaseFee)
	}

	var baseFeeDenominator *big.Int
	if kc.BaseFeeDenominator == 0 {
		// To avoid panic, set the fluctuation range small
		baseFeeDenominator = new(big.Int).SetUint64(64)
	} else {
		baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
	}
	gasTarget := kc.GasTarget
	upperGasLimit := kc.MaxBlockGasUsedForBaseFee

	// check the case of upper/lowerBoundBaseFee is updated by governance mechanism
	parentBaseFee := parentHeaderBaseFee
	if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {
		parentBaseFee = upperBoundBaseFee
	} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
		parentBaseFee = lowerBoundBaseFee
	}

	// upper gas limit cut off the impulse of used gas to upper bound
	parentGasUsed := min(parentHeaderGasUsed, upperGasLimit)
	if parentGasUsed == gasTarget {
		return makeEvenByFloor(parentBaseFee)
	} else if parentGasUsed > gasTarget {
		// shortcut. If parentBaseFee is already reached upperbound, do not calculate.
		if parentBaseFee.Cmp(upperBoundBaseFee) == 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		// If the parent block used more gas than its target,
		// the baseFee of the next block should increase.
		// baseFeeDelta = max(1, parentBaseFee * (parentGasUsed - gasTarget) / gasTarget / baseFeeDenominator)
		gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := math.BigMax(x.Div(y, baseFeeDenominator), common.Big1)

		nextBaseFee := x.Add(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(upperBoundBaseFee) > 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	} else {
		// shortcut. If parentBaseFee is already reached lower bound, do not calculate.
		if parentBaseFee.Cmp(lowerBoundBaseFee) == 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		// Otherwise if the parent block used less gas than its target,
		// the baseFee of the next block should decrease.
		// baseFeeDelta = parentBaseFee * (gasTarget - parentGasUsed) / gasTarget / baseFeeDenominator
		gasUsedDelta := new(big.Int).SetUint64(gasTarget - parentGasUsed)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := x.Div(y, baseFeeDenominator)

		nextBaseFee := x.Sub(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(lowerBoundBaseFee) < 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	}
}
```
