### Title
Unauthenticated `NType=NodeTypeBN` in PING Packet Injects Attacker Node into All Four Discovery Storages — (`networks/p2p/discover/table_data.go`, `udp.go`, `table_bond.go`)

### Summary

A remote peer can send a UDP PING packet with a self-reported `req.From.NType = NodeTypeBN`. The victim node passes this value unvalidated through `ping.handle → t.bond → tab.Bond → tab.addNode`. Because `addNode` unconditionally inserts any `NodeTypeBN`-typed node into **all four** per-type storages (CN, PN, EN, BN), the attacker's node is returned by `RandomNodes` for every node type, enabling a Sybil-amplified eclipse of the victim's peer discovery.

### Finding Description

**Step 1 — No NType validation in `ping.preverify`**

`ping.preverify` only checks expiration and NetworkID. It never validates `req.From.NType`. [1](#0-0) 

**Step 2 — Attacker-controlled NType flows into `t.bond`**

`ping.handle` passes `req.From.NType` directly to `t.bond`: [2](#0-1) 

**Step 3 — `t.bond` constructs a Node with the attacker-supplied NType** [3](#0-2) 

**Step 4 — `tab.Bond` completes the handshake and calls `addNode`**

The only inbound guard is `pinged && !tab.initialized()`. Once the table is seeded (normal operating state), this guard is bypassed. The victim then pings the attacker back; if the attacker responds with a valid PONG (trivially achievable), `addNode` is called: [4](#0-3) 

**Step 5 — `addNode` inserts into ALL four storages for NType=NodeTypeBN**

This is the root cause. The `NodeTypeBN` branch iterates over every storage and calls `s.add(n)`: [5](#0-4) 

**Step 6 — `RandomNodes` returns the attacker's node for every type** [6](#0-5) 

**Step 7 — `flatStorage.add` has no capacity limit**

The CN, PN, and BN storages use `flatStorage` with `math.MaxInt64` as the size cap, so the attacker can add unlimited nodes: [7](#0-6)

### Impact Explanation

With multiple Sybil nodes each sending `NType=NodeTypeBN` PINGs, the attacker populates all four storages with their own nodes. The dial scheduler uses `RandomNodes` to select peers to connect to. A victim CN whose discovery table is dominated by attacker nodes will establish TCP connections primarily to attacker-controlled peers. This enables:

- **Eclipse of the victim CN**: the victim cannot reach honest peers for block propagation or consensus messages.
- **Consensus divergence**: an eclipsed CN misses legitimate blocks, stalls, or is fed a fork, causing it to diverge from the honest chain.

The 4× amplification (one Sybil node occupies four slots instead of one) significantly lowers the Sybil cost compared to a correctly-typed node.

---

### Likelihood Explanation

The attack requires only a reachable UDP endpoint and the ability to craft a PING packet with `NType=NodeTypeBN`. No privileged access, no key compromise, and no cryptographic break is needed. The PING packet is signed with the attacker's own ECDSA key (which is recovered as `fromID`), so signature verification passes. The only liveness requirement is that the attacker responds to the victim's return PING with a valid PONG, which any cooperative attacker node can do.

---

### Recommendation

1. **Validate NType against a permissioned list**: Before calling `t.bond`, check whether the claimed `NType=NodeTypeBN` matches a known, configured bootstrap node list (`tab.nursery`). Reject or downgrade the NType if the sender is not in the list.
2. **Decouple wire NType from storage routing**: Do not trust the self-reported NType for storage placement. Either derive NType from a signed, out-of-band registry, or treat all inbound-PING nodes as `NodeTypeUnknown` until verified.
3. **Add a size cap to `flatStorage`**: Even without the NType fix, bounding `flatStorage` prevents unbounded Sybil accumulation.

func (req *ping) preverify(t *udp, from *net.UDPAddr, fromID NodeID) error {
	if expired(req.Expiration) {
		return errExpired
	}
	if req.NetworkID != t.networkID {
		logger.Debug("udp: ping: mismatch networkid", "local", t.networkID, "remote", req.NetworkID)
		mismatchNetworkCounter.Mark(1)
		return errMismatchNetwork
	}
	// Bootstrap nodes rate-limit discovery pings per source IP to bound
	// amplification/DoS against the UDP endpoint. Rejecting here prevents both
	// the pong reply and the bonding goroutine in handle().
	//
	// LAN/loopback sources are exempt: the limit protects an internet-reachable
	// BN from public ping floods, while co-located/local nodes legitimately share
	// a single private IP (e.g. many nodes behind one NAT, or localhost in tests)
	// and must not throttle one another. This mirrors the LAN exemption on the
	// inbound TCP connection throttle.
	//
	// The limit is otherwise applied to every (non-LAN) source IP, not just
	// unbonded ones: a UDP source IP is unauthenticated/spoofable and kaia's bond
	// is keyed by NodeID only, so a "bonded NodeID + spoofed source IP" packet
	// could otherwise bypass the limit and reflect a pong to the spoofed victim.
	if t.ourEndpoint.NType == NodeTypeBN && t.pingLimiter != nil && !netutil.IsLAN(from.IP) {
		if !t.pingLimiter.allow(from.IP, time.Now()) {
			logger.Trace("udp: ping: rate limited", "addr", from)
			pingRateLimitedCounter.Mark(1)
			return errPingRateLimited
		}
	}
	return nil
}

func (tab *Table2) Bond(pinged bool, n *Node) error {
	if n.ID == tab.selfID {
		return errSelfBonding
	}
	// Do not accept inbound (i.e. remote pinged me) bonding requests before
	// populating from my seeds. It prevents remote nodes from filling up the table by spamming.
	if pinged && !tab.initialized() {
		return errTableNotReady
	}
	// Do not attempt bonding if the table is closed. Could happen after tab.Close() and before udp.close()
	// You can't write to the closed DB.
	if tab.closed.Load() {
		return errTableNotReady
	}

	// Skip if we're really sure that this node is reachable and completed the bonding process.
	if tab.canAssumeBonded(n.ID, n.IP) {
		return nil
	}

	// Deduplicate concurrent Bond() calls for the same node.
	_, err, _ := tab.bondGroup.Do(n.ID.String(), func() (interface{}, error) {
		err := tab.pingpong(pinged, n)
		if err == nil {
			tab.addNode(n)
			tab.recordBonded(n)
		}
		return nil, err
	})
	return err
