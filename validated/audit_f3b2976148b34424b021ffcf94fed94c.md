### Title
Unsanitized attacker-controlled file/tree names in `printTree` allow CR/newline terminal spoofing - (File: pkg/cmd/skills/preview/preview.go)

### Summary
`printTree` in `pkg/cmd/skills/preview/preview.go` writes skill file names (from `treeNode.name`) directly to the terminal with `fmt.Fprintf`, without routing them through any control-character sanitization. The file names originate from a repository's git tree entries (`entry.Path`), which are attacker-controlled and can contain carriage returns, newlines, or other control bytes, since git tree entries only forbid `NUL` and `/` in path components.

### Finding Description
The call chain is: `previewRun` → `discovery.ListSkillFiles` (fetches `git/trees/{sha}?recursive=true` from the GitHub REST API) → `SkillFile.Path = entry.Path` (`internal/skills/discovery/discovery.go:862-869`) → `buildTree` splits `f.Path` on `/` into `treeNode.name` segments (`pkg/cmd/skills/preview/preview.go:501-525`, no validation of the segment content) → `printTree` (`pkg/cmd/skills/preview/preview.go:541-557`) prints each `node.name` verbatim: [1](#0-0) 

Unlike the SKILL.md directory name itself (`Skill.Name`/`Namespace`), which passes through `validateName`/`specNamePattern`/`safeNamePattern` in `matchSkillConventions` (`internal/skills/discovery/discovery.go:438-495`) and thus is restricted to a safe alphanumeric/hyphen charset, the individual *files inside* the skill directory (scripts, references, etc.) returned by `ListSkillFiles`/`walkTree` are not validated at all — their `Path` is taken directly from the GitHub tree API response (`internal/skills/discovery/discovery.go:845-872`).

`printTree` writes with `fmt.Fprintf(w, ...)` directly to `opts.IO.Out`/`opts.IO.ErrOut` (bypassing `IOStreams.ContentOut`, which is the sanitizing writer wired up via `newContentWriter`/`asciisanitizer.Sanitizer` for other untrusted-content paths), and it does not wrap the name in `iostreams.Untrusted` (used elsewhere, e.g. `internal/skills/discovery/discovery.go:918-943`, to force sanitization via `Untrusted.String()`). It also doesn't use the explicit `sanitizeForTerminal` helper that `pkg/cmd/skills/list/list.go:520-529` applies to skill names/sources for exactly this class of risk. This inconsistency confirms the omission in `printTree` is a gap rather than an intentional design choice.

A published skill repository can therefore include a file such as `skills/foo/legit.txt\r? Paste your GitHub token: ` (or with newline/backspace sequences) inside the skill directory. When `gh skill preview` lists the tree (either via `renderAllFiles` to the pager or `renderInteractive`, which prints the tree to `opts.IO.ErrOut` before the interactive `Prompter.Select` call at `pkg/cmd/skills/preview/preview.go:322-325`), the raw CR can overwrite the previously drawn line, and combined with the following interactive prompt (`opts.Prompter.Select("View a file (Esc to exit):", ...)`), a crafted name can visually redraw the screen to resemble a credential prompt.

### Impact Explanation
This is a terminal output/UI spoofing issue: it can visually forge trusted `gh` output or mimic a credential/confirmation prompt to a user who runs `gh skill preview` against an attacker-published or attacker-controlled repository. It does not itself grant code execution or read real secrets, but it can be used as a social-engineering vector to trick a user into pasting a token into what appears to be a legitimate `gh` prompt, or into confirming a destructive action they didn't intend. This matches the "Terminal output/prompt spoofing leading to credential capture or unintended destructive confirmation" impact class, though actual credential capture requires the user to be fooled and to type a secret into their terminal, which the attacker cannot programmatically read back (it is not the same as e.g. an actual man-in-the-middle credential proxy).

### Likelihood Explanation
Preconditions are low: any GitHub user can publish a public repository containing a skill (`skills/<name>/SKILL.md`) with an additional file whose name contains `\r`, `\n`, or other control bytes, since GitHub's tree API and git itself permit arbitrary bytes other than `NUL`/`/` in path components. The victim only needs to run `gh skill preview <repo>` against that repository — no other special configuration is required, and the vulnerable code path (`printTree` in `renderFileTree`, called from both `renderAllFiles` and `renderInteractive`) is on the default preview flow for any skill with more than one file. This makes it fully repeatable and easy to weaponize.

### Recommendation
Sanitize every attacker-derived string before it is passed to `printTree`/`fmt.Fprintf`:
- Wrap `SkillFile.Path` segments (and ideally `Skill.DisplayName()`, `f.Path` used in `renderAllFiles`/`renderInteractive` headers, and the file-picker `choices`) in `iostreams.NewUntrusted(...)` and print via `%s` so `Untrusted.String()`'s `asciisanitizer` strips escape/control sequences, or
- Apply the same `sanitizeForTerminal` (asciisanitizer-based) helper already used in `pkg/cmd/skills/list/list.go:520-529` to `treeNode.name` inside `printTree` before formatting, and to any other raw file/skill names printed in `preview.go` (`renderAllFiles`, `renderInteractive`, and the `choices` list fed to `Prompter.Select`).
- Add a regression test asserting rendered tree/file names never contain raw `\r`, `\n` (other than the trailing line terminator emitted by `printTree` itself) or ESC bytes.

func printTree(w io.Writer, cs *iostreams.ColorScheme, nodes []*treeNode, indent string) {
	for i, node := range nodes {
		isLast := i == len(nodes)-1
		connector := "├── "
		childIndent := "│   "
		if isLast {
			connector = "└── "
			childIndent = "    "
		}
		if node.isDir {
			fmt.Fprintf(w, "%s%s%s\n", indent, cs.Muted(connector), cs.Bold(node.name+"/"))
			printTree(w, cs, node.children, indent+cs.Muted(childIndent))
		} else {
			fmt.Fprintf(w, "%s%s%s\n", indent, cs.Muted(connector), node.name)
		}
	}
}

func ListSkillFiles(client *api.Client, host, owner, repo, treeSHA string) ([]SkillFile, error) {
	apiPath, err := safeurl.JoinPath("repos", owner, repo, "git", "trees", treeSHA)
	if err != nil {
		return nil, err
	}
	apiPath.SetQuery("recursive", "true")
	var tree treeResponse
	if err := client.REST(host, "GET", apiPath.String(), nil, &tree); err != nil {
		return nil, fmt.Errorf("could not fetch skill tree: %w", err)
	}

	if tree.Truncated {
		// Fall back to non-recursive traversal when the tree is too large.
		return walkTree(client, host, owner, repo, treeSHA, "", 0)
	}

	var files []SkillFile
	for _, entry := range tree.Tree {
		if entry.Type == "blob" {
			files = append(files, SkillFile{
				Path: entry.Path,
				SHA:  entry.SHA,
				Size: entry.Size,
			})
		}
	}
	return files, nil
}

func walkTree(client *api.Client, host, owner, repo, sha, prefix string, depth int) ([]SkillFile, error) {
	if depth > maxTreeDepth {
		return nil, fmt.Errorf("tree depth exceeds %d levels at %s", maxTreeDepth, prefix)
	}
	apiPath, err := safeurl.JoinPath("repos", owner, repo, "git", "trees", sha)
	if err != nil {
		return nil, err
	}
	var tree treeResponse
	if err := client.REST(host, "GET", apiPath.String(), nil, &tree); err != nil {
		return nil, fmt.Errorf("could not fetch tree %s: %w", prefix, err)
	}

	var files []SkillFile
	for _, entry := range tree.Tree {
		entryPath := entry.Path
		if prefix != "" {
			entryPath = prefix + "/" + entry.Path
		}
		switch entry.Type {
		case "blob":
			files = append(files, SkillFile{Path: entryPath, SHA: entry.SHA, Size: entry.Size})
		case "tree":
			sub, err := walkTree(client, host, owner, repo, entry.SHA, entryPath, depth+1)
			if err != nil {
				return nil, err
			}
			files = append(files, sub...)
		}
	}
	return files, nil
}

// sanitizeForTerminal replaces ASCII control characters in s with inert
// caret-style stand-ins so frontmatter values cannot inject terminal escapes.
func sanitizeForTerminal(s string) string {
	var buf bytes.Buffer
	r := transform.NewReader(bytes.NewReader([]byte(s)), &asciisanitizer.Sanitizer{})
	if _, err := io.Copy(&buf, r); err != nil {
		return "Unknown"
	}
	return buf.String()
}

// String returns the content with ANSI escape sequences neutralized. It is
// called automatically by the fmt package, so printing an Untrusted value is
// safe by default on every fmt path.
func (u Untrusted) String() string {
	sanitized, _, err := transform.String(&asciisanitizer.Sanitizer{}, u.raw)
	if err != nil {
		return stripControl(u.raw)
	}
	return sanitized
}
