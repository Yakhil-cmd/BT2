## Title
Uncontrolled recursion / stack-overflow DoS via deeply nested unit message payload during hash validation - (File: `string_utils.js`, `object_length.js`)

### Summary
`string_utils.js`'s `getSourceString()` and `getJsonSourceString()`, and `object_length.js`'s `getLength()`, are recursive tree-walking functions with **no recursion-depth guard**, unlike the formula/AA validators in this codebase (`formula/validation.js`, `formula/evaluation.js`, `aa_validation.js`) which all explicitly cap recursion via `MAX_DEPTH`/`depth > 100` checks and periodic `setImmediate` call-stack interruption. These unguarded functions are invoked on attacker-controlled, arbitrarily-nested JSON structures (e.g. a `data`/`profile`/`temp_data` message payload) during core unit validation, *before* any nesting-depth or complexity check is applied to that data — mirroring the curl FTP wildcard bug-class: a small, cheaply-crafted input drives unbounded recursive descent and can exhaust the call stack.

### Finding Description
When a joint (unit) is validated in `validation.js`, the code computes the payload hash of every message to make sure it wasn't tampered with, *before* dispatching to app-specific payload validation: [1](#0-0) 
This calls `objectHash.getBase64Hash(getPayloadForHash(m), ...)`, which for JSON-based units resolves to `string_utils.getJsonSourceString()` (and for legacy units, `getSourceString()`): [2](#0-1) 

Both serialization functions recurse into every array element / object value with **no depth limit whatsoever**: [3](#0-2) [4](#0-3) 

Likewise, headers/payload size accounting (`getHeadersSize`, `getTotalPayloadSize`) walks the whole unit recursively via `getLength()`, which is also unbounded: [5](#0-4) 
This is invoked immediately after the hash check, still prior to any depth screening: [6](#0-5) 

Crucially, the app-level payload check for `data`/`profile` messages only requires `typeof payload === "object"` — arrays qualify — with **no structural depth restriction**: [7](#0-6) 

By contrast, the codebase clearly recognizes this risk elsewhere and defends against it: the formula validator/evaluator caps AST recursion at depth 100 (`formula/validation.js:287`, `formula/evaluation.js:128`) and `aa_validation.js` enforces `MAX_DEPTH = 100` for AA-definition payload trees. There is also a purpose-built guard, `isTooDeeplyNestedOrHasTooManyNodes()`, used to bound device-message nesting in `network.js` (`isTooDeeplyNestedOrHasTooManyNodes(objDeviceMessage, 5, 100)`): [8](#0-7) 
and `isTooBigObj()` used to bound `json_parse()` results inside oscript formulas: [9](#0-8) 
but none of these guards are applied to the raw message payload of a `data`/`profile`/`temp_data` message (or an address/AA definition's non-formula literal fields) before it is fed into `getSourceString`/`getJsonSourceString`/`getLength` for hashing and size accounting during core unit validation.

### Impact Explanation
An unprivileged unit poster can submit a unit containing a `data` (or `profile`/`temp_data`) message whose payload is a deeply nested array/object (e.g. `[`×N `1` `]`×N, JSON-valid and only a few bytes per nesting level, well under `MAX_UNIT_LENGTH`). Every node — witness, hub, full node, or light client — that receives and validates this joint will recurse through `getPayloadForHash` → `getJsonSourceString`/`getSourceString` (and shortly after through `getLength` for commission accounting) with recursion depth proportional to the nesting depth chosen by the attacker. With sufficient nesting (a few thousand to tens of thousands of levels, trivially fitting in a unit well under size limits), this exceeds V8's call-stack limit and throws/crashes with "Maximum call stack size exceeded," aborting the validation process for that node. If unhandled (this occurs deep inside synchronous helper calls invoked from `validate()`, not wrapped the way async validation errors are), this can crash the Node.js process handling unit validation across the network — a network-wide inability to validate/confirm new units, i.e., a denial of service analogous to the curl uncontrolled-recursion CVE class.

### Likelihood Explanation
High likelihood: the attack requires posting a single ordinary unit with a `data`/`profile` message — no special privileges, no AA trigger, no asset issuance, just a standard message type reachable by any unprivileged address. The payload size needed to reach dangerous recursion depth is small (well within normal unit size limits), and the vulnerable code path (`getPayloadForHash`/hash verification) runs unconditionally as part of basic joint validation for every unit every node processes, before any AA-specific complexity/depth protections (which exist only for oscript/AA-definition trees) can apply.

### Recommendation
Apply an early, cheap depth/size guard (e.g. the existing `isTooDeeplyNestedOrHasTooManyNodes()` / `isTooBigObj()` utilities) to every message's `payload` (and to the whole `objUnit`/`objHeader`) immediately after JSON parsing and before `getPayloadForHash`, `getSourceString`, `getJsonSourceString`, or `getLength` are invoked. Alternatively, convert `extractComponents`/`stringify`/`_getLength` in `string_utils.js`/`object_length.js` to explicit-stack iterative algorithms, or add a maximum-depth parameter (mirroring `formula/validation.js`'s `depth > 100` check) that aborts with a validation error rather than recursing unbounded.

### Proof of Concept
1. Construct a unit with a single `data` message whose payload is a deeply nested array, e.g.:
   `payload = JSON.parse('['.repeat(50000) + '1' + ']'.repeat(50000))`
2. Compute `payload_hash` normally (this requires running the same recursive hashing function once locally, which will itself need to succeed or the attacker can adjust depth until it just barely still computes locally on a machine with a larger stack size / different stack settings, then submit to network nodes with default, smaller stack limits) — or, more directly, submit the raw joint over the wire; each receiving node independently calls `getPayloadForHash`/`getSourceString` on the same structure.
3. On any receiving node, `validate()` in `validation.js` reaches the payload-hash verification loop (`validation.js:219-243`) and calls into `string_utils.getJsonSourceString`/`getSourceString`, which recurses `extractComponents`/`stringify` 50,000 levels deep, exceeding V8's default stack and throwing `RangeError: Maximum call stack size exceeded`, crashing or destabilizing the validation flow for that unit across all nodes that receive it.

function getSourceString(obj) {
	var arrComponents = [];
	function extractComponents(variable){
		if (variable === null)
			throw Error("null value in "+JSON.stringify(obj));
		switch (typeof variable){
			case "string":
				if (variable.includes(STRING_JOIN_CHAR))
					throw Error("00 byte in string value in " + JSON.stringify(obj));
				arrComponents.push("s", variable);
				break;
			case "number":
				if (!isFinite(variable))
					throw Error("invalid number: " + variable);
				arrComponents.push("n", variable.toString());
				break;
			case "boolean":
				arrComponents.push("b", variable.toString());
				break;
			case "object":
				if (Array.isArray(variable)){
					if (variable.length === 0)
						throw Error("empty array in "+JSON.stringify(obj));
					arrComponents.push('[');
					for (var i=0; i<variable.length; i++)
						extractComponents(variable[i]);
					arrComponents.push(']');
				}
				else{
					var keys = Object.keys(variable).sort();
					if (keys.length === 0)
						throw Error("empty object in "+JSON.stringify(obj));
					keys.forEach(function(key){
						if (typeof variable[key] === "undefined")
							throw Error("undefined at "+key+" of "+JSON.stringify(obj));
						if (key.includes(STRING_JOIN_CHAR))
							throw Error("00 byte in object key in " + JSON.stringify(obj));
						arrComponents.push(key);
						extractComponents(variable[key]);
					});
				}
				break;
			default:
				throw Error("getSourceString: unknown type="+(typeof variable)+" of "+variable+", object: "+JSON.stringify(obj));
		}
	}

	extractComponents(obj);
	return arrComponents.join(STRING_JOIN_CHAR);
}

function getJsonSourceString(obj, bAllowEmpty) {
	let cache = new WeakMap();  // object to stringified result
	function stringify(variable){
		if (variable === null)
			throw Error("null value in "+JSON.stringify(obj));
		switch (typeof variable){
			case "string":
				return toWellFormedJsonStringify(variable);
			case "number":
				if (!isFinite(variable))
					throw Error("invalid number: " + variable);
			case "boolean":
				return variable.toString();
			case "object":
				// return cached result if already processed
				if (cache.has(variable))
					return cache.get(variable);
				let result;
				if (Array.isArray(variable)){
					if (variable.length === 0 && !bAllowEmpty)
						throw Error("empty array in "+JSON.stringify(obj));
					result = '[' + variable.map(stringify).join(',') + ']';
				}
				else{
					var keys = Object.keys(variable).sort();
					if (keys.length === 0 && !bAllowEmpty)
						throw Error("empty object in "+JSON.stringify(obj));
					result = '{' + keys.map(function(key){ return toWellFormedJsonStringify(key)+':'+stringify(variable[key]) }).join(',') + '}';
				}
				cache.set(variable, result);  // memoize for future references
				return result;
			default:
				throw Error("getJsonSourceString: unknown type="+(typeof variable)+" of "+variable+", object: "+JSON.stringify(obj));
		}
	}

	return stringify(obj);
}

function isTooBigObj(obj, { depthLimit = 100, nodesLimit = 10000, lengthLimit = 1000000 }) {
	let nodeCount = 0;
	let length = 0;

	function check(variable, depth){
		if (depth > depthLimit || nodeCount > nodesLimit || length > lengthLimit)
			return true;
		if (typeof variable === "string")
			length += variable.length;
		else if (typeof variable === "number" || typeof variable === "boolean")
			length += variable.toString().length;
		else if (variable === null)
			length += 4; // "null"
		else if (typeof variable !== "object")
			throw Error("isTooBigObj: unexpected type=" + (typeof variable) + " of " + variable);
		if (length > lengthLimit)
			return true;
		if (typeof variable !== "object" || variable === null)
			return false;
		if (Array.isArray(variable)) {
			nodeCount += variable.length;
			for (let v of variable)
				if (check(v, depth + 1))
					return true;
		}
		else {
			const keys = Object.keys(variable);
			nodeCount += keys.length;
			length += keys.reduce((sum, key) => sum + key.length, 0);
			for (let key in variable)
				if (check(variable[key], depth + 1))
					return true;
		}
		return false;
	}

	return check(obj, 1);
}

function getLength(value, bWithKeys) {
	let cache = new WeakMap();  // object to length
	function _getLength(value) {
		if (value === null)
			return 0;
		switch (typeof value) {
			case "string":
				return value.length;
			case "number":
				if (!isFinite(value))
					throw Error("invalid number: " + value);
				return 8;
				//return value.toString().length;
			case "object":
				// return cached result if already processed
				if (cache.has(value))
					return cache.get(value);
				var len = 0;
				if (Array.isArray(value))
					value.forEach(function (element) {
						len += _getLength(element);
					});
				else
					for (var key in value) {
						if (!Object.prototype.hasOwnProperty.call(value, key))
							throw Error("object has non-own property " + key + " in " + JSON.stringify(value));
						if (typeof value[key] === "undefined")
							throw Error("undefined at " + key + " of " + JSON.stringify(value));
						if (bWithKeys)
							len += key.length;
						len += _getLength(value[key]);
					}
				cache.set(value, len);  // memoize for future references
				return len;
			case "boolean":
				return 1;
			default:
				throw Error("unknown type=" + (typeof value) + " of " + value);
		}
	}
	return _getLength(value);
}
