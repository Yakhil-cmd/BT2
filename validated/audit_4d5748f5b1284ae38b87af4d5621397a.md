### Title
Division by Zero in `NextMagmaBlockBaseFee` via Governance-Settable `kip71.gastarget = 0` Causes Chain Halt — (`File: params/kip71_config.go`)

---

### Summary

The `kip71.gastarget` governance parameter has no non-zero format check, allowing it to be voted to `0`. When `GasTarget == 0` and any parent block consumed gas, `NextMagmaBlockBaseFee` performs an integer division by zero (`x.Div(x, new(big.Int).SetUint64(gasTarget))`), causing a Go runtime panic. This panic propagates through block validation (`VerifyMagmaHeader`), block production, and the tx pool, halting consensus on all honest nodes.

---

### Finding Description

**Unguarded divisor in `NextMagmaBlockBaseFee`**

`params/kip71_config.go` lines 100–121 compute the base-fee delta by dividing by `gasTarget`:

```go
// parentGasUsed > gasTarget branch (line 100-103)
gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
y := x.Div(x, new(big.Int).SetUint64(gasTarget))   // ← DIV BY ZERO if gasTarget == 0
baseFeeDelta := math.BigMax(x.Div(y, baseFeeDenominator), common.Big1)

// parentGasUsed < gasTarget branch (line 118-121)
gasUsedDelta := new(big.Int).SetUint64(gasTarget - parentGasUsed)
x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
y := x.Div(x, new(big.Int).SetUint64(gasTarget))   // ← DIV BY ZERO if gasTarget == 0
baseFeeDelta := x.Div(y, baseFeeDenominator)
``` [1](#0-0) 

The only safe branch is `parentGasUsed == gasTarget` (line 90), which returns early. When `gasTarget == 0`, this branch is only taken when `parentGasUsed == 0` (an empty block). Any block with non-zero gas usage causes a panic.

**`kip71.gastarget` accepts zero via governance**

`Kip71GasTarget` in `kaiax/gov/param.go` uses `noopFormatChecker`, which accepts any `uint64` value including `0`:

```go
Kip71GasTarget: {
    Canonicalizer: uint64Canonicalizer,
    FormatChecker: noopFormatChecker,   // ← no zero-check
    ...
    DefaultValue: uint64(30000000),
},
``` [2](#0-1) 

By contrast, `Kip71BaseFeeDenominator` explicitly rejects zero:

```go
Kip71BaseFeeDenominator: {
    FormatChecker: func(cv any) bool {
        v, ok := cv.(uint64)
        return ok && v != 0   // ← zero explicitly rejected
    },
``` [3](#0-2) 

The `BaseFeeDenominator == 0` case also has a runtime fallback in `NextMagmaBlockBaseFee` (lines 71–76), but **`GasTarget == 0` has no such fallback**. [4](#0-3) 

**Call sites that panic**

`NextMagmaBlockBaseFee` is called in three production paths:

1. `blockchain/block_validator.go` → `VerifyMagmaHeader` — called on every imported block during consensus validation.
2. `work/worker.go` line 382 — called during block production.
3. `blockchain/tx_pool.go` — called to filter pending transactions. [5](#0-4) 

---

### Impact Explanation

After the governance change takes effect (next epoch), every block whose parent consumed any gas triggers a Go runtime panic in `NextMagmaBlockBaseFee`. Because `VerifyMagmaHeader` is called during block import and validation, all honest nodes reject every non-empty block, causing a **consensus halt**. Block production also fails. The chain is permanently stalled until a hard-coded patch is deployed. This matches the "system becomes fully blocked" impact class from the external report.

---

### Likelihood Explanation

In `single` governance mode (Mainnet/Kairos), only the designated governing node can vote. A misconfiguration or key compromise of that node is sufficient. In `none` mode, any GC member can vote. The `noopFormatChecker` provides no on-chain rejection of `0`, so the vote is accepted and ratified normally. The impact is irreversible without a coordinated hard fork.

---

### Recommendation

Add a non-zero format check to `Kip71GasTarget`, mirroring the existing check on `Kip71BaseFeeDenominator`:

```go
Kip71GasTarget: {
    Canonicalizer: uint64Canonicalizer,
    FormatChecker: func(cv any) bool {
        v, ok := cv.(uint64)
        return ok && v != 0   // prevent division by zero in NextMagmaBlockBaseFee
    },
    ...
},
```

Additionally, add a defensive guard in `NextMagmaBlockBaseFee` analogous to the existing `BaseFeeDenominator == 0` guard:

```go
if kc.GasTarget == 0 {
    return makeEvenByFloor(lowerBoundBaseFee)
}
```

---

### Proof of Concept

1. In `none` governance mode, any GC member calls `governance_vote("kip71.gastarget", 0)`.
2. The vote passes `noopFormatChecker` and is inscribed in `header.Vote`.
3. At the next epoch block, the ratification is written to `header.Governance`; the parameter takes effect at the following epoch.
4. From that epoch onward, every block where `parentGasUsed > 0` causes `NextMagmaBlockBaseFee` to execute `new(big.Int).SetUint64(0)` as the divisor in `x.Div(x, new(big.Int).SetUint64(gasTarget))`.
5. Go's `(*big.Int).Div` panics on a zero divisor, crashing the node process.
6. All honest nodes crash on the same block, halting the chain. [6](#0-5) [2](#0-1)

func (kc *KIP71Config) VerifyMagmaHeader(headerBaseFee *big.Int, parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) error {
	if headerBaseFee == nil {
		return fmt.Errorf("header is missing baseFee")
	}
	// Verify the baseFee is correct based on the parent header.
	expectedBaseFee := kc.NextMagmaBlockBaseFee(parentHeaderNumber, parentHeaderBaseFee, parentHeaderGasUsed)
	if headerBaseFee.Cmp(expectedBaseFee) != 0 {
		return fmt.Errorf("invalid baseFee: have %s, want %s, parentBaseFee %s, parentGasUsed %d",
			headerBaseFee, expectedBaseFee, parentHeaderBaseFee, parentHeaderGasUsed)
	}
	return nil
}
