### Title
Uncontrolled Recursion in `getSourceString`/`getJsonSourceString` Causing Unrecoverable Process Crash via Unbounded Stack Growth - ([File: string_utils.js])

### Summary
`string_utils.js` exposes two recursive serialization helpers, `getSourceString()` and `getJsonSourceString()`, which are used by `object_hash.js` to compute chashes/hashes for units, AA definitions, and other DAG-visible objects. Unlike the recursive AST evaluators in `formula/evaluation.js` and `formula/validation.js` (which explicitly track `depth`/`count` and bail out with `"maximum depth exceeded"`), these two serialization functions have **no depth counter, no node-count limit, and no `try/catch` safety net** around their recursive calls.

### Finding Description
`getSourceString()` (`string_utils.js:11-60`) and `getJsonSourceString()` (`string_utils.js:220-257`) both define an inner recursive function (`extractComponents`/`stringify`) that recurses into every array element or object member with **zero bound**: [1](#0-0) [2](#0-1) 

These are invoked by `object_hash.js` for:
- `getChash160()` — used to derive/verify addresses, including AA addresses derived from ojson definitions (`getJsonSourceString` branch): [3](#0-2) 
- `getUnitHash()` / `getUnitContentHash()` — computed on every incoming unit's stripped/naked content, which includes attacker-controlled message payloads (data, definition, AA trigger data, etc.): [4](#0-3) 
- `getUnitHashToSign()` / `getSignedPackageHashToSign()`: [5](#0-4) 

Elsewhere in the codebase, recursion over user/attacker-supplied AA-related data is explicitly guarded:
- `formula/evaluation.js`'s `evaluate()` uses `count % 100` batching via `setImmediate` to avoid deep call stacks: [6](#0-5) 
- `formula/validation.js`'s `evaluate()` tracks `depth` and returns `"maximum depth exceeded"` once `depth > 100`: [7](#0-6) 
- `aa_validation.js`'s `validate()` explicitly checks `depth > MAX_DEPTH`: [8](#0-7) 
- `string_utils.isTooDeeplyNestedOrHasTooManyNodes()` / `isTooBigObj()` bound object depth/size to 100/10000 nodes for AA-formula-constructed objects (dictionary/array literals): [9](#0-8) 

Crucially, these depth/size guards apply to objects **constructed inside the AA formula evaluator**, not to the *raw unit content* (messages, payloads, ojson AA definitions) that arrives from the network before formula evaluation ever runs. `getSourceString`/`getJsonSourceString` are called directly on this raw content when computing hashes/chashes — a step that necessarily happens very early in unit processing (to verify address-definition matches and unit integrity) and is not preceded by any equivalent depth check.

### Impact Explanation
An unprivileged unit poster can craft a unit whose message payload (or an ojson AA definition being registered) contains an extremely deeply nested array/object (e.g., tens of thousands of nesting levels). When the node computes `getUnitHash`/`getUnitContentHash`/`getChash160` on this content, the unbounded recursion in `extractComponents`/`stringify` will exhaust the V8 call stack. In Node.js this manifests as an uncaught `RangeError: Maximum call stack size exceeded` deep inside a chain of validation/hashing calls; if this occurs outside a local `try/catch` (which is not guaranteed for every caller of `getChash160`/`getUnitHash`), it propagates as an uncaught exception and crashes the node process — a node that can no longer validate or confirm any unit is a network-availability failure, matching the "network unable to confirm new units" impact class.

### Likelihood Explanation
Likelihood is moderate-to-high: constructing a deeply nested JSON/ojson payload is trivial and can be embedded in any message payload or an AA definition being posted by any unprivileged party. No privileged role, DAG position, or timing condition is required — a single crafted unit is sufficient to trigger the hashing path on an honest node processing it.

### Recommendation
Add explicit depth/node-count bounds (mirroring `isTooDeeplyNestedOrHasTooManyNodes`/`isTooBigObj`) inside `getSourceString()` and `getJsonSourceString()` themselves, and/or validate the depth/size of raw unit/message/definition content before it ever reaches `object_hash.js`. Additionally wrap hash computation call-sites in `try/catch` to convert any residual `RangeError` into a controlled validation failure rather than an uncaught process-terminating exception.

### Proof of Concept
```js
// conceptual PoC – not exact wire format
var deep = 1;
for (var i = 0; i < 100000; i++) deep = [deep];   // 100000-level nested array
var objUnit = {
    version: constants.version,
    messages: [{ app: 'data', payload: { d: deep } }],
    // ... other required unit fields
};
// When the node validates this unit and computes:
object_hash.getUnitHash(objUnit);      // -> getSourceString(getStrippedUnit(objUnit))
// extractComponents() recurses 100000 levels deep with no bound,
// exhausting the call stack and potentially crashing the process.
```

Note: unlike the .NET `StackOverflowException` referenced in the original Scriban report, Node.js raises a catchable `RangeError`; the severity of this analog therefore depends on whether every call path to `getUnitHash`/`getChash160`/`getJsonSourceString` is wrapped in `try/catch` — this could not be fully confirmed for all call sites within the available investigation, and should be verified before treating this as conclusively High severity.

function isTooDeeplyNestedOrHasTooManyNodes(obj, depthLimit = 100, nodesLimit = 10000) {
	let nodeCount = 0;

	function check(variable, depth){
		if (depth > depthLimit || nodeCount > nodesLimit)
			return true;
		if (variable === null || typeof variable !== "object")
			return false;
		if (Array.isArray(variable)) {
			nodeCount += variable.length;
			for (let v of variable)
				if (check(v, depth + 1))
					return true;
		}
		else {
			nodeCount += Object.keys(variable).length;
			for (let key in variable)
				if (check(variable[key], depth + 1))
					return true;
		}
		return false;
	}

	return check(obj, 1);
}

function getUnitHashToSign(objUnit) {
	var objNakedUnit = getNakedUnit(objUnit);
	for (var i=0; i<objNakedUnit.authors.length; i++)
		delete objNakedUnit.authors[i].authentifiers;
	var sourceString = (typeof objUnit.version === 'undefined' || objUnit.version === constants.versionWithoutTimestamp) ? getSourceString(objNakedUnit) : getJsonSourceString(objNakedUnit);
	return crypto.createHash("sha256").update(sourceString, "utf8").digest();
}

function getSignedPackageHashToSign(signedPackage) {
