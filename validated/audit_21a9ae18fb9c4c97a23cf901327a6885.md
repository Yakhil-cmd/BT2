### Title
Missing deadline check in `ExtractTxBundles` allows expired gasless swap bundles to be built, causing proposer KAIA loss — (`kaiax/gasless/impl/builder.go`)

---

### Summary

The gasless module (KIP-247) validates a swap transaction's `deadline` field only at txpool admission time (`checkBalanceForSwap`), but never re-validates it at block-building time (`ExtractTxBundles` → `IsExecutable` → `VerifyExecutable`). A swap transaction whose deadline expires while sitting in the pending pool will still be bundled by the proposer. The proposer's lend transaction executes and transfers KAIA to the user, but the `swapForGas()` call reverts on-chain due to the expired deadline, leaving the proposer unrepaid.

---

### Finding Description

The gasless transaction flow bundles three transactions atomically: `[LendTx, ApproveTx?, SwapTx]`. The `LendTx` is generated by the proposer and sends KAIA to the user to cover gas. The `SwapTx` calls `GaslessSwapRouter.swapForGas(token, amountIn, minAmountOut, amountRepay, deadline)` which is expected to repay the proposer.

The `deadline` field is validated at txpool admission in `checkBalanceForSwap`: [1](#0-0) 

This check uses `g.Chain.CurrentBlock().Time()` — the **last finalized block's timestamp** — not the pending block's timestamp. The pending block will have a timestamp of at least `CurrentBlock().Time() + 1`.

At block-building time, `ExtractTxBundles` calls `IsExecutable`: [2](#0-1) 

`IsExecutable` delegates to `VerifyExecutable`, which checks sender, nonce, token, and repay amount — but **never checks the deadline**: [3](#0-2) 

The deadline field is decoded and stored in `SwapArgs.Deadline`: [4](#0-3) 

but is never read inside `VerifyExecutable`.

**Attack path:**

1. User submits a `SwapTx` with `deadline = CurrentBlock().Time() + N` (small N, e.g. 2 seconds).
2. `checkBalanceForSwap` passes: `deadline >= CurrentBlock().Time()`.
3. Transaction sits in the pending pool for N+1 blocks.
4. Proposer calls `ExtractTxBundles`; `IsExecutable` passes (no deadline check).
5. Bundle `[LendTx, SwapTx]` is included in the block.
6. `LendTx` executes: proposer transfers KAIA to user.
7. `SwapTx` executes: `GaslessSwapRouter.swapForGas()` checks `block.timestamp <= deadline` → reverts.
8. Proposer's lent KAIA is not repaid.

The off-by-one between the txpool check (`deadline >= CurrentBlock().Time()`) and the actual block timestamp (`CurrentBlock().Time() + 1`) also creates a guaranteed 1-block window where a transaction with `deadline == CurrentBlock().Time()` passes txpool admission but will always revert on-chain.

---

### Impact Explanation

**High.** The block proposer (a validator) loses KAIA that was lent to the user. The `LendTx` is an unconditional transfer generated by the proposer's node key. If the `SwapTx` reverts, the lent amount is not recovered. This is an unauthorized transfer of KAIA from the proposer's balance with no recourse.

---

### Likelihood Explanation

**Low-to-Medium.** The window requires a swap transaction to remain in the pending pool past its deadline. Given `PendingTimeout = 10 * time.Second` and `QueueTimeout = 10 * time.Second`: [5](#0-4) 

a user setting `deadline = CurrentBlock().Time() + 5` and the transaction sitting for 6 blocks (6 seconds) is realistic under normal network conditions. The off-by-one case (`deadline == CurrentBlock().Time()`) is deterministic and requires no waiting.

---

### Recommendation

Add a deadline check inside `VerifyExecutable` (or directly in `ExtractTxBundles`) using the pending block's timestamp, not the last finalized block's timestamp:

```go
// In VerifyExecutable or ExtractTxBundles:
pendingTime := g.Chain.CurrentBlock().Time().Uint64() + 1 // conservative lower bound
if swapArgs.Deadline.Uint64() < pendingTime {
    return ErrSwapDeadlineExpired
}
```

Alternatively, add the check in `ExtractTxBundles` before creating the bundle, so expired swap transactions are silently skipped rather than bundled.

---

### Proof of Concept

1. Deploy `GaslessSwapRouter` and register it in the Registry.
2. User submits `SwapTx` with `deadline = chain.CurrentBlock().Time()` (exactly equal to last block time).
3. `checkBalanceForSwap` passes: `deadline.Cmp(CurrentBlock().Time()) < 0` is `false`.
4. Proposer calls `ExtractTxBundles`; `IsExecutable` → `VerifyExecutable` passes (no deadline check).
5. Bundle `[LendTx, SwapTx]` is built into the next block (timestamp = `CurrentBlock().Time() + 1`).
6. `LendTx` succeeds; proposer balance decreases by lend amount.
7. `SwapTx` reverts: `block.timestamp (T+1) > deadline (T)`.
8. Proposer's lend amount is permanently lost.

func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
