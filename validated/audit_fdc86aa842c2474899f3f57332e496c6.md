### Title
`kip71.gastarget` Governance Parameter Lacks Zero-Guard, Causing Division-by-Zero Panic in `NextMagmaBlockBaseFee` and Chain Halt - (File: `params/kip71_config.go`)

### Summary
The `kip71.gastarget` governance parameter uses `noopFormatChecker`, accepting any `uint64` value including zero. When `GasTarget = 0` takes effect, every subsequent block whose parent used any gas triggers an unguarded integer division by zero inside `NextMagmaBlockBaseFee`, panicking all honest nodes and permanently halting consensus. The sibling parameter `kip71.basefeedenominator` has an explicit `v != 0` guard for the same reason, confirming the developers are aware of the pattern but omitted it for `GasTarget`.

### Finding Description

**Missing bound check on `Kip71GasTarget`**

In `kaiax/gov/param.go`, the `Kip71GasTarget` entry uses `noopFormatChecker`, which unconditionally returns `true` for any canonicalized value: [1](#0-0) 

By contrast, `Kip71BaseFeeDenominator` — which is also used as a divisor — has an explicit non-zero guard: [2](#0-1) 

The `checkConsistency` function in `kaiax/gov/headergov/impl/header.go` performs no additional check for `Kip71GasTarget` votes; it falls into the default "return nil" branch: [3](#0-2) 

**Division-by-zero in `NextMagmaBlockBaseFee`**

Once `GasTarget = 0` is committed to chain state, every call to `NextMagmaBlockBaseFee` for a block whose parent consumed any gas reaches the following lines: [4](#0-3) 

`new(big.Int).SetUint64(gasTarget)` is zero, so `x.Div(x, ...)` panics with a runtime division-by-zero. The only escape hatch before this point is the shortcut at line 94 (`parentBaseFee == upperBoundBaseFee`), which is not guaranteed to hold.

The same panic exists in the decreasing-fee branch: [5](#0-4) 

`NextMagmaBlockBaseFee` is called from `VerifyMagmaHeader` during block validation: [6](#0-5) 

Every node that attempts to validate or produce a block after the governance change takes effect will panic.

### Impact Explanation

All honest nodes crash simultaneously when the first post-governance block with non-zero gas usage is validated. This constitutes a **consensus divergence** (all honest nodes halt) and **persistent inability to execute canonical state transitions, transfers, or settlements**. No new blocks can be produced; the chain is permanently halted until a manual hotfix is deployed.

### Likelihood Explanation

In `governance.governancemode = "single"`, the single governing node can unilaterally cast the vote. In `"none"` mode, any validator can cast a vote. The vote passes all existing format and consistency checks without error. The effect is delayed by one epoch (the governance activation lag), giving no on-chain warning before the chain halts.

### Recommendation

Add a non-zero guard to `Kip71GasTarget`, mirroring the existing guard on `Kip71BaseFeeDenominator`:

```go
Kip71GasTarget: {
    Canonicalizer: uint64Canonicalizer,
    FormatChecker: func(cv any) bool {
        v, ok := cv.(uint64)
        return ok && v != 0   // GasTarget is used as a divisor; zero panics
    },
    ...
},
```

Additionally, add a defensive zero-check inside `NextMagmaBlockBaseFee` before the division:

```go
if gasTarget == 0 {
    return makeEvenByFloor(upperBoundBaseFee)
}
```

### Proof of Concept

1. In a Magma-enabled chain with `governance.governancemode = "none"` (or "single"), a validator (or the governing node) submits a governance vote: `kip71.gastarget = 0`.
2. The vote is accepted — `noopFormatChecker` returns `true`, `checkConsistency` returns `nil`.
3. After the epoch boundary, the governance change is committed: `GasTarget = 0`.
4. The next block is produced with any non-zero `gasUsed` (e.g., a single value-transfer transaction).
5. Every node calls `VerifyMagmaHeader` → `NextMagmaBlockBaseFee` with `parentGasUsed > 0`.
6. `parentGasUsed > gasTarget` (i.e., `> 0`) is true; the shortcut at line 94 does not fire (current `parentBaseFee` is below `upperBoundBaseFee`).
7. `x.Div(x, new(big.Int).SetUint64(0))` panics: **runtime error: integer divide by zero**.
8. All nodes crash. The chain halts permanently.

func (kc *KIP71Config) VerifyMagmaHeader(headerBaseFee *big.Int, parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) error {
	if headerBaseFee == nil {
		return fmt.Errorf("header is missing baseFee")
	}
	// Verify the baseFee is correct based on the parent header.
	expectedBaseFee := kc.NextMagmaBlockBaseFee(parentHeaderNumber, parentHeaderBaseFee, parentHeaderGasUsed)
	if headerBaseFee.Cmp(expectedBaseFee) != 0 {
		return fmt.Errorf("invalid baseFee: have %s, want %s, parentBaseFee %s, parentGasUsed %d",
			headerBaseFee, expectedBaseFee, parentHeaderBaseFee, parentHeaderGasUsed)
	}
	return nil
}
