### Title
Unchecked accrual valuation can permanently freeze an overgrown market - (File: `common/src/rates/simulate.rs`)

### Summary
The pool calculates total scaled debt and supply before applying the configured index ceilings. Once a market's scaled balances are large enough, normal index growth makes `scaled * index` exceed `i128::MAX`; every subsequent operation that synchronizes that market reverts, leaving suppliers unable to withdraw and borrowers or liquidators unable to reduce debt.

### Finding Description
`accrue_step` first converts the market-wide scaled balances to RAY values through `scaled_to_original`, then derives utilization and the next index from those values. [1](#0-0)  The conversion is a checked `Ray` multiplication rather than a saturating or bounded one. [2](#0-1)  Although `update_borrow_index` caps the next index afterward, that cap does not protect the earlier `borrowed * borrow_index` calculation in `calculate_supplier_rewards`. [3](#0-2) 

All ordinary pool legs load an interest-synced market before mutating it. [4](#0-3)  In particular, borrow, withdraw, and repay all reach `ops::load_leg`, which invokes `synced_market`. [5](#0-4) [6](#0-5) [7](#0-6)  Liquidation and bad-debt cleanup also synchronize each touched market before applying seizure entries. [8](#0-7) 

### Impact Explanation
An unprivileged borrower can push an existing large market to very high utilization through `Controller::borrow`; interest then does the rest. [9](#0-8)  Once the aggregate scaled debt and borrow index cross the representable RAY-value boundary, `MathOverflow` is raised before the borrow-index ceiling can make accrual a harmless no-op. [10](#0-9)  Because the same accrual precedes repayment, withdrawal, liquidation, seizure, and revenue accounting, the market cannot recover through normal user or keeper actions. [4](#0-3) [8](#0-7)  This permanently freezes every supplier's funds in that market and blocks repayment or liquidation of its debt.

### Likelihood Explanation
The trigger needs a market whose admitted caps and real liquidity permit aggregate scaled balances near the `i128` RAY-value domain, plus sustained high utilization long enough for index growth to cross the boundary. An attacker cannot create the market or lift its caps, but can use the permissionless `supply`, `borrow`, and `update_indexes` paths to establish the required state once governance has admitted such a market. [11](#0-10) [12](#0-11)  The repository's regression test reaches the failure with a billion whole 18-decimal units at 98% utilization and confirms that withdrawal and repayment subsequently fail with `MathOverflow`. [13](#0-12) 

### Recommendation
Bound accrual by checking `borrowed * borrow_index` and `supplied * supply_index` before multiplication, or represent market totals in a wider integer type during accrual. If the current step would exceed the representable domain, clamp the borrow index before deriving supplier rewards rather than reverting. Also enforce market-entry caps below the arithmetic ceiling so no admitted cap can place total scaled exposure within reach of this cliff.

### Proof of Concept
The existing test `a_whale_market_at_sustained_high_utilization_hits_the_ray_value_ceiling_before_the_index_cap` is a direct reproduction: it supplies one billion whole 18-decimal tokens, borrows 98%, advances time, observes `update_indexes` fail with `MATH_OVERFLOW` below `MAX_BORROW_INDEX_RAY`, and then confirms both withdrawal and repayment hit the same failure. [13](#0-12)

```rust
pub fn calculate_supplier_rewards(
    env: &Env,
    params: &MarketParams,
    borrowed: Ray,
    new_borrow_index: Ray,
    old_borrow_index: Ray,
) -> (Ray, Ray) {
    let old_total_debt = borrowed.mul(env, old_borrow_index);
    let new_total_debt = borrowed.mul(env, new_borrow_index);

    let accrued_interest = new_total_debt.checked_sub(env, old_total_debt);

    let protocol_fee = params.reserve_factor.apply_to_ray(env, accrued_interest);
    let supplier_rewards = accrued_interest.checked_sub(env, protocol_fee);
```

```rust
pub(crate) fn apply(env: &Env, entry: &PoolSeizeEntry) -> MarketStateSnapshot {
    require_nonneg_amount(env, entry.position.scaled_amount);
    let mut cache = ops::synced_market(env, &entry.hub_asset);
    let position = Ray::from(entry.position.scaled_amount);

    match entry.side {
        AccountPositionType::Borrow => {
            let bad_debt = cache.unscale_borrow_ceil_ray(position);
            interest::apply_bad_debt_to_supply_index(&mut cache, bad_debt);
            cache.burn_debt(position);
        }
        AccountPositionType::Deposit => {
            cache.absorb_supply_as_revenue(position);
        }
    }

    cache.commit()
```

```rust
fn a_whale_market_at_sustained_high_utilization_hits_the_ray_value_ceiling_before_the_index_cap() {
    let mut t = LendingTest::new()
        .with_market(big("BIG18", 18, xlm_curve()))
        .with_market(col())
        .with_max_utilization_disabled_all_markets()
        .build();
    lift_caps(&t, "BIG18", 18);
    lift_caps(&t, "COL", 7);
    let principal = BILLION * 10i128.pow(18);
    t.supply_raw(BOB, "BIG18", principal);
    let debt = principal / 100 * 98;
    t.supply_raw(ALICE, "COL", BILLION * 10_000_000 * 3);
    t.borrow_raw(ALICE, "BIG18", debt);

    let mut years = 0u32;
    let failure = loop {
        years += 1;
        assert!(
            years <= 40,
            "no cliff within 40 years; the bound in docs/reference/formulas.md is wrong"
        );
        t.advance_time(YEAR_SECS);
        if let Err(e) = t.try_update_indexes_for(&["BIG18"]) {
            break e;
        }
    };
    let failed: Result<(), soroban_sdk::Error> = Err(failure);
    assert_contract_error(failed, errors::MATH_OVERFLOW);
    let last = book(&t, "BIG18");
    assert!(
        last.borrow_index < MAX_BORROW_INDEX_RAY,
        "the index cap did not engage before the value overflow"
    );
    // The market is frozen: exits and repayments accrue first and hit the same panic.
    assert_contract_error(t.try_withdraw_raw(BOB, "BIG18", 1), errors::MATH_OVERFLOW);
    assert_contract_error(t.try_repay(ALICE, "BIG18", 1.0), errors::MATH_OVERFLOW);
```
