**Step 1 — `checkBalanceForSwap` allowance-skip logic** [1](#0-0) 

`senderNonce = getCurrentStateNonce(sender)` reads the **committed** state (set in `PostInsertBlock`). If committed nonce = N and the swap tx has nonce = N+1, then `noApproveTxPreceeds = (N+1 == N) = false` → the allowance check is **skipped**. The balance check still runs. The swap tx is accepted into the queue. This part of the claim is **correct**.

**Step 2 — `isSwapTxReady` with prevTx = non-gasless tx** [2](#0-1) 

The claim asserts the non-gasless tx is "treated as approveTx". This is **wrong**. `IsApproveTx(prevTx)` checks A1–A4 (whitelisted ERC20 `to`, `approve(spender, MaxUint)` calldata, whitelisted spender): [3](#0-2) 

A non-gasless tx fails all of these. So `isSwapTxReady` returns **false** at line 281 while the non-gasless tx is still in pending. The swap tx stays in the queue.

**Step 3 — What actually happens after the non-gasless tx is mined**

After the non-gasless tx at nonce N is mined, `PostInsertBlock` updates `currentState` to nonce N+1: [4](#0-3) 

`promoteExecutables` is then called. `ReadyWithGasPrice(N+1, ...)` is called on the sender's queue: [5](#0-4)

**Step 4 — Block builder creates the bundle without allowance check** [7](#0-6)

func (m *txSortedMap) ReadyWithGasPrice(start uint64, baseFee *big.Int, modules []kaiax.TxPoolModule) types.Transactions {
	// Short circuit if no transactions are available
	if m.index.Len() == 0 || (*m.index)[0] > start {
		return nil
	}
	// Otherwise start accumulating incremental transactions
	ready := make(types.Transactions, 0, m.index.Len())
	for next := (*m.index)[0]; m.index.Len() > 0 && (*m.index)[0] == next; next++ {
		if m.items[next].GasPrice().Cmp(baseFee) < 0 {
			break
		}

		rejectByModule := false
		for _, module := range modules {
			if module.IsModuleTx(m.items[next]) {
				if !module.IsReady(m.items, next, ready) {
					rejectByModule = true
				}
				break
			}
		}
		// break if this is rejected because this has to return sequential txs
		if rejectByModule {
			break
		}

		ready = append(ready, m.items[next])
		delete(m.items, next)
		heap.Pop(m.index)
	}
	// If we had a cached order, shift the front
	if m.cache != nil {
		m.cache = m.cache[len(ready):]
	}

	return ready
