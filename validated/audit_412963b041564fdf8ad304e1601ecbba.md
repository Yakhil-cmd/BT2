The closest structural analog in the Polkadot SDK is the substrate RPC server's `--rpc-external`/`RpcMethods::Auto`/`DenyUnsafe` logic, where the safe/unsafe RPC method exposure is determined by whether the listen address is a loopback interface [1](#0-0)  and whether `deny_unsafe` classification is applied per interface [2](#0-1) , with CLI parameters (`rpc_external`, `rpc_methods`) determining the effective bind address and warning about unsafe exposure [3](#0-2) . This has already been the subject of an explicit fix (`pr_5678.prdoc`, "rpc server: fix deny unsafe on RpcMethods::Auto") [4](#0-3) , and node operators are explicitly warned via CLI documentation and startup warnings when exposing RPC externally [5](#0-4) [6](#0-5) .

This does not satisfy the required analog criteria for this scan:
- It is a node-operator/CLI/deployment configuration concern (default listen interface and RPC method-set selection), not a code-path reachable through a signed extrinsic, permitted contract call, or XCM message as mandated by the "real user entry" requirement.
- It falls squarely into the excluded category of "config-only" findings that the method explicitly instructs to reject.
- No FRAME pallet, XCM executor, contracts/revive, or bridge boundary is implicated; the exposure (if any) depends entirely on operator-chosen CLI flags (`--rpc-external`, `--unsafe-rpc-external`), not on a missing runtime check.

Given these constraints, there is no legitimate Polkadot SDK analog to the K3s kubelet `ReadOnlyPort`/credential-exposure issue that meets the required reachability, root-cause, and non-config-only criteria.

/// Signifies whether a potentially unsafe RPC should be denied.
#[derive(Clone, Copy, Debug)]
pub enum DenyUnsafe {
	/// Denies only potentially unsafe RPCs.
	Yes,
	/// Allows calling every RPCs.
	No,
}

impl DenyUnsafe {
	/// Returns `Ok(())` if the RPCs considered unsafe are safe to call,
	/// otherwise returns `Err(UnsafeRpcError)`.
	pub fn check_if_safe(self) -> Result<(), UnsafeRpcError> {
		match self {
			DenyUnsafe::Yes => Err(UnsafeRpcError),

fn rpc_interface(
	is_external: bool,
	is_unsafe_external: bool,
	rpc_methods: RpcMethods,
	is_validator: bool,
) -> crate::Result<(Ipv4Addr, Ipv6Addr)> {
	if is_external && is_validator && rpc_methods != RpcMethods::Unsafe {
		return Err(crate::Error::Input(
			"--rpc-external option shouldn't be used if the node is running as \
			 a validator. Use `--unsafe-rpc-external` or `--rpc-methods=unsafe` if you understand \
			 the risks. See the options description for more information."
				.to_owned(),
		));
	}

	if is_external || is_unsafe_external {
		if rpc_methods == RpcMethods::Unsafe {
			eprintln!(
				"It isn't safe to expose RPC publicly without a proxy server that filters \
				 available set of RPC methods."
			);
		}

		Ok((Ipv4Addr::UNSPECIFIED, Ipv6Addr::UNSPECIFIED))
	} else {
		Ok((Ipv4Addr::LOCALHOST, Ipv6Addr::LOCALHOST))
