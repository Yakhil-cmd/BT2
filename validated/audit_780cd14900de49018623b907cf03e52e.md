### Title
Inconsistent Cross-Parameter Validation in `checkConsistency` Allows Ratification of Conflicting `kip71.lowerboundbasefee`/`kip71.upperboundbasefee` Votes, Corrupting Base-Fee Calculation — (File: `kaiax/gov/headergov/impl/header.go`)

---

### Summary

The `checkConsistency` function validates each governance vote independently against the *current* parameter set at vote time. Two votes cast in the same epoch — one raising `kip71.lowerboundbasefee` above the current upper bound, and one lowering `kip71.upperboundbasefee` below the current lower bound — each pass validation individually. When both are ratified at epoch end, the resulting state has `LowerBoundBaseFee > UpperBoundBaseFee`, inverting the base-fee adjustment logic and corrupting KAIA fee collection and burning for every subsequent block.

---

### Finding Description

In `checkConsistency` (`kaiax/gov/headergov/impl/header.go`, lines 179–192), the two KIP-71 bound parameters are validated in isolation:

```go
case gov.Kip71LowerBoundBaseFee:
    params := h.GetParamSet(blockNum)
    if vote.Value().(uint64) > params.UpperBoundBaseFee {   // checked against CURRENT upper
        return ErrLowerBoundBaseFee
    }
    return nil
case gov.Kip71UpperBoundBaseFee:
    params := h.GetParamSet(blockNum)
    if vote.Value().(uint64) < params.LowerBoundBaseFee {   // checked against CURRENT lower
        return ErrUpperBoundBaseFee
    }
    return nil
``` [1](#0-0) 

Each vote is validated against the *current* effective parameter set, not against other votes already queued in the same epoch. The epoch-end ratification logic in `getExpectedGovernance` simply takes the last vote per parameter name in sorted block order, with no cross-parameter consistency check:

```go
for _, voteBlock := range sortedVoteBlocks {
    vote := prevEpochVotes[voteBlock]
    govs.Add(string(vote.Name()), vote.Value())
}
``` [2](#0-1) 

**Indeterminate / conflicting state scenario (governance mode `none`):**

| Block | Vote | Validation check | Result |
|-------|------|-----------------|--------|
| 100 | `lowerboundbasefee = 500 gwei` | `500 <= 750` (current upper) | ✅ accepted |
| 200 | `upperboundbasefee = 100 gwei` | `100 >= 25` (current lower) | ✅ accepted |
| 604800 (epoch) | Both ratified | — | `lower=500 > upper=100` |

The check at block 200 uses the *current* lower bound (25 gwei), not the *proposed* lower bound from block 100 (500 gwei). The two conditions are not mutually exclusive: both pass, yet together they produce an invalid state.

---

### Impact Explanation

Once `LowerBoundBaseFee > UpperBoundBaseFee` is committed to the governance parameter set, `NextMagmaBlockBaseFee` in `params/kip71_config.go` (lines 58–128) produces inverted behavior:

```go
if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {   // e.g. parentFee >= 100
    parentBaseFee = upperBoundBaseFee              // clamp to 100
} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
    parentBaseFee = lowerBoundBaseFee
}
// ...
if nextBaseFee.Cmp(upperBoundBaseFee) > 0 {       // nextFee > 100 → return 100
    return makeEvenByFloor(upperBoundBaseFee)
}
// ...
if nextBaseFee.Cmp(lowerBoundBaseFee) < 0 {       // nextFee < 500 → return 500
    return makeEvenByFloor(lowerBoundBaseFee)
}
``` [3](#0-2) 

With `lower=500, upper=100`:
- **High gas usage** (network congested) → base fee is forced to **100 gwei** (minimum, opposite of intent)
- **Low gas usage** (network idle) → base fee jumps to **500 gwei** (maximum, opposite of intent)

This inverts the EIP-1559-style fee market for every block after the corrupt epoch boundary. Consequences:
1. **KAIA fee burning is corrupted**: the half-fee burn in Magma/Kore rules operates on the wrong base fee, permanently misaccounting burnt KAIA.
2. **Transaction fee overcharging**: users pay 500 gwei base fee when the network is underutilized.
3. **Block validation divergence risk**: any node that recomputes the expected base fee via `VerifyMagmaHeader` will reject blocks whose proposer used a different (also wrong) clamped value if rounding differs. [4](#0-3) 

---

### Likelihood Explanation

- **Governance mode `none`**: Any two GC members can independently cast conflicting bound votes in the same epoch without coordination. Neither vote is individually invalid. This is a realistic accidental or adversarial scenario.
- **Governance mode `single`** (Mainnet/Kairos): The single governing node would need to cast both conflicting votes itself — either by mistake or maliciously. While this requires a privileged actor, the code provides no guard against it even for the trusted path.
- The epoch on Mainnet is 604,800 blocks (~1 week), giving ample time for two conflicting votes to accumulate before the inconsistency is detected.

---

### Recommendation

Add a cross-parameter consistency check at ratification time (in `getExpectedGovernance` or `VerifyGov`) that rejects any epoch governance data where the ratified `LowerBoundBaseFee >= UpperBoundBaseFee`. Additionally, `checkConsistency` should validate a new lower-bound vote against any *pending* upper-bound vote in the same epoch (and vice versa), not only against the currently effective value.

---

### Proof of Concept

1. Deploy a chain in governance mode `none` with default KIP-71 params: `lower=25 gwei`, `upper=750 gwei`.
2. At block 100, GC member A proposes block with `header.Vote = (kip71.lowerboundbasefee, 500 gwei)`. `VerifyVote` calls `checkConsistency`: `500 <= 750` → passes.
3. At block 200, GC member B proposes block with `header.Vote = (kip71.upperboundbasefee, 100 gwei)`. `VerifyVote` calls `checkConsistency`: `100 >= 25` → passes.
4. At block 604800 (epoch boundary), `getExpectedGovernance` collects both votes and ratifies `{lowerboundbasefee: 500, upperboundbasefee: 100}`. `VerifyGov` accepts this governance data (no cross-parameter check exists).
5. From block 604800 onward, `NextMagmaBlockBaseFee` returns 100 gwei under high load and 500 gwei under low load — the opposite of correct behavior. Fee burning and user charges are permanently corrupted until a corrective governance vote is ratified in a subsequent epoch. [5](#0-4) [6](#0-5) [7](#0-6)

func (h *headerGovModule) getExpectedGovernance(blockNum uint64) headergov.GovData {
	prevEpochIdx := calcEpochIdx(blockNum, h.epoch) - 1
	prevEpochVotes := h.getVotesInEpoch(prevEpochIdx)
	govs := make(gov.PartialParamSet)

	sortedVoteBlocks := slices.Collect(maps.Keys(prevEpochVotes))
	slices.Sort(sortedVoteBlocks)

	for _, voteBlock := range sortedVoteBlocks {
		vote := prevEpochVotes[voteBlock]
		govs.Add(string(vote.Name()), vote.Value())
	}

	// assert(len(headergov.NewGovData(govs).Items()) == len(govs))
	return headergov.NewGovData(govs)
}

func (kc *KIP71Config) VerifyMagmaHeader(headerBaseFee *big.Int, parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) error {
	if headerBaseFee == nil {
		return fmt.Errorf("header is missing baseFee")
	}
	// Verify the baseFee is correct based on the parent header.
	expectedBaseFee := kc.NextMagmaBlockBaseFee(parentHeaderNumber, parentHeaderBaseFee, parentHeaderGasUsed)
	if headerBaseFee.Cmp(expectedBaseFee) != 0 {
		return fmt.Errorf("invalid baseFee: have %s, want %s, parentBaseFee %s, parentGasUsed %d",
			headerBaseFee, expectedBaseFee, parentHeaderBaseFee, parentHeaderGasUsed)
	}
	return nil
}

func (kc *KIP71Config) NextMagmaBlockBaseFee(parentHeaderNumber *big.Int, parentHeaderBaseFee *big.Int, parentHeaderGasUsed uint64) *big.Int {
	// governance parameters
	lowerBoundBaseFee := new(big.Int).SetUint64(kc.LowerBoundBaseFee)
	upperBoundBaseFee := new(big.Int).SetUint64(kc.UpperBoundBaseFee)
	makeEvenByCeil(lowerBoundBaseFee)
	makeEvenByFloor(upperBoundBaseFee)

	// If the parent is the magma disabled block or genesis, then return the lowerBoundBaseFee (default 25ston)
	if parentHeaderNumber.Cmp(new(big.Int).SetUint64(0)) == 0 || parentHeaderBaseFee == nil {
		return makeEvenByFloor(lowerBoundBaseFee)
	}

	var baseFeeDenominator *big.Int
	if kc.BaseFeeDenominator == 0 {
		// To avoid panic, set the fluctuation range small
		baseFeeDenominator = new(big.Int).SetUint64(64)
	} else {
		baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
	}
	gasTarget := kc.GasTarget
	upperGasLimit := kc.MaxBlockGasUsedForBaseFee

	// check the case of upper/lowerBoundBaseFee is updated by governance mechanism
	parentBaseFee := parentHeaderBaseFee
	if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {
		parentBaseFee = upperBoundBaseFee
	} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
		parentBaseFee = lowerBoundBaseFee
	}

	// upper gas limit cut off the impulse of used gas to upper bound
	parentGasUsed := min(parentHeaderGasUsed, upperGasLimit)
	if parentGasUsed == gasTarget {
		return makeEvenByFloor(parentBaseFee)
	} else if parentGasUsed > gasTarget {
		// shortcut. If parentBaseFee is already reached upperbound, do not calculate.
		if parentBaseFee.Cmp(upperBoundBaseFee) == 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		// If the parent block used more gas than its target,
		// the baseFee of the next block should increase.
		// baseFeeDelta = max(1, parentBaseFee * (parentGasUsed - gasTarget) / gasTarget / baseFeeDenominator)
		gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := math.BigMax(x.Div(y, baseFeeDenominator), common.Big1)

		nextBaseFee := x.Add(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(upperBoundBaseFee) > 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	} else {
		// shortcut. If parentBaseFee is already reached lower bound, do not calculate.
		if parentBaseFee.Cmp(lowerBoundBaseFee) == 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		// Otherwise if the parent block used less gas than its target,
		// the baseFee of the next block should decrease.
		// baseFeeDelta = parentBaseFee * (gasTarget - parentGasUsed) / gasTarget / baseFeeDenominator
		gasUsedDelta := new(big.Int).SetUint64(gasTarget - parentGasUsed)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := x.Div(y, baseFeeDenominator)

		nextBaseFee := x.Sub(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(lowerBoundBaseFee) < 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	}
