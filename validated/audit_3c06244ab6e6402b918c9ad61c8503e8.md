The Mattermost issue is a zip-bomb / decompression amplification DoS. The direct analog in Polkadot SDK would be decompression of attacker-supplied blobs (parachain validation code, PoV block data, runtime WASM). However, every decompression call site in this codebase already enforces an explicit `bomb_limit` via `sp_maybe_compressed_blob::decompress`, which caps decompressed output and rejects payloads that exceed it with `Error::PossibleBomb` [1](#0-0) .

This is applied consistently:
- Validation code preparation enforces `pvf.validation_code_bomb_limit()` before decompressing untrusted candidate validation code [2](#0-1) .
- PoV block data decompression during execution is bounded by `POV_BOMB_LIMIT` [3](#0-2) .
- The runtime exposes a dynamic `validation_code_bomb_limit` API tying the cap to `max_code_size * MAX_VALIDATION_CODE_COMPRESSION_RATIO`, so the limit scales with the configured max code size rather than being a fixed/bypassable constant [4](#0-3) .
- Generic WASM runtime blob decompression (e.g. for `RuntimeBlob::uncompress_if_needed`) uses `CODE_BLOB_BOMB_LIMIT` unconditionally [5](#0-4) .
- There is even a dedicated test asserting oversized compressed code is rejected at both precheck and validation stages [6](#0-5) .

Unlike the Mattermost case (no size limit enforced on decompressed Slack import archives, allowing a team-admin-level user to trigger a zip bomb), the Polkadot SDK's decompression paths consistently enforce bomb limits before/while inflating attacker-controlled compressed input, so there is no missing-check analog. Additionally, per the scan rules, generic resource-exhaustion / oversized-input / decompression-bomb-style claims are explicitly out of scope even if a gap existed.

fn read_from_decoder(
	decoder: impl Read,
	blob_len: usize,
	bomb_limit: usize,
) -> Result<Vec<u8>, Error> {
	let mut decoder = decoder.take((bomb_limit + 1) as u64);

	let mut buf = Vec::with_capacity(blob_len);
	decoder.read_to_end(&mut buf).map_err(|_| Error::Invalid)?;

	if buf.len() <= bomb_limit {
		Ok(buf)
	} else {
		Err(Error::PossibleBomb)
	}
}
