## Analysis

The reported CVE describes an unbounded-recursion stack overflow in `vfprintf` triggered by deeply nested input, causing a crash (DoS). ocore has a directly analogous pattern: the JS source-string hashing routines recurse without any depth limit, and — critically — they are invoked in the unit-validation entry point **before** the depth-limiting guard runs.

In `validate()`, `objectHash.getUnitHash(objUnit)` is computed at [1](#0-0) 
while the depth/size guard `isTooDeeplyNestedOrHasTooManyNodes(objUnit)` is only applied later: [2](#0-1) 

`getUnitHash()` calls `getNakedUnit()`, which preserves `authors[].definition` (an arbitrary, attacker-controlled nested structure) untouched: [3](#0-2) 

That structure is then serialized by the fully recursive, depth-unbounded `getSourceString`/`extractComponents`: [4](#0-3) 

or by `getJsonSourceString`'s `stringify`, which is likewise unbounded: [5](#0-4) 

Both are plain JS recursive functions (one stack frame per nesting level), with no `MAX_DEPTH`/`isTooDeeplyNestedOrHasTooManyNodes` check applied before they run on this code path. By contrast, other parts of the codebase (formula evaluation, AA definition validation, `network.js` message handlers) deliberately call `isTooDeeplyNestedOrHasTooManyNodes` or track an explicit `depth` counter before recursing, e.g.: [6](#0-5) [7](#0-6) [8](#0-7) 

but the unit-hash-verification step in `validate()` is not protected this way — the nested `author.definition` reaches `getSourceString`/`getJsonSourceString` recursion before the depth check at line 154 has a chance to reject it.

### Title
Unbounded recursion in `getSourceString`/`getJsonSourceString` via unchecked `author.definition` causes stack-overflow DoS during unit hash verification - (File: `object_hash.js`, `string_utils.js`, `validation.js`)

### Summary
`validation.js`'s `validate()` computes `objectHash.getUnitHash(objUnit)` to check the unit hash before it ever calls `isTooDeeplyNestedOrHasTooManyNodes(objUnit)`. `getUnitHash` → `getNakedUnit` preserves the attacker-supplied `authors[].definition` structure unmodified, which is then serialized by the plain recursive `getSourceString`/`getJsonSourceString` functions in `string_utils.js`. Neither function enforces any recursion-depth limit, so an attacker who posts (or relays) a unit whose `authors[0].definition` is nested deeply enough will exhaust the V8 call stack and crash the node process while it is still inside `objectHash.getUnitHash`, i.e., before the "unit is too deeply nested" rejection logic ever executes.

### Finding Description
`validate()` in `validation.js` performs, in order:
1. `objectHash.getUnitHash(objUnit) !== objUnit.unit` (line 133) — recurses over the whole naked unit including `authors[].definition`.
2. `isTooDeeplyNestedOrHasTooManyNodes(objUnit)` (line 154) — the depth/size guard.

Because step 1 happens first and has no depth bound of its own, a deeply nested `definition` array (e.g., thousands of levels of `['and', [...]]` or `['address', ...]` wrapping) placed in `objAuthor.definition` of a freshly-posted, not-yet-known unit causes `getSourceString`'s `extractComponents` (or `getJsonSourceString`'s `stringify`) to recurse once per nesting level. This is unbounded native JS recursion with no `setImmediate`-based stack-breaking (unlike the formula evaluator, which explicitly interrupts every 100 calls) and no depth counter, so sufficient nesting overflows the call stack and crashes the Node.js process with an uncatchable `RangeError: Maximum call stack size exceeded` in many engine/version configurations, or otherwise consumes the stack unpredictably.

This is reachable by any unprivileged peer/unit poster: `handleOnlineJoint`/`handlePostedJoint` in `network.js` accept an incoming joint and eventually call `validation.validate(objJoint, ...)`, and light/full wallets/hubs that receive `post_joint` or gossip `joint` messages hit the same `validate()` path.

### Impact Explanation
A crafted unit with an excessively deep `authors[].definition` can crash the receiving node's process before any semantic validation rejects it. Because this happens inside the core validation pipeline used by every full node and hub processing incoming units, an attacker can repeatedly crash nodes that accept unsolicited joints/units, degrading network availability and potentially preventing confirmation of new units on affected nodes (denial of service). This aligns with the "network unable to confirm new units" / node crash criteria.

### Likelihood Explanation
Likelihood is moderate-to-high: constructing a deeply nested (but otherwise structurally simple, e.g., repeated `['not', [...]]` or `['and', [[...]]]`) `definition` array is trivial for any user able to post or relay a unit/joint, and no authentication or special privilege is required — only that the unit reach `validation.validate()`. The main variable is how many nesting levels are needed to exhaust the stack for a given Node.js configuration, but this is a fixed, discoverable constant per deployment.

### Recommendation
Move the `isTooDeeplyNestedOrHasTooManyNodes(objUnit)` check (and/or an explicit recursion-depth guard inside `getSourceString`/`getJsonSourceString`) to execute **before** `objectHash.getUnitHash(objUnit)` is invoked in `validate()`. Additionally, harden `extractComponents`/`stringify` in `string_utils.js` themselves with an explicit depth parameter that throws/returns an error once a safe limit (e.g., 100, matching other validators) is exceeded, so that any future caller cannot be tricked into unbounded recursion regardless of check ordering elsewhere.

### Proof of Concept
1. Construct a unit whose sole author has `definition` set to a very deeply nested oscript-style array, e.g. programmatically build `['not', ['not', ['not', ... ['sig', {...}] ... ]]]]` nested ~50,000+ levels deep (bypassing client-side generation limits by crafting the JSON directly).
2. Set `objUnit.unit` to any value (or compute a correct hash for a shallow decoy first, then swap in the deep `definition` — the hash mismatch check itself is what triggers the crash before rejecting).
3. Send this unit as a `post_joint` request or as a gossiped `joint` justsaying message to a target ocore node.
4. Observe the node process crash with a stack-overflow/`RangeError` originating from `string_utils.js`'s `extractComponents`/`stringify` invoked via `object_hash.js:getUnitHash → getNakedUnit → getBase64Hash`, occurring inside `validation.js:validate()` prior to the `isTooDeeplyNestedOrHasTooManyNodes` check.

function getSourceString(obj) {
	var arrComponents = [];
	function extractComponents(variable){
		if (variable === null)
			throw Error("null value in "+JSON.stringify(obj));
		switch (typeof variable){
			case "string":
				if (variable.includes(STRING_JOIN_CHAR))
					throw Error("00 byte in string value in " + JSON.stringify(obj));
				arrComponents.push("s", variable);
				break;
			case "number":
				if (!isFinite(variable))
					throw Error("invalid number: " + variable);
				arrComponents.push("n", variable.toString());
				break;
			case "boolean":
				arrComponents.push("b", variable.toString());
				break;
			case "object":
				if (Array.isArray(variable)){
					if (variable.length === 0)
						throw Error("empty array in "+JSON.stringify(obj));
					arrComponents.push('[');
					for (var i=0; i<variable.length; i++)
						extractComponents(variable[i]);
					arrComponents.push(']');
				}
				else{
					var keys = Object.keys(variable).sort();
					if (keys.length === 0)
						throw Error("empty object in "+JSON.stringify(obj));
					keys.forEach(function(key){
						if (typeof variable[key] === "undefined")
							throw Error("undefined at "+key+" of "+JSON.stringify(obj));
						if (key.includes(STRING_JOIN_CHAR))
							throw Error("00 byte in object key in " + JSON.stringify(obj));
						arrComponents.push(key);
						extractComponents(variable[key]);
					});
				}
				break;
			default:
				throw Error("getSourceString: unknown type="+(typeof variable)+" of "+variable+", object: "+JSON.stringify(obj));
		}
	}

	extractComponents(obj);
	return arrComponents.join(STRING_JOIN_CHAR);
}

function getJsonSourceString(obj, bAllowEmpty) {
	let cache = new WeakMap();  // object to stringified result
	function stringify(variable){
		if (variable === null)
			throw Error("null value in "+JSON.stringify(obj));
		switch (typeof variable){
			case "string":
				return toWellFormedJsonStringify(variable);
			case "number":
				if (!isFinite(variable))
					throw Error("invalid number: " + variable);
			case "boolean":
				return variable.toString();
			case "object":
				// return cached result if already processed
				if (cache.has(variable))
					return cache.get(variable);
				let result;
				if (Array.isArray(variable)){
					if (variable.length === 0 && !bAllowEmpty)
						throw Error("empty array in "+JSON.stringify(obj));
					result = '[' + variable.map(stringify).join(',') + ']';
				}
				else{
					var keys = Object.keys(variable).sort();
					if (keys.length === 0 && !bAllowEmpty)
						throw Error("empty object in "+JSON.stringify(obj));
					result = '{' + keys.map(function(key){ return toWellFormedJsonStringify(key)+':'+stringify(variable[key]) }).join(',') + '}';
				}
				cache.set(variable, result);  // memoize for future references
				return result;
			default:
				throw Error("getJsonSourceString: unknown type="+(typeof variable)+" of "+variable+", object: "+JSON.stringify(obj));
		}
	}

	return stringify(obj);
}

function isTooDeeplyNestedOrHasTooManyNodes(obj, depthLimit = 100, nodesLimit = 10000) {
	let nodeCount = 0;

	function check(variable, depth){
		if (depth > depthLimit || nodeCount > nodesLimit)
			return true;
		if (variable === null || typeof variable !== "object")
			return false;
		if (Array.isArray(variable)) {
			nodeCount += variable.length;
			for (let v of variable)
				if (check(v, depth + 1))
					return true;
		}
		else {
			nodeCount += Object.keys(variable).length;
			for (let key in variable)
				if (check(variable[key], depth + 1))
					return true;
		}
		return false;
	}

	return check(obj, 1);
}
