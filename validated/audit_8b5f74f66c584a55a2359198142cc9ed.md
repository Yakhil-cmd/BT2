### Title
Unvalidated Peer-Supplied `StakingInfo` Overwrites Reward-Distribution State During Fast Sync — (`datasync/downloader/queue.go`, `datasync/downloader/downloader.go`)

---

### Summary

During fast sync, a malicious peer can supply arbitrary `P2PStakingInfo` content for any requested block number. Because the `validate` callback in `queue.DeliverStakingInfos` is an explicit no-op (marked `// TODO-Kaia-Snapsync update validation logic`), the peer-supplied data is written unconditionally to the persistent staking-info database via `PutStakingInfoToDB` / `WriteStakingInfo`. The corrupted record is subsequently consumed by `GetStakingInfo` for reward distribution and proposer selection, redirecting KAIA block rewards to attacker-controlled addresses and distorting validator weight.

### Impact Explanation

A malicious peer that is selected to serve staking info during fast sync can supply a `P2PStakingInfo` with:

- **`CouncilRewardAddrs`** set to attacker-controlled addresses → block rewards for every validator in the corrupted epoch are sent to the attacker instead of the legitimate reward addresses.
- **`CouncilStakingAmounts`** set to skewed values → proposer selection under `WeightedRandom` policy is distorted, giving the attacker's validator disproportionate proposal rights.
- **`KEFAddr` / `KIFAddr`** set to attacker-controlled addresses → treasury fund distributions (KEF, KIF) are redirected.

The corrupted record persists in the MiscDB under key `"stakingInfo" || Uint64LE(sourceNum)` and is served from cache on every subsequent call to `GetStakingInfo` for the affected epoch, affecting all blocks in that staking interval.

---

### Likelihood Explanation

- Fast sync is the default mode for any new node or node recovering from a long offline period.
- Any peer reachable on the public Kaia P2P network can connect and be selected to serve staking info.
- The attacker does not need any privileged key or majority validator collusion — only a standard P2P connection during the sync window.
- The `// TODO-Kaia-Snapsync update validation logic` comment confirms the guard was intentionally deferred, not accidentally omitted.

---

### Recommendation

1. **Implement content validation** in `queue.DeliverStakingInfos`: after receiving a `P2PStakingInfo` for block `N`, re-derive the expected staking info from the local canonical state at block `N` (using `getFromStateByNumber`) and reject the delivery if the peer-supplied data does not match.
2. **Guard `PutStakingInfoToDB`**: before writing, check whether a valid entry already exists (`GetStakingInfoFromDB`) and refuse to overwrite it with peer-supplied data.
3. **Cross-check with multiple peers**: require staking info to be confirmed by at least a threshold of independent peers before persisting, analogous to how snap-sync verifies trie nodes.

---

### Proof of Concept

1. Attacker runs a Kaia node and connects to a victim node that is performing fast sync.
2. Victim node sends `StakingInfoRequestMsg` (code `0x12`) for block hash `H` (block number `N`, a staking-update block).
3. Attacker responds with `StakingInfoMsg` (code `0x13`) containing a `P2PStakingInfo` where `BlockNum = N`, `CouncilRewardAddrs = [attacker_addr, attacker_addr, ...]`, and `CouncilStakingAmounts = [max_uint64, 0, 0, ...]`.
4. `handleStakingInfoMsg` → `DeliverStakingInfos` → `queue.DeliverStakingInfos` (validate = no-op) → `commitFastSyncData` → `PutStakingInfoToDB(N, fakeInfo)`.
5. Victim node completes fast sync. On the next block processed in epoch `N`, `GetStakingInfo` returns the attacker's record from DB.
6. `FinalizeState` calls `state.AddBalance(attacker_addr, blockReward)` for every validator slot, draining the minting reward to the attacker. [10](#0-9) [11](#0-10)

func (d *Downloader) commitFastSyncData(results []*fetchResult, stateSync *stateSync) error {
	// Check for any early termination requests
	if len(results) == 0 {
		return nil
	}
	select {
	case <-d.quitCh:
		return errCancelContentProcessing
	case <-stateSync.done:
		if err := stateSync.Wait(); err != nil {
			return err
		}
	default:
	}
	// Retrieve the a batch of results to import
	first, last := results[0].Header, results[len(results)-1].Header
	logger.Debug("Inserting fast-sync blocks", "items", len(results),
		"firstnum", first.Number, "firsthash", first.Hash(),
		"lastnumn", last.Number, "lasthash", last.Hash(),
	)
	blocks := make([]*types.Block, len(results))
	receipts := make([]types.Receipts, len(results))
	for i, result := range results {
		blocks[i] = types.NewBlockWithHeader(result.Header).WithBody(result.Transactions)
		receipts[i] = result.Receipts
		if result.StakingInfo != nil {
			d.stakingModule.PutStakingInfoToDB(result.StakingInfo.BlockNum, staking.ToStakingInfo(result.StakingInfo))
			logger.Info("Imported new staking information", "number", result.StakingInfo.BlockNum)
		}
	}
	if index, err := d.blockchain.InsertReceiptChain(blocks, receipts); err != nil {
		logger.Debug("Downloaded item processing failed", "number", results[index].Header.Number, "hash", results[index].Header.Hash(), "err", err)
		return fmt.Errorf("%w: %v", errInvalidChain, err)
	}
	return nil
}

func (s *StakingModule) GetStakingInfo(num uint64) (*staking.StakingInfo, error) {
	isKaia := s.ChainConfig.IsKaiaForkEnabled(new(big.Int).SetUint64(num))
	sourceNum := sourceBlockNum(num, isKaia, s.stakingInterval)

	// Try cache first
	if si, ok := s.stakingInfoCache.Get(sourceNum); ok {
		return si.(*staking.StakingInfo), nil
	}

	// Only before Kaia, try the database
	if !isKaia {
		if si := ReadStakingInfo(s.ChainKv, sourceNum); si != nil {
			s.stakingInfoCache.Add(sourceNum, si)
			return si, nil
		}
	}

	// Read from the state
	si, err := s.getFromStateByNumber(sourceNum)
	if err != nil {
		return nil, err
	}

	// Only before Kaia, write to database
	if !isKaia {
		WriteStakingInfo(s.ChainKv, sourceNum, si)
	}

	// Cache it
	s.stakingInfoCache.Add(sourceNum, si)
	return si, nil
}

// handleStakingInfoMsg handles staking information response message.
func handleStakingInfoMsg(pm *ProtocolManager, p Peer, msg p2p.Msg) error {
	if pm.chainconfig.Istanbul == nil || pm.chainconfig.Istanbul.ProposerPolicy != uint64(istanbul.WeightedRandom) {
		return errResp(ErrUnsupportedEnginePolicy, "the engine is not istanbul or the policy is not weighted random")
	}

	// A batch of stakingInfos arrived to one of our previous requests
	var stakingInfos []*staking.P2PStakingInfo
	if err := msg.Decode(&stakingInfos); err != nil {
		return errResp(ErrDecode, "msg %v: %v", msg, err)
	}
	// Deliver all to the downloader
	if err := pm.downloader.DeliverStakingInfos(p.GetID(), stakingInfos); err != nil {
		logger.Debug("Failed to deliver staking information", "err", err)
	}
	return nil
}
