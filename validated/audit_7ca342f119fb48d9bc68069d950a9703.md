I examined logging/telemetry-related paths (`substrate/client/telemetry/src/lib.rs`, `substrate/client/telemetry/src/node.rs`, `substrate/primitives/io/src/lib.rs` logging host functions) and protobuf-based network message handling (`substrate/client/network/sync/src/block_request_handler.rs`, `substrate/client/network/statement/src/lib.rs`) that are the closest analogs to "protobuf logging with improper exception cleanup causing a crash." None of these expose a reachable panic-on-exception path triggerable by an unprivileged attacker through a real user entry point (signed extrinsic, XCM, contract call, or proof submission):

- Telemetry's `process_message`/`process_register` in [1](#0-0)  and serialization failures use `Result`/`unwrap_or_else` fallback logging rather than panicking.
- The `Node<TTrans>` sink implementation in [2](#0-1)  gracefully logs serialization errors via `log::debug!` instead of crashing on malformed/edge-case payloads.
- Protobuf decode failures in block sync are mapped to `Result` errors rather than left as unhandled exceptions: [3](#0-2) .
- Malformed gossip/statement messages are explicitly tested to not panic: [4](#0-3) .
- Runtime-side panics are caught at the host/wasm boundary via `catch_unwind` rather than propagating as an uncleaned exception: [5](#0-4) .

None of this logging/telemetry machinery is reachable via a signed extrinsic, permitted XCM message, contract call, or public proof submission — it is client/node-side infrastructure, not runtime dispatch logic. There is no analogous "protobuf logging enabled + attacker-controlled query causes improper exception cleanup + daemon crash" chain wired to an actual unprivileged user entry point in this codebase.

	async fn process_message(
		input: Option<TelemetryMessage>,
		node_pool: &mut HashMap<Multiaddr, Node<WsTrans>>,
		node_map: &HashMap<Id, Vec<(VerbosityLevel, Multiaddr)>>,
	) {
		let (id, verbosity, payload) = input.expect("the stream is never closed; qed");

		let ts = chrono::Local::now().to_rfc3339();
		let mut message = serde_json::Map::new();
		message.insert("id".into(), id.into());
		message.insert("ts".into(), ts.into());
		message.insert("payload".into(), payload.into());

		let nodes = if let Some(nodes) = node_map.get(&id) {
			nodes
		} else {
			// This is a normal error because the telemetry ID exists before the telemetry is
			// initialized.
			log::trace!(
				target: "telemetry",
				"Received telemetry log for unknown id ({:?}): {}",
				id,
				serde_json::to_string(&message)
					.unwrap_or_else(|err| format!(
						"could not be serialized ({}): {:?}",
						err,
						message,
					)),
			);
			return;
		};

		for (node_max_verbosity, addr) in nodes {
			if verbosity > *node_max_verbosity {
				continue;
			}

			if let Some(node) = node_pool.get_mut(addr) {
				let _ = node.send(message.clone()).await;
			} else {
				log::debug!(
					target: "telemetry",
					"Received message for unknown node ({}). This is a bug. \
					Message sent: {}",
					addr,
					serde_json::to_string(&message)
						.unwrap_or_else(|err| format!(
							"could not be serialized ({}): {:?}",
							err,
							message,
						)),
				);
			}
		}
	}

	fn start_send(mut self: Pin<&mut Self>, item: TelemetryPayload) -> Result<(), Self::Error> {
		// Any buffered outgoing telemetry messages are discarded while (re-)connecting.
		match &mut self.socket {
			NodeSocket::Connected(conn) => match serde_json::to_vec(&item) {
				Ok(data) => {
					log::trace!(target: "telemetry", "Sending {} bytes", data.len());
					let _ = conn.sink.start_send_unpin(data);
				},
				Err(err) => log::debug!(
					target: "telemetry",
					"Could not serialize payload: {}",
					err,
				),
			},
			// We are currently dialing the node.
			NodeSocket::Dialing(_) => log::trace!(target: "telemetry", "Dialing"),
			// A new connection should be started as soon as possible.
			NodeSocket::ReconnectNow => log::trace!(target: "telemetry", "Reconnecting"),
			// Waiting before attempting to dial again.
			NodeSocket::WaitingReconnect(_) => {},
			// Temporary transition state.
			NodeSocket::Poisoned => log::trace!(target: "telemetry", "Poisoned"),
		}
		Ok(())
	}
