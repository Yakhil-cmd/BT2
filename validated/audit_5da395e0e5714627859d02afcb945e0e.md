### Title
Missing Deadline Check in `GaslessModule.ExtractTxBundles` Allows Expired Gasless Swap Bundles to Be Included in Blocks, Causing Proposer KAIA Loss — (`kaiax/gasless/impl/builder.go`)

---

### Summary

The `GaslessModule` (KIP-247) checks the swap transaction's `deadline` only at txpool admission time (`checkBalanceForSwap`), but never again at bundle-extraction time (`ExtractTxBundles`) or promotion time (`IsExecutable`/`VerifyExecutable`). A user can submit a swap transaction whose deadline expires between pool admission and block building. The proposer's node will still bundle and include the expired swap, causing the proposer's lend transaction (which already transferred KAIA to the user) to go unrepaid when the on-chain `swapForGas` call reverts.

---

### Finding Description

The gasless bundle structure is `[LendTx, ApproveTx?, SwapTx]`:

- **LendTx** (generated by proposer): transfers `R2 + R3` KAIA from proposer → user.
- **ApproveTx** (optional): user approves token for the router.
- **SwapTx**: user calls `swapForGas(token, amountIn, minAmountOut, amountRepay, deadline)` on `GaslessSwapRouter`, which internally calls the Uniswap V2 router and repays the proposer.

**Deadline check exists only at admission time:** [1](#0-0) 

```go
// tx.deadline >= currentTimestamp
deadline := swapArgs.Deadline
if deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
    return fmt.Errorf("insufficient deadline: deadline=%s, want=%s", ...)
}
```

This check is inside `checkBalanceForSwap`, which is called only when the transaction is first added to the pool via `GetCheckBalance()`. [2](#0-1) 

**Bundle extraction never re-checks the deadline:** [3](#0-2) 

`ExtractTxBundles` calls only `g.IsExecutable(approveTxs[addr], tx)`, which delegates to `VerifyExecutable`: [4](#0-3) 

`VerifyExecutable` checks nonce (SP3), sender (AP1), token (SP1), approve amount (SP2), and repay amount (SP4) — **but never the deadline**. The `Deadline` field is decoded and stored in `SwapArgs` but is never validated here. [5](#0-4) 

Similarly, `isSwapTxReady` and `isApproveTxReady` (called during promotion) both call `IsExecutable` and inherit the same omission: [6](#0-5) 

---

### Impact Explanation

When a gasless bundle with an expired `deadline` is included in a block:

1. **LendTx executes**: proposer irreversibly transfers `lendAmount = ApproveTx.Fee() + SwapTx.Fee()` KAIA to the user.
2. **ApproveTx executes** (if present): user's token approval is set.
3. **SwapTx reverts**: `GaslessSwapRouter` passes `deadline` to the Uniswap V2 router, which enforces `require(deadline >= block.timestamp, 'UniswapV2Router: EXPIRED')`. The swap reverts, so the proposer is never repaid.

The proposer loses `R2 + R3` KAIA (the lend amount) per exploited bundle. The user receives this KAIA for free. This is an unauthorized KAIA transfer from the proposer (a system-managed validator) to the user.

The `SwappedForGas` event (which signals successful repayment) is never emitted: [7](#0-6) 

---

### Likelihood Explanation

Any user can craft a swap transaction with `deadline = currentBlock.Time()` (which passes the pool admission check `deadline >= currentBlock.Time()`) but expires by the time the next block is built (since the next block's timestamp will be strictly greater). The `PendingTimeout` of 10 seconds means the tx can remain in the pending pool long enough for the deadline to expire: [8](#0-7) 

The admission check uses `g.Chain.CurrentBlock().Time()` (the head block's timestamp), not the timestamp of the block being built, creating a systematic gap: [9](#0-8) 

This is a low-effort, zero-cost attack: the user submits a valid-looking swap tx, receives the lend KAIA, and the swap reverts without repayment.

---

### Recommendation

Add a deadline check in `ExtractTxBundles` before creating a bundle, using the pending block's expected timestamp (or at minimum the current head block's time):

```go
// In ExtractTxBundles, before appending the bundle:
} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
    swapArgs, ok := decodeSwapTx(tx, g.signer)
    if !ok || swapArgs.Deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
        continue // skip expired swap tx, do not create bundle
    }
    bundleTxs := builder.NewTxOrGenList(...)
    ...
}
```

Alternatively, add the deadline check inside `VerifyExecutable` so it is enforced at every call site (promotion, bundle extraction, and the public API): [10](#0-9) 

---

### Proof of Concept

1. User submits `SwapTx` with `deadline = chain.CurrentBlock().Time()` (e.g., timestamp `T`). Pool admission check passes: `T >= T`.
2. The next block is built with timestamp `T+1`. `ExtractTxBundles` calls `IsExecutable` — no deadline check — and creates bundle `[LendTx, SwapTx]`.
3. Block is committed. `LendTx` executes: proposer sends `R2 + R3` KAIA to user.
4. `SwapTx` executes: `GaslessSwapRouter` calls Uniswap V2 router with `deadline = T`. Router checks `require(T >= T+1)` → **reverts**.
5. Proposer's lend is unrecovered. User retains `R2 + R3` KAIA.

The existing integration test confirms the deadline is enforced on-chain: [11](#0-10) 

```go
// reject swapTx when deadline is in the past
_, err = sendSwapTx(t, gsrContract, accounts[0], testTokenAddr, swapAmmount, minAmountOut, amountRepaySwap, common.Big1)
assert.ErrorContains(t, err, "insufficient deadline: deadline=1")
```

This test only covers pool-level rejection. There is no test covering the case where a tx passes pool admission but the deadline expires before block inclusion — the gap exploited by this vulnerability.

```go
func (g *GaslessModule) IsExecutable(approveTxOrNil, swapTx *types.Transaction) bool {
	err := g.VerifyExecutable(approveTxOrNil, swapTx)
	if err != nil {
		return false
	}
	return true
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}
```
