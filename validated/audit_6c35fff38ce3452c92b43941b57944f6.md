## Analysis Result

### Title
Unbounded Recursion in Unit Hashing Before Depth-Limit Check Enables Node Disagreement via Stack Overflow - (File: string_utils.js, object_hash.js, validation.js)

### Summary
CVE-2026-44028 describes unbounded recursion in a data parser causing a stack overflow before any depth-bounding logic can intervene. In `ocore`, the unit-validation entry point `validate()` computes the unit hash via `objectHash.getUnitHash()` — which recursively walks the entire untrusted unit object through `getSourceString()`/`getJsonSourceString()` — *before* the depth/size guard (`isTooDeeplyNestedOrHasTooManyNodes`) is applied.

### Finding Description
In `validate(objJoint, callbacks, external_conn)`, the very first content-dependent operation performed on an attacker-supplied unit is: [1](#0-0) 
This calls `objectHash.getUnitHash(objUnit)`, which (for units without `content_hash`) recursively clones and serializes the full unit via `getNakedUnit` → `getSourceString`/`getJsonSourceString`: [2](#0-1) 

Both serialization functions are plain, unbounded recursive walks over the object graph with no depth counter or interrupt of the call stack: [3](#0-2) [4](#0-3) 

Only *after* this hashing step does `validate()` invoke the dedicated depth/size guard: [5](#0-4) 

That guard, `isTooDeeplyNestedOrHasTooManyNodes`, is itself a bounded recursive check with an explicit `depthLimit`/`nodesLimit`: [6](#0-5) 

But because it runs *after* `getUnitHash`, a unit with extremely deep nesting in `messages`/payload/definition structures reaches the unbounded recursive hashing code first. This mirrors the CVE's root cause: a bound-check exists in the codebase, but the recursive walk that should be protected by it executes beforehand.

### Impact Explanation
A pure-JS stack overflow (`RangeError: Maximum call stack size exceeded`) is normally caught by the surrounding `try { … } catch(e) { return callbacks.ifJointError(...) }` block at [1](#0-0) , so this does not directly yield the memory-corruption/RCE primitive described in the original advisory (Node.js/V8 checks JS stack usage explicitly, unlike a guard-page-less native coroutine stack). However, the *point at which* the stack limit is hit is not deterministic across the network: it depends on Node.js version, platform default stack size, `--stack-size` flags, and current call-stack depth/other work already on the stack for a given process. This means different full nodes can reach different verdicts on whether the exact same crafted unit is "too deeply nested" (rejected before hashing completes) versus successfully hashed and passed on to the depth check — a source of **non-deterministic validation results for identical input**, which is precisely the kind of consensus-divergence risk (nodes disagreeing on unit validity) that is in-scope for high-severity findings on ocore.

### Likelihood Explanation
Any unprivileged user can construct and broadcast a unit (or its constituent messages/definitions/payload) with deep nesting sufficiently close to node stack limits without exceeding the eventual `isTooDeeplyNestedOrHasTooManyNodes` bound check order-of-operations issue — the attacker only needs the hashing recursion to occur before the guard executes, which is guaranteed by code order. No special privileges, races, or third-party cooperation are required; it is reachable directly from `validate()`, which is invoked by ordinary joint/unit processing.

### Recommendation
Move the `isTooDeeplyNestedOrHasTooManyNodes(objUnit)` depth/size check to execute strictly before any hashing (`objectHash.getUnitHash`) or other recursive traversal of `objUnit`. Additionally, harden `getSourceString`/`getJsonSourceString` in `string_utils.js` themselves with an explicit depth counter (mirroring the pattern already used in `formula/validation.js`'s `evaluate()` and `aa_validation.js`'s `MAX_DEPTH`), so hashing code is safe to call regardless of call order elsewhere in the codebase.

### Proof of Concept
1. Craft an unsigned unit joint whose `unit.messages[0].payload` (or nested `definition`) contains deeply nested arrays/objects, e.g. depth on the order of the platform's JS recursion limit (typically several thousand to tens of thousands of frames depending on frame size and default stack size).
2. Submit the joint to a node via the normal unit-broadcast path so it reaches `validation.js`'s `validate()`.
3. Observe that `objectHash.getUnitHash(objUnit)` (line 133) is invoked, recursing through `getNakedUnit`/`getSourceString`/`getJsonSourceString`, before `isTooDeeplyNestedOrHasTooManyNodes` (line 154) ever runs.
4. Vary the effective Node.js stack budget between two node instances (e.g. via `--stack-size`, differing platform defaults, or differing amount of already-consumed stack in the event loop at time of validation) and observe that one node throws/catches a stack overflow at line 137 (`ifJointError`) while the other completes hashing and proceeds toward acceptance — demonstrating non-deterministic validation outcomes for the identical unit across the network.

function getSourceString(obj) {
	var arrComponents = [];
	function extractComponents(variable){
		if (variable === null)
			throw Error("null value in "+JSON.stringify(obj));
		switch (typeof variable){
			case "string":
				if (variable.includes(STRING_JOIN_CHAR))
					throw Error("00 byte in string value in " + JSON.stringify(obj));
				arrComponents.push("s", variable);
				break;
			case "number":
				if (!isFinite(variable))
					throw Error("invalid number: " + variable);
				arrComponents.push("n", variable.toString());
				break;
			case "boolean":
				arrComponents.push("b", variable.toString());
				break;
			case "object":
				if (Array.isArray(variable)){
					if (variable.length === 0)
						throw Error("empty array in "+JSON.stringify(obj));
					arrComponents.push('[');
					for (var i=0; i<variable.length; i++)
						extractComponents(variable[i]);
					arrComponents.push(']');
				}
				else{
					var keys = Object.keys(variable).sort();
					if (keys.length === 0)
						throw Error("empty object in "+JSON.stringify(obj));
					keys.forEach(function(key){
						if (typeof variable[key] === "undefined")
							throw Error("undefined at "+key+" of "+JSON.stringify(obj));
						if (key.includes(STRING_JOIN_CHAR))
							throw Error("00 byte in object key in " + JSON.stringify(obj));
						arrComponents.push(key);
						extractComponents(variable[key]);
					});
				}
				break;
			default:
				throw Error("getSourceString: unknown type="+(typeof variable)+" of "+variable+", object: "+JSON.stringify(obj));
		}
	}

	extractComponents(obj);
	return arrComponents.join(STRING_JOIN_CHAR);
}

function getJsonSourceString(obj, bAllowEmpty) {
	let cache = new WeakMap();  // object to stringified result
	function stringify(variable){
		if (variable === null)
			throw Error("null value in "+JSON.stringify(obj));
		switch (typeof variable){
			case "string":
				return toWellFormedJsonStringify(variable);
			case "number":
				if (!isFinite(variable))
					throw Error("invalid number: " + variable);
			case "boolean":
				return variable.toString();
			case "object":
				// return cached result if already processed
				if (cache.has(variable))
					return cache.get(variable);
				let result;
				if (Array.isArray(variable)){
					if (variable.length === 0 && !bAllowEmpty)
						throw Error("empty array in "+JSON.stringify(obj));
					result = '[' + variable.map(stringify).join(',') + ']';
				}
				else{
					var keys = Object.keys(variable).sort();
					if (keys.length === 0 && !bAllowEmpty)
						throw Error("empty object in "+JSON.stringify(obj));
					result = '{' + keys.map(function(key){ return toWellFormedJsonStringify(key)+':'+stringify(variable[key]) }).join(',') + '}';
				}
				cache.set(variable, result);  // memoize for future references
				return result;
			default:
				throw Error("getJsonSourceString: unknown type="+(typeof variable)+" of "+variable+", object: "+JSON.stringify(obj));
		}
	}

	return stringify(obj);
}

function isTooDeeplyNestedOrHasTooManyNodes(obj, depthLimit = 100, nodesLimit = 10000) {
	let nodeCount = 0;

	function check(variable, depth){
		if (depth > depthLimit || nodeCount > nodesLimit)
			return true;
		if (variable === null || typeof variable !== "object")
			return false;
		if (Array.isArray(variable)) {
			nodeCount += variable.length;
			for (let v of variable)
				if (check(v, depth + 1))
					return true;
		}
		else {
			nodeCount += Object.keys(variable).length;
			for (let key in variable)
				if (check(variable[key], depth + 1))
					return true;
		}
		return false;
	}

	return check(obj, 1);
}
