The TimescaleDB bug is specific to its Gorilla compression algorithm's reverse row iterator over a `BitArray`/bucket structure used for time-series columnar storage — a component that does not exist anywhere in the Polkadot SDK. I searched for analogous patterns (bit-array/bitmap decoding with attacker-controlled bucket index arithmetic, reverse iterators over compressed/decoded data, unsigned integer wraparound in index computation reachable from unprivileged extrinsics) and found none that match the violated invariant.

Relevant compression/iterator code that was inspected but does not share the vulnerable pattern:
- `sp_maybe_compressed_blob::decompress`/`read_from_decoder` bound decompressed output by an explicit `bomb_limit`, rejecting oversized output rather than computing an unchecked bucket index from attacker data [1](#0-0) .
- The trie `Bitmap` decode/`value_at` in `node_codec.rs` operates on a fixed 16-bit bitmap with no reverse iterator or bucket math [2](#0-1) .
- `sparse_bitmap.rs`'s `compute_bucket_and_mask` shifts a `u64` index to derive a bucket, but this is test/library code for Snowbridge internal state tracking, not a reverse iterator over externally-supplied compressed data with an "internally inconsistent" structure [3](#0-2) .
- `Junctions` `DoubleEndedIterator`/`next_back` implementations use `checked_sub` and bounds checks against `len()`, guarding against the exact wraparound class described in the report [4](#0-3) .
- The `sp-trie` compact-proof decoding had prior panics on badly-constructed proofs, but these were fixed by returning errors rather than reading out of bounds, and don't involve a reverse-iterator bucket-index wraparound [5](#0-4) .

None of these expose a user-reachable path where an attacker-supplied "compressed datum" with an internally inconsistent structure drives an unsigned integer wraparound in a bucket-index computation during reverse-order iteration, which is the specific root cause in the TimescaleDB report. There is no FRAME pallet, XCM component, or bridge/Snowbridge code implementing Gorilla-style time-series compression with a reverse iterator over a bucketed `BitArray`.

fn read_from_decoder(
	decoder: impl Read,
	blob_len: usize,
	bomb_limit: usize,

	let mut decoder = decoder.take((bomb_limit + 1) as u64);

	let mut buf = Vec::with_capacity(blob_len);
	decoder.read_to_end(&mut buf).map_err(|_| Error::Invalid)?;

	if buf.len() <= bomb_limit {
		Ok(buf)
	} else {
		Err(Error::PossibleBomb)

}
