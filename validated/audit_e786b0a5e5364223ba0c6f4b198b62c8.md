### Title
Path traversal via unsanitized release asset name allows arbitrary file write - ([File: pkg/cmd/release/download/download.go])

### Summary
`shared.ReleaseAsset.Name` is taken verbatim from the GitHub API response and passed unmodified into `destinationWriter.makePath`, which calls `filepath.Join(w.dir, name)` without stripping `..` segments or rejecting absolute/rooted names. An attacker who controls a release (their own public repo, which victims can be pointed at via `-R`/`gh release download`) can name an asset `../../.bashrc` (or similar) so that `gh release download` writes attacker-controlled content outside `--dir`.

### Finding Description
The flow is: `downloadRun` builds `targets[i] = downloadTarget{name: a.Name}` directly from `release.Assets` (`a.Name`, itself sourced from the GitHub API `name` field with no validation) [3](#0-2) . This is passed to `downloadAssets` → `downloadAsset`, which calls `dest.Check(fileName)` and later `dest.Copy(fileName, resp.Body)` [4](#0-3) [5](#0-4) . Both `Check` and `Copy` resolve the destination via `makePath`, which does `filepath.Join(w.dir, name)` with no traversal guard, no `filepath.Base`, and no check that the resolved path remains inside `w.dir` [2](#0-1) . `Copy` then creates any needed parent directories via `os.MkdirAll(dir, 0755)` and opens the file for write/truncate/create [6](#0-5) . There is no validation anywhere in `downloadRun`/`downloadAsset`/`destinationWriter` that rejects asset names containing `/`, `\`, or `..` segments — the only filename check present is `isWindowsReservedFilename`, which is unrelated to traversal [7](#0-6) . Since `filepath.Join` cleans `..` algebraically rather than rejecting it, a name like `../../.bashrc` combined with `dir=/tmp/out` resolves outside the intended destination directory.

### Impact Explanation
This is an arbitrary file write primitive scoped to paths writable by the victim's OS user, exploitable purely by an attacker publishing a release with a maliciously named asset that the victim downloads with `gh release download`. Overwriting shell startup files (`.bashrc`, `.zprofile`, `.profile`) or other config/executable files can lead to code execution on the victim's next shell session, matching a file-write/code-execution-adjacent bounty impact class.

### Likelihood Explanation
Feasibility is high: creating a release asset with a path-traversal filename is straightforward via the GitHub UI/API (release asset display names/`name` fields are attacker-controlled), and the victim only needs to run an ordinary `gh release download [tag]` (or the pattern/archive variants) with default flags against the attacker's repo — no special privileges, tokens, or victim opt-in beyond running the command are required. It is fully repeatable and deterministic given `filepath.Join` semantics.

### Recommendation
In `destinationWriter.makePath` (or earlier, when building `downloadTarget`/`toDownload`), sanitize `name` before joining: reject or strip any path separators and `..` segments (e.g., use `filepath.Base(name)` or verify with `filepath.Rel`/`strings.Contains(name, "..")` that the cleaned joined path remains a descendant of `filepath.Clean(w.dir)`), and fail closed with an error if the asset name attempts traversal.

### Proof of Concept
```go
package download

import (
	"os"
	"path/filepath"
	"strings"
	"testing"
)

func TestDestinationWriter_PathTraversalRejected(t *testing.T) {
	dir := t.TempDir()
	w := destinationWriter{dir: dir}

	maliciousName := "../../evil.sh"
	fp := w.makePath(maliciousName)

	cleanDir := filepath.Clean(dir)
	if !strings.HasPrefix(filepath.Clean(fp), cleanDir+string(os.PathSeparator)) {
		t.Fatalf("makePath escaped destination dir: dir=%s resolved=%s", dir, fp)
	}

	// Demonstrate current (vulnerable) behavior: Copy would write outside dir.
	if err := w.Copy(maliciousName, strings.NewReader("malicious payload")); err == nil {
		resolved := filepath.Clean(w.makePath(maliciousName))
		if !strings.HasPrefix(resolved, cleanDir+string(os.PathSeparator)) {
			t.Fatalf("Copy wrote file outside destination directory: %s", resolved)
		}
	}
}
```

func isWindowsReservedFilename(filename string) bool {
	// Windows terminals should prevent the creation of these files
	// but that behavior is not enforced across terminals. Prevent
	// the user from downloading files with these reserved names as
	// they represent an exploit vector for bad actors.
	// Reserved filenames defined at:
	// https://learn.microsoft.com/en-us/windows/win32/fileio/naming-a-file#win32-file-namespaces
	reservedFilenames := []string{"CON", "PRN", "AUX", "NUL", "COM0",
		"COM1", "COM2", "COM3", "COM4", "COM5",
		"COM6", "COM7", "COM8", "COM9", "COM¹",
		"COM²", "COM³", "LPT0", "LPT1", "LPT2",
		"LPT3", "LPT4", "LPT5", "LPT6", "LPT7",
		"LPT8", "LPT9", "LPT¹", "LPT²", "LPT³"}

	// Normalize type case and remove file type extension from filename.
	filename = strings.ToUpper(strings.Split(filename, ".")[0])

	return slices.Contains(reservedFilenames, filename)
}
