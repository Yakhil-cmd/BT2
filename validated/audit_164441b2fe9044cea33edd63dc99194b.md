### Title
Unvalidated P2P Staking Info Delivery Allows Malicious Peer to Corrupt Reward-Distribution Database — (`datasync/downloader/queue.go`)

### Summary

During fast-sync, a malicious connected peer can serve arbitrarily fabricated `StakingInfo` payloads (wrong staking amounts, wrong reward addresses, wrong treasury-fund addresses). The delivery validation callback is an explicit no-op, so the data is written directly to the persistent staking-info database without any content check against the canonical chain state. For pre-Kaia-fork blocks, `GetStakingInfo` reads from this database before falling back to state, so the corrupted entries are consumed by `FinalizeState` to drive KAIA reward distribution.

---

### Finding Description

`queue.DeliverStakingInfos` is the queue-side handler for staking-info packets received from a peer during fast-sync. Every other data type (bodies, receipts) has a cryptographic validate callback:

```go
// DeliverBodies – validates TxHash
validate := func(index int, header *types.Header) error {
    if types.DeriveTransactionsRoot(...) != header.TxHash { return errInvalidBody }
    ...
}

// DeliverReceipts – validates ReceiptHash
validate := func(index int, header *types.Header) error {
    if types.DeriveReceiptsRoot(...) != header.ReceiptHash { return errInvalidReceipt }
    ...
}
```

`DeliverStakingInfos` has no such check:

```go
validate := func(index int, header *types.Header) error {
    // TODO-Kaia-Snapsync update validation logic
    return nil
}
``` [1](#0-0) 

The accepted `P2PStakingInfo` is then stored unconditionally:

```go
// commitFastSyncData
if result.StakingInfo != nil {
    d.stakingModule.PutStakingInfoToDB(result.StakingInfo.BlockNum, staking.ToStakingInfo(result.StakingInfo))
}
``` [2](#0-1) 

`PutStakingInfoToDB` writes directly to the key-value store with no further validation: [3](#0-2) 

`GetStakingInfo` consults the database before falling back to state for all pre-Kaia-fork block numbers:

```go
if !isKaia {
    if si := ReadStakingInfo(s.ChainKv, sourceNum); si != nil {
        s.stakingInfoCache.Add(sourceNum, si)
        return si, nil   // ← corrupted entry returned here
    }
}
``` [4](#0-3) 

`FinalizeState` calls `GetDeferredReward` → `GetStakingInfo` and then calls `state.AddBalance` for every entry in `spec.Rewards`: [5](#0-4) 

The `StakingInfo` fields that drive reward distribution are:

| Field | Effect if corrupted |
|---|---|
| `StakingAmounts` | Proportional staking rewards re-routed |
| `RewardAddrs` | Validator rewards sent to attacker addresses |
| `KIFAddr` / `KEFAddr` / `KPFAddr` | Treasury fund shares redirected | [6](#0-5) 

---

### Impact Explanation

A malicious peer can cause a syncing node to persist fabricated `StakingInfo` for any pre-Kaia-fork block interval. When `FinalizeState` later processes blocks that reference those intervals, it distributes KAIA block rewards to attacker-controlled addresses instead of legitimate validators and treasury funds. The corrupted values are: wrong `StakingAmounts` (shifts proportional staking rewards), wrong `RewardAddrs` (redirects validator share), and wrong `KIFAddr`/`KEFAddr`/`KPFAddr` (redirects treasury shares). This constitutes unauthorized reward distribution affecting KAIA.

**Scope note**: After the Kaia hardfork, `GetStakingInfo` reads from state rather than the database, so post-Kaia block processing is unaffected. The impact is confined to chains that have not yet reached the Kaia fork (private networks, testnets, or a node fast-syncing a chain whose pivot block is pre-Kaia).

---

### Likelihood Explanation

Any peer that a fast-syncing node connects to can serve this attack. No privileged key is required — only a valid P2P connection. The `StakingInfoMsg` handler in `node/cn/handler.go` decodes the message and forwards it directly to `DeliverStakingInfos` with no additional checks: [7](#0-6) 

The TODO comment in the validate callback confirms the missing guard is a known gap, not an intentional design choice. [1](#0-0) 

---

### Recommendation

Replace the no-op `validate` callback in `queue.DeliverStakingInfos` with a content-integrity check. The canonical approach is to derive a deterministic commitment from the `StakingInfo` fields (e.g., a Merkle root or hash of the sorted `(nodeId, stakingAmount, rewardAddr)` tuples) and compare it against a value committed in the corresponding block header or a system-contract storage slot. Until a header commitment exists, the fallback should be to re-derive the staking info from the local state at `sourceNum` and reject any peer-supplied value that differs.

---

### Proof of Concept

1. Attacker runs a Kaia node and connects to a victim node that is fast-syncing a pre-Kaia chain.
2. When the victim sends `StakingInfoRequestMsg` for block hash `H` (block number `N`, pre-Kaia), the attacker responds with a `P2PStakingInfo` where:
   - `BlockNum = N` (passes the block-number check in `SyncStakingInfo`)
   - `RewardAddrs = [attacker_address, ...]`
   - `StakingAmounts = [max_uint64, ...]`
   - `KIFAddr = attacker_address`
3. `handleStakingInfoMsg` → `DeliverStakingInfos` → `queue.DeliverStakingInfos` → `validate` returns `nil` → `PutStakingInfoToDB` writes the fabricated entry.
4. After fast-sync completes, when the node processes block `N + stakingInterval` (pre-Kaia), `FinalizeState` calls `GetStakingInfo(N + stakingInterval)` → `ReadStakingInfo(db, N)` → returns the fabricated entry → `state.AddBalance(attacker_address, fullReward)`. func (s *StakingModule) GetStakingInfo(num uint64) (*staking.StakingInfo, error) {
	isKaia := s.ChainConfig.IsKaiaForkEnabled(new(big.Int).SetUint64(num))
	sourceNum := sourceBlockNum(num, isKaia, s.stakingInterval)

	// Try cache first
	if si, ok := s.stakingInfoCache.Get(sourceNum); ok {
		return si.(*staking.StakingInfo), nil
	}

	// Only before Kaia, try the database
	if !isKaia {
		if si := ReadStakingInfo(s.ChainKv, sourceNum); si != nil {
			s.stakingInfoCache.Add(sourceNum, si)
			return si, nil
		}
	}

	// Read from the state
	si, err := s.getFromStateByNumber(sourceNum)
	if err != nil {
		return nil, err
	}

	// Only before Kaia, write to database
	if !isKaia {
		WriteStakingInfo(s.ChainKv, sourceNum, si)
	}

	// Cache it
	s.stakingInfoCache.Add(sourceNum, si)
	return si, nil
}

func (r *RewardModule) FinalizeState(header *types.Header, state *state.StateDB, txs []*types.Transaction, receipts []*types.Receipt) error {
	if r.GovModule.GetParamSet(header.Number.Uint64()).ProposerPolicy == uint64(istanbul.WeightedRandom) && common.EmptyHash(header.Root) {
		qualified, err := r.ValsetModule.GetQualifiedValidators(header.Number.Uint64())
		if err != nil {
			return err
		}
		useRewardAddress := valset.NewAddressSet(qualified).Contains(r.NodeAddress)

		if rewardAddr := r.GetRewardAddress(header.Number.Uint64(), r.NodeAddress); useRewardAddress && rewardAddr != (common.Address{}) {
			header.Rewardbase = rewardAddr
			logger.Trace("Use reward address for nodeValidator", "header.Number", header.Number.Uint64(), "nodeAddress", r.NodeAddress, "rewardbase", header.Rewardbase)
		} else {
			logger.Trace("No reward address for nodeValidator. Use node's rewardbase.", "header.Number", header.Number.Uint64(), "nodeAddress", r.NodeAddress, "rewardbase", header.Rewardbase)
		}
	}

	spec, err := r.GetDeferredReward(header, txs, receipts)
	if err != nil {
		return err
	}
	if err := spec.Validate(); err != nil {
		return err
	}
	for addr, amount := range spec.Rewards {
		state.AddBalance(addr, amount)
	}
	return nil
}

// handleStakingInfoMsg handles staking information response message.
func handleStakingInfoMsg(pm *ProtocolManager, p Peer, msg p2p.Msg) error {
	if pm.chainconfig.Istanbul == nil || pm.chainconfig.Istanbul.ProposerPolicy != uint64(istanbul.WeightedRandom) {
		return errResp(ErrUnsupportedEnginePolicy, "the engine is not istanbul or the policy is not weighted random")
	}

	// A batch of stakingInfos arrived to one of our previous requests
	var stakingInfos []*staking.P2PStakingInfo
	if err := msg.Decode(&stakingInfos); err != nil {
		return errResp(ErrDecode, "msg %v: %v", msg, err)
	}
	// Deliver all to the downloader
	if err := pm.downloader.DeliverStakingInfos(p.GetID(), stakingInfos); err != nil {
		logger.Debug("Failed to deliver staking information", "err", err)
	}
	return nil
