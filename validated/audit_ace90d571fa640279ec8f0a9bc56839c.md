### Title
Gasless SwapTx Deadline Validated Against Stale Block Timestamp Allows Proposer KAIA Loss — (`File: kaiax/gasless/impl/tx_pool.go`)

---

### Summary

The `checkBalanceForSwap` function validates a gasless swap transaction's `deadline` field against `g.Chain.CurrentBlock().Time()` — the timestamp of the **already-finalized** head block — at pool-admission time. The actual on-chain `swapForGas` call executes in a **future** block whose timestamp is strictly greater. A user can craft a `GaslessSwapTx` with `deadline == currentBlock.Time()`, which passes pool validation but causes the `swapForGas` contract to revert on-chain. Because the block proposer has already irrevocably transferred `lendAmount` KAIA to the user via the prepended `LendTx`, the proposer suffers a direct, unrecoverable KAIA loss.

---

### Finding Description

**Pool-admission deadline check (stale timestamp):**

In `checkBalanceForSwap`, the deadline is compared against the current head block's time:

```go
// tx.deadline >= currentTimestamp
deadline := swapArgs.Deadline
if deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
    return fmt.Errorf("insufficient deadline: deadline=%s, want=%s", ...)
}
```

This accepts any `deadline >= currentBlock.Time()`. [1](#0-0) 

**Block-building path — no deadline re-check:**

`ExtractTxBundles` calls `IsExecutable` → `VerifyExecutable`, which checks sender/nonce/repay-amount consistency but **never re-validates the deadline** against the pending block's timestamp. [2](#0-1) [3](#0-2) 

**Proposer lends real KAIA unconditionally:**

`GetLendTxGenerator` creates a `LendTx` signed by the proposer's node key that transfers `lendAmount = ApproveTx.Fee() + SwapTx.Fee()` KAIA to the user. This transfer executes and finalizes before the `SwapTx` runs. [4](#0-3) 

The lend amount formula:

```go
func lendAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
    r := new(big.Int)
    if approveTxOrNil != nil {
        r.Add(r, approveTxOrNil.Fee())
    }
    r.Add(r, swapTx.Fee())
    return r
}
``` [5](#0-4) 

**On-chain `swapForGas` enforces `block.timestamp <= deadline`:**

The `GaslessSwapRouter` contract's `swapForGas(token, amountIn, minAmountOut, amountRepay, deadline)` enforces the deadline against the actual block timestamp at execution time. [6](#0-5) 

**Block timestamp progression:**

Kaia produces blocks with `header.Time = parent.Time + BlockGenerationInterval` (minimum 1 second). A `deadline == currentBlock.Time()` is guaranteed to be expired by the time the next block is sealed. [7](#0-6) 

---

### Impact Explanation

The bundle execution order is `[LendTx → ApproveTx → SwapTx]`. The `LendTx` is an unconditional KAIA transfer from the proposer to the user. When `SwapTx` reverts due to deadline expiry, the EVM unwinds only the `SwapTx`'s state changes — the `LendTx` transfer is already committed in the same block and is **not** rolled back. The proposer permanently loses `lendAmount` KAIA per exploited bundle.

The `repayAmount` (which includes `R1 = LendTx.Fee()`, `R2 = ApproveTx.Fee()`, `R3 = SwapTx.Fee()`) is never collected. [8](#0-7) 

**Corrupted value:** Proposer's KAIA balance is debited by `lendAmount` with no corresponding credit from the swap repayment.

---

### Likelihood Explanation

Any user can submit a `GaslessSwapTx` with `deadline = currentBlock.Time()` (or `currentBlock.Time() + N` for small N, exploiting network/processing latency). The pool check uses strict `<` (rejects only if `deadline < currentBlock.Time()`), so `deadline == currentBlock.Time()` always passes. The next block's timestamp is always `>= currentBlock.Time() + 1`, guaranteeing on-chain revert. No special privilege is required — any EOA with a token balance can trigger this. The `PendingTimeout` of 10 seconds means a transaction with `deadline = currentBlock.Time() + 9` could also be exploited if block production is delayed. [9](#0-8) 

---

### Recommendation

In `checkBalanceForSwap`, validate the deadline against the **anticipated execution block's timestamp**, not the current head. At minimum, require:

```go
// Require deadline to be at least one block interval beyond the current head
minDeadline := new(big.Int).Add(
    g.Chain.CurrentBlock().Time(),
    new(big.Int).SetUint64(uint64(params.BlockGenerationInterval)),
)
if deadline.Cmp(minDeadline) < 0 {
    return fmt.Errorf("deadline too tight: deadline=%s, minRequired=%s", ...)
}
```

Additionally, add a deadline re-check in `ExtractTxBundles` (block-building time) against the pending block's header timestamp, so that a swap whose deadline has expired between pool admission and block sealing is dropped rather than bundled with a `LendTx`.

---

### Proof of Concept

1. Observe current head block timestamp `T = chain.CurrentBlock().Time()`.
2. Submit `GaslessSwapTx` with `deadline = T` (exactly equal). Pool check: `T >= T` → accepted.
3. The proposer node, acting as block proposer for block `N+1` (timestamp `T+1`), calls `ExtractTxBundles` → `IsExecutable` → no deadline check → bundle is formed as `[LendTx, SwapTx]`.
4. Block `N+1` is sealed. `LendTx` executes: proposer transfers `lendAmount` KAIA to user. State committed.
5. `SwapTx` executes: `swapForGas` checks `block.timestamp (T+1) <= deadline (T)` → **reverts**.
6. `SwapTx` state changes are rolled back; `LendTx` transfer is permanent.
7. Proposer's KAIA balance is reduced by `lendAmount`; user retains the lent KAIA and their tokens.

The existing test confirms the pool correctly rejects `deadline=1` (past), but does not test the boundary case `deadline == currentBlock.Time()`, which passes pool validation and fails on-chain. [10](#0-9)

func (g *GaslessModule) ExtractTxBundles(txs []*types.Transaction, prevBundles []*builder.Bundle) []*builder.Bundle {
	// there are only at most two gasless transactions in pending for a sender
	bundles := []*builder.Bundle{}
	approveTxs := map[common.Address]*types.Transaction{}
	targetTxHash := common.Hash{}
	for _, tx := range txs {
		addr, err := types.Sender(g.signer, tx)
		if err != nil {
			continue
		}
		if g.IsApproveTx(tx) {
			approveTxs[addr] = tx
		} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
			bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
			if approveTxs[addr] != nil {
				bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(approveTxs[addr]))
			}
			bundleTxs = append(bundleTxs, builder.NewTxOrGenFromTx(tx))

			b := builder.NewBundle(
				bundleTxs,
				targetTxHash,
				false,
			)

			targetTxHash = tx.Hash()

			isConflict := false
			for _, prev := range append(prevBundles, bundles...) {
				if prev.IsConflict(b) {
					isConflict = true
					break
				}
			}
			if isConflict {
				// Gasless transactions will just fail even if they aren't bundled.
				continue
			}
			bundles = append(bundles, b)
		} else {
			targetTxHash = tx.Hash()
		}
	}
	return bundles

func (g *GaslessModule) IsExecutable(approveTxOrNil, swapTx *types.Transaction) bool {
	err := g.VerifyExecutable(approveTxOrNil, swapTx)
	if err != nil {
		return false
	}
	return true
}

// VerifyExecutable checks if the given transactions form a valid gasless transaction
// It returns an error explaining why the transaction is not executable if it's not,
// and a boolean indicating whether the transaction is executable
func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

func (g *GaslessModule) GetLendTxGenerator(approveTxOrNil, swapTx *types.Transaction) *builder.TxOrGen {
	var src []byte
	if approveTxOrNil != nil {
		src = append(src, approveTxOrNil.Hash().Bytes()...)
	}
	src = append(src, swapTx.Hash().Bytes()...)
	bundleHash := crypto.Keccak256Hash(src)

	gen := func(nonce uint64) (*types.Transaction, error) {
		var (
			chainId = g.InitOpts.ChainConfig.ChainID
			signer  = types.LatestSignerForChainID(chainId)
			key     = g.InitOpts.NodeKey
		)

		to, err := types.Sender(signer, swapTx)
		if err != nil {
			return nil, err
		}

		tx, err := types.NewTransactionWithMap(types.TxTypeEthereumDynamicFee, map[types.TxValueKeyType]interface{}{
			types.TxValueKeyNonce:      nonce,
			types.TxValueKeyTo:         &to,
			types.TxValueKeyAmount:     lendAmount(approveTxOrNil, swapTx),
			types.TxValueKeyData:       common.Hex2Bytes("0x"),
			types.TxValueKeyGasLimit:   params.TxGas,
			types.TxValueKeyGasFeeCap:  swapTx.GasFeeCap(),
			types.TxValueKeyGasTipCap:  swapTx.GasTipCap(),
			types.TxValueKeyAccessList: types.AccessList{},
			types.TxValueKeyChainID:    chainId,
		})
		if err != nil {
			return nil, err
		}

		err = tx.Sign(signer, key)
		return tx, err
	}

	return builder.NewTxOrGenFromGen(gen, bundleHash)
}

func repayAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	// R1 = LendTx.Fee() = SwapTx.GasPrice() * TxGas
	r1 := new(big.Int).Mul(swapTx.GasPrice(), new(big.Int).SetUint64(params.TxGas))

	// RepayAmount = R1 + R2 + R3
	return new(big.Int).Add(r1, lendAmount(approveTxOrNil, swapTx))
}
