- `compute_challenge` hashes the domain string, degree, the fixed 131072 zero bytes of the blob, and the (fixed) commitment bytes through `blst_sha256`/`hash_to_bls_field`, producing one deterministic `evaluation_challenge_fr` — the function has no branching on blob content [3](#0-2) .
- In `compute_kzg_proof_impl`, `evaluate_polynomial_in_evaluation_form` with an all-zero `poly` returns `y_out = 0` regardless of `z` (the sum term is always zero since every `poly[i] = 0`) [4](#0-3) .

- The final proof, `g1_lincomb_fast` over the all-zero `q_poly`, is deterministically the identity element on every conforming implementation — there is no non-determinism, no undefined division (the `fr_batch_inv` guard against a zero-input only rejects if the accumulated product is exactly zero, which does not occur here since `ω_i - z` values are generically nonzero field elements, and even in the on-domain case the `m`-branch avoids the same division-by-zero) [6](#0-5) .
- `verify_blob_kzg_proof` recomputes the same deterministic `evaluation_challenge_fr` and `y_fr` (=0) from the same blob/commitment bytes, and the pairing check `verify_kzg_proof_impl` on the (identity commitment, z, y=0, identity proof) succeeds by the standard KZG pairing identity `e(P - [y], G2) == e(Q, X - [z]G2)`, which holds trivially when `P`, `y`, and `Q` are all zero/identity [7](#0-6) .

There is no divergent byte output, no assertion failure, no division-by-zero, and no path where `compute_blob_kzg_proof` for the all-zero blob produces a proof that fails `verify_blob_kzg_proof`. static C_KZG_RET fr_batch_inv(fr_t *out, const fr_t *a, int len) {
    int i;

    assert(len > 0);
    assert(a != out);

    fr_t accumulator = FR_ONE;

    for (i = 0; i < len; i++) {
        out[i] = accumulator;
        fr_mul(&accumulator, &accumulator, &a[i]);
    }

    /* Bail on any zero input */
    if (fr_is_zero(&accumulator)) {
        return C_KZG_BADARGS;
    }

    fr_inv(&accumulator, &accumulator);

    for (i = len - 1; i >= 0; i--) {
        fr_mul(&out[i], &out[i], &accumulator);
        fr_mul(&accumulator, &accumulator, &a[i]);
    }

    return C_KZG_OK;
}

void compute_challenge(fr_t *eval_challenge_out, const Blob *blob, const g1_t *commitment) {
    Bytes32 eval_challenge;
    uint8_t bytes[CHALLENGE_INPUT_SIZE];

    /* Pointer tracking `bytes` for writing on top of it */
    uint8_t *offset = bytes;

    /* Copy domain separator */
    memcpy(offset, FIAT_SHAMIR_PROTOCOL_DOMAIN, DOMAIN_STR_LENGTH);
    offset += DOMAIN_STR_LENGTH;

    /* Copy polynomial degree (16-bytes, big-endian) */
    bytes_from_uint64(offset, 0);
    offset += sizeof(uint64_t);
    bytes_from_uint64(offset, FIELD_ELEMENTS_PER_BLOB);
    offset += sizeof(uint64_t);

    /* Copy blob */
    memcpy(offset, blob->bytes, BYTES_PER_BLOB);
    offset += BYTES_PER_BLOB;

    /* Copy commitment */
    bytes_from_g1((Bytes48 *)offset, commitment);
    offset += BYTES_PER_COMMITMENT;

    /* Make sure we wrote the entire buffer */
    assert(offset == bytes + CHALLENGE_INPUT_SIZE);

    /* Now let's create the challenge! */
    blst_sha256(eval_challenge.bytes, bytes, CHALLENGE_INPUT_SIZE);
    hash_to_bls_field(eval_challenge_out, &eval_challenge);
