**Analysis:**

`CoinRegisterEvent::try_from_bytes` [1](#0-0)  is a pure BCS deserialization helper for a Move event struct that is only ever *produced* on-chain, inside `aptos_framework::account`, when the `CoinRegisterEvent`/`CoinRegister` event is emitted during coin registration: [2](#0-1) . The `type_info` field (a `TypeInfo`/`TypeInfoResource`) is populated by the Move VM's native `type_info::type_of<CoinType>()` at execution time based on the actual coin type's module address — it is never constructed from attacker-supplied bytes at admission time.

The only Rust-side consumers of `CoinRegisterEvent`/`CoinRegister::try_from_bytes` are the storage indexer's V2→V1 event translator [3](#0-2)  and API/indexer JSON serialization for already-committed, already-executed events. These run strictly after execution and epilogue, operating on event data the VM itself produced — they have no path back into `AptosVM::validate_signed_transaction`'s fee-payer resolution logic [4](#0-3)  or the prologue's fee-payer/signer binding in `transaction_validation.rs` [5](#0-4) , both of which derive the fee payer strictly from `transaction_data.fee_payer` / `SignedTransaction` authenticator fields, not from any coin/event data.

Since `account_address` inside a `CoinRegisterEvent`/`TypeInfoResource` is never trusted or consumed by mempool, vm-validator, or VM prologue/epilogue code to determine sender, signer, fee payer, or module context, there is no admission-time binding for an attacker to corrupt via a crafted event payload. The proposed exploit path does not exist in the reachable admission stack.

        let coin_register = CoinRegister::try_from_bytes(v2.event_data())?;
        let struct_tag_str = "0x1::account::Account".to_string();
        let struct_tag = StructTag::from_str(&struct_tag_str)?;
        let (key, sequence_number) = if let Some(state_value_bytes) =
            engine.get_state_value_bytes_for_resource(coin_register.account(), &struct_tag)?
        {
            let account_resource: AccountResource = bcs::from_bytes(&state_value_bytes)?;
            let key = *account_resource.coin_register_events().key();
            let sequence_number = engine
                .get_next_sequence_number(&key, account_resource.coin_register_events().count())?;
            (key, sequence_number)
        } else {
            // The creation number of CoinRegisterEvent is deterministically 0.
            static COIN_REGISTER_EVENT_CREATION_NUMBER: u64 = 0;
            (
                EventKey::new(
                    COIN_REGISTER_EVENT_CREATION_NUMBER,
                    *coin_register.account(),
                ),
                0,
            )
        };
        let coin_register_event = CoinRegisterEvent::new(coin_register.type_info().clone());
        Ok(ContractEventV1::new(
            key,
            sequence_number,
            COIN_REGISTER_EVENT_TYPE.clone(),
            bcs::to_bytes(&coin_register_event)?,
        )?)
