### Title
Missing host-check when attaching Copilot Bearer token allows credential leak on redirect - (File: pkg/cmd/agent-task/capi/client.go)

### Summary
`capiTransport.RoundTrip` in `pkg/cmd/agent-task/capi/client.go` unconditionally sets the `Authorization: Bearer <token>` header on every HTTP request that passes through the shared `http.Client`, with no check on the destination host. This mirrors the analog bug class from the external report — a control that is supposed to gate sensitive behavior based on identity/address is applied inconsistently, so behavior meant only for one target ("CAPI host") leaks onto a different target ("any host"), causing unintended and potentially harmful results (credential disclosure instead of asset misdelivery).

### Finding Description
`newCAPITransport`/`capiTransport.RoundTrip` wraps the base transport used by the same `http.Client` returned from `f.HttpClient()` (see `pkg/cmd/agent-task/shared/capi.go:28-43`), and that client is reused for both GitHub API calls and Copilot API (CAPI) calls per the code's own comment: [1](#0-0) 

Note the header logic: the `Authorization: Bearer <token>` header is set on line 65 for **every** request unconditionally, and only the CAPI-specific headers (`Copilot-Integration-Id`, `X-GitHub-Api-Version`) are gated behind a host check (`req.URL.Host == ct.capiHost`). There is no analogous host check protecting the `Authorization` header itself, and critically no protection against **redirects**: unlike `AddAuthTokenHeader` in `api/http_client.go`, which explicitly detects a hostname change across a redirect and withholds the token in that case: [2](#0-1) 

`capiTransport.RoundTrip` has no equivalent `redirectHostnameChange` check. Since Go's `http.Client` invokes the installed `RoundTripper` again for each hop of a redirect, if any CAPI endpoint (e.g. `GetSessionLogs`, which fetches `agents/sessions/{id}/logs` and reads the raw response body without validating headers) responds with a redirect to an external/attacker-influenced host, the Bearer token would be re-attached and sent to that host by `capiTransport.RoundTrip`: [3](#0-2) 

The existing GHES/redirect handling code elsewhere in the same codebase (`pkg/cmd/run/view/logs_test.go`) shows that log-serving endpoints in this product area commonly return `302` redirects to external log-storage domains, which is the realistic vector for this transport to leak the token to a non-`capiHost` destination.

### Impact Explanation
If the CAPI host or an endpoint fronted by it were to issue (or be tricked into issuing) a redirect to an attacker-controlled host, the CLI would resend the user's Copilot Bearer token (a live, unprivileged-but-sensitive credential tied to the authenticated `gh` user) to that host. This is a credential-exfiltration primitive analogous to the WETH report's "inconsistent handling of a special-case check causing unintended cross-contamination between two code paths that should be kept separate" — here, the separation between "attach Copilot token" and "any destination host" is missing, whereas the codebase's own `AddAuthTokenHeader` demonstrates the correct pattern that should have been reused.

### Likelihood Explanation
Reachability requires only a normal `gh agent-task` / CAPI command flow (e.g. viewing session logs) hitting an endpoint that returns a redirect Location header pointing outside `capiHost`. Because `GetSessionLogs` and other CAPI calls use a plain `http.Client` without a custom `CheckRedirect` policy, standard Go redirect-following semantics apply and the vulnerable transport is invoked on every hop.

### Recommendation
Add the same origin/host check used in `api.AddAuthTokenHeader` to `capiTransport.RoundTrip`: track whether the current request is part of a redirect chain that changed the host, and only attach `Authorization: Bearer <token>` when the destination host equals `capiHost` (or the original request host), withholding the header otherwise.

### Proof of Concept
Not independently executed; based on static code review of `pkg/cmd/agent-task/capi/client.go` and `pkg/cmd/agent-task/capi/sessions.go`, plus the redirect-handling test pattern already present in `pkg/cmd/run/view/logs_test.go:37-64`, which confirms that log-fetch style CAPI/API endpoints in this codebase legitimately return 302 redirects to external domains — the same interaction pattern applicable to `GetSessionLogs`.

func (ct *capiTransport) RoundTrip(req *http.Request) (*http.Response, error) {
	req.Header.Set("Authorization", "Bearer "+ct.token)

	// Since this RoundTrip is reused for both Copilot API and
	// GitHub API requests, we conditionally add the integration
	// ID only when performing requests to the Copilot API.
	if req.URL.Host == ct.capiHost {
		req.Header.Add("Copilot-Integration-Id", "copilot-4-cli")

		// Ensure we are not using GitHub API versions while targeting CAPI.
		req.Header.Set("X-GitHub-Api-Version", "2026-01-09")
	}
	return ct.rp.RoundTrip(req)

// AddAuthTokenHeader adds an authentication token header for the host specified by the request.
func AddAuthTokenHeader(rt http.RoundTripper, cfg tokenGetter) http.RoundTripper {
	return &funcTripper{roundTrip: func(req *http.Request) (*http.Response, error) {
		// If the header is already set in the request, don't overwrite it.
		if req.Header.Get(authorization) == "" {
			var redirectHostnameChange bool
			if req.Response != nil && req.Response.Request != nil {
				redirectHostnameChange = getHost(req) != getHost(req.Response.Request)
			}
			// Only set header if an initial request or redirect request to the same host as the initial request.
			// If the host has changed during a redirect do not add the authentication token header.
			if !redirectHostnameChange {
				hostname := ghauth.NormalizeHostname(getHost(req))
				if token, _ := cfg.ActiveToken(hostname); token != "" {
					req.Header.Set(authorization, fmt.Sprintf("token %s", token))
				}
			}
		}
		return rt.RoundTrip(req)
	}}
}

// GetSessionLogs retrieves logs of an agent session identified by ID.
func (c *CAPIClient) GetSessionLogs(ctx context.Context, id string) ([]byte, error) {
	if id == "" {
		return nil, fmt.Errorf("missing session ID")
	}

	u, err := safeurl.JoinPathWithHostPrefix(c.capiBaseURL, "agents", "sessions", id, "logs")
	if err != nil {
		return nil, err
	}

	req, err := http.NewRequestWithContext(ctx, http.MethodGet, u.String(), http.NoBody)
	if err != nil {
		return nil, err
	}

	res, err := c.httpClient.Do(req)
	if err != nil {
		return nil, err
	}

	defer res.Body.Close()
	if res.StatusCode != http.StatusOK {
		if res.StatusCode == http.StatusNotFound {
			return nil, ErrSessionNotFound
		}
		return nil, fmt.Errorf("failed to get session: %s", res.Status)
	}

	return io.ReadAll(res.Body)
}
