### Title
One Persistently Failing Value Transfer Event Blocks All Subsequent Bridge Transfers in `processingPendingRequestEvents` — (File: `node/sc/bridge_manager.go`)

### Summary
`processingPendingRequestEvents` processes pending cross-chain value transfer events in strict nonce order. When `handleRequestValueTransferEvent` fails for event at nonce N, the function re-queues that event **and every higher-nonce event** back into the pending queue and returns. On every subsequent tick the same failing event is retried first. If the failure is persistent — bridge account KAIA balance depleted, nonce desync, or counterpart bridge unreachable — all user transfers with nonces > N are permanently deferred, locking their assets in the source bridge contract with no on-chain or off-chain skip mechanism.
