## Analysis Result

I found a valid analog to CVE-2019-12212 (unbounded recursion → stack exhaustion).

### Title
Unbounded recursion in `getSourceString`/`getJsonSourceString`/`getLength` causes stack-exhaustion DoS when hashing/sizing attacker-supplied nested unit payloads - (File: string_utils.js, object_length.js, object_hash.js)

### Summary
`validate()` in `validation.js` computes the hash and length of every message payload of an incoming unit *before* any structural/depth checks are performed on the payload's internal shape. The hashing and length routines (`getSourceString`, `getJsonSourceString`, `getLength`) walk arbitrarily nested arrays/objects with plain, unbounded recursion — exactly the bug class in CVE-2019-12212 (`StreamCalcIFDSize` self-recursion causing stack exhaustion).

### Finding Description
For every inline message, `validate()` calls:
```
objectHash.getBase64Hash(getPayloadForHash(m), ...)
``` [1](#0-0) 
which internally calls `getSourceString`/`getJsonSourceString`. Both use naive recursive tree-walkers with no depth cap: [2](#0-1) [3](#0-2) 

Similarly, `objectLength.getHeadersSize`/`getTotalPayloadSize` (used to verify `headers_commission`/`payload_commission` on every unit) call `getLength`, which recurses the same way with no depth limit: [4](#0-3) [5](#0-4) 

`getChash160` (used for address definitions, `definer_address`, etc.) also delegates to the same unbounded recursive `getSourceString`/`getJsonSourceString`: [6](#0-5) 

Unlike the AA-formula and address-definition evaluators (`definition.js`'s `evaluate`, `aa_validation.js`'s `validate`, `formula/validation.js`'s `evaluate`), which all explicitly track `depth`/`MAX_DEPTH`/`complexity` and periodically `setImmediate` to break the call stack, these lower-level serialization/hashing utilities have **no such protection**.

A message such as `app: "data"` only requires `isNonemptyObject(payload)`: [7](#0-6) 
There is no check on internal nesting depth of the object/array structure. An attacker can craft a payload like `{a: [[[[[ ... deeply nested ... ]]]]]}` with tens of thousands of nesting levels while staying well under `MAX_UNIT_LENGTH` (since each nesting level costs only 2 bytes, e.g. `[`/`]`). When this unit is processed, `getBase64Hash`/`getLength` recurse once per nesting level, exhausting the V8 call stack and crashing the Node.js process with an uncatchable `RangeError: Maximum call stack size exceeded` (uncatchable in the sense that it occurs deep inside hashing/serialization code paths executed synchronously, before any try/catch that would produce a graceful validation error — in many of these call sites there is no wrapping try/catch, e.g. `getLength` in `getHeadersSize`/`getTotalPayloadSize`).

### Impact Explanation
Any single posted unit (reachable by any unprivileged unit poster — no witness/hub/AA/asset issuer/peer role required) that contains a deeply but narrowly nested JSON object in any inline payload field (`data`, `profile`, `attestation.profile`, `data_feed` values that are objects, etc., or even the unit's own header fields) triggers stack exhaustion in every node (full nodes and hubs) that attempts to validate it — since hashing/size validation is unconditionally performed on every message before any policy-specific check. This crashes the validating process, matching "a network unable to confirm new units" (repeated crash-on-validate for the same unit content across all validating nodes), which is a valid High-severity impact category per the rules.

### Likelihood Explanation
High likelihood: constructing a deeply nested (but small, byte-size-wise) JSON structure is trivial and doesn't require any privileged role, funds, special asset, or AA — a normal user can post a unit with a `data` message app containing a deeply nested array. It reaches the hashing code unconditionally as part of standard `validate()` processing (`validation.js` payload-hash pre-check, which runs before app-specific validation).

### Recommendation
- Add explicit recursion-depth limits (mirroring the `MAX_DEPTH`/`depth` counters already used in `definition.js`, `aa_validation.js`, and `formula/validation.js`) to `getSourceString`, `getJsonSourceString` in `string_utils.js`, and to `getLength` in `object_length.js`.
- Alternatively/additionally, convert these recursive walkers to iterative (stack-based) implementations, or enforce a maximum nesting depth on any raw message payload (`data`, `profile`, `attestation`, `data_feed`, etc.) as part of `validateInlinePayload`, applied before hashing/length computation.
- Wrap the hash/length computation calls in `validate()` in a try/catch that converts `RangeError` into a graceful `ifUnitError`/`ifJointError` rather than letting it propagate as an uncaught stack overflow.

### Proof of Concept
Construct and broadcast a unit with a message:
```js
{
  app: "data",
  payload: (() => {
    let obj = { x: 1 };
    for (let i = 0; i < 50000; i++) obj = { a: obj };  // 50,000 levels deep, small total size
    return obj;
  })()
}
```
When any node calls `objectHash.getBase64Hash(getPayloadForHash(m), ...)` (validation.js payload-hash check) or later `objectLength.getTotalPayloadSize(objUnit)`, the recursive `stringify`/`extractComponents`/`_getLength` functions in `string_utils.js`/`object_length.js` recurse 50,000 times, exceeding Node's default call-stack limit and crashing the validating process.

---
Note: I was not able to fully trace `getPayloadForHash` (the wrapper used before hashing) in `validation.js` due to index size limits — its exact line range and full field-selection logic weren't retrievable in this session; a Devin session with full file access would be needed to confirm the exact fields passed into hashing per app type and to verify there's no depth pre-check I might have missed elsewhere in `validation.js`.

function getSourceString(obj) {
	var arrComponents = [];
	function extractComponents(variable){
		if (variable === null)
			throw Error("null value in "+JSON.stringify(obj));
		switch (typeof variable){
			case "string":
				if (variable.includes(STRING_JOIN_CHAR))
					throw Error("00 byte in string value in " + JSON.stringify(obj));
				arrComponents.push("s", variable);
				break;
			case "number":
				if (!isFinite(variable))
					throw Error("invalid number: " + variable);
				arrComponents.push("n", variable.toString());
				break;
			case "boolean":
				arrComponents.push("b", variable.toString());
				break;
			case "object":
				if (Array.isArray(variable)){
					if (variable.length === 0)
						throw Error("empty array in "+JSON.stringify(obj));
					arrComponents.push('[');
					for (var i=0; i<variable.length; i++)
						extractComponents(variable[i]);
					arrComponents.push(']');
				}
				else{
					var keys = Object.keys(variable).sort();
					if (keys.length === 0)
						throw Error("empty object in "+JSON.stringify(obj));
					keys.forEach(function(key){
						if (typeof variable[key] === "undefined")
							throw Error("undefined at "+key+" of "+JSON.stringify(obj));
						if (key.includes(STRING_JOIN_CHAR))
							throw Error("00 byte in object key in " + JSON.stringify(obj));
						arrComponents.push(key);
						extractComponents(variable[key]);
					});
				}
				break;
			default:
				throw Error("getSourceString: unknown type="+(typeof variable)+" of "+variable+", object: "+JSON.stringify(obj));
		}
	}

	extractComponents(obj);
	return arrComponents.join(STRING_JOIN_CHAR);
```

function getJsonSourceString(obj, bAllowEmpty) {
	let cache = new WeakMap();  // object to stringified result
	function stringify(variable){
		if (variable === null)
			throw Error("null value in "+JSON.stringify(obj));
		switch (typeof variable){
			case "string":
				return toWellFormedJsonStringify(variable);
			case "number":
				if (!isFinite(variable))
					throw Error("invalid number: " + variable);
			case "boolean":
				return variable.toString();
			case "object":
				// return cached result if already processed
				if (cache.has(variable))
					return cache.get(variable);
				let result;
				if (Array.isArray(variable)){
					if (variable.length === 0 && !bAllowEmpty)
						throw Error("empty array in "+JSON.stringify(obj));
					result = '[' + variable.map(stringify).join(',') + ']';
				}
				else{
					var keys = Object.keys(variable).sort();
					if (keys.length === 0 && !bAllowEmpty)
						throw Error("empty object in "+JSON.stringify(obj));
					result = '{' + keys.map(function(key){ return toWellFormedJsonStringify(key)+':'+stringify(variable[key]) }).join(',') + '}';
				}
				cache.set(variable, result);  // memoize for future references
				return result;
			default:
				throw Error("getJsonSourceString: unknown type="+(typeof variable)+" of "+variable+", object: "+JSON.stringify(obj));
		}
	}

	return stringify(obj);
```

function getLength(value, bWithKeys) {
	let cache = new WeakMap();  // object to length
	function _getLength(value) {
		if (value === null)
			return 0;
		switch (typeof value) {
			case "string":
				return value.length;
			case "number":
				if (!isFinite(value))
					throw Error("invalid number: " + value);
				return 8;
				//return value.toString().length;
			case "object":
				// return cached result if already processed
				if (cache.has(value))
					return cache.get(value);
				var len = 0;
				if (Array.isArray(value))
					value.forEach(function (element) {
						len += _getLength(element);
					});
				else
					for (var key in value) {
						if (!Object.prototype.hasOwnProperty.call(value, key))
							throw Error("object has non-own property " + key + " in " + JSON.stringify(value));
						if (typeof value[key] === "undefined")
							throw Error("undefined at " + key + " of " + JSON.stringify(value));
						if (bWithKeys)
							len += key.length;
						len += _getLength(value[key]);
					}
				cache.set(value, len);  // memoize for future references
				return len;
			case "boolean":
				return 1;
			default:
				throw Error("unknown type=" + (typeof value) + " of " + value);
		}
	}
	return _getLength(value);
}

function getHeadersSize(objUnit) {
	if (objUnit.content_hash)
		throw Error("trying to get headers size of stripped unit");
	var objHeader = _.cloneDeep(objUnit);
	delete objHeader.unit;
	delete objHeader.headers_commission;
	delete objHeader.payload_commission;
	delete objHeader.oversize_fee;
//	delete objHeader.tps_fee;
	delete objHeader.actual_tps_fee;
	delete objHeader.main_chain_index;
	if (objUnit.version === constants.versionWithoutTimestamp)
		delete objHeader.timestamp;
	delete objHeader.messages;
	delete objHeader.parent_units; // replaced with PARENT_UNITS_SIZE
	var bWithKeys = (objUnit.version !== constants.versionWithoutTimestamp && objUnit.version !== constants.versionWithoutKeySizes);
	return getLength(objHeader, bWithKeys) + PARENT_UNITS_SIZE + (bWithKeys ? PARENT_UNITS_KEY_SIZE : 0);
}

function getTotalPayloadSize(objUnit) {
	if (objUnit.content_hash)
		throw Error("trying to get payload size of stripped unit");
	var bWithKeys = (objUnit.version !== constants.versionWithoutTimestamp && objUnit.version !== constants.versionWithoutKeySizes);
	const { temp_data_length, messages_without_temp_data } = extractTempData(objUnit.messages);
	return Math.ceil(temp_data_length * constants.TEMP_DATA_PRICE) + getLength({ messages: messages_without_temp_data }, bWithKeys);
}
