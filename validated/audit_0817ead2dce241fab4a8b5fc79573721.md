### Title
Governance vote for `kip71.gastarget = 0` causes chain-halting division-by-zero panic in `NextMagmaBlockBaseFee` — (`params/kip71_config.go`)

---

### Summary

The `kip71.gastarget` governance parameter accepts `0` as a valid value (via `noopFormatChecker`) and has no consistency guard in `checkConsistency`. When `GasTarget = 0` takes effect, `NextMagmaBlockBaseFee` divides by `gasTarget` without a zero-check, causing a Go `big.Int` division-by-zero **panic** on every block with non-zero gas usage. This halts all honest nodes and constitutes a consensus divergence.

---

### Finding Description

**Root cause 1 — `noopFormatChecker` on `Kip71GasTarget`:**

`Kip71GasTarget` is registered with `noopFormatChecker`, which unconditionally returns `true` for any canonical value, including `0`. [1](#0-0) 

By contrast, `Kip71BaseFeeDenominator` — also used as a divisor — explicitly rejects `0`: [2](#0-1) 

**Root cause 2 — `checkConsistency` returns `nil` for `Kip71GasTarget` without validation:**

`checkConsistency` in `header.go` handles `Kip71LowerBoundBaseFee` and `Kip71UpperBoundBaseFee` with cross-parameter checks, but `Kip71GasTarget` falls into the catch-all `return nil` branch with no validation at all. [3](#0-2) 

**Root cause 3 — `NextMagmaBlockBaseFee` divides by `gasTarget` without a zero-guard:**

`BaseFeeDenominator` has an explicit zero-guard (lines 71–76), but `gasTarget` does not. When `parentGasUsed > 0` and `gasTarget = 0`, execution reaches:

```go
y := x.Div(x, new(big.Int).SetUint64(gasTarget))  // gasTarget == 0 → panic
```

at both the "gas above target" path (line 102) and the "gas below target" path (line 120). [4](#0-3) 

The zero-guard that exists for `BaseFeeDenominator` is absent for `GasTarget`: [5](#0-4) 

**Trigger path:**

The vote is cast via `governance_vote` API → `Vote()` → `NewVoteData()` (passes `noopFormatChecker`) → `checkConsistency` (returns `nil`) → stored in `header.Vote`. At the next epoch boundary, `GetParamSet` returns `GasTarget = 0`. Every subsequent call to `NextMagmaBlockBaseFee` with non-zero `parentGasUsed` panics. [6](#0-5) 

`NextMagmaBlockBaseFee` is called in the block worker, tx pool reset, fee history oracle, and header verification — all of which crash: [7](#0-6) [8](#0-7) 

---

### Impact Explanation

After `GasTarget = 0` takes effect, every node that processes or produces a block with non-zero gas usage panics in `NextMagmaBlockBaseFee`. This halts block production and block validation simultaneously on all honest nodes — a complete consensus divergence and chain halt. The corrupted governance parameter persists in the ratified `header.Governance` field and in the governance DB, so the chain cannot recover without a coordinated out-of-band fix.

---

### Likelihood Explanation

In `single` governance mode (Mainnet/Kairos), only the single governing node needs to cast this vote. In `none` mode, any GC member whose vote is last in the epoch wins. The vote passes every existing validation layer (`NewVoteData`, `DeprecatedAt`, `checkConsistency`). No special exploit is needed beyond calling the standard `governance_vote` RPC.

---

### Recommendation

1. **Add a non-zero `FormatChecker` for `Kip71GasTarget`** in `kaiax/gov/param.go`, mirroring `Kip71BaseFeeDenominator`:
   ```go
   FormatChecker: func(cv any) bool {
       v, ok := cv.(uint64)
       return ok && v != 0
   },
   ```

2. **Add a zero-guard in `NextMagmaBlockBaseFee`** in `params/kip71_config.go`, analogous to the existing `BaseFeeDenominator` guard:
   ```go
   if kc.GasTarget == 0 {
       return makeEvenByFloor(lowerBoundBaseFee)
   }
   ```

3. **Add a `checkConsistency` case for `Kip71GasTarget`** in `kaiax/gov/headergov/impl/header.go` that rejects `0`.

---

### Proof of Concept

```
1. Governing node calls: governance_vote("kip71.gastarget", uint64(0))
2. NewVoteData: noopFormatChecker returns true → vote created
3. checkConsistency: Kip71GasTarget → return nil (no validation)
4. Vote stored in header.Vote at next proposed block
5. At epoch boundary: header.Governance ratifies GasTarget = 0
6. GetParamSet(N) now returns ParamSet{GasTarget: 0, ...}
7. Next block with any transactions (parentGasUsed > 0):
   - worker.go calls NextMagmaBlockBaseFee(parent.Number, parent.BaseFee, parent.GasUsed)
   - gasTarget := kc.GasTarget  // == 0
   - parentGasUsed = min(parentHeaderGasUsed, upperGasLimit) > 0
   - parentGasUsed > gasTarget (0) → enters "else if" branch
   - x.Div(x, new(big.Int).SetUint64(0))  → PANIC: division by zero
8. All nodes crash. Chain halts.
``` [9](#0-8) [1](#0-0) [10](#0-9)

	if kc.BaseFeeDenominator == 0 {
		// To avoid panic, set the fluctuation range small
		baseFeeDenominator = new(big.Int).SetUint64(64)
	} else {
		baseFeeDenominator = new(big.Int).SetUint64(kc.BaseFeeDenominator)
	}
	gasTarget := kc.GasTarget
	upperGasLimit := kc.MaxBlockGasUsedForBaseFee

	// check the case of upper/lowerBoundBaseFee is updated by governance mechanism
	parentBaseFee := parentHeaderBaseFee
	if parentBaseFee.Cmp(upperBoundBaseFee) >= 0 {
		parentBaseFee = upperBoundBaseFee
	} else if parentBaseFee.Cmp(lowerBoundBaseFee) <= 0 {
		parentBaseFee = lowerBoundBaseFee
	}

	// upper gas limit cut off the impulse of used gas to upper bound
	parentGasUsed := min(parentHeaderGasUsed, upperGasLimit)
	if parentGasUsed == gasTarget {
		return makeEvenByFloor(parentBaseFee)
	} else if parentGasUsed > gasTarget {
		// shortcut. If parentBaseFee is already reached upperbound, do not calculate.
		if parentBaseFee.Cmp(upperBoundBaseFee) == 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		// If the parent block used more gas than its target,
		// the baseFee of the next block should increase.
		// baseFeeDelta = max(1, parentBaseFee * (parentGasUsed - gasTarget) / gasTarget / baseFeeDenominator)
		gasUsedDelta := new(big.Int).SetUint64(parentGasUsed - gasTarget)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := math.BigMax(x.Div(y, baseFeeDenominator), common.Big1)

		nextBaseFee := x.Add(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(upperBoundBaseFee) > 0 {
			return makeEvenByFloor(upperBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)
	} else {
		// shortcut. If parentBaseFee is already reached lower bound, do not calculate.
		if parentBaseFee.Cmp(lowerBoundBaseFee) == 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		// Otherwise if the parent block used less gas than its target,
		// the baseFee of the next block should decrease.
		// baseFeeDelta = parentBaseFee * (gasTarget - parentGasUsed) / gasTarget / baseFeeDenominator
		gasUsedDelta := new(big.Int).SetUint64(gasTarget - parentGasUsed)
		x := new(big.Int).Mul(parentBaseFee, gasUsedDelta)
		y := x.Div(x, new(big.Int).SetUint64(gasTarget))
		baseFeeDelta := x.Div(y, baseFeeDenominator)

		nextBaseFee := x.Sub(parentBaseFee, baseFeeDelta)
		if nextBaseFee.Cmp(lowerBoundBaseFee) < 0 {
			return makeEvenByFloor(lowerBoundBaseFee)
		}
		return makeEvenByFloor(nextBaseFee)

func (api *headerGovAPI) Vote(name string, value any) (string, error) {
	var (
		voter     = api.h.nodeAddress
		nextBlock = api.h.Chain.CurrentBlock().NumberU64() + 1
		gp        = api.h.GetParamSet(nextBlock)
		gMode     = gp.GovernanceMode
	)

	if gMode == "single" && voter != gp.GoverningNode {
		return "", ErrVotePermissionDenied
	}

	vote := headergov.NewVoteData(voter, name, value)
	if vote == nil {
		return "", ErrInvalidKeyValue
	}

	if gov.DeprecatedAt(vote.Name(), api.h.ChainConfig.Rules(new(big.Int).SetUint64(nextBlock))) {
		return "", ErrDeprecatedVote
	}

	err := api.h.checkConsistency(nextBlock, vote)
	if err != nil {
		return "", err
	}

	// TODO-kaiax: add removevalidator vote check

	api.h.PushMyVotes(vote)
	return "(kaiax) Your vote is prepared. It will be put into the block header or applied when your node generates a block as a proposer. Note that your vote may be duplicate.", nil
