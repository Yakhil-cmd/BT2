### Title
Proposer Can Remove All Council Validators via `governance.removevalidator` Vote, Permanently Halting Consensus — (File: `kaiax/gov/headergov/impl/header.go`, `kaiax/valset/impl/getter_council.go`)

---

### Summary

In the permissioned (pre-Permissionless fork) governance system, `checkConsistency` imposes no minimum-council-size guard on `RemoveValidator` votes in `"none"` or `"ballot"` governance mode. A single block proposer can cast one multi-address `governance.removevalidator` vote that removes every council member, including themselves. `applyVote` applies the removal unconditionally, leaving `Council(N+1) = ∅`. Any subsequent call to `GetProposer` or `GetCommittee` for block N+1 reaches `AddressSet.At` with an empty list and panics with an integer division-by-zero, permanently halting consensus on all honest nodes.

---

### Finding Description

**Vote verification path — no minimum-size guard**

`VerifyVote` in `kaiax/gov/headergov/impl/header.go` delegates consistency checking to `checkConsistency`. For `gov.RemoveValidator`, the switch arm is:

```go
case gov.AddValidator, gov.RemoveValidator:
    params := h.GetParamSet(blockNum)
    if params.GovernanceMode != "single" {
        return nil          // ← no check at all in "none"/"ballot" mode
    }
    if slices.Contains(vote.Value().([]common.Address), params.GoverningNode) {
        return ErrGovNodeInValSetVoteValue
    }
    return nil
```

In `"none"` or `"ballot"` governance mode the function returns `nil` immediately, with no check on whether the resulting council would be empty. [1](#0-0) 

The `validatorAddressListCanonicalizer` accepts a comma-separated list of addresses, so a single vote can name every current council member. [2](#0-1) 

**Vote application path — no minimum-size guard**

`applyVote` in `kaiax/valset/impl/getter_council.go` removes each named address from the council in-place with no lower-bound check:

```go
case gov.RemoveValidator:
    if council.Contains(address) {
        council.Remove(address)
    }
```

After the loop, `council` can be empty. [3](#0-2) 

The council update formula is `Council(N) = Council(N-1) − RemoveValidatorVotes(N-1)`, so the empty council takes effect at block N+1. [4](#0-3) 

**Crash on empty council**

`AddressSet.At` performs an unchecked modulo:

```go
func (as *AddressSet) At(i int) common.Address {
    return as.list[i%len(as.list)]   // panic: integer divide by zero when len == 0
}
``` [5](#0-4) 

Every proposer-selection path calls `At` or divides by `qualified.Len()`:

- `selectRoundRobinProposer`: `qualified.At((prevIdx + int(round) + 1) % qualified.Len())`
- `selectStickyProposer`: `qualified.At((prevIdx + int(round)) % qualified.Len())`
- `getBlockContext`: `qualified.At(0)` (line 58) [6](#0-5) 

`selectWeightedRandomProposer` and `selectRandaoProposer` similarly index into a list whose length is used as a modulus. [7](#0-6) 

---

### Impact Explanation

Once the council is empty, every honest node that attempts to start a new consensus round calls `GetProposer` → `getBlockContext` → `qualified.At(0)` and panics. No block can ever be proposed or validated again. The chain halts permanently. This is an irreversible consensus divergence / invalid state transition affecting all honest nodes.

---

### Likelihood Explanation

Requires a council member to be selected as proposer (normal rotation) and to cast a malicious multi-address `RemoveValidator` vote. This is a single-validator attack — no majority collusion is needed. The governance mode must be `"none"` or `"ballot"` (not `"single"`). Networks that deploy with these modes are fully exposed.

---

### Recommendation

1. **In `checkConsistency`** (`kaiax/gov/headergov/impl/header.go`): for `RemoveValidator` votes, compute the post-vote council size and reject the vote if it would leave the council empty (or below a safe minimum, e.g. 1).

2. **In `applyVote`** (`kaiax/valset/impl/getter_council.go`): after applying removals, check `council.Len() > 0` and revert the removal if the result would be empty.

3. **Defensive guard in `AddressSet.At`**: return a zero address and log an error instead of panicking when the set is empty.

---

### Proof of Concept

```
Setup:
  - Governance mode: "none" (or "ballot")
  - Council at block N: [A, B, C, D]  (4 validators)
  - Block N proposer: A

Attack:
  1. Validator A, when selected as proposer for block N, crafts a header with:
       Vote = governance.removevalidator([A, B, C, D])
     (multi-address removal, accepted by validatorAddressListCanonicalizer)

  2. VerifyVote passes:
     - A is in council ✓
     - A is the block author ✓
     - governance mode != "single" → checkConsistency returns nil immediately ✓

  3. Block N is committed. PostInsertBlock calls applyVote:
       council.Remove(A); council.Remove(B); council.Remove(C); council.Remove(D)
     → council is now empty; writeCouncil(db, N, []) is stored.

  4. Any node attempting to produce or validate block N+1 calls:
       GetProposer(N+1, 0)
       → getBlockContext(N+1)
       → qualifiedFromHeaderOrState(N+1) → empty AddressSet
       → qualified.At(0)  →  as.list[0 % 0]  →  PANIC: integer divide by zero

  Result: All honest nodes crash. Chain halts permanently.
```

		switch v := v.(type) {
		case []byte: // input from header.Vote
			// There are three types of header.Vote encoding for validator address(es).
			// Type1. Single address, [20]byte. See Mainnet block 5505383.
			// Type2. Multiple addresses, [20*n]byte.
			// Type3. Single address, [42]byte (hex-encoded bytes). See Mainnet block 90915008.

func applyVote(header *types.Header, council *valset.AddressSet, governingNode common.Address) bool {
	voteKey, addresses, ok := parseValidatorVote(header)
	if !ok {
		return false
	}

	originalSize := council.Len()
	for _, address := range addresses {
		if address == governingNode {
			continue
		}
		switch voteKey {
		case gov.AddValidator:
			if !council.Contains(address) {
				council.Add(address)
			}
		case gov.RemoveValidator:
			if council.Contains(address) {
				council.Remove(address)
			}
		}
	}
	return originalSize != council.Len()
```
