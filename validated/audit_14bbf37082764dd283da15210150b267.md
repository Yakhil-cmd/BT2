Confirmed: `getSourceString` in `string_utils.js` performs unbounded recursive traversal of arbitrary objects with no depth limit or interruption of the call stack, and it is invoked on message payloads (and getters like `getUnitHashToSign`, `getBase64Hash`) as part of core, unauthenticated unit-validation logic that runs on every posted unit.

### Title
Unbounded recursive traversal in `getSourceString` allows stack-overflow DoS via deeply nested `data`/`profile` message payloads - (File: string_utils.js)

### Summary
`string_utils.js`'s `getSourceString()` recursively walks arbitrary JS objects/arrays without any depth limit, counter, or `setImmediate` stack-interruption, unlike its sibling protections elsewhere in the codebase (`aa_validation.js` `MAX_DEPTH = 100` checks, `formula/validation.js` depth>100 check, `string_utils.js`'s own `isTooBigObj`/`isTooDeeplyNestedOrHasTooManyNodes` helpers). `getSourceString` is called by `object_hash.getBase64Hash(obj, false)` [1](#0-0)  which is invoked from `validation.js` to verify a message's `payload_hash` against `getPayloadForHash(m)` for every message in every incoming unit, before any app-specific structural/depth validation happens [2](#0-1) .

### Finding Description
The recursive helper function is: [3](#0-2) 

Unlike `isTooBigObj`/`isTooDeeplyNestedOrHasTooManyNodes`, which explicitly bound depth and node count [4](#0-3) , `getSourceString`'s inner `extractComponents` recurses into every array element and object value with no depth cap.

The `data` and `profile` app message payloads are validated only for `typeof payload === "object"` — with no depth, size, or nesting-count check at all: [5](#0-4) 

However, before `validateInlinePayload` is even reached, `validation.js` computes and verifies the SHA-256 hash of every inline message payload by calling `objectHash.getBase64Hash(getPayloadForHash(m), ...)`, which for non-JSON-based units (`objUnit.version === constants.versionWithoutTimestamp`) calls the unbounded `getSourceString`: [6](#0-5) [1](#0-0) 

An attacker can post (or relay) a unit containing a `data` (or `profile`) message whose payload is a deeply nested JSON object/array (e.g., `{"a":{"a":{"a": ... }}}` thousands of levels deep). This payload passes the earlier "must be a non-empty object" / "isNonemptyObject" checks trivially (it's a valid, well-formed object), but when `getSourceString` recurses through it to compute/verify `payload_hash`, the deep nesting triggers a `RangeError: Maximum call stack size exceeded` in the Node.js process handling unit validation — a JS exception that is not defensively caught around this hashing call path in the way malformed-JSON parse errors are.

### Impact Explanation
A crash/`RangeError` thrown deep inside synchronous hashing code during unit validation, if uncaught, can crash the hub/full node process handling the incoming unit (denial of service), consistent with CWE-674 in the referenced advisory. Because this code path is reached by any single posted unit from an unprivileged sender (the `data`/`profile` app message types are ordinary, publicly postable message types validated identically for light and full nodes), this satisfies the requirement of being reachable by an unprivileged unit poster. The severity aligns with "a network unable to confirm new units" if nodes repeatedly crash while trying to validate/relay such a unit.

### Likelihood Explanation
Likelihood is moderate: constructing a unit with a deeply nested `data` message payload is trivial and requires no special privileges, only that the resulting payload still satisfy the size/commission accounting in `object_length.js` (`getTotalPayloadSize`) and overall `MAX_UNIT_LENGTH`. A deeply nested but narrow structure (e.g., single-key chains) can achieve significant nesting depth while staying within typical serialized-size limits, since JSON nesting overhead per level can be very small (`{"a":` ... `}`), potentially allowing thousands of nesting levels within a byte budget well under `MAX_UNIT_LENGTH`.

### Recommendation
Add an explicit recursion-depth (and/or node-count) guard to `getSourceString` in `string_utils.js` (mirroring the `MAX_DEPTH` pattern used in `aa_validation.js` and `formula/validation.js`, or reusing `isTooDeeplyNestedOrHasTooManyNodes`/`isTooBigObj`), and reject payloads that exceed the limit before/while computing `getSourceString`/`getBase64Hash`. Additionally, apply an explicit depth/size check to `data`/`profile`/other free-form object payloads in `validateInlinePayload` (`validation.js`) prior to hash verification, similar to the `isTooBigObj` check already used for `json_parse` results in `formula/evaluation.js`.

### Proof of Concept
Conceptually: construct a unit with a `data` (or `profile`) message whose `payload` is `JSON.parse('{"a":' .repeat(N) + '1' + '}'.repeat(N))` for a sufficiently large `N` (e.g., a few thousand), keep `payload_hash` consistent with what `getBase64Hash`/`getSourceString` would produce (or simply submit any payload — hash verification itself triggers the recursive walk on both the honest and forged hash-computation attempt), and submit/relay the unit for validation. `validation.js`'s early payload-hash verification loop invokes `getSourceString` on the nested object, causing uncontrolled recursion. [7](#0-6)  shows the project is aware of and tests deep-nesting DoS concerns for the *formula* evaluator, but no equivalent guard/test exists for `getSourceString` in `string_utils.js`.

function getSourceString(obj) {
	var arrComponents = [];
	function extractComponents(variable){
		if (variable === null)
			throw Error("null value in "+JSON.stringify(obj));
		switch (typeof variable){
			case "string":
				if (variable.includes(STRING_JOIN_CHAR))
					throw Error("00 byte in string value in " + JSON.stringify(obj));
				arrComponents.push("s", variable);
				break;
			case "number":
				if (!isFinite(variable))
					throw Error("invalid number: " + variable);
				arrComponents.push("n", variable.toString());
				break;
			case "boolean":
				arrComponents.push("b", variable.toString());
				break;
			case "object":
				if (Array.isArray(variable)){
					if (variable.length === 0)
						throw Error("empty array in "+JSON.stringify(obj));
					arrComponents.push('[');
					for (var i=0; i<variable.length; i++)
						extractComponents(variable[i]);
					arrComponents.push(']');
				}
				else{
					var keys = Object.keys(variable).sort();
					if (keys.length === 0)
						throw Error("empty object in "+JSON.stringify(obj));
					keys.forEach(function(key){
						if (typeof variable[key] === "undefined")
							throw Error("undefined at "+key+" of "+JSON.stringify(obj));
						if (key.includes(STRING_JOIN_CHAR))
							throw Error("00 byte in object key in " + JSON.stringify(obj));
						arrComponents.push(key);
						extractComponents(variable[key]);
					});
				}
				break;
			default:
				throw Error("getSourceString: unknown type="+(typeof variable)+" of "+variable+", object: "+JSON.stringify(obj));
		}
	}

	extractComponents(obj);
	return arrComponents.join(STRING_JOIN_CHAR);
}

function isTooDeeplyNestedOrHasTooManyNodes(obj, depthLimit = 100, nodesLimit = 10000) {
	let nodeCount = 0;

	function check(variable, depth){
		if (depth > depthLimit || nodeCount > nodesLimit)
			return true;
		if (variable === null || typeof variable !== "object")
			return false;
		if (Array.isArray(variable)) {
			nodeCount += variable.length;
			for (let v of variable)
				if (check(v, depth + 1))
					return true;
		}
		else {
			nodeCount += Object.keys(variable).length;
			for (let key in variable)
				if (check(variable[key], depth + 1))
					return true;
		}
		return false;
	}

	return check(obj, 1);
}

function isTooBigObj(obj, { depthLimit = 100, nodesLimit = 10000, lengthLimit = 1000000 }) {
	let nodeCount = 0;
	let length = 0;

	function check(variable, depth){
		if (depth > depthLimit || nodeCount > nodesLimit || length > lengthLimit)
			return true;
		if (typeof variable === "string")
			length += variable.length;
		else if (typeof variable === "number" || typeof variable === "boolean")
			length += variable.toString().length;
		else if (variable === null)
			length += 4; // "null"
		else if (typeof variable !== "object")
			throw Error("isTooBigObj: unexpected type=" + (typeof variable) + " of " + variable);
		if (length > lengthLimit)
			return true;
		if (typeof variable !== "object" || variable === null)
			return false;
		if (Array.isArray(variable)) {
			nodeCount += variable.length;
			for (let v of variable)
				if (check(v, depth + 1))
					return true;
		}
		else {
			const keys = Object.keys(variable);
			nodeCount += keys.length;
			length += keys.reduce((sum, key) => sum + key.length, 0);
			for (let key in variable)
				if (check(variable[key], depth + 1))
					return true;
		}
		return false;
	}

	return check(obj, 1);
}
