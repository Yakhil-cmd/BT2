### Title
Sigverify worker parses transaction structure and computes cost/priority for unsigned/unverified packets before ed25519 signature verification, enabling unauthenticated CPU resource exhaustion during load - ([File: core/src/sigverify.rs])

### Summary
In `SigVerifyWorkerPool::run_transaction_task`, when the scheduler's priority floor is active, every non-deduplicated packet in a batch is fully parsed, sanitized, and cost-scored via `calculate_priority_from_bytes` before `sigverify::ed25519_verify_serial` is ever called to check the packet's signature. [1](#0-0)  This mirrors the reported bug class: expensive body/message processing occurs prior to the authentication (signature) check, letting an unauthenticated sender force disproportionate work per rejected packet.

### Finding Description
`run_transaction_task` processes each incoming packet batch in this order: (1) dedup, (2) if a non-zero priority floor is published by the scheduler, call `apply_priority_floor_to_batch`, and only then (3) `sigverify::ed25519_verify_serial` to cryptographically verify signatures. [2](#0-1) 

`apply_priority_floor_to_batch` invokes `calculate_priority_from_bytes(bank, data)` on every packet that hasn't already been marked as discarded — with no precondition that the packet's signature has been checked. [3](#0-2) 

`calculate_priority_from_bytes` performs substantial parsing/compute work on the raw bytes:
- Builds a `SanitizedTransactionView` (structural parse of the whole compact-encoded transaction).
- Constructs a `RuntimeTransaction` from the view, which in turn parses every instruction for compute-budget details via `ComputeBudgetInstructionDetails::try_from` / `InstructionMeta::try_new`.
- Resolves the transaction configuration and runs the cost model (`calculate_priority_and_cost`) to derive write-lock cost, data-bytes cost, and execution cost. [4](#0-3) 

None of this requires a valid signature — `calculate_priority_from_bytes` only requires the bytes to structurally sanitize (`SanitizedTransactionView::try_new_sanitized`), which does not verify signatures against pubkeys; the actual ed25519 check (`sigverify::ed25519_verify_serial`, which walks `view.signatures()...all(|(signature, pubkey)| signature.verify(...))`) happens strictly afterward in the pipeline. [5](#0-4) 

The parsing/cost-model work in `calculate_priority_from_bytes` is more expensive per packet than a single ed25519 verification (multiple linear passes over instructions, address-lookup handling, cost accounting), so an attacker who submits many structurally-valid-but-unsigned (or garbage-signed) transactions can force the validator to spend more CPU per rejected packet than it would spend simply verifying and discarding an invalid signature.

### Impact Explanation
This matches CWE-400/CWE-408 (uncontrolled resource consumption due to expensive processing performed before the cheap authentication check). Critically, this code path is only exercised when `state.priority_floor` is active with `floor > 0` — i.e., precisely when the scheduler has already signaled congestion/backlog. [6](#0-5)  An attacker can therefore amplify CPU load on sigverify workers exactly at the moment the validator is already under load, worsening TPU-port congestion and potentially degrading transaction throughput or leader block production for legitimate unprivileged senders. This is a transaction/packet-ingestion-triggered resource-exhaustion vector reachable without any valid signature or stake.

### Likelihood Explanation
Any unprivileged client can send arbitrary packets to a validator's TPU port. The only requirement to trigger the expensive path is that the packet bytes structurally sanitize as a `SanitizedTransactionView` (a much weaker bar than passing cryptographic signature verification), so crafting many such "sanitizable but signature-invalid" packets is straightforward and requires no special access, stake, or leader status. The trigger condition (non-zero priority floor) occurs naturally under normal network load/congestion, which is also when the impact is most damaging.

### Recommendation
Reorder the checks in `run_transaction_task` so that cheap discard filters run first and the (relatively cheap) ed25519 signature verification happens before the more expensive `calculate_priority_from_bytes` parsing/cost-model computation used for priority-floor filtering. At minimum, `apply_priority_floor_to_batch` should only be applied to packets that have already passed `ed25519_verify_serial`, or `calculate_priority_from_bytes` should be replaced with a lighter-weight extraction that avoids full compute-budget-instruction parsing and cost-model evaluation for as-yet-unauthenticated packets.

### Proof of Concept
1. Enable/observe a validator under load such that the scheduler publishes a non-zero `SchedulerPriorityFloor` (the normal congestion condition the mechanism is designed for).
2. Craft a flood of packets containing structurally valid, compact-encoded transactions (valid header, account keys, instructions, compute-budget instructions) but with invalid/garbage signatures (or simply zeroed signatures that will fail `ed25519_verify_serial`).
3. Send these packets to the TPU/QUIC ingestion path feeding `SigVerifyWorkerPool`.
4. Observe that each packet routes through `apply_priority_floor_to_batch` → `calculate_priority_from_bytes`, performing full transaction-view parsing, compute-budget-instruction processing, and cost-model calculation for every packet, before any packet reaches `ed25519_verify_serial` — measurable via increased `total_priority_floor_time_us` relative to `total_verify_time_us` in `SigVerifyWorkerStats`. [7](#0-6)

fn apply_priority_floor_to_batch(
    batch: &mut PacketBatch,
    floor: u64,
    bank: &Bank,
) -> (usize, bool) {
    let mut dropped: usize = 0;
    let mut any_kept = false;
    for mut packet in batch.iter_mut() {
        if packet.meta().discard() {
            continue;
        }
        let Some(data) = packet.data(..) else {
            // Zero-length or otherwise unreadable: leave to downstream
            // stages to reject.
            any_kept = true;
            continue;
        };
        // Unparseable packets are kept and left for downstream rejection.
        match calculate_priority_from_bytes(bank, data) {
            Some(priority) if priority <= floor => {
                packet.meta_mut().set_discard(true);
                dropped = dropped.saturating_add(1);
            }
            _ => any_kept = true,
        }
    }
    (dropped, !any_kept)

pub(crate) fn calculate_priority_from_bytes(bank: &Bank, data: &[u8]) -> Option<u64> {
    let view = SanitizedTransactionView::try_new_sanitized(data, &sanitize_config()).ok()?;
    let runtime_tx = RuntimeTransaction::<SanitizedTransactionView<_>>::try_new(
        view,
        MessageHash::Compute,
        None,
    )
    .ok()?;
    let transaction_configuration = runtime_tx
        .transaction_configuration(&bank.feature_set)
        .ok()?;
    let (priority, _cost) =
        calculate_priority_and_cost(bank, &runtime_tx, &transaction_configuration);

    Some(priority)
}

fn verify_packet(packet: &mut PacketRefMut, reject_non_vote: bool, enable_tx_v1: bool) -> bool {
    // If this packet was already marked as discard, drop it
    if packet.meta().discard() {
        return false;
    }

    let Some(data) = packet.data(..) else {
        return false;
    };

    let (is_simple_vote_tx, verified) = {
        let Ok(view) = SanitizedTransactionView::try_new_sanitized(data, &sanitize_config()) else {
            return false;
        };

        if !enable_tx_v1 && matches!(view.version(), TransactionVersion::V1) {
            return false;
        }

        let is_simple_vote_tx = is_simple_vote_transaction_view(&view);
        if reject_non_vote && !is_simple_vote_tx {
            (is_simple_vote_tx, false)
        } else {
            let signatures = view.signatures();
            if signatures.is_empty() {
                (is_simple_vote_tx, false)
            } else {
                let message = view.message_data();
                let static_account_keys = view.static_account_keys();
                let verified = signatures
                    .iter()
                    .zip(static_account_keys.iter())
                    .all(|(signature, pubkey)| signature.verify(pubkey.as_ref(), message));
                (is_simple_vote_tx, verified)
            }
        }
    };

    if is_simple_vote_tx {
        packet.meta_mut().flags |= PacketFlags::SIMPLE_VOTE_TX;
    }

    verified
}
