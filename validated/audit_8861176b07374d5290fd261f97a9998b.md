The sigverify pipeline verifies signatures cryptographically **before** packets reach `insert_packet`/`insert_vote`: `verify_packet` in `perf/src/sigverify.rs` checks `signature.verify(pubkey.as_ref(), message)` for every signature/pubkey pair, and if this fails the packet is marked `discard` via `packet.meta_mut().set_discard(true)` (caller-enforced per the doc comment). Once discarded, `BytesPacket::data()` returns `None`, so `vote_packet_receiver.rs`'s `buffer_packet_batch` (`let Some(packet_data) = packet.data(..) else { continue; }`) skips it before it ever reaches `SanitizedTransactionView::try_new_sanitized` or `vote_storage.insert_packet`.
