## Analysis: Missing length check after string split leads to index-out-of-range panic on attacker-controlled attestation data

### Title
Unchecked split length in `getOrgAndRepo` causes crash on attacker-controlled attestation predicate content - (File: `pkg/cmd/attestation/inspect/bundle.go`)

### Summary
`getOrgAndRepo` parses the `repository` field taken from an attestation's SLSA predicate (`predicate.BuildDefinition.ExternalParameters.Workflow.Repository`) by trimming a known prefix and then splitting the remainder on `/`, indexing `parts[0]` and `parts[1]` without first checking that the split produced at least two elements. [1](#0-0) 

### Finding Description
This is the direct analog of the reported Solidity bug class: data taken from untrusted, externally-supplied content is decoded/parsed without validating its length before extraction, so a malformed value leads to wrong data or a crash. Here, instead of `abi.decode` on unchecked bytes, the code does `strings.Split(after, "/")` and unconditionally accesses `parts[0]` and `parts[1]`: [2](#0-1) 

The `repoURL` value originates from the attestation predicate content, which is decoded from an attestation bundle: [3](#0-2) 

Attestation bundles are attacker-influenced content in normal `gh` workflows: they can be loaded from a local `.json`/`.jsonl` bundle file, fetched from an OCI registry, or fetched from the GitHub API, all of which are treated as external/untrusted input by the attestation verification code: [4](#0-3) [5](#0-4) 

If the `Repository` field in the predicate does not contain a `/` after the `https://github.com/` (or tenant) prefix — e.g. `https://github.com/foo` or `https://github.com/` — then `after` is `"foo"` or `""`, `strings.Split(after, "/")` returns a slice of length 1 (or 1 with an empty string), and `parts[1]` panics with an index-out-of-range runtime error.

### Impact Explanation
This causes an unhandled panic and process crash (`gh` CLI denial of service) when processing a maliciously crafted or malformed attestation bundle via `gh attestation inspect`. Since attestation bundles can be supplied by third parties (e.g., a package's attestation fetched from an OCI registry, a `.jsonl` bundle downloaded from the network, or content controlled by whoever published the artifact being inspected), an attacker can trigger a crash for any user who runs `gh attestation inspect` against their artifact/bundle. This is lower severity than memory corruption but represents a concrete, reachable robustness/availability bug matching the "decode without length check" bug class from the source report.

### Likelihood Explanation
Likelihood is high for any user who inspects attestations from third-party sources (a common workflow, since `gh attestation inspect` is specifically designed to examine bundles that haven't been trust-verified). No authentication or special access is required by the attacker — they only need to control or influence the content of an attestation bundle that a victim inspects.

### Recommendation
Validate the split result length before indexing, e.g.:
```go
parts := strings.Split(after, "/")
if len(parts) != 2 || parts[0] == "" || parts[1] == "" {
    return "", "", fmt.Errorf("failed to get org and repo from %s", repoURL)
}
return parts[0], parts[1], nil
```

### Proof of Concept
Craft (or modify) a local attestation bundle (`.jsonl`) whose in-toto predicate contains:
```json
"buildDefinition": {
  "externalParameters": {
    "workflow": { "repository": "https://github.com/onlyowner" }
  }
}
```
Run:
```
gh attestation inspect malicious-bundle.jsonl
```
`getAttestationDetail` → `getOrgAndRepo` executes `strings.Split("onlyowner", "/")`, producing `["onlyowner"]`; the subsequent `parts[1]` access panics, crashing the `gh` process.

func getOrgAndRepo(tenant, repoURL string) (string, string, error) {
	var after string
	var found bool
	if tenant == "" {
		after, found = strings.CutPrefix(repoURL, "https://github.com/")
		if !found {
			return "", "", fmt.Errorf("failed to get org and repo from %s", repoURL)
		}
	} else {
		after, found = strings.CutPrefix(repoURL,
			fmt.Sprintf("https://%s.ghe.com/", tenant))
		if !found {
			return "", "", fmt.Errorf("failed to get org and repo from %s", repoURL)
		}
	}

	parts := strings.Split(after, "/")
	return parts[0], parts[1], nil
}

// GetLocalAttestations returns a slice of attestations read from a local bundle file.
func GetLocalAttestations(path string) ([]*api.Attestation, error) {
	var attestations []*api.Attestation
	var err error
	fileExt := filepath.Ext(path)
	if fileExt == ".json" {
		attestations, err = loadBundleFromJSONFile(path)
	} else if fileExt == ".jsonl" {
		attestations, err = loadBundlesFromJSONLinesFile(path)
	} else {
		return nil, ErrUnrecognisedBundleExtension
	}

	if err != nil {
		var pathErr *os.PathError
		if errors.As(err, &pathErr) {
			return nil, fmt.Errorf("could not load content from file path %s: %w", path, err)
		} else if errors.Is(err, bundle.ErrValidation) {
			return nil, err
		}
		return nil, fmt.Errorf("bundle content could not be parsed: %w", err)
	}

	return attestations, nil
}
