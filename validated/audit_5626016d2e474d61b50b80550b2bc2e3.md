### Title
Terminal escape-sequence injection via attacker-controlled devcontainer.json port label reaching table output unsanitized - (File: pkg/cmd/codespace/ports.go)

### Summary
`(*portInfo).Label` returns the raw `label` field from a `.devcontainer/devcontainer.json` file fetched from the codespace's repository, and in the non-`--json` path this value is passed directly to `tp.AddField` with no escaping, whereas the `--json` path serializes the same value through `encoding/json`, which escapes control characters. An attacker who controls a repository's devcontainer configuration (e.g., via a fork or PR the victim opens as a codespace) can embed terminal control/escape sequences in a port label that render unsafely only when the victim runs the default `gh codespace ports` table output.

### Finding Description
`getDevContainer` fetches `.devcontainer/devcontainer.json` from the codespace's repository contents via `apiClient.GetCodespaceRepositoryContents` and unmarshals it into `devContainer.PortAttributes[port].Label` [1](#0-0) [2](#0-1) . This label is attacker-controlled content of a repository the victim opens as a codespace. `(*portInfo).Label` returns this value verbatim: [3](#0-2) .

In `ListPorts`, when no `--json` exporter is set, the code calls `tp.AddField(port.Label())` directly, writing the raw string into the table renderer with no escaping applied at this call site [4](#0-3) . In contrast, when `--json` is used, `exporter.Write` serializes `ExportData` (which also calls `pi.Label()`) through `encoding/json`, which escapes ASCII control characters (e.g., `\u001b` for ESC) by design [5](#0-4) .

The table rendering itself is delegated to the vendored `github.com/cli/go-gh/v2/pkg/tableprinter` via `internal/tableprinter.TablePrinter.AddField`, which is a thin wrapper with no additional sanitization added in this repo's own code [6](#0-5) . I was unable to inspect the internals of the vendored `go-gh` tableprinter package within this index to confirm definitively whether it strips ANSI/control sequences before writing to `a.io.Out`; this is a real gap in verification. If it does not strip such sequences (consistent with the general design of these table libraries, which focus on column alignment/truncation rather than security sanitization), then arbitrary control bytes in the label reach the terminal unescaped.

### Impact Explanation
If unescaped, this allows terminal escape-sequence injection (e.g., cursor manipulation, terminal title spoofing, or on vulnerable terminal emulators more severe effects) when a victim lists ports for a codespace created from an attacker-influenced repository/devcontainer configuration. This matches the "terminal injection / output spoofing" impact class rather than direct code execution, since the vulnerable class in `gh` CLI output paths.

### Likelihood Explanation
Preconditions: the victim must open a codespace against a repository whose `.devcontainer/devcontainer.json` is attacker-influenced (fork, PR branch, or a repo the victim was directed to), and then run plain `gh codespace ports` (no `--json`) in a terminal. This is a plausible but not trivial precondition — it requires the victim to create/select a codespace from attacker content, which does happen in fork/PR review workflows.

### Recommendation
Sanitize or strip ASCII control characters (particularly ESC, `\x1b`) from `portInfo.Label()` output (or centrally within `internal/tableprinter.AddField`) before writing to the table, mirroring the escaping that `encoding/json` already performs for the `--json` path, so both output paths have consistent, safe handling of untrusted label text.

```go
func getDevContainer(ctx context.Context, apiClient apiClient, codespace *api.Codespace) <-chan devContainerResult {
	ch := make(chan devContainerResult, 1)
	go func() {
		contents, err := apiClient.GetCodespaceRepositoryContents(ctx, codespace, ".devcontainer/devcontainer.json")
		if err != nil {
			ch <- devContainerResult{nil, fmt.Errorf("error getting content: %w", err)}
			return
		}

		if contents == nil {
			ch <- devContainerResult{nil, nil}
			return
		}

		convertedJSON := normalizeJSON(jsonc.ToJSON(contents))
		if !jsonc.Valid(convertedJSON) {
			ch <- devContainerResult{nil, errors.New("failed to convert json to standard json")}
			return
		}

		var container devContainer
		if err := json.Unmarshal(convertedJSON, &container); err != nil {
			ch <- devContainerResult{nil, fmt.Errorf("error unmarshalling: %w", err)}
			return
		}

		ch <- devContainerResult{&container, nil}
	}()
	return ch
```

```go
// IsTTY gets whether the TablePrinter will render to a terminal.
func (t *TablePrinter) IsTTY() bool {
	return t.isTTY
}

// AddTimeField in TTY mode displays the fuzzy time difference between now and t.
// In non-TTY mode it just displays t with the time.RFC3339 format.
func (tp *TablePrinter) AddTimeField(now, t time.Time, c func(string) string) {
	var tf string
	if tp.isTTY {
		tf = text.FuzzyAgo(now, t)
	} else {
		tf = t.Format(time.RFC3339)
	}
	tp.AddField(tf, WithColor(c))
}

var (
	WithColor    = tableprinter.WithColor
	WithPadding  = tableprinter.WithPadding
	WithTruncate = tableprinter.WithTruncate
)
```
