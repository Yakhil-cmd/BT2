### Title
Missing Deadline Enforcement in `VerifyExecutable` / `ExtractTxBundles` Allows Expired GaslessSwapTx to Be Bundled, Causing Proposer KAIA Loss — (`kaiax/gasless/impl/getter.go`, `kaiax/gasless/impl/builder.go`)

---

### Summary

The Kaia gasless module (`kaiax/gasless`) implements a `deadline` field inside every `GaslessSwapTx` (the `swapForGas` calldata parameter). The deadline is checked at txpool admission time in `checkBalanceForSwap`, but it is **never checked** in `VerifyExecutable` or `ExtractTxBundles` — the two functions that gate bundle creation during block building. A user can submit a SwapTx with `deadline == lastBlockTime`, which passes the admission check, but is expired relative to the next block's timestamp. The proposer's block-building code still creates the bundle `[LendTx, ApproveTx, SwapTx]`, the LendTx executes (proposer sends KAIA to the user), and the SwapTx reverts on-chain due to the expired deadline. The proposer loses the lent KAIA with no repayment.

---

### Finding Description

**Deadline check exists only at txpool admission — not at bundle extraction.**

`checkBalanceForSwap` in `kaiax/gasless/impl/tx_pool.go` performs the deadline check:

```go
// tx.deadline >= currentTimestamp
deadline := swapArgs.Deadline
if deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
    return fmt.Errorf("insufficient deadline: ...")
}
``` [1](#0-0) 

This check uses `g.Chain.CurrentBlock().Time()` — the **last confirmed block's timestamp** — not the timestamp of the block being built. It is called only from `GetCheckBalance()`, which is invoked during txpool admission and `demoteUnexecutables()`.

`VerifyExecutable`, which is the canonical validity gate for gasless bundles, checks SP1–SP4 (sender, token, nonce, repay amount) but **contains no deadline check**: [2](#0-1) 

`ExtractTxBundles`, called during block building, calls `IsExecutable` → `VerifyExecutable` and creates the bundle without any deadline validation:

```go
} else if g.IsSwapTx(tx) && g.IsExecutable(approveTxs[addr], tx) {
    bundleTxs := builder.NewTxOrGenList(g.GetLendTxGenerator(approveTxs[addr], tx))
    ...
    bundles = append(bundles, b)
}
``` [3](#0-2) 

The LendTx generator unconditionally creates a KAIA transfer from the proposer to the user: [4](#0-3) 

The lend amount is `ApproveTx.Fee() + SwapTx.Fee()`: [5](#0-4) 

---

### Impact Explanation

When a SwapTx with `deadline == lastBlockTime` is bundled into the next block (whose `block.timestamp = lastBlockTime + 1`):

1. **LendTx executes**: proposer transfers `lendAmount` KAIA to the user — this is an irreversible state change.
2. **SwapTx reverts**: the GaslessSwapRouter contract enforces `require(block.timestamp <= deadline)` (standard Uniswap-style deadline enforcement), so the swap fails.
3. **No repayment**: the user retains the lent KAIA and their tokens. The proposer's KAIA is permanently lost.

The corrupted value is `lendAmount = ApproveTx.Fee() + SwapTx.Fee()` in KAIA, transferred from the proposer's account to the user's account with no corresponding repayment. This is an unauthorized KAIA transfer from a system-privileged actor (the block proposer) caused by a missing validity check in the production bundle-building path.

---

### Likelihood Explanation

- The attack requires submitting a SwapTx with `deadline == g.Chain.CurrentBlock().Time()`. The current block timestamp is public.
- In Kaia's ~1-second BFT block time, the next block's timestamp will be `lastBlockTime + 1`, making the deadline expired.
- The `demoteUnexecutables()` call (which re-runs `checkBalanceForSwap`) uses the same `lastBlockTime` reference, so it does **not** evict the tx before block building begins.
- The attack is repeatable across multiple blocks and multiple users simultaneously.
- No privileged access is required; any user of the gasless system can trigger this.

---

### Recommendation

Add a deadline check inside `VerifyExecutable` using the **pending block's timestamp** (passed as a parameter), and also inside `ExtractTxBundles` before creating the bundle:

```go
// In VerifyExecutable, add a pendingBlockTime parameter:
if swapArgs.Deadline.Cmp(pendingBlockTime) < 0 {
    return fmt.Errorf("swap deadline expired: deadline=%s, blockTime=%s",
        swapArgs.Deadline, pendingBlockTime)
}
```

`ExtractTxBundles` should receive the pending block header and pass its timestamp to `IsExecutable`/`VerifyExecutable`. This mirrors the standard pattern used in Uniswap and openGSN forwarders where deadline is validated at execution time, not only at submission time.

---

### Proof of Concept

```
1. Observe current block N with timestamp T.
2. Construct SwapTx with deadline = T (exactly equal to last block time).
3. Submit SwapTx to txpool.
   → checkBalanceForSwap: deadline(T) >= currentBlock.Time(T) → PASSES (not strictly less than).
4. txPool.demoteUnexecutables() runs after block N insertion:
   → same check: deadline(T) >= blockN.Time(T) → PASSES, tx stays in pending.
5. Block N+1 building begins (block.timestamp = T+1):
   → ExtractTxBundles calls IsExecutable → VerifyExecutable → NO deadline check.
   → Bundle [LendTx, ApproveTx, SwapTx] is created.
6. Block N+1 is executed:
   → LendTx: proposer sends lendAmount KAIA to user. ✓ (irreversible)
   → ApproveTx: user approves router. ✓
   → SwapTx: GaslessSwapRouter checks require(block.timestamp(T+1) <= deadline(T)) → REVERTS.
7. Result: proposer loses lendAmount KAIA; user retains tokens and lent KAIA.
```

func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}

func lendAmount(approveTxOrNil, swapTx *types.Transaction) *big.Int {
	r := new(big.Int)

	// R2 = ApproveTx.Fee() if exists
	if approveTxOrNil != nil {
		r.Add(r, approveTxOrNil.Fee())
	}

	// R3 = SwapTx.Fee()
	r.Add(r, swapTx.Fee())

	// LendAmount = R2 + R3
	return r
}
