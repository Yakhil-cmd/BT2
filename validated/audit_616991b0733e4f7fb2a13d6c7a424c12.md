### Title
Insolvent-account liquidation bonuses enlarge socialized bad debt - (File: contracts/controller/src/positions/liquidation/curve.rs)

### Summary
XOXNO Lending preserves health factor for solvent liquidations, but switches to a fixed base-bonus quote once `total_collateral < total_debt`. A permissionless `liquidate` call can therefore seize collateral worth more than the debt repaid, leave a larger residual unsecured balance, and immediately socialize that balance through bad-debt cleanup, imposing the liquidation bonus on suppliers.

### Finding Description
`liquidate` accepts a liquidator-specified debt-payment list and delegates sizing to `build_liquidation_plan`. [1](#0-0)  The plan snapshots `total_debt`, `total_collateral`, weighted collateral, `proportion_seized`, and the health factor. [2](#0-1) 

For a solvent account, `max_hf_preserving_bonus_bps` caps the bonus so `1 + bonus <= HF / proportion_seized`, preventing the seizure premium from reducing post-liquidation health factor. [3](#0-2)  However, `estimate_liquidation_amount` bypasses that bound whenever `total_collateral < total_debt`: it returns `min(D, floor(C / (1 + base)))` while still paying the base liquidation bonus. [4](#0-3) 

The seizure calculation then allocates `repay_usd * (1 + bonus)` of collateral pro-rata. [5](#0-4)  When the accepted repayment reaches the collateral-backed quote within token-unit rounding, `seize_all` causes every collateral leg to be capped at its entire held `actual_ray` balance rather than merely the proportional computed amount. [6](#0-5) [7](#0-6) 

After seizure, `check_bad_debt_after_liquidation` socializes the account whenever remaining debt exceeds remaining collateral and collateral is no more than the dust threshold; a seizure of all collateral satisfies this condition whenever any debt remains. [8](#0-7)  Cleanup submits the residual borrow positions to the pool, which writes the unpaid debt down through `apply_bad_debt_to_supply_index`, reducing supplier claims pro-rata. [9](#0-8) [10](#0-9) 

### Impact Explanation
This is a protocol-insolvency analog rather than merely an unfavorable borrower outcome. For collateral value `C`, debt `D > C`, and base bonus `b`, the liquidator repays approximately `C / (1 + b)` and receives approximately `C`. The residual bad debt becomes:

```text
D - C / (1 + b)
```

instead of the smaller `D - C` that would remain if collateral were applied one-for-one. The liquidation bonus therefore increases the amount immediately written down against the debt market's supply index, transferring the bonus cost to suppliers. [11](#0-10) 

### Likelihood Explanation
Any unprivileged liquidator can invoke `liquidate` once the account has `health_factor < 1` and `total_collateral < total_debt`; account ownership is not required. [12](#0-11)  The liquidator need only offer enough debt tokens to reach the collateral-backed quote; excess offers are trimmed by repayment normalization, while `seize_all` still awards all collateral when the accepted amount is within one native unit of the quote. [13](#0-12) 

The resulting loss is bounded by the base-bonus fraction of the insolvent account's collateral, but it repeats for every insolvent liquidation and does not require privileged configuration, oracle manipulation, or an external protocol failure.

### Recommendation
For `C < D`, do not pay a liquidation bonus out of collateral that is already insufficient to cover debt. Cap seizure value at received repayment value, or calculate the maximum repaid amount as `min(D, C)` with no bonus on the insolvent shortfall. If liquidator incentives are still needed for bad-debt cleanup, fund them from protocol revenue or a dedicated reserve rather than increasing supplier socialization.

### Proof of Concept
Assume one collateral asset and one debt asset, strict oracle prices, `C = $100`, `D = $105`, and weighted collateral still below debt so `HF < 1`. Let the stamped weighted base bonus be `5%`.

1. The attacker calls `liquidate(liquidator, account_id, [(debt_hub_asset, amount >= $95.238...)] , SeizeMode::Transfer)` or equivalent `Credit` mode.
2. Because `C < D`, `estimate_liquidation_amount` selects the insolvency quote `floor(100 / 1.05) = $95.238...` at `5%` bonus. [14](#0-13) 
3. The controller pulls about `$95.24` of debt tokens from the attacker and reduces the borrow position by that measured receipt. [15](#0-14) 
4. Seizure is calculated as `95.238... * 1.05 = $100`, and `seize_all` awards the entire collateral balance to the liquidator, less only any configured liquidation fee. [16](#0-15) 
5. The account now has `D' = $9.76` and `C' = $0`, satisfying the socialization predicate because debt exceeds collateral and collateral is below the dust threshold. [17](#0-16) 
6. `check_bad_debt_after_liquidation` invokes cleanup, and the pool burns the remaining debt while reducing the debt market's supply index by the unpaid `$9.76`. [18](#0-17) [19](#0-18) 

Without the bonus, repaying the same `$100` collateral value would leave only `$5` of bad debt; the liquidation premium therefore adds `$4.76` to supplier losses in this example.

/// Allocates repayment plus bonus pro-rata by collateral USD value, capped at
/// each held balance. Principal comes from the uncapped seizure; fees apply
/// only to bonus remaining after the cap.
///
/// Transfer amounts round down for partial closes and half-up for full closes.
/// Positive fees floor to asset units with a one-unit minimum, capped by the
/// whole units the pool pays above the repayment share. Credit mode retains a
/// separate exact share representation.
///
/// A partial leg below `MIN_BORROWABLE_ASSET_DECIMALS` seizes whole units only:
/// rounded up to the held balance when the plan repays all debt, down otherwise.
/// Returns the seizures and the repayment USD that the dropped fractions no
/// longer back, floored so the kept repayment rounds toward the protocol.
pub(crate) fn calculate_seized_collateral(
    env: &Env,
    account: &Account,
    total_collateral: Wad,
    repayment: &NormalizedRepaymentPlan,
    cache: &mut Context,
) -> (Vec<SeizeEntry>, Wad) {
    let mut seized: Vec<SeizeEntry> = Vec::new(env);
    if total_collateral <= Wad::ZERO {
        return (seized, Wad::ZERO);
    }

    let one_plus_bonus = Wad::ONE.checked_add(env, repayment.bonus.to_wad(env));

    let total_seizure_usd = repayment.repay_usd.mul(env, one_plus_bonus);
    let mut unseized_usd = Wad::ZERO;

    // Units: *_ray = RAY asset value (shares * index); *_scaled = RAY shares;
    // *_amount, pool_gross, realised_excess, fee_asset, and protocol_fee = token
    // units at the feed's decimals.
    for (hub_asset, position) in iter_typed_positions(&account.supply_positions) {
        let feed = cache.cached_price(&hub_asset.asset);
        let market_index = cache.cached_market_index(&hub_asset);

        let actual_ray = position.scaled_amount.mul(env, market_index.supply_index);
        let asset_value = risk::position_value(
            env,
            position.scaled_amount,
            market_index.supply_index,
            feed.price,
        );

        let share = asset_value.div(env, total_collateral);
        let seizure_for_asset_usd = total_seizure_usd.mul(env, share);

        let seizure_amount_wad = seizure_for_asset_usd.div(env, feed.price);
        let mut seizure_ray = seizure_amount_wad.to_ray(env);

        if !repayment.seize_all
            && feed.asset_decimals < MIN_BORROWABLE_ASSET_DECIMALS
            && seizure_ray < actual_ray

            if repayment.repays_all_debt {
                let whole = seizure_ray.to_asset_ceil(env, feed.asset_decimals);
                seizure_ray = Ray::from_asset(env, whole, feed.asset_decimals).min(actual_ray);
            } else {
                let whole = seizure_ray.to_asset_floor(env, feed.asset_decimals);
                seizure_ray = Ray::from_asset(env, whole, feed.asset_decimals);
                let whole_usd = seizure_ray.to_wad(env).mul(env, feed.price);

                }

        }

        if seizure_ray <= Ray::ZERO {
            continue;
        }

        let capped_ray = if repayment.seize_all {
            actual_ray
        } else {
            seizure_ray.min(actual_ray)

/// Socializes `bad_debt` by reducing the supply index (capped at total supply value).
///
/// Used when seizing unpaid debt: remaining supplier claims shrink pro-rata.
/// No-op when total supplied value is zero. Floors the resulting index at
/// [`SUPPLY_INDEX_FLOOR_RAW`] to avoid a zero index.
pub(crate) fn apply_bad_debt_to_supply_index(cache: &mut Cache, bad_debt: Ray) {
    let total_supplied_value = cache.supplied().mul(cache.env(), cache.supply_index());

    if total_supplied_value == Ray::ZERO {
        return;
    }

    let capped = bad_debt.min(total_supplied_value);
    let remaining = total_supplied_value.checked_sub(cache.env(), capped);

    let reduction_factor = remaining.div_floor(cache.env(), total_supplied_value);
    let new_supply_index = cache
        .supply_index()
        .mul_floor(cache.env(), reduction_factor);

    cache.set_supply_index(new_supply_index.max(Ray::from(SUPPLY_INDEX_FLOOR_RAW)));
