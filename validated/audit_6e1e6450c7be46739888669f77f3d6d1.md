### Title
Same-ledger borrow and repayment bypasses configured flash-loan fees - (File: `contracts/pool/src/interest.rs`)

### Summary
An account with sufficient collateral can call `borrow`, use the received liquidity, and call `repay` in the same ledger without paying interest or the market’s configured flash-loan fee. [1](#0-0) [2](#0-1) 

### Finding Description
Every pool mutation first calls `global_sync`, but it returns without accruing when no time elapsed since `last_timestamp`. [3](#0-2)  Consequently, a borrow executed after the market is synced stamps no additional interest before a same-ledger repayment; the repayment path simply burns the debt shares represented by the paid amount and refunds overpayment. [4](#0-3) [5](#0-4) 

The normal permissionless path is `controller.borrow(caller, account_id, borrows, to)` followed by `controller.repay(caller, account_id, payments)`; repayment may be submitted by anyone and requires only that the caller fund the measured transfer to the pool. [6](#0-5) [7](#0-6)  This bypasses the dedicated `flash_loan` path, which computes `amount * flashloan_fee / BPS`, charges at least one unit whenever the configured rate is positive, and books the result as protocol revenue. [8](#0-7) [9](#0-8) 

The deployed mainnet XLM market is flash-loanable with `flashloan_fee = 9` BPS, so this is not dependent on a zero-fee configuration. [10](#0-9)  The repository’s own regression test confirms that a same-ledger borrow/repay round trip leaves `supply_index`, `borrow_index`, and `last_timestamp` unchanged. [11](#0-10) 

### Impact Explanation
The attacker obtains atomic use of pool liquidity while paying no configured flash-loan fee and no measurable time-based interest. [12](#0-11)  On a positive-fee market, the pool’s cash and protocol revenue remain lower than they would be for the equivalent `flash_loan`; this is direct loss of unclaimed protocol yield rather than a rounding issue. [13](#0-12) 

The bypass is collateralized, so it does not provide uncollateralized liquidity, but collateralization does not compensate the pool for instant liquidity use: the same-ledger repayment returns principal while the configured flash fee is never assessed. [14](#0-13) [15](#0-14) 

### Likelihood Explanation
Any user who already controls a solvent collateralized account can perform the sequence, and a third party can fund the final `repay` operation. [7](#0-6)  The only timing requirement is that `repay` execute in the same ledger as the latest market accrual, which occurs naturally when the borrow and repay are included in one transaction or same-ledger operation sequence. [3](#0-2) 

### Recommendation
Assess an atomic-use charge when debt is opened and fully closed without elapsed time, such as the market’s configured `flashloan_fee`, or reject same-ledger closure of newly opened debt. [15](#0-14)  If ordinary same-ledger repayment must remain supported, record the opening timestamp or last borrow timestamp per debt position and apply the fee only to zero-elapsed borrow/repay round trips rather than to all borrows. [16](#0-15) 

### Proof of Concept
1. Create or use a solvent account with enough collateral to pass `process_borrow`’s post-pool solvency check. [17](#0-16) 
2. Call `controller.borrow(caller, account_id, [(USDC_hub_asset, amount)], Some(attacker))`. The pool mints ceiling-rounded debt shares, debits cash, and transfers `amount` to the attacker. [18](#0-17) [14](#0-13) 
3. Use `amount` in the attacker’s same-ledger arbitrage or swap flow.
4. Call `controller.repay(caller, account_id, [(USDC_hub_asset, amount_or_ceiled_debt)])`. Because `elapsed_ms() == 0`, `global_sync` does not move the borrow index, and `resolve_repay` burns the position without an interest or flash-fee component. [3](#0-2) [5](#0-4) 
5. Compare against `controller.flash_loan(..., amount, receiver, data)` on a `flashloan_fee = 9` market: the direct flash path requires `amount + fee`, while the borrow/repay path restores only principal. [19](#0-18) [20](#0-19)

/// Accrues borrow/supply indexes from `last_timestamp` to the cache's current time.
///
/// No-op when no time has elapsed. Splits long gaps into max-sized compound
/// windows, then sets `last_timestamp` to `current_timestamp`.
pub(crate) fn global_sync(env: &Env, cache: &mut Cache) {
    if !cache.needs_accrual() {
        return;
    }

    let mut remaining = cache.elapsed_ms();
    while let Some(nonzero) = NonZeroU64::new(remaining) {
        let chunk = nonzero.get().min(MAX_COMPOUND_DELTA_MS);
        accrue_chunk(env, cache, chunk);
        remaining = remaining.saturating_sub(chunk);
    }

    cache.mark_accrued();
}

/// Computes fee and expected pool balances from the pre-loan token balance.
pub(crate) fn terms(env: &Env, amount: i128, fee_bps: u32, pre_balance: i128) -> FlashTerms {
    let fee = Bps::from(i128::from(fee_bps)).flash_loan_fee_on(env, amount);
    FlashTerms {
        fee,
        total_repayment: amount
            .checked_add(fee)
            .unwrap_or_else(|| panic_with_error!(env, GenericError::MathOverflow)),
        balance_after_payout: pre_balance
            .checked_sub(amount)
            .unwrap_or_else(|| panic_with_error!(env, GenericError::MathOverflow)),
        balance_after_repayment: pre_balance
            .checked_add(fee)
            .unwrap_or_else(|| panic_with_error!(env, GenericError::MathOverflow)),
    }
}

pub(crate) fn accounting(env: &Env, action: &PoolAction) -> RepayOutcome {
    let (mut cache, position) = ops::load_leg(env, action);
    let amount = action.amount;

    let (burned, overpayment) = cache.resolve_repay(amount, position);

    cache.burn_debt(burned);

    cache.credit_cash(net_repay);

    let snapshot = cache.commit();

pub(crate) fn mint_debt(env: &Env, cache: &mut Cache, position: &mut Ray, amount: i128) {
    require_positive_amount(env, amount);
    cache.require_reserves(amount);
    guards::require_liquidation_buffer(env, cache, amount);

    let minted = cache.calculate_scaled_borrow(amount);

    assert_with_error!(
        env,
        minted.raw() > 0,
        GenericError::BorrowRoundsToZeroShares
    );

    *position = position.checked_add(env, minted);
    cache.mint_debt(minted);
    guards::require_utilization_below_max(env, cache);
