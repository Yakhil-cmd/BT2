### Title
Silent git-to-binary migration during `gh extension upgrade` bypasses git provenance with unverified binary download - ([File: pkg/cmd/extension/manager.go])

### Summary
`upgradeExtension` automatically migrates a previously git-cloned extension to the unauthenticated binary-release install path whenever the attacker-controlled repository's latest release contains an asset matching the local platform suffix, with no signature/checksum verification on the downloaded binary. This migration happens regardless of the `force` flag, meaning any repo owner (or anyone who can push a release to that repo) can flip a trusted git-history-based extension into a raw downloaded executable.

### Finding Description
In `pkg/cmd/extension/manager.go`, `upgradeExtension` (`manager.go:520-549`) checks `ext.IsBinary()`; for git-based extensions it re-derives the repo from the local clone's origin remote via `repoFromPath` and calls `isBinExtension(m.client, repo)` (`manager.go:534-539`), which is a purely repository-attacker-controlled signal — it only inspects release asset filenames for a matching platform suffix (`manager.go:748-770`, `possibleDists`). If `isBinExtension` returns true, the code unconditionally removes the existing git-cloned extension directory (`m.Remove(ext.Name())`) and calls `m.installBin(repo, "")` (`manager.go:540-545`) — this branch is **not gated by the `force` parameter** at all, unlike `upgradeGitExtension` which does check `force` for hard-reset behavior.

`installBin` (`manager.go:282-383`) selects the release asset by suffix match only (`manager.go:299-306`) and calls `downloadAsset` (`pkg/cmd/extension/http.go:79-112`), which performs a plain HTTP GET and writes the response body directly to `destPath` with mode `0755` (executable) — there is no checksum verification, no signature verification, and no sigstore/attestation check anywhere in this path. The `binManifest` written afterward (`manager.go:364-371`) contains no integrity data either.

This means the git-history-based trust model (where `gh` had previously verified nothing more than "this repo's HEAD is git-cloned/pulled," but at least the code the user runs is exactly the tracked git tree) is silently replaced by "download whatever bytes are behind a release asset URL and execute them," triggered purely by the attacker publishing a release with a suffix-matching asset name — no `--force` flag or explicit user opt-in to binary mode is required.

### Impact Explanation
An attacker who controls (or compromises) the extension's upstream repository can publish a release with an asset named to match the victim's platform (e.g., `gh-cool-ext-linux-amd64`), and the next `gh extension upgrade` (with or without `--force`) run by any victim who git-installed that extension will silently delete the git checkout and replace it with an unverified downloaded binary that becomes the executable invoked by `gh cool-ext`. This is code execution on the victim host contingent only on repository publish rights (which the threat model already grants to the "attacker-controlled extension repo" scenario), matching the "arbitrary code execution via unverified binary replacing a previously git-tracked extension" impact class.

### Likelihood Explanation
Preconditions are realistic and match common gh-extension usage: the victim has previously installed an extension via `gh extension install <repo>` where the repo lacked binary release assets (thus installed via git), and later runs `gh extension upgrade <name>` or `gh extension upgrade --all`. The attacker only needs push/release access to that same repository (which they already have as the extension author, or via a supply-chain compromise of that repo) — no MITM, no token, no local access. The suffix-matching heuristic in `isBinExtension`/`possibleDists` is broad and easy to satisfy. This is entirely repeatable and deterministic.

### Recommendation
- Do not silently migrate an installed git-based extension to the binary install path during `upgrade`; require explicit user consent (e.g., a distinct flag or interactive prompt) before switching install methods for an existing extension.
- Add integrity verification for the binary-asset install path: verify a checksum/signature (e.g., sigstore-based attestation verification, already implemented elsewhere in the codebase under `pkg/cmd/attestation`) before writing `downloadAsset` output to a location that becomes the invoked executable.
- At minimum, gate the git→bin migration branch in `upgradeExtension` behind the same `force` semantics as `upgradeGitExtension`, and surface a clear warning to the user when an extension's install method changes.

func (m *Manager) installBin(repo ghrepo.Interface, target string) error {
	var r *release
	var err error
	isPinned := target != ""
	if isPinned {
		r, err = fetchReleaseFromTag(m.client, repo, target)
	} else {
		r, err = fetchLatestRelease(m.client, repo)
	}
	if err != nil {
		return err
	}

	platform, ext := m.platform()
	isMacARM := platform == "darwin-arm64"
	trueARMBinary := false

	var asset *releaseAsset
	for _, a := range r.Assets {
		if strings.HasSuffix(a.Name, platform+ext) {
			asset = &a
			trueARMBinary = isMacARM
			break
		}
	}

	// if using an ARM-based Mac and an arm64 binary is unavailable, fall back to amd64 if a relevant binary is available and Rosetta 2 is installed
	if asset == nil && isMacARM {
		for _, a := range r.Assets {
			if strings.HasSuffix(a.Name, darwinAmd64) {
				if !hasRosetta() {
					return fmt.Errorf(
						"%[1]s unsupported for %[2]s. Install Rosetta with `softwareupdate --install-rosetta` to use the available %[3]s binary, or open an issue: `gh issue create -R %[4]s/%[1]s -t'Support %[2]s'`",
						repo.RepoName(), platform, darwinAmd64, repo.RepoOwner())
				}

				fallbackMessage := fmt.Sprintf("%[1]s not available for %[2]s. Falling back to compatible %[3]s binary", repo.RepoName(), platform, darwinAmd64)
				fmt.Fprintln(m.io.Out, fallbackMessage)

				asset = &a
				break
			}
		}
	}

	if asset == nil {
		cs := m.io.ColorScheme()
		errorMessageInRed := fmt.Sprintf(cs.Red("%[1]s unsupported for %[2]s."), repo.RepoName(), platform)
		issueCreateCommand := generateMissingBinaryIssueCreateCommand(repo.RepoOwner(), repo.RepoName(), platform)

		return fmt.Errorf(
			"%[1]s\n\nTo request support for %[2]s, open an issue on the extension's repo by running the following command:\n\n	`%[3]s`",
			errorMessageInRed, platform, issueCreateCommand)
	}

	if m.dryRunMode {
		return nil
	}

	name := repo.RepoName()
	if err := m.cleanExtensionUpdateDir(name); err != nil {
		return err
	}

	targetDir := filepath.Join(m.installDir(), name)
	if err = os.MkdirAll(targetDir, 0755); err != nil {
		return fmt.Errorf("failed to create installation directory: %w", err)
	}

	binPath := filepath.Join(targetDir, name)
	binPath += ext

	err = downloadAsset(m.client, safeurl.NewImmutableSafeURL(asset.APIURL), binPath)
	if err != nil {
		return fmt.Errorf("failed to download asset %s: %w", asset.Name, err)
	}
	if trueARMBinary {
		if err := codesignBinary(binPath); err != nil {
			return fmt.Errorf("failed to codesign downloaded binary: %w", err)
		}
	}

	manifest := binManifest{
		Name:     name,
		Owner:    repo.RepoOwner(),
		Host:     repo.RepoHost(),
		Path:     binPath,
		Tag:      r.Tag,
		IsPinned: isPinned,
	}

	bs, err := yaml.Marshal(manifest)
	if err != nil {
		return fmt.Errorf("failed to serialize manifest: %w", err)
	}

	if err := writeManifest(targetDir, manifestName, bs); err != nil {
		return err
	}

	return nil
}

func (m *Manager) upgradeExtension(ext *Extension, force bool) error {
	if ext.IsLocal() {
		return localExtensionUpgradeError
	}
	if !force && ext.IsPinned() {
		return pinnedExtensionUpgradeError
	}
	if !ext.UpdateAvailable() {
		return upToDateError
	}
	var err error
	if ext.IsBinary() {
		err = m.upgradeBinExtension(ext)
	} else {
		// Check if git extension has changed to a binary extension
		var isBin bool
		repo, repoErr := repoFromPath(m.gitClient, filepath.Join(ext.Path(), ".."))
		if repoErr == nil {
			isBin, _ = isBinExtension(m.client, repo)
		}
		if isBin {
			if err := m.Remove(ext.Name()); err != nil {
				return fmt.Errorf("failed to migrate to new precompiled extension format: %w", err)
			}
			return m.installBin(repo, "")
		}
		err = m.upgradeGitExtension(ext, force)
	}
	return err
}

func isBinExtension(client *http.Client, repo ghrepo.Interface) (isBin bool, err error) {
	var r *release
	r, err = fetchLatestRelease(client, repo)
	if err != nil {
		return
	}

	for _, a := range r.Assets {
		dists := possibleDists()
		for _, d := range dists {
			suffix := d
			if strings.HasPrefix(d, "windows") {
				suffix += ".exe"
			}
			if strings.HasSuffix(a.Name, suffix) {
				isBin = true
				break
			}
		}
	}

	return
}

func downloadAsset(httpClient *http.Client, assetURL safeurl.SafeURL, destPath string) (downloadErr error) {
	var req *http.Request
	if req, downloadErr = http.NewRequest("GET", assetURL.String(), nil); downloadErr != nil {
		return
	}

	req.Header.Set("Accept", "application/octet-stream")

	var resp *http.Response
	// TODO(api-client-rollout)
	// This has been deferred from moving to api.Client due to its custom Accept header and binary response streaming.
	if resp, downloadErr = httpClient.Do(req); downloadErr != nil {
		return
	}
	defer resp.Body.Close()

	if resp.StatusCode > 299 {
		downloadErr = api.HandleHTTPError(resp)
		return
	}

	var f *os.File
	if f, downloadErr = os.OpenFile(destPath, os.O_CREATE|os.O_WRONLY|os.O_TRUNC, 0755); downloadErr != nil {
		return
	}
	defer func() {
		if err := f.Close(); downloadErr == nil && err != nil {
			downloadErr = err
		}
	}()

	_, downloadErr = io.Copy(f, resp.Body)
	return
}
