**Rationale:**

The `weighted_sum` function and the underlying `VariableBaseMSM::msm` are part of `aptos-crypto`'s arkworks utilities used exclusively for cryptographic protocols such as DKG/PVSS transcripts, sigma protocols, and polynomial commitment schemes (KZG/Shplonk/Zeromorph), plus a generic Move-exposed elliptic-curve scalar-multiplication native for the `algebra` module. [1](#0-0) [2](#0-1) 

None of these code paths are involved in Aptos's actual multisig/transaction admission logic. The production multisig approval threshold check in `multisig_account.move` computes approvals by iterating owners and counting boolean votes stored in a `simple_map`, entirely independent of elliptic-curve arithmetic or MSM: `num_approvals_and_rejections_internal` and `validate_multisig_transaction` use plain integer counters (`num_approvals += 1`) compared against `num_signatures_required`. [3](#0-2) [4](#0-3) 

Likewise, the `MultiKey`/`MultiEd25519` authenticator threshold verification (used in transaction authenticators at the admission boundary) checks a bitmap/count of valid individual signatures, not a weighted elliptic-curve sum. [5](#0-4) [6](#0-5) 

Since `weighted_sum`/`VariableBaseMSM::msm` is not reachable from any unprivileged transaction/authenticator/API admission path (mempool, vm-validator, VM prologue, or multisig approval counting), the premise that an identity-point base could corrupt "approval-set weight sum bookkeeping used for multisig admission threshold checks" does not correspond to any real code path in this repository. The exploit scenario is invalid for this codebase.

    inline fun num_approvals_and_rejections_internal(owners: &vector<address>, transaction: &MultisigTransaction): (u64, u64) {
        let num_approvals = 0;
        let num_rejections = 0;

        let votes = &transaction.votes;
        owners.for_each_ref(|owner| {
            if (simple_map::contains_key(votes, owner)) {
                if (*simple_map::borrow(votes, owner)) {
                    num_approvals += 1;
                } else {
                    num_rejections += 1;
                };
            }
        });

        (num_approvals, num_rejections)
    }
