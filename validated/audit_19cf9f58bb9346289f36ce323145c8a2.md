### Title
Off-by-one Deadline Check in `checkBalanceForSwap` Allows Expired-Deadline Swap Bundles to Drain Proposer KAIA — (`kaiax/gasless/impl/tx_pool.go`)

---

### Summary

The txpool-level deadline guard in `checkBalanceForSwap` uses a strict-less-than comparison (`< 0`) against `currentBlock.Time()`, so a swap tx with `deadline == currentBlock.Time()` is admitted to the pool. No deadline re-check exists during block building. When the bundle executes in the next block (whose timestamp is `> currentBlock.Time()`), the on-chain `swapForGas` contract's deadline enforcement causes the SwapTx to revert. The LendTx has already transferred KAIA from the proposer to the sender; with SwapTx reverted, the repayment never occurs, and the proposer permanently loses the lent KAIA.

---

### Finding Description

`checkBalanceForSwap` is the sole deadline enforcement point in the gasless module. It is called only at txpool admission via `GetCheckBalance()`:

```go
// tx.deadline >= currentTimestamp
deadline := swapArgs.Deadline
if deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {
    return fmt.Errorf("insufficient deadline: ...")
}
``` [1](#0-0) 

The condition rejects only when `deadline < currentBlock.Time()`. When `deadline == currentBlock.Time()`, the comparison returns `0`, which is **not** `< 0`, so the tx is accepted.

During block building, `ExtractTxBundles` calls `IsExecutable` → `VerifyExecutable`: [2](#0-1) 

`VerifyExecutable` checks structural bundle validity (nonces, amounts, senders, repay amount) but contains **no deadline check**: [3](#0-2) 

Similarly, `IsReady` → `isSwapTxReady` → `IsExecutable` performs no deadline validation: [4](#0-3) 

The bundle execution order is fixed as `[LendTx, ApproveTx?, SwapTx]`: [5](#0-4) 

The `swapForGas` ABI includes a `deadline` parameter, and the module's own comment (`// tx.deadline >= currentTimestamp`) confirms the on-chain router enforces it at execution time. When the next block's `block.timestamp > deadline`, the router reverts the SwapTx.

---

### Impact Explanation

The bundle execution is not atomic in terms of failure recovery. LendTx (KAIA transfer from proposer to sender) executes and is committed. If SwapTx reverts, the repayment (`amountRepay`) never occurs. The proposer's KAIA is permanently transferred to the attacker with no compensation. This is an unauthorized KAIA transfer from the proposer (a system-managed fund holder in the gasless flow) to the attacker.

---

### Likelihood Explanation

The attack requires only a public RPC call to submit a swap tx with `deadline = currentBlock.Time()`. The current block time is publicly readable. No privileged access, validator collusion, or key compromise is needed. The attacker can repeat this every block to continuously drain the proposer. The only constraint is that the attacker must hold sufficient token balance and allowance to pass the `ShouldCheckToken()` checks, but those are standard user-controlled values.

---

### Recommendation

Change the deadline check from strict-less-than to less-than-or-equal, so that `deadline == currentBlock.Time()` is also rejected:

```go
// Before (buggy): accepts deadline == currentBlock.Time()
if deadline.Cmp(g.Chain.CurrentBlock().Time()) < 0 {

// After (fixed): rejects deadline == currentBlock.Time()
if deadline.Cmp(g.Chain.CurrentBlock().Time()) <= 0 {
``` [6](#0-5) 

Additionally, add a deadline re-check in `ExtractTxBundles` (or `VerifyExecutable`) against the pending block's expected timestamp, so that bundles with stale deadlines are dropped before the LendTx is ever created.

---

### Proof of Concept

1. Observe `currentBlock.Time()` = T via public RPC.
2. Submit a swap tx with `deadline = T`, valid token balance, and correct `amountRepay`.
3. `checkBalanceForSwap` evaluates `T.Cmp(T) < 0` → `0 < 0` → `false` → tx admitted to pool.
4. Proposer's node calls `ExtractTxBundles`; `VerifyExecutable` passes (no deadline check); bundle `[LendTx, SwapTx]` is assembled.
5. Next block is produced with `timestamp = T+1`.
6. LendTx executes: proposer sends `lendAmount` KAIA to attacker. State committed.
7. SwapTx executes: on-chain router checks `block.timestamp (T+1) <= deadline (T)` → false → revert.
8. Attacker's KAIA balance increased by `lendAmount`; proposer's KAIA balance decreased by `lendAmount`; no repayment.

func (g *GaslessModule) isSwapTxReady(swapTx, prevTx *types.Transaction) bool {
	addr, err := types.Sender(g.signer, swapTx)
	if err != nil {
		return false
	}
	nonce := g.getCurrentStateNonce(addr)

	var approveTx *types.Transaction
	if swapTx.Nonce() == nonce {
		approveTx = nil
	} else if swapTx.Nonce() == nonce+1 {
		if prevTx == nil || !g.IsApproveTx(prevTx) {
			return false
		}
		approveTx = prevTx
	} else {
		return false
	}

	return g.IsExecutable(approveTx, swapTx)
}

func (g *GaslessModule) VerifyExecutable(approveTxOrNil, swapTx *types.Transaction) error {
	// Sx.
	swapArgs, ok := decodeSwapTx(swapTx, g.signer)
	if !ok {
		return ErrDecodeSwapTx
	}
	if !g.isSwapTx(swapArgs) {
		return ErrSwapTxInvalid
	}

	// Conditions involving ApproveTx
	if approveTxOrNil != nil {
		// Ax.
		approveArgs, ok := decodeApproveTx(approveTxOrNil, g.signer)
		if !ok {
			return ErrDecodeApproveTx
		}
		if !g.isApproveTx(approveArgs) {
			return ErrApproveTxInvalid
		}
		// AP1.
		if approveArgs.Sender != swapArgs.Sender {
			return ErrDifferentSenders
		}
		// SP1.
		if approveArgs.Token != swapArgs.Token {
			return fmt.Errorf("%w: approve token %s, swap token %s", ErrDifferentTokens, approveArgs.Token.Hex(), swapArgs.Token.Hex())
		}
		// SP2.
		if approveArgs.Amount.Cmp(swapArgs.AmountIn) < 0 {
			return fmt.Errorf("%w: approve amount %s, required amount %s", ErrInsufficientApproveAmount, approveArgs.Amount.String(), swapArgs.AmountIn.String())
		}
		// SP3.
		if approveTxOrNil.Nonce()+1 != swapTx.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, swap nonce %d (expected %d)", ErrNonSequentialNonce, approveTxOrNil.Nonce(), swapTx.Nonce(), approveTxOrNil.Nonce()+1)
		}
		if nonce := g.getCurrentStateNonce(approveArgs.Sender); nonce != approveTxOrNil.Nonce() {
			return fmt.Errorf("%w: approve nonce %d, current nonce %d", ErrApproveNonceNotCurrent, approveTxOrNil.Nonce(), nonce)
		}
	} else {
		// SP3.
		if nonce := g.getCurrentStateNonce(swapArgs.Sender); nonce != swapTx.Nonce() {
			return fmt.Errorf("%w: swap nonce %d, current nonce %d", ErrSwapNonceNotCurrent, swapTx.Nonce(), nonce)
		}
	}

	// SP4.
	if swapArgs.AmountRepay.Cmp(repayAmount(approveTxOrNil, swapTx)) != 0 {
		return fmt.Errorf("%w: got %s, expected %s", ErrIncorrectRepayAmount, swapArgs.AmountRepay.String(), repayAmount(approveTxOrNil, swapTx).String())
	}

	return nil
}
