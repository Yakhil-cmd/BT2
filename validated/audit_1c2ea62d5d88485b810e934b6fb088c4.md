### Title
Unauthenticated `ServiceChainParentChainInfoResponseMsg` Allows Any Bridge Peer to Corrupt Parent Operator Nonce and Gas Price, Permanently Bricking the ServiceChain Bridge — (`node/sc/sub_bridge_handler.go`)

### Summary

`SubBridgeHandler.handleParentChainInfoResponseMsg` unconditionally applies `Nonce`, `GasPrice`, and `KIP71Config` values received in a `ServiceChainParentChainInfoResponseMsg` P2P message without verifying that the sending peer is the legitimate parent chain node. Any node that connects to the SubBridge P2P port with the correct parent `chainID` can send this message with attacker-controlled values, overwriting the bridge operator's nonce and gas-price state. Setting the nonce to `math.MaxUint64` permanently bricks all future bridge value-transfer transactions; setting `UpperBoundBaseFee` to zero (with `IsMagmaEnabled=true`) forces `remoteGasPrice` to zero, causing every bridge transaction to be rejected by the parent chain's txpool.

### Finding Description

**Root cause — no peer-identity check in the response handler.**

`SubBridgeHandler.RegisterNewPeer` admits any peer whose `chainID` matches the configured parent chain ID: [1](#0-0) 

The parent chain ID (e.g., Kaia mainnet `8217`) is publicly known. Once admitted, the peer can send any ServiceChain protocol message. `HandleMainMsg` dispatches `ServiceChainParentChainInfoResponseMsg` (code `0x04`) directly to `handleParentChainInfoResponseMsg` with no further authentication: [2](#0-1) 

`handleParentChainInfoResponseMsg` decodes the attacker-supplied `parentChainInfo` struct and unconditionally writes its fields into the bridge's protected state: [3](#0-2) 

The three state mutations are:

1. **Nonce** — `setParentOperatorNonce(pcInfo.Nonce)` is called in every branch of the nonce-selection logic (lines 292, 295, 299, 302). An attacker supplies `Nonce = math.MaxUint64`.
2. **Gas price** — `setRemoteGasPrice(pcInfo.GasPrice)` sets `pAccount.gasPrice` and `sbh.remoteGasPrice`: [4](#0-3) 
3. **KIP71 config** — when `IsMagmaEnabled=true`, `remoteGasPrice` is overwritten with `pcInfo.KIP71Config.UpperBoundBaseFee` and `SetParentKIP71Config` is called: [5](#0-4) 

The corrupted nonce is then embedded directly into every anchoring and value-transfer transaction built by `genUnsignedChainDataAnchoringTx`: [6](#0-5) 

The corrupted gas price is embedded as `TxValueKeyGasPrice` in the same transaction map (line 339).

**How the message is normally triggered.** The SubBridge sends `ServiceChainParentChainInfoRequestMsg` to all peers every `SyncRequestInterval` (10) blocks when nonce is unsynced, and on every new peer connection: [7](#0-6) 

There is no request-response correlation, no nonce, and no HMAC. Any peer that receives or intercepts the request — or simply sends an unsolicited response — will have its values applied.

**The `parentChainInfo` struct** carries all four attacker-controlled fields: [8](#0-7) 

### Impact Explanation

| Attack payload | Immediate effect | Protected-state impact |
|---|---|---|
| `Nonce = math.MaxUint64` | Every subsequent bridge tx is built with nonce `2^64-1` | Parent chain rejects all bridge txs with "nonce too high"; KAIA/ERC20/ERC721 value transfers permanently halted |
| `IsMagmaEnabled=true, UpperBoundBaseFee=0` | `remoteGasPrice` set to 0 | All bridge txs rejected by parent txpool (gas price below base fee); bridge bricked |
| `Nonce = current − 1` | Nonce regression | Duplicate-nonce txs; bridge operator account nonce desynchronised, causing replay failures |

The bridge operator account (`pAccount`) is the sole signing key for all cross-chain value transfers. Corrupting its nonce or gas price directly prevents any KAIA, ERC20, or ERC721 asset from crossing the bridge until an operator manually resets the state — and the attacker can re-corrupt it on the next sync cycle (every 10 blocks).

### Likelihood Explanation

The SubBridge P2P server is reachable by any node that knows the parent chain ID and the SubBridge's enode address. Both are publicly discoverable. The attacker does not need any on-chain funds, private keys, or validator status. The attack can be repeated every `SyncRequestInterval` (10 blocks, ~10 seconds on Kaia) because `SyncNonceAndGasPrice` is called periodically and on every new peer connection, and the handler applies the first valid-RLP response it receives.

### Recommendation

1. **Verify peer identity before applying nonce/gas-price updates.** The SubBridge should only accept `ServiceChainParentChainInfoResponseMsg` from the single configured parent-chain peer (matched by node ID, not just chain ID).
2. **Add request-response correlation.** Issue a random nonce with each `ServiceChainParentChainInfoRequestMsg` and reject responses that do not echo it.
3. **Bound the accepted nonce.** Reject any `pcInfo.Nonce` that exceeds the current on-chain nonce by more than a small threshold (e.g., 100), preventing `MaxUint64` injection.
4. **Bound the accepted gas price.** Reject `pcInfo.GasPrice` or `pcInfo.KIP71Config.UpperBoundBaseFee` values of zero or values that deviate unreasonably from the last known value.

### Proof of Concept

```
1. Attacker starts a Kaia node configured with parentChainID = <target SubBridge's parent chainID>.
2. Attacker connects to the SubBridge's P2P port (enode discoverable from the bridge's public endpoint).
3. SubBridgeHandler.RegisterNewPeer passes (chainID matches); SyncNonceAndGasPrice() is called,
   broadcasting ServiceChainParentChainInfoRequestMsg to all peers including the attacker.
4. Attacker immediately sends back a ServiceChainParentChainInfoResponseMsg (code 0x04) with:
     pcInfo = parentChainInfo{
         Nonce:          math.MaxUint64,
         GasPrice:       0,
         KIP71Config:    params.KIP71Config{UpperBoundBaseFee: 0, ...},
         IsMagmaEnabled: true,
     }
5. handleParentChainInfoResponseMsg decodes pcInfo; poolNonce == 0 (attacker has no txs in pool),
   so the else-branch executes: setParentOperatorNonce(math.MaxUint64).
   setRemoteChainValues sets remoteGasPrice = 0 and KIP71Config.UpperBoundBaseFee = 0.
6. setParentOperatorNonceSynced(true) is set → LocalChainHeadEvent now proceeds to build txs.
7. Every subsequent bridge tx (anchoring, KAIA transfer, ERC20 transfer) is built with
   nonce = math.MaxUint64 and gasPrice = 0 → rejected by parent chain txpool.
8. Bridge is permanently bricked until operator intervention; attacker repeats every 10 blocks.

func (sbh *SubBridgeHandler) handleParentChainInfoResponseMsg(p BridgePeer, msg p2p.Msg) error {
	var pcInfo parentChainInfo
	if err := msg.Decode(&pcInfo); err != nil {
		logger.Error("failed to decode", "err", err)
		return errResp(ErrDecode, "msg %v: %v", msg, err)
	}
	sbh.LockParentOperator()
	defer sbh.UnLockParentOperator()

	poolNonce := sbh.subbridge.bridgeTxPool.GetMaxTxNonce(sbh.GetParentOperatorAddr())
	if poolNonce > 0 {
		poolNonce += 1
		// just check
		if sbh.getParentOperatorNonce() > poolNonce {
			logger.Error("parent chain operator nonce is bigger than the chain pool nonce.", "BridgeTxPoolNonce", poolNonce, "mainChainAccountNonce", sbh.getParentOperatorNonce())
		}
		if poolNonce < pcInfo.Nonce {
			// BridgeTxPool journal miss txs which already sent to parent-chain
			logger.Error("chain pool nonce is less than the parent chain nonce.", "chainPoolNonce", poolNonce, "receivedNonce", pcInfo.Nonce)
			sbh.setParentOperatorNonce(pcInfo.Nonce)
		} else {
			// BridgeTxPool journal has txs which don't receive receipt from parent-chain
			sbh.setParentOperatorNonce(poolNonce)
		}
	} else if sbh.getParentOperatorNonce() > pcInfo.Nonce {
		logger.Error("parent chain operator nonce is bigger than the received nonce.", "mainChainAccountNonce", sbh.getParentOperatorNonce(), "receivedNonce", pcInfo.Nonce)
		sbh.setParentOperatorNonce(pcInfo.Nonce)
	} else {
		// there is no tx in bridgetTxPool, so parent-chain's nonce is used
		sbh.setParentOperatorNonce(pcInfo.Nonce)
	}
	sbh.setParentOperatorNonceSynced(true)
	sbh.setRemoteChainValues(pcInfo)
	logger.Info("ParentChainNonceResponse", "receivedNonce", pcInfo.Nonce, "gasPrice", pcInfo.GasPrice, "mainChainAccountNonce", sbh.getParentOperatorNonce())
	return nil
}
