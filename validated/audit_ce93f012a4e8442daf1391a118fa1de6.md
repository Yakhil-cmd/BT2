[1](#0-0)  It has no connection to transaction admission, fee-payer authenticator validation, sponsor/secondary-signer binding, gas, sequence number, or chain-id checks. The `client_known_version = None` case simply maps to `client_known_num_leaves = 0` (pre-genesis), which is the documented, intended behavior for a client bootstrapping with no prior accumulator state — not a bug. [2](#0-1)  The underlying `MerkleAccumulator::get_consistency_proof` deterministically computes frozen subtree siblings between two leaf counts using content-addressed hashes from the `HashReader`, so the returned proof mathematically commits to the accumulator's actual root hash — there is no code path here where an attacker-controlled input (transaction, authenticator, gas payload) could bias which hashes are returned or forge a root. [3](#0-2)  Verification of a consistency/range proof by a client always recomputes and checks against the actual committed root (as reflected in the `TransactionAccumulatorSummary::try_from_genesis_proof` usage), so no combination of `get_consistency_proof` and range-proof responses can "reconstruct" a different, misrepresented root without the underlying leaf/subtree hashes being cryptographically inconsistent and rejected.     /// Returns proof that shows the ledger at `ledger_version` is consistent with the ledger at
    /// `client_known_version`.
    pub fn get_consistency_proof(
        &self,
        client_known_version: Option<Version>,
        ledger_version: Version,
    ) -> Result<AccumulatorConsistencyProof> {
        let client_known_num_leaves = client_known_version
            .map(|v| v.saturating_add(1))
            .unwrap_or(0);
        let ledger_num_leaves = ledger_version.saturating_add(1);
        Accumulator::get_consistency_proof(self, ledger_num_leaves, client_known_num_leaves)
            .map_err(Into::into)
    }

    /// Implementation for public interface `MerkleAccumulator::get_consistency_proof`.
    fn get_consistency_proof(
        &self,
        sub_acc_leaves: LeafCount,
    ) -> Result<AccumulatorConsistencyProof> {
        ensure!(
            sub_acc_leaves <= self.num_leaves,
            "Can't get accumulator consistency proof for a version newer than the local version. \
            Local next version: {}, asked next version: {}",
            self.num_leaves,
            sub_acc_leaves,
        );

        let subtrees = FrozenSubtreeSiblingIterator::new(sub_acc_leaves, self.num_leaves)
            .map(|p| self.reader.get(p))
            .collect::<Result<Vec<_>>>()?;

        Ok(AccumulatorConsistencyProof::new(subtrees))
    }
