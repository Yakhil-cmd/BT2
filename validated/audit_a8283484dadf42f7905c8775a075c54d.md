### Title
Voting `governance.governingnode` to `address(0)` Permanently Locks Governance in Single Mode — (`kaiax/gov/headergov/impl/header.go`, `kaiax/gov/param.go`)

---

### Summary

The `checkConsistency` function for `governance.governingnode` votes validates only that the **current** governing node is in the council. It never validates the **new** value being voted in. Because `NewVoteData` also accepts `address(0)` as a valid `common.Address` for this parameter, the governing node in `single` mode can ratify a vote that sets `governance.governingnode` to `address(0)`. Once ratified, no block proposer can ever equal `address(0)`, so no future vote can pass `VerifyVote`'s single-mode check. Governance is permanently and irrecoverably locked.

---

### Finding Description

**Step 1 — `NewVoteData` accepts `address(0)` for `governance.governingnode`.**

The `FormatChecker` for `GovernanceGoverningNode` only asserts the canonical value is a `common.Address`:

```go
GovernanceGoverningNode: {
    Canonicalizer: addressCanonicalizer,
    FormatChecker: func(cv any) bool {
        _, ok := cv.(common.Address)
        return ok          // zero address passes
    },
    ...
    DefaultValue: common.HexToAddress("0x0000000000000000000000000000000000000000"),
},
```

The test suite explicitly lists `"0x0000000000000000000000000000000000000000"` as a **good vote** for this parameter, confirming zero address is accepted.

**Step 2 — `checkConsistency` validates the current governing node, not the new value.**

```go
case gov.GovernanceGoverningNode:
    params := h.GetParamSet(blockNum)
    if params.GovernanceMode != "single" {
        return nil
    }
    council, err := h.ValSet.GetCouncil(blockNum - 1)
    ...
    if slices.Contains(council, params.GoverningNode) {
        return nil          // only checks CURRENT governing node
    }
    return ErrGovNodeNotInValSetList
```

`vote.Value()` (the proposed new governing node) is never inspected. If the current governing node is in the council, any address — including `address(0)` — passes.

**Step 3 — After ratification, `VerifyVote` permanently rejects all future votes.**

In single mode, `VerifyVote` enforces:

```go
if h.ChainConfig.IsPermissionlessForkEnabled(...) &&
    params.GovernanceMode == "single" &&
    vote.Voter() != params.GoverningNode {
    return ErrVotePermissionDenied
}
```

With `params.GoverningNode == address(0)`, only a block proposer whose address is `address(0)` could vote. No real node has that address, so the condition `vote.Voter() != address(0)` is always true, and every future vote is rejected.

**Step 4 — The governance mode cannot be changed to escape the lock.**

`GovernanceGovernanceMode` is in `AlwaysDeprecated`:

```go
var AlwaysDeprecated = map[ParamName]struct{}{
    GovernanceGovernanceMode: {},
    ...
}
```

Votes on this parameter are always rejected. A chain that starts in `single` mode stays in `single` mode forever. There is no recovery path.

---

### Impact Explanation

Once the governing node is set to `address(0)` and the epoch ratifies the change, all governance parameter changes are permanently blocked: `reward.mintingamount`, `governance.unitprice`, `istanbul.committeesize`, `kip71.*`, `reward.ratio`, and all other live parameters are frozen at their current values with no on-chain mechanism to update them. This is a permanent, irreversible corruption of the governance state.

---

### Likelihood Explanation

The trigger is the current governing node casting a `governance.governingnode` vote with value `address(0)`. In `single` mode this is a single actor. The action could be accidental (e.g., a scripting error that passes an empty/zero address) or deliberate. The system provides no guard — the vote is accepted, serialised into `header.Vote`, verified by all peers, and ratified at the epoch boundary without any node raising an error.

---

### Recommendation

In `checkConsistency` for `gov.GovernanceGoverningNode`, validate the **proposed new value**, not only the current one:

```go
case gov.GovernanceGoverningNode:
    newNode := vote.Value().(common.Address)
    // Reject zero address
    if common.EmptyAddress(newNode) {
        return ErrInvalidGoverningNode
    }
    params := h.GetParamSet(blockNum)
    if params.GovernanceMode != "single" {
        return nil
    }
    council, err := h.ValSet.GetCouncil(blockNum - 1)
    if err != nil {
        return err
    }
    // New governing node must be reachable (in council)
    if !slices.Contains(council, newNode) {
        return ErrGovNodeNotInValSetList
    }
    // Current governing node must still be in council
    if !slices.Contains(council, params.GoverningNode) {
        return ErrGovNodeNotInValSetList
    }
    return nil
```

Alternatively, add a zero-address guard to the `FormatChecker` for `GovernanceGoverningNode` in `param.go`.

---

### Proof of Concept

1. Chain is in `single` governance mode with `governingNode = 0xGN`.
2. `0xGN` calls `governance_vote("governance.governingnode", "0x0000000000000000000000000000000000000000")`.
3. `NewVoteData` succeeds (zero address is a valid `common.Address`). [1](#0-0) 
4. `checkConsistency` checks only that `0xGN` is in the council — it is — and returns `nil`. The new value `address(0)` is never inspected. [2](#0-1) 
5. The vote is written to `header.Vote` when `0xGN` next proposes a block. All peers accept it via `VerifyVote` → `checkConsistency` (same path). [3](#0-2) 
6. At the next epoch boundary, `getExpectedGovernance` collects the vote and the epoch block's `header.Governance` is set to `{"governance.governingnode": "0x0000...0000"}`. All peers accept this governance data.
7. From `(k+1)*epoch` onward, `GetParamSet` returns `GoverningNode = address(0)`.
8. Every subsequent `governance_vote` call or `VerifyVote` check in single mode compares `voter != address(0)` — always true — and returns `ErrVotePermissionDenied`. [4](#0-3) 
9. `GovernanceGovernanceMode` is `AlwaysDeprecated`, so the mode cannot be changed to `none` to escape the lock. [5](#0-4) 
10. Governance is permanently frozen. The test file confirms `address(0)` is treated as a valid governing-node vote value with no rejection. [6](#0-5)

func (h *headerGovModule) VerifyVote(header *types.Header) error {
	if len(header.Vote) == 0 {
		return nil
	}

	var (
		vb       headergov.VoteBytes = header.Vote
		blockNum                     = header.Number.Uint64()
	)

	vote, err := vb.ToVoteData()
	if err != nil {
		logger.Error("ToVoteData error", "num", blockNum, "vote", vb, "err", err)
		return err
	}

	if gov.DeprecatedAt(vote.Name(), h.ChainConfig.Rules(header.Number)) {
		logger.Error("Vote is deprecated", "num", blockNum, "name", vote.Name())
		return ErrDeprecatedVote
	}

	council, err := h.ValSet.GetCouncil(blockNum)
	if err != nil {
		return err
	}

	// check if the voter is in council
	if !slices.Contains(council, vote.Voter()) {
		return ErrInvalidKeyValue
	}

	// check if Voter is the block proposer.
	author, err := h.Chain.Sealer().Author(header)
	if err != nil {
		return err
	}
	if author != vote.Voter() {
		return ErrInvalidVoter
	}

	// In single mode, only the governing node can write header.Vote after Permissionless.
	params := h.GetParamSet(blockNum)
	if h.ChainConfig.IsPermissionlessForkEnabled(new(big.Int).SetUint64(blockNum)) &&
		params.GovernanceMode == "single" &&
		vote.Voter() != params.GoverningNode {
		return ErrVotePermissionDenied
	}

	return h.checkConsistency(blockNum, vote)
}
```

// checkConsistency checks if vote values are consistent with chain states such as other parameters and validator set.
func (h *headerGovModule) checkConsistency(blockNum uint64, vote headergov.VoteData) error {
	switch vote.Name() {
	case gov.GovernanceGoverningNode:
		params := h.GetParamSet(blockNum)

		// compare with governing node only in single mode.
		if params.GovernanceMode != "single" {
			return nil
		}

		// we'll use blockNum-1 for the blocknumber of GetCouncil since blockNum cannot be available(eg. vote)
		// it's definite that the valSet vote is not included in this block
		// so the council(blockNum - 1) and council(blockNum) should be same
		council, err := h.ValSet.GetCouncil(blockNum - 1)
		if err != nil {
			return err
		}

		if slices.Contains(council, params.GoverningNode) {
			return nil
		}
		return ErrGovNodeNotInValSetList
```
